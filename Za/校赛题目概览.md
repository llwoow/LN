# 校赛题目概览
总结每个数学建模竞赛选题的问题和要求，并分析其难易程度和建模思路。文档中包含以下六个问题：

# Problem A: Cloud Formation over an Oceanic Island（MCM）

问题总结：**该问题要求建立耦合大气热力学和动力学的模型，预测海洋性岛屿上空云的宏观特征（如类型、位置、高度）随时间（从早到晚）的演变，考虑背景风场、海表温度等因素。核心是模拟云的形成物理过程。**
要求总结：

建模空气团绝热上升的温度变化和抬升凝结高度。
引入环境温度剖面，分析对流有效位能（CAPE）并预测云类型。
建立二维和三维模型，模拟海陆风与地形强迫下的垂直速度场和云分布。
预测时空演化（如云线形成、无云区）。
验证模型（如卫星数据）并进行敏感性分析。
提交报告（不超过25页）。

难易分析：**高难度**。问题需要专业的大气科学知识，涉及偏微分方程、数值模拟和物理参数化。难点在于耦合热力学和动力学过程，并处理非线性效应（如敏感性问题）。但文档提供了详细物理过程说明（如附录），为建模提供了基础。
建模思路：

热力学模型：使用绝热过程方程（如泊松方程）计算温度变化和凝结高度。
稳定性分析：基于环境温度剖面计算CAPE，判断云类型（如积云 vs. 层云）。
动力学模型：采用流体力学方程（如Navier-Stokes方程）模拟海陆风环流和地形抬升，数值解法（如有限差分）计算垂直速度场。
时空演化：引入时间依赖的太阳辐射函数，耦合表面热通量，模拟云的生消过程。
验证与敏感性：对比遥感数据（如卫星云图），并扰动参数（如风速、海温）分析非线性响应。

# Problem B: The Millennium-Old Hydraulic Project Dujiangyan（MCM）

问题总结：**该问题要求用数学模型阐释都江堰水利工程的分水（旱涝季节流量分配）和排沙原理，验证其科学性和有效性。核心是水力学和泥沙动力学建模。**
要求总结：

建立分水模型，计算不同总流量下内江与外江的流量比例（如旱季60-40，汛期40-60）。
建立排沙模型，解释都江堰如何减少内江泥沙浓度。
使用水文和几何数据验证结果。
提交报告（不超过25页）。

难易分析：**中等**。问题聚焦具体工程，涉及经典水力学公式，数据需求明确（如流量、泥沙数据）。难点在于准确模拟泥沙输运（非均匀流），但都江堰结构相对简单，有现成理论可参考（如曼宁公式）。
建模思路：

分水模型：应用水力学公式（如伯努利方程或堰流公式），基于几何形状（如鱼嘴、飞沙堰）计算流量分配。
排沙模型：使用泥沙运动学方程（如悬移质输沙公式），结合流速和湍流分析，解释“弯道环流”等排沙机制。
验证：收集历史水文数据（如流量记录），进行回归分析或计算误差。

# Problem C: U.S. Tariff Wars（MCM）

问题总结：**该问题要求分析2025年美国发动的关税战对美国、中国和全球经济的短期和长期影响，包括经济产出、贸易变化和全球供应链。核心是贸易经济学建模。**
要求总结：

收集数据，建立模型分析关税战对美国经济产出的短期影响。
分析对中国经济的短长期影响（如贸易、产业升级）。
描绘对全球经济的变化（如贸易收缩、增长放缓）。
评估模型不确定性和性能指标。
提交报告（不超过25页）。

难易分析：**中等偏难**。问题涉及宏观经济建模，需要大量贸易和经济数据（如GDP、关税税率），且需处理动态影响和不确定性。难点在于预测长期效应和全球联动性，但文档提供了历史案例和影响机制，降低了理论难度。
建模思路：

短期影响：使用计量经济学模型（如向量自回归VAR）或投入产出分析，量化关税对价格、消费和产出的冲击。
长期影响：构建可计算一般均衡（CGE）模型，模拟产业结构和全球供应链变化。
全球影响：通过情景分析或系统动力学，评估贸易摩擦的多米诺效应。
不确定性评估：采用蒙特卡洛模拟或置信区间分析模型预测的稳健性。

# Problem D: Of rats and garbagemen sanitation workers（ICM）

问题总结：**该问题要求为纽约市曼哈顿区的垃圾收运系统设计一个综合优化方案，重点解决资源分配、效率与公平性评估、应对突发事件（如车辆故障或天气变化）、鼠患控制以及推广使用带盖垃圾桶的影响。核心目标是提升垃圾管理的效率、公平性和韧性。**
要求总结：

制定资源分配策略，优化曼哈顿12个卫生区的收运频率和卡车数量。
提出量化指标评估方案的效率与公平性（尤其关注低收入社区）。
分析常见中断场景（如天气、节日）的应对策略。
研究垃圾问题与鼠患的相关性，并设计收运策略以减少鼠群。
评估带盖垃圾桶强制推广对鼠患和卡车需求的影响。
提交一份详细报告，包括一页执行摘要、完整解决方案等（不超过25页）。

难易分析：**中等偏难**。问题涉及多目标优化（效率、公平、韧性）、数据驱动分析（需垃圾产量、鼠患数据等）和现实约束（如街道狭窄）。难点在于平衡相互冲突的目标（如效率与公平），并整合突发场景模拟。但文档提供了基础数据（如垃圾产量、卡车容量），降低了数据收集难度。
建模思路：

资源分配：使用整数规划或线性规划优化卡车调度和收运频率，考虑各区垃圾产量、道路网络等约束。
效率与公平：定义指标如收运延迟时间（效率）和基尼系数（公平性），并通过多准则决策模型（如TOPSIS）权衡取舍。
中断场景：采用蒙特卡洛模拟或鲁棒优化模型，模拟车辆故障或天气变化的影响，并设计备份路线或共享卡车策略。
鼠患控制：使用相关性分析（如皮尔逊系数） linking 垃圾暴露时间与鼠患数据，并基于收运时间优化（如早晨 vs. 傍晚收运）减少鼠群食物源。
垃圾桶影响：通过成本效益分析或系统动力学模型，评估带盖垃圾桶对鼠患减少和收运效率的提升（如装载时间缩短）。

# Problem E: A Global Strategy for Regulatory T-Cell Therapies（ICM）

问题总结：**该问题要求为国际健康规划委员会（IHPC）制定Treg疗法的全球研发与分配策略，涉及疾病优先级排序、研发资金分配、个体治疗响应预测、公平定价和市场竞争分析。目标是最大化健康效益并减少不平等。**
要求总结：

构建多维度评估模型，优先选择Treg疗法研发的疾病（如基于疾病负担、治疗潜力）。
设计动态资源分配模型，优化50亿美元研发资金在不同阶段的分配。
建立个体治疗响应预测模型，基于患者特征（如年龄、基因）。
设计公平定价和分配框架，确保全球可及性。
分析技术垄断与竞争场景的影响。
提交战略备忘录和报告（不超过25页）。

难易分析：**高难度**。问题高度复杂，涉及多学科交叉（医学、经济学、优化理论），需要处理不确定性（如研发成功率）和全球公平性问题。难点在于整合多个子模型（如优先级排序、资金分配）并平衡短期与长期目标。但文档提供了明确框架，降低了问题模糊性。
建模思路：

疾病优先级：使用多属性决策模型（如TOPSIS或加权评分），整合疾病负担、治疗缺口等指标。
资金分配：采用动态规划或随机优化模型，模拟研发阶段的风险和收益，最大化预期健康效益。
治疗响应预测：应用机器学习模型（如逻辑回归或随机森林），基于患者数据分类响应概率。
公平定价：设计游戏理论模型或差别定价策略，结合成本-效果分析。
市场竞争分析：使用Agent-based模拟或均衡模型，比较垄断与竞争下的价格和创新激励。

# Problem F: Selection of rental and purchase plans（ICM）

问题总结：**该问题聚焦中国重庆或深圳的住房市场，要求分析个人住房决策（如新员工租房购房策略、已有住房者换房决策），预测未来房价趋势，并向政府或开发商提出建议。核心是建立住房选择的经济模型。**
要求总结：

为新入职外地员工制定租房与购房策略的决策方法，包括因素权重确定。
为已有住房者提供换房决策方案（如时机和方式）。
基于近年统计数据预测未来5-10年房价趋势。
向政府或开发商提出政策建议。
提交报告（不超过25页），含摘要、目录等。

难易分析：**中等**。问题涉及经济学建模和预测，需要住房市场数据（如价格、租金、人口统计），但文档未提供具体数据，需参赛者自行收集。难点在于房价预测的不确定性和个人决策的复杂性（如多因素权衡）。然而，问题结构清晰，有标准建模方法可循。
建模思路：

租房购房策略：采用多准则决策模型（如层次分析法AHP）确定因素权重（如收入、利率、通勤时间），并构建效用函数比较不同方案。
换房决策：使用动态规划或最优停止理论，考虑房价波动、交易成本等，最大化长期收益。
房价预测：应用时间序列模型（如ARIMA）或机器学习方法（如回归分析），结合宏观经济指标（如GDP、人口增长率）。
政策建议：基于模型结果，设计仿真（如系统动力学）评估政策影响（如补贴或税收）。
