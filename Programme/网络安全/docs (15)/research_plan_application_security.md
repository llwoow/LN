# 应用层安全、Web应用安全和软件安全开发研究计划

## 研究目标
深入研究应用层安全、Web应用安全和软件安全开发的六个核心领域，重点关注漏洞原理、检测方法和防护策略。

## 研究范围
1. Web应用安全漏洞（OWASP Top 10）
2. 安全开发生命周期（SDL）
3. 代码审计和安全测试
4. 数据库安全
5. API安全
6. 移动应用安全
