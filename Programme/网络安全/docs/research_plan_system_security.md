# 操作系统安全、访问控制和安全加固技术研究计划

## 研究目标
深入研究操作系统安全、访问控制和安全加固技术，重点关注安全模型、权限管理和安全配置。

## 研究范围
1. 访问控制模型（自主访问控制DAC、强制访问控制MAC、基于角色的访问控制RBAC）
2. 身份认证和授权
3. 操作系统安全机制
4. 系统安全加固
5. 虚拟化安全
6. 容器安全
