## 2. 基础数据结构

### 2.1 线性表

#### 2.1.1 数组（Array）

##### 基本概念
线性表是最基础的数据结构，数组是其中最重要的实现方式。

**定义**: 数组是具有相同类型的数据元素的有限序列。

**数学表示**: $A = (a_1, a_2, a_3, ..., a_n)$，其中 $a_i$ 是第 $i$ 个元素。

##### 数组的基本操作

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 访问元素 $A[i]$ | $O(1)$ | $O(1)$ | 直接寻址 |
| 插入元素 | $O(n)$ | $O(1)$ | 需要移动元素 |
| 删除元素 | $O(n)$ | $O(1)$ | 需要移动元素 |
| 查找元素 | $O(n)$ | $O(1)$ | 顺序查找 |

##### 数组的优缺点

**优点**:
- 随机访问速度快 $O(1)$
- 内存连续，缓存友好
- 实现简单

**缺点**:
- 插入删除需要移动元素 $O(n)$
- 大小固定（静态数组）
- 可能造成内存浪费

#### 2.1.2 链表（Linked List）

##### 单向链表

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

**基本操作复杂度**:

| 操作 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 访问第 $i$ 个节点 | $O(n)$ | $O(1)$ | 需要遍历 |
| 插入节点 | $O(1)$ | $O(1)$ | 已知位置 |
| 删除节点 | $O(1)$ | $O(1)$ | 已知位置 |
| 查找节点 | $O(n)$ | $O(1)$ | 顺序查找 |

##### 双向链表

```python
class DListNode:
    def __init__(self, val=0, prev=None, next=None):
        self.val = val
        self.prev = prev
        self.next = next
```

**优势**:
- 可以双向遍历
- 删除操作更高效（无需前驱指针）

##### 循环链表

**特点**: 最后一个节点的next指向头节点，形成循环。

**应用场景**:
- 约瑟夫环问题
- 操作系统中的进程调度

#### 2.1.3 静态链表

**定义**: 用数组实现的链表，通过数组下标模拟指针。

**优点**:
- 避免频繁的内存分配
- 插入删除不需要移动元素

**缺点**:
- 失去了链表随机访问的优点
- 需要预先分配固定大小的数组

### 2.2 栈和队列

#### 2.2.1 栈（Stack）

##### 定义与性质
**定义**: 栈是一种后进先出（LIFO, Last In First Out）的线性表。

**数学性质**: 设栈 $S = (a_1, a_2, ..., a_n)$，则：
- $a_1$ 称为栈底元素
- $a_n$ 称为栈顶元素
- 插入和删除操作都在栈顶进行

##### 基本操作

| 操作 | 描述 | 时间复杂度 | 空间复杂度 |
|------|------|------------|------------|
| `push(x)` | 将元素x压入栈顶 | $O(1)$ | $O(1)$ |
| `pop()` | 弹出栈顶元素 | $O(1)$ | $O(1)$ |
| `top()` | 获取栈顶元素 | $O(1)$ | $O(1)$ |
| `isEmpty()` | 判断栈是否为空 | $O(1)$ | $O(1)$ |

##### 栈的应用

1. **函数调用栈** - 保存函数调用信息
2. **表达式求值** - 中缀表达式转后缀表达式
3. **括号匹配** - 验证括号序列的正确性
4. **深度优先搜索（DFS）** - 图和树的遍历

<details>
<summary><strong>中缀表达式转后缀表达式算法推导</strong></summary>

**问题**: 将中缀表达式转换为后缀表达式（逆波兰表示法）

**算法思想**:
1. 初始化一个空栈和空结果列表
2. 从左到右扫描中缀表达式
3. 遇到操作数时，直接输出到结果列表
4. 遇到运算符时：
   - 如果栈顶运算符优先级低于当前运算符，压入栈
   - 否则弹出栈顶运算符到结果列表，直到栈顶运算符优先级低于当前运算符
5. 遇到左括号时，压入栈
6. 遇到右括号时，弹出栈顶运算符到结果列表，直到遇到左括号
7. 最后将栈中剩余运算符全部弹出到结果列表

**正确性证明**:

*引理1*: 栈中运算符的优先级从栈底到栈顶严格递增。

*证明*: 当运算符被压入栈时，所有优先级更高的运算符已经弹出。因此，栈中的运算符优先级不会递减。∎

*引理2*: 当右括号出现时，栈顶到左括号的运算符序列正好对应一个完整的子表达式。

*证明*: 根据引理1，左括号被压入栈后，只有优先级更高的运算符才能被压入在其上。当遇到右括号时，弹出的运算符序列正好是从该左括号到当前右括号的完整子表达式。∎

*定理*: 该算法产生正确的后缀表达式。

*证明*: 通过数学归纳法，对表达式长度进行归纳。基础情况显然成立。假设长度小于n的表达式处理正确，对于长度为n的表达式，根据算法规则处理每个token，最终得到的序列满足后缀表达式的定义。∎
</details>

##### 栈的数组实现

```python
class Stack:
    def __init__(self, capacity=100):
        self.data = [0] * capacity
        self.top = -1
        self.capacity = capacity
    
    def push(self, x):
        if self.top + 1 >= self.capacity:
            raise Exception("Stack overflow")
        self.top += 1
        self.data[self.top] = x
    
    def pop(self):
        if self.top == -1:
            raise Exception("Stack underflow")
        x = self.data[self.top]
        self.top -= 1
        return x
```

#### 2.2.2 队列（Queue）

##### 定义与性质
**定义**: 队列是一种先进先出（FIFO, First In First Out）的线性表。

**数学表示**: 设队列 $Q = (a_1, a_2, ..., a_n)$，其中：
- $a_1$ 称为队头（front）
- $a_n$ 称为队尾（rear）
- 插入操作在队尾进行，删除操作在队头进行

##### 基本操作

| 操作 | 描述 | 时间复杂度 | 空间复杂度 |
|------|------|------------|------------|
| `enqueue(x)` | 将元素x加入队尾 | $O(1)$ | $O(1)$ |
| `dequeue()` | 移除队头元素 | $O(1)$ | $O(1)$ |
| `front()` | 获取队头元素 | $O(1)$ | $O(1)$ |
| `isEmpty()` | 判断队列是否为空 | $O(1)$ | $O(1)$ |

##### 循环队列

**问题**: 顺序队列的假溢出问题

**解决方案**: 使用循环队列，将队列的首尾相连。

**关键公式**:
- 队空条件: `front == rear`
- 队满条件: `(rear + 1) % capacity == front`
- 队列长度: `(rear - front + capacity) % capacity`

<details>
<summary><strong>循环队列队满条件的推导</strong></summary>

**问题**: 如何判断循环队列是否已满？

**分析**: 如果简单地使用 `front == rear` 作为队满条件，会与队空条件冲突。

**解决方案**: 牺牲一个存储单元

**队满条件推导**:
设队列容量为 `capacity`，数组索引范围为 `[0, capacity-1]`

1. **队空条件**: `front == rear`
2. **队满条件**: `(rear + 1) % capacity == front`

**证明**:
- 当队列只有一个元素时，`front = 0`, `rear = 0`
- 插入一个元素后，`front = 0`, `rear = 1`
- 再插入一个元素后，`front = 0`, `rear = 2`
- ...
- 当 `rear = capacity-1` 时，插入元素后 `rear = (capacity-1 + 1) % capacity = 0`
- 此时 `front = 0`, `rear = 0`，但队列实际已满

因此，队满条件应该是 `(rear + 1) % capacity == front`

**空间利用率**: 最大为 `(capacity-1) / capacity`
</details>

##### 双端队列（Deque）

**定义**: 双端队列允许在两端进行插入和删除操作。

**基本操作**:
- `addFirst(x)` - 在队头插入
- `addLast(x)` - 在队尾插入  
- `removeFirst()` - 移除队头
- `removeLast()` - 移除队尾

**应用场景**:
- 滑动窗口问题
- 股票价格的最大值问题

### 2.3 堆和优先队列

#### 2.3.1 堆的定义与性质

##### 基本概念
**堆（Heap）**: 堆是完全二叉树的一种特殊实现，可以分为最大堆和最小堆。

**最大堆**: 父节点的值大于等于子节点的值
**最小堆**: 父节点的值小于等于子节点的值

**数学性质**: 对于任意节点 $i$：
- 左子节点: $2i + 1$（0-based索引）
- 右子节点: $2i + 2$（0-based索引）
- 父节点: $\lfloor (i-1)/2 \rfloor$

##### 堆的存储

由于堆是完全二叉树，可以用数组顺序存储：

```
        10
       /  \
      5    3
     / \
    2   4

数组表示: [10, 5, 3, 2, 4]
```

#### 2.3.2 堆的基本操作

##### 插入操作（Heapify Up）

```python
def heap_insert(heap, x):
    heap.append(x)
    i = len(heap) - 1
    while i > 0:
        parent = (i - 1) // 2
        if heap[parent] >= x:  # 最小堆
            break
        heap[i], heap[parent] = heap[parent], heap[i]
        i = parent
```

**时间复杂度**: $O(\log n)$

##### 删除堆顶元素（Heapify Down）

```python
def heap_extract_min(heap):
    if len(heap) == 0:
        return None
    min_val = heap[0]
    heap[0] = heap[-1]
    heap.pop()
    heapify_down(heap, 0)
    return min_val

def heapify_down(heap, i):
    n = len(heap)
    while True:
        left = 2 * i + 1
        right = 2 * i + 2
        smallest = i
        
        if left < n and heap[left] < heap[smallest]:
            smallest = left
        if right < n and heap[right] < heap[smallest]:
            smallest = right
            
        if smallest == i:
            break
            
        heap[i], heap[smallest] = heap[smallest], heap[i]
        i = smallest
```

**时间复杂度**: $O(\log n)$

##### 建堆操作

**自底向上建堆**:
```python
def build_heap(arr):
    n = len(arr)
    for i in range(n // 2 - 1, -1, -1):
        heapify_down(arr, i)
```

**时间复杂度**: $O(n)$

<details>
<summary><strong>建堆时间复杂度证明</strong></summary>

**定理**: 建堆操作的时间复杂度为 $O(n)$

**证明**:

设 $T(n)$ 为对大小为 $n$ 的堆进行建堆操作的时间复杂度。

对于高度为 $h$ 的节点，最多需要向下调整 $h$ 层。

- 高度为 0 的节点（叶子节点）: $n/2$ 个，每个调整 0 次
- 高度为 1 的节点: $n/4$ 个，每个调整 1 次  
- 高度为 2 的节点: $n/8$ 个，每个调整 2 次
- ...
- 高度为 $h$ 的节点: 1 个，调整 $h$ 次

总时间复杂度为:
$$T(n) \leq \sum_{i=0}^{h} \frac{n}{2^{i+1}} \cdot i$$

令 $k = i$，则:
$$T(n) \leq \frac{n}{2} \sum_{k=0}^{h} \frac{k}{2^k}$$

已知无穷级数 $\sum_{k=0}^{\infty} \frac{k}{2^k} = 2$

因此:
$$T(n) \leq \frac{n}{2} \cdot 2 = n$$

即 $T(n) = O(n)$ ∎
</details>

#### 2.3.3 优先队列

**定义**: 优先队列是一种抽象数据类型，支持以下操作：
- `insert(x)`: 插入元素 $x$
- `extract_max()`: 移除并返回最大元素
- `peek()`: 返回最大元素（不删除）

**实现方式比较**:

| 实现方式 | 插入 | 删除最大 | 查看最大 | 空间复杂度 |
|----------|------|----------|----------|------------|
| 无序数组 | $O(1)$ | $O(n)$ | $O(n)$ | $O(n)$ |
| 有序数组 | $O(n)$ | $O(1)$ | $O(1)$ | $O(n)$ |
| 平衡二叉搜索树 | $O(\log n)$ | $O(\log n)$ | $O(1)$ | $O(n)$ |
| **堆** | $O(\log n)$ | $O(\log n)$ | $O(1)$ | $O(n)$ |

**堆是最优实现**，因为它在所有操作上都达到了良好的时间复杂度。

### 2.4 树和二叉树

#### 2.4.1 树的基本概念

##### 定义
**树（Tree）**: 树是 $n$ 个节点的有限集合 $T$，满足：
1. $T$ 为空时称为空树
2. $T$ 非空时，有且仅有一个称为根（root）的节点
3. 其余节点分为 $m$ 个互不相交的子集 $T_1, T_2, ..., T_m$，每个子集本身又是一棵树

##### 基本术语

| 术语 | 定义 | 举例 |
|------|------|------|
| 节点 | 树中的基本元素 | 图中的圆圈 |
| 边 | 连接两个节点的线段 | 节点间的连线 |
| 根节点 | 没有父节点的节点 | 树的最高层节点 |
| 叶子节点 | 没有子节点的节点 | 最底层节点 |
| 内部节点 | 非根节点和非叶子节点 | 有子节点但不是根 |
| 父节点 | 某节点的直接上级节点 | 节点的直接前驱 |
| 子节点 | 某节点的直接下级节点 | 节点的直接后继 |
| 兄弟节点 | 拥有相同父节点的节点 | 同一层的相邻节点 |
| 祖先节点 | 从根到某节点的路径上的所有节点 | 路径上的所有节点 |
| 子孙节点 | 某节点的所有后代节点 | 子树中的所有节点 |
| 度 | 节点的子节点个数 | 节点的孩子数量 |
| 树的度 | 树中所有节点度的最大值 | 树的最大分支数 |
| 层次 | 根节点为第1层，其子节点为第2层，依此类推 | 节点的深度 |
| 树的高度 | 树中节点的最大层次数 | 树的最大深度 |
| 深度 | 从根节点到某节点的路径长度 | 节点的层次数 |

##### 树的性质

**性质1**: 树中的节点数等于所有节点的度数之和加1。

$$\sum_{i=1}^{n} deg(v_i) = n - 1$$

**性质2**: 高度为 $h$ 的树最多有 $2^h - 1$ 个节点。

**性质3**: 高度为 $h$ 的满二叉树有 $2^{h-1}$ 个叶子节点。

#### 2.4.2 二叉树

##### 定义
**二叉树（Binary Tree）**: 二叉树是有限个节点的集合，这个集合或者是空集，或者是由一个根节点和两棵互不相交的左子树和右子树组成。

**数学表示**: 二叉树 $T = (r, L, R)$，其中：
- $r$ 是根节点
- $L$ 是左子树
- $R$ 是右子树

##### 二叉树的性质

**性质1**: 在二叉树的第 $i$ 层上最多有 $2^{i-1}$ 个节点。

**性质2**: 深度为 $h$ 的二叉树最多有 $2^h - 1$ 个节点。

**性质3**: 对于任何一棵二叉树 $T$，如果叶子节点数为 $n_0$，度为2的节点数为 $n_2$，则：
$$n_0 = n_2 + 1$$

<details>
<summary><strong>二叉树性质3的证明</strong></summary>

**定理**: 在任何二叉树中，叶子节点数等于度为2的节点数加1。

**证明**:

设：
- $n$ 为总节点数
- $n_0$ 为叶子节点数（度为0）
- $n_1$ 为度为1的节点数  
- $n_2$ 为度为2的节点数

则有：
$$n = n_0 + n_1 + n_2 \quad (1)$$

设 $E$ 为二叉树中的边数。每条边连接一个父节点和一个子节点。

从子节点的角度看，每个节点（除了根节点）都有一条指向它的边，因此：
$$E = n - 1 \quad (2)$$

从父节点的角度看，每个度为 $i$ 的节点都有 $i$ 条边指向它的子节点，因此：
$$E = 0 \cdot n_0 + 1 \cdot n_1 + 2 \cdot n_2 = n_1 + 2n_2 \quad (3)$$

由(2)和(3)得：
$$n - 1 = n_1 + 2n_2 \quad (4)$$

将(1)代入(4)：
$$(n_0 + n_1 + n_2) - 1 = n_1 + 2n_2$$

化简得：
$$n_0 - 1 = n_2$$

即：
$$n_0 = n_2 + 1$$

证毕。∎
</details>

##### 特殊二叉树

1. **满二叉树（Full Binary Tree）**
   - 定义: 所有叶子节点都在同一层，且所有非叶子节点都有两个子节点
   - 性质: 高度为 $h$ 的满二叉树有 $2^h - 1$ 个节点

2. **完全二叉树（Complete Binary Tree）**
   - 定义: 除了最后一层外，每一层都达到最大节点数，且最后一层的节点都集中在左边
   - 性质: 可以用数组顺序存储

3. **二叉搜索树（Binary Search Tree, BST）**
   - 定义: 左子树的所有节点值小于根节点值，右子树的所有节点值大于根节点值
   - 性质: 中序遍历得到有序序列

#### 2.4.3 二叉树的遍历

##### 遍历方式

1. **前序遍历（Preorder）**: 根 → 左 → 右
2. **中序遍历（Inorder）**: 左 → 根 → 右  
3. **后序遍历（Postorder）**: 左 → 右 → 根
4. **层次遍历（Level-order）**: 按层次从上到下、从左到右

##### 遍历实现

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def preorder_traversal(root):
    """前序遍历"""
    if root is None:
        return []
    return [root.val] + preorder_traversal(root.left) + preorder_traversal(root.right)

def inorder_traversal(root):
    """中序遍历"""
    if root is None:
        return []
    return inorder_traversal(root.left) + [root.val] + inorder_traversal(root.right)

def postorder_traversal(root):
    """后序遍历"""
    if root is None:
        return []
    return postorder_traversal(root.left) + postorder_traversal(root.right) + [root.val]

def level_order_traversal(root):
    """层次遍历"""
    if root is None:
        return []
    result = []
    queue = [root]
    while queue:
        level = []
        next_queue = []
        for node in queue:
            level.append(node.val)
            if node.left:
                next_queue.append(node.left)
            if node.right:
                next_queue.append(node.right)
        result.append(level)
        queue = next_queue
    return result
```

##### 遍历的时间复杂度

所有遍历方式的时间复杂度都是 $O(n)$，其中 $n$ 是节点数。

**空间复杂度**:
- 递归实现: $O(h)$，其中 $h$ 是树的高度
- 迭代实现: $O(n)$（层次遍历使用队列）

<details>
<summary><strong>遍历算法正确性证明</strong></summary>

**定理**: 二叉树的前序、中序、后序遍历算法能正确访问树中的所有节点。

**证明**:

我们用数学归纳法证明前序遍历的正确性。

**基础情况**: 对于空树（`root = None`），算法返回空列表，正确。

**归纳假设**: 假设对于所有高度小于 $h$ 的二叉树，前序遍历算法都能正确访问所有节点。

**归纳步骤**: 考虑高度为 $h$ 的二叉树 $T$，根节点为 $r$，左子树为 $L$，右子树为 $R$。

根据算法：
1. 访问根节点 $r$
2. 递归遍历左子树 $L$
3. 递归遍历右子树 $R$

根据归纳假设，步骤2和步骤3能正确访问左子树和右子树中的所有节点。

因此，整个算法能访问树中的所有节点，且访问顺序为根→左→右，符合前序遍历的定义。

类似地，可以证明中序遍历和后序遍历的正确性。

证毕。∎

### 2.5 图论基础

#### 2.5.1 图的基本概念

##### 定义
**图（Graph）**: 图 $G$ 是一个二元组 $(V, E)$，其中：
- $V$ 是非空有限集合，称为顶点集（Vertex Set）
- $E$ 是 $V \times V$ 的有限集合，称为边集（Edge Set）

**数学表示**: $G = (V, E)$，其中 $V = \{v_1, v_2, ..., v_n\}$，$E = \{e_1, e_2, ..., e_m\}$

##### 图的分类

1. **有向图（Directed Graph）**: 边有方向
   - 边表示为有序对 $(u, v)$，表示从 $u$ 到 $v$ 的有向边

2. **无向图（Undirected Graph）**: 边无方向  
   - 边表示为无序对 $\{u, v\}$，表示 $u$ 和 $v$ 之间的无向边

##### 基本术语

| 术语 | 定义 |
|------|------|
| 顶点（Vertex） | 图中的基本元素 |
| 边（Edge） | 连接两个顶点的线段 |
| 邻接（Adjacent） | 两个顶点由一条边直接相连 |

| 简单路径 | 顶点不重复的路径 |
| 回路（Cycle） | 起点和终点相同的路径 |
| 连通图 | 任意两个顶点之间都有路径相连 |
| 连通分量 | 图中的极大连通子图 |
| 度（Degree） | 顶点的相邻边数 |
| 入度（In-degree） | 有向图中指向该顶点的边数 |
| 出度（Out-degree） | 有向图中从该顶点出发的边数 |

##### 图的存储结构

1. **邻接矩阵（Adjacency Matrix）**
   ```python
   # 无向图邻接矩阵
   graph = [
       [0, 1, 1, 0],  # 顶点0与顶点1、2相连
       [1, 0, 1, 1],  # 顶点1与顶点0、2、3相连
       [1, 1, 0, 0],  # 顶点2与顶点0、1相连

   ```

2. **邻接表（Adjacency List）**
   ```python

   ```

**存储结构比较**:

|----------|------------|--------|------------|
| 邻接矩阵 | $O(n^2)$ | $O(1)$ | $O(n)$ |
| 邻接表 | $O(n + m)$ | $O(deg(v))$ | $O(deg(v))$ |

其中 $n$ 是顶点数，$m$ 是边数，$deg(v)$ 是顶点 $v$ 的度数。

#### 2.5.2 图的遍历

##### 深度优先搜索（DFS）

**算法思想**: 尽可能深地搜索每个分支。

```python
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    
    visited.add(start)
    print(start)  # 访问节点
    
    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)
```

**时间复杂度**: $O(n + m)$，其中 $n$ 是顶点数，$m$ 是边数。

##### 广度优先搜索（BFS）

**算法思想**: 按层次遍历，先访问距离起点最近的顶点。

```python
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    
    while queue:
        current = queue.popleft()
        print(current)  # 访问节点
        
        for neighbor in graph[current]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```

**时间复杂度**: $O(n + m)$

##### DFS与BFS的应用

| 算法 | 典型应用 |
|------|----------|
| DFS | 连通分量、拓扑排序、路径查找 |
| BFS | 最短路径（无权图）、层次遍历 |

<details>
<summary><strong>DFS和BFS的复杂度分析</strong></summary>

**定理**: 对于图 $G = (V, E)$，DFS和BFS的时间复杂度都是 $O(|V| + |E|)$。

**证明**:

**DFS复杂度分析**:
1. 初始化访问标记数组: $O(|V|)$
2. 对每个未访问的顶点调用DFS:
   - 每个顶点被访问一次: $O(|V|)$
   - 每条边被检查一次: $O(|E|)$

总时间复杂度: $O(|V| + |E|)$

**BFS复杂度分析**:
1. 初始化队列和访问标记: $O(|V|)$
2. 每个顶点入队出队各一次: $O(|V|)$
3. 每条边被检查一次: $O(|E|)$

总时间复杂度: $O(|V| + |E|)$

证毕。∎

### 2.6 散列表

#### 2.6.1 散列表的基本概念

##### 定义
**散列表（Hash Table）**: 散列表是一种根据关键码值而直接进行访问的数据结构，通过散列函数将关键码映射到表中的位置来访问记录。

**数学表示**: 设散列表大小为 $m$，散列函数为 $h: K \rightarrow \{0, 1, 2, ..., m-1\}$，其中 $K$ 是关键码集合。

##### 散列函数的设计原则

1. **确定性**: 相同的键总是产生相同的散列值
2. **均匀性**: 键值应均匀分布在整个散列表中
3. **简单性**: 计算应尽可能简单快速

##### 常见的散列函数

1. **除留余数法**: $h(k) = k \mod m$
2. **平方取中法**: $h(k) = \lfloor (k^2 \mod 10^d) / 10^{d/2} \rfloor$
3. **数字分析法**: 分析键值各位数字的分布
4. **折叠法**: 将键值分成若干段，相加后取模

#### 2.6.2 冲突处理方法

##### 开放寻址法（Open Addressing）

**线性探测**: $h_i(k) = (h(k) + i) \mod m$

**二次探测**: $h_i(k) = (h(k) + i^2) \mod m$

**双重散列**: $h_i(k) = (h_1(k) + i \cdot h_2(k)) \mod m$

##### 链地址法（Separate Chaining）

每个散列位置维护一个链表，所有散列到该位置的元素都存储在链表中。

```python
class HashTable:
    def __init__(self, size=10):
        self.size = size
        self.table = [[] for _ in range(size)]
    
    def hash_function(self, key):
        return hash(key) % self.size
    
    def insert(self, key, value):
        index = self.hash_function(key)
        for item in self.table[index]:
            if item[0] == key:
                item[1] = value  # 更新值
                return
        self.table[index].append([key, value])
    
    def search(self, key):
        index = self.hash_function(key)
        for item in self.table[index]:
            if item[0] == key:
                return item[1]
        return None
```

##### 冲突处理方法比较

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 线性探测 | 实现简单，缓存友好 | 容易产生聚集 | 负载因子较低 |
| 二次探测 | 减少聚集 | 探测序列不覆盖所有位置 | 负载因子较低 |
| 双重散列 | 性能最好 | 实现复杂 | 高性能要求 |
| 链地址法 | 处理冲突能力强 | 需要额外空间存储指针 | 负载因子较高 |

#### 2.6.3 散列表的性能分析

##### 负载因子
**负载因子** $\alpha = \frac{n}{m}$，其中 $n$ 是元素个数，$m$ 是散列表大小。

##### 成功查找的平均查找长度（ASL）

| 冲突处理方法 | 成功查找ASL |
|--------------|-------------|
| 线性探测 | $\approx \frac{1}{2}(1 + \frac{1}{1-\alpha})$ |
| 链地址法 | $1 + \frac{\alpha}{2}$ |

##### 失败查找的平均查找长度

| 冲突处理方法 | 失败查找ASL |
|--------------|-------------|
| 线性探测 | $\approx \frac{1}{2}(1 + \frac{1}{(1-\alpha)^2})$ |
| 链地址法 | $\frac{\alpha}{2}$ |

<details>
<summary><strong>链地址法成功查找ASL推导</strong></summary>

**定理**: 使用链地址法的散列表，成功查找的平均查找长度为 $1 + \frac{\alpha}{2}$。

**证明**:

设散列表有 $m$ 个桶，存储了 $n$ 个元素，负载因子 $\alpha = \frac{n}{m}$。

**假设**: 散列函数将元素均匀分布到各个桶中。

**分析**:
1. 成功查找时，需要先找到正确的桶，然后在该桶的链表中查找
2. 找到正确桶的概率为1（因为散列函数保证）
3. 在长度为 $k$ 的链表中查找成功，平均需要比较 $\frac{k+1}{2}$ 次

**期望查找长度计算**:
设第 $i$ 个桶中有 $n_i$ 个元素，则 $\sum_{i=1}^{m} n_i = n$

桶 $i$ 的期望查找长度: $1 + \frac{n_i}{2}$

总体期望查找长度:
$$ASL = \frac{1}{n} \sum_{i=1}^{m} n_i \left(1 + \frac{n_i}{2}\right)$$

$$= \frac{1}{n} \left(\sum_{i=1}^{m} n_i + \frac{1}{2} \sum_{i=1}^{m} n_i^2\right)$$

$$= 1 + \frac{1}{2n} \sum_{i=1}^{m} n_i^2$$

由于 $\sum_{i=1}^{m} n_i = n$，且 $n_i$ 近似服从泊松分布，期望值为 $\alpha$，方差也为 $\alpha$。

因此:
$$\sum_{i=1}^{m} n_i^2 = \sum_{i=1}^{m} (E[n_i]^2 + Var[n_i]) \approx m(\alpha^2 + \alpha)$$

$$ASL \approx 1 + \frac{1}{2n} \cdot m(\alpha^2 + \alpha) = 1 + \frac{\alpha^2 + \alpha}{2\alpha} = 1 + \frac{\alpha}{2}$$

证毕。∎
</details>

```python
def swap(a, b):
```

```python
def is_odd(n):
```

```python
def abs(n):
```

#### 2.7.3 位图数据结构

##### 基本概念
**位图（Bitmap）**: 位图是一种使用位（bit）来表示数据的数据结构，每个位可以表示两种状态（0或1）。

**数学表示**: 位图 $B = (b_0, b_1, b_2, ..., b_{n-1})$，其中 $b_i \in \{0, 1\}$

##### 位图的实现

```python
class Bitmap:
    def __init__(self, size):
        self.size = size
        self.bits = [0] * ((size + 31) // 32)  # 32位为一个整数
    
    def set(self, index):
        """设置第index位为1"""
        word_index = index // 32
        bit_index = index % 32
        self.bits[word_index] |= (1 << bit_index)
    
    def get(self, index):
        """获取第index位的值"""
        word_index = index // 32
        bit_index = index % 32
        return (self.bits[word_index] >> bit_index) & 1
    
    def clear(self, index):
        """清除第index位"""
        word_index = index // 32
        bit_index = index % 32
        self.bits[word_index] &= ~(1 << bit_index)
```

##### 位图的应用

1. **数据去重**: 使用位图快速判断元素是否已存在
2. **集合运算**: 通过位运算实现集合的交、并、差运算
3. **布隆过滤器**: 使用多个位图减少哈希冲突
4. **数据库索引**: 压缩存储大量布尔值

**空间复杂度**: $O(\frac{n}{32})$，相比数组存储节省32倍空间。

<details>
<summary><strong>位图在数据去重中的应用分析</strong></summary>

```python
def has_duplicate_with_bitmap(arr, min_val, max_val):

        index = num - min_val
        if bitmap.get(index) == 1:

        bitmap.set(index)
    
    return False
```

**复杂度分析**:
- 时间复杂度: $O(n)$

**优势**:
1. 空间效率高，比布尔数组节省32倍空间
2. 查找操作时间复杂度为 $O(1)$
3. 适合大规模数据的快速去重

**局限性**:
1. 需要预先知道数据的取值范围
2. 取值范围不能过大（否则空间开销过大）
3. 只能处理整数类型的数据

## 3. 基础算法

### 3.1 排序算法

#### 3.1.1 排序算法概述

##### 排序的定义
**排序（Sorting）**: 将一个数据元素序列重新排列成按关键字有序的序列。

**数学表示**: 给定序列 $R = (r_1, r_2, ..., r_n)$，排序是找到一个排列 $p$，使得：
$$R' = (r_{p(1)}, r_{p(2)}, ..., r_{p(n)})$$
满足 $key(r_{p(1)}) \leq key(r_{p(2)}) \leq ... \leq key(r_{p(n)})$

##### 排序算法的分类

**按是否需要比较**:
- **比较排序**: 需要通过比较元素大小来排序
- **非比较排序**: 不需要比较元素大小

**按稳定性**:
- **稳定排序**: 相等元素的相对位置在排序后保持不变
- **不稳定排序**: 相等元素的相对位置可能改变

**按时间复杂度**:
- **平方阶排序**: $O(n^2)$
- **线性对数阶排序**: $O(n\log n)$
- **线性阶排序**: $O(n)$

#### 3.1.2 基础排序算法

##### 冒泡排序（Bubble Sort）

**算法思想**: 反复交换相邻的逆序元素，直到序列有序。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        if not swapped:
            break
    return arr
```

**优化版本**: 添加标志位，如果一趟排序中没有发生交换，说明序列已经有序。

**复杂度分析**:
- 时间复杂度: $O(n^2)$（最坏和平均情况），$O(n)$（最好情况）
- 空间复杂度: $O(1)$
- 稳定性: 稳定

##### 选择排序（Selection Sort）

**算法思想**: 每次选择未排序部分的最小元素，放到已排序部分的末尾。

```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr
```

**复杂度分析**:
- 时间复杂度: $O(n^2)$
- 空间复杂度: $O(1)$
- 稳定性: 不稳定

##### 插入排序（Insertion Sort）

**算法思想**: 将序列分为已排序和未排序两部分，每次将未排序部分的第一个元素插入到已排序部分的正确位置。

```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr
```

**复杂度分析**:
- 时间复杂度: $O(n^2)$（最坏和平均），$O(n)$（最好）
- 空间复杂度: $O(1)$
- 稳定性: 稳定

<details>
<summary><strong>插入排序正确性证明</strong></summary>

**定理**: 插入排序算法能够正确地将输入数组排序。

**证明**:

我们使用循环不变式来证明算法的正确性。

**循环不变式**: 在第 $i$ 次循环开始时（$i$ 从1到 $n-1$），子数组 $arr[0..i]$ 包含原始数组中前 $i+1$ 个元素，且已按非降序排列。

**证明步骤**:

**初始化**: 当 $i = 1$ 时，子数组 $arr[0..1]$ 包含两个元素。插入排序将 $arr[1]$ 插入到 $arr[0]$ 的正确位置，使得 $arr[0..1]$ 有序。循环不变式成立。

**维护**: 假设循环不变式在第 $i$ 次循环开始时成立，即 $arr[0..i]$ 已排序。

在第 $i$ 次循环中，算法将 $arr[i]$ 与已排序的 $arr[0..i-1]$ 中的元素从右向左比较，找到正确的插入位置，然后将 $arr[i]$ 插入到该位置。

插入后，$arr[0..i]$ 仍然包含原始数组中前 $i+1$ 个元素，且按非降序排列。因此，循环不变式在第 $i+1$ 次循环开始时仍然成立。

**终止**: 当 $i = n-1$ 时，循环结束。根据循环不变式，子数组 $arr[0..n-1]$ 包含所有元素且已排序。

因此，插入排序算法是正确的。∎
</details>

#### 3.1.3 高级排序算法

##### 快速排序（Quick Sort）

**算法思想**: 选择一个基准元素，将数组分割为两部分：小于基准的元素和大于基准的元素，然后递归地对两部分进行排序。

```python
def quick_sort(arr, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        # 分割操作，返回基准元素的最终位置
        pi = partition(arr, low, high)
        
        # 递归排序基准左右两部分
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    # 选择最后一个元素作为基准
    pivot = arr[high]
    
    # 较小元素的索引
    i = low - 1
    
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

**复杂度分析**:
- 时间复杂度: $O(n\log n)$（平均），$O(n^2)$（最坏）
- 空间复杂度: $O(\log n)$（递归栈）
- 稳定性: 不稳定

**最坏情况分析**: 当每次选择的基准都是当前子数组的最大或最小元素时，时间复杂度退化为 $O(n^2)$。

**优化策略**:
1. 随机选择基准
2. 三数取中法选择基准
3. 当子数组较小时使用插入排序

##### 归并排序（Merge Sort）

**算法思想**: 采用分治策略，将数组分为两半，分别排序后合并。

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

**复杂度分析**:
- 时间复杂度: $O(n\log n)$
- 空间复杂度: $O(n)$
- 稳定性: 稳定

<details>
<summary><strong>归并排序时间复杂度分析</strong></summary>

**定理**: 归并排序的时间复杂度为 $O(n\log n)$。

**证明**:

设 $T(n)$ 为对大小为 $n$ 的数组进行归并排序的时间复杂度。

根据算法：
1. 分割操作: $O(1)$
2. 递归排序左半部分: $T(\frac{n}{2})$
3. 递归排序右半部分: $T(\frac{n}{2})$
4. 合并操作: $O(n)$

因此得到递归式：
$$T(n) = 2T(\frac{n}{2}) + O(n)$$

**使用主定理求解**:
- $a = 2$，$b = 2$，$f(n) = O(n)$
- $\log_b a = \log_2 2 = 1$
- $f(n) = O(n^1) = O(n^{\log_b a})$

根据主定理第二种情况：
$$T(n) = O(n^{\log_b a} \log n) = O(n \log n)$$

证毕。∎
</details>

##### 堆排序（Heap Sort）

**算法思想**: 利用堆的性质进行排序，先建立最大堆，然后反复提取堆顶元素。

```python
def heap_sort(arr):
    n = len(arr)
    
    # 建立最大堆
    for i in range(n // 2 - 1, -1, -1):
        heapify(arr, n, i)
    
    # 逐个提取元素
    for i in range(n - 1, 0, -1):
        arr[0], arr[i] = arr[i], arr[0]  # 交换堆顶和最后一个元素
        heapify(arr, i, 0)  # 重新调整堆

def heapify(arr, n, i):
    largest = i
    left = 2 * i + 1
    right = 2 * i + 2
    
    if left < n and arr[left] > arr[largest]:
        largest = left
    
    if right < n and arr[right] > arr[largest]:
        largest = right
    
    if largest != i:
        arr[i], arr[largest] = arr[largest], arr[i]
        heapify(arr, n, largest)
```

**复杂度分析**:
- 时间复杂度: $O(n\log n)$
- 空间复杂度: $O(1)$
- 稳定性: 不稳定

#### 3.1.4 线性时间排序算法

##### 计数排序（Counting Sort）

**算法思想**: 假设输入是范围在 $[0, k]$ 的整数，统计每个值出现的次数，然后按顺序输出。

```python
def counting_sort(arr, max_val):
    count = [0] * (max_val + 1)
    
    # 统计每个元素的出现次数
    for num in arr:
        count[num] += 1
    
    # 计算累计次数
    for i in range(1, len(count)):
        count[i] += count[i - 1]
    
    # 创建输出数组
    output = [0] * len(arr)
    
    # 从后往前遍历，确保稳定性
    for i in range(len(arr) - 1, -1, -1):
        output[count[arr[i]] - 1] = arr[i]
        count[arr[i]] -= 1
    
    return output
```

**复杂度分析**:
- 时间复杂度: $O(n + k)$，其中 $k$ 是输入范围
- 空间复杂度: $O(n + k)$
- 稳定性: 稳定
- 适用条件: 输入范围不太大

##### 桶排序（Bucket Sort）

**算法思想**: 将输入数据分到有限数量的桶中，对每个桶内的数据进行排序，然后按顺序输出。

```python
def bucket_sort(arr, bucket_size=5):
    if len(arr) == 0:
        return arr
    
    # 确定桶的数量
    min_val, max_val = min(arr), max(arr)
    bucket_count = (max_val - min_val) // bucket_size + 1
    buckets = [[] for _ in range(bucket_count)]
    
    # 将元素分配到桶中
    for num in arr:
        bucket_index = (num - min_val) // bucket_size
        buckets[bucket_index].append(num)
    
    # 对每个桶进行排序
    result = []
    for bucket in buckets:
        if bucket:
            result.extend(sorted(bucket))
    
    return result
```

**复杂度分析**:
- 时间复杂度: $O(n + k)$（平均），$O(n^2)$（最坏）
- 空间复杂度: $O(n + k)$
- 稳定性: 取决于桶内排序算法

##### 基数排序（Radix Sort）

**算法思想**: 按位进行排序，从最低位到最高位。

```python
def radix_sort(arr):
    if not arr:
        return arr
    
    # 找到最大数以确定位数
    max_num = max(arr)
    
    # 从个位开始排序
    exp = 1
    while max_num // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10

def counting_sort_by_digit(arr, exp):
    n = len(arr)
    output = [0] * n
    count = [0] * 10
    
    # 统计每个数字的出现次数
    for i in range(n):
        index = arr[i] // exp
        count[index % 10] += 1
    
    # 计算累计次数
    for i in range(1, 10):
        count[i] += count[i - 1]
    
    # 构建输出数组
    i = n - 1
    while i >= 0:
        index = arr[i] // exp
        output[count[index % 10] - 1] = arr[i]
        count[index % 10] -= 1
        i -= 1
    
    # 复制回原数组
    for i in range(n):
        arr[i] = output[i]
```

**复杂度分析**:
- 时间复杂度: $O(d(n + k))$，其中 $d$ 是位数，$k$ 是基数
- 空间复杂度: $O(n + k)$
- 稳定性: 稳定

### 3.2 查找算法

#### 3.2.1 查找算法概述

##### 查找的定义
**查找（Search）**: 在数据集合中寻找满足特定条件的数据元素的过程。

**数学表示**: 给定查找表 $T = \{t_1, t_2, ..., t_n\}$ 和查找条件 $C$，查找是找到集合 $S = \{t_i | C(t_i) = true\}$。

##### 查找的分类

**按查找方式**:
- **静态查找**: 只进行查找操作，不修改查找表
- **动态查找**: 查找过程中可能插入或删除元素

**按数据结构**:
- **线性表查找**: 顺序查找、二分查找
- **树表查找**: 二叉搜索树、平衡二叉树
- **散列查找**: 直接通过散列函数定位

#### 3.2.2 线性表查找

##### 顺序查找（Sequential Search）

**算法思想**: 从表的一端开始，顺序扫描整个表，依次检查每个元素。

```python
def sequential_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i
    return -1
```

**复杂度分析**:
- 时间复杂度: $O(n)$
- 空间复杂度: $O(1)$
- 适用性: 适用于有序和无序表

##### 二分查找（Binary Search）

**算法思想**: 在有序数组中，通过比较中间元素与目标值，每次排除一半的搜索范围。

```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1
```

**递归实现**:
```python
def binary_search_recursive(arr, target, left=0, right=None):
    if right is None:
        right = len(arr) - 1
    
    if left > right:
        return -1
    
    mid = left + (right - left) // 2
    
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, right)
    else:
        return binary_search_recursive(arr, target, left, mid - 1)
```

**复杂度分析**:
- 时间复杂度: $O(\log n)$
- 空间复杂度: $O(1)$（迭代），$O(\log n)$（递归）
- 适用条件: 有序数组

<details>
<summary><strong>二分查找正确性证明</strong></summary>

**定理**: 二分查找算法能够正确地在有序数组中查找目标元素。

**证明**:

我们使用循环不变式来证明算法的正确性。

**循环不变式**: 在每次循环开始时，如果目标元素在数组中，那么它一定在子数组 $arr[left..right]$ 中。

**证明步骤**:

**初始化**: 第一次循环开始时，$left = 0$，$right = n-1$，子数组是整个数组。如果目标元素在数组中，它一定在 $arr[0..n-1]$ 中。循环不变式成立。

**维护**: 假设循环不变式在当前循环开始时成立，即目标元素（如果存在）一定在 $arr[left..right]$ 中。

计算中间位置 $mid = \lfloor (left + right) / 2 \rfloor$，有三种情况：

1. **$arr[mid] = target$**: 找到目标，返回 $mid$，算法终止。

2. **$arr[mid] < target$**: 由于数组是有序的，$arr[left..mid]$ 中的所有元素都小于 $target$。因此，如果目标存在，它一定在 $arr[mid+1..right]$ 中。设置 $left = mid + 1$，循环不变式仍然成立。

3. **$arr[mid] > target$**: 类似地，目标（如果存在）一定在 $arr[left..mid-1]$ 中。设置 $right = mid - 1$，循环不变式仍然成立。

**终止**: 循环在两种情况下终止：
1. 找到目标，返回其位置。
2. $left > right$，此时子数组为空。根据循环不变式，如果目标存在，它应该在子数组中，但子数组为空，因此目标不存在，返回 $-1$。

因此，二分查找算法是正确的。∎
</details>

##### 插值查找（Interpolation Search）

**算法思想**: 二分查找的改进，根据目标值在数组中的相对位置来选择分割点。

```python
def interpolation_search(arr, target):
    left, right = 0, len(arr) - 1
    
    while left <= right and target >= arr[left] and target <= arr[right]:
        if left == right:
            if arr[left] == target:
                return left
            return -1
        
        # 插值公式
        pos = left + (target - arr[left]) * (right - left) // (arr[right] - arr[left])
        
        if arr[pos] == target:
            return pos
        elif arr[pos] < target:
            left = pos + 1
        else:
            right = pos - 1
    
    return -1
```

**复杂度分析**:
- 时间复杂度: $O(\log \log n)$（均匀分布），$O(n)$（最坏）
- 空间复杂度: $O(1)$
- 适用条件: 有序且分布均匀的数组

##### 斐波那契查找（Fibonacci Search）

**算法思想**: 利用斐波那契数列的性质来分割数组。

```python
def fibonacci_search(arr, target):
    n = len(arr)
    
    # 找到大于等于n的最小斐波那契数
    fib_m2, fib_m1 = 0, 1
    while fib_m1 < n:
        fib_m2, fib_m1 = fib_m1, fib_m2 + fib_m1
    
    # 标记已比较的数组边界
    offset = -1
    
    while fib_m1 > 1:
        # 检查fib_m2是否在有效范围内
        i = min(offset + fib_m2, n - 1)
        
        if arr[i] < target:
            fib_m1, fib_m2 = fib_m2, fib_m1 - fib_m2
            offset = i
        elif arr[i] > target:
            fib_m1, fib_m2 = fib_m2, fib_m1 - fib_m2
        else:
            return i
    
    # 检查最后一个元素
    if fib_m1 and offset + 1 < n and arr[offset + 1] == target:
        return offset + 1
    
    return -1
```

**复杂度分析**:
- 时间复杂度: $O(\log n)$
- 空间复杂度: $O(1)$

### 3.3 递归与分治

#### 3.3.1 递归的基本概念

##### 递归的定义
**递归（Recursion）**: 函数调用自身来解决问题的方法。

**递归的两个基本要素**:
1. **递归出口（Base Case）**: 递归结束的条件
2. **递归关系（Recursive Case）**: 问题如何分解为更小的子问题

##### 递归的数学模型

对于递归函数 $T(n)$，通常可以表示为：
$$T(n) = \begin{cases}
O(1) & \text{if } n \leq c \\
aT(\frac{n}{b}) + f(n) & \text{if } n > c
\end{cases}$$

其中：
- $a$ 是递归调用的次数
- $b$ 是问题规模的缩减因子
- $f(n)$ 是递归调用之外的工作

#### 3.3.2 经典递归算法

##### 阶乘计算

```python
def factorial(n):

    return n * factorial(n - 1)
```

**复杂度分析**:
- 时间复杂度: $O(n)$
- 空间复杂度: $O(n)$（递归栈）

```python
def fibonacci_memo(n, memo=None):
```

#### 3.3.3 分治算法

##### 分治的基本思想

**分治（Divide and Conquer）**的基本步骤：
1. **分解（Divide）**: 将原问题分解为若干个规模较小的子问题
2. **解决（Conquer）**: 递归地解决各个子问题
3. **合并（Combine）**: 将子问题的解合并为原问题的解

##### 归并排序（分治经典应用）

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    
    # 分解
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    
    # 合并
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

##### 快速排序（分治应用）

```python
def quick_sort(arr, low=0, high=None):
    if high is None:
        high = len(arr) - 1
    
    if low < high:
        # 分解：partition操作
        pi = partition(arr, low, high)
        
        # 递归解决
        quick_sort(arr, low, pi - 1)
        quick_sort(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1
```

##### 最近点对问题

**问题**: 在平面上的点集中，找到距离最近的两个点。

```python
def closest_pair(points):
    if len(points) <= 3:
        return brute_force_closest_pair(points)
    
    # 按x坐标排序
    points.sort(key=lambda p: p[0])
    
    mid = len(points) // 2
    mid_x = points[mid][0]
    
    # 递归求解左右两部分
    left_closest = closest_pair(points[:mid])
    right_closest = closest_pair(points[mid:])
    
    # 合并结果
    min_dist = min(left_closest[1], right_closest[1])
    
    # 检查跨越中线的点对
    strip = [p for p in points if abs(p[0] - mid_x) < min_dist]
    
    return min(
        (left_closest, right_closest),
        closest_pair_in_strip(strip, min_dist)
    )

def closest_pair_in_strip(strip, min_dist):
    min_pair = None
    min_distance = min_dist
    
    for i in range(len(strip)):
        for j in range(i + 1, min(i + 8, len(strip))):  # 最多检查7个点
            dist = distance(strip[i], strip[j])
            if dist < min_distance:
                min_distance = dist
                min_pair = (strip[i], strip[j])
    
    return (min_pair, min_distance) if min_pair else (None, float('inf'))
```

**复杂度分析**:
- 时间复杂度: $O(n\log n)$
- 空间复杂度: $O(\log n)$

### 3.4 动态规划

#### 3.4.1 动态规划的基本概念

##### 动态规划的定义
**动态规划（Dynamic Programming, DP）**: 一种通过将复杂问题分解为相互重叠的子问题，并存储子问题的解来避免重复计算的算法设计方法。

**基本思想**:
1. **最优子结构**: 问题的最优解包含其子问题的最优解
2. **重叠子问题**: 不同的子问题会重复出现
3. **无后效性**: 当前状态一旦确定，就不受未来决策影响

##### 动态规划的基本步骤

1. **定义状态**: 明确问题的状态表示
2. **建立状态转移方程**: 找到状态之间的递推关系
3. **确定边界条件**: 明确递归的终止条件
4. **计算顺序**: 确定状态计算的顺序

#### 3.4.2 经典动态规划问题

##### 斐波那契数列（DP版本）

**状态定义**: $dp[i]$ 表示第 $i$ 个斐波那契数

**状态转移方程**: $dp[i] = dp[i-1] + dp[i-2]$

**边界条件**: $dp[0] = 0$，$dp[1] = 1$

```python
def fibonacci_dp(n):
    if n <= 1:
        return n
    
    dp = [0] * (n + 1)
    dp[1] = 1
    
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    
    return dp[n]
```

**空间优化版本**:
```python
def fibonacci_optimized(n):
    if n <= 1:
        return n
    
    prev, curr = 0, 1
    for i in range(2, n + 1):
        prev, curr = curr, prev + curr
    
    return curr
```

**复杂度分析**:
- 时间复杂度: $O(n)$

- 空间复杂度: $O(1)$

##### 背包问题

**问题描述**: 给定 $n$ 个物品和容量为 $W$ 的背包，每个物品有重量 $w_i$ 和价值 $v_i$，求在不超过背包容量的前提下，使总价值最大。

**状态定义**: $dp[i][w]$ 表示前 $i$ 个物品在容量为 $w$ 时的最大价值

**状态转移方程**: 
$$dp[i][w] = \max(dp[i-1][w], dp[i-1][w-w_i] + v_i)$$

**边界条件**: $dp[0][w] = 0$，$dp[i][0] = 0$

```python
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0 for _ in range(capacity + 1)] for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for w in range(capacity + 1):
            # 不选择第i个物品
            dp[i][w] = dp[i-1][w]
            
            # 选择第i个物品
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w], dp[i-1][w-weights[i-1]] + values[i-1])
    
    return dp[n][capacity]
```

**空间优化版本**:
```python
def knapsack_optimized(weights, values, capacity):
    n = len(weights)
    dp = [0] * (capacity + 1)
    
    for i in range(n):
        for w in range(capacity, weights[i]-1, -1):
            dp[w] = max(dp[w], dp[w-weights[i]] + values[i])
    
    return dp[capacity]
```

**复杂度分析**:
- 时间复杂度: $O(n \times W)$
- 空间复杂度: $O(W)$（优化后）

##### 最长公共子序列（LCS）

**问题描述**: 给定两个字符串，求它们的最长公共子序列。

**状态定义**: $dp[i][j]$ 表示 $text1[0..i-1]$ 和 $text2[0..j-1]$ 的最长公共子序列长度

**状态转移方程**:
$$dp[i][j] = \begin{cases}
dp[i-1][j-1] + 1 & \text{if } text1[i-1] = text2[j-1] \\
\max(dp[i-1][j], dp[i][j-1]) & \text{otherwise}
\end{cases}$$

```python
def longest_common_subsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    
    return dp[m][n]
```

**复杂度分析**:
- 时间复杂度: $O(m \times n)$
- 空间复杂度: $O(m \times n)$，可优化为 $O(\min(m, n))$

##### 最长递增子序列（LIS）

**问题描述**: 给定一个序列，求其最长递增子序列的长度。

**方法1: 动态规划**

```python
def length_of_lis_dp(nums):
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)
```

**方法2: 二分查找优化**

```python
def length_of_lis_binary(nums):
    if not nums:
        return 0
    
    import bisect
    tails = []
    
    for num in nums:
        # 找到第一个大于等于num的位置
        pos = bisect.bisect_left(tails, num)
        
        if pos == len(tails):
            tails.append(num)
        else:
            tails[pos] = num
    
    return len(tails)
```

**复杂度分析**:
- 方法1: $O(n^2)$ 时间，$O(n)$ 空间
- 方法2: $O(n\log n)$ 时间，$O(n)$ 空间

##### 单调队列优化

当状态转移涉及区间最值查询时，可以使用单调队列。

**滑动窗口最大值**:

```python
def max_sliding_window(nums, k):
    from collections import deque
    
    result = []
    dq = deque()  # 存储索引
    
    for i in range(len(nums)):
        # 移除窗口外的元素
        while dq and dq[0] <= i - k:
            dq.popleft()
        
        # 移除比当前元素小的元素
        while dq and nums[dq[-1]] <= nums[i]:
            dq.pop()
        
        dq.append(i)
        
        # 记录窗口最大值
        if i >= k - 1:
            result.append(nums[dq[0]])
    
    return result
```

### 3.5 贪心算法

#### 3.5.1 贪心算法的基本概念

##### 贪心算法的定义
**贪心算法（Greedy Algorithm）**: 在求解问题时，总是做出当前看来最好的选择，期望通过局部最优选择达到全局最优。

**贪心算法的特点**:
1. **贪心选择性质**: 每一步的选择都是当前状态下的最优选择
2. **最优子结构**: 问题的最优解包含子问题的最优解
3. **无后效性**: 当前选择不会影响未来的选择

##### 贪心算法的基本步骤

1. **建立数学模型**: 明确问题和要求
2. **分解为子问题**: 将原问题分解为若干个子问题
3. **贪心选择**: 在每个子问题中做出最优选择
4. **递归/迭代**: 递归或迭代地解决子问题
5. **组合解**: 将子问题的解组合成原问题的解

#### 3.5.2 经典贪心算法问题

##### 活动选择问题

**问题描述**: 给定一组活动，每个活动有开始时间和结束时间，选择最大数量的互不重叠的活动。

**贪心策略**: 选择结束时间最早的活动

```python
def activity_selection(activities):
    # 按结束时间排序
    activities.sort(key=lambda x: x[1])
    
    selected = [activities[0]]
    last_end_time = activities[0][1]
    
    for activity in activities[1:]:
        start, end = activity
        if start >= last_end_time:
            selected.append(activity)
            last_end_time = end
    
    return selected
```

**正确性证明**:

<details>
<summary><strong>活动选择问题的贪心算法正确性证明</strong></summary>

**定理**: 选择结束时间最早的活动能够得到最大数量的互不重叠活动。

**证明**:

我们使用交换论证法来证明算法的正确性。

设算法选择的活动序列为 $A = \{a_1, a_2, ..., a_k\}$，其中 $a_i$ 是第 $i$ 个选择的活动。

设任意最优解为 $O = \{o_1, o_2, ..., o_m\}$。

**引理1**: 对于任意 $i$，有 $end(a_i) \leq end(o_i)$。

**证明**: 我们对 $i$ 进行归纳。

**基础情况** ($i = 1$): 根据算法，$a_1$ 是所有活动中结束时间最早的，因此 $end(a_1) \leq end(o_1)$。

**归纳步骤**: 假设对所有 $j < i$ 有 $end(a_j) \leq end(o_j)$。

由于 $a_{i-1}$ 在 $o_{i-1}$ 之前结束或同时结束，且 $a_i$ 是第一个与 $a_{i-1}$ 不重叠的活动，而 $o_i$ 是第一个与 $o_{i-1}$ 不重叠的活动，因此 $start(a_i) \geq end(a_{i-1}) \geq end(o_{i-1})$。

这意味着 $a_i$ 不与 $o_{i-1}$ 重叠，而 $o_i$ 是第一个与 $o_{i-1}$ 不重叠的活动，所以 $end(a_i) \leq end(o_i)$。

**定理证明**: 由引理1可知，$end(a_i) \leq end(o_i)$ 对于所有 $i$ 成立。

假设 $m > k$，那么考虑活动 $o_{k+1}$。由于 $end(a_k) \leq end(o_k)$，且 $a_{k+1}$ 不存在，说明没有活动能在 $end(a_k)$ 之后开始。因此，$o_{k+1}$ 不可能存在，矛盾。

因此，$k \geq m$，即算法得到的解是最优解。

证毕。∎

##### 哈夫曼编码

**问题描述**: 给定字符及其出现频率，构造最优前缀码。

**贪心策略**: 每次选择频率最小的两个节点合并

```python
import heapq

class Node:
    def __init__(self, freq, char=None, left=None, right=None):
        self.freq = freq
        self.char = char
        self.left = left
        self.right = right
    
    def __lt__(self, other):
        return self.freq < other.freq

def huffman_coding(freq_dict):
    # 创建优先队列
    heap = []
    for char, freq in freq_dict.items():
        heapq.heappush(heap, Node(freq, char))
    
    # 合并节点
    while len(heap) > 1:
        left = heapq.heappop(heap)
        right = heapq.heappop(heap)
        parent = Node(left.freq + right.freq, left=left, right=right)
        heapq.heappush(heap, parent)
    
    # 生成编码
    codes = {}
    def generate_codes(node, code=""):
        if node.char is not None:
            codes[node.char] = code
        else:
            generate_codes(node.left, code + "0")
            generate_codes(node.right, code + "1")
    
    generate_codes(heap[0])
    return codes
```

**复杂度分析**:
- 时间复杂度: $O(n\log n)$
- 空间复杂度: $O(n)$

##### 最小生成树（Kruskal算法）

**问题描述**: 在带权无向图中，找到连接所有顶点的最小权重的生成树。

**贪心策略**: 按权值从小到大选择边，如果不会形成环就加入生成树

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py:
            return False
        
        if self.rank[px] < self.rank[py]:
            self.parent[px] = py
        elif self.rank[px] > self.rank[py]:
            self.parent[py] = px
        else:
            self.parent[py] = px
            self.rank[px] += 1
        return True

def kruskal_mst(n, edges):
    # 按权值排序
    edges.sort(key=lambda x: x[2])
    
    uf = UnionFind(n)
    mst = []
    total_weight = 0
    
    for u, v, weight in edges:
        if uf.union(u, v):
            mst.append((u, v, weight))
            total_weight += weight
            if len(mst) == n - 1:
                break
    
    return mst, total_weight
```

##### 最短路径（Dijkstra算法）

**问题描述**: 在带权有向图中，找到从单源点到其他所有点的最短路径。

**贪心策略**: 每次选择距离源点最近的未确定顶点

```python
import heapq

def dijkstra(graph, start):
    # graph[u] = [(v, weight), ...]
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    pq = [(0, start)]
    visited = set()
    
    while pq:
        current_dist, current = heapq.heappop(pq)
        
        if current in visited:
            continue
        
        visited.add(current)
        
        for neighbor, weight in graph[current]:
            distance = current_dist + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(pq, (distance, neighbor))
    
    return distances
```

**复杂度分析**:
- 时间复杂度: $O((V + E)\log V)$
- 空间复杂度: $O(V)$

#### 3.5.3 贪心算法的适用条件

##### 贪心选择性质
**定义**: 问题的全局最优解可以通过一系列局部最优选择得到。

**判断方法**:
1. 贪心选择是否与子问题无关
2. 贪心选择是否保持问题的最优子结构

##### 最优子结构

**验证方法**:

### 3.6 字符串算法

#### 3.6.1 字符串匹配基础

##### 字符串匹配的定义
**字符串匹配（String Matching）**: 在文本串 $T$ 中查找模式串 $P$ 的出现位置。

**数学表示**: 给定文本 $T = t_1t_2...t_n$ 和模式 $P = p_1p_2...p_m$，找到所有位置 $i$ 使得 $t_{i+j} = p_j$ 对于 $j = 1, 2, ..., m$。

##### 基本术语

| 术语 | 定义 |
|------|------|
| 文本串（Text） | 被搜索的字符串 |
| 模式串（Pattern） | 要搜索的字符串 |
| 前缀（Prefix） | 从字符串开头开始的连续子串 |
| 后缀（Suffix） | 从字符串结尾开始的连续子串 |
| 真前缀/真后缀 | 不等于字符串本身的前缀/后缀 |

#### 3.6.2 经典字符串匹配算法

##### 暴力匹配算法（Brute Force）

**算法思想**: 依次比较文本和模式的所有可能位置。

```python
def brute_force_search(text, pattern):
    n, m = len(text), len(pattern)
    positions = []
    
    for i in range(n - m + 1):
        j = 0
        while j < m and text[i + j] == pattern[j]:
            j += 1
        
        if j == m:
            positions.append(i)
    
    return positions
```

**复杂度分析**:
- 时间复杂度: $O(n \times m)$
- 空间复杂度: $O(1)$

##### KMP算法

**算法思想**: 利用已经匹配的信息，避免不必要的回溯。

**关键概念**:
- **前缀函数（Prefix Function）**: $\pi[i]$ 表示模式串 $P[0..i]$ 的最长真前缀也是后缀的长度
- **部分匹配表（Partial Match Table）**: 存储每个位置的前缀函数值

```python
def compute_prefix_function(pattern):
    m = len(pattern)
    pi = [0] * m
    k = 0
    
    for i in range(1, m):
        while k > 0 and pattern[k] != pattern[i]:
            k = pi[k - 1]
        
        if pattern[k] == pattern[i]:
            k += 1
        
        pi[i] = k
    
    return pi

def kmp_search(text, pattern):
    if not pattern:
        return [0]
    
    n, m = len(text), len(pattern)
    pi = compute_prefix_function(pattern)
    positions = []
    q = 0  # 已匹配的模式字符数
    
    for i in range(n):
        while q > 0 and pattern[q] != text[i]:
            q = pi[q - 1]
        
        if pattern[q] == text[i]:
            q += 1
        
        if q == m:
            positions.append(i - m + 1)
            q = pi[q - 1]
    
    return positions
```

**复杂度分析**:
- 时间复杂度: $O(n + m)$
- 空间复杂度: $O(m)$

<details>
<summary><strong>KMP算法前缀函数计算的正确性证明</strong></summary>

**定理**: 前缀函数 $\pi[i]$ 正确地表示了模式串 $P[0..i]$ 的最长真前缀也是后缀的长度。

**证明**:

我们使用数学归纳法证明前缀函数计算的正确性。

**引理**: 在计算 $\pi[i]$ 时，变量 $k$ 的值等于 $\pi[i-1]$。

**证明**: 
- 当 $i = 1$ 时，$\pi[0] = 0$，$k$ 初始化为0，引理成立。
- 假设对于位置 $i-1$，$k = \pi[i-1]$。
- 在计算 $\pi[i]$ 时，$k$ 的初始值就是 $\pi[i-1]$。

**归纳证明**:

**基础情况** ($i = 0$): $\pi[0] = 0$（长度为1的字符串没有真前缀），正确。

**归纳步骤**: 假设对于所有 $j < i$，$\pi[j]$ 正确计算。

考虑位置 $i$ 的计算：

1. **while循环**: 如果 $k > 0$ 且 $P[k] \neq P[i]$，则 $k = \pi[k-1]$。
   - 根据归纳假设，$\pi[k-1]$ 是 $P[0..k-1]$ 的最长真前缀也是后缀的长度
   - 这个循环确保找到最长的匹配前缀

2. **if条件**: 如果 $P[k] = P[i]$，则 $k$ 增加1。
   - 此时 $P[0..k]$ 是 $P[0..i]$ 的一个真前缀也是后缀
   - 由于while循环已经排除了更长的可能，这个 $k$ 是最长的

3. **赋值**: $\pi[i] = k$。

因此，$\pi[i]$ 确实表示了 $P[0..i]$ 的最长真前缀也是后缀的长度。

证毕。∎

##### Boyer-Moore算法

**算法思想**: 从模式串的右端开始匹配，利用坏字符和好后缀规则跳跃。

**关键概念**:
- **坏字符规则（Bad Character Rule）**: 当发生不匹配时，将模式向右移动使其与文本中的坏字符对齐
- **好后缀规则（Good Suffix Rule）**: 利用已匹配的后缀信息进行跳跃

```python
def boyer_moore_search(text, pattern):
    n, m = len(text), len(pattern)
    positions = []
    
    # 构建坏字符表
    bad_char = {}
    for i in range(m):
        bad_char[pattern[i]] = i
    
    i = 0
    while i <= n - m:
        j = m - 1
        
        # 从右向左匹配
        while j >= 0 and text[i + j] == pattern[j]:
            j -= 1
        
        if j < 0:
            positions.append(i)
            i += m  # 完全匹配，跳跃m个位置
        else:
            # 坏字符规则
            bad_char_shift = j - bad_char.get(text[i + j], -1)
            i += max(1, bad_char_shift)
    
    return positions
```

**复杂度分析**:
- 时间复杂度: $O(n + m)$（平均），$O(mn)$（最坏）
- 空间复杂度: $O(m + \sigma)$，其中 $\sigma$ 是字符集大小

##### Sunday算法

**算法思想**: 关注文本中与模式串最后一个字符对齐的字符。

```python
def sunday_search(text, pattern):
    n, m = len(text), len(pattern)
    positions = []
    
    # 构建跳转表
    jump = {}
    for i in range(256):
        jump[chr(i)] = m + 1
    
    for i in range(m):
        jump[pattern[i]] = m - i
    
    i = 0
    while i <= n - m:
        j = 0
        while j < m and text[i + j] == pattern[j]:
            j += 1
        
        if j == m:
            positions.append(i)
            i += jump.get(text[i + m], m + 1)
        else:
            i += jump.get(text[i + j], m + 1)
    
    return positions
```

**复杂度分析**:
- 时间复杂度: $O(n + m)$
- 空间复杂度: $O(\sigma)$

```python
def rotate_matrix_inplace(matrix):
    n = len(matrix)
    
    for layer in range(n // 2):
        first, last = layer, n - 1 - layer
        
        for i in range(first, last):
            offset = i - first
            
            # 保存顶部
            top = matrix[first][i]
            
            # 左 -> 顶
            matrix[first][i] = matrix[last - offset][first]
            
            # 底 -> 左
            matrix[last - offset][first] = matrix[last][last - offset]
            
            # 右 -> 底
            matrix[last][last - offset] = matrix[i][last]
            
            # 顶 -> 右
            matrix[i][last] = top
```

```python
def search_sorted_matrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    
    m, n = len(matrix), len(matrix[0])
    row, col = 0, n - 1
    
    while row < m and col >= 0:
        if matrix[row][col] == target:

        elif matrix[row][col] > target:

        else:
```

```python
def unique_paths_dp(m, n):

    for i in range(1, m):
```

##### 矩阵乘法链

**问题描述**: 给定矩阵链，求最小标量乘法次数。

```python
def matrix_chain_multiplication(dimensions):
    n = len(dimensions) - 1  # 矩阵个数
    dp = [[0] * n for _ in range(n)]
    
    # 计算不同长度的子链
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            dp[i][j] = float('inf')
            
            # 尝试不同的分割点
            for k in range(i, j):
                cost = dp[i][k] + dp[k+1][j] + dimensions[i] * dimensions[k+1] * dimensions[j+1]
                dp[i][j] = min(dp[i][j], cost)
    
    return dp[0][n-1]
```

**复杂度分析**:
- 时间复杂度: $O(n^3)$
- 空间复杂度: $O(n^2)$

### 4.1 平衡二叉树

#### 4.1.1 AVL树

##### AVL树的基本概念

**定义**: AVL树是一种自平衡二叉搜索树，其中任何节点的两个子树的高度差最多为1。

**数学性质**: 对于AVL树的每个节点 $x$，满足：
$$|height(left(x)) - height(right(x))| \leq 1$$

其中 $height(x)$ 表示以 $x$ 为根的子树的高度。

##### AVL树的旋转操作

**单旋转**:

1. **右旋转（Right Rotation）**
```python
def right_rotate(y):
    x = y.left
    T2 = x.right
    
    # 执行旋转
    x.right = y
    y.left = T2
    
    # 更新高度
    y.height = max(get_height(y.left), get_height(y.right)) + 1
    x.height = max(get_height(x.left), get_height(x.right)) + 1
    
    return x
```

2. **左旋转（Left Rotation）**

```python
def left_rotate(x):

    T2 = y.left

    x.right = T2
    
    # 更新高度
```

##### AVL树的插入操作

```python
class AVLNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None
        self.height = 1

def get_height(node):
    return node.height if node else 0

def get_balance(node):
    return get_height(node.left) - get_height(node.right) if node else 0

def insert_avl(root, key):
    # 1. 执行标准BST插入
    if not root:
        return AVLNode(key)
    
    if key < root.key:
        root.left = insert_avl(root.left, key)
    elif key > root.key:
        root.right = insert_avl(root.right, key)
    else:
        return root  # 不允许重复值
    
    # 2. 更新高度
    root.height = max(get_height(root.left), get_height(root.right)) + 1
    
    # 3. 获取平衡因子
    balance = get_balance(root)
    
    # 4. 如果不平衡，进行旋转
    # 左左情况
    if balance > 1 and key < root.left.key:
        return right_rotate(root)
    
    # 右右情况
    if balance < -1 and key > root.right.key:
        return left_rotate(root)
    
    # 左右情况
    if balance > 1 and key > root.left.key:
        root.left = left_rotate(root.left)
        return right_rotate(root)
    
    # 右左情况
    if balance < -1 and key < root.right.key:
        root.right = right_rotate(root.right)
        return left_rotate(root)
    
    return root
```

##### AVL树的删除操作

```python

    elif key > root.key:
        root.right = delete_avl(root.right, key)
    else:

        if not root.left:
            return root.right
        elif not root.right:

        else:

    # 3. 获取平衡因子
    balance = get_balance(root)
    
    # 4. 如果不平衡，进行旋转
    # 左左情况
    if balance > 1 and get_balance(root.left) >= 0:
        return right_rotate(root)
    
    # 左右情况
    if balance > 1 and get_balance(root.left) < 0:
        root.left = left_rotate(root.left)
        return right_rotate(root)
    
    # 右右情况
    if balance < -1 and get_balance(root.right) <= 0:

    # 右左情况
    if balance < -1 and get_balance(root.right) > 0:
```

**时间复杂度**:
- 查找: $O(\log n)$
- 插入: $O(\log n)$
- 删除: $O(\log n)$

**空间复杂度**: $O(n)$

**高度分析**: AVL树的高度 $h$ 满足：
$$h \leq \log_2(n+1) + 1$$

<details>
<summary><strong>AVL树高度上界证明</strong></summary>

**定理**: 高度为 $h$ 的AVL树至少有 $F_{h+3} - 1$ 个节点，其中 $F_i$ 是斐波那契数列。

**证明**:

设 $N(h)$ 是高度为 $h$ 的AVL树的最少节点数。

**基础情况**:
- $N(0) = 1$（单节点）
- $N(1) = 2$（根节点和一个子节点）

**递推关系**:
对于高度 $h \geq 2$ 的AVL树，其左右子树的高度差不超过1。

设左子树高度为 $h-1$，右子树高度为 $h-2$（或相反），则：
$$N(h) = 1 + N(h-1) + N(h-2)$$

**证明递推关系**:
- 为了最小化节点数，一个子树的高度应为 $h-1$，另一个为 $h-2$
- 这样可以满足平衡条件且节点数最少

**求解递推式**:
$$N(h) = 1 + N(h-1) + N(h-2)$$

这个递推式与斐波那契数列相关：
$$N(h) + 1 = (N(h-1) + 1) + (N(h-2) + 1)$$

设 $M(h) = N(h) + 1$，则：
$$M(h) = M(h-1) + M(h-2)$$

初始条件：
- $M(0) = N(0) + 1 = 2$
- $M(1) = N(1) + 1 = 3$

因此，$M(h) = F_{h+3}$，其中 $F_i$ 是斐波那契数列：
$$F_0 = 0, F_1 = 1, F_2 = 1, F_3 = 2, F_4 = 3, F_5 = 5, ...$$

所以：
$$N(h) = M(h) - 1 = F_{h+3} - 1$$

**高度上界**:
由于 $F_{h+3} \approx \phi^{h+3} / \sqrt{5}$（其中 $\phi = (1+\sqrt{5})/2 \approx 1.618$），因此：
$$n \geq F_{h+3} - 1 \approx \frac{\phi^{h+3}}{\sqrt{5}}$$

解得：
$$h \leq \log_\phi(\sqrt{5} \cdot (n+1)) \approx 1.44 \log_2(n+1)$$

证毕。∎
</details>

#### 4.1.2 红黑树

##### 红黑树的基本概念

**定义**: 红黑树是一种自平衡二叉搜索树，每个节点包含一个颜色位（红色或黑色）。

**红黑树的性质**:
1. 每个节点要么是红色，要么是黑色
2. 根节点是黑色
3. 所有叶子节点（NIL）都是黑色

5. 从任意节点到其所有后代叶子节点的路径中，黑色节点的数量相同

### 4.2 B树、B+树、B*树

#### 4.2.1 B树的基本概念

##### B树的定义
**B树（B-Tree）**: 一种自平衡的多路搜索树，能够保持数据有序，支持高效的插入、删除和查找操作。

**B树的性质**:
设 $t$ 是B树的最小度数（$t \geq 2$），则：
1. 每个节点最多有 $2t-1$ 个关键字
2. 每个节点最少有 $t-1$ 个关键字（根节点除外）
3. 所有叶子节点都在同一层
4. 节点中的关键字按非降序排列
5. $k$ 个关键字将节点分为 $k+1$ 个子树

##### B树的节点结构

```python
class BTreeNode:
    def __init__(self, leaf=True):
        self.leaf = leaf
        self.keys = []
        self.children = []
    
    def search(self, key):
        i = 0
        while i < len(self.keys) and key > self.keys[i]:
            i += 1
        
        if i < len(self.keys) and key == self.keys[i]:
            return self, i
        
        if self.leaf:
            return None
        
        return self.children[i].search(key)
```

#### 4.2.2 B树的插入操作

```python
def insert_non_full(root, key):
    i = len(root.keys) - 1
    
    if root.leaf:
        # 在叶子节点中插入
        while i >= 0 and key < root.keys[i]:
            i -= 1
        root.keys.insert(i + 1, key)
    else:
        # 找到要插入的子树
        while i >= 0 and key < root.keys[i]:
            i -= 1
        i += 1
        
        if len(root.children[i].keys) == 2 * MIN_DEGREE - 1:
            # 分裂子节点
            split_child(root, i)
            if key > root.keys[i]:
                i += 1
        
        insert_non_full(root.children[i], key)

def split_child(parent, index):
    full_child = parent.children[index]
    mid = len(full_child.keys) // 2
    
    # 创建新节点
    new_child = BTreeNode(leaf=full_child.leaf)
    
    # 移动关键字和子节点
    new_child.keys = full_child.keys[mid + 1:]
    full_child.keys = full_child.keys[:mid]
    
    if not full_child.leaf:
        new_child.children = full_child.children[mid + 1:]
        full_child.children = full_child.children[:mid + 1]
    
    # 在父节点中插入中间关键字
    parent.keys.insert(index, full_child.keys[mid])
    parent.children.insert(index + 1, new_child)
```

#### 4.2.3 B树的删除操作

```python
def delete_key(root, key):
    if not root.search(key):
        return root
    
    if root.leaf:
        root.keys.remove(key)
    else:
        i = 0
        while i < len(root.keys) and key > root.keys[i]:
            i += 1
        
        if i < len(root.keys) and key == root.keys[i]:
            # 删除内部节点中的关键字
            if len(root.children[i].keys) >= MIN_DEGREE:
                # 前驱替换
                pred = get_predecessor(root.children[i])
                root.keys[i] = pred
                delete_key(root.children[i], pred)
            elif len(root.children[i + 1].keys) >= MIN_DEGREE:
                # 后继替换
                succ = get_successor(root.children[i + 1])
                root.keys[i] = succ
                delete_key(root.children[i + 1], succ)
            else:
                # 合并子节点
                merge_children(root, i)
                delete_key(root.children[i], key)
        else:
            # 在子节点中删除
            if len(root.children[i].keys) < MIN_DEGREE:
                fill_child(root, i)
            
            if i > len(root.keys):
                i -= 1
            
            delete_key(root.children[i], key)
    
    return root

def get_predecessor(node):
    while not node.leaf:
        node = node.children[-1]
    return node.keys[-1]

def get_successor(node):
    while not node.leaf:
        node = node.children[0]
    return node.keys[0]

def merge_children(parent, index):
    child = parent.children[index]
    sibling = parent.children[index + 1]
    
    # 下移父节点中的关键字
    child.keys.append(parent.keys[index])
    child.keys.extend(sibling.keys)
    
    if not child.leaf:
        child.children.extend(sibling.children)
    
    # 从父节点中移除关键字和兄弟节点
    parent.keys.pop(index)
    parent.children.pop(index + 1)
```

### 4.3 并查集（Union-Find）

#### 4.3.1 并查集的基本概念

**定义**: 并查集（Disjoint Set Union, DSU）是一种数据结构，用于处理不相交集合的合并和查询操作。

**基本操作**:
1. **MakeSet(x)**: 创建一个只包含元素x的集合
2. **Find(x)**: 找到元素x所在集合的根节点
3. **Union(x, y)**: 合并元素x和y所在的集合

#### 4.3.2 并查集的实现

##### 基本实现

```python
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n
    
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]
    
    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        
        if px == py:
            return False
        
        # 按秩合并
        if self.rank[px] < self.rank[py]:
            px, py = py, px
        
        self.parent[py] = px
        
        if self.rank[px] == self.rank[py]:
            self.rank[px] += 1
        
        return True
```

##### 路径压缩优化

```python
def find_optimized(self, x):
    if self.parent[x] != x:
        self.parent[x] = self.find_optimized(self.parent[x])
    return self.parent[x]
```

##### 按秩合并优化

**按大小合并**:
```python
def union_by_size(self, x, y):
    px, py = self.find(x), self.find(y)
    
    if px == py:
        return False
    
    if self.size[px] < self.size[py]:
        px, py = py, px
    
    self.parent[py] = px
    self.size[px] += self.size[py]
    
    return True
```

#### 4.3.4 并查集的复杂度分析

**理论复杂度**:
- 使用路径压缩和按秩合并
- Find操作: $O(\alpha(n))$（$\alpha$ 是反阿克曼函数）
- Union操作: $O(\alpha(n))$
- 空间复杂度: $O(n)$

**实际性能**:
- 对于所有实际应用，$\alpha(n) < 5$
- 近似常数时间复杂度

<details>
<summary><strong>并查集复杂度分析</strong></summary>

**定理**: 使用路径压缩和按秩合并的并查集，Find和Union操作的摊还时间复杂度为 $O(\alpha(n))$。

**证明**:

**定义**: 反阿克曼函数 $\alpha(n)$ 定义为：
$$\alpha(n) = \min\{k | A(k, k) \geq n\}$$

其中 $A(k, m)$ 是阿克曼函数。

**关键引理**: 在按秩合并中，每个节点的秩至少翻倍时，其父节点才会改变。

**证明**:
- 当节点 $x$ 与另一个集合合并时，如果 $rank(x) < rank(y)$，则 $rank(x)$ 不变
- 只有当 $rank(x) = rank(y)$ 时，$rank(x)$ 才会增加1
- 因此，节点的秩至少翻倍时，它才会成为另一个节点的子节点

**复杂度分析**:
- 路径压缩将路径上的所有节点直接连接到根节点
- 按秩合并确保树的高度较小
- 这两个优化结合，使得操作复杂度接近常数

**实际意义**:
- $\alpha(n)$ 增长极其缓慢
- 对于 $n \leq 10^{80}$，$\alpha(n) \leq 5$
- 因此可以认为是近似常数时间

### 4.4 线段树、树状数组

#### 4.4.1 线段树

##### 线段树的基本概念

**定义**: 线段树（Segment Tree）是一种二叉树结构，用于存储区间或线段的信息，支持高效的区间查询和更新操作。

**应用场景**:
- 区间求和
- 区间最大值/最小值
- 区间修改（加法、赋值等）
- 区间计数

##### 线段树的构建

```python
class SegmentTree:
    def __init__(self, data):
        self.n = len(data)
        self.size = 1
        while self.size < self.n:
            self.size *= 2
        self.tree = [0] * (2 * self.size)
        
        # 填充叶子节点
        for i in range(self.n):
            self.tree[self.size + i] = data[i]
        
        # 构建内部节点
        for i in range(self.size - 1, 0, -1):
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1]
```

##### 线段树的查询操作

```python
def query(self, l, r):
    """查询区间[l, r]的和"""
    l += self.size
    r += self.size
    result = 0
    
    while l <= r:
        if l % 2 == 1:
            result += self.tree[l]
            l += 1
        if r % 2 == 0:
            result += self.tree[r]
            r -= 1
        l //= 2
        r //= 2
    
    return result
```

##### 线段树的更新操作

```python
def update(self, index, value):
    """更新位置index的值"""
    pos = self.size + index
    self.tree[pos] = value
    
    pos //= 2
    while pos >= 1:
        self.tree[pos] = self.tree[2 * pos] + self.tree[2 * pos + 1]
        pos //= 2

def range_update(self, l, r, value):
    """区间更新：给区间[l, r]中的所有元素加上value"""
    self._range_update(l, r, value, 1, 0, self.size - 1)

def _range_update(self, l, r, value, node, node_l, node_r):
    if r < node_l or node_r < l:
        return
    
    if l <= node_l and node_r <= r:
        self.tree[node] += value * (node_r - node_l + 1)
        return
    
    mid = (node_l + node_r) // 2
    self._range_update(l, r, value, 2 * node, node_l, mid)
    self._range_update(l, r, value, 2 * node + 1, mid + 1, node_r)
    self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]
```

#### 4.4.2 树状数组（Fenwick Tree）

##### 树状数组的基本概念

**定义**: 树状数组（Binary Indexed Tree, BIT）是一种支持前缀和查询和点更新的数据结构。

**数学表示**: 树状数组使用二进制表示来维护区间信息。

##### 树状数组的实现

```python
class FenwickTree:
    def __init__(self, size):
        self.n = size
        self.tree = [0] * (size + 1)
    
    def update(self, index, delta):
        """在位置index增加delta"""
        i = index + 1  # 转换为1-based索引
        
        while i <= self.n:
            self.tree[i] += delta
            i += i & (-i)  # i += lowbit(i)
    
    def query(self, index):
        """查询前缀和[0, index]"""
        result = 0
        i = index + 1
        
        while i > 0:
            result += self.tree[i]
            i -= i & (-i)  # i -= lowbit(i)
        
        return result
    
    def range_query(self, l, r):
        """查询区间[l, r]的和"""
        return self.query(r) - (self.query(l - 1) if l > 0 else 0)
```

##### 树状数组的构建

```python
def build(self, data):
    """从数组构建树状数组"""
    for i in range(len(data)):
        self.update(i, data[i])
```

##### 树状数组的应用

**逆序对计数**:
```python
def count_inversions(arr):
    ft = FenwickTree(len(arr))
    inversions = 0
    
    for i, num in enumerate(arr):
        # 查询已处理元素中大于当前元素的个数
        inversions += ft.range_query(num + 1, len(arr) - 1)
        ft.update(num, 1)
    
    return inversions
```

### 4.5 字典树（Trie）

#### 4.5.1 Trie的基本概念

**定义**: 字典树（Trie）是一种树形数据结构，用于高效地存储和检索字符串集合中的键。

**特点**:
- 每个节点代表一个字符
- 从根到节点的路径表示一个字符串
- 所有具有相同前缀的字符串共享路径

#### 4.5.2 Trie的实现

##### 基本实现

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end_of_word = False

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end_of_word = True
    
    def search(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                return False
            node = node.children[char]
        return node.is_end_of_word
    
    def starts_with(self, prefix):
        node = self.root
        for char in prefix:
            if char not in node.children:
                return False
            node = node.children[char]
        return True
```

#### 4.6.2 后缀数组

##### 后缀数组的定义
**后缀数组（Suffix Array）**: 是对字符串所有后缀进行字典序排序后得到的数组。

##### 后缀数组的构建

**倍增算法**:
```python
def build_suffix_array(s):
    n = len(s)
    k = 1
    rank = [ord(c) for c in s]
    tmp = [0] * n
    sa = list(range(n))
    
    while True:
        # 按(前k个字符的排名, 后k个字符的排名)排序
        sa.sort(key=lambda x: (rank[x], rank[x + k] if x + k < n else -1))
        
        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, cur = sa[i - 1], sa[i]
            tmp[cur] = tmp[prev] + ((rank[prev], rank[prev + k] if prev + k < n else -1) < 
                                    (rank[cur], rank[cur + k] if cur + k < n else -1))
        
        rank, tmp = tmp, rank
        
        if rank[sa[-1]] == n - 1:
            break
        
        k <<= 1
    
    return sa
```

##### 后缀数组的应用

**最长重复子串**:

```python
        if lcp > max_len:

            result = s[sa[i]:sa[i] + lcp]

def compute_lcp(s, i, j):
    lcp = 0
    while i + lcp < len(s) and j + lcp < len(s) and s[i + lcp] == s[j + lcp]:
```

### 4.7 跳表（Skip List）

#### 4.7.1 跳表的基本概念

```python
        while random.random() < self.p and level < self.max_level:
            level += 1
        return level
    
    def insert(self, key, value):
        update = [None] * (self.max_level + 1)
        current = self.header
        
        # 找到要插入的位置
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
            update[i] = current
        
        current = current.forward[0]
        
        if current and current.key == key:
            current.value = value
        else:
            lvl = self.random_level()
            
            if lvl > self.level:
                for i in range(self.level + 1, lvl + 1):
                    update[i] = self.header
                self.level = lvl
            
            new_node = SkipListNode(key, value, lvl)
            
            for i in range(lvl + 1):
                new_node.forward[i] = update[i].forward[i]
                update[i].forward[i] = new_node
    
    def search(self, key):
        current = self.header
        
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
        
        current = current.forward[0]
        
        if current and current.key == key:
            return current.value
        return None
    
    def delete(self, key):
        update = [None] * (self.max_level + 1)
        current = self.header
        
        for i in range(self.level, -1, -1):
            while current.forward[i] and current.forward[i].key < key:
                current = current.forward[i]
            update[i] = current
        
        current = current.forward[0]
        
        if current and current.key == key:
            for i in range(self.level + 1):
                if update[i].forward[i] != current:
                    break
                update[i].forward[i] = current.forward[i]
            
            while self.level > 0 and not self.header.forward[self.level]:
                self.level -= 1
```

##### Dijkstra算法

**算法描述**: 在带权有向图中，计算从单源点到其他所有点的最短路径。

**适用条件**: 所有边权值非负。

```python
import heapq

def dijkstra(graph, start):
    """
    graph: {u: [(v, weight), ...]}
    """
    distances = {node: float('inf') for node in graph}
    distances[start] = 0
    pq = [(0, start)]
    visited = set()
    predecessors = {node: None for node in graph}
    
    while pq:
        current_dist, current = heapq.heappop(pq)
        
        if current in visited:
            continue
        
        visited.add(current)
        
        for neighbor, weight in graph[current]:
            distance = current_dist + weight
            
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                predecessors[neighbor] = current
                heapq.heappush(pq, (distance, neighbor))
    
    return distances, predecessors

def reconstruct_path(predecessors, start, end):
    path = []
    current = end
    while current is not None:
        path.append(current)
        current = predecessors[current]
    return list(reversed(path))
```

```python
import random

def randomized_quick_sort(arr):
    """
    随机化快速排序
    """
    def partition(arr, low, high):
        # 随机选择基准
        random_index = random.randint(low, high)
        arr[random_index], arr[high] = arr[high], arr[random_index]
        
        pivot = arr[high]
        i = low - 1
        
        for j in range(low, high):
            if arr[j] <= pivot:
                i += 1
                arr[i], arr[j] = arr[j], arr[i]
        
        arr[i + 1], arr[high] = arr[high], arr[i + 1]
        return i + 1
    
    def quick_sort_recursive(arr, low, high):
        if low < high:
            pi = partition(arr, low, high)
            quick_sort_recursive(arr, low, pi - 1)
            quick_sort_recursive(arr, pi + 1, high)
    
    quick_sort_recursive(arr, 0, len(arr) - 1)
    return arr
```

```python
    随机化选择算法：找到第k小的元素
    时间复杂度：O(n)（期望）

    pivot = arr[pivot_index]
```

### 7.4 流网络和最大流算法

#### 7.4.1 Ford-Fulkerson算法

```python
class Edge:
    def __init__(self, to, rev, capacity):
        self.to = to
        self.rev = rev
        self.capacity = capacity

class MaxFlow:
    def __init__(self, n):
        self.n = n
        self.graph = [[] for _ in range(n)]
    
    def add_edge(self, fr, to, cap):
        forward = Edge(to, len(self.graph[to]), cap)
        backward = Edge(fr, len(self.graph[fr]), 0)
        self.graph[fr].append(forward)
        self.graph[to].append(backward)
    
    def bfs(self, s, t, parent):
        """
        BFS寻找增广路径
        """
        visited = [False] * self.n
        queue = [s]
        visited[s] = True
        
        while queue:
            v = queue.pop(0)
            
            for edge in self.graph[v]:
                if not visited[edge.to] and edge.capacity > 0:
                    visited[edge.to] = True
                    parent[edge.to] = v
                    if edge.to == t:
                        return True
                    queue.append(edge.to)
        
        return False
    
    def max_flow(self, s, t):
        """
        Ford-Fulkerson算法
        """
        parent = [-1] * self.n
        max_flow = 0
        
        while self.bfs(s, t, parent):
            # 找到瓶颈容量
            path_flow = float('inf')
            v = t
            while v != s:
                u = parent[v]
                for edge in self.graph[u]:
                    if edge.to == v:
                        path_flow = min(path_flow, edge.capacity)
                        break
                v = u
            
            # 更新残量网络
            v = t
            while v != s:
                u = parent[v]
                for edge in self.graph[u]:
                    if edge.to == v:
                        edge.capacity -= path_flow
                        self.graph[v][edge.rev].capacity += path_flow
                        break
                v = u
            
            max_flow += path_flow
            parent = [-1] * self.n
        
        return max_flow
```

#### 7.4.2 Edmonds-Karp算法

```python
def edmonds_karp_max_flow(graph, source, sink):
    """
    Edmonds-Karp算法：使用BFS寻找最短增广路径
    时间复杂度：O(V * E^2)
    """
    n = len(graph)
    residual = [row[:] for row in graph]  # 残量网络
    parent = [-1] * n
    max_flow = 0
    
    while True:
        # BFS寻找增广路径
        parent = [-1] * n
        parent[source] = source
        queue = [source]
        
        while queue and parent[sink] == -1:
            u = queue.pop(0)
            for v in range(n):
                if parent[v] == -1 and residual[u][v] > 0:
                    parent[v] = u
                    queue.append(v)
        
        if parent[sink] == -1:
            break
        
        # 找到瓶颈容量
        path_flow = float('inf')
        v = sink
        while v != source:
            u = parent[v]
            path_flow = min(path_flow, residual[u][v])
            v = u
        
        # 更新残量网络
        v = sink
        while v != source:
            u = parent[v]
            residual[u][v] -= path_flow
            residual[v][u] += path_flow
            v = u
        
        max_flow += path_flow
    
    return max_flow
```

#### 7.5.1 单纯形法

```python
import numpy as np

def simplex_method(c, A, b):
    """
    单纯形法求解线性规划问题
    最大化：c^T x
    约束：Ax ≤ b, x ≥ 0
    """
    m, n = len(A), len(A[0])
    
    # 构建单纯形表
    tableau = np.zeros((m + 1, n + m + 1))
    tableau[:-1, :n] = A
    tableau[:-1, n:n + m] = np.eye(m)
    tableau[:-1, -1] = b
    tableau[-1, :n] = -c
    
    # 基变量索引
    basis = list(range(n, n + m))
    
    while True:
        # 检查是否达到最优解
        if np.all(tableau[-1, :-1] >= 0):
            break
        
        # 选择进入变量（最负的检验数）
        entering_col = np.argmin(tableau[-1, :-1])
        
        # 检查无界性
        if np.all(tableau[:-1, entering_col] <= 0):
            return None  # 无界解
        
        # 选择离开变量（最小比值）
        ratios = tableau[:-1, -1] / tableau[:-1, entering_col]
        ratios = np.where(tableau[:-1, entering_col] > 0, ratios, np.inf)
        leaving_row = np.argmin(ratios)
        
        # 枢轴操作
        pivot = tableau[leaving_row, entering_col]
        tableau[leaving_row] /= pivot
        
        for i in range(m + 1):
            if i != leaving_row:
                factor = tableau[i, entering_col]
                tableau[i] -= factor * tableau[leaving_row]
        
        basis[leaving_row] = entering_col
    
    # 提取解
    solution = np.zeros(n)
    for i in range(m):
        if basis[i] < n:
            solution[basis[i]] = tableau[i, -1]
    
    optimal_value = tableau[-1, -1]
    return solution, optimal_value
```

#### 7.5.2 整数规划

##### 分支定界法

```python
def branch_and_bound_integer_programming(c, A, b):
    """
    分支定界法求解整数规划
    """
    from math import inf
    
    # 求解线性规划松弛
    lp_solution, lp_value = simplex_method(c, A, b)
    
    if lp_solution is None:
        return None, inf  # 无解
    
    # 检查整数性
    if all(abs(x - round(x)) < 1e-6 for x in lp_solution):
        return lp_solution, lp_value
    
    # 选择非整数变量进行分支
    fractional_vars = [i for i, x in enumerate(lp_solution) if abs(x - round(x)) > 1e-6]
    branch_var = fractional_vars[0]
    
    # 分支1：x_i ≤ floor(x_i)
    A1, b1 = A[:], b[:]
    A1.append([1 if i == branch_var else 0 for i in range(len(c))])
    b1.append(int(lp_solution[branch_var]))
    
    # 分支2：x_i ≥ ceil(x_i)
    A2, b2 = A[:], b[:]
    A2.append([-1 if i == branch_var else 0 for i in range(len(c))])
    b2.append(-int(lp_solution[branch_var]) - 1)
    
    # 递归求解
    sol1, val1 = branch_and_bound_integer_programming(c, A1, b1)
    sol2, val2 = branch_and_bound_integer_programming(c, A2, b2)
    
    # 选择最优解
    if val1 < val2:
        return sol1, val1
    else:
        return sol2, val2
```

```python
def max_subarray_sum_analysis():
    """
    问题：求数组的最大子数组和
    解法：Kadane算法
    
    状态定义：dp[i] = 以i结尾的最大子数组和
    状态转移：dp[i] = max(dp[i-1] + arr[i], arr[i])
    
    复杂度：O(n)时间，O(1)空间
    """
    def kadane(arr):
        max_ending = max_global = arr[0]
        
        for i in range(1, len(arr)):
            max_ending = max(arr[i], max_ending + arr[i])
            max_global = max(max_global, max_ending)
        
        return max_global
```

**例题2: 最长公共子序列**

```python
def lcs_analysis():
    """
    问题：求两个字符串的最长公共子序列
    解法：动态规划
    
    状态定义：dp[i][j] = text1[:i]和text2[:j]的LCS长度
    状态转移：
    dp[i][j] = dp[i-1][j-1] + 1 (if text1[i-1] == text2[j-1])
    dp[i][j] = max(dp[i-1][j], dp[i][j-1]) (otherwise)
    
    复杂度：O(m*n)时间，O(m*n)空间
    """
    def longest_common_subsequence(text1, text2):
        m, n = len(text1), len(text2)
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if text1[i-1] == text2[j-1]:
                    dp[i][j] = dp[i-1][j-1] + 1
                else:
                    dp[i][j] = max(dp[i-1][j], dp[i][j-1])
        
        return dp[m][n]
```

```python
class LRUCache:
    """
    问题：实现LRU缓存
    要求：O(1)时间复杂度的get和put操作
    
    解法：哈希表 + 双向链表
    - 哈希表：O(1)查找
    - 双向链表：O(1)移动节点
    """
    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}
        self.head = Node()
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head
    
    def get(self, key):
        node = self.cache.get(key)
        if not node:
            return -1
        
        self.move_to_head(node)
        return node.value
    
    def put(self, key, value):
        node = self.cache.get(key)
        
        if node:
            node.value = value
            self.move_to_head(node)
        else:
            if len(self.cache) >= self.capacity:
                self.remove_tail()
            
            new_node = Node(key, value)
            self.add_to_head(new_node)
            self.cache[key] = new_node
```
