## 📝 核心公式汇总

### 性能评价公式
- CPU执行时间：$T_{CPU} = IC \times CPI \times T_{clock}$
- MIPS计算：$MIPS = \frac{f_{clock}}{CPI \times 10^6}$
- Amdahl定律：$S = \frac{1}{(1-f) + \frac{f}{n}}$

### 存储系统公式
- Cache平均访问时间：$AMAT = Hit_Time + Miss_Rate \times Miss_Penalty$
- 存储器带宽：$Bandwidth = Width \times Frequency$
- 磁盘访问时间：$T = T_{seek} + T_{rotation} + T_{transfer}$

### 流水线公式
- 流水线加速比：$S = \frac{T_{serial}}{T_{pipeline}}$
- 流水线效率：$E = \frac{S}{k}$（k为流水段数）

### 总线性能公式
- 总线带宽：$Bandwidth = \frac{Width \times Frequency}{8}$
