## 📊 核心公式速查

### 性能评价公式
| 公式名称 | 数学表达式 | 适用场景 |
|---------|-----------|----------|
| CPU执行时间 | $T_{CPU} = IC \times CPI \times T_{clock}$ | 程序执行时间计算 |
| MIPS | $MIPS = \frac{f_{clock}}{CPI \times 10^6}$ | 指令执行速度 |
| Amdahl定律 | $S = \frac{1}{(1-f) + \frac{f}{n}}$ | 系统加速比计算 |
| 流水线加速比 | $S = \frac{T_{serial}}{T_{pipeline}}$ | 流水线性能分析 |

### 存储系统公式
| 公式名称 | 数学表达式 | 适用场景 |
|---------|-----------|----------|
| Cache AMAT | $AMAT = Hit_Time + Miss_Rate \times Miss_Penalty$ | Cache性能分析 |
| 存储器带宽 | $Bandwidth = Width \times Frequency$ | 内存带宽计算 |
| 磁盘访问时间 | $T = T_{seek} + T_{rotation} + T_{transfer}$ | 磁盘性能分析 |
| 虚拟存储命中率 | $Hit_Rate = \frac{Hit_Count}{Total_Access}$ | 虚存性能评估 |

### 总线性能公式
| 公式名称 | 数学表达式 | 适用场景 |
|---------|-----------|----------|
| 总线带宽 | $Bandwidth = \frac{Width \times Frequency}{8}$ | 总线传输能力 |
| 总线利用率 | $Utilization = \frac{Data_Transfer_Time}{Total_Cycle_Time}$ | 总线使用效率 |

|------|------|------|------|--------|----------|

## 🧮 常用计算模板

### CPU性能计算模板
```
已知：
- 指令总数：IC
- 平均CPI：CPI_avg  
- 时钟周期：T_clock

求解：
CPU执行时间 = IC × CPI_avg × T_clock
MIPS = f_clock / (CPI_avg × 10^6)
```

### Cache性能计算模板
```
已知：
- Cache命中率：h
- Cache访问时间：t_c
- 主存访问时间：t_m

求解：
AMAT = h × t_c + (1-h) × t_m
```

### 总线带宽计算模板
```
已知：
- 总线宽度：W (位)
- 总线频率：f (Hz)

求解：
带宽 = (W × f) / 8 (字节/秒)
```

## 📚 重要概念速记

### 冯·诺依曼体系特点
- 存储程序概念
- 五大部件：运算器、控制器、存储器、输入、输出
- 二进制表示
- 顺序执行

### 哈佛结构特点
- 指令存储器和数据存储器分离
- 并行取指和访存
- 避免冯·诺依曼瓶颈

### 流水线技术要点
- **加速比**：理想情况 = 流水段数
- **效率**：$\frac{实际加速比}{流水段数}$
- **吞吐率**：$\frac{指令数}{总时间}$

### Cache设计要点
- **映射方式**：直接、组相联、全相联
- **替换策略**：LRU、FIFO、随机
- **写策略**：写直达、写回
