# 中国科学技术大学计算机组成原理课程调研报告

## 课程基本信息

**课程名称：** 计算机组成原理  
**授课教师：** 卢建良老师 (lujl@ustc.edu.cn)

## 详细章节内容

### Lab1：实用汇编程序
**实验目标：** 熟悉RISC指令集（龙芯LA32R和RV32I）的指令格式和编码，为后续硬件实现做准备

**核心内容：**
- 指令集选择：RV32I（RISC-V子集）和LA32R（龙芯架构子集）
- **任务1（6分）：** 计算斐波那契数列第N项（1≤N≤30）
- **任务2（3分）：** 计算斐波那契数列第N项（1≤N≤80）的大整数结果
- **任务3（1分）：** 导出指令段的COE文件

**核心知识点：**
- RISC架构特点
- 固定长度指令编码
- load/store架构
- 寄存器操作
- 算术逻辑运算
- 内存访问
- 跳转分支指令

### Lab2：CPU功能部件设计
**实验目标：** 通过Verilog实现CPU功能部件，为后续单周期CPU设计奠定基础

**核心内容：**
- **任务1（3分）：** 设计32位寄存器堆，仿真验证
- **任务2（3分）：** 设计32位ALU，支持多种运算模式
- **任务3（3分）：** 基于ALU在FPGAOL平台搭建计算器
- **任务4（1分）：** 创建存储器IP核，导入COE文件

**核心知识点：**
- Verilog硬件描述语言
- FPGA开发
- 仿真验证
- 硬件调试
- 寄存器堆设计
- ALU设计

### Lab3：简单单周期CPU
**实验目标：** 构建第一个基础的单周期CPU，理解CPU、PDU和MEM之间的协同工作原理

**核心内容：**
- **任务1（3分）：** 译码器设计，根据选择的指令集设计Decoder模块
- **任务2（4分）：** CPU搭建，实现CPU各功能模块并正确连接
- **任务3（3分）：** 思考与总结，回答关于时钟信号、指令选择和关键路径的问题

**核心知识点：**
- 单周期CPU架构
- 指令译码
- 控制信号生成
- 数据通路设计
- 时序分析
- 支持从add.w到pcaddu12i的全部指令

### Lab4：完整单周期CPU
**实验目标：** 完善单周期CPU，增加分支指令和访存指令功能

**核心内容：**
- **任务1（3分）：** 设计访存控制单元SL_UNIT
- **任务2（4分）：** 搭建CPU并正确连接各功能模块
- **任务3（1分）：** 实现斐波那契数列程序并运行
- **任务4（2分）：** 思考与总结，包括重新设计SL_UNIT和分析关键路径

**新增指令：**
- 8种访存指令：ld.w, ld.h, ld.b, ld.hu, ld.bu, st.w, st.h, st.b
- 8种分支跳转指令：jirl, b, bl, beq, bne, blt, bge, bltu, bgeu

### Lab5：无冒险流水线CPU
**实验目标：** 将上次实验的CPU进行流水化，形成不考虑冒险的流水线CPU

**核心内容：**
- **任务1（3分）：** 实现写优先寄存器堆，仿真测试并回答特定指令序列下x4和x5的结果
- **任务2（7分）：** 设计无冒险流水线CPU，在FPGAOL上板运行并通过测试程序

**核心知识点：**
- 流水线架构
- 段间寄存器flush功能
- commit信号流水传递
- PC始终+4
- 分支错误时清零nop指令的commit信号

### Lab6：完整流水线CPU
**实验目标：** 结合前递模块与段间寄存器控制模块，构建完整流水线CPU

**核心内容：**
- **任务1（2分）：** 前递模块设计，根据传入信号与优先级判断进行前递模块设计
- **任务2（3分）：** 加入前递的流水线，将前递模块接入CPU并通过仿真测试
- **任务3（2分）：** 段间寄存器控制模块设计，根据输入信号进行段间寄存器控制
- **任务4：** 完整流水线CPU实现

**核心知识点：**
- 数据前递技术
- 流水线冒险处理
- 段间寄存器控制
- 流水线CPU优化

### Lab7：高速缓存Cache
**实验目标：** 学习高速缓存Cache的组织结构和工作机理，提高CPU性能

**核心内容：**
- **任务1（5分）：** 二路组相连Cache，支持LRU替换策略
- **任务2（2分）：** 实现除LRU外的至少两种替换策略（伪随机、FIFO等）
- **任务3（3分）：** 实现参数化的N路组相连Cache，支持LRU替换策略

**核心知识点：**
- Cache组织结构
- 替换策略机制（LRU、伪随机、FIFO等）
- N路组相连设计原理
- Cache命中与缺失处理

## 总结

中国科学技术大学的计算机组成原理课程是一门设计精良、体系完整的专业核心课程。课程采用渐进式教学方法，从基础的汇编编程开始，逐步深入到CPU设计和Cache实现，最终构建完整的计算机系统。课程不仅注重理论知识的传授，更强调实践能力的培养，通过7个精心设计的实验项目，让学生在动手实践中深入理解计算机组成原理的核心概念和设计思想。

该课程的特色在于：
1. **系统性：** 覆盖了从指令集到CPU到存储系统的完整计算机体系
2. **实践性：** 每个理论概念都有对应的实验验证
3. **先进性：** 使用现代化的开发工具和平台
4. **完整性：** 提供了从入门到精通的完整学习路径

这门课程为学生后续学习计算机体系结构、操作系统、编译器等高级课程奠定了坚实的基础，是计算机科学与技术专业学生不可或缺的重要课程。
