### 可见题目内容

根据页面分析，发现以下常考大题：

#### 题目1: 存储体系结构设计
**题目内容**: "在'Cache-主存-辅存'三级存储体系中，'Cache-主存'结构与'主存-辅存'结构的引入为"

**考点分析**:
- **核心概念**: 存储器层次结构设计原理
- **关键知识点**: 
  - 局部性原理（时间局部性、空间局部性）
  - 存储系统性能优化
  - 成本与速度的权衡
- **设计要点**: 
  - Cache-主存：解决速度匹配问题
  - 主存-辅存：解决容量扩展问题

**解题方法**:
1. 分析三级存储体系各层特点
2. 说明引入原因和设计原理
3. 阐述各层在系统中的作用
4. 总结性能提升效果

#### 题目2: CPU控制单元寄存器
**题目内容**: "在CPU中，那些寄存器属于控制用指令部件，它们各起什么作用？"

**考点分析**:
- **核心概念**: CPU内部寄存器组织结构
- **关键知识点**:
  - 程序计数器(PC)
  - 指令寄存器(IR)
  - 存储器地址寄存器(MAR)
  - 存储器数据寄存器(MDR)
  - 控制单元工作原理
- **设计要点**:
  - 指令周期各阶段寄存器的作用
  - 控制信号的生成和传递

**解题方法**:
1. 列出控制用寄存器类型
2. 逐一说明各寄存器功能
3. 描述寄存器间的协作关系
4. 解释在指令执行中的作用

#### 题目3: 中断与DMA方式比较
**题目内容**: "比较说明中断方式与DMA方式的异同"

**考点分析**:
- **核心概念**: I/O数据传送方式
- **关键知识点**:
  - 中断机制原理
  - DMA传输机制
  - CPU参与程度差异
  - 传输效率比较
- **设计要点**:
  - 两种方式的优缺点
  - 适用场景分析
  - 硬件实现差异

**解题方法**:
1. 阐述中断方式特点
2. 阐述DMA方式特点
3. 对比分析异同点
4. 说明各自适用场景

## 计算机组成原理大题常见题型分析

### 1. 设计类题目
**特点**: 要求设计计算机系统各部件
**常见考点**:
- 存储器层次结构设计
- CPU结构设计
- 总线系统设计
- I/O接口设计

**解题策略**:
1. 明确设计需求和约束条件
2. 分析各部件功能要求
3. 设计具体实现方案
4. 验证设计合理性和可行性

### 2. 比较分析类题目
**特点**: 对比不同技术方案的优缺点
**常见考点**:
- 不同存储方式比较
- 多种I/O方式比较
- 指令系统设计比较
- CPU性能优化方法比较

**解题策略**:
1. 列出对比维度和评价标准
2. 逐一分析各方案特点
3. 量化比较关键指标
4. 总结适用场景

### 3. 原理分析类题目
**特点**: 深入分析工作原理和机制
**常见考点**:
- 指令执行过程分析
- 中断处理机制
- 流水线技术原理
- Cache工作原理

**解题策略**:
1. 梳理基本工作流程
2. 分析关键控制信号
3. 解释时序关系
4. 说明优化措施

### 4. 计算类题目
**特点**: 涉及定量分析和计算
**常见考点**:
- 存储器容量计算
- 性能指标计算
- 传输时间计算
- 命中率计算

**解题策略**:
1. 建立数学模型
2. 确定计算公式
3. 代入参数计算
4. 验证结果合理性
