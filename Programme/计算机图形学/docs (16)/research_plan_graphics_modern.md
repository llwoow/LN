# 现代图形学和实时渲染技术研究计划

## 研究目标
深入研究现代图形学和实时渲染技术的核心概念、架构原理和实际应用，产出全面的技术文档。

## 研究范围
1. GPU架构：GPU流水线、并行计算、显存管理
2. Shader编程：顶点着色器、片段着色器、几何着色器
3. 着色器语言：GLSL、HLSL、Shader模型
4. 光线追踪：光线生成、交点计算、光线追踪算法
5. 实时渲染优化：LOD技术、遮挡剔除、批处理
6. 现代渲染技术：延迟渲染、前向渲染、体积渲染
7. 图形API：OpenGL、Vulkan、DirectX
