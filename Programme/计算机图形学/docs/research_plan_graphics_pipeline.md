# 图形渲染管线核心技术研究计划

## 研究目标
深入研究图形渲染管线的核心技术，重点关注算法实现和数学原理

## 研究范围
1. 几何变换：模型变换、视图变换、投影变换
2. 投影变换：正交投影、透视投影、投影矩阵推导
3. 光栅化算法：DDA算法、Bresenham算法、扫描线算法
4. 纹理映射：UV坐标、纹理采样、双线性插值
5. 深度缓冲：Z-buffer算法、深度测试
6. 渲染管线：顶点处理、图元装配、光栅化、片段处理
