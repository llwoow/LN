# 计算机图形学高级技术研究计划

## 研究目标
深入研究计算机图形学的高级技术和算法，涵盖光照模型、阴影算法、反射模型、曲线曲面、几何算法和纹理技术等六个核心领域。

## 任务分解

### 1. 光照模型研究
- [x] 1.1 Phong光照模型：数学原理、公式推导、优缺点分析
- [x] 1.2 Blinn-Phong模型：改进原理、与Phong模型对比
- [x] 1.3 Cook-Torrance模型：微表面理论、物理基础、实现细节

### 2. 阴影算法研究
- [x] 2.1 阴影映射：算法原理、深度纹理、采样技术
- [x] 2.2 阴影体积：模板缓存、几何构造、性能分析
- [x] 2.3 软阴影：PCF、采样方法、质量评估

### 3. 反射模型研究
- [x] 3.1 镜面反射：反射定律、光线追踪
- [x] 3.2 漫反射：Lambert模型、能量守恒
- [x] 3.3 BRDF理论：双向反射分布函数、物理基础、测量方法

### 4. 曲线曲面研究
- [x] 4.1 Bezier曲线：定义、性质、算法实现
- [x] 4.2 B样条：基函数、节点矢量、控制点
- [x] 4.3 NURBS：非均匀有理B样条、权重控制
- [x] 4.4 细分曲面：Catmull-Clark、Loop细分

### 5. 几何算法研究
- [x] 5.1 裁剪算法：Sutherland-Hodgman、Cohen-Sutherland
- [x] 5.2 相交检测：线段相交、多边形相交、包围体
- [x] 5.3 几何构造：布尔运算、网格重建

### 6. 纹理技术研究
- [x] 6.1 法线贴图：切线空间、法线计算、采样方法
- [x] 6.2 位移贴图：高度场、几何细节、采样算法
- [x] 6.3 环境贴图：球面映射、立方体映射、IBL
