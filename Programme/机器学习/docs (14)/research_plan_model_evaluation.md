# 机器学习模型评估指标和优化方法研究计划

## 研究目标
深入研究机器学习中的模型评估指标和优化方法，提供全面的技术分析和实践指导。

## 研究范围
1. **评估指标研究**
   - [ ] 分类指标：准确率、精确率、召回率、F1-score、AUC-ROC
   - [ ] 回归指标：RMSE、MAE、R²
   - [ ] 指标选择的理论依据和应用场景

2. **交叉验证方法**
   - [ ] Hold-out验证
   - [ ] K折交叉验证
   - [ ] 分层K折交叉验证
   - [ ] 时间序列交叉验证
   - [ ] 留一交叉验证

3. **超参数优化方法**
   - [ ] 网格搜索（Grid Search）
   - [ ] 随机搜索（Random Search）
   - [ ] 贝叶斯优化（Bayesian Optimization）
   - [ ] 其他优化方法（遗传算法、粒子群优化等）

4. **特征选择和特征工程**
   - [ ] 特征选择方法：过滤法、包装法、嵌入法
   - [ ] 特征工程技术：标准化、归一化、编码、特征构造
   - [ ] 降维技术：PCA、t-SNE、UMAP

5. **模型选择和集成方法**
   - [ ] Bagging方法（Bootstrap Aggregating）
   - [ ] Boosting方法（AdaBoost、Gradient Boosting、XGBoost等）
   - [ ] Stacking方法
   - [ ] Voting方法

6. **正则化方法**
   - [ ] L1正则化（Lasso）
   - [ ] L2正则化（Ridge）
   - [ ] Elastic Net
   - [ ] Dropout
   - [ ] 早停法
