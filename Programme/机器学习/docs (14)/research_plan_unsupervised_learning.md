# 无监督学习算法深入研究计划

## 研究目标
深入研究无监督学习的主要算法和方法，包括算法原理、数学推导、实现步骤、优缺点分析、应用场景等。

## 研究范围
1. 聚类算法（K-means、层次聚类、DBSCAN）
2. 降维技术（PCA、t-SNE、UMAP）
3. 关联规则挖掘（Apriori算法）
4. 异常检测方法
5. 密度估计
