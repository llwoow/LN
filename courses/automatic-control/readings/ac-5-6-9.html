读稳定裕度，判断延迟风险

把滤波器放进反馈回路后，真正要问的是：某个频率的扰动绕一圈回来，会被抵消还是继续维持？把从误差到反馈信号的一圈频响记为 \(L(j\omega)\)，减号留在比较点。若这一圈恰好把波形翻相 180°，比较点再减一次，返回的扰动就与初始扰动同相；若幅值比同时为 1，它绕一圈也不会变小。这个边界对应 \(L(j\omega)=-1\)，也是负反馈特征方程 \(1+L(s)=0\) 出现虚轴根的条件。

公式与重点速查

在伯德图上，两种裕度各从哪张图开始读

用三个时间常数均为 1 s 的一阶环节串联，回路低频增益取 4。用秒作时间尺度，开环 \(L(s)=4/(1+s)^3\)，\(s\) 为复频率；\(\omega\) 为角频率（rad/s）。\(\omega_c\) 指幅值到 1（0 dB）的增益交越频率，\(\omega_{180}\) 指相位到 −180° 的频率。由串联环节的幅相相加，三个相同环节的幅值比相乘、相位相加，得到下式，并画成图5.6.9.1。前一页 RC 的 −3 dB 点属于单个环节，整圈的 0 dB 要从 \(L\) 的曲线上找。

\[\begin{aligned} |L(j\omega)| &= \frac{4}{(1+\omega^2)^{3/2}},\\ \angle L(j\omega) &= -3\arctan\omega. \end{aligned}\]

要问还能多滞后多少，就在上图找 0 dB，沿同一条竖线到下图读连续相位。相位裕度 \(\varphi_m\) 是该处相位到 −180° 的差：

\[\varphi_m=180^\circ+\angle L(j\omega_c).\]

手算时，用式（C.5.6.9.1）令 \((1+\omega_c^2)^{3/2}=4\)，两边取 \(2/3\) 次幂，得 \(\omega_c=\sqrt{4^{2/3}-1}\approx1.233\,\mathrm{rad/s}\)。这一频率下每段约滞后 50.95°，三段合为 −152.86°。代入式（C.5.6.9.2）得到 27.14°。

要问增益还能乘多少，就在下图找 −180°，沿同一条竖线到上图读幅值。把实数正增益统一乘一个倍数，幅值会同比例变化，相位曲线保持原样。记临界倍数为增益裕度 \(G_m\)，用 \(G_{m,\mathrm{dB}}\) 表示同一倍数的分贝数：

\[\begin{aligned} G_m &= \frac{1}{|L(j\omega_{180})|},\\ G_{m,\mathrm{dB}} &= 20\log_{10}G_m. \end{aligned}\]

式（C.5.6.9.1）的三段相位相同，因此总相位到 −180° 时每段恰好滞后 60°，得到 \(\omega_{180}=\tan 60^\circ=\sqrt3\,\mathrm{rad/s}\)。代回同一频率的幅值，得到 \(4/(1+3)^{3/2}=0.5\)。按式（C.5.6.9.3）取倒数，裕度为 2 倍（+6.02 dB）。图上的 −6.02 dB 是原幅值；要把曲线抬到 0 dB，需要的是 +6.02 dB。

再用闭环极点核对。把低频增益记为 \(K\)，由 \(1+L(s)=0\) 得特征多项式 \(s^3+3s^2+3s+1+K\)。对正增益，系数都为正，三阶劳斯判据还要求 \(3\times3>1+K\)，所以 \(0<K<8\)。到 8 时多项式分解为 \((s+3)(s^2+3)\)，正好在 \(\omega_{180}=\sqrt3\,\mathrm{rad/s}\) 出现一对虚轴根，与从 4 乘 2 的结果吻合。

加上延迟后，还剩多少相位余量

额外纯延迟 \(T_d\)（s）把整条正弦波向右移。把正弦的时间 \(t\) 换成 \(t-T_d\)，相位就从 \(\omega t\) 变为 \(\omega t-\omega T_d\)。换成复数，就是给开环乘 \(e^{-j\omega T_d}\)。这个因子的模始终为 1，因此 0 dB 交越还在原频率；在这里继续扣掉相位，直到刚好耗完原裕度。记首次临界延迟为 \(T_{d,\mathrm{crit}}\)（s）：

\[T_{d,\mathrm{crit}}=\frac{\varphi_m}{\omega_c}.\]

式（C.5.6.9.4）的分子必须用弧度。这里 \(27.14^\circ\times\pi/180\approx0.474\,\mathrm{rad}\)，除以 \(1.233\,\mathrm{rad/s}\)，得到 0.384 s。加 0.20 s 后还剩 13.01°；加 0.40 s 后首次稳定边界已经越过。这是模型的边界，做实际预算还需要给参数不确定性和波动留余量。

这个算法依赖本例原本闭环稳定、幅值只有一次 0 dB 交越，而且新增环节可以当作纯延迟。实际电驱串级回路里的采样、保持、滤波和执行器可能同时改变幅值和相位。把整个环路的响应核对清楚，才能用这项预算。

为什么有些回路不能光看两处交越

奈奎斯特图把每个频率的幅值和相位画成复平面上的一个点，随频率连成轨迹。伯德图的两种交越分别对应轨迹穿过单位圆和负实轴。完整的奈奎斯特判据还要数轨迹绕 −1 的圈数，才能处理开环已有不稳定极点或存在多次交越的回路。

沿 \(s\) 平面顺时针包围右半平面，记开环极点数为 \(P\)，闭环极点数为 \(Z\)，都只数右半平面并计重数。记 \(L(s)\) 的轨迹相对 −1 的净顺时针圈数为 \(N\)。对 \(1+L(s)\) 应用辐角原理，数它绕原点的圈数，和数 \(L(s)\) 绕 −1 等价：

\[N=Z-P.\]

在没有被传递函数相消掩盖的不稳定模态，且没有临界根的前提下，要使 \(Z=0\)，就要逆时针绕 \(P\) 圈。开环有虚轴极点时，扫描路径要绕开极点；轨迹经过 −1 时则要直接检查虚轴根。

比如以秒为时间尺度的单位负反馈回路 \(L(s)=0.5/(s-1)\)，所有频率的开环幅值都不超过 0.5，因而没有 0 dB 交越。右半平面边界在无穷远的圆弧映到原点附近，整条奈奎斯特轨迹落在半径 0.5 的圆内，绕 −1 的圈数 \(N=0\)。开环有一个右半平面极点，按式（C.5.6.9.5）仍有 \(Z=P=1\)；直接解 \(1+L(s)=0\) 也得到 \(s=0.5\,\mathrm{s^{-1}}\)。

公式与重点速查

  • 单个环节的幅相怎样影响整个回路？ 从波形用 \(20\log_{10}(A_o/A_i)\) 和 \(-360^\circ f\Delta t\) 得到同一频率的幅相，见式（C.5.1.4）。计入级间加载后，串联环节的分贝数和相位分别相加。一阶 RC 在 \(f_{\mathrm c}=1/(2\pi RC)\) 处贡献 −3.01 dB 和 −45°，见式（C.5.1.3）。把它接入回路后，相位和 0 dB 交越都可能变，要先合成整圈的响应再判断。
  • 两种裕度都在问离 \(-1\) 还有多远。 0 dB 已满足幅值为 1，所以在这个频率量相位还差多少，得到 \(\varphi_m=180^\circ+\angle L(j\omega_c)\)，见式（C.5.6.9.2）。−180° 已满足翻相，所以在那个频率量增益还要乘多少，得到 \(G_m=1/|L(j\omega_{180})|\)，见式（C.5.6.9.3）。这两个问题固定的量不同，才会用到两个交越。
  • 加了什么环节，决定该重算哪一步。 整条波形单纯后移时，只在原 0 dB 处扣除 \(\omega_c T_d\) 弧度。用弧度代入 \(T_{d,\mathrm{crit}}=\varphi_m/\omega_c\)，见式（C.5.6.9.4）。加滤波器会同时改变幅值和相位。若控制器每次读数后把输出锁到下一次更新，要从实际保持时序重新判断稳定边界。
  • 回路本身有不稳定极点时，还要看整条轨迹。 两个裕度只取两处读数。检查全轨迹绕 \(-1\) 的圈数，可以把开环与闭环右半平面根数联系起来，见式（C.5.6.9.5）。有多个交越时，这个整体检查也能避免选了一处看起来安全的读数就下结论。
