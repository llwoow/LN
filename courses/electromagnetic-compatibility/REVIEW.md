- 教材扫描 PDF 的全部页面还未完成逐式、逐图审校；当前不能称“所有原图原题已核读”。课程输出是**原创教学解析**而不是整书原文公开转录。

## 继续完善时的检查顺序

1. 核读对应教材扫描页、课件图片与公式（必要时对关键图逐个放大），标记缺失、冲突和只出现于一份材料的内容。
2. 从电路/电磁场对象建立变量、参考方向、边界条件和推导，再编写可独立阅读的说明，配高保真自绘工程图和可复算算例。不采用固定七段模板。
3. 按 `TEACHING.md` 与 `PRACTICE.md` 审查真实内容，建立章节来源/公式/图表/术语索引并写入核验记录。
4. 运行 `python scripts/build-reference-index.py --check`、`python scripts/build-glossary.py --check`、`python -m unittest discover -s tests -v`、`node tests/knowledge-map.test.cjs` 以及浏览器回归测试，再判断是否满足发布条件。
