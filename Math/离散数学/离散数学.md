#### 一、集合论基础

##### 1. 集合的定义与表示
- **集合（Set）**：由确定、互异的元素组成的整体。
- **表示方法**：
  - 列举法：`A = {1, 2, 3}`
  - 描述法：`A = {x | x 是正整数且 x < 4}`
- **特殊集合**：
  - **空集（∅）**：不含任何元素的集合。
  - **全集（U）**：当前讨论范围内的所有元素构成的集合。

##### 2. 集合的关系
- **属于关系（∈）**：元素与集合的关系，如 `a ∈ A`。
- **包含关系**：
  - **子集（⊆）**：若 `∀x (x ∈ A → x ∈ B)`，则 `A ⊆ B`。
  - **真子集（⊂）**：`A ⊆ B` 且 `A ≠ B`。
- **幂集（Power Set）**：集合 `A` 的所有子集构成的集合，记作 `P(A)`。
  - 例如，`A = {1, 2}`，则 `P(A) = {∅, {1}, {2}, {1, 2}}`。

##### 3. 集合的运算
| 运算               | 符号   | 定义                                     |
|--------------------|--------|------------------------------------------|
| 并集               | `A ∪ B`| `{x | x ∈ A 或 x ∈ B}`               |
| 交集               | `A ∩ B`| `{x | x ∈ A 且 x ∈ B}`               |
| 差集               | `A − B`| `{x | x ∈ A 且 x ∉ B}`               |
| 补集               | `Ā`    | `U − A`                                  |
| 对称差集           | `A ⊕ B`| `(A − B) ∪ (B − A)`                     |

##### 4. 集合的运算律
- **交换律**：  
  `A ∪ B = B ∪ A`，`A ∩ B = B ∩ A`
- **结合律**：  
  `(A ∪ B) ∪ C = A ∪ (B ∪ C)`
- **分配律**：  
  `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`  
  `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`
- **德摩根律**：  
  `A ∪ B̄ = Ā ∩ B̄`  
  `A ∩ B̄ = Ā ∪ B̄`

##### 5. 集合的基数
- **基数（Cardinality）**：集合中元素的数量，记作 `|A|`。
- **容斥原理**：  
  $$|A ∪ B| = |A| + |B| - |A ∩ B|$$  
  扩展到三个集合：  
  $$|A ∪ B ∪ C| = |A| + |B| + |C| - |A ∩ B| - |A ∩ C| - |B ∩ C| + |A ∩ B ∩ C|$$

#### 二、关系（Relations）

##### 1. 二元关系的基本概念
- **定义**：若 `A` 和 `B` 是集合，则 `A × B` 的子集称为从 `A` 到 `B` 的二元关系。
  - 例如：`A = {1, 2}`，`B = {a, b}`，则 `R = {(1, a), (2, b)}` 是一个关系。
- **关系性质**：
  - **自反性**：`∀a ∈ A`, `(a, a) ∈ R`
  - **对称性**：若 `(a, b) ∈ R`，则 `(b, a) ∈ R`
  - **传递性**：若 `(a, b) ∈ R` 且 `(b, c) ∈ R`，则 `(a, c) ∈ R`

##### 2. 等价关系（Equivalence Relation）
- **定义**：同时满足自反、对称、传递的关系。
- **等价类**：对于 `a ∈ A`，其等价类为 `[a] = {x | (a, x) ∈ R}`。
- **划分（Partition）**：等价关系将集合划分为互不相交的等价类。
  - **示例**：  
    - `A = {1, 2, 3}`，`R = {(1,1), (2,2), (3,3), (1,2), (2,1)}`，等价类为 `[1] = [2] = {1, 2}`，`[3] = {3}`。

##### 3. 偏序关系（Partial Order）
- **定义**：同时满足自反、反对称（若 `(a,b) ∈ R` 且 `(b,a) ∈ R`，则 `a = b`）、传递的关系。
- **哈斯图（Hasse Diagram）**：省略自反和传递边的简化表示。
  - **示例**：  
    ```text
    6
    | \
    3 2
    ```

##### 4. 函数作为特殊关系
- **函数（Function）**：满足单值性的关系（若 `(a, b) ∈ f` 且 `(a, c) ∈ f`，则 `b = c`）。
  - **单射（Injective）**：不同输入映射到不同输出。
  - **满射（Surjective）**：所有输出都被覆盖。
  - **双射（Bijective）**：既是单射又是满射。

#### 三、应用场景
1. **计算机科学**：
   - 数据库中的关系模型（如 SQL 表）。
   - 编程语言中的集合数据结构（如 Python `set`）。
2. **算法设计**：
   - 图论中的邻接关系（邻接矩阵/表）。
3. **逻辑与密码学**：
   - 等价关系用于数据分类（如哈希表冲突处理）。
   - 偏序关系用于任务调度依赖分析。

#### 四、典型例题
### 1. 证明等价关系
**题目**：设 `R` 是整数集上的关系，定义为 `aRb` 当且仅当 `a − b` 是偶数。证明 `R` 是等价关系。  
**解答**：  
- **自反性**：`a − a = 0` 是偶数。  
- **对称性**：若 `a − b` 是偶数，则 `b − a = -(a − b)` 也是偶数。  
- **传递性**：若 `a − b` 和 `b − c` 均为偶数，则 `a − c = (a − b) + (b − c)` 也是偶数。

##### 2. 构造哈斯图
**题目**：集合 `A = {1, 2, 3, 4, 6, 12}`，关系为“整除”。画出哈斯图。  
**解答**：
```text
    12
   / | \
  6  4 3
  |  | |
  2  1 1
  \    /
    1
```
