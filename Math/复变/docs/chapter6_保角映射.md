# 第六章 保角映射

## 6.1 保角映射的概念

### 6.1.1 定义

**保角映射**（共形映射）是指在映射过程中保持角度不变的解析函数映射。

**定义 6.1**：设 $f$ 在区域 $D$ 内解析，若 $f'(z) \neq 0$ 对所有 $z \in D$，则称 $f$ 在 $D$ 内是**保角映射**。

**等价定义**：若 $f$ 在 $z_0$ 处解析且 $f'(z_0) \neq 0$，则 $f$ 在 $z_0$ 处是保角的。

### 6.1.2 几何意义

保角映射具有以下几何性质：

1. **角度保持性**：两条光滑曲线在交点处的夹角经过映射后保持不变
2. **方向保持性**：映射保持曲线的定向
3. **局部相似性**：在充分小的邻域内，映射近似于相似变换

**定理 6.1**：若 $f$ 在 $z_0$ 处解析且 $f'(z_0) \neq 0$，则存在 $z_0$ 的邻域 $U$，使得：
- $f$ 在 $U$ 上是单叶的
- $f$ 在 $U$ 上是保角的
- $f(U)$ 是开集

<details>
<summary>证明</summary>

**证明**：由于 $f'(z_0) \neq 0$，根据解析函数的性质，$f$ 在 $z_0$ 的某个邻域内可以展开为幂级数：

$$f(z) = f(z_0) + f'(z_0)(z-z_0) + \frac{f''(z_0)}{2!}(z-z_0)^2 + \cdots$$

令 $w = f(z) - f(z_0)$，则：

$$w = f'(z_0)(z-z_0) + \frac{f''(z_0)}{2!}(z-z_0)^2 + \cdots$$

$$= (z-z_0)\left[f'(z_0) + \frac{f''(z_0)}{2!}(z-z_0) + \cdots\right]$$

由于 $f'(z_0) \neq 0$，当 $|z-z_0|$ 充分小时，括号内的表达式非零，因此 $w$ 与 $(z-z_0)$ 同阶。

构造映射 $g(w) = z$，则 $g$ 在 $w=0$ 处解析且 $g'(0) = \frac{1}{f'(z_0)} \neq 0$，故 $g$ 在 $w=0$ 的邻域内单叶解析。

因此 $f$ 在 $z_0$ 的充分小邻域内是单叶解析的，即为保角映射。

</details>

### 6.1.3 映射的局部性质

**局部线性化**：在 $z_0$ 附近，映射 $f$ 可以近似为：

$$f(z) \approx f(z_0) + f'(z_0)(z-z_0)$$

这表明局部上，映射是相似变换：
- 旋转角度：$\arg f'(z_0)$
- 伸缩比例：$|f'(z_0)|$

## 6.2 分式线性映射

### 6.2.1 定义

**分式线性映射**（莫比乌斯变换）是指形如：

![分式线性映射](imgs/lft-cross-ratio-formula-graphic.jpg)
*图6-1: 分式线性映射的交比公式*

$$w = f(z) = \frac{az+b}{cz+d}$$

其中 $a, b, c, d$ 为复常数，且 $ad-bc \neq 0$ 的映射。

**标准形式**：
- 当 $c \neq 0$ 时：$w = \frac{az+b}{cz+d}$
- 当 $c = 0$ 时：$w = \frac{a}{d}z + \frac{b}{d}$（线性映射）

### 6.2.2 基本性质

**性质 6.1**：分式线性映射是保角映射。

**证明**：$f'(z) = \frac{ad-bc}{(cz+d)^2}$，由于 $ad-bc \neq 0$，故 $f'(z) \neq 0$（除去极点 $z = -\frac{d}{c}$）。

**性质 6.2**：分式线性映射的逆映射也是分式线性映射。

若 $w = \frac{az+b}{cz+d}$，则逆映射为：
$$z = \frac{-dw+b}{cw-a}$$

**性质 6.3**：分式线性映射的复合仍是分式线性映射。

<details>
<summary>证明</summary>

设两个分式线性映射：
$$f_1(z) = \frac{a_1z+b_1}{c_1z+d_1}, \quad f_2(z) = \frac{a_2z+b_2}{c_2z+d_2}$$

则复合映射：
$$f_2(f_1(z)) = \frac{a_2\frac{a_1z+b_1}{c_1z+d_1}+b_2}{c_2\frac{a_1z+b_1}{c_1z+d_1}+d_2}$$

$$= \frac{a_2(a_1z+b_1)+b_2(c_1z+d_1)}{c_2(a_1z+b_1)+d_2(c_1z+d_1)}$$

$$= \frac{(a_2a_1+b_2c_1)z+(a_2b_1+b_2d_1)}{(c_2a_1+d_2c_1)z+(c_2b_1+d_2d_1)}$$

仍是分式线性映射。

</details>

### 6.2.3 不动点

**定义 6.2**：若 $f(z_0) = z_0$，则称 $z_0$ 为映射 $f$ 的**不动点**。

对于分式线性映射 $w = \frac{az+b}{cz+d}$，不动点满足：

$$\frac{az_0+b}{cz_0+d} = z_0$$

即：$az_0 + b = z_0(cz_0 + d)$

整理得：$cz_0^2 + (d-a)z_0 - b = 0$

**定理 6.2**：分式线性映射最多有两个不动点。

<details>
<summary>证明</summary>

从上述方程 $cz_0^2 + (d-a)z_0 - b = 0$ 可以看出，这是一个关于 $z_0$ 的二次方程，最多有两个根（考虑重根情况）。

特殊情况：
- 当 $c = 0$ 时，方程变为 $(d-a)z_0 - b = 0$，只有一个不动点（线性映射）
- 当 $c \neq 0$ 时，最多有两个不动点

</details>

### 6.2.4 保圆性

**定理 6.3**：分式线性映射将圆周映射为圆周或直线。

**证明**：圆的一般方程为：
$$Az\bar{z} + \bar{B}z + B\bar{z} + C = 0$$

其中 $A, C$ 为实数，$B$ 为复数。

将 $z = \frac{dw-b}{-cw+a}$ 代入，整理后可证明映射后仍是圆或直线。

**推论 6.1**：分式线性映射将圆内部映射为圆内部或外部。

### 6.2.5 特殊分式线性映射

#### 6.2.5.1 平移映射
$$w = z + b$$

#### 6.2.5.2 旋转映射
$$w = e^{i\theta}z$$

#### 6.2.5.3 伸缩映射
$$w = kz \quad (k > 0)$$

#### 6.2.5.4 反演映射
$$w = \frac{1}{z}$$

### 6.2.6 映射类型与性质对照表

| 映射类型 | 标准形式 | 不动点 | 保圆性 | 特殊性质 |
|---------|---------|--------|--------|----------|
| 平移 | $w = z + b$ | 无 | 保持 | 纯平移 |
| 旋转 | $w = e^{i\theta}z$ | $z = 0$ | 保持 | 保持模长 |
| 伸缩 | $w = kz$ | $z = 0$ | 保持 | 改变模长 |
| 反演 | $w = \frac{1}{z}$ | $z = \pm 1$ | 保持 | 单位圆内外互换 |
| 一般分式线性 | $w = \frac{az+b}{cz+d}$ | 最多2个 | 保持 | 最一般的保角映射 |

## 6.3 幂函数与指数函数映射

### 6.3.1 幂函数映射

#### 6.3.1.1 基本形式
$$w = z^n \quad (n \in \mathbb{N}, n \geq 2)$$

**导数**：$f'(z) = nz^{n-1}$

**奇点**：$z = 0$（当 $n \geq 2$ 时，$f'(0) = 0$）

#### 6.3.1.2 映射性质

**定理 6.4**：$w = z^n$ 在 $z \neq 0$ 处是保角映射。

**证明**：当 $z \neq 0$ 时，$f'(z) = nz^{n-1} \neq 0$，故映射保角。

**角度性质**：
- 幅角放大 $n$ 倍：$\arg(w) = n\arg(z)$
- 模长幂次变换：$|w| = |z|^n$

**区域映射**：
- 角形区域：$0 < \arg(z) < \frac{2\pi}{n}$ 映射为上半平面
- 单位圆：$|z| = 1$ 映射为单位圆 $|w| = 1$
- 单位圆内部：$|z| < 1$ 映射为 $|w| < 1$

#### 6.3.1.3 应用实例

**例 6.1**：将角形区域 $D = \{z : 0 < \arg z < \frac{\pi}{4}\}$ 映射为上半平面。

**解**：取 $w = z^4$，则：
- $\arg w = 4\arg z$
- 当 $0 < \arg z < \frac{\pi}{4}$ 时，$0 < \arg w < \pi$
- 故 $w$ 的虚部大于0，即在上半平面

### 6.3.2 指数函数映射

#### 6.3.2.1 基本形式
$$w = e^z$$

**导数**：$f'(z) = e^z \neq 0$（处处非零）

**映射性质**：指数函数在复平面上处处保角。

#### 6.3.2.2 映射特性

**周期性质**：$e^{z+2\pi i} = e^z$

**水平带映射**：
- 水平带 $0 < \Im(z) < 2\pi$ 映射为复平面去掉负实轴
- 水平带 $0 < \Im(z) < \pi$ 映射为上半平面

**幅角性质**：
- $\arg w = \Im(z)$
- $\ln|w| = \Re(z)$

#### 6.3.2.3 应用实例

**例 6.2**：将带形区域 $D = \{z : 0 < \Im(z) < \pi\}$ 映射为上半平面。

**解**：直接取 $w = e^z$，则：
- $\Im(w) = e^{\Re(z)}\sin(\Im(z)) > 0$（因为 $0 < \Im(z) < \pi$）
- 故 $w$ 在上半平面

### 6.3.3 对数函数映射

#### 6.3.3.1 基本形式
$$w = \log z = \ln|z| + i\arg z$$

**多值性**：对数函数是多值函数，通常取主值分支：
$$\log z = \ln|z| + i\arg z \quad (-\pi < \arg z \leq \pi)$$

#### 6.3.3.2 映射性质

**分支切割**：通常在负实轴处切割。

**逆映射性质**：$\exp(\log z) = z$

**区域映射**：
- 上半平面映射为带形区域 $0 < \Im(w) < \pi$
- 单位圆内部映射为左半平面 $\Re(w) < 0$

## 6.4 多角形映射（施瓦茨-克里斯托费尔映射）

### 6.4.1 施瓦茨-克里斯托费尔映射

**定理 6.5**：存在唯一的分式线性映射将上半平面映射到给定的多角形区域。

**施瓦茨-克里斯托费尔公式**：

设多角形 $P$ 的顶点为 $a_1, a_2, \ldots, a_n$（按逆时针顺序），对应的内角为 $\alpha_1\pi, \alpha_2\pi, \ldots, \alpha_n\pi$，则映射为：

$$f(z) = C\int_{z_0}^z \prod_{k=1}^n (\zeta-a_k)^{\alpha_k-1} d\zeta + D$$

其中 $C, D$ 为常数，$z_0$ 为起点。

**参数条件**：$\sum_{k=1}^n \alpha_k = n-2$

<details>
<summary>证明思路</summary>

证明基于以下观察：
1. 映射在实轴上的每个点 $a_k$ 附近，映射的导数 $f'(z)$ 有 $(\zeta-a_k)^{\alpha_k-1}$ 形式的奇点
2. 这保证了映射在 $a_k$ 处的角度变化为 $\alpha_k\pi$
3. 分式线性映射可以将任意三个点映射到指定位置
4. 积分常数 $C, D$ 用于调整位置和缩放

详细的证明需要分析映射的局部行为和整体性质。

</details>

### 6.4.2 常见多角形映射

#### 6.4.2.1 三角形映射

**等边三角形**：顶点 $a_1 = 0, a_2 = 1, a_3 = \infty$，内角均为 $\frac{\pi}{3}$

映射公式：
$$f(z) = C\int_0^z \zeta^{-\frac{2}{3}}(1-\zeta)^{-\frac{2}{3}} d\zeta + D$$

#### 6.4.2.2 矩形映射

**矩形**：顶点 $a_1 = -1, a_2 = 1, a_3 = \infty$，内角均为 $\frac{\pi}{2}$

映射公式：
$$f(z) = C\int_{-1}^z \frac{d\zeta}{\sqrt{(1-\zeta^2)}} + D = C\arcsin z + D$$

#### 6.4.2.3 半平面到多角形的映射

**一般步骤**：
1. 选择实轴上的三个点映射到多角形的三个顶点
2. 使用分式线性映射完成这个步骤
3. 应用施瓦茨-克里斯托费尔公式处理剩余顶点

### 6.4.3 映射的构造方法

**步骤 1**：确定多角形的内角 $\alpha_1\pi, \alpha_2\pi, \ldots, \alpha_n\pi$

**步骤 2**：选择实轴上的点 $x_1 < x_2 < \ldots < x_n$ 作为原像

**步骤 3**：构造映射：
$$f(z) = A\int_{x_1}^z \prod_{k=1}^n (t-x_k)^{\alpha_k-1} dt + B$$

**步骤 4**：确定常数 $A, B$ 使得映射满足边界条件

### 6.4.4 应用实例

**例 6.3**：构造将上半平面映射到等腰直角三角形的映射。

**解**：
1. 等腰直角三角形内角：$\frac{\pi}{2}, \frac{\pi}{4}, \frac{\pi}{4}$
2. 选择实轴上的点：$x_1 = 0, x_2 = 1, x_3 = \infty$
3. 映射公式：
$$f(z) = A\int_0^z t^{-\frac{1}{2}}(1-t)^{-\frac{3}{4}} dt + B$$

## 6.5 映射的应用

### 6.5.1 拉普拉斯方程的边值问题

**狄利克雷问题**：在区域 $D$ 内求调和函数 $u$，使得：
$$\begin{cases}
\Delta u = 0 & \text{在 } D \text{ 内} \\
u = f & \text{在 } \partial D \text{ 上}
\end{cases}$$

**解法**：
1. 构造保角映射 $\phi: D \to \mathbb{H}$（上半平面）
2. 复合映射 $u(z) = v(\phi(z))$，其中 $v$ 在 $\mathbb{H}$ 内调和
3. 利用泊松公式求解 $v$

### 6.5.2 流体力学应用

**复势**：若 $f(z) = \phi(x,y) + i\psi(x,y)$，其中 $\phi$ 为速度势，$\psi$ 为流函数。

**保角映射的应用**：
- 复杂边界问题转化为简单边界问题
- 保角映射保持流线的角度关系

### 6.5.3 电磁场应用

**共形映射在电磁场中的应用**：
- 静电场的边界值问题
- 传输线的特性分析
- 天线辐射模式的计算

## 6.6 小结

### 6.6.1 重要定理总结

| 定理 | 内容 | 条件 |
|------|------|------|
| 保角映射基本定理 | 解析函数在导数非零点处保角 | $f'(z_0) \neq 0$ |
| 分式线性映射保圆性 | 将圆映射为圆或直线 | 分式线性映射 |
| 施瓦茨-克里斯托费尔映射 | 上半平面到多角形的映射 | 多角形内角和为 $(n-2)\pi$ |

### 6.6.2 映射类型比较

| 映射类型 | 定义域 | 值域 | 保角性 | 特殊性质 |
|---------|--------|------|--------|----------|
| 分式线性 | $\mathbb{C}$（除去极点） | $\mathbb{C}$（除去像点） | 处处保角 | 保圆性，复合封闭 |
| 幂函数 $z^n$ | $\mathbb{C}$ | $\mathbb{C}$ | $z \neq 0$ 处保角 | 角度放大 $n$ 倍 |
| 指数函数 $e^z$ | $\mathbb{C}$ | $\mathbb{C}\setminus\{0\}$ | 处处保角 | 周期函数 |
| 对数函数 $\log z$ | $\mathbb{C}\setminus(-\infty,0]$ | 带状区域 | 分支内保角 | 多值函数 |

### 6.6.3 实际应用要点

1. **选择合适的映射**：根据边界形状和求解目标选择映射类型
2. **处理分支切割**：对于多值函数，需要仔细选择分支
3. **数值计算**：复杂映射需要数值方法求解
4. **边界对应**：确保映射正确建立边界对应关系

保角映射作为复分析的重要工具，在理论数学和工程应用中都有重要价值。通过掌握不同类型映射的性质和应用，可以有效地解决复杂的数学和物理问题。
