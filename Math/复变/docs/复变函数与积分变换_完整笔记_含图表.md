## 1. 复数与复平面

### 1.1 复数的定义与表示

#### 1.1.1 代数形式
复数 $z$ 可以表示为：
$$z = x + iy$$

其中：
- $x = \operatorname{Re}(z)$ 为实部
- $y = \operatorname{Im}(z)$ 为虚部
- $i = \sqrt{-1}$ 为虚数单位

#### 1.1.2 共轭复数
复数 $z = x + iy$ 的共轭复数为：
$$\bar{z} = x - iy$$

**重要性质：**
- $z \cdot \bar{z} = |z|^2 = x^2 + y^2$
- $\overline{z_1 + z_2} = \bar{z_1} + \bar{z_2}$
- $\overline{z_1 \cdot z_2} = \bar{z_1} \cdot \bar{z_2}$

### 1.2 复数的四则运算

设 $z_1 = x_1 + iy_1$，$z_2 = x_2 + iy_2$

#### 1.2.1 加法运算
$$z_1 + z_2 = (x_1 + x_2) + i(y_1 + y_2)$$

#### 1.2.2 乘法运算
$$z_1 \cdot z_2 = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1)$$

#### 1.2.3 除法运算
$$\frac{z_1}{z_2} = \frac{z_1 \cdot \bar{z_2}}{|z_2|^2} = \frac{(x_1 + iy_1)(x_2 - iy_2)}{x_2^2 + y_2^2}$$

### 1.3 复数的三角形式与指数形式

#### 1.3.1 三角形式
$$z = r(\cos\theta + i\sin\theta)$$

![复数的三角形式](imgs/complex-number-polar-trigonometric-representation-diagram.jpg)
*图1-2: 复数的三角形式和极坐标表示*

其中：
- $r = |z| = \sqrt{x^2 + y^2}$ 为模
- $\theta = \arg(z)$ 为辐角，满足 $\cos\theta = \frac{x}{r}$，$\sin\theta = \frac{y}{r}$

#### 1.3.2 指数形式（欧拉公式）
$$z = re^{i\theta}$$

其中 $e^{i\theta} = \cos\theta + i\sin\theta$

**重要关系：**
- $x = r\cos\theta$
- $y = r\sin\theta$
- $\theta = \arctan\left(\frac{y}{x}\right)$（注意象限）

#### 1.3.3 模与辐角的重要性质

| 性质 | 公式 | 说明 |
|------|------|------|
| 模的乘积 | $\|z_1 z_2\| = \|z_1\| \cdot \|z_2\|$ | 模的乘积等于乘积的模 |
| 模的商 | $\left\|\frac{z_1}{z_2}\right\| = \frac{\|z_1\|}{\|z_2\|}$ | 模的商等于商的模 |
| 辐角的和 | $\arg(z_1 z_2) = \arg(z_1) + \arg(z_2)$ | 辐角的可加性 |
| 辐角的差 | $\arg\left(\frac{z_1}{z_2}\right) = \arg(z_1) - \arg(z_2)$ | 辐角的可减性 |

### 1.4 复平面

复数 $z = x + iy$ 可以用平面上的点 $(x, y)$ 表示，其中：
- 横坐标表示实部 $x$
- 纵坐标表示虚部 $y$

![复平面图示](imgs/complex-plane-argand-diagram-illustration.jpg)
*图1-1: 复平面（Argand图）示意图*

**重要概念：**
- 原点：$z = 0$
- 实轴：$\operatorname{Im}(z) = 0$
- 虚轴：$\operatorname{Re}(z) = 0$

**几何意义：**
- 复数可以用从原点到该点的向量表示
- 向量的长度表示复数的模 $|z| = \sqrt{x^2 + y^2}$
- 向量与正实轴的夹角表示复数的辐角 $\arg(z)$

## 2. 复变函数概念

### 2.1 复变函数的定义

设 $D$ 是复平面上的一个区域，$f$ 是定义在 $D$ 上的函数，如果对每个 $z \in D$，都有唯一确定的复数 $w$ 与之对应，则称 $f$ 是定义在 $D$ 上的**复变函数**，记作：
$$w = f(z)$$

其中 $z \in D$，$w \in \mathbb{C}$。

### 2.2 复变函数的表示方法

#### 2.2.1 代数表示
设 $f(z) = u(x, y) + iv(x, y)$，其中：
- $u(x, y) = \operatorname{Re}[f(z)]$ 为实部函数
- $v(x, y) = \operatorname{Im}[f(z)]$ 为虚部函数

#### 2.2.2 极坐标表示
设 $z = re^{i\theta}$，则：
$$f(z) = f(re^{i\theta}) = \rho(r, \theta)e^{i\phi(r, \theta)}$$

其中 $\rho = |f(z)|$ 为模函数，$\phi = \arg[f(z)]$ 为辐角函数。

### 2.3 复变函数的几何意义

复变函数 $w = f(z)$ 可以看作是从 $z$ 平面到 $w$ 平面的映射：

![复变函数映射](imgs/complex-exponential-function-mapping-z-plane-to-w-plane.jpg)
*图2-1: 复指数函数 $w = e^z$ 的映射示例*

1. **点映射**：$z$ 平面上的点 $z_0$ 映射到 $w$ 平面上的点 $w_0 = f(z_0)$
2. **曲线映射**：$z$ 平面上的曲线映射到 $w$ 平面上的曲线
3. **区域映射**：$z$ 平面上的区域映射到 $w$ 平面上的区域

**映射的几何性质：**
- **伸缩变换**：映射的导数 $f'(z)$ 的模 $|f'(z)|$ 表示局部伸缩比
- **旋转变换**：映射的导数 $f'(z)$ 的辐角 $\arg[f'(z)]$ 表示局部旋转角
- **保角性**：解析函数在其定义域内具有保角性质（保持角度不变）

### 2.4 常用的基本复变函数

#### 2.4.1 幂函数
$$f(z) = z^n, \quad n \in \mathbb{N}$$

#### 2.4.2 指数函数
$$f(z) = e^z = e^{x+iy} = e^x(\cos y + i\sin y)$$

**重要性质：**
- $|e^z| = e^x$
- $\arg(e^z) = y + 2k\pi, \quad k \in \mathbb{Z}$

#### 2.4.3 对数函数
$$f(z) = \operatorname{Log} z = \ln|z| + i\arg(z)$$

其中 $\arg(z)$ 是多值函数，通常取主值 $\arg(z) \in (-\pi, \pi]$。

#### 2.4.4 三角函数
$$\sin z = \frac{e^{iz} - e^{-iz}}{2i}, \quad \cos z = \frac{e^{iz} + e^{-iz}}{2}$$

## 3. 极限与连续性

### 3.1 复变函数的极限

#### 3.1.1 极限的定义
设 $f(z)$ 在 $z_0$ 的去心邻域内有定义，如果存在复数 $A$，使得对任意 $\epsilon > 0$，总存在 $\delta > 0$，当 $0 < |z - z_0| < \delta$ 时，都有 $|f(z) - A| < \epsilon$，则称 $A$ 为 $f(z)$ 在 $z_0$ 处的极限，记作：
$$\lim_{z \to z_0} f(z) = A$$

#### 3.1.2 极限的四则运算
如果 $\lim_{z \to z_0} f(z) = A$，$\lim_{z \to z_0} g(z) = B$，则：
- $\lim_{z \to z_0} [f(z) \pm g(z)] = A \pm B$
- $\lim_{z \to z_0} [f(z) \cdot g(z)] = A \cdot B$
- $\lim_{z \to z_0} \frac{f(z)}{g(z)} = \frac{A}{B} \quad (B \neq 0)$

#### 3.1.3 极限存在的充要条件
$\lim_{z \to z_0} f(z) = A$ 当且仅当：
$$\lim_{z \to z_0} u(x, y) = \operatorname{Re}(A), \quad \lim_{z \to z_0} v(x, y) = \operatorname{Im}(A)$$

其中 $f(z) = u(x, y) + iv(x, y)$，$A = \operatorname{Re}(A) + i\operatorname{Im}(A)$。

<details>
<summary><strong>证明：</strong>极限存在的充要条件</summary>

**必要性**：若 $\lim_{z \to z_0} f(z) = A$，则对任意 $\epsilon > 0$，存在 $\delta > 0$，当 $0 < |z - z_0| < \delta$ 时，有 $|f(z) - A| < \epsilon$。

由于 $|u(x, y) - \operatorname{Re}(A)| \leq |f(z) - A|$ 和 $|v(x, y) - \operatorname{Im}(A)| \leq |f(z) - A|$，可得：
$$|u(x, y) - \operatorname{Re}(A)| < \epsilon, \quad |v(x, y) - \operatorname{Im}(A)| < \epsilon$$

因此 $\lim_{z \to z_0} u(x, y) = \operatorname{Re}(A)$，$\lim_{z \to z_0} v(x, y) = \operatorname{Im}(A)$。

**充分性**：若 $\lim_{z \to z_0} u(x, y) = \operatorname{Re}(A)$，$\lim_{z \to z_0} v(x, y) = \operatorname{Im}(A)$，则对任意 $\epsilon > 0$，存在 $\delta_1, \delta_2 > 0$，使得：
- 当 $0 < |z - z_0| < \delta_1$ 时，$|u(x, y) - \operatorname{Re}(A)| < \frac{\epsilon}{2}$
- 当 $0 < |z - z_0| < \delta_2$ 时，$|v(x, y) - \operatorname{Im}(A)| < \frac{\epsilon}{2}$

取 $\delta = \min(\delta_1, \delta_2)$，则当 $0 < |z - z_0| < \delta$ 时：
$$|f(z) - A| = \sqrt{[u(x, y) - \operatorname{Re}(A)]^2 + [v(x, y) - \operatorname{Im}(A)]^2} < \sqrt{\left(\frac{\epsilon}{2}\right)^2 + \left(\frac{\epsilon}{2}\right)^2} = \frac{\epsilon}{\sqrt{2}} < \epsilon$$

故 $\lim_{z \to z_0} f(z) = A$。
</details>

### 3.2 复变函数的连续性

#### 3.2.1 连续的定义
设 $f(z)$ 在 $z_0$ 的邻域内有定义，如果：
$$\lim_{z \to z_0} f(z) = f(z_0)$$

则称 $f(z)$ 在 $z_0$ 处连续。

#### 3.2.2 连续函数的性质
1. **局部有界性**：连续函数在每点附近有界
2. **四则运算**：连续函数的和、差、积、商（分母不为零）仍连续
3. **复合函数**：连续函数的复合函数仍连续

#### 3.2.3 连续性的判别方法
$f(z) = u(x, y) + iv(x, y)$ 在 $z_0 = x_0 + iy_0$ 处连续当且仅当 $u(x, y)$ 和 $v(x, y)$ 在 $(x_0, y_0)$ 处连续。

### 3.3 一致连续性

#### 3.3.1 一致连续的定义
设 $f(z)$ 在区域 $D$ 内有定义，如果对任意 $\epsilon > 0$，存在 $\delta > 0$，使得对任意 $z_1, z_2 \in D$，当 $|z_1 - z_2| < \delta$ 时，都有 $|f(z_1) - f(z_2)| < \epsilon$，则称 $f(z)$ 在 $D$ 内一致连续。

#### 3.3.2 重要定理
**海涅-博雷尔定理**：有界闭区域上的连续函数必一致连续。

## 4. 导数与微分

### 4.1 复变函数导数的定义

#### 4.1.1 导数的定义
设 $f(z)$ 在 $z_0$ 的邻域内有定义，如果极限：
$$\lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

存在且有限，则称 $f(z)$ 在 $z_0$ 处可导，该极限称为 $f(z)$ 在 $z_0$ 处的导数，记作：
$$f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

#### 4.1.2 微分的定义
如果 $f(z)$ 在 $z_0$ 处可导，则称：
$$df(z_0) = f'(z_0) dz$$

为 $f(z)$ 在 $z_0$ 处的微分，其中 $dz = \Delta z$。

### 4.2 导数的几何意义

复变函数 $w = f(z)$ 的导数 $f'(z_0)$ 具有明确的几何意义：

1. **模的意义**：$|f'(z_0)|$ 表示映射在 $z_0$ 处的伸缩比
2. **辐角的意义**：$\arg[f'(z_0)]$ 表示映射在 $z_0$ 处的旋转角

<details>
<summary><strong>推导：</strong>导数的几何意义</summary>

设 $z = z_0 + \Delta z$，$w = f(z) = f(z_0 + \Delta z)$，则：
$$\Delta w = f(z_0 + \Delta z) - f(z_0) = f'(z_0)\Delta z + o(\Delta z)$$

当 $\Delta z$ 充分小时，$o(\Delta z)$ 可以忽略，因此：
$$\Delta w \approx f'(z_0)\Delta z$$

设 $f'(z_0) = |f'(z_0)|e^{i\theta}$，$\Delta z = |\Delta z|e^{i\phi}$，则：
$$\Delta w \approx |f'(z_0)|e^{i\theta} \cdot |\Delta z|e^{i\phi} = |f'(z_0)||\Delta z|e^{i(\theta + \phi)}$$

这表明：
1. 长度伸缩比为 $|f'(z_0)|$
2. 角度旋转角为 $\theta = \arg[f'(z_0)]$
</details>

### 4.3 求导法则

#### 4.3.1 基本求导法则
| 法则 | 公式 |
|------|------|
| 常数法则 | $\frac{d}{dz}[C] = 0$ |
| 幂法则 | $\frac{d}{dz}[z^n] = nz^{n-1}$ |
| 指数法则 | $\frac{d}{dz}[e^z] = e^z$ |
| 对数法则 | $\frac{d}{dz}[\log z] = \frac{1}{z}$ |
| 三角法则 | $\frac{d}{dz}[\sin z] = \cos z$，$\frac{d}{dz}[\cos z] = -\sin z$ |

#### 4.3.2 运算法则
1. **线性法则**：$\frac{d}{dz}[af(z) + bg(z)] = af'(z) + bg'(z)$
2. **乘积法则**：$\frac{d}{dz}[f(z)g(z)] = f'(z)g(z) + f(z)g'(z)$
3. **商法则**：$\frac{d}{dz}\left[\frac{f(z)}{g(z)}\right] = \frac{f'(z)g(z) - f(z)g'(z)}{g^2(z)}$
4. **链式法则**：$\frac{d}{dz}[f(g(z))] = f'(g(z)) \cdot g'(z)$

### 4.4 解析函数

#### 4.4.1 解析的定义
如果 $f(z)$ 在 $z_0$ 的邻域内可导，则称 $f(z)$ 在 $z_0$ 处解析。

如果 $f(z)$ 在区域 $D$ 内的每点都解析，则称 $f(z)$ 在 $D$ 内解析。

#### 4.4.2 解析函数的性质
1. **无限可微性**：解析函数具有任意阶导数
2. **幂级数展开**：解析函数可以展开为泰勒级数
3. **平均值性质**：解析函数在圆周上的平均值等于圆心的函数值

## 5. 柯西-黎曼方程

### 5.1 柯西-黎曼方程的推导

设 $f(z) = u(x, y) + iv(x, y)$ 在 $z_0 = x_0 + iy_0$ 处可导，则：
$$f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

令 $\Delta z = \Delta x + i\Delta y$，则：
$$\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} = \frac{[u(x_0+\Delta x, y_0+\Delta y) + iv(x_0+\Delta x, y_0+\Delta y)] - [u(x_0, y_0) + iv(x_0, y_0)]}{\Delta x + i\Delta y}$$

<details>
<summary><strong>推导过程：</strong>柯西-黎曼方程</summary>

分别沿实轴和虚轴取极限：

**沿实轴取极限**（$\Delta y = 0$，$\Delta x \to 0$）：
$$f'(z_0) = \lim_{\Delta x \to 0} \frac{u(x_0+\Delta x, y_0) - u(x_0, y_0) + i[v(x_0+\Delta x, y_0) - v(x_0, y_0)]}{\Delta x}$$
$$= \frac{\partial u}{\partial x}\bigg|_{(x_0,y_0)} + i\frac{\partial v}{\partial x}\bigg|_{(x_0,y_0)}$$

**沿虚轴取极限**（$\Delta x = 0$，$\Delta y \to 0$）：
$$f'(z_0) = \lim_{\Delta y \to 0} \frac{u(x_0, y_0+\Delta y) - u(x_0, y_0) + i[v(x_0, y_0+\Delta y) - v(x_0, y_0)]}{i\Delta y}$$
$$= \frac{1}{i}\left[\frac{\partial u}{\partial y}\bigg|_{(x_0,y_0)} + i\frac{\partial v}{\partial y}\bigg|_{(x_0,y_0)}\right]$$
$$= -i\frac{\partial u}{\partial y}\bigg|_{(x_0,y_0)} + \frac{\partial v}{\partial y}\bigg|_{(x_0,y_0)}$$

由于两个极限都等于 $f'(z_0)$，因此实部和虚部分别相等：

实部：$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$
虚部：$\frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$

即得到柯西-黎曼方程。
</details>

### 5.2 柯西-黎曼方程

**柯西-黎曼方程**（C-R方程）：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial v}{\partial x} = -\frac{\partial u}{\partial y}$$

或者写成：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

### 5.3 柯西-黎曼方程的充分必要条件

#### 5.3.1 必要条件
如果 $f(z) = u(x, y) + iv(x, y)$ 在 $z_0$ 处可导，则在 $z_0$ 处必有：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

#### 5.3.2 充分条件
如果 $u(x, y)$ 和 $v(x, y)$ 在 $z_0$ 的邻域内：
1. 连续可微（即偏导数存在且连续）
2. 满足柯西-黎曼方程

则 $f(z)$ 在 $z_0$ 处可导，且：
$$f'(z_0) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y}$$

<details>
<summary><strong>证明：</strong>充分条件</summary>

由于 $u$ 和 $v$ 连续可微，利用全微分公式：
$$du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy$$
$$dv = \frac{\partial v}{\partial x}dx + \frac{\partial v}{\partial y}dy$$

由柯西-黎曼方程：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

因此：
$$df = du + idv = \left(\frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy\right) + i\left(\frac{\partial v}{\partial x}dx + \frac{\partial v}{\partial y}dy\right)$$
$$= \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy + i\frac{\partial v}{\partial x}dx + i\frac{\partial u}{\partial x}dy$$
$$= \frac{\partial u}{\partial x}(dx + idy) + i\frac{\partial v}{\partial x}(dx + idy)$$
$$= \left(\frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x}\right)(dx + idy)$$

这表明 $df = f'(z)dz$，其中 $f'(z) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x}$，故 $f(z)$ 在 $z_0$ 处可导。
</details>

### 5.4 柯西-黎曼方程的几何意义

柯西-黎曼方程反映了复变函数映射的保角性质：

1. **正交性**：等值曲线 $u(x, y) = c_1$ 和 $v(x, y) = c_2$ 在交点处正交
2. **保角性**：映射保持两条曲线的夹角大小和方向

**证明**：等值曲线 $u(x, y) = c_1$ 的法向量为 $\nabla u = \left(\frac{\partial u}{\partial x}, \frac{\partial u}{\partial y}\right)$，等值曲线 $v(x, y) = c_2$ 的法向量为 $\nabla v = \left(\frac{\partial v}{\partial x}, \frac{\partial v}{\partial y}\right)$。

由柯西-黎曼方程：
$$\nabla u \cdot \nabla v = \frac{\partial u}{\partial x}\frac{\partial v}{\partial x} + \frac{\partial u}{\partial y}\frac{\partial v}{\partial y}$$
$$= \frac{\partial u}{\partial x}\left(-\frac{\partial u}{\partial y}\right) + \frac{\partial u}{\partial y}\frac{\partial u}{\partial x} = 0$$

因此两法向量正交，即两等值曲线正交。

### 5.5 调和函数

#### 5.5.1 调和函数的定义
如果函数 $\phi(x, y)$ 在区域 $D$ 内具有连续的二阶偏导数，且满足拉普拉斯方程：
$$\frac{\partial^2 \phi}{\partial x^2} + \frac{\partial^2 \phi}{\partial y^2} = 0$$

则称 $\phi(x, y)$ 为调和函数。

#### 5.5.2 解析函数与调和函数的关系
如果 $f(z) = u(x, y) + iv(x, y)$ 在区域 $D$ 内解析，则：
1. $u(x, y)$ 和 $v(x, y)$ 都是调和函数
2. $u(x, y)$ 和 $v(x, y)$ 互为共轭调和函数

**证明**：由柯西-黎曼方程：
$$\frac{\partial^2 u}{\partial x^2} = \frac{\partial}{\partial x}\left(\frac{\partial v}{\partial y}\right) = \frac{\partial^2 v}{\partial x\partial y}$$
$$\frac{\partial^2 u}{\partial y^2} = \frac{\partial}{\partial y}\left(-\frac{\partial v}{\partial x}\right) = -\frac{\partial^2 v}{\partial y\partial x}$$

由混合偏导数的连续性（施瓦茨定理），$\frac{\partial^2 v}{\partial x\partial y} = \frac{\partial^2 v}{\partial y\partial x}$，因此：
$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = \frac{\partial^2 v}{\partial x\partial y} - \frac{\partial^2 v}{\partial y\partial x} = 0$$

同理可证 $v(x, y)$ 也是调和函数。

## 典型例题

### 例题1：复数运算
**题目**：计算 $(1 + i)^4$

**解答**：
$$1 + i = \sqrt{2}e^{i\pi/4}$$
$$(1 + i)^4 = (\sqrt{2})^4 e^{i\pi} = 4(\cos\pi + i\sin\pi) = 4(-1 + 0i) = -4$$

### 例题2：极限计算
**题目**：计算 $\lim_{z \to i} \frac{z^2 + 1}{z - i}$

**解答**：
$$z^2 + 1 = (z - i)(z + i)$$
$$\lim_{z \to i} \frac{z^2 + 1}{z - i} = \lim_{z \to i} (z + i) = i + i = 2i$$

### 例题3：柯西-黎曼方程
**题目**：验证 $f(z) = z^2$ 满足柯西-黎曼方程

**解答**：
$$f(z) = z^2 = (x + iy)^2 = x^2 - y^2 + 2ixy$$
$$u(x, y) = x^2 - y^2, \quad v(x, y) = 2xy$$

$$\frac{\partial u}{\partial x} = 2x, \quad \frac{\partial v}{\partial y} = 2x$$
$$\frac{\partial u}{\partial y} = -2y, \quad \frac{\partial v}{\partial x} = 2y$$

满足 $\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}$ 和 $\frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$，故满足柯西-黎曼方程。

## 2.1 解析函数的定义与性质

### 2.1.1 解析函数的定义

**定义2.1（可导）**  
设函数 $f(z)$ 在点 $z_0$ 的某个邻域内有定义，如果极限
$$\lim_{z \to z_0} \frac{f(z) - f(z_0)}{z - z_0}$$
存在且有限，则称 $f(z)$ 在点 $z_0$ **可导**。这个极限值称为 $f(z)$ 在 $z_0$ 处的**导数**，记作 $f'(z_0)$。

**定义2.2（解析函数）**  
如果函数 $f(z)$ 在点 $z_0$ 的某个邻域内的每一点都可导，则称 $f(z)$ 在点 $z_0$ **解析**。如果 $f(z)$ 在区域 $D$ 内的每一点都解析，则称 $f(z)$ 在区域 $D$ 内**解析**，或称 $f(z)$ 是 $D$ 内的**解析函数**。

**重要概念：**
- **解析点**：使函数解析的点
- **奇点**：函数不解析的点
- **解析域**：函数在其上解析的区域

### 2.1.2 解析函数的基本性质

**性质2.1（解析函数的代数运算）**  
如果 $f(z)$ 和 $g(z)$ 都在区域 $D$ 内解析，则：
- $f(z) + g(z)$ 在 $D$ 内解析
- $f(z) \cdot g(z)$ 在 $D$ 内解析  
- $\frac{f(z)}{g(z)}$ 在 $D$ 内解析（$g(z) \neq 0$）
- $f(g(z))$ 在相应区域内解析（复合函数）

**性质2.2（解析函数的导数）**  
如果 $f(z)$ 在区域 $D$ 内解析，则 $f'(z)$ 也在 $D$ 内解析。

**性质2.3（解析函数的幂级数展开）**  
如果 $f(z)$ 在圆盘 $|z - z_0| < R$ 内解析，则 $f(z)$ 可以展开为幂级数：
$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!}(z - z_0)^n$$

## 2.2 解析函数的判定

### 2.2.1 柯西-黎曼条件

**定理2.1（柯西-黎曼条件）**  
设 $f(z) = u(x, y) + iv(x, y)$ 在区域 $D$ 内有定义，则 $f(z)$ 在 $D$ 内解析的充分必要条件是：
1. $u(x, y)$ 和 $v(x, y)$ 在 $D$ 内可微
2. 满足**柯西-黎曼方程**：
   $$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

<details>
<parameter name="summary">柯西-黎曼条件的详细推导
$$f'(z_0) = \lim_{\Delta z \to 0} \frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z}$$

令 $\Delta z = \Delta x + i\Delta y$，则：
$$\frac{f(z_0 + \Delta z) - f(z_0)}{\Delta z} = \frac{[u(x_0+\Delta x, y_0+\Delta y) - u(x_0, y_0)] + i[v(x_0+\Delta x, y_0+\Delta y) - v(x_0, y_0)]}{\Delta x + i\Delta y}$$

当 $\Delta z$ 沿实轴方向趋近于0时（$\Delta y = 0$）：
$$f'(z_0) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x}$$

当 $\Delta z$ 沿虚轴方向趋近于0时（$\Delta x = 0$）：
$$f'(z_0) = -i\frac{\partial u}{\partial y} + \frac{\partial v}{\partial y}$$

令两个表达式相等，得到柯西-黎曼方程：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

反过来，如果柯西-黎曼方程成立且偏导数连续，则 $f(z)$ 可导，且：
$$f'(z) = \frac{\partial u}{\partial x} + i\frac{\partial v}{\partial x} = \frac{\partial v}{\partial y} - i\frac{\partial u}{\partial y}$$
**证明：**  
设 $|f(z)| \leq M$ 对所有 $z \in \mathbb{C}$ 成立。由柯西积分公式：
$$f'(z) = \frac{1}{2\pi i} \int_C \frac{f(\zeta)}{(\zeta-z)^2}d\zeta$$

其中 $C$ 为以 $z$ 为中心、半径为 $R$ 的圆周。取模：
$$|f'(z)| \leq \frac{1}{2\pi} \int_C \frac{|f(\zeta)|}{|\zeta-z|^2}|d\zeta| \leq \frac{1}{2\pi} \cdot \frac{M}{R^2} \cdot 2\pi R = \frac{M}{R}$$

令 $R \to \infty$，得 $|f'(z)| \leq 0$，即 $f'(z) = 0$。故 $f(z)$ 为常数。

**定理2.4（平均值性质）**  
如果 $f(z)$ 在 $|z - z_0| < R$ 内解析，则：
$$f(z_0) = \frac{1}{2\pi} \int_0^{2\pi} f(z_0 + re^{i\theta})d\theta$$

其中 $0 < r < R$。

**定理2.5（最大值模原理）**  
如果 $f(z)$ 在区域 $D$ 内解析且不恒为零，则 $|f(z)|$ 在 $D$ 内不能取得最大值。

<details>
<parameter name="summary">最大值模原理的证明**证明：**  
假设 $|f(z)|$ 在 $z_0 \in D$ 取得最大值。由解析函数的平均值性质：
$$f(z_0) = \frac{1}{2\pi} \int_0^{2\pi} f(z_0 + re^{i\theta})d\theta$$

取模：
$$|f(z_0)| \leq \frac{1}{2\pi} \int_0^{2\pi} |f(z_0 + re^{i\theta})|d\theta$$

如果 $|f(z_0)|$ 是最大值，则等号成立，这意味着 $f(z_0 + re^{i\theta})$ 在圆周上的辐角必须相同，即 $f(z)$ 在该圆周上为常数。由解析延拓，$f(z)$ 在整个连通分量上为常数。

## 2.6 总结

本章主要介绍了复变函数中解析函数理论的核心内容：

### 2.6.1 核心概念

## 1. 复积分的定义与性质

### 1.1 复积分的定义

设函数 $f(z) = u(x,y) + iv(x,y)$ 在区域 $D$ 内有定义，$C$ 是 $D$ 内一条有向光滑曲线，参数方程为：
$$z(t) = x(t) + iy(t), \quad a \leq t \leq b$$

![复积分路径](imgs/contour-integration-path-complex-plane.jpg)
*图3-1: 复平面上的积分路径示意图*

**定义：** 复积分定义为
$$\int_C f(z)dz = \int_a^b f(z(t))z'(t)dt = \int_a^b [u(x(t),y(t)) + iv(x(t),y(t))][x'(t) + iy'(t)]dt$$

展开后得：
$$\int_C f(z)dz = \int_C (udx - vdy) + i\int_C (vdx + udy)$$

**几何意义：**
- 复积分是沿复平面上曲线的线积分
- $dz = dx + idy$ 表示复平面上的微分元素
- 积分结果是一个复数，包含实部和虚部

### 1.2 复积分的计算方法

| 积分类型 | 计算方法 | 适用条件 |
|---------|---------|---------|
| 参数方程法 | $\int_C f(z)dz = \int_a^b f(z(t))z'(t)dt$ | 曲线有参数方程 |
| 原函数法 | $\int_C f(z)dz = F(z_2) - F(z_1)$ | $f(z)$ 有原函数 |
| 分部积分法 | $\int_C udv = [uv]_C - \int_C vdu$ | 适用于乘积形式 |

### 1.3 复积分的基本性质

**性质1（线性性质）：**
$$\int_C [af(z) + bg(z)]dz = a\int_C f(z)dz + b\int_C g(z)dz$$

**性质2（路径性质）：**
$$\int_{-C} f(z)dz = -\int_C f(z)dz$$
其中 $-C$ 表示与 $C$ 方向相反的曲线。

**性质3（路径可加性）：**
若 $C = C_1 + C_2$，则：
$$\int_C f(z)dz = \int_{C_1} f(z)dz + \int_{C_2} f(z)dz$$

**性质4（估值不等式）：**
$$\left|\int_C f(z)dz\right| \leq \int_C |f(z)||dz| \leq M \cdot L$$
其中 $M = \max_{z \in C} |f(z)|$，$L$ 为曲线 $C$ 的长度。

## 2. 柯西定理

### 2.1 柯西定理（柯西-古萨定理）

**定理陈述：** 若函数 $f(z)$ 在单连通区域 $D$ 内解析，且 $C$ 是 $D$ 内任意一条闭曲线，则：
$$\oint_C f(z)dz = 0$$

<details>
<summary><strong>证明：</strong></summary>

**证明：** 由于 $f(z) = u(x,y) + iv(x,y)$ 在 $D$ 内解析，根据柯西-黎曼方程：
$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

复积分可表示为：
$$\oint_C f(z)dz = \oint_C (udx - vdy) + i\oint_C (vdx + udy)$$

应用格林公式：
$$\oint_C (Pdx + Qdy) = \iint_D \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)dxdy$$

对于实部：
$$\oint_C (udx - vdy) = \iint_D \left(-\frac{\partial v}{\partial x} - \frac{\partial u}{\partial y}\right)dxdy = 0$$

对于虚部：
$$\oint_C (vdx + udy) = \iint_D \left(\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y}\right)dxdy = 0$$

因此 $\oint_C f(z)dz = 0$。
</details>

### 2.2 复合闭路定理

**定理陈述：** 若 $f(z)$ 在多连通区域 $D$ 内解析，$C$ 是 $D$ 内的一条外闭路，$C_1, C_2, ..., C_n$ 是 $D$ 内的内闭路，则：
$$\oint_C f(z)dz = \oint_{C_1} f(z)dz + \oint_{C_2} f(z)dz + ... + \oint_{C_n} f(z)dz$$

**说明：** 沿外闭路的积分等于沿所有内闭路积分之和（方向一致）。

### 2.3 闭路变形原理

**原理：** 在解析区域内，解析函数的闭路积分只与闭路的同伦类有关，与具体路径形状无关。

**推论：** 
1. 若 $C_1$ 和 $C_2$ 是两条同伦的闭路，则 $\oint_{C_1} f(z)dz = \oint_{C_2} f(z)dz$
2. 若 $C$ 可以连续收缩为一点，则 $\oint_C f(z)dz = 0$

### 2.4 柯西定理的应用

| 应用类型 | 计算方法 | 典型例题 |
|---------|---------|---------|
| 直接计算 | 利用定理判断积分为0 | $\oint_{\|z\|=1} \frac{dz}{z^2+1}$ |
| 路径无关性 | 选择便于计算的路径 | $\int_1^i \frac{dz}{z}$ |
| 分段计算 | 将复杂路径分解 | 矩形围线积分 |

## 3. 柯西积分公式

### 3.1 基本柯西积分公式

**定理陈述：** 若 $f(z)$ 在单连通区域 $D$ 内解析，$C$ 是 $D$ 内任意一条正向闭路，$z_0$ 是 $C$ 内部一点，则：
$$f(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{z-z_0}dz$$

<details>
<summary><strong>证明：</strong></summary>

**证明：** 考虑函数 $g(z) = \frac{f(z)}{z-z_0}$。由于 $f(z)$ 在 $z_0$ 处解析，$g(z)$ 在 $z_0$ 处有孤立奇点。

在 $z_0$ 附近作小圆周 $\gamma$，根据复合闭路定理：
$$\oint_C g(z)dz = \oint_\gamma g(z)dz$$

在 $\gamma$ 上，$z = z_0 + re^{i\theta}$，$dz = ire^{i\theta}d\theta$，代入得：
$$\oint_\gamma \frac{f(z)}{z-z_0}dz = \int_0^{2\pi} \frac{f(z_0 + re^{i\theta})}{re^{i\theta}} \cdot ire^{i\theta}d\theta = i\int_0^{2\pi} f(z_0 + re^{i\theta})d\theta$$

令 $r \to 0^+$，由于 $f(z)$ 连续：
$$\lim_{r \to 0^+} i\int_0^{2\pi} f(z_0 + re^{i\theta})d\theta = i \cdot 2\pi f(z_0)$$

因此：
$$\oint_C \frac{f(z)}{z-z_0}dz = 2\pi i f(z_0)$$
即：
$$f(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{z-z_0}dz$$
</details>

### 3.2 柯西积分公式的推广形式

**推广公式1（高阶导数形式）：**
$$f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$$

**推广公式2（多极点形式）：**
若 $z_0$ 是 $C$ 内孤立奇点，则：
$$\oint_C \frac{f(z)}{(z-z_0)^{k+1}}dz = \frac{2\pi i}{k!} f^{(k)}(z_0)$$

### 3.3 柯西积分公式的应用

| 应用类型 | 计算公式 | 适用条件 |
|---------|---------|---------|
| 函数值计算 | $f(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{z-z_0}dz$ | $f$ 解析，$z_0$ 在 $C$ 内 |
| 导数计算 | $f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$ | $f$ 解析，$z_0$ 在 $C$ 内 |
| 留数计算 | $\text{Res}(f,z_0) = \frac{1}{2\pi i} \oint_C f(z)dz$ | $f$ 有孤立奇点 |

## 4. 高阶导数公式

### 4.1 高阶导数的存在性

**定理：** 若函数 $f(z)$ 在区域 $D$ 内解析，则 $f(z)$ 在 $D$ 内有任意阶导数，且各阶导数也在 $D$ 内解析。

**重要推论：** 解析函数的导数仍然是解析函数。

### 4.2 高阶导数公式

**柯西积分公式的导数形式：**
$$f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$$

其中 $C$ 是包含 $z_0$ 的任意正向简单闭曲线。

<details>
<parameter name="summary"><strong>证明：</strong></summary>

**证明：** 由基本柯西积分公式：
$$f(z) = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{\zeta-z}d\zeta$$

对 $z$ 求 $n$ 阶导数：
$$f^{(n)}(z) = \frac{n!}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta-z)^{n+1}}d\zeta$$

令 $z = z_0$，得到：
$$f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta-z_0)^{n+1}}d\zeta$$
</details>

### 4.3 高阶导数的计算

| 导数阶数 | 计算公式 | 典型应用 |
|---------|---------|---------|
| 一阶导数 | $f'(z_0) = \frac{1}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^2}dz$ | 斜率计算 |
| 二阶导数 | $f''(z_0) = \frac{2!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^3}dz$ | 曲率计算 |
| n阶导数 | $f^{(n)}(z_0) = \frac{n!}{2\pi i} \oint_C \frac{f(z)}{(z-z_0)^{n+1}}dz$ | 泰勒展开系数 |

### 4.4 高阶导数公式的应用

**应用1：解析函数的泰勒展开**
$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!}(z-z_0)^n$$

**应用2：解析函数的唯一性**
若两个解析函数在某个区域内有相同的各阶导数值，则它们在该区域内恒等。

## 5. 莫雷拉定理

### 5.1 莫雷拉定理的陈述

**定理陈述：** 若函数 $f(z)$ 在单连通区域 $D$ 内连续，且对 $D$ 内任意一条闭曲线 $C$，都有：
$$\oint_C f(z)dz = 0$$
则 $f(z)$ 在 $D$ 内解析。

<details>
<summary><strong>证明：</strong></summary>

**证明：** 
1. **构造原函数：** 定义
$$F(z) = \int_{z_0}^z f(\zeta)d\zeta$$
其中积分路径为 $D$ 内任意一条从 $z_0$ 到 $z$ 的曲线。

2. **证明 $F'(z) = f(z)$：** 
对于任意 $z \in D$，有：
$$\frac{F(z+h)-F(z)}{h} = \frac{1}{h} \int_z^{z+h} f(\zeta)d\zeta$$

当 $h \to 0$ 时，由于 $f$ 连续：
$$\lim_{h \to 0} \frac{F(z+h)-F(z)}{h} = f(z)$$

3. **证明 $F'(z)$ 解析：** 
由于 $f$ 连续，$F'(z) = f(z)$ 连续。由柯西-黎曼方程的逆定理，$F(z)$ 解析。

4. **结论：** $f(z) = F'(z)$ 解析。
</details>

### 5.2 莫雷拉定理的应用

| 应用场景 | 验证方法 | 实际意义 |
|---------|---------|---------|
| 函数解析性判定 | 验证闭路积分为0 | 判断函数是否可导 |
| 原函数存在性 | 验证路径积分只与端点有关 | 求解不定积分 |
| 解析延拓 | 通过局部性质判断整体解析性 | 扩大定义域 |

### 5.3 莫雷拉定理与其他定理的关系

**与柯西定理的关系：**
- 柯西定理：解析函数 → 闭路积分为0
- 莫雷拉定理：闭路积分为0 → 函数解析

**与柯西-黎曼方程的关系：**
- 柯西-黎曼方程：充分必要条件（需偏导连续）
- 莫雷拉定理：无需偏导连续条件

### 5.4 莫雷拉定理的应用实例

**例题1：** 判定函数 $f(z) = e^x\cos y + i e^x\sin y$ 的解析性。

**解：** 
1. $f(z) = e^x(\cos y + i\sin y) = e^z$
2. 验证：$\oint_C e^z dz = 0$（因为 $e^z$ 解析）
3. 由莫雷拉定理，$f(z)$ 解析。

**例题2：** 求解积分 $\int_C \frac{dz}{z-1}$，其中 $C$ 为 $|z|=2$。

**解：** 
1. 被积函数 $f(z) = \frac{1}{z-1}$ 在 $|z|=2$ 内有奇点 $z=1$
2. 由柯西积分公式：$\oint_C \frac{dz}{z-1} = 2\pi i \cdot f(1) = 2\pi i$

## 总结

复变函数积分理论的核心内容包括：

1. **复积分定义**：将实积分推广到复数域
2. **柯西定理**：解析函数闭路积分为0的重要定理
3. **柯西积分公式**：连接函数值与边界积分的桥梁
4. **高阶导数公式**：解析函数具有任意阶导数
5. **莫雷拉定理**：从积分性质判断函数解析性

这些定理构成了复变函数理论的基础，在实际应用中具有重要意义，特别是在计算复杂积分、求解微分方程等方面发挥着重要作用。

## 4.1 复数项级数

### 4.1.1 基本概念

**定义4.1.1** 设 $\{z_n\}$ 是复数列，称形式和式
$$\sum_{n=1}^{\infty} z_n = z_1 + z_2 + \cdots + z_n + \cdots$$
为复数项级数，其中 $z_n = a_n + ib_n$，$a_n, b_n \in \mathbb{R}$。

**部分和**：$S_n = z_1 + z_2 + \cdots + z_n$

**收敛定义**：若 $\lim_{n \to \infty} S_n = S$（$S$ 为有限复数），则称级数 $\sum_{n=1}^{\infty} z_n$ 收敛于 $S$，记作
$$\sum_{n=1}^{\infty} z_n = S$$

### 4.1.2 收敛性判别

**定理4.1.1** 复数项级数 $\sum_{n=1}^{\infty} z_n$ 收敛的充要条件是实部级数和虚部级数都收敛，即
$$\sum_{n=1}^{\infty} z_n = \sum_{n=1}^{\infty} a_n + i\sum_{n=1}^{\infty} b_n$$

### 4.1.3 绝对收敛与条件收敛

**定义4.1.2** 若级数 $\sum_{n=1}^{\infty} |z_n|$ 收敛，则称 $\sum_{n=1}^{\infty} z_n$ 绝对收敛。

**定理4.1.2** 绝对收敛的级数必收敛。

**定义4.1.3** 若级数收敛但不绝对收敛，则称其为条件收敛。

### 4.1.4 收敛判别法比较

| 判别法 | 条件 | 结论 |
|--------|------|------|
| 比较判别法 | $\sum \|z_n\|$ 与已知收敛级数比较 | 绝对收敛 |
| 比值判别法 | $\lim_{n \to \infty} \left\|\frac{z_{n+1}}{z_n}\right\| = \rho$ | $\rho < 1$ 绝对收敛，$\rho > 1$ 发散 |
| 根值判别法 | $\lim_{n \to \infty} \sqrt[n]{\|z_n\|} = \rho$ | $\rho < 1$ 绝对收敛，$\rho > 1$ 发散 |

<details>
<summary><strong>定理4.1.2证明</strong></summary>

**证明**：设 $S_n = \sum_{k=1}^n z_k$，则
$$|S_n - S_m| = \left|\sum_{k=m+1}^n z_k\right| \leq \sum_{k=m+1}^n |z_k|$$

由于 $\sum |z_k|$ 收敛，对任意 $\epsilon > 0$，存在 $N$，当 $n > m > N$ 时，
$$\sum_{k=m+1}^n |z_k| < \epsilon$$

因此 $\{S_n\}$ 是柯西序列，故收敛。$\square$
</details>

## 4.2 幂级数

### 4.2.1 基本概念

**定义4.2.1** 形如
$$\sum_{n=0}^{\infty} a_n (z - z_0)^n = a_0 + a_1(z - z_0) + a_2(z - z_0)^2 + \cdots$$
的级数称为幂级数，其中 $a_n, z, z_0$ 为复数。

### 4.2.2 收敛圆与收敛半径

**阿贝尔定理**：若幂级数在 $z = z_1 \neq z_0$ 处收敛，则在圆 $|z - z_0| < |z_1 - z_0|$ 内绝对收敛。

**收敛半径**：存在唯一 $R \geq 0$，使得：
- 当 $|z - z_0| < R$ 时，级数绝对收敛
- 当 $|z - z_0| > R$ 时，级数发散
- 当 $|z - z_0| = R$ 时，级数可能收敛也可能发散

### 4.2.3 收敛半径的计算公式

| 公式 | 条件 | 收敛半径 |
|------|------|----------|
| $R = \lim_{n \to \infty} \left\|\frac{a_n}{a_{n+1}}\right\|$ | 极限存在 | $R$ |
| $R = \frac{1}{\limsup_{n \to \infty} \sqrt[n]{\|a_n\|}}$ | 柯西-阿达马公式 | $R$ |
| $R = \lim_{n \to \infty} \left\|\frac{a_n}{a_{n+1}}\right\|$ | 比值法 | $R$ |

### 4.2.4 和函数的性质

**定理4.2.1** 幂级数的和函数 $f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n$ 在收敛圆内：
1. 连续
2. 解析
3. 可逐项积分和逐项求导

<details>
<summary><strong>定理4.2.1证明</strong></summary>

**证明**：由于幂级数在收敛圆内绝对收敛且内闭一致收敛，因此：
1. 连续性：由一致收敛性和连续函数的性质可得
2. 解析性：可逐项求导，且导数级数同样在收敛圆内收敛
3. 逐项积分：沿收敛圆内的任何路径积分，可交换积分与求和的次序

$\square$
</details>

## 4.3 泰勒级数

### 4.3.1 泰勒展开定理

**定理4.3.1** 设 $f(z)$ 在圆域 $|z - z_0| < R$ 内解析，则 $f(z)$ 可唯一地展开为幂级数：
$$f(z) = \sum_{n=0}^{\infty} \frac{f^{(n)}(z_0)}{n!}(z - z_0)^n$$

其中系数为：
$$a_n = \frac{f^{(n)}(z_0)}{n!} = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} d\zeta$$

**泰勒系数**：$a_n = \frac{f^{(n)}(z_0)}{n!}$

### 4.3.2 收敛性与唯一性

**收敛圆**：泰勒级数的收敛半径等于从 $z_0$ 到 $f(z)$ 最近奇点的距离。

**唯一性定理**：若 $f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n$ 在 $|z - z_0| < R$ 内成立，则必有 $a_n = \frac{f^{(n)}(z_0)}{n!}$。

<details>
<summary><strong>定理4.3.1证明</strong></summary>

**证明**：设 $C$ 为圆 $|z - z_0| = \rho < R$ 上的正向圆周。由柯西积分公式：
$$f(z) = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{\zeta - z} d\zeta$$

将 $\frac{1}{\zeta - z}$ 展开为几何级数：
$$\frac{1}{\zeta - z} = \frac{1}{\zeta - z_0} \cdot \frac{1}{1 - \frac{z - z_0}{\zeta - z_0}} = \sum_{n=0}^{\infty} \frac{(z - z_0)^n}{(\zeta - z_0)^{n+1}}$$

在 $C$ 上一致收敛，故可逐项积分：
$$f(z) = \sum_{n=0}^{\infty} (z - z_0)^n \cdot \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} d\zeta$$

其中积分即为 $\frac{f^{(n)}(z_0)}{n!}$。$\square$
</details>

### 4.3.3 常用函数的泰勒展开

| 函数 | 泰勒级数 | 收敛半径 |
|------|----------|----------|
| $e^z$ | $\sum_{n=0}^{\infty} \frac{z^n}{n!}$ | $\infty$ |
| $\sin z$ | $\sum_{n=0}^{\infty} (-1)^n \frac{z^{2n+1}}{(2n+1)!}$ | $\infty$ |
| $\cos z$ | $\sum_{n=0}^{\infty} (-1)^n \frac{z^{2n}}{(2n)!}$ | $\infty$ |
| $\frac{1}{1-z}$ | $\sum_{n=0}^{\infty} z^n$ | $1$ |

## 4.4 洛朗级数（重点）

### 4.4.1 基本概念

**定义4.4.1** 形如
$$\sum_{n=-\infty}^{\infty} a_n (z - z_0)^n = \cdots + a_{-2}(z - z_0)^{-2} + a_{-1}(z - z_0)^{-1} + a_0 + a_1(z - z_0) + \cdots$$
的级数称为洛朗级数，其中包含负幂项。

**洛朗级数的组成部分**：
- **主要部分**：$\sum_{n=-\infty}^{-1} a_n (z - z_0)^n$（负幂项）
- **正则部分**：$\sum_{n=0}^{\infty} a_n (z - z_0)^n$（非负幂项）

### 4.4.2 洛朗展开定理

**定理4.4.1** 设 $f(z)$ 在圆环 $r < |z - z_0| < R$ $(0 \leq r < R \leq \infty)$ 内解析，则 $f(z)$ 可唯一地展开为洛朗级数：
$$f(z) = \sum_{n=-\infty}^{\infty} a_n (z - z_0)^n$$

其中系数为：
$$a_n = \frac{1}{2\pi i} \oint_C \frac{f(\zeta)}{(\zeta - z_0)^{n+1}} d\zeta$$

这里 $C$ 是圆环内任意正向简单闭曲线。

### 4.4.3 收敛环

洛朗级数的收敛域是一个圆环：
- **内圆半径**：由主要部分决定
- **外圆半径**：由正则部分决定
- **收敛环**：$r < |z - z_0| < R$

**定理4.4.2** 洛朗级数在收敛环内绝对收敛且内闭一致收敛，其和函数在收敛环内解析。

<details>
<summary><strong>定理4.4.1证明</strong></summary>

**证明**：设 $C_1$ 和 $C_2$ 分别是圆环内半径为 $\rho_1$ 和 $\rho_2$ 的圆周，$r < \rho_1 < \rho_2 < R$。由柯西积分公式：
$$f(z) = \frac{1}{2\pi i} \oint_{C_2} \frac{f(\zeta)}{\zeta - z} d\zeta - \frac{1}{2\pi i} \oint_{C_1} \frac{f(\zeta)}{\zeta - z} d\zeta$$

对每个积分，将 $\frac{1}{\zeta - z}$ 展开为几何级数：
- 在 $C_2$ 上：$|z - z_0| < |\zeta - z_0| = \rho_2$，展开为正幂级数
- 在 $C_1$ 上：$|z - z_0| > |\zeta - z_0| = \rho_1$，展开为负幂级数

合并后得到洛朗级数展开。$\square$
</details>

### 4.4.4 洛朗展开的方法

#### 方法一：直接展开法
适用于已知函数的泰勒展开，通过变量替换得到洛朗展开。

**例4.4.1** 求 $f(z) = \frac{1}{z(1-z)}$ 在 $0 < |z| < 1$ 内的洛朗展开。

**解**：
$$\frac{1}{z(1-z)} = \frac{1}{z} \cdot \frac{1}{1-z} = \frac{1}{z} \sum_{n=0}^{\infty} z^n = \sum_{n=0}^{\infty} z^{n-1} = \sum_{n=-1}^{\infty} z^n$$

#### 方法二：部分分式法
适用于有理函数的洛朗展开。

**例4.4.2** 求 $f(z) = \frac{1}{(z-1)(z-2)}$ 在 $1 < |z| < 2$ 内的洛朗展开。

**解**：
$$\frac{1}{(z-1)(z-2)} = \frac{A}{z-1} + \frac{B}{z-2}$$

解得 $A = -1$，$B = 1$，故：
$$\frac{1}{(z-1)(z-2)} = -\frac{1}{z-1} + \frac{1}{z-2}$$

在 $1 < |z| < 2$ 内：
$$-\frac{1}{z-1} = -\frac{1}{z} \cdot \frac{1}{1-\frac{1}{z}} = -\sum_{n=1}^{\infty} \frac{1}{z^n}$$
$$\frac{1}{z-2} = -\frac{1}{2} \cdot \frac{1}{1-\frac{z}{2}} = -\sum_{n=0}^{\infty} \frac{z^n}{2^{n+1}}$$

因此：
$$\frac{1}{(z-1)(z-2)} = -\sum_{n=1}^{\infty} \frac{1}{z^n} - \sum_{n=0}^{\infty} \frac{z^n}{2^{n+1}}$$

## 4.5 孤立奇点分类（重点）

### 4.5.1 孤立奇点的定义

**定义4.5.1** 设 $z_0$ 是 $f(z)$ 的奇点，若存在 $\delta > 0$，使得 $f(z)$ 在去心邻域 $0 < |z - z_0| < \delta$ 内解析，则称 $z_0$ 为孤立奇点。

### 4.5.2 孤立奇点的分类

根据洛朗级数中负幂项的情况，孤立奇点可分为三类：

![奇点分类图示](imgs/laurent-series-singularity-classification-chart.jpg)
*图4-1: 洛朗级数中孤立奇点的分类*

#### 1. 可去奇点（Removable Singularity）

**定义4.5.2** 若洛朗级数中无负幂项（即主要部分为零），则 $z_0$ 为可去奇点。

**特征**：
- 洛朗展开：$f(z) = \sum_{n=0}^{\infty} a_n (z - z_0)^n$
- $\lim_{z \to z_0} f(z)$ 存在且有限
- 补充定义 $f(z_0) = \lim_{z \to z_0} f(z)$ 后，$f(z)$ 在 $z_0$ 处解析

**例4.5.1** $f(z) = \frac{\sin z}{z}$ 在 $z = 0$ 处为可去奇点，因为：
$$\frac{\sin z}{z} = \sum_{n=0}^{\infty} (-1)^n \frac{z^{2n}}{(2n+1)!}$$

#### 2. 极点（Pole）

**定义4.5.3** 若洛朗级数中有有限个负幂项，则 $z_0$ 为极点。

**特征**：
- 洛朗展开：$f(z) = \sum_{n=-m}^{\infty} a_n (z - z_0)^n$，其中 $a_{-m} \neq 0$
- $m$ 称为极点的阶数
- $\lim_{z \to z_0} (z - z_0)^m f(z)$ 存在且非零

**例4.5.2** $f(z) = \frac{1}{z^2}$ 在 $z = 0$ 处为二阶极点。

#### 3. 本性奇点（Essential Singularity）

**定义4.5.4** 若洛朗级数中有无穷多个负幂项，则 $z_0$ 为本性奇点。

**特征**：
- 洛朗展开：$f(z) = \sum_{n=-\infty}^{\infty} a_n (z - z_0)^n$，其中无穷多个 $a_n \neq 0$（$n < 0$）
- $\lim_{z \to z_0} f(z)$ 不存在
- 皮卡定理：$f(z)$ 在本性奇点的任意去心邻域内取遍所有复值（至多一个值除外）

**例4.5.3** $f(z) = e^{1/z}$ 在 $z = 0$ 处为本性奇点，因为：
$$e^{1/z} = \sum_{n=0}^{\infty} \frac{1}{n!} z^{-n}$$

### 4.5.3 奇点分类判别法

| 判别方法 | 可去奇点 | 极点 | 本性奇点 |
|----------|----------|------|----------|
| 洛朗级数 | 无负幂项 | 有限个负幂项 | 无穷多个负幂项 |
| 极限判别 | $\lim_{z \to z_0} f(z)$ 存在 | $\lim_{z \to z_0} \|f(z)\| = \infty$ | 极限不存在 |
| 阶数判别 | 0阶 | $m$阶（$m \geq 1$） | 无穷阶 |

### 4.5.4 极点阶数的确定

**定理4.5.1** $z_0$ 是 $f(z)$ 的 $m$ 阶极点的充要条件是：
$$\lim_{z \to z_0} (z - z_0)^m f(z) = A \neq 0$$

**推论**：若 $f(z) = \frac{p(z)}{q(z)}$，其中 $p(z)$ 和 $q(z)$ 在 $z_0$ 处解析，且 $p(z_0) \neq 0$，$q(z)$ 在 $z_0$ 处有 $m$ 阶零点，则 $z_0$ 是 $f(z)$ 的 $m$ 阶极点。

<details>
<summary><strong>定理4.5.1证明</strong></summary>

**证明**：
（必要性）若 $z_0$ 是 $m$ 阶极点，则洛朗级数为：
$$f(z) = \sum_{n=-m}^{\infty} a_n (z - z_0)^n = (z - z_0)^{-m} \sum_{n=0}^{\infty} a_{n-m} (z - z_0)^n$$

其中 $a_{-m} \neq 0$，因此：
$$(z - z_0)^m f(z) = \sum_{n=0}^{\infty} a_{n-m} (z - z_0)^n$$

令 $z \to z_0$，得极限为 $a_0 \neq 0$。

（充分性）若 $\lim_{z \to z_0} (z - z_0)^m f(z) = A \neq 0$，则 $(z - z_0)^m f(z)$ 在 $z_0$ 处解析且不为零，故 $f(z)$ 在去心邻域内可展开为洛朗级数，且负幂项的最高阶为 $-m$。$\square$

### 4.6.1 级数类型对比

| 级数类型 | 形式 | 收敛域 | 主要应用 |
|----------|------|--------|----------|
| 复数项级数 | $\sum z_n$ | 依具体级数而定 | 基础收敛理论 |
| 幂级数 | $\sum a_n(z-z_0)^n$ | 圆域 $\|z-z_0\| < R$ | 泰勒展开 |
| 洛朗级数 | $\sum a_n(z-z_0)^n$ | 圆环 $r < \|z-z_0\| < R$ | 奇点分析 |

### 4.6.3 重点内容回顾

1. **洛朗级数**是复分析的核心工具，用于分析孤立奇点邻域内的函数行为
2. **奇点分类**基于洛朗级数的负幂项特征：
   - 可去奇点：无负幂项
   - 极点：有限个负幂项
   - 本性奇点：无穷多个负幂项
3. **皮卡定理**揭示了本性奇点的本质特征
4. **泰勒级数**是洛朗级数的特例（无负幂项）

**收敛半径公式**：
$$R = \frac{1}{\limsup_{n \to \infty} \sqrt[n]{\|a_n\|}}$$

## 5.1 留数的定义与计算

### 5.1.1 留数的定义

设函数 $f(z)$ 在点 $z_0$ 的去心邻域 $0 < |z - z_0| < R$ 内解析，在 $z_0$ 处可能有奇点。则 $f(z)$ 在 $z_0$ 处的**留数**定义为：

$$\text{Res}[f(z), z_0] = \frac{1}{2\pi i} \oint_C f(z) dz$$

其中 $C$ 是任意一条包含 $z_0$ 的正向简单闭曲线。

### 5.1.2 留数的计算方法

根据奇点的类型，留数有不同的计算方法：

#### 1. 可去奇点和极点

设 $z_0$ 是 $f(z)$ 的孤立奇点，则：

- 如果 $z_0$ 是可去奇点，则 $\text{Res}[f(z), z_0] = 0$
- 如果 $z_0$ 是极点，则：
  - 一阶极点：$\text{Res}[f(z), z_0] = \lim_{z \to z_0} (z - z_0)f(z)$
  - $n$ 阶极点：$\text{Res}[f(z), z_0] = \frac{1}{(n-1)!} \lim_{z \to z_0} \frac{d^{n-1}}{dz^{n-1}}[(z-z_0)^n f(z)]$

#### 2. 本性奇点

设 $z_0$ 是本性奇点，则留数需要通过洛朗级数展开的 $-1$ 次幂系数确定：

$$\text{Res}[f(z), z_0] = c_{-1}$$

其中 $c_{-1}$ 是洛朗级数展开式中 $(z-z_0)^{-1}$ 项的系数。

### 5.1.3 常用函数的留数

| 函数类型 | 奇点类型 | 留数计算公式 | 适用条件 |
|---------|---------|-------------|---------|
| $\frac{p(z)}{q(z)}$ | 一阶极点 $z_0$ | $\frac{p(z_0)}{q'(z_0)}$ | $q(z_0) = 0, q'(z_0) \neq 0$ |
| $\frac{1}{(z-z_0)^n}$ | $n$ 阶极点 | $\begin{cases} 1, & n=1 \\ 0, & n>1 \end{cases}$ | $n$ 为正整数 |
| $e^{\frac{1}{z}}$ | 本性奇点 | $\text{Res}[e^{\frac{1}{z}}, 0] = 1$ | 洛朗级数展开 |

## 5.2 留数定理

### 5.2.1 留数定理陈述

**留数定理**：设函数 $f(z)$ 在简单闭曲线 $C$ 所围成的有界区域 $D$ 内，除有限个孤立奇点 $z_1, z_2, \ldots, z_n$ 外解析，且在 $C$ 上连续。则：

$$\oint_C f(z) dz = 2\pi i \sum_{k=1}^n \text{Res}[f(z), z_k]$$

**证明**：

<details>
<summary>留数定理的详细证明</summary>

**证明步骤**：

1. **构造辅助曲线**：对于每个孤立奇点 $z_k$，作一个小圆周 $\gamma_k$，使得 $\gamma_k$ 互不相交且都位于 $D$ 内。

2. **应用柯西积分定理**：由于 $f(z)$ 在 $C$ 和 $\gamma_k$ 围成的区域上解析，根据柯西积分定理：

$$\oint_C f(z) dz = \sum_{k=1}^n \oint_{\gamma_k} f(z) dz$$

3. **应用留数定义**：根据留数的定义：

$$\oint_{\gamma_k} f(z) dz = 2\pi i \cdot \text{Res}[f(z), z_k]$$

4. **合并结果**：

$$\oint_C f(z) dz = 2\pi i \sum_{k=1}^n \text{Res}[f(z), z_k]$$

证毕。
</details>

### 5.2.2 留数定理的应用

留数定理将复积分的计算转化为留数的计算，为定积分的计算提供了强大的工具。

## 5.3 留数在定积分计算中的应用

### 5.3.1 三角函数积分

#### 类型一：$\int_0^{2\pi} R(\cos\theta, \sin\theta) d\theta$

**方法**：令 $z = e^{i\theta}$，则 $dz = ie^{i\theta}d\theta = iz d\theta$，因此 $d\theta = \frac{dz}{iz}$。

**变换公式**：
- $\cos\theta = \frac{z + z^{-1}}{2} = \frac{z^2 + 1}{2z}$
- $\sin\theta = \frac{z - z^{-1}}{2i} = \frac{z^2 - 1}{2iz}$
- $d\theta = \frac{dz}{iz}$

**积分化为**：
$$\int_0^{2\pi} R(\cos\theta, \sin\theta) d\theta = \oint_{|z|=1} R\left(\frac{z^2 + 1}{2z}, \frac{z^2 - 1}{2iz}\right) \frac{dz}{iz}$$

#### 典型例题

**例题1**：计算 $I = \int_0^{2\pi} \frac{d\theta}{a + b\cos\theta}$，其中 $a > |b| > 0$。

**解答**：
1. 令 $z = e^{i\theta}$，则 $\cos\theta = \frac{z^2 + 1}{2z}$，$d\theta = \frac{dz}{iz}$
2. 积分化为：
   $$I = \oint_{|z|=1} \frac{1}{a + b\frac{z^2 + 1}{2z}} \cdot \frac{dz}{iz} = \oint_{|z|=1} \frac{2dz}{iz(2az + bz^2 + b)}$$
3. 整理得：
   $$I = \oint_{|z|=1} \frac{2dz}{i(bz^2 + 2az + b)}$$
4. 极点为 $z = \frac{-2a \pm \sqrt{4a^2 - 4b^2}}{2b} = \frac{-a \pm \sqrt{a^2 - b^2}}{b}$
5. 由于 $a > |b|$，单位圆内的极点为 $z_0 = \frac{-a + \sqrt{a^2 - b^2}}{b}$
6. 一阶极点的留数：
   $$\text{Res}\left[\frac{2}{i(bz^2 + 2az + b)}, z_0\right] = \frac{2}{i \cdot b \cdot 2z_0 + 2ai} = \frac{1}{i(bz_0 + a)}$$
7. 代入 $z_0$ 的值并计算：
   $$I = 2\pi i \cdot \frac{1}{i\sqrt{a^2 - b^2}} = \frac{2\pi}{\sqrt{a^2 - b^2}}$$

### 5.3.2 无理函数积分

#### 类型二：$\int_{-\infty}^{\infty} \frac{p(x)}{q(x)} dx$

**适用条件**：
- $q(x)$ 在实轴上无零点
- $\deg q \geq \deg p + 2$
- $q(x)$ 的所有零点都在上半平面

**方法**：
1. 考虑复函数 $f(z) = \frac{p(z)}{q(z)}$
2. 构造上半圆围道：$C_R = [-R, R] \cup \Gamma_R$，其中 $\Gamma_R$ 是半径为 $R$ 的上半圆
3. 当 $R \to \infty$ 时，$\int_{\Gamma_R} f(z) dz \to 0$
4. 根据留数定理：
   $$\int_{-\infty}^{\infty} \frac{p(x)}{q(x)} dx = 2\pi i \sum \text{Res}[f(z), z_k]$$

其中 $z_k$ 是 $f(z)$ 在上半平面的极点。

#### 典型例题

**例题2**：计算 $I = \int_{-\infty}^{\infty} \frac{dx}{x^4 + 1}$。

**解答**：
1. 分母因式分解：$x^4 + 1 = (x^2 + \sqrt{2}x + 1)(x^2 - \sqrt{2}x + 1)$
2. 极点为 $z = \pm\frac{\sqrt{2}}{2} \pm i\frac{\sqrt{2}}{2}$
3. 上半平面的极点：$z_1 = \frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}$，$z_2 = -\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}$
4. 计算留数：
   $$\text{Res}[f(z), z_1] = \frac{1}{4z_1^3} = \frac{1}{4\left(\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right)^3}$$
   $$\text{Res}[f(z), z_2] = \frac{1}{4z_2^3} = \frac{1}{4\left(-\frac{\sqrt{2}}{2} + i\frac{\sqrt{2}}{2}\right)^3}$$
5. 计算结果：
   $$I = 2\pi i \left(\text{Res}[f(z), z_1] + \text{Res}[f(z), z_2]\right) = \frac{\pi}{2\sqrt{2}}$$

### 5.3.3 积分主值

#### 柯西主值

对于积分 $\int_{-\infty}^{\infty} f(x) dx$，如果被积函数在实轴上有奇点，可以使用柯西主值：

$$\text{P.V.} \int_{-\infty}^{\infty} f(x) dx = \lim_{\epsilon \to 0^+, R \to \infty} \left(\int_{-\infty}^{x_0-\epsilon} f(x) dx + \int_{x_0+\epsilon}^{R} f(x) dx\right)$$

其中 $x_0$ 是实轴上的奇点。

#### 小半圆法

**方法步骤**：
1. 在奇点 $x_0$ 处作小半圆 $\gamma_\epsilon$，半径为 $\epsilon$
2. 构造围道避开奇点
3. 计算 $\int_{\gamma_\epsilon} f(z) dz$ 的极限值
4. 应用留数定理

**小半圆积分**：
- 上半小半圆：$\int_{\gamma_\epsilon} f(z) dz \to -\pi i \cdot \text{Res}[f(z), x_0]$
- 下半小半圆：$\int_{\gamma_\epsilon} f(z) dz \to \pi i \cdot \text{Res}[f(z), x_0]$

### 5.3.4 积分类型总结

| 积分类型 | 积分形式 | 变换方法 | 围道选择 | 关键条件 |
|---------|---------|---------|---------|---------|
| 三角函数 | $\int_0^{2\pi} R(\cos\theta, \sin\theta) d\theta$ | $z = e^{i\theta}$ | 单位圆 $\|z\| = 1$ | $R$ 为有理函数 |
| 无理函数 | $\int_{-\infty}^{\infty} \frac{p(x)}{q(x)} dx$ | 直接考虑 | 上半平面 | $\deg q \geq \deg p + 2$ |
| 主值积分 | P.V. $\int_{-\infty}^{\infty} f(x) dx$ | 小半圆法 | 避开实轴奇点 | 实轴有奇点 |
| 傅里叶型 | $\int_{-\infty}^{\infty} f(x)e^{ix} dx$ | 约当引理 | 上/下半平面 | $f(z)$ 在无穷远点性质 |

## 5.4 幅角原理

### 5.4.1 幅角原理

**幅角原理**：设函数 $f(z)$ 在简单闭曲线 $C$ 所围成的区域 $D$ 内解析，在 $\bar{D} = D \cup C$ 上连续，且在 $C$ 上无零点。则：

$$\frac{1}{2\pi i} \oint_C \frac{f'(z)}{f(z)} dz = N - P$$

其中 $N$ 是 $f(z)$ 在 $D$ 内零点的个数（按重数计），$P$ 是 $f(z)$ 在 $D$ 内极点的个数（按重数计）。

**证明**：

<details>
<summary>幅角原理的详细证明</summary>

**证明步骤**：

1. **分解函数**：设 $f(z)$ 在 $D$ 内有零点 $z_1, z_2, \ldots, z_m$ 和极点 $w_1, w_2, \ldots, w_n$，则：

   $$f(z) = (z-z_1)^{\alpha_1} \cdots (z-z_m)^{\alpha_m} (z-w_1)^{-\beta_1} \cdots (z-w_n)^{-\beta_n} g(z)$$

   其中 $g(z)$ 在 $\bar{D}$ 上解析且无零点。

2. **求导数**：

   $$\frac{f'(z)}{f(z)} = \sum_{k=1}^m \frac{\alpha_k}{z-z_k} - \sum_{k=1}^n \frac{\beta_k}{z-w_k} + \frac{g'(z)}{g(z)}$$

3. **应用留数定理**：

   $$\frac{1}{2\pi i} \oint_C \frac{f'(z)}{f(z)} dz = \sum_{k=1}^m \alpha_k - \sum_{k=1}^n \beta_k = N - P$$

证毕。
</details>

### 5.4.2 儒歇定理

**儒歇定理**：设函数 $f(z)$ 和 $g(z)$ 在简单闭曲线 $C$ 所围成的区域 $D$ 内解析，在 $\bar{D}$ 上连续。如果在 $C$ 上有 $|f(z)| > |g(z)|$，则 $f(z)$ 和 $f(z) + g(z)$ 在 $D$ 内有相同数目的零点。

**证明**：

<details>
<summary>儒歇定理的详细证明</summary>

**证明步骤**：

1. **构造辅助函数**：考虑函数 $F(z) = f(z) + \lambda g(z)$，其中 $\lambda \in [0, 1]$。

2. **应用幅角原理**：对于每个 $\lambda$，定义：

   $$N(\lambda) = \frac{1}{2\pi i} \oint_C \frac{F'(z)}{F(z)} dz$$

3. **证明 $N(\lambda)$ 为常数**：
   - 在 $C$ 上，$|F(z)| = |f(z) + \lambda g(z)| \geq |f(z)| - \lambda|g(z)| > 0$
   - 因此 $F(z)$ 在 $C$ 上无零点，$N(\lambda)$ 有定义且为整数
   - $N(\lambda)$ 连续（因为 $F(z)$ 连续依赖于 $\lambda$）
   - 连续整数函数必为常数

4. **特殊情况**：
   - 当 $\lambda = 0$ 时，$N(0) = N_f$（$f(z)$ 的零点数）
   - 当 $\lambda = 1$ 时，$N(1) = N_{f+g}$（$f(z) + g(z)$ 的零点数）
   - 因此 $N_f = N_{f+g}$

证毕。
</details>

### 5.4.3 幅角原理的应用

#### 例题3：应用儒歇定理

**例题3**：证明方程 $z^7 - 5z^5 + 2z^3 - 3z + 1 = 0$ 在单位圆 $|z| = 1$ 内有7个根。

**解答**：
1. 设 $f(z) = z^7$，$g(z) = -5z^5 + 2z^3 - 3z + 1$
2. 在 $|z| = 1$ 上，$|f(z)| = |z|^7 = 1$
3. $|g(z)| \leq 5 + 2 + 3 + 1 = 11$，但需要更精确估计：
   - 当 $|z| = 1$ 时，$|g(z)| \leq 5|z|^5 + 2|z|^3 + 3|z| + 1 = 5 + 2 + 3 + 1 = 11$
   - 这个估计不够精确，我们需要 $|g(z)| < |f(z)| = 1$
4. 重新选择：设 $f(z) = z^7 - 5z^5$，$g(z) = 2z^3 - 3z + 1$
   - 在 $|z| = 1$ 上，$|f(z)| = |z^5(z^2 - 5)| = |z^2 - 5| \geq 5 - 1 = 4$
   - $|g(z)| \leq 2 + 3 + 1 = 6$，仍然不满足
5. 最终选择：$f(z) = z^7$，$g(z) = -5z^5 + 2z^3 - 3z + 1$
   - 在 $|z| = 1$ 上，$|f(z)| = 1$
   - $|g(z)| \leq 5 + 2 + 3 + 1 = 11$，但实际在单位圆上：
     $$|g(z)| = |-5e^{i5\theta} + 2e^{i3\theta} - 3e^{i\theta} + 1| \leq 5 + 2 + 3 + 1 = 11$$
   - 这个估计不够好，需要用最大值原理或其他方法

**更精确的证明**：
- 在 $|z| = 1$ 上，$|z^7 - 5z^5 + 2z^3 - 3z| \geq |5z^5| - |z^7 + 2z^3 - 3z| \geq 5 - (1 + 2 + 3) = -1$
- 这个估计仍然不够好
- 实际上，可以证明在 $|z| = 1$ 上，$|z^7 - 5z^5 + 2z^3 - 3z| > 1$，从而应用儒歇定理

| 可去奇点 | 直接计算 | 洛朗级数无负幂项 | 留数为0 |
| 极点 | 导数公式 | $n$ 阶极点用导数公式 | 一阶极点可用简化公式 |
| 本性奇点 | 洛朗级数 | 展开后取 $c_{-1}$ | 需要完整级数展开 |

### 5.5.3 定积分计算策略

1. **识别积分类型**：三角函数、无理函数、傅里叶型等
2. **选择合适的变换**：$z = e^{i\theta}$、直接考虑复函数等
3. **构造适当围道**：上半平面、下半平面、单位圆等
4. **计算留数**：根据极点类型选择计算方法
5. **应用留数定理**：得到最终结果

### 5.5.4 重要定理应用场景

- **留数定理**：计算各种类型的定积分
- **幅角原理**：研究零点分布
- **儒歇定理**：比较不同函数的零点个数
- **小半圆法**：处理实轴上的奇点

留数定理作为复分析的重要工具，在数学物理、工程技术等领域都有广泛应用，是连接复分析与实分析的重要桥梁。
# 第六章 保角映射

## 6.1 保角映射的概念

### 6.1.1 定义

**保角映射**（共形映射）是指在映射过程中保持角度不变的解析函数映射。

**定义 6.1**：设 $f$ 在区域 $D$ 内解析，若 $f'(z) \neq 0$ 对所有 $z \in D$，则称 $f$ 在 $D$ 内是**保角映射**。

**等价定义**：若 $f$ 在 $z_0$ 处解析且 $f'(z_0) \neq 0$，则 $f$ 在 $z_0$ 处是保角的。

### 6.1.2 几何意义

保角映射具有以下几何性质：

1. **角度保持性**：两条光滑曲线在交点处的夹角经过映射后保持不变
2. **方向保持性**：映射保持曲线的定向
3. **局部相似性**：在充分小的邻域内，映射近似于相似变换

**定理 6.1**：若 $f$ 在 $z_0$ 处解析且 $f'(z_0) \neq 0$，则存在 $z_0$ 的邻域 $U$，使得：
- $f$ 在 $U$ 上是单叶的
- $f$ 在 $U$ 上是保角的
- $f(U)$ 是开集

<details>
<summary>证明</summary>

**证明**：由于 $f'(z_0) \neq 0$，根据解析函数的性质，$f$ 在 $z_0$ 的某个邻域内可以展开为幂级数：

$$f(z) = f(z_0) + f'(z_0)(z-z_0) + \frac{f''(z_0)}{2!}(z-z_0)^2 + \cdots$$

令 $w = f(z) - f(z_0)$，则：

$$w = f'(z_0)(z-z_0) + \frac{f''(z_0)}{2!}(z-z_0)^2 + \cdots$$

$$= (z-z_0)\left[f'(z_0) + \frac{f''(z_0)}{2!}(z-z_0) + \cdots\right]$$

由于 $f'(z_0) \neq 0$，当 $|z-z_0|$ 充分小时，括号内的表达式非零，因此 $w$ 与 $(z-z_0)$ 同阶。

构造映射 $g(w) = z$，则 $g$ 在 $w=0$ 处解析且 $g'(0) = \frac{1}{f'(z_0)} \neq 0$，故 $g$ 在 $w=0$ 的邻域内单叶解析。

因此 $f$ 在 $z_0$ 的充分小邻域内是单叶解析的，即为保角映射。

</details>

### 6.1.3 映射的局部性质

**局部线性化**：在 $z_0$ 附近，映射 $f$ 可以近似为：

$$f(z) \approx f(z_0) + f'(z_0)(z-z_0)$$

这表明局部上，映射是相似变换：
- 旋转角度：$\arg f'(z_0)$
- 伸缩比例：$|f'(z_0)|$

## 6.2 分式线性映射

### 6.2.1 定义

**分式线性映射**（莫比乌斯变换）是指形如：

![分式线性映射](imgs/lft-cross-ratio-formula-graphic.jpg)
*图6-1: 分式线性映射的交比公式*

$$w = f(z) = \frac{az+b}{cz+d}$$

其中 $a, b, c, d$ 为复常数，且 $ad-bc \neq 0$ 的映射。

**标准形式**：
- 当 $c \neq 0$ 时：$w = \frac{az+b}{cz+d}$
- 当 $c = 0$ 时：$w = \frac{a}{d}z + \frac{b}{d}$（线性映射）

### 6.2.2 基本性质

**性质 6.1**：分式线性映射是保角映射。

**证明**：$f'(z) = \frac{ad-bc}{(cz+d)^2}$，由于 $ad-bc \neq 0$，故 $f'(z) \neq 0$（除去极点 $z = -\frac{d}{c}$）。

**性质 6.2**：分式线性映射的逆映射也是分式线性映射。

若 $w = \frac{az+b}{cz+d}$，则逆映射为：
$$z = \frac{-dw+b}{cw-a}$$

**性质 6.3**：分式线性映射的复合仍是分式线性映射。

<details>
<summary>证明</summary>

设两个分式线性映射：
$$f_1(z) = \frac{a_1z+b_1}{c_1z+d_1}, \quad f_2(z) = \frac{a_2z+b_2}{c_2z+d_2}$$

则复合映射：
$$f_2(f_1(z)) = \frac{a_2\frac{a_1z+b_1}{c_1z+d_1}+b_2}{c_2\frac{a_1z+b_1}{c_1z+d_1}+d_2}$$

$$= \frac{a_2(a_1z+b_1)+b_2(c_1z+d_1)}{c_2(a_1z+b_1)+d_2(c_1z+d_1)}$$

$$= \frac{(a_2a_1+b_2c_1)z+(a_2b_1+b_2d_1)}{(c_2a_1+d_2c_1)z+(c_2b_1+d_2d_1)}$$

仍是分式线性映射。

</details>

### 6.2.3 不动点

**定义 6.2**：若 $f(z_0) = z_0$，则称 $z_0$ 为映射 $f$ 的**不动点**。

对于分式线性映射 $w = \frac{az+b}{cz+d}$，不动点满足：

$$\frac{az_0+b}{cz_0+d} = z_0$$

即：$az_0 + b = z_0(cz_0 + d)$

整理得：$cz_0^2 + (d-a)z_0 - b = 0$

**定理 6.2**：分式线性映射最多有两个不动点。

<details>
<summary>证明</summary>

从上述方程 $cz_0^2 + (d-a)z_0 - b = 0$ 可以看出，这是一个关于 $z_0$ 的二次方程，最多有两个根（考虑重根情况）。

特殊情况：
- 当 $c = 0$ 时，方程变为 $(d-a)z_0 - b = 0$，只有一个不动点（线性映射）
- 当 $c \neq 0$ 时，最多有两个不动点

</details>

### 6.2.4 保圆性

**定理 6.3**：分式线性映射将圆周映射为圆周或直线。

**证明**：圆的一般方程为：
$$Az\bar{z} + \bar{B}z + B\bar{z} + C = 0$$

其中 $A, C$ 为实数，$B$ 为复数。

将 $z = \frac{dw-b}{-cw+a}$ 代入，整理后可证明映射后仍是圆或直线。

**推论 6.1**：分式线性映射将圆内部映射为圆内部或外部。

### 6.2.5 特殊分式线性映射

#### 6.2.5.1 平移映射
$$w = z + b$$

#### 6.2.5.2 旋转映射
$$w = e^{i\theta}z$$

#### 6.2.5.3 伸缩映射
$$w = kz \quad (k > 0)$$

#### 6.2.5.4 反演映射
$$w = \frac{1}{z}$$

### 6.2.6 映射类型与性质对照表

| 映射类型 | 标准形式 | 不动点 | 保圆性 | 特殊性质 |
|---------|---------|--------|--------|----------|
| 平移 | $w = z + b$ | 无 | 保持 | 纯平移 |
| 旋转 | $w = e^{i\theta}z$ | $z = 0$ | 保持 | 保持模长 |
| 伸缩 | $w = kz$ | $z = 0$ | 保持 | 改变模长 |
| 反演 | $w = \frac{1}{z}$ | $z = \pm 1$ | 保持 | 单位圆内外互换 |
| 一般分式线性 | $w = \frac{az+b}{cz+d}$ | 最多2个 | 保持 | 最一般的保角映射 |

## 6.3 幂函数与指数函数映射

### 6.3.1 幂函数映射

#### 6.3.1.1 基本形式
$$w = z^n \quad (n \in \mathbb{N}, n \geq 2)$$

**导数**：$f'(z) = nz^{n-1}$

**奇点**：$z = 0$（当 $n \geq 2$ 时，$f'(0) = 0$）

#### 6.3.1.2 映射性质

**定理 6.4**：$w = z^n$ 在 $z \neq 0$ 处是保角映射。

**证明**：当 $z \neq 0$ 时，$f'(z) = nz^{n-1} \neq 0$，故映射保角。

**角度性质**：
- 幅角放大 $n$ 倍：$\arg(w) = n\arg(z)$
- 模长幂次变换：$|w| = |z|^n$

**区域映射**：
- 角形区域：$0 < \arg(z) < \frac{2\pi}{n}$ 映射为上半平面
- 单位圆：$|z| = 1$ 映射为单位圆 $|w| = 1$
- 单位圆内部：$|z| < 1$ 映射为 $|w| < 1$

#### 6.3.1.3 应用实例

**例 6.1**：将角形区域 $D = \{z : 0 < \arg z < \frac{\pi}{4}\}$ 映射为上半平面。

**解**：取 $w = z^4$，则：
- $\arg w = 4\arg z$
- 当 $0 < \arg z < \frac{\pi}{4}$ 时，$0 < \arg w < \pi$
- 故 $w$ 的虚部大于0，即在上半平面

### 6.3.2 指数函数映射

#### 6.3.2.1 基本形式
$$w = e^z$$

**导数**：$f'(z) = e^z \neq 0$（处处非零）

**映射性质**：指数函数在复平面上处处保角。

#### 6.3.2.2 映射特性

**周期性质**：$e^{z+2\pi i} = e^z$

**水平带映射**：
- 水平带 $0 < \Im(z) < 2\pi$ 映射为复平面去掉负实轴
- 水平带 $0 < \Im(z) < \pi$ 映射为上半平面

**幅角性质**：
- $\arg w = \Im(z)$
- $\ln|w| = \Re(z)$

#### 6.3.2.3 应用实例

**例 6.2**：将带形区域 $D = \{z : 0 < \Im(z) < \pi\}$ 映射为上半平面。

**解**：直接取 $w = e^z$，则：
- $\Im(w) = e^{\Re(z)}\sin(\Im(z)) > 0$（因为 $0 < \Im(z) < \pi$）
- 故 $w$ 在上半平面

### 6.3.3 对数函数映射

#### 6.3.3.1 基本形式
$$w = \log z = \ln|z| + i\arg z$$

**多值性**：对数函数是多值函数，通常取主值分支：
$$\log z = \ln|z| + i\arg z \quad (-\pi < \arg z \leq \pi)$$

#### 6.3.3.2 映射性质

**分支切割**：通常在负实轴处切割。

**逆映射性质**：$\exp(\log z) = z$

**区域映射**：
- 上半平面映射为带形区域 $0 < \Im(w) < \pi$
- 单位圆内部映射为左半平面 $\Re(w) < 0$

## 6.4 多角形映射（施瓦茨-克里斯托费尔映射）

### 6.4.1 施瓦茨-克里斯托费尔映射

**定理 6.5**：存在唯一的分式线性映射将上半平面映射到给定的多角形区域。

**施瓦茨-克里斯托费尔公式**：

设多角形 $P$ 的顶点为 $a_1, a_2, \ldots, a_n$（按逆时针顺序），对应的内角为 $\alpha_1\pi, \alpha_2\pi, \ldots, \alpha_n\pi$，则映射为：

$$f(z) = C\int_{z_0}^z \prod_{k=1}^n (\zeta-a_k)^{\alpha_k-1} d\zeta + D$$

其中 $C, D$ 为常数，$z_0$ 为起点。

**参数条件**：$\sum_{k=1}^n \alpha_k = n-2$

<details>
<summary>证明思路</summary>

证明基于以下观察：
1. 映射在实轴上的每个点 $a_k$ 附近，映射的导数 $f'(z)$ 有 $(\zeta-a_k)^{\alpha_k-1}$ 形式的奇点
2. 这保证了映射在 $a_k$ 处的角度变化为 $\alpha_k\pi$
3. 分式线性映射可以将任意三个点映射到指定位置
4. 积分常数 $C, D$ 用于调整位置和缩放

详细的证明需要分析映射的局部行为和整体性质。

</details>

### 6.4.2 常见多角形映射

#### 6.4.2.1 三角形映射

**等边三角形**：顶点 $a_1 = 0, a_2 = 1, a_3 = \infty$，内角均为 $\frac{\pi}{3}$

映射公式：
$$f(z) = C\int_0^z \zeta^{-\frac{2}{3}}(1-\zeta)^{-\frac{2}{3}} d\zeta + D$$

#### 6.4.2.2 矩形映射

**矩形**：顶点 $a_1 = -1, a_2 = 1, a_3 = \infty$，内角均为 $\frac{\pi}{2}$

映射公式：
$$f(z) = C\int_{-1}^z \frac{d\zeta}{\sqrt{(1-\zeta^2)}} + D = C\arcsin z + D$$

#### 6.4.2.3 半平面到多角形的映射

**一般步骤**：
1. 选择实轴上的三个点映射到多角形的三个顶点
2. 使用分式线性映射完成这个步骤
3. 应用施瓦茨-克里斯托费尔公式处理剩余顶点

### 6.4.3 映射的构造方法

**步骤 1**：确定多角形的内角 $\alpha_1\pi, \alpha_2\pi, \ldots, \alpha_n\pi$

**步骤 2**：选择实轴上的点 $x_1 < x_2 < \ldots < x_n$ 作为原像

**步骤 3**：构造映射：
$$f(z) = A\int_{x_1}^z \prod_{k=1}^n (t-x_k)^{\alpha_k-1} dt + B$$

**步骤 4**：确定常数 $A, B$ 使得映射满足边界条件

### 6.4.4 应用实例

**例 6.3**：构造将上半平面映射到等腰直角三角形的映射。

**解**：
1. 等腰直角三角形内角：$\frac{\pi}{2}, \frac{\pi}{4}, \frac{\pi}{4}$
2. 选择实轴上的点：$x_1 = 0, x_2 = 1, x_3 = \infty$
3. 映射公式：
$$f(z) = A\int_0^z t^{-\frac{1}{2}}(1-t)^{-\frac{3}{4}} dt + B$$

## 6.5 映射的应用

### 6.5.1 拉普拉斯方程的边值问题

**狄利克雷问题**：在区域 $D$ 内求调和函数 $u$，使得：
$$\begin{cases}
\Delta u = 0 & \text{在 } D \text{ 内} \\
u = f & \text{在 } \partial D \text{ 上}
\end{cases}$$

**解法**：
1. 构造保角映射 $\phi: D \to \mathbb{H}$（上半平面）
2. 复合映射 $u(z) = v(\phi(z))$，其中 $v$ 在 $\mathbb{H}$ 内调和
3. 利用泊松公式求解 $v$

### 6.5.2 流体力学应用

**复势**：若 $f(z) = \phi(x,y) + i\psi(x,y)$，其中 $\phi$ 为速度势，$\psi$ 为流函数。

**保角映射的应用**：
- 复杂边界问题转化为简单边界问题
- 保角映射保持流线的角度关系

### 6.5.3 电磁场应用

**共形映射在电磁场中的应用**：
- 静电场的边界值问题
- 传输线的特性分析
- 天线辐射模式的计算

## 1. 傅里叶级数

### 1.1 三角级数形式

**定义（周期函数的三角级数展开）**：

设函数 $f(x)$ 在区间 $[-\pi, \pi]$ 上可积，则它可以展开为三角级数：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx)$$

其中傅里叶系数为：

$$a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx \, dx \quad (n = 0, 1, 2, \ldots)$$

$$b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx \, dx \quad (n = 1, 2, 3, \ldots)$$

### 1.2 复数形式

**复数形式的傅里叶级数**：

利用欧拉公式 $e^{inx} = \cos nx + i \sin nx$，三角级数可以写成复数形式：

$$f(x) = \sum_{n=-\infty}^{\infty} c_n e^{inx}$$

其中复数傅里叶系数为：

$$c_n = \frac{1}{2\pi} \int_{-\pi}^{\pi} f(x) e^{-inx} \, dx \quad (n = 0, \pm1, \pm2, \ldots)$$

**复数形式与三角形式的关系**：

$$c_0 = \frac{a_0}{2}, \quad c_n = \frac{a_n - ib_n}{2}, \quad c_{-n} = \frac{a_n + ib_n}{2} \quad (n = 1, 2, 3, \ldots)$$

### 1.3 收敛性定理

<details>
<summary><strong>定理7.1 狄利克雷收敛定理</strong></summary>

**定理内容**：
如果函数 $f(x)$ 在区间 $[-\pi, \pi]$ 上满足：
1. 连续或只有有限个第一类间断点
2. 只有有限个极值点

则 $f(x)$ 的傅里叶级数在每一点 $x$ 处收敛，且：
- 在连续点处，级数和等于 $f(x)$
- 在间断点处，级数和等于 $\frac{f(x^+) + f(x^-)}{2}$

**证明思路**：
利用三角函数系的正交性和贝塞尔不等式，结合部分和的积分表示，通过狄利克雷核的性质进行证明。
</details>

<details>
<summary><strong>定理7.2 帕塞瓦尔等式</strong></summary>

**定理内容**：
如果 $f(x)$ 在 $[-\pi, \pi]$ 上平方可积，则：

$$\frac{1}{\pi} \int_{-\pi}^{\pi} [f(x)]^2 \, dx = \frac{a_0^2}{2} + \sum_{n=1}^{\infty} (a_n^2 + b_n^2)$$

或等价地：

$$\frac{1}{2\pi} \int_{-\pi}^{\pi} [f(x)]^2 \, dx = \sum_{n=-\infty}^{\infty} |c_n|^2$$

**证明思路**：
利用傅里叶级数的部分和与原函数的平方误差，通过正交性计算内积并取极限。
</details>

### 1.4 常用函数的傅里叶级数

|------|------------|--------|
| $f(x) = x$ ($-\pi < x < \pi$) | $2\sum_{n=1}^{\infty} \frac{(-1)^{n+1}}{n} \sin nx$ | $(-\pi, \pi)$ |

| $f(x) = \begin{cases} 1, & 0 < x < \pi \\ -1, & -\pi < x < 0 \end{cases}$ | $\frac{4}{\pi} \sum_{n=1,3,5,\ldots}^{\infty} \frac{1}{n} \sin nx$ | $(-\pi, 0) \cup (0, \pi)$ |

## 2. 傅里叶变换的定义与性质

### 2.1 傅里叶变换的定义

**定义（傅里叶变换）**：

设函数 $f(t)$ 在 $(-\infty, +\infty)$ 上绝对可积，即 $\int_{-\infty}^{+\infty} |f(t)| \, dt < \infty$，则 $f(t)$ 的傅里叶变换定义为：

$$\mathcal{F}[f(t)] = F(\omega) = \int_{-\infty}^{+\infty} f(t) e^{-i\omega t} \, dt$$

其逆变换为：

$$\mathcal{F}^{-1}[F(\omega)] = f(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} F(\omega) e^{i\omega t} \, d\omega$$

其中：
- $f(t)$ 称为原函数或时域函数
- $F(\omega)$ 称为像函数或频域函数
- $\omega$ 为角频率

### 2.2 傅里叶变换的基本性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $af(t) + bg(t)$ | $aF(\omega) + bG(\omega)$ |
| **时移** | $f(t-t_0)$ | $F(\omega)e^{-i\omega t_0}$ |
| **频移** | $f(t)e^{i\omega_0 t}$ | $F(\omega-\omega_0)$ |
| **尺度变换** | $f(at)$ | $\frac{1}{\|a\|}F(\frac{\omega}{a})$ |
| **微分** | $f'(t)$ | $i\omega F(\omega)$ |
| **积分** | $\int_{-\infty}^{t} f(\tau)d\tau$ | $\frac{F(\omega)}{i\omega} + \pi F(0)\delta(\omega)$ |
| **共轭** | $\overline{f(t)}$ | $\overline{F(-\omega)}$ |
| **时间反转** | $f(-t)$ | $F(-\omega)$ |

### 2.3 常用变换对

| 原函数 $f(t)$ | 傅里叶变换 $F(\omega)$ |
|---------------|------------------------|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| $e^{-at}u(t)$ $(a>0)$ | $\frac{1}{a+i\omega}$ |
| $e^{-a\|t\|}$ $(a>0)$ | $\frac{2a}{a^2+\omega^2}$ |
| $\text{rect}(t)$ | $\text{sinc}(\frac{\omega}{2})$ |
| $\text{sinc}(t)$ | $\pi \text{rect}(\frac{\omega}{2})$ |
| $e^{-\pi t^2}$ | $e^{-\pi \omega^2}$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega-\omega_0) + \delta(\omega+\omega_0)]$ |
| $\sin(\omega_0 t)$ | $i\pi[\delta(\omega+\omega_0) - \delta(\omega-\omega_0)]$ |

其中：
- $\text{rect}(t) = \begin{cases} 1, & |t| < \frac{1}{2} \\ 0, & |t| > \frac{1}{2} \end{cases}$
- $\text{sinc}(t) = \frac{\sin(\pi t)}{\pi t}$

### 2.4 卷积定理

<details>
<summary><strong>定理7.3 时域卷积定理</strong></summary>

**定理内容**：
如果 $f(t)$ 和 $g(t)$ 的傅里叶变换分别为 $F(\omega)$ 和 $G(\omega)$，则：

$$\mathcal{F}[f(t) * g(t)] = F(\omega) \cdot G(\omega)$$

其中卷积定义为：
$$(f * g)(t) = \int_{-\infty}^{+\infty} f(\tau)g(t-\tau) \, d\tau$$

**证明**：
$$\begin{align*}
\mathcal{F}[f * g] &= \int_{-\infty}^{+\infty} \left[\int_{-\infty}^{+\infty} f(\tau)g(t-\tau) \, d\tau\right] e^{-i\omega t} dt \\
&= \int_{-\infty}^{+\infty} f(\tau) \left[\int_{-\infty}^{+\infty} g(t-\tau) e^{-i\omega t} dt\right] d\tau \\
&= \int_{-\infty}^{+\infty} f(\tau) e^{-i\omega \tau} \left[\int_{-\infty}^{+\infty} g(u) e^{-i\omega u} du\right] d\tau \\
&= F(\omega) \cdot G(\omega)
\end{align*}$$
</details>

<details>
<summary><strong>定理7.4 频域卷积定理</strong></summary>

**定理内容**：
$$\mathcal{F}[f(t) \cdot g(t)] = \frac{1}{2\pi} F(\omega) * G(\omega)$$

其中频域卷积定义为：
$$(F * G)(\omega) = \int_{-\infty}^{+\infty} F(\Omega)G(\omega-\Omega) \, d\Omega$$

**证明**：
利用傅里叶变换的对偶性和时域卷积定理。
</details>

### 2.5 帕塞瓦尔定理

<details>
<summary><strong>定理7.5 帕塞瓦尔定理</strong></summary>

**定理内容**：
如果 $f(t)$ 和 $g(t)$ 的傅里叶变换分别为 $F(\omega)$ 和 $G(\omega)$，则：

$$\int_{-\infty}^{+\infty} f(t)\overline{g(t)} \, dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} F(\omega)\overline{G(\omega)} \, d\omega$$

特别地，当 $f(t) = g(t)$ 时：

$$\int_{-\infty}^{+\infty} |f(t)|^2 \, dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |F(\omega)|^2 \, d\omega$$

**物理意义**：时域能量等于频域能量（相差因子 $2\pi$）
</details>

## 3. 傅里叶变换的应用

### 3.1 信号处理中的应用

#### 3.1.1 频谱分析

![傅里叶变换频谱分析](imgs/fourier-transform-frequency-spectrum-analysis-diagram.jpg)
*图7-1: 傅里叶变换的时域-频域对应关系*

**定义（频谱）**：
信号 $f(t)$ 的频谱定义为 $|F(\omega)|$，相位谱定义为 $\arg F(\omega)$。

**功率谱密度**：
$$S(\omega) = \frac{|F(\omega)|^2}{2\pi}$$

**频谱分析的意义：**
- **时域分析**：信号随时间的变化
- **频域分析**：信号包含的频率成分
- **频谱图**：显示各频率分量的幅度和相位信息

#### 3.1.2 滤波

**理想低通滤波器**：
$$H(\omega) = \begin{cases}
1, & |\omega| < \omega_c \\
0, & |\omega| > \omega_c
\end{cases}$$

**滤波过程**：
$$Y(\omega) = H(\omega)X(\omega)$$

#### 3.1.3 采样定理

<details>
<summary><strong>定理7.6 奈奎斯特采样定理</strong></summary>

**定理内容**：
如果信号 $f(t)$ 的频谱 $F(\omega)$ 满足 $F(\omega) = 0$ 对于 $|\omega| > \omega_m$，那么当采样频率 $\omega_s > 2\omega_m$ 时，信号可以完全从其采样值恢复。

**重建公式**：
$$f(t) = \sum_{n=-\infty}^{\infty} f(nT) \cdot \text{sinc}\left(\frac{t-nT}{T}\right)$$

其中 $T = \frac{2\pi}{\omega_s}$ 为采样周期。
</details>

### 3.2 偏微分方程求解中的应用

#### 3.2.1 热传导方程

**问题**：求解热传导方程
$$\frac{\partial u}{\partial t} = a^2 \frac{\partial^2 u}{\partial x^2}, \quad x \in \mathbb{R}, t > 0$$

**解法**：
1. 对 $x$ 进行傅里叶变换：$U(\omega, t) = \mathcal{F}[u(x, t)]$
2. 变换后方程：$\frac{\partial U}{\partial t} = -a^2 \omega^2 U$
3. 解为：$U(\omega, t) = U(\omega, 0)e^{-a^2\omega^2 t}$
4. 逆变换得到解

**解**：
$$u(x, t) = \frac{1}{2a\sqrt{\pi t}} \int_{-\infty}^{+\infty} u(\xi, 0) e^{-\frac{(x-\xi)^2}{4a^2 t}} \, d\xi$$

#### 3.2.2 波动方程

**问题**：求解一维波动方程
$$\frac{\partial^2 u}{\partial t^2} = c^2 \frac{\partial^2 u}{\partial x^2}, \quad x \in \mathbb{R}, t > 0$$

**解法**：
1. 对 $x$ 进行傅里叶变换
2. 得到常微分方程：$\frac{\partial^2 U}{\partial t^2} + c^2\omega^2 U = 0$
3. 解为：$U(\omega, t) = A(\omega)e^{i c \omega t} + B(\omega)e^{-i c \omega t}$

#### 3.2.3 拉普拉斯方程

**问题**：求解拉普拉斯方程的边值问题
$$\nabla^2 u = 0, \quad (x, y) \in \mathbb{R}^2_+$$

**解法**：
1. 对 $x$ 进行傅里叶变换
2. 得到常微分方程：$\frac{d^2 U}{dy^2} - \omega^2 U = 0$
3. 解为：$U(\omega, y) = A(\omega)e^{|\omega|y} + B(\omega)e^{-|\omega|y}$

## 4. 快速傅里叶变换（FFT）

### 4.1 FFT算法原理

**问题背景**：
直接计算 $N$ 点离散傅里叶变换（DFT）需要 $O(N^2)$ 次运算，当 $N$ 很大时计算量巨大。

**DFT定义**：
$$X(k) = \sum_{n=0}^{N-1} x(n) e^{-i\frac{2\pi}{N}kn}, \quad k = 0, 1, \ldots, N-1$$

### 4.2 基2 FFT算法

**算法原理**：
将 $N$ 点DFT分解为两个 $N/2$ 点DFT，利用旋转因子的周期性。

**分解过程**：
$$X(k) = \sum_{n=0}^{N-1} x(n) W_N^{kn} = \sum_{n=0}^{N/2-1} x(n) W_N^{kn} + \sum_{n=N/2}^{N-1} x(n) W_N^{kn}$$

$$= \sum_{n=0}^{N/2-1} x(n) W_N^{kn} + \sum_{n=0}^{N/2-1} x(n+N/2) W_N^{k(n+N/2)}$$

$$= \sum_{n=0}^{N/2-1} [x(n) + x(n+N/2)W_N^{kN/2}] W_N^{kn}$$

其中 $W_N^{kN/2} = (-1)^k$，所以：

$$X(k) = \sum_{n=0}^{N/2-1} [x(n) + (-1)^k x(n+N/2)] W_N^{kn}$$

令：
- $x_1(n) = x(n) + x(n+N/2)$
- $x_2(n) = [x(n) - x(n+N/2)]W_N^{kn}$

则：
$$X(k) = \sum_{n=0}^{N/2-1} [x_1(n) + x_2(n)] W_N^{kn}$$

### 4.3 FFT算法流程

**蝶形运算**：
```
     x(n) --------+-------- x_1(n)
                  |
                  |  (-1)^k
                  |
     x(n+N/2) ----+-------- x_2(n)
```

**算法步骤**：
1. **分解**：将输入序列按奇偶位置重新排列
2. **计算**：进行 $\log_2 N$ 级蝶形运算
3. **合成**：得到最终的频域结果

### 4.4 FFT复杂度分析

**计算复杂度**：
- 直接DFT：$O(N^2)$ 次复数乘法
- FFT：$O(N \log_2 N)$ 次复数乘法

**加速比**：
$$\text{加速比} = \frac{N^2}{N \log_2 N} = \frac{N}{\log_2 N}$$

例如，当 $N = 1024$ 时，加速比约为 $\frac{1024}{10} = 102.4$

### 4.5 FFT的应用

| 应用领域 | 具体应用 |
|----------|----------|
| **数字信号处理** | 频谱分析、滤波器设计、信号检测 |
| **图像处理** | 图像压缩、图像滤波、特征提取 |
| **通信系统** | OFDM调制、信道估计、频偏校正 |
| **雷达系统** | 目标检测、速度估计、波形设计 |
| **音频处理** | 音乐分析、语音识别、噪声消除 |

### 4.6 实现注意事项

1. **输入长度**：通常要求 $N = 2^m$，如果不是需要补零
2. **数值稳定性**：注意浮点运算的精度问题
3. **内存管理**：合理安排数据存储顺序
4. **并行化**：利用多核处理器进行并行计算

## 8.1 拉普拉斯变换的定义

### 8.1.1 拉普拉斯变换的定义

**定义 8.1.1（拉普拉斯变换）**  
设函数 $f(t)$ 在 $t \geq 0$ 上有定义，如果积分
$$\mathcal{L}\{f(t)\} = F(s) = \int_0^{+\infty} f(t) e^{-st} dt$$
在复平面 $s = \sigma + j\omega$ 的某个区域内收敛，则称 $F(s)$ 为函数 $f(t)$ 的拉普拉斯变换，记为 $\mathcal{L}\{f(t)\}$。

其中：
- $s$ 为复变量，称为拉普拉斯变换的复频率
- $f(t)$ 称为原函数
- $F(s)$ 称为像函数

**拉普拉斯逆变换**  
如果 $F(s)$ 是 $f(t)$ 的拉普拉斯变换，则
$$f(t) = \mathcal{L}^{-1}\{F(s)\} = \frac{1}{2\pi j} \int_{\sigma-j\infty}^{\sigma+j\infty} F(s) e^{st} ds$$
称为拉普拉斯逆变换。

### 8.1.2 拉普拉斯变换的收敛域

**定义 8.1.2（收敛域）**  
拉普拉斯变换 $F(s)$ 收敛的复数 $s$ 的集合称为拉普拉斯变换的收敛域（ROC）。

对于函数 $f(t)$，存在实数 $\sigma_0$，使得：
- 当 $\text{Re}(s) > \sigma_0$ 时，积分 $\int_0^{+\infty} f(t) e^{-st} dt$ 收敛
- 当 $\text{Re}(s) < \sigma_0$ 时，积分发散

$\sigma_0$ 称为收敛横坐标。

### 8.1.3 拉普拉斯变换的存在条件

**定理 8.1.1（拉普拉斯变换存在定理）**  
如果函数 $f(t)$ 满足以下条件：
1. 在 $t \geq 0$ 的任何有限区间上分段连续
2. 存在常数 $M > 0$ 和 $\sigma_0$，使得 $|f(t)| \leq M e^{\sigma_0 t}$ 对所有 $t \geq 0$ 成立
3. $f(t)$ 在 $t = 0$ 处至多有第一类间断点

则 $f(t)$ 的拉普拉斯变换 $F(s)$ 在 $\text{Re}(s) > \sigma_0$ 的半平面内收敛且解析。

<details>
<summary>证明过程</summary>

**证明：**  
设 $s = \sigma + j\omega$，其中 $\sigma > \sigma_0$。

由于 $|f(t)| \leq M e^{\sigma_0 t}$，有
$$|f(t) e^{-st}| = |f(t) e^{-\sigma t} e^{-j\omega t}| \leq M e^{\sigma_0 t} e^{-\sigma t} = M e^{-(\sigma - \sigma_0)t}$$

当 $\sigma > \sigma_0$ 时，积分 $\int_0^{+\infty} e^{-(\sigma - \sigma_0)t} dt$ 收敛，因此
$$\int_0^{+\infty} |f(t) e^{-st}| dt \leq M \int_0^{+\infty} e^{-(\sigma - \sigma_0)t} dt < +\infty$$

根据绝对收敛判别法，拉普拉斯变换在 $\text{Re}(s) > \sigma_0$ 时收敛。

$\square$
</details>

## 8.2 拉普拉斯变换的性质

### 8.2.1 线性性质

**定理 8.2.1（线性性质）**  
设 $\mathcal{L}\{f_1(t)\} = F_1(s)$，$\mathcal{L}\{f_2(t)\} = F_2(s)$，则对任意常数 $a, b$，有
$$\mathcal{L}\{a f_1(t) + b f_2(t)\} = a F_1(s) + b F_2(s)$$

<details>
<summary>证明过程</summary>

**证明：**  
$$\mathcal{L}\{a f_1(t) + b f_2(t)\} = \int_0^{+\infty} [a f_1(t) + b f_2(t)] e^{-st} dt$$
$$= a \int_0^{+\infty} f_1(t) e^{-st} dt + b \int_0^{+\infty} f_2(t) e^{-st} dt$$
$$= a F_1(s) + b F_2(s)$$

$\square$
</details>

### 8.2.2 微分性质

**定理 8.2.2（微分性质）**  
设 $\mathcal{L}\{f(t)\} = F(s)$，则
$$\mathcal{L}\{f'(t)\} = s F(s) - f(0^+)$$

更一般地，
$$\mathcal{L}\{f^{(n)}(t)\} = s^n F(s) - s^{n-1}f(0^+) - s^{n-2}f'(0^+) - \cdots - f^{(n-1)}(0^+)$$

<details>
<summary>证明过程</summary>

**证明：**  
对 $f'(t)$ 进行拉普拉斯变换：
$$\mathcal{L}\{f'(t)\} = \int_0^{+\infty} f'(t) e^{-st} dt$$

使用分部积分法：
$$\int_0^{+\infty} f'(t) e^{-st} dt = [f(t)e^{-st}]_0^{+\infty} + s \int_0^{+\infty} f(t) e^{-st} dt$$

由于 $f(t)$ 满足增长条件，$\lim_{t \to +\infty} f(t)e^{-st} = 0$，因此：
$$\mathcal{L}\{f'(t)\} = -f(0^+) + s F(s) = s F(s) - f(0^+)$$

$\square$
</details>

### 8.2.3 积分性质

**定理 8.2.3（积分性质）**  
设 $\mathcal{L}\{f(t)\} = F(s)$，则
$$\mathcal{L}\left\{\int_0^t f(\tau) d\tau\right\} = \frac{F(s)}{s}$$

更一般地，
$$\mathcal{L}\left\{\int_0^t \int_0^{\tau_1} \cdots \int_0^{\tau_{n-1}} f(\tau_n) d\tau_n \cdots d\tau_1\right\} = \frac{F(s)}{s^n}$$

### 8.2.4 卷积定理

**定理 8.2.4（卷积定理）**  
设 $\mathcal{L}\{f_1(t)\} = F_1(s)$，$\mathcal{L}\{f_2(t)\} = F_2(s)$，则
$$\mathcal{L}\{f_1(t) * f_2(t)\} = F_1(s) F_2(s)$$

其中卷积定义为：
$$f_1(t) * f_2(t) = \int_0^t f_1(\tau) f_2(t-\tau) d\tau$$

<details>
<summary>证明过程</summary>

**证明：**  
$$f_1(t) * f_2(t) = \int_0^t f_1(\tau) f_2(t-\tau) d\tau$$

对卷积进行拉普拉斯变换：
$$\mathcal{L}\{f_1(t) * f_2(t)\} = \int_0^{+\infty} \left[\int_0^t f_1(\tau) f_2(t-\tau) d\tau\right] e^{-st} dt$$

交换积分次序（由Fubini定理保证）：
$$= \int_0^{+\infty} f_1(\tau) \left[\int_{\tau}^{+\infty} f_2(t-\tau) e^{-st} dt\right] d\tau$$

令 $u = t - \tau$，则：
$$= \int_0^{+\infty} f_1(\tau) e^{-s\tau} \left[\int_0^{+\infty} f_2(u) e^{-su} du\right] d\tau$$
$$= F_1(s) F_2(s)$$

$\square$
</details>

### 8.2.5 拉普拉斯变换性质汇总表

| 性质名称 | 原函数 | 像函数 |
|---------|--------|--------|
| 线性性质 | $a f_1(t) + b f_2(t)$ | $a F_1(s) + b F_2(s)$ |
| 微分性质 | $f'(t)$ | $s F(s) - f(0^+)$ |
| 积分性质 | $\int_0^t f(\tau) d\tau$ | $\frac{F(s)}{s}$ |
| 延时性质 | $f(t-a)u(t-a)$ | $e^{-as} F(s)$ |
| 位移性质 | $e^{at} f(t)$ | $F(s-a)$ |
| 尺度变换 | $f(at)$ | $\frac{1}{\|a\|} F(\frac{s}{a})$ |
| 卷积性质 | $f_1(t) * f_2(t)$ | $F_1(s) F_2(s)$ |

## 8.3 常用函数的拉普拉斯变换

### 8.3.1 基本函数变换对

| 原函数 $f(t)$ | 像函数 $F(s)$ | 收敛域 |
|-------------|-------------|--------|
| $\delta(t)$ | 1 | 全平面 |
| $u(t)$ | $\frac{1}{s}$ | $\text{Re}(s) > 0$ |
| $t^n u(t)$ | $\frac{n!}{s^{n+1}}$ | $\text{Re}(s) > 0$ |
| $e^{at} u(t)$ | $\frac{1}{s-a}$ | $\text{Re}(s) > \text{Re}(a)$ |
| $\sin(\omega t) u(t)$ | $\frac{\omega}{s^2 + \omega^2}$ | $\text{Re}(s) > 0$ |
| $\cos(\omega t) u(t)$ | $\frac{s}{s^2 + \omega^2}$ | $\text{Re}(s) > 0$ |
| $e^{at} \sin(\omega t) u(t)$ | $\frac{\omega}{(s-a)^2 + \omega^2}$ | $\text{Re}(s) > \text{Re}(a)$ |
| $e^{at} \cos(\omega t) u(t)$ | $\frac{s-a}{(s-a)^2 + \omega^2}$ | $\text{Re}(s) > \text{Re}(a)$ |

## 8.4 拉普拉斯逆变换

### 8.4.1 部分分式法

当像函数 $F(s)$ 是有理函数时，可以使用部分分式法求拉普拉斯逆变换。

**步骤：**
1. 将 $F(s)$ 化为真分式
2. 将分母分解为一次因子和二次因子的乘积
3. 将 $F(s)$ 展开为部分分式
4. 求每个部分分式的逆变换

**例题：** 求 $F(s) = \frac{s+3}{s(s+1)(s+2)}$ 的逆变换。

**解：**  
设 $\frac{s+3}{s(s+1)(s+2)} = \frac{A}{s} + \frac{B}{s+1} + \frac{C}{s+2}$

两边同乘 $s(s+1)(s+2)$：
$$s+3 = A(s+1)(s+2) + Bs(s+2) + Cs(s+1)$$

令 $s = 0$：$3 = A(1)(2) \Rightarrow A = \frac{3}{2}$  
令 $s = -1$：$2 = B(-1)(1) \Rightarrow B = -2$  
令 $s = -2$：$1 = C(-2)(-1) \Rightarrow C = \frac{1}{2}$

因此：
$$F(s) = \frac{3/2}{s} - \frac{2}{s+1} + \frac{1/2}{s+2}$$

逆变换为：
$$f(t) = \frac{3}{2} - 2e^{-t} + \frac{1}{2}e^{-2t}, \quad t \geq 0$$

### 8.4.2 留数法

**定理 8.4.1（拉普拉斯反演公式）**  
如果 $F(s)$ 在 $\text{Re}(s) > \sigma_0$ 内解析，且 $\lim_{s \to \infty} F(s) = 0$，则
$$f(t) = \frac{1}{2\pi j} \int_{\sigma-j\infty}^{\sigma+j\infty} F(s) e^{st} ds = \sum \text{Res}[F(s)e^{st}, s_k]$$

其中 $s_k$ 是 $F(s)$ 在左半平面的所有奇点。

**例题：** 求 $F(s) = \frac{1}{(s+1)^2(s+2)}$ 的逆变换。

**解：**  
奇点：$s = -1$（二阶极点），$s = -2$（一阶极点）

留数计算：
- 在 $s = -1$ 处：$\text{Res} = \frac{1}{1!} \lim_{s \to -1} \frac{d}{ds}[(s+1)^2 F(s) e^{st}]$
  $$= \lim_{s \to -1} \frac{d}{ds}\left[\frac{e^{st}}{s+2}\right] = \lim_{s \to -1} \frac{te^{st}(s+2) - e^{st}}{(s+2)^2}$$
  $$= \frac{te^{-t}(1) - e^{-t}}{(1)^2} = (t-1)e^{-t}$$

- 在 $s = -2$ 处：$\text{Res} = \lim_{s \to -2} (s+2) F(s) e^{st} = \lim_{s \to -2} \frac{e^{st}}{(s+1)^2} = e^{-2t}$

因此：
$$f(t) = (t-1)e^{-t} + e^{-2t} = e^{-2t} + (t-1)e^{-t}, \quad t \geq 0$$

## 8.5 拉普拉斯变换的应用

### 8.5.1 微分方程求解

拉普拉斯变换在求解线性微分方程中具有重要应用。

**求解步骤：**
1. 对微分方程两边进行拉普拉斯变换
2. 利用微分性质，将微分方程转化为代数方程
3. 求解代数方程，得到像函数 $F(s)$
4. 求 $F(s)$ 的逆变换，得到原微分方程的解

**例题：** 求解微分方程 $y'' + 3y' + 2y = e^{-t}$，初始条件 $y(0) = 1$，$y'(0) = 0$。

**解：**  
对方程两边进行拉普拉斯变换：
$$\mathcal{L}\{y''\} + 3\mathcal{L}\{y'\} + 2\mathcal{L}\{y\} = \mathcal{L}\{e^{-t}\}$$

利用微分性质：
$$[s^2 Y(s) - sy(0) - y'(0)] + 3[sY(s) - y(0)] + 2Y(s) = \frac{1}{s+1}$$

代入初始条件：
$$[s^2 Y(s) - s \cdot 1 - 0] + 3[sY(s) - 1] + 2Y(s) = \frac{1}{s+1}$$

整理得：
$$s^2 Y(s) - s + 3sY(s) - 3 + 2Y(s) = \frac{1}{s+1}$$

$$(s^2 + 3s + 2)Y(s) = s + 3 + \frac{1}{s+1}$$

$$Y(s) = \frac{s+3}{s^2 + 3s + 2} + \frac{1}{(s+1)(s^2 + 3s + 2)}$$

化简分母：$s^2 + 3s + 2 = (s+1)(s+2)$

$$Y(s) = \frac{s+3}{(s+1)(s+2)} + \frac{1}{(s+1)^2(s+2)}$$

使用部分分式法：
$$Y(s) = \frac{2}{s+1} - \frac{1}{s+2} + \frac{1}{(s+1)^2(s+2)}$$

对最后一项进行部分分式分解：
$$\frac{1}{(s+1)^2(s+2)} = \frac{A}{s+1} + \frac{B}{(s+1)^2} + \frac{C}{s+2}$$

解得：$A = -1$，$B = 1$，$C = 1$

$$Y(s) = \frac{2}{s+1} - \frac{1}{s+2} - \frac{1}{s+1} + \frac{1}{(s+1)^2} + \frac{1}{s+2}$$

$$Y(s) = \frac{1}{s+1} + \frac{1}{(s+1)^2}$$

逆变换：
$$y(t) = e^{-t} + t e^{-t} = (1 + t)e^{-t}, \quad t \geq 0$$

### 8.5.2 控制系统中的应用

在控制系统中，拉普拉斯变换用于分析系统的传递函数和稳定性。

**传递函数：**  
线性时不变系统的传递函数定义为输出与输入拉普拉斯变换的比值：
$$G(s) = \frac{Y(s)}{X(s)}$$

**系统稳定性：**  
系统稳定的充要条件是传递函数的所有极点（分母的根）都具有负的实部，即位于左半平面。

**例题：** 分析系统 $G(s) = \frac{1}{s^2 + 2s + 5}$ 的稳定性。

**解：**  
特征方程：$s^2 + 2s + 5 = 0$

根：$s = -1 \pm 2j$

由于所有极点都具有负实部，系统稳定。

### 8.5.3 电路分析中的应用

拉普拉斯变换在电路分析中用于求解动态电路的响应。

**基本元件的拉普拉斯变换模型：**

| 元件 | 时域关系 | 拉普拉斯变换 |
|------|----------|-------------|
| 电阻 $R$ | $v_R(t) = R i(t)$ | $V_R(s) = R I(s)$ |
| 电感 $L$ | $v_L(t) = L \frac{di(t)}{dt}$ | $V_L(s) = L[sI(s) - i(0^-)]$ |
| 电容 $C$ | $i_C(t) = C \frac{dv(t)}{dt}$ | $I_C(s) = C[sV(s) - v(0^-)]$ |

**例题：** RLC串联电路，$R = 2\Omega$，$L = 1H$，$C = 0.5F$，初始条件为零，输入电压 $v_i(t) = u(t)$，求输出电压 $v_C(t)$。

**解：**  
电路方程：
$$v_i(t) = R i(t) + L \frac{di(t)}{dt} + v_C(t)$$

其中 $i(t) = C \frac{dv_C(t)}{dt}$

拉普拉斯变换：
$$\frac{1}{s} = 2I(s) + sI(s) + V_C(s)$$

$$I(s) = 0.5s V_C(s)$$

代入：
$$\frac{1}{s} = 2(0.5s V_C(s)) + s(0.5s V_C(s)) + V_C(s)$$

$$\frac{1}{s} = s V_C(s) + 0.5s^2 V_C(s) + V_C(s)$$

$$\frac{1}{s} = V_C(s)(0.5s^2 + s + 1)$$

$$V_C(s) = \frac{1}{s(0.5s^2 + s + 1)} = \frac{2}{s(s^2 + 2s + 2)}$$

逆变换：
$$v_C(t) = 1 - e^{-t}(\cos t + \sin t), \quad t \geq 0$$

# 第九章 Z变换

## 9.1 Z变换的定义

### 9.1.1 Z变换的定义

对于离散时间序列 $x[n]$，其**双边Z变换**定义为：

$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n]z^{-n}$$

其中 $z$ 是复变量，通常表示为 $z = re^{j\omega}$。

**单边Z变换**定义为：

$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=0}^{\infty} x[n]z^{-n}$$

### 9.1.2 收敛域（ROC）

![Z变换收敛域](imgs/z-transform-sequences-poles-region-of-convergence-diagram.jpg)
*图9-1: Z变换的收敛域(ROC)和零极点图*

Z变换的**收敛域**是使无穷级数绝对收敛的 $z$ 值集合：

$$ROC = \{z : \sum_{n=-\infty}^{\infty} |x[n]z^{-n}| < \infty\}$$

#### 收敛域的性质：

1. **ROC是环状区域**：ROC在z平面上是一个环形区域（双边Z变换）或圆外/圆内区域（单边Z变换）
2. **ROC内不包含极点**：ROC内不能包含 $X(z)$ 的任何极点
3. **有限长序列**：ROC是整个z平面（除去可能的 $z=0$ 或 $z=\infty$）
4. **右边序列**：ROC是某个圆的外部区域
5. **左边序列**：ROC是某个圆的内部区域
6. **双边序列**：ROC是环形区域

**收敛域的图形表示：**
- **极点位置**：用×标记
- **零点位置**：用○标记  
- **ROC区域**：用阴影区域表示
- **单位圆**：$|z| = 1$（系统稳定性判断）

### 9.1.3 存在条件

Z变换存在的充分必要条件是：

$$\sum_{n=-\infty}^{\infty} |x[n]z^{-n}| < \infty$$

对于右边序列 $x[n] = 0, n < n_0$：

$$\sum_{n=n_0}^{\infty} |x[n]||z|^{-n} < \infty$$

这要求 $|z| > \lim_{n \to \infty} \sqrt[n]{|x[n]|}$

## 9.2 Z变换的性质

### 9.2.1 线性性质

如果：
$$X_1(z) = \mathcal{Z}\{x_1[n]\}, \quad ROC = R_1$$
$$X_2(z) = \mathcal{Z}\{x_2[n]\}, \quad ROC = R_2$$

则：
$$\mathcal{Z}\{a x_1[n] + b x_2[n]\} = a X_1(z) + b X_2(z)$$

ROC是 $R_1 \cap R_2$（可能需要去掉极点）

<details>
<summary><strong>证明：</strong></summary>

$$\mathcal{Z}\{a x_1[n] + b x_2[n]\} = \sum_{n=-\infty}^{\infty} [a x_1[n] + b x_2[n]]z^{-n}$$
$$= a \sum_{n=-\infty}^{\infty} x_1[n]z^{-n} + b \sum_{n=-\infty}^{\infty} x_2[n]z^{-n}$$
$$= a X_1(z) + b X_2(z)$$

证毕。
</details>

### 9.2.2 移位性质

#### 右移位（延迟）：
$$\mathcal{Z}\{x[n-k]\} = z^{-k}X(z), \quad k > 0$$

ROC与 $X(z)$ 相同，可能增加 $z=0$（若 $k > 0$）或 $z=\infty$（若 $k < 0$）

#### 左移位（超前）：
$$\mathcal{Z}\{x[n+k]\} = z^{k}X(z) - \sum_{m=0}^{k-1} x[m]z^{k-m}, \quad k > 0$$

<details>
<summary><strong>证明（右移位）：</strong></summary>

$$\mathcal{Z}\{x[n-k]\} = \sum_{n=-\infty}^{\infty} x[n-k]z^{-n}$$
令 $m = n-k$，则：
$$= \sum_{m=-\infty}^{\infty} x[m]z^{-(m+k)} = z^{-k} \sum_{m=-\infty}^{\infty} x[m]z^{-m} = z^{-k}X(z)$$

证毕。
</details>

### 9.2.3 尺度变换性质

如果 $X(z) = \mathcal{Z}\{x[n]\}$，ROC为 $R$，则：

$$\mathcal{Z}\{a^n x[n]\} = X\left(\frac{z}{a}\right)$$

ROC为 $|a|R = \{z : \frac{z}{a} \in R\}$

### 9.2.4 时间反转性质

$$\mathcal{Z}\{x[-n]\} = X\left(\frac{1}{z}\right)$$

ROC为 $\{z : \frac{1}{z} \in R\}$，即 $R$ 的倒数变换

### 9.2.5 差分性质

#### 一阶后向差分：
$$\mathcal{Z}\{\nabla x[n]\} = \mathcal{Z}\{x[n] - x[n-1]\} = (1 - z^{-1})X(z)$$

#### 一阶前向差分：
$$\mathcal{Z}\{\Delta x[n]\} = \mathcal{Z}\{x[n+1] - x[n]\} = (z - 1)X(z) - z x[0]$$

### 9.2.6 卷积定理

如果：
$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]h[n-k]$$

则：
$$Y(z) = X(z)H(z)$$

ROC是 $R_x \cap R_h$（可能去掉极点）

<details>
<summary><strong>证明：</strong></summary>

$$Y(z) = \mathcal{Z}\{x[n] * h[n]\} = \sum_{n=-\infty}^{\infty} \left[\sum_{k=-\infty}^{\infty} x[k]h[n-k]\right]z^{-n}$$
$$= \sum_{k=-\infty}^{\infty} x[k] \sum_{n=-\infty}^{\infty} h[n-k]z^{-n}$$
令 $m = n-k$，则：
$$= \sum_{k=-\infty}^{\infty} x[k]z^{-k} \sum_{m=-\infty}^{\infty} h[m]z^{-m} = X(z)H(z)$$

证毕。
</details>

### 9.2.7 初值定理

对于右边序列（$x[n] = 0, n < 0$）：
$$x[0] = \lim_{z \to \infty} X(z)$$

如果 $x[n]$ 是因果序列，且 $x[1], x[2], \ldots$ 存在：
$$x[1] = \lim_{z \to \infty} [z(X(z) - x[0])]$$

### 9.2.8 终值定理

如果 $X(z)$ 的所有极点都在单位圆内（$|z| = 1$ 内），或在 $z = 1$ 处只有一阶极点，则：

$$\lim_{n \to \infty} x[n] = \lim_{z \to 1} (z-1)X(z)$$

<details>
<summary><strong>证明：</strong></summary>

考虑 $(z-1)X(z)$ 的留数：
$$(z-1)X(z) = \sum_{k} \text{Res}[X(z), p_k] + \text{Res}[X(z), 1]$$

其中 $p_k$ 是除 $z=1$ 外的所有极点。

当 $z \to 1$ 时：
$$(z-1)X(z) \to \text{Res}[X(z), 1] = \sum_{n=0}^{\infty} x[n] = \lim_{n \to \infty} \sum_{k=0}^{n} x[k]$$

由Z变换定义和终值定理的条件可得：
$$\lim_{n \to \infty} x[n] = \lim_{z \to 1} (z-1)X(z)$$

证毕。
</details>

## 9.3 常用Z变换对

| 序列 $x[n]$ | Z变换 $X(z)$ | ROC |
|-------------|-------------|-----|
| $\delta[n]$ | $1$ | 整个z平面 |
| $\delta[n-k]$ | $z^{-k}$ | $z \neq 0$（若 $k > 0$）|
| $u[n]$ | $\frac{1}{1-z^{-1}}$ | $\|z\| > 1$ |
| $-u[-n-1]$ | $\frac{1}{1-z^{-1}}$ | $\|z\| < 1$ |
| $a^n u[n]$ | $\frac{1}{1-az^{-1}}$ | $\|z\| > \|a\|$ |
| $-a^n u[-n-1]$ | $\frac{1}{1-az^{-1}}$ | $\|z\| < \|a\|$ |
| $n a^n u[n]$ | $\frac{az^{-1}}{(1-az^{-1})^2}$ | $\|z\| > \|a\|$ |
| $\cos(\omega_0 n) u[n]$ | $\frac{1 - \cos(\omega_0)z^{-1}}{1 - 2\cos(\omega_0)z^{-1} + z^{-2}}$ | $\|z\| > 1$ |
| $\sin(\omega_0 n) u[n]$ | $\frac{\sin(\omega_0)z^{-1}}{1 - 2\cos(\omega_0)z^{-1} + z^{-2}}$ | $\|z\| > 1$ |

## 9.4 Z逆变换

Z逆变换定义为：
$$x[n] = \mathcal{Z}^{-1}\{X(z)\} = \frac{1}{2\pi j} \oint_C X(z)z^{n-1}dz$$

其中 $C$ 是包围ROC的闭合积分路径。

### 9.4.1 部分分式展开法

当 $X(z)$ 是有理函数时，可表示为：
$$X(z) = \frac{N(z)}{D(z)} = \frac{b_m z^m + b_{m-1}z^{m-1} + \cdots + b_0}{a_n z^n + a_{n-1}z^{n-1} + \cdots + a_0}$$

**步骤：**
1. 将 $X(z)$ 表示为 $z^{-1}$ 的多项式比
2. 进行部分分式展开
3. 求每一项的逆Z变换

**示例：**
$$X(z) = \frac{1}{(1-z^{-1})(1-2z^{-1})}$$

展开为：
$$X(z) = \frac{A}{1-z^{-1}} + \frac{B}{1-2z^{-1}}$$

求得：$A = -1$，$B = 2$

$$X(z) = -\frac{1}{1-z^{-1}} + \frac{2}{1-2z^{-1}}$$

逆变换：
$$x[n] = -u[n] + 2 \cdot 2^n u[n] = (-1 + 2^{n+1})u[n]$$

### 9.4.2 幂级数展开法

将 $X(z)$ 展开为 $z^{-1}$ 的幂级数：
$$X(z) = \sum_{n=-\infty}^{\infty} c_n z^{-n}$$

则 $x[n] = c_n$

**示例：**
$$X(z) = \frac{1}{1-z^{-1}} = \sum_{n=0}^{\infty} z^{-n}$$

所以 $x[n] = u[n]$

### 9.4.3 留数法

根据留数定理：
$$x[n] = \sum_{k} \text{Res}[X(z)z^{n-1}, p_k]$$

其中 $p_k$ 是被积函数在ROC内的极点。

**一阶极点留数：**
$$\text{Res}[F(z), p_k] = \lim_{z \to p_k} (z-p_k)F(z)$$

**m阶极点留数：**
$$\text{Res}[F(z), p_k] = \frac{1}{(m-1)!} \lim_{z \to p_k} \frac{d^{m-1}}{dz^{m-1}}[(z-p_k)^m F(z)]$$

## 9.5 Z变换在离散系统中的应用

### 9.5.1 差分方程求解

考虑线性常系数差分方程：
$$\sum_{k=0}^{N} a_k y[n-k] = \sum_{m=0}^{M} b_m x[n-m]$$

**求解步骤：**
1. 对差分方程两边进行Z变换
2. 利用移位性质和线性性质
3. 解出 $Y(z)$
4. 进行Z逆变换得到 $y[n]$

**示例：**
求解 $y[n] - 0.5y[n-1] = x[n]$，其中 $x[n] = u[n]$，$y[-1] = 0$

**解：**
1. Z变换：
$$Y(z) - 0.5z^{-1}Y(z) = X(z)$$

2. 解出 $Y(z)$：
$$Y(z) = \frac{X(z)}{1-0.5z^{-1}}$$

3. $X(z) = \frac{1}{1-z^{-1}}$，代入：
$$Y(z) = \frac{1}{(1-z^{-1})(1-0.5z^{-1})}$$

4. 部分分式展开：
$$Y(z) = \frac{2}{1-z^{-1}} - \frac{1}{1-0.5z^{-1}}$$

5. 逆变换：
$$y[n] = (2 - 0.5^n)u[n]$$

### 9.5.2 系统函数与频率响应

**系统函数定义为：**
$$H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^{M} b_k z^{-k}}{\sum_{k=0}^{N} a_k z^{-k}}$$

**频率响应：**
$$H(e^{j\omega}) = H(z)|_{z=e^{j\omega}} = \frac{\sum_{k=0}^{M} b_k e^{-jk\omega}}{\sum_{k=0}^{N} a_k e^{-jk\omega}}$$

### 9.5.3 数字滤波器设计

#### 9.5.3.1 IIR滤波器设计

**巴特沃斯低通滤波器：**
$$|H(e^{j\omega})|^2 = \frac{1}{1 + (\omega_c/\omega)^{2N}}$$

其中 $N$ 是滤波器阶数，$\omega_c$ 是截止频率。

**双线性变换法：**
$$s = \frac{2}{T} \frac{1-z^{-1}}{1+z^{-1}}$$

将模拟滤波器 $H_a(s)$ 转换为数字滤波器 $H(z)$：
$$H(z) = H_a\left(\frac{2}{T} \frac{1-z^{-1}}{1+z^{-1}}\right)$$

#### 9.5.3.2 FIR滤波器设计

**窗函数法：**
理想频率响应 $H_d(e^{j\omega})$ 的单位脉冲响应：
$$h_d[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} H_d(e^{j\omega})e^{j\omega n}d\omega$$

实际滤波器：
$$h[n] = h_d[n] \cdot w[n]$$

其中 $w[n]$ 是窗函数。

**常用窗函数：**

| 窗函数 | 表达式 | 主瓣宽度 | 旁瓣衰减 |
|--------|--------|----------|----------|
| 矩形窗 | $w[n] = 1$ | $4\pi/N$ | -13dB |
| 汉宁窗 | $w[n] = 0.5(1-\cos(2\pi n/(N-1)))$ | $8\pi/N$ | -31dB |
| 汉明窗 | $w[n] = 0.54-0.46\cos(2\pi n/(N-1))$ | $8\pi/N$ | -41dB |
| 布莱克曼窗 | $w[n] = 0.42-0.5\cos(2\pi n/(N-1)) + 0.08\cos(4\pi n/(N-1))$ | $12\pi/N$ | -58dB |

### 9.5.4 系统稳定性分析

**稳定性条件：**
- 连续系统：所有极点位于左半s平面
- 离散系统：所有极点位于单位圆内（$|z| < 1$）

**BIBO稳定性：**
系统是BIBO稳定的当且仅当：
$$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$$

在Z域中，这等价于ROC包含单位圆 $|z| = 1$。

### 9.5.5 状态空间分析

**状态方程：**
$$\begin{cases}
\mathbf{x}[n+1] = \mathbf{A}\mathbf{x}[n] + \mathbf{B}\mathbf{u}[n] \\
\mathbf{y}[n] = \mathbf{C}\mathbf{x}[n] + \mathbf{D}\mathbf{u}[n]
\end{cases}$$

**系统矩阵：**
$$\mathbf{H}(z) = \mathbf{C}(z\mathbf{I} - \mathbf{A})^{-1}\mathbf{B} + \mathbf{D}$$

**特征多项式：**
$$\det(z\mathbf{I} - \mathbf{A}) = 0$$

系统稳定的条件是所有特征值位于单位圆内。
