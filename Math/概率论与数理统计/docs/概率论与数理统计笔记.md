## 1. 概率论基础

### 1.1 随机事件与样本空间

#### 基本概念

**样本空间（Sample Space）**：随机试验的所有可能结果组成的集合，记为 $\Omega$。

**随机事件（Random Event）**：样本空间的子集，记为 $A, B, C, \ldots$

**基本事件（Elementary Event）**：只包含一个样本点的单点集。

**必然事件（Certain Event）**：样本空间 $\Omega$ 本身。

**不可能事件（Impossible Event）**：空集 $\emptyset$。

#### 事件的关系与运算

| 关系 | 记号 | 含义 | 韦恩图表示 |
|------|------|------|------------|
| 包含 | $A \subseteq B$ | A发生则B一定发生 | A在B内 |
| 相等 | $A = B$ | A与B同时发生或同时不发生 | 完全重合 |
| 并集 | $A \cup B$ | A或B至少有一个发生 | 两圆合并 |
| 交集 | $A \cap B$ | A与B同时发生 | 两圆重叠 |
| 差集 | $A - B$ | A发生但B不发生 | A内B外部分 |
| 互斥 | $A \cap B = \emptyset$ | A与B不能同时发生 | 两圆分离 |
| 对立 | $A \cup B = \Omega$ 且 $A \cap B = \emptyset$ | A与B互斥且必有一个发生 | 两圆分离且合并为全集 |

#### 📊 事件关系图示

```

    ┌─────────────────┐

    │  ┌─────────┐    │
    │  │    A    │    │

    ┌─────────────────┐

    ┌─────────┐ ┌─────────┐

    └─────────────────┘
```

**运算律**：
- 交换律：$A \cup B = B \cup A$，$A \cap B = B \cap A$
- 结合律：$(A \cup B) \cup C = A \cup (B \cup C)$，$(A \cap B) \cap C = A \cap (B \cap C)$
- 分配律：$(A \cup B) \cap C = (A \cap C) \cup (B \cap C)$，$(A \cap B) \cup C = (A \cup C) \cap (B \cup C)$
- 德摩根律：$\overline{A \cup B} = \overline{A} \cap \overline{B}$，$\overline{A \cap B} = \overline{A} \cup \overline{B}$

### 1.2 概率的定义与性质

#### 概率的公理化定义

设 $\Omega$ 为样本空间，若对每一个事件 $A$，都有一个实数 $P(A)$ 与之对应，且满足：

1. **非负性**：$P(A) \geq 0$
2. **规范性**：$P(\Omega) = 1$
3. **可列可加性**：若 $A_1, A_2, \ldots, A_n, \ldots$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

则称 $P(A)$ 为事件 $A$ 的概率。

#### 概率的基本性质

1. **不可能事件的概率**：$P(\emptyset) = 0$
2. **有限可加性**：若 $A_1, A_2, \ldots, A_n$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$
3. **对立事件概率**：$P(\overline{A}) = 1 - P(A)$
4. **单调性**：若 $A \subseteq B$，则 $P(A) \leq P(B)$
5. **加法公式**：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$

#### 古典概型

当样本空间 $\Omega$ 包含有限个基本事件，且每个基本事件发生的可能性相等时：

$$P(A) = \frac{\text{事件A包含的基本事件数}}{\text{基本事件总数}} = \frac{m}{n}$$

**典型例题**：
- 掷骰子、抽球问题
- 生日问题
- 抽签问题

### 1.3 条件概率与乘法公式

#### 条件概率

在事件 $B$ 发生的条件下，事件 $A$ 发生的概率称为条件概率：

$$P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

<details>
<summary><strong>条件概率推导</strong></summary>

考虑样本空间 $\Omega$，事件 $B$ 的基本事件数为 $n_B$，事件 $A \cap B$ 的基本事件数为 $n_{AB}$。

在 $B$ 发生的条件下，样本空间缩减为 $B$，此时 $A$ 发生的概率为：
$$P(A|B) = \frac{n_{AB}}{n_B} = \frac{\frac{n_{AB}}{n_\Omega}}{\frac{n_B}{n_\Omega}} = \frac{P(A \cap B)}{P(B)}$$

其中 $n_\Omega$ 为样本空间总的基本事件数。
</details>

#### 乘法公式

由条件概率公式可得：
$$P(A \cap B) = P(A)P(B|A) = P(B)P(A|B)$$

**推广到多个事件**：
$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 \cap A_2) \cdots P(A_n|A_1 \cap \cdots \cap A_{n-1})$$

### 1.4 全概率公式与贝叶斯公式

#### 全概率公式

设 $B_1, B_2, \ldots, B_n$ 是样本空间 $\Omega$ 的一个划分（互斥且完备），则对任意事件 $A$：

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$

<details>
<summary><strong>全概率公式推导</strong></summary>

因为 $B_1, B_2, \ldots, B_n$ 是样本空间的划分，所以：
$$A = A \cap \Omega = A \cap \left(\bigcup_{i=1}^{n} B_i\right) = \bigcup_{i=1}^{n} (A \cap B_i)$$

由于 $B_i$ 两两互斥，故 $A \cap B_i$ 也两两互斥。由概率的可列可加性：
$$P(A) = P\left(\bigcup_{i=1}^{n} (A \cap B_i)\right) = \sum_{i=1}^{n} P(A \cap B_i)$$

再由乘法公式 $P(A \cap B_i) = P(B_i)P(A|B_i)$，可得：
$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$
</details>

#### 贝叶斯公式

在上述条件下：
$$P(B_j|A) = \frac{P(B_j)P(A|B_j)}{P(A)} = \frac{P(B_j)P(A|B_j)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)}$$

其中：
- $P(B_i)$ 称为**先验概率**
- $P(A|B_i)$ 称为**似然函数**
- $P(B_i|A)$ 称为**后验概率**

<details>
<summary><strong>贝叶斯公式推导</strong></summary>

由条件概率定义：
$$P(B_j|A) = \frac{P(B_j \cap A)}{P(A)}$$

分子：$P(B_j \cap A) = P(B_j)P(A|B_j)$（乘法公式）
分母：$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$（全概率公式）

因此：
$$P(B_j|A) = \frac{P(B_j)P(A|B_j)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)}$$
</details>

**典型应用场景**：
- 医学诊断（疾病检测）
- 垃圾邮件过滤
- 机器学习中的朴素贝叶斯分类器

## 2. 随机变量及其分布

### 2.1 随机变量的概念

**随机变量（Random Variable）**：定义在样本空间 $\Omega$ 上的实值函数 $X = X(\omega)$，其中 $\omega \in \Omega$。

**分类**：
- **离散型随机变量**：取值有限个或可列无限个
- **连续型随机变量**：取值充满某个区间或整个实数轴

### 2.2 离散型随机变量

#### 概率分布律

设 $X$ 为离散型随机变量，其可能取值为 $x_1, x_2, \ldots, x_n, \ldots$，则：

$$P(X = x_k) = p_k, \quad k = 1, 2, \ldots$$

满足：
1. $p_k \geq 0$（非负性）
2. $\sum_{k=1}^{\infty} p_k = 1$（归一性）

#### 分布函数

$$F(x) = P(X \leq x) = \sum_{x_k \leq x} p_k$$

**性质**：
1. $0 \leq F(x) \leq 1$
2. $F(x)$ 单调非减
3. $F(x)$ 右连续
4. $\lim_{x \to -\infty} F(x) = 0$，$\lim_{x \to +\infty} F(x) = 1$

#### 常见离散分布

| 分布名称 | 概率分布 | 参数 | 期望 | 方差 | 应用场景 |
|----------|----------|------|------|------|----------|
| **二项分布** $B(n,p)$ | $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$ | $n, p$ | $np$ | $np(1-p)$ | n次独立重复试验 |
| **泊松分布** $P(\lambda)$ | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ | $\lambda$ | 稀有事件、单位时间内事件发生次数 |
| **几何分布** $Ge(p)$ | $P(X=k) = (1-p)^{k-1}p$ | $p$ | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ | 首次成功所需试验次数 |
| **超几何分布** $H(N,M,n)$ | $P(X=k) = \frac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}$ | $N,M,n$ | $\frac{nM}{N}$ | $\frac{nM(N-M)(N-n)}{N^2(N-1)}$ | 不放回抽样 |

**泊松定理**：当 $n$ 很大，$p$ 很小时，二项分布近似泊松分布：
$$\binom{n}{k}p^k(1-p)^{n-k} \approx \frac{\lambda^k e^{-\lambda}}{k!}, \quad \lambda = np$$

### 2.3 连续型随机变量

#### 概率密度函数

若存在非负函数 $f(x)$，使得对任意 $a \leq b$：
$$P(a \leq X \leq b) = \int_a^b f(x)dx$$

则称 $f(x)$ 为 $X$ 的概率密度函数。

**性质**：
1. $f(x) \geq 0$
2. $\int_{-\infty}^{+\infty} f(x)dx = 1$
3. 对任意 $x$，$P(X = x) = 0$
4. $P(a < X < b) = P(a \leq X \leq b) = \int_a^b f(x)dx$

#### 分布函数

$$F(x) = P(X \leq x) = \int_{-\infty}^x f(t)dt$$

且 $f(x) = F'(x)$（在 $F$ 可导点处）

#### 常见连续分布

| 分布名称 | 概率密度函数 | 参数 | 期望 | 方差 | 应用场景 |
|----------|--------------|------|------|------|----------|
| **均匀分布** $U(a,b)$ | $f(x) = \begin{cases}\frac{1}{b-a}, & a < x < b \\ 0, & \text{其他}\end{cases}$ | $a,b$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 几何概率、随机数生成 |
| **指数分布** $Exp(\lambda)$ | $f(x) = \begin{cases}\lambda e^{-\lambda x}, & x > 0 \\ 0, & x \leq 0\end{cases}$ | $\lambda$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | 寿命模型、等待时间 |
| **正态分布** $N(\mu,\sigma^2)$ | $f(x) = \frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu,\sigma$ | $\mu$ | $\sigma^2$ | 自然现象、测量误差 |
| **标准正态分布** $N(0,1)$ | $\phi(x) = \frac{1}{\sqrt{2\pi}}e^{-\frac{x^2}{2}}$ | - | 0 | 1 | 标准化、查表计算 |

#### 正态分布的重要性质

**标准化变换**：若 $X \sim N(\mu,\sigma^2)$，则 $Z = \frac{X-\mu}{\sigma} \sim N(0,1)$

**3σ原则**：
- $P(\mu-\sigma < X < \mu+\sigma) \approx 0.6826$
- $P(\mu-2\sigma < X < \mu+2\sigma) \approx 0.9544$
- $P(\mu-3\sigma < X < \mu+3\sigma) \approx 0.9974$

## 3. 多维随机变量

### 3.1 二维随机变量

#### 联合分布函数

$$F(x,y) = P(X \leq x, Y \leq y)$$

**性质**：
1. $0 \leq F(x,y) \leq 1$
2. $F(x,y)$ 对每个变量单调非减、右连续
3. $\lim_{x \to -\infty} F(x,y) = 0$，$\lim_{y \to -\infty} F(x,y) = 0$
4. $\lim_{x \to +\infty, y \to +\infty} F(x,y) = 1$

#### 离散型联合分布

$$P(X = x_i, Y = y_j) = p_{ij}$$

满足：
1. $p_{ij} \geq 0$
2. $\sum_{i=1}^{\infty} \sum_{j=1}^{\infty} p_{ij} = 1$

#### 连续型联合分布

存在非负函数 $f(x,y)$，使得：
$$F(x,y) = \int_{-\infty}^x \int_{-\infty}^y f(u,v)dudv$$

**性质**：
1. $f(x,y) \geq 0$
2. $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x,y)dxdy = 1$
3. $f(x,y) = \frac{\partial^2 F(x,y)}{\partial x \partial y}$

### 3.2 边际分布

#### 边际分布函数

$$F_X(x) = \lim_{y \to +\infty} F(x,y) = F(x, +\infty)$$
$$F_Y(y) = \lim_{x \to +\infty} F(x,y) = F(+\infty, y)$$

#### 离散型边际分布

$$P(X = x_i) = \sum_{j=1}^{\infty} p_{ij}$$
$$P(Y = y_j) = \sum_{i=1}^{\infty} p_{ij}$$

#### 连续型边际分布

$$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)dy$$
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)dx$$

### 3.3 条件分布

#### 条件分布函数

$$F_{X|Y}(x|y) = P(X \leq x|Y = y) = \frac{P(X \leq x, Y = y)}{P(Y = y)}$$

#### 离散型条件分布

$$P(X = x_i|Y = y_j) = \frac{p_{ij}}{p_{\cdot j}}$$

其中 $p_{\cdot j} = \sum_{i=1}^{\infty} p_{ij}$

#### 连续型条件分布

$$f_{X|Y}(x|y) = \frac{f(x,y)}{f_Y(y)}$$

### 3.4 随机变量的独立性

#### 独立的定义

若对所有 $x, y$ 有：
$$F(x,y) = F_X(x)F_Y(y)$$

则称 $X$ 与 $Y$ 独立。

#### 离散型独立的等价条件

$$P(X = x_i, Y = y_j) = P(X = x_i)P(Y = y_j)$$

对所有 $i, j$ 成立。

#### 连续型独立的等价条件

$$f(x,y) = f_X(x)f_Y(y)$$

对所有 $x, y$ 成立。

#### 独立的性质

1. 若 $X$ 与 $Y$ 独立，则 $g(X)$ 与 $h(Y)$ 也独立
2. $E[XY] = E[X]E[Y]$（当期望存在时）
3. $Var(X+Y) = Var(X) + Var(Y)$（当 $X$ 与 $Y$ 独立时）

## 4. 随机变量的数字特征

### 4.1 数学期望

#### 离散型数学期望

若 $X$ 的分布律为 $P(X = x_k) = p_k$，则：
$$E[X] = \sum_{k=1}^{\infty} x_k p_k$$

#### 连续型数学期望

若 $X$ 的概率密度为 $f(x)$，则：
$$E[X] = \int_{-\infty}^{+\infty} x f(x)dx$$

#### 期望的性质

1. **线性性**：$E[aX + b] = aE[X] + b$
2. **可加性**：$E[X + Y] = E[X] + E[Y]$
3. **若 $X$ 与 $Y$ 独立**：$E[XY] = E[X]E[Y]$
4. **若 $X \geq 0$**：$E[X] \geq 0$

#### 随机变量函数的期望

**离散型**：$E[g(X)] = \sum_{k=1}^{\infty} g(x_k) p_k$

**连续型**：$E[g(X)] = \int_{-\infty}^{+\infty} g(x) f(x)dx$

### 4.2 方差与标准差

#### 方差的定义

$$Var(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

#### 标准差

$$\sigma(X) = \sqrt{Var(X)}$$

#### 方差的性质

1. **非负性**：$Var(X) \geq 0$
2. **平移不变性**：$Var(X + c) = Var(X)$
3. **缩放性质**：$Var(aX) = a^2 Var(X)$
4. **若 $X$ 与 $Y$ 独立**：$Var(X + Y) = Var(X) + Var(Y)$
5. **一般情况**：$Var(X + Y) = Var(X) + Var(Y) + 2Cov(X,Y)$

### 4.3 协方差与相关系数

#### 协方差

$$Cov(X,Y) = E[(X - E[X])(Y - E[Y])] = E[XY] - E[X]E[Y]$$

#### 相关系数

$$\rho_{XY} = \frac{Cov(X,Y)}{\sqrt{Var(X)Var(Y)}}$$

#### 性质

1. **协方差性质**：
   - $Cov(X,X) = Var(X)$
   - $Cov(X,Y) = Cov(Y,X)$
   - $Cov(aX,bY) = abCov(X,Y)$
   - $Cov(X+Y,Z) = Cov(X,Z) + Cov(Y,Z)$

2. **相关系数性质**：
   - $|\rho_{XY}| \leq 1$
   - $|\rho_{XY}| = 1$ 当且仅当 $X$ 与 $Y$ 线性相关

3. **独立与不相关**：
   - 若 $X$ 与 $Y$ 独立，则 $\rho_{XY} = 0$
   - $\rho_{XY} = 0$ 不一定意味着独立（不相关 ≠ 独立）

### 4.4 常见分布的数字特征

| 分布 | 期望 $E[X]$ | 方差 $Var(X)$ |
|------|-------------|---------------|
| 二项分布 $B(n,p)$ | $np$ | $np(1-p)$ |
| 泊松分布 $P(\lambda)$ | $\lambda$ | $\lambda$ |
| 几何分布 $Ge(p)$ | $\frac{1}{p}$ | $\frac{1-p}{p^2}$ |
| 均匀分布 $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| 指数分布 $Exp(\lambda)$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| 正态分布 $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |

## 5. 大数定律与中心极限定理

### 5.1 切比雪夫不等式

#### 切比雪夫不等式

对任意随机变量 $X$，若 $E[X]$ 和 $Var(X)$ 存在，则对任意 $\varepsilon > 0$：

$$P(|X - E[X]| \geq \varepsilon) \leq \frac{Var(X)}{\varepsilon^2}$$

<details>
<summary><strong>证明</strong></summary>

设 $Y = (X - E[X])^2$，则 $Y \geq 0$，且：
$$E[Y] = Var(X)$$

对任意 $\varepsilon > 0$，考虑事件 $\{|X - E[X]| \geq \varepsilon\}$，即 $\{(X - E[X])^2 \geq \varepsilon^2\}$。

由于 $Y \geq 0$，有：
$$E[Y] = E[Y \cdot I_{\{Y \geq \varepsilon^2\}}] + E[Y \cdot I_{\{Y < \varepsilon^2\}}] \geq E[Y \cdot I_{\{Y \geq \varepsilon^2\}}] \geq \varepsilon^2 E[I_{\{Y \geq \varepsilon^2\}}]$$

其中 $I_A$ 是事件 $A$ 的示性函数。

因此：
$$P(|X - E[X]| \geq \varepsilon) = E[I_{\{|X - E[X]| \geq \varepsilon\}}] \leq \frac{E[Y]}{\varepsilon^2} = \frac{Var(X)}{\varepsilon^2}$$
</details>

### 5.2 大数定律

#### 弱大数定律（切比雪夫）

设 $X_1, X_2, \ldots, X_n$ 是相互独立的随机变量序列，$E[X_i] = \mu$，$Var(X_i) \leq C$（$C$ 为常数），则对任意 $\varepsilon > 0$：

$$\lim_{n \to \infty} P\left(\left|\frac{1}{n}\sum_{i=1}^{n}X_i - \mu\right| < \varepsilon\right) = 1$$

#### 辛钦大数定律

设 $X_1, X_2, \ldots, X_n$ 是相互独立同分布的随机变量序列，$E[X_i] = \mu$，则：

$$\frac{1}{n}\sum_{i=1}^{n}X_i \xrightarrow{P} \mu$$

即样本均值依概率收敛于总体均值。

$$\lim_{n \to \infty} P\left(\left|\frac{\mu_n}{n} - p\right| < \varepsilon\right) = 1$$

**意义**：频率稳定于概率，为用频率估计概率提供理论依据。

### 5.3 中心极限定理

#### 林德伯格-列维中心极限定理

设 $X_1, X_2, \ldots, X_n$ 是相互独立同分布的随机变量序列，$E[X_i] = \mu$，$Var(X_i) = \sigma^2 > 0$，则：

$$\frac{\sum_{i=1}^{n}X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$$

即：
$$\lim_{n \to \infty} P\left(\frac{\sum_{i=1}^{n}X_i - n\mu}{\sigma\sqrt{n}} \leq x\right) = \Phi(x)$$

其中 $\Phi(x)$ 是标准正态分布的分布函数。

<details>
<summary><strong>定理意义</strong></summary>

1. **普遍性**：无论 $X_i$ 服从什么分布，只要满足独立同分布且方差存在，标准化后的和就近似标准正态分布。

2. **近似计算**：当 $n$ 较大时，可以利用正态分布来近似计算独立同分布随机变量和的概率。

3. **统计推断基础**：为参数估计和假设检验提供理论基础。

4. **实际应用**：在质量控制、金融风险评估、测量误差分析等领域有广泛应用。
</details>

#### 棣莫弗-拉普拉斯中心极限定理

设 $\mu_n$ 服从二项分布 $B(n,p)$，则：

$$\frac{\mu_n - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0,1)$$

**应用**：当 $n$ 较大时，可以用正态分布近似计算二项分布的概率。

## 6. 数理统计基本概念

### 6.1 总体与样本

#### 总体

**总体（Population）**：研究对象的全体。

**总体分布**：总体中个体取值所服从的分布，记为 $F(x)$ 或 $f(x)$。

**总体参数**：描述总体分布特征的数值，如 $\mu, \sigma^2, p$ 等。

#### 样本

**样本（Sample）**：从总体中抽取的部分个体。

**样本容量（样本量）**：样本中个体的个数，记为 $n$。

**样本观测值**：样本中各个体的具体取值，记为 $x_1, x_2, \ldots, x_n$。

**样本空间**：所有可能样本观测值组成的集合。

#### 简单随机样本

**定义**：$X_1, X_2, \ldots, X_n$ 称为来自总体 $F(x)$ 的简单随机样本，若满足：

1. **独立性**：$X_1, X_2, \ldots, X_n$ 相互独立
2. **同分布**：每个 $X_i$ 都服从分布 $F(x)$

**性质**：样本的联合分布函数为：
$$F_n(x_1, x_2, \ldots, x_n) = \prod_{i=1}^{n} F(x_i)$$

### 6.2 统计量

#### 统计量的定义

**统计量（Statistic）**：由样本构成的、不含未知参数的函数：
$$T = T(X_1, X_2, \ldots, X_n)$$

#### 常见统计量

**样本均值**：
$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n}X_i$$

**样本方差**：
$$S^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2$$

**样本标准差**：
$$S = \sqrt{S^2}$$

**样本 $k$ 阶原点矩**：
$$A_k = \frac{1}{n}\sum_{i=1}^{n}X_i^k$$

**样本 $k$ 阶中心矩**：
$$B_k = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^k$$

**顺序统计量**：
$$X_{(1)} \leq X_{(2)} \leq \cdots \leq X_{(n)}$$

其中 $X_{(k)}$ 是第 $k$ 小的观测值。

### 6.3 抽样分布

#### $\chi^2$ 分布

**定义**：若 $X_1, X_2, \ldots, X_n$ 独立同分布 $N(0,1)$，则：
$$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2 \sim \chi^2(n)$$

**性质**：
- 自由度为 $n$
- $E[\chi^2(n)] = n$，$Var(\chi^2(n)) = 2n$
- 可加性：若 $\chi_1^2 \sim \chi^2(n_1)$，$\chi_2^2 \sim \chi^2(n_2)$，则 $\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$

#### $t$ 分布

**定义**：若 $X \sim N(0,1)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 独立，则：
$$t = \frac{X}{\sqrt{Y/n}} \sim t(n)$$

**性质**：
- 自由度为 $n$
- $E[t(n)] = 0$（$n > 1$），$Var(t(n)) = \frac{n}{n-2}$（$n > 2$）
- 当 $n \to \infty$ 时，$t(n)$ 近似 $N(0,1)$

#### $F$ 分布

**定义**：若 $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，且 $U$ 与 $V$ 独立，则：
$$F = \frac{U/n_1}{V/n_2} \sim F(n_1, n_2)$$

**性质**：
- 第一自由度为 $n_1$，第二自由度为 $n_2$
- 若 $F \sim F(n_1, n_2)$，则 $\frac{1}{F} \sim F(n_2, n_1)$

#### 重要定理

**定理1**：设 $X_1, X_2, \ldots, X_n$ 是来自 $N(\mu, \sigma^2)$ 的简单随机样本，则：
1. $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$
2. $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
3. $\bar{X}$ 与 $S^2$ 独立
4. $\frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$

## 7. 参数估计

### 7.1 点估计

#### 点估计的概念

**点估计（Point Estimation）**：用样本统计量来估计总体参数的方法。

**估计量（Estimator）**：用于估计参数的统计量，记为 $\hat{\theta}$。

**估计值（Estimate）**：估计量的具体数值。

#### 估计量的评选标准

##### 无偏性

**无偏估计**：若 $E[\hat{\theta}] = \theta$，则称 $\hat{\theta}$ 是 $\theta$ 的无偏估计。

**渐近无偏估计**：若 $\lim_{n \to \infty} E[\hat{\theta}] = \theta$，则称 $\hat{\theta}$ 是 $\theta$ 的渐近无偏估计。

##### 有效性

**有效估计**：在所有无偏估计中，方差最小的估计。

**相对效率**：设 $\hat{\theta}_1$ 和 $\hat{\theta}_2$ 都是 $\theta$ 的无偏估计，若：
$$\frac{Var(\hat{\theta}_1)}{Var(\hat{\theta}_2)} < 1$$

则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 有效。

##### 一致性（相合性）

**一致估计**：若 $\hat{\theta} \xrightarrow{P} \theta$，则称 $\hat{\theta}$ 是 $\theta$ 的一致估计。

### 7.2 矩估计法

#### 矩估计的原理

**矩估计法（Method of Moments）**：用样本矩来估计相应的总体矩，从而得到参数的估计。

**基本思想**：用样本矩替代总体矩。

#### 矩估计的步骤

1. **计算总体矩**：设总体分布含 $k$ 个未知参数 $\theta_1, \theta_2, \ldots, \theta_k$，计算前 $k$ 阶原点矩：
   $$\mu_j = E[X^j] = g_j(\theta_1, \theta_2, \ldots, \theta_k), \quad j = 1, 2, \ldots, k$$

2. **解方程组**：用样本矩 $A_j$ 替代总体矩 $\mu_j$，解方程组：
   $$\begin{cases}
   A_1 = g_1(\hat{\theta}_1, \hat{\theta}_2, \ldots, \hat{\theta}_k) \\
   A_2 = g_2(\hat{\theta}_1, \hat{\theta}_2, \ldots, \hat{\theta}_k) \\
   \vdots \\
   A_k = g_k(\hat{\theta}_1, \hat{\theta}_2, \ldots, \hat{\theta}_k)
   \end{cases}$$

3. **得到估计量**：解得的 $\hat{\theta}_1, \hat{\theta}_2, \ldots, \hat{\theta}_k$ 即为参数的矩估计。

<details>
<summary><strong>矩估计的性质</strong></summary>

1. **一致性**：在一定条件下，矩估计是一致估计
2. **渐近正态性**：在一定条件下，$\sqrt{n}(\hat{\theta} - \theta) \xrightarrow{d} N(0, \sigma^2(\theta))$
3. **不变性**：若 $\hat{\theta}$ 是 $\theta$ 的矩估计，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的矩估计

**优点**：
- 计算简单
- 不需要知道分布的具体形式
- 一致性好

**缺点**：
- 可能不是最有效的估计
- 不唯一（不同矩可能给出不同估计）
</details>

### 7.3 极大似然估计法

#### 极大似然估计的原理

**极大似然估计（Maximum Likelihood Estimation, MLE）**：选择使样本出现概率最大的参数值作为估计。

**基本思想**：既然样本已经出现，就认为它出现的概率是最大的。

#### 似然函数

**离散型**：设 $X_1, X_2, \ldots, X_n$ 是来自离散分布 $P(X = x) = p(x;\theta)$ 的样本，则似然函数为：
$$L(\theta) = \prod_{i=1}^{n} p(x_i;\theta)$$

**连续型**：设 $X_1, X_2, \ldots, X_n$ 是来自连续分布 $f(x;\theta)$ 的样本，则似然函数为：
$$L(\theta) = \prod_{i=1}^{n} f(x_i;\theta)$$

#### 极大似然估计的步骤

1. **写似然函数**：$L(\theta) = \prod_{i=1}^{n} f(x_i;\theta)$

2. **取对数**：$\ln L(\theta) = \sum_{i=1}^{n} \ln f(x_i;\theta)$

3. **求导数**：$\frac{d}{d\theta} \ln L(\theta) = 0$

4. **解方程**：求解方程 $\frac{d}{d\theta} \ln L(\theta) = 0$，得到 $\hat{\theta}$

<details>
<summary><strong>极大似然估计的性质</strong></summary>

1. **不变性**：若 $\hat{\theta}$ 是 $\theta$ 的极大似然估计，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的极大似然估计

2. **渐近正态性**：在一定条件下，$\sqrt{n}(\hat{\theta} - \theta) \xrightarrow{d} N(0, I^{-1}(\theta))$，其中 $I(\theta)$ 是Fisher信息量

3. **渐近有效性**：在正则条件下，极大似然估计是渐近有效的

4. **一致性**：在一定条件下，极大似然估计是一致估计

**优点**：
- 在正则条件下具有最优性质
- 不变性
- 渐近正态性

**缺点**：
- 计算可能复杂
- 需要知道分布形式
- 可能不存在或唯一性不保证
</details>

### 7.4 区间估计

#### 区间估计的概念

**区间估计（Interval Estimation）**：给出参数 $\theta$ 的一个区间 $[\hat{\theta}_L, \hat{\theta}_U]$，使得：
$$P(\hat{\theta}_L \leq \theta \leq \hat{\theta}_U) = 1 - \alpha$$

其中 $1 - \alpha$ 称为**置信水平**（Confidence Level），$[\hat{\theta}_L, \hat{\theta}_U]$ 称为**置信区间**（Confidence Interval）。

#### 置信区间的构造

**枢轴量法**：
1. 找一个包含待估参数 $\theta$ 但不含其他未知参数的统计量 $G(X_1, \ldots, X_n; \theta)$
2. 确定 $G$ 的分布（与 $\theta$ 无关）
3. 对给定的置信水平 $1 - \alpha$，找常数 $a, b$ 使得：
   $$P(a \leq G \leq b) = 1 - \alpha$$
4. 将不等式 $a \leq G \leq b$ 等价变形为 $\hat{\theta}_L \leq \theta \leq \hat{\theta}_U$

#### 📊 置信区间图示

**置信区间的几何意义**：

#### 常见分布的置信区间

##### 正态总体均值的置信区间

**方差已知**：
$$\bar{X} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$$

**方差未知**：
$$\bar{X} \pm t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}$$

##### 正态总体方差的置信区间

$$\left[\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$$

##### 两正态总体均值差的置信区间

**方差已知**：
$$(\bar{X} - \bar{Y}) \pm z_{\alpha/2} \sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}$$

**方差未知但相等**：
$$(\bar{X} - \bar{Y}) \pm t_{\alpha/2}(n_1 + n_2 - 2) S_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}$$

其中 $S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}$

##### 两正态总体方差比的置信区间

$$\left[\frac{S_1^2/S_2^2}{F_{\alpha/2}(n_1-1, n_2-1)}, \frac{S_1^2/S_2^2}{F_{1-\alpha/2}(n_1-1, n_2-1)}\right]$$

## 8. 假设检验

### 8.1 假设检验的基本思想

#### 假设检验的概念

**假设检验（Hypothesis Testing）**：根据样本信息，对总体参数的某个假设进行判断的方法。

#### 基本概念

**原假设（零假设）$H_0$**：待检验的假设，通常是"没有效应"或"没有差异"。

**备择假设（对立假设）$H_1$**：与 $H_0$ 对立的假设。

**检验统计量**：用于进行检验的统计量。

**显著性水平 $\alpha$**：预先规定的允许犯第一类错误的概率。

#### 两类错误

| 真实情况 | 接受 $H_0$ | 拒绝 $H_0$ |
|----------|------------|------------|
| $H_0$ 为真 | 正确（概率 $1-\alpha$） | 第一类错误（概率 $\alpha$） |
| $H_0$ 为假 | 第二类错误（概率 $\beta$） | 正确（概率 $1-\beta$） |

**第一类错误（弃真错误）**：$H_0$ 为真但被拒绝。

**第二类错误（取伪错误）**：$H_0$ 为假但被接受。

**检验的功效**：$1 - \beta$，正确拒绝虚假原假设的概率。

#### 检验的步骤

1. **建立假设**：提出原假设 $H_0$ 和备择假设 $H_1$
2. **选择检验统计量**：确定检验统计量及其分布
3. **确定拒绝域**：根据显著性水平 $\alpha$ 确定拒绝域
4. **计算检验统计量的值**：根据样本观测值计算
5. **做出判断**：若检验统计量落在拒绝域，则拒绝 $H_0$；否则接受 $H_0$

### 8.2 正态总体参数的假设检验

#### 单个正态总体均值的检验

##### 方差已知：$Z$ 检验

**假设**：
$$H_0: \mu = \mu_0 \quad vs \quad H_1: \mu \neq \mu_0$$

**检验统计量**：
$$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} \sim N(0,1)$$

**拒绝域**：$|Z| > z_{\alpha/2}$

##### 方差未知：$t$ 检验

**假设**：
$$H_0: \mu = \mu_0 \quad vs \quad H_1: \mu \neq \mu_0$$

**检验统计量**：
$$t = \frac{\bar{X} - \mu_0}{S/\sqrt{n}} \sim t(n-1)$$

**拒绝域**：$|t| > t_{\alpha/2}(n-1)$

#### 单个正态总体方差的检验

**假设**：
$$H_0: \sigma^2 = \sigma_0^2 \quad vs \quad H_1: \sigma^2 \neq \sigma_0^2$$

**检验统计量**：
$$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)$$

**拒绝域**：$\chi^2 < \chi^2_{1-\alpha/2}(n-1)$ 或 $\chi^2 > \chi^2_{\alpha/2}(n-1)$

#### 两个正态总体均值的检验

##### 方差已知

**假设**：
$$H_0: \mu_1 = \mu_2 \quad vs \quad H_1: \mu_1 \neq \mu_2$$

**检验统计量**：
$$Z = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}} \sim N(0,1)$$

##### 方差未知但相等

**检验统计量**：
$$t = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$

其中 $S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}$

#### 两个正态总体方差的检验

**假设**：
$$H_0: \sigma_1^2 = \sigma_2^2 \quad vs \quad H_1: \sigma_1^2 \neq \sigma_2^2$$

**检验统计量**：
$$F = \frac{S_1^2}{S_2^2} \sim F(n_1-1, n_2-1)$$

**拒绝域**：$F < F_{1-\alpha/2}(n_1-1, n_2-1)$ 或 $F > F_{\alpha/2}(n_1-1, n_2-1)$

### 8.3 假设检验与置信区间的关系

#### 双侧检验与置信区间

对于参数 $\theta$ 的双侧检验：
$$H_0: \theta = \theta_0 \quad vs \quad H_1: \theta \neq \theta_0$$

拒绝 $H_0$ 当且仅当 $\theta_0$ 不在置信水平为 $1-\alpha$ 的置信区间内。

#### 单侧检验与置信区间

对于右侧检验：
$$H_0: \theta \leq \theta_0 \quad vs \quad H_1: \theta > \theta_0$$

拒绝 $H_0$ 当且仅当 $\theta_0$ 小于置信水平为 $1-\alpha$ 的单侧置信下限。

### 8.4 非参数检验

#### $\chi^2$ 拟合优度检验

**用途**：检验样本是否来自指定的分布。

**检验统计量**：
$$\chi^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i}$$

其中 $O_i$ 为实际频数，$E_i$ 为期望频数。

**自由度**：$k-1-m$，其中 $k$ 为分组数，$m$ 为估计的参数个数。

#### 列联表独立性检验

**用途**：检验两个分类变量是否独立。

**检验统计量**：
$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{s} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

其中 $E_{ij} = \frac{n_{i\cdot} \cdot n_{\cdot j}}{n}$。

**自由度**：$(r-1)(s-1)$，其中 $r$ 和 $s$ 分别为两个变量的水平数。

## 9. 回归分析

### 9.1 一元线性回归

#### 回归分析的概念

**回归分析（Regression Analysis）**：研究一个或多个自变量与因变量之间依赖关系的统计方法。

**回归函数**：因变量的条件期望关于自变量的函数。

#### 一元线性回归模型

$$Y_i = \beta_0 + \beta_1 X_i + \varepsilon_i, \quad i = 1, 2, \ldots, n$$

其中：
- $Y_i$：因变量的观测值
- $X_i$：自变量的观测值
- $\beta_0, \beta_1$：未知参数（回归系数）
- $\varepsilon_i$：随机误差项

**基本假设**：
1. $\varepsilon_i \sim N(0, \sigma^2)$（正态性）
2. $E[\varepsilon_i] = 0$（零均值性）
3. $Var(\varepsilon_i) = \sigma^2$（同方差性）
4. $\varepsilon_i$ 相互独立（独立性）

#### 参数估计

##### 最小二乘法

**目标**：最小化残差平方和：
$$Q(\beta_0, \beta_1) = \sum_{i=1}^{n}(Y_i - \beta_0 - \beta_1 X_i)^2$$

**正规方程组**：
$$\begin{cases}
n\beta_0 + \beta_1\sum_{i=1}^{n}X_i = \sum_{i=1}^{n}Y_i \\
\beta_0\sum_{i=1}^{n}X_i + \beta_1\sum_{i=1}^{n}X_i^2 = \sum_{i=1}^{n}X_iY_i
\end{cases}$$

**解**：
$$\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^{n}(X_i - \bar{X})^2}$$
$$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1\bar{X}$$

##### 极大似然估计

在正态假设下，最小二乘估计与极大似然估计相同。

#### 回归方程的评价

##### 决定系数 $R^2$

$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

其中：
- $SSR = \sum_{i=1}^{n}(\hat{Y}_i - \bar{Y})^2$（回归平方和）
- $SST = \sum_{i=1}^{n}(Y_i - \bar{Y})^2$（总平方和）
- $SSE = \sum_{i=1}^{n}(Y_i - \hat{Y}_i)^2$（残差平方和）

**意义**：$R^2$ 表示因变量变异中被自变量解释的比例。

##### 显著性检验

**回归系数的 $t$ 检验**：

检验 $H_0: \beta_1 = 0$ vs $H_1: \beta_1 \neq 0$

**检验统计量**：
$$t = \frac{\hat{\beta}_1}{\hat{\sigma} \sqrt{\sum_{i=1}^{n}(X_i - \bar{X})^2}} \sim t(n-2)$$

其中 $\hat{\sigma}^2 = \frac{SSE}{n-2}$。

**回归方程的 $F$ 检验**：

检验 $H_0: \beta_1 = 0$ vs $H_1: \beta_1 \neq 0$

**检验统计量**：
$$F = \frac{SSR/1}{SSE/(n-2)} \sim F(1, n-2)$$

#### 预测与控制

##### 点预测

对于给定的 $X = x_0$，$\hat{Y}_0 = \hat{\beta}_0 + \hat{\beta}_1 x_0$

##### 区间预测

**置信区间**（平均值的预测）：
$$\hat{Y}_0 \pm t_{\alpha/2}(n-2)\hat{\sigma}\sqrt{\frac{1}{n} + \frac{(x_0 - \bar{X})^2}{\sum_{i=1}^{n}(X_i - \bar{X})^2}}$$

**预测区间**（个别值的预测）：
$$\hat{Y}_0 \pm t_{\alpha/2}(n-2)\hat{\sigma}\sqrt{1 + \frac{1}{n} + \frac{(x_0 - \bar{X})^2}{\sum_{i=1}^{n}(X_i - \bar{X})^2}}$$

### 9.2 多元线性回归

#### 多元线性回归模型

$$Y_i = \beta_0 + \beta_1X_{i1} + \beta_2X_{i2} + \cdots + \beta_pX_{ip} + \varepsilon_i, \quad i = 1, 2, \ldots, n$$

**矩阵形式**：
$$\mathbf{Y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\varepsilon}$$

其中：
- $\mathbf{Y} = (Y_1, Y_2, \ldots, Y_n)^T$
- $\mathbf{X} = \begin{pmatrix} 1 & X_{11} & \cdots & X_{1p} \\ 1 & X_{21} & \cdots & X_{2p} \\ \vdots & \vdots & \ddots & \vdots \\ 1 & X_{n1} & \cdots & X_{np} \end{pmatrix}$
- $\boldsymbol{\beta} = (\beta_0, \beta_1, \ldots, \beta_p)^T$
- $\boldsymbol{\varepsilon} = (\varepsilon_1, \varepsilon_2, \ldots, \varepsilon_n)^T$

#### 参数估计

**最小二乘估计**：
$$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{Y}$$

**残差向量**：
$$\hat{\boldsymbol{\varepsilon}} = \mathbf{Y} - \hat{\mathbf{Y}} = \mathbf{Y} - \mathbf{X}\hat{\boldsymbol{\beta}}$$

**误差方差的估计**：
$$\hat{\sigma}^2 = \frac{SSE}{n-p-1} = \frac{\hat{\boldsymbol{\varepsilon}}^T\hat{\boldsymbol{\varepsilon}}}{n-p-1}$$

#### 显著性检验

##### 回归系数的检验

**检验 $H_{0j}: \beta_j = 0$ vs $H_{1j}: \beta_j \neq 0$**

**检验统计量**：
$$t_j = \frac{\hat{\beta}_j}{\hat{\sigma}\sqrt{c_{jj}}} \sim t(n-p-1)$$

其中 $c_{jj}$ 是 $(\mathbf{X}^T\mathbf{X})^{-1}$ 的对角线元素。

##### 回归方程的检验

**检验 $H_0: \beta_1 = \beta_2 = \cdots = \beta_p = 0$ vs $H_1$：至少有一个 $\beta_j \neq 0$**

**检验统计量**：
$$F = \frac{SSR/p}{SSE/(n-p-1)} \sim F(p, n-p-1)$$

#### 决定系数

**多元决定系数**：
$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

**调整决定系数**：
$$R_a^2 = 1 - \frac{SSE/(n-p-1)}{SST/(n-1)}$$

#### 模型选择

##### 逐步回归

1. **向前选择**：从空模型开始，逐步加入变量
2. **向后删除**：从全模型开始，逐步删除变量
3. **逐步选择**：结合向前选择和向后删除

##### 信息准则

**AIC准则**：
$$AIC = -2\ln L + 2p$$

**BIC准则**：
$$BIC = -2\ln L + p\ln n$$

其中 $L$ 是似然函数，$p$ 是参数个数。
