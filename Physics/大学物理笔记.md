## 1. 力学

### 1.1 质点运动学

#### 1.1.1 基本概念

**参考系与坐标系**

在研究物体运动时，必须选择合适的参考系。参考系是观察和描述物体运动的参照标准。在经典力学中，我们通常使用**笛卡尔坐标系**来描述物体的位置。

- **参考系**：观察物体运动的参照标准
- **坐标系**：在参考系中建立的数学工具，用于定量描述物体位置

**质点的定义**

质点是物理学中的一个理想化模型。当物体的形状和大小对所研究的问题可以忽略时，我们可以将物体简化为一个具有质量的点。

- **质点**：忽略物体形状和大小，只保留质量属性的理想化模型
- **适用条件**：当物体尺寸远小于运动范围，或物体只做平动时

**位置矢量与位移**

在坐标系中，质点的位置可以用位置矢量 $\vec{r}$ 来描述：

$$\vec{r}(t) = x(t)\hat{i} + y(t)\hat{j} + z(t)\hat{k}$$

**位移**：质点位置的变化量
$$\Delta \vec{r} = \vec{r}_2 - \vec{r}_1 = (x_2 - x_1)\hat{i} + (y_2 - y_1)\hat{j} + (z_2 - z_1)\hat{k}$$

**速度**：位移对时间的变化率
$$\vec{v} = \frac{d\vec{r}}{dt} = \frac{dx}{dt}\hat{i} + \frac{dy}{dt}\hat{j} + \frac{dz}{dt}\hat{k}$$

**加速度**：速度对时间的变化率
$$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2} = \frac{d^2x}{dt^2}\hat{i} + \frac{d^2y}{dt^2}\hat{j} + \frac{d^2z}{dt^2}\hat{k}$$

<details>
<summary><strong>重要概念：矢量和标量的区别</strong></summary>

**矢量**：既有大小又有方向的物理量
- 例如：位移、速度、加速度、力等
- 运算遵循矢量运算法则

**标量**：只有大小没有方向的物理量  
- 例如：时间、质量、能量、功等
- 运算遵循代数运算法则
</details>

#### 1.1.2 直线运动

**匀速直线运动**

当质点沿直线运动且速度保持不变时，称为匀速直线运动。

**运动方程**：
$$x = x_0 + vt$$

其中：
- $x_0$ 为初始位置
- $v$ 为恒定速度
- $t$ 为时间

**速度-时间图像**：
匀速直线运动的 v-t 图像是一条平行于时间轴的直线。

**位移-时间图像**：
匀速直线运动的 x-t 图像是一条斜率为速度的直线。

**匀变速直线运动**

当质点沿直线运动且加速度保持不变时，称为匀变速直线运动。

<details>
<summary><strong>匀变速直线运动基本公式推导</strong></summary>

从加速度定义出发：
$$a = \frac{dv}{dt} = \text{常数}$$

积分得速度公式：
$$v = v_0 + at$$

从速度公式出发：
$$v = \frac{dx}{dt} = v_0 + at$$

积分得位移公式：
$$x = x_0 + v_0t + \frac{1}{2}at^2$$

消去时间 $t$，得速度-位移关系：
$$v^2 = v_0^2 + 2a(x - x_0)$$
</details>

**匀变速直线运动基本公式**：

1. **速度公式**：$v = v_0 + at$
2. **位移公式**：$x = x_0 + v_0t + \frac{1}{2}at^2$
3. **速度-位移关系**：$v^2 = v_0^2 + 2a(x - x_0)$
4. **平均速度公式**：$\bar{v} = \frac{v_0 + v}{2}$

**自由落体运动**

自由落体运动是匀变速直线运动的特例，物体在重力作用下的下落运动。

**运动特点**：
- 初速度 $v_0 = 0$
- 加速度 $a = g = 9.8 \, \text{m/s}^2$（向下）

**基本公式**：
- 速度：$v = gt$
- 位移：$h = \frac{1}{2}gt^2$
- 速度-位移关系：$v^2 = 2gh$

**上抛运动**

物体以一定初速度向上抛出的运动。

**运动特点**：
- 初速度 $v_0$（向上）
- 加速度 $a = -g$（向下）

**运动方程**：
- 速度：$v = v_0 - gt$
- 位移：$h = v_0t - \frac{1}{2}gt^2$

**例题1**：一物体从高度 $h = 20 \, \text{m}$ 处自由下落，不计空气阻力，求：
(1) 下落时间
(2) 着地时的速度

**解答**：
(1) 由 $h = \frac{1}{2}gt^2$，得 $t = \sqrt{\frac{2h}{g}} = \sqrt{\frac{2 \times 20}{9.8}} \approx 2.02 \, \text{s}$

(2) 由 $v^2 = 2gh$，得 $v = \sqrt{2gh} = \sqrt{2 \times 9.8 \times 20} \approx 19.8 \, \text{m/s}$

**例题2**：一球以 $v_0 = 10 \, \text{m/s}$ 的初速度向上抛出，求：
(1) 最大高度
(2) 回到抛出点的时间

**解答**：
(1) 在最高点 $v = 0$，由 $v^2 = v_0^2 - 2gh$，得 $h = \frac{v_0^2}{2g} = \frac{10^2}{2 \times 9.8} \approx 5.1 \, \text{m}$

(2) 由对称性，上升时间等于下降时间，总时间 $t = \frac{2v_0}{g} = \frac{2 \times 10}{9.8} \approx 2.04 \, \text{s}$

#### 1.1.3 曲线运动

**抛物运动**

抛物运动是平面曲线运动，可以分解为水平方向的匀速直线运动和竖直方向的匀变速直线运动。

**运动分解**：
- 水平方向：$x = v_0\cos\theta \cdot t$
- 竖直方向：$y = v_0\sin\theta \cdot t - \frac{1}{2}gt^2$

**轨迹方程**：
消去时间 $t$，得轨迹方程：
$$y = x\tan\theta - \frac{gx^2}{2v_0^2\cos^2\theta}$$

**射程公式**：
当 $y = 0$ 时，$x = \frac{v_0^2\sin2\theta}{g}$

**最大射程**：当 $\theta = 45^\circ$ 时，射程最大

**最大高度**：
$$h_{\text{max}} = \frac{v_0^2\sin^2\theta}{2g}$$

**圆周运动**

**匀速圆周运动**：
- 速度大小不变，方向不断变化
- 加速度指向圆心，称为向心加速度

**向心加速度**：
$$a_n = \frac{v^2}{r} = \omega^2r$$

其中：
- $v$ 为线速度
- $\omega$ 为角速度
- $r$ 为圆周半径

**角速度与线速度的关系**：
$$v = \omega r$$

**周期与频率**：
- 周期 $T$：完成一次完整圆周运动所需时间
- 频率 $f$：单位时间内完成的圆周运动次数
- 关系：$f = \frac{1}{T}$，$\omega = 2\pi f = \frac{2\pi}{T}$

<details>
<summary><strong>变速圆周运动</strong></summary>

变速圆周运动中，加速度可以分解为：
1. **切向加速度**：$a_t = \frac{dv}{dt}$，改变速度大小
2. **法向加速度**：$a_n = \frac{v^2}{r}$，改变速度方向

总加速度：
$$\vec{a} = \vec{a_t} + \vec{a_n}$$

加速度大小：
$$a = \sqrt{a_t^2 + a_n^2}$$

加速度方向：
$$\tan\phi = \frac{a_n}{a_t}$$

其中 $\phi$ 为加速度与切线方向的夹角。
</details>

**例题3**：一物体以 $v_0 = 10 \, \text{m/s}$ 的初速度，与水平方向成 $30^\circ$ 角抛出，求：
(1) 射程
(2) 最大高度
(3) 飞行时间

**解答**：
(1) 射程：$R = \frac{v_0^2\sin2\theta}{g} = \frac{10^2 \times \sin60^\circ}{9.8} \approx \frac{100 \times 0.866}{9.8} \approx 8.84 \, \text{m}$

(2) 最大高度：$h_{\text{max}} = \frac{v_0^2\sin^2\theta}{2g} = \frac{100 \times \sin^230^\circ}{2 \times 9.8} \approx \frac{100 \times 0.25}{19.6} \approx 1.28 \, \text{m}$

(3) 飞行时间：$T = \frac{2v_0\sin\theta}{g} = \frac{2 \times 10 \times 0.5}{9.8} \approx 1.02 \, \text{s}$

**例题4**：半径 $r = 0.5 \, \text{m}$ 的水平圆盘上放一物体，物体与圆盘间的最大静摩擦力为其重力的 0.4 倍，求圆盘匀速转动时物体刚好不滑动时的角速度。

**解答**：
物体不滑动时，静摩擦力提供向心力：
$$f_{\text{max}} = m\omega^2r$$

其中 $f_{\text{max}} = 0.4mg$，所以：
$$0.4mg = m\omega^2r$$

$$\omega = \sqrt{\frac{0.4g}{r}} = \sqrt{\frac{0.4 \times 9.8}{0.5}} \approx 2.8 \, \text{rad/s}$$

**习题**：
1. 一汽车以 $54 \, \text{km/h}$ 的速度匀速行驶，突然发现前方 $50 \, \text{m}$ 处有障碍物，立即以 $a = -5 \, \text{m/s}^2$ 的加速度刹车，问能否避免撞车？
2. 从同一高度同时释放两个物体，一个自由下落，另一个以 $10 \, \text{m/s}$ 的水平速度抛出，求两物体落地时间差。
3. 一小球在半径 $r = 1 \, \text{m}$ 的竖直圆轨道内做圆周运动，求小球在最高点的最小速度。

### 1.2 质点动力学

质点动力学研究物体运动状态变化的原因，即力与运动的关系。牛顿运动定律是经典力学的基础。

#### 1.2.1 牛顿运动定律

**牛顿第一定律（惯性定律）**

**内容**：任何物体都保持静止状态或匀速直线运动状态，直到有外力迫使它改变这种状态为止。

**物理意义**：
- 揭示了物体具有惯性
- 定义了惯性参考系
- 说明了力是改变运动状态的原因，而不是维持运动的原因

**惯性**：物体保持原有运动状态的性质
- 质量是惯性大小的唯一量度
- 质量越大，惯性越大，越难改变运动状态

**牛顿第二定律（动力学基本定律）**

**内容**：物体的加速度与作用在它上面的力成正比，与物体的质量成反比，加速度的方向与力的方向相同。

**数学表达式**：
$$\vec{F} = m\vec{a} = \frac{d\vec{p}}{dt}$$

其中动量 $\vec{p} = m\vec{v}$

<details>
<summary><strong>牛顿第二定律的详细推导</strong></summary>

**从实验出发**：
1. **加速度与力的关系**：实验表明 $a \propto F$（在质量不变的情况下）
2. **加速度与质量的关系**：实验表明 $a \propto 1/m$（在力不变的情况下）

**综合得**：$a = \frac{F}{m}$，即 $\vec{F} = m\vec{a}$

**更一般的形式**：考虑到质量可能变化的情况：
$$\vec{F} = \frac{d\vec{p}}{dt} = \frac{d(m\vec{v})}{dt}$$

当 $m$ 为常数时：$\vec{F} = m\frac{d\vec{v}}{dt} = m\vec{a}$

**分量形式**：
$$F_x = ma_x, \quad F_y = ma_y, \quad F_z = ma_z$$

**叠加原理**：当物体同时受到多个力作用时，合力等于各力的矢量和：
$$\vec{F}_{\text{合}} = \sum_{i=1}^{n} \vec{F_i} = m\vec{a}$$
</details>

**牛顿第三定律（作用力与反作用力定律）**

**内容**：两个物体之间的作用力和反作用力总是大小相等，方向相反，作用在同一条直线上。

**数学表达式**：
$$\vec{F}_{12} = -\vec{F}_{21}$$

**重要特征**：
1. **同时性**：作用力和反作用力同时产生，同时消失
2. **等大反向**：大小相等，方向相反
3. **共线**：作用在同一条直线上
4. **异物**：作用在两个不同的物体上
5. **同性质**：都是同一种性质的力

**例题5**：质量为 $m = 2 \, \text{kg}$ 的物体，受到 $F = 10 \, \text{N}$ 的水平拉力作用，求加速度。

**解答**：
根据牛顿第二定律：$F = ma$
$$a = \frac{F}{m} = \frac{10}{2} = 5 \, \text{m/s}^2$$

加速度方向与拉力方向相同。

#### 1.2.2 常见力

![力学_力的合成分解](imgs/力学_力的合成分解.png)

**重力**

重力是地球对物体的万有引力在地面附近的近似表现。

**重力公式**：$\vec{G} = m\vec{g}$

其中重力加速度 $g \approx 9.8 \, \text{m/s}^2$，方向竖直向下。

**重力特性**：
- 与物体的质量成正比
- 在地球表面附近可视为恒力
- 作用在物体的重心上

**弹力**

弹力是物体发生形变时产生的力，遵循胡克定律。

**胡克定律**：$F = -kx$

其中：
- $k$ 为弹簧的劲度系数（N/m）
- $x$ 为弹簧的形变量（m）
- 负号表示弹力方向与形变方向相反

**弹力类型**：
1. **弹簧弹力**：$F = -kx$
2. **绳子的拉力**：沿绳子方向
3. **支持面的支持力**：垂直于支持面
4. **杆的推力或拉力**：沿杆的方向

**摩擦力**

摩擦力是相互接触的物体间产生的阻碍相对运动或相对运动趋势的力。

**静摩擦力**：
- 条件：接触面粗糙、有正压力、有相对运动趋势
- 特点：大小可变，方向与相对运动趋势相反
- 最大静摩擦力：$f_{\text{max}} = \mu_s N$
- 一般静摩擦力：$0 \leq f \leq \mu_s N$

**动摩擦力**：
- 条件：接触面粗糙、有正压力、有相对运动
- 特点：大小近似恒定，方向与相对运动方向相反
- 动摩擦力：$f = \mu_k N$

其中：
- $\mu_s$ 为静摩擦系数
- $\mu_k$ 为动摩擦系数
- $N$ 为正压力

**摩擦力特性**：
- 静摩擦系数 $\mu_s$ 通常大于动摩擦系数 $\mu_k$
- 摩擦力大小与接触面积无关
- 摩擦力方向与接触面平行

**流体阻力**

物体在流体中运动时受到的阻力。

**低速时（斯托克斯定律）**：$f = 6\pi\eta rv$

**高速时**：$f = \frac{1}{2}C\rho Sv^2$

其中：
- $\eta$ 为流体粘度
- $r$ 为球形物体半径
- $C$ 为阻力系数
- $\rho$ 为流体密度
- $S$ 为迎流面积
- $v$ 为物体速度

**例题6**：质量为 $m = 1 \, \text{kg}$ 的物体放在水平面上，物体与地面间的静摩擦系数 $\mu_s = 0.4$，动摩擦系数 $\mu_k = 0.3$。求：
(1) 要使物体开始运动，至少需要多大的水平拉力？
(2) 物体匀速运动时，拉力为多大？

**解答**：
(1) 开始运动时，拉力必须克服最大静摩擦力：
$$F_{\text{min}} = f_{\text{max}} = \mu_s mg = 0.4 \times 1 \times 9.8 = 3.92 \, \text{N}$$

(2) 匀速运动时，拉力等于动摩擦力：
$$F = f_k = \mu_k mg = 0.3 \times 1 \times 9.8 = 2.94 \, \text{N}$$

#### 1.2.3 质点动力学应用

**变质量问题**

当物体的质量随时间变化时，牛顿第二定律应写为：
$$\vec{F} = \frac{d\vec{p}}{dt} = \frac{d(m\vec{v})}{dt}$$

**火箭推进原理**

火箭在推进过程中不断喷射燃气，质量逐渐减小。

**火箭运动方程**：
设火箭质量为 $m$，速度为 $v$，在时间 $dt$ 内喷出质量为 $dm$（$dm < 0$）的燃气，燃气相对于火箭的速度为 $u$，则燃气相对于地面的速度为 $v - u$。

根据动量守恒：
$$m\vec{v} = (m + dm)(\vec{v} + d\vec{v}) + (-dm)(\vec{v} - u)$$

忽略二阶小量 $dm \cdot d\vec{v}$，得：
$$m d\vec{v} = -u dm$$

$$\vec{F}_{\text{外}} = m\frac{d\vec{v}}{dt} = -u\frac{dm}{dt}$$

火箭受到的推力：$\vec{F}_{\text{推}} = -\vec{F}_{\text{外}} = u\frac{dm}{dt}$

**齐奥尔科夫斯基公式**：
对于火箭从静止开始，在重力场外飞行：
$$v = u \ln\frac{m_0}{m}$$

其中 $m_0$ 为初始质量，$m$ 为剩余质量。

**相对论质量**

在高速情况下，质量随速度变化：
$$m = \frac{m_0}{\sqrt{1 - \frac{v^2}{c^2}}}$$

其中 $m_0$ 为静止质量，$c$ 为光速。

此时牛顿第二定律仍成立：$\vec{F} = \frac{d(m\vec{v})}{dt}$

**例题7**：火箭初始质量 $m_0 = 1000 \, \text{kg}$，燃气喷射速度 $u = 2000 \, \text{m/s}$，求燃料质量为多少时，火箭速度达到 $v = 1000 \, \text{m/s}$。

**解答**：
根据齐奥尔科夫斯基公式：
$$v = u \ln\frac{m_0}{m}$$

$$\frac{m_0}{m} = e^{v/u} = e^{1000/2000} = e^{0.5} \approx 1.649$$

$$m = \frac{m_0}{1.649} = \frac{1000}{1.649} \approx 606.4 \, \text{kg}$$

燃料质量：$\Delta m = m_0 - m = 1000 - 606.4 = 393.6 \, \text{kg}$

### 1.3 功和能

功和能是描述物体运动状态变化的重要物理量。功是能量转化的量度，能量是物体做功能力的体现。

#### 1.3.1 功的概念

**功的定义**

功是力在空间上的累积效果，定义为力与位移的点积。

**恒力做功**：
$$W = \vec{F} \cdot \vec{s} = Fs\cos\theta$$

其中：
- $\vec{F}$ 为恒定力
- $\vec{s}$ 为位移
- $\theta$ 为力与位移的夹角

**功的单位**：焦耳（J），1J = 1N·m

**功的正负**：
- $\theta < 90^\circ$：$\cos\theta > 0$，做正功
- $\theta = 90^\circ$：$\cos\theta = 0$，不做功
- $\theta > 90^\circ$：$\cos\theta < 0$，做负功

**变力做功**

当力随位置变化时，需要用积分计算：
$$W = \int_{s_1}^{s_2} \vec{F} \cdot d\vec{s} = \int_{s_1}^{s_2} F\cos\theta \, ds$$

**曲线运动的功**：
$$W = \int_{C} \vec{F} \cdot d\vec{r}$$

**功率**

功率是单位时间内所做的功，描述做功的快慢。

**平均功率**：$\bar{P} = \frac{W}{t}$

**瞬时功率**：$P = \frac{dW}{dt} = \vec{F} \cdot \vec{v}$

**功率单位**：瓦特（W），1W = 1J/s

<details>
<summary><strong>变力做功的详细计算</strong></summary>

**线性变力做功**：
设力随位置线性变化：$F = F_0 + kx$

$$W = \int_{x_1}^{x_2} (F_0 + kx) dx = F_0(x_2 - x_1) + \frac{1}{2}k(x_2^2 - x_1^2)$$

**弹簧弹力做功**：
弹簧弹力：$F = -kx$

$$W = \int_{x_1}^{x_2} (-kx) dx = -\frac{1}{2}k(x_2^2 - x_1^2)$$

**重力做功**：
$$W = \int_{h_1}^{h_2} (-mg) dh = -mg(h_2 - h_1)$$

**万有引力做功**：
$$W = \int_{r_1}^{r_2} \left(-\frac{GMm}{r^2}\right) dr = GMm\left(\frac{1}{r_2} - \frac{1}{r_1}\right)$$
</details>

**例题8**：质量为 $m = 2 \, \text{kg}$ 的物体，在水平面上受到 $F = 10 \, \text{N}$ 的水平拉力作用，摩擦系数 $\mu = 0.2$，求物体移动 $s = 5 \, \text{m}$ 时各力所做的功。

**解答**：
正压力：$N = mg = 2 \times 9.8 = 19.6 \, \text{N}$

摩擦力：$f = \mu N = 0.2 \times 19.6 = 3.92 \, \text{N}$

拉力做功：$W_F = Fs\cos0^\circ = 10 \times 5 = 50 \, \text{J}$

摩擦力做功：$W_f = fs\cos180^\circ = 3.92 \times 5 \times (-1) = -19.6 \, \text{J}$

重力做功：$W_G = 0$（位移水平，重力垂直）

支持力做功：$W_N = 0$（位移水平，支持力垂直）

#### 1.3.2 动能定理

**动能**

动能是物体由于运动而具有的能量。

$$E_k = \frac{1}{2}mv^2$$

动能是标量，单位：焦耳（J）

**动能定理**

合外力对物体所做的功等于物体动能的变化量。

$$W_{\text{合}} = \Delta E_k = E_{k2} - E_{k1}$$

<details>
<summary><strong>动能定理的详细推导</strong></summary>

**从牛顿第二定律出发**：
$$\vec{F} = m\vec{a} = m\frac{d\vec{v}}{dt}$$

**两边点乘位移**：
$$\vec{F} \cdot d\vec{r} = m\frac{d\vec{v}}{dt} \cdot d\vec{r}$$

**利用 $d\vec{r} = \vec{v} dt$**：
$$\vec{F} \cdot d\vec{r} = m\frac{d\vec{v}}{dt} \cdot \vec{v} dt = mv \cdot d\vec{v}$$

**积分**：
$$W = \int \vec{F} \cdot d\vec{r} = \int_{v_1}^{v_2} mv \cdot dv = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$

即：$W = \Delta E_k$

**对于多个力**：
$$W_{\text{合}} = W_1 + W_2 + \cdots + W_n = \Delta E_k$$
</details>

**动能定理的应用**：
1. 已知力求位移：$s = \frac{v_2^2 - v_1^2}{2a}$
2. 已知位移求速度：$v_2 = \sqrt{v_1^2 + \frac{2W}{m}}$
3. 已知初末速度求做功：$W = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$

**例题9**：质量为 $m = 1 \, \text{kg}$ 的物体，从静止开始受到 $F = 10 \, \text{N}$ 的水平拉力作用，摩擦力 $f = 2 \, \text{N}$，求物体移动 $s = 10 \, \text{m}$ 时的速度。

**解答**：
合外力做功：$W_{\text{合}} = (F - f)s = (10 - 2) \times 10 = 80 \, \text{J}$

根据动能定理：
$$W_{\text{合}} = \frac{1}{2}mv^2 - 0$$

$$80 = \frac{1}{2} \times 1 \times v^2$$

$$v = \sqrt{160} = 12.65 \, \text{m/s}$$

#### 1.3.3 势能

**势能的概念**

势能是物体由于位置或形变而具有的能量。与物体间的相互作用力有关。

**重力势能**

$$E_p = mgh$$

其中 $h$ 为相对于零势能面的高度。

重力势能的物理意义：将物体从参考面举高 $h$ 时重力所做的功。

**重力做功与重力势能的关系**：
$$W_G = -\Delta E_p = -(E_{p2} - E_{p1})$$

**弹性势能**

$$E_p = \frac{1}{2}kx^2$$

其中 $x$ 为弹簧的形变量。

弹性势能的物理意义：将弹簧从自然长度压缩或拉伸 $x$ 时弹力所做的功。

**弹力做功与弹性势能的关系**：
$$W_{\text{弹}} = -\Delta E_p = -(E_{p2} - E_{p1})$$

**万有引力势能**

$$E_p = -\frac{GMm}{r}$$

其中 $r$ 为两物体间的距离。

万有引力势能的物理意义：将物体从无穷远移到当前位置时万有引力所做的功。

**保守力与非保守力**

**保守力**：做功与路径无关，只与初末位置有关的力。
- 重力、弹力、万有引力、静电场力等
- 特点：可以定义势能

**非保守力**：做功与路径有关的力。
- 摩擦力、空气阻力等
- 特点：不能定义势能

**保守力的判别**：
1. 沿闭合路径做功为零：$\oint \vec{F} \cdot d\vec{r} = 0$
2. 存在势能函数：$\vec{F} = -\nabla E_p$

**例题10**：质量为 $m = 0.5 \, \text{kg}$ 的物体挂在劲度系数 $k = 100 \, \text{N/m}$ 的弹簧下，求：
(1) 弹簧伸长量
(2) 系统的重力势能和弹性势能（以弹簧原长时下端位置为零势能面）

**解答**：
(1) 平衡时：$kx = mg$
$$x = \frac{mg}{k} = \frac{0.5 \times 9.8}{100} = 0.049 \, \text{m}$$

(2) 重力势能：$E_{pG} = mgx = 0.5 \times 9.8 \times 0.049 = 0.24 \, \text{J}$

弹性势能：$E_{pK} = \frac{1}{2}kx^2 = \frac{1}{2} \times 100 \times (0.049)^2 = 0.12 \, \text{J}$

#### 1.3.4 机械能守恒定律

**机械能**

机械能是动能与势能之和：$E = E_k + E_p$

**机械能守恒定律**

在只有保守力做功的情况下，系统的机械能保持不变。

$$E_1 = E_2 = \text{常数}$$

即：$\Delta E_k + \Delta E_p = 0$

**机械能守恒条件**：
1. 只有保守力做功
2. 非保守力做功为零
3. 系统与外界无能量交换

<details>
<summary><strong>机械能守恒定律的推导</strong></summary>

**从动能定理出发**：
$$W_{\text{合}} = \Delta E_k$$

**合外力做功分为两部分**：
$$W_{\text{合}} = W_{\text{保守}} + W_{\text{非保守}}$$

**保守力做功等于势能减少**：
$$W_{\text{保守}} = -\Delta E_p$$

**代入得**：
$$W_{\text{非保守}} - \Delta E_p = \Delta E_k$$

**整理得**：
$$\Delta E_k + \Delta E_p = W_{\text{非保守}}$$

**当 $W_{\text{非保守}} = 0$ 时**：
$$\Delta E_k + \Delta E_p = 0$$

即：$E_1 = E_2$
</details>

**能量转化与守恒**

自然界中能量既不能创造也不能消灭，只能从一种形式转化为另一种形式。

**能量守恒定律**：$E_{\text{总}} = \text{常数}$

**常见能量形式**：
- 机械能：动能、势能
- 内能：分子动能、分子势能
- 热能：热运动能量
- 化学能：化学键能量
- 电磁能：电磁场能量

**例题11**：质量为 $m = 0.2 \, \text{kg}$ 的小球从高度 $h = 5 \, \text{m}$ 处自由下落，不计空气阻力，求：
(1) 小球落地时的速度
(2) 小球落地时的动能
(3) 重力势能的减少量

**解答**：
(1) 根据机械能守恒：
$$mgh = \frac{1}{2}mv^2$$
$$v = \sqrt{2gh} = \sqrt{2 \times 9.8 \times 5} = 9.9 \, \text{m/s}$$

(2) 动能：$E_k = \frac{1}{2}mv^2 = \frac{1}{2} \times 0.2 \times (9.9)^2 = 9.8 \, \text{J}$

(3) 重力势能减少量：$\Delta E_p = mgh = 0.2 \times 9.8 \times 5 = 9.8 \, \text{J}$

### 1.4 动量守恒定律

动量是描述物体运动状态的另一个重要物理量，与动能不同，动量是矢量。动量守恒定律是自然界的基本定律之一。

#### 1.4.1 冲量与动量

**动量**

动量是物体质量与速度的乘积。

$$\vec{p} = m\vec{v}$$

动量是矢量，方向与速度方向相同。

单位：kg·m/s

**冲量**

冲量是力在时间上的累积效果。

$$\vec{I} = \int_{t_1}^{t_2} \vec{F} dt$$

对于恒力：$\vec{I} = \vec{F}\Delta t$

冲量是矢量，方向与力的方向相同。

单位：N·s

**动量定理**

合外力的冲量等于物体动量的变化量。

$$\vec{I} = \Delta \vec{p} = \vec{p}_2 - \vec{p}_1$$

<details>
<summary><strong>动量定理的推导</strong></summary>

**从牛顿第二定律出发**：
$$\vec{F} = \frac{d\vec{p}}{dt}$$

**两边对时间积分**：
$$\int_{t_1}^{t_2} \vec{F} dt = \int_{t_1}^{t_2} \frac{d\vec{p}}{dt} dt = \int_{\vec{p}_1}^{\vec{p}_2} d\vec{p} = \vec{p}_2 - \vec{p}_1$$

即：$\vec{I} = \Delta \vec{p}$

**物理意义**：
- 冲量是力对时间的累积
- 动量变化需要冲量来实现
- 同样的动量变化，力越大时间越短，或时间越长力越小
</details>

**动量定理的分量形式**：
$$I_x = \Delta p_x, \quad I_y = \Delta p_y, \quad I_z = \Delta p_z$$

**平均冲力**：
$$\vec{F}_{\text{平均}} = \frac{\vec{I}}{\Delta t} = \frac{\Delta \vec{p}}{\Delta t}$$

**例题12**：质量为 $m = 0.1 \, \text{kg}$ 的小球，以 $v = 10 \, \text{m/s}$ 的速度撞墙后以 $v' = 8 \, \text{m/s}$ 的速度反弹，碰撞时间为 $\Delta t = 0.01 \, \text{s}$，求：
(1) 小球动量的变化
(2) 墙对小球的平均冲力

**解答**：
设墙的方向为正方向。

(1) 动量变化：
$$\Delta p = mv' - mv = 0.1 \times 8 - 0.1 \times (-10) = 0.8 + 1.0 = 1.8 \, \text{kg·m/s}$$

(2) 平均冲力：
$$F = \frac{\Delta p}{\Delta t} = \frac{1.8}{0.01} = 180 \, \text{N}$$

#### 1.4.2 动量守恒定律

**动量守恒定律**

当系统不受外力或所受外力的合力为零时，系统的总动量保持不变。

$$\sum \vec{p}_i = \text{常数}$$

即：$\sum m_i\vec{v}_i = \text{常数}$

**动量守恒条件**：
1. 系统不受外力：$\sum \vec{F}_{\text{外}} = 0$
2. 系统所受外力的合力为零：$\sum \vec{F}_{\text{外}} = 0$
3. 内力远大于外力时，可近似认为动量守恒

**动量守恒的分量形式**：
$$\sum p_{ix} = \text{常数}, \quad \sum p_{iy} = \text{常数}, \quad \sum p_{iz} = \text{常数}$$

<details>
<summary><strong>动量守恒定律的推导</strong></summary>

**从牛顿第三定律出发**：
对于由 $n$ 个质点组成的系统，任意两个质点间的作用力与反作用力大小相等、方向相反：
$$\vec{F}_{ij} = -\vec{F}_{ji}$$

**系统所受的合外力**：
$$\vec{F}_{\text{合}} = \sum_{i=1}^{n} \vec{F}_{i\text{外}}$$

**每个质点所受的力**：
$$\vec{F}_i = \vec{F}_{i\text{外}} + \sum_{j \neq i} \vec{F}_{ij}$$

**根据牛顿第二定律**：
$$\vec{F}_i = \frac{d\vec{p}_i}{dt}$$

**对所有质点求和**：
$$\sum_{i=1}^{n} \vec{F}_i = \sum_{i=1}^{n} \frac{d\vec{p}_i}{dt} = \frac{d}{dt}\sum_{i=1}^{n} \vec{p}_i$$

**左边**：
$$\sum_{i=1}^{n} \vec{F}_i = \sum_{i=1}^{n} \vec{F}_{i\text{外}} + \sum_{i=1}^{n} \sum_{j \neq i} \vec{F}_{ij}$$

**由于作用力与反作用力成对出现**：
$$\sum_{i=1}^{n} \sum_{j \neq i} \vec{F}_{ij} = 0$$

**所以**：
$$\sum_{i=1}^{n} \vec{F}_{i\text{外}} = \frac{d}{dt}\sum_{i=1}^{n} \vec{p}_i$$

**当 $\sum \vec{F}_{i\text{外}} = 0$ 时**：
$$\frac{d}{dt}\sum_{i=1}^{n} \vec{p}_i = 0$$

即：$\sum \vec{p}_i = \text{常数}$
</details>

**碰撞问题**

碰撞是动量守恒定律的重要应用。根据碰撞后物体的形变恢复情况，碰撞可分为三类。

**弹性碰撞**：
- 碰撞前后动量守恒：$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$
- 碰撞前后动能守恒：$\frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 = \frac{1}{2}m_1v_1'^2 + \frac{1}{2}m_2v_2'^2$
- 碰撞后物体形状完全恢复

**一维弹性碰撞的速度公式**：
$$v_1' = \frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2}$$
$$v_2' = \frac{(m_2 - m_1)v_2 + 2m_1v_1}{m_1 + m_2}$$

**完全非弹性碰撞**：
- 碰撞前后动量守恒：$m_1v_1 + m_2v_2 = (m_1 + m_2)v'$
- 碰撞后两物体粘在一起，具有相同速度
- 动能不守恒，有动能损失

**非弹性碰撞**：
- 碰撞前后动量守恒
- 碰撞前后动能不守恒
- 碰撞后物体有部分形变

**碰撞中的能量损失**：
$$\Delta E_k = E_{k\text{初}} - E_{k\text{末}} = \frac{1}{2}\mu(v_1 - v_2)^2 - \frac{1}{2}\mu(v_1' - v_2')^2$$

其中 $\mu = \frac{m_1m_2}{m_1 + m_2}$ 为约化质量。

**例题13**：质量为 $m_1 = 2 \, \text{kg}$ 的物体A以 $v_1 = 6 \, \text{m/s}$ 的速度与静止在光滑水平面上质量为 $m_2 = 3 \, \text{kg}$ 的物体B发生弹性碰撞，求碰撞后两物体的速度。

**解答**：
根据一维弹性碰撞公式：
$$v_1' = \frac{(m_1 - m_2)v_1 + 2m_2v_2}{m_1 + m_2} = \frac{(2 - 3) \times 6 + 2 \times 3 \times 0}{2 + 3} = \frac{-6}{5} = -1.2 \, \text{m/s}$$

$$v_2' = \frac{(m_2 - m_1)v_2 + 2m_1v_1}{m_1 + m_2} = \frac{(3 - 2) \times 0 + 2 \times 2 \times 6}{5} = \frac{24}{5} = 4.8 \, \text{m/s}$$

验证：动量守恒：$2 \times 6 + 3 \times 0 = 2 \times (-1.2) + 3 \times 4.8 = -2.4 + 14.4 = 12 \, \text{kg·m/s}$（守恒）

动能守恒：$\frac{1}{2} \times 2 \times 6^2 = 36 \, \text{J}$，$\frac{1}{2} \times 2 \times (-1.2)^2 + \frac{1}{2} \times 3 \times 4.8^2 = 1.44 + 34.56 = 36 \, \text{J}$（守恒）

#### 1.4.3 变质量系统

**火箭推进原理**

火箭在推进过程中不断喷射燃气，质量逐渐减小，是典型的变质量问题。

**火箭运动方程**：
设火箭质量为 $m$，速度为 $\vec{v}$，在时间 $dt$ 内喷出质量为 $dm$（$dm < 0$）的燃气，燃气相对于火箭的速度为 $\vec{u}$。

根据动量守恒：
$$m\vec{v} = (m + dm)(\vec{v} + d\vec{v}) + (-dm)(\vec{v} - \vec{u})$$

忽略二阶小量 $dm \cdot d\vec{v}$，得：
$$m d\vec{v} = -\vec{u} dm$$

$$\vec{F}_{\text{外}} = m\frac{d\vec{v}}{dt} = -\vec{u}\frac{dm}{dt}$$

火箭受到的推力：$\vec{F}_{\text{推}} = -\vec{F}_{\text{外}} = \vec{u}\frac{dm}{dt}$

**齐奥尔科夫斯基公式**：
对于火箭从静止开始，在重力场外飞行：
$$v = u \ln\frac{m_0}{m}$$

其中 $m_0$ 为初始质量，$m$ 为剩余质量。

**火箭效率**：
$$\eta = \frac{\text{火箭动能}}{\text{燃料化学能}} = \frac{\frac{1}{2}m v^2}{\frac{1}{2} \frac{dm}{dt} u^2 \cdot t}$$

#### 1.4.4 质心运动定理

**质心的定义**

质心是质点系质量分布的平均位置。

$$\vec{r}_c = \frac{\sum m_i\vec{r}_i}{\sum m_i} = \frac{\sum m_i\vec{r}_i}{M}$$

其中 $M = \sum m_i$ 为系统总质量。

**质心运动定理**

质心的运动等于将全部质量集中在质心上的合外力作用下的运动。

$$M\vec{a}_c = \sum \vec{F}_{\text{外}}$$

即：$\sum \vec{F}_{\text{外}} = M\frac{d^2\vec{r}_c}{dt^2}$

**质心运动守恒**：
当 $\sum \vec{F}_{\text{外}} = 0$ 时，$\vec{v}_c = \text{常数}$，质心做匀速直线运动。

**例题14**：质量为 $m_1 = 2 \, \text{kg}$ 和 $m_2 = 3 \, \text{kg}$ 的两个物体，分别位于 $(0, 0)$ 和 $(4, 3)$ 处，求系统质心的位置。

**解答**：
总质量：$M = m_1 + m_2 = 5 \, \text{kg}$

质心坐标：
$$x_c = \frac{m_1x_1 + m_2x_2}{M} = \frac{2 \times 0 + 3 \times 4}{5} = \frac{12}{5} = 2.4 \, \text{m}$$

$$y_c = \frac{m_1y_1 + m_2y_2}{M} = \frac{2 \times 0 + 3 \times 3}{5} = \frac{9}{5} = 1.8 \, \text{m}$$

质心位置：$(2.4, 1.8) \, \text{m}$

### 1.5 刚体力学

刚体力学研究不能形变的物体的运动规律。刚体是实际物体在一定条件下的理想化模型。

#### 1.5.1 刚体运动学

**刚体的定义**

刚体是在任何外力作用下，其大小和形状都不发生变化的物体。

**刚体的运动形式**：
1. **平动**：刚体上任意两点间的连线始终保持平行
2. **转动**：刚体上各点都绕同一固定轴线做圆周运动
3. **平面运动**：平动和转动的合成

**平动**

**平动特点**：
- 刚体上所有点的轨迹相同
- 所有点的速度相同：$\vec{v}_A = \vec{v}_B$
- 所有点的加速度相同：$\vec{a}_A = \vec{a}_B$

**平动方程**：
刚体的平动可以简化为质点的运动，使用质点运动学方法。

**转动**

**转动特点**：
- 刚体上各点都绕同一固定轴线做圆周运动
- 各点的角速度相同：$\omega_A = \omega_B$
- 各点的角加速度相同：$\alpha_A = \alpha_B$
- 各点的线速度不同：$v = \omega r$

**角位移**：$\Delta\theta$

**角速度**：$\omega = \frac{d\theta}{dt}$

**角加速度**：$\alpha = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$

**匀变速转动公式**：
$$\omega = \omega_0 + \alpha t$$
$$\theta = \omega_0 t + \frac{1}{2}\alpha t^2$$
$$\omega^2 = \omega_0^2 + 2\alpha\theta$$

**平面运动**

平面运动是平动和转动的合成。

**运动分解**：
1. **随基点的平动**：基点的运动
2. **绕基点的转动**：相对基点的转动

**基点选择**：
- 通常选择质心或固定点作为基点
- 基点选择不同，分解形式不同，但运动结果相同

#### 1.5.2 转动惯量

**转动惯量的定义**

转动惯量是刚体转动惯性大小的量度。

**点质量的转动惯量**：
$$I = mr^2$$

其中 $r$ 为点到转轴的距离。

**离散质点系的转动惯量**：
$$I = \sum_{i=1}^{n} m_i r_i^2$$

**连续刚体的转动惯量**：
$$I = \int r^2 dm$$

其中 $dm$ 为质量元。

**转动惯量的物理意义**：
- 转动惯量越大，越难改变转动状态
- 转动惯量与质量分布有关
- 转动惯量与转轴位置有关

**常见刚体的转动惯量**：

1. **细棒（转轴通过中心）**：$I = \frac{1}{12}ml^2$

2. **细棒（转轴通过一端）**：$I = \frac{1}{3}ml^2$

3. **圆环（转轴通过中心垂直环面）**：$I = mr^2$

4. **圆盘（转轴通过中心垂直盘面）**：$I = \frac{1}{2}mr^2$

5. **球体（转轴通过球心）**：$I = \frac{2}{5}mr^2$

6. **圆柱体（转轴沿几何轴线）**：$I = \frac{1}{2}mr^2$

<details>
<summary><strong>圆盘转动惯量的推导</strong></summary>

**问题**：求质量为 $m$、半径为 $R$ 的均匀圆盘绕通过中心且垂直于盘面的轴的转动惯量。

**解法**：
将圆盘分割为许多同心圆环，取半径为 $r$、宽度为 $dr$ 的圆环。

圆环面积：$dS = 2\pi r dr$

圆环质量：$dm = \frac{m}{\pi R^2} \cdot 2\pi r dr = \frac{2m}{R^2} r dr$

圆环的转动惯量：$dI = r^2 dm = r^2 \cdot \frac{2m}{R^2} r dr = \frac{2m}{R^2} r^3 dr$

积分：
$$I = \int dI = \int_0^R \frac{2m}{R^2} r^3 dr = \frac{2m}{R^2} \int_0^R r^3 dr = \frac{2m}{R^2} \cdot \frac{R^4}{4} = \frac{1}{2}mr^2$$
</details>

**平行轴定理**

刚体绕任意轴的转动惯量等于绕通过质心且平行于该轴的转动惯量加上刚体质量与两轴间距离平方的乘积。

$$I = I_c + md^2$$

其中：
- $I_c$ 为绕质心轴的转动惯量
- $d$ 为两平行轴间的距离
- $m$ 为刚体质量

**垂直轴定理**

对于薄板，绕垂直于板面的轴的转动惯量等于绕板面内两互相垂直轴的转动惯量之和。

$$I_z = I_x + I_y$$

**例题15**：质量为 $m = 2 \, \text{kg}$、长度为 $l = 1 \, \text{m}$ 的均匀细棒，求：
(1) 绕通过中心且垂直于棒长的轴的转动惯量
(2) 绕通过一端且垂直于棒长的轴的转动惯量

**解答**：
(1) 绕中心轴：$I_c = \frac{1}{12}ml^2 = \frac{1}{12} \times 2 \times 1^2 = \frac{1}{6} \, \text{kg·m}^2$

(2) 绕一端轴：使用平行轴定理
$$I = I_c + md^2 = \frac{1}{6} + 2 \times \left(\frac{1}{2}\right)^2 = \frac{1}{6} + 2 \times \frac{1}{4} = \frac{1}{6} + \frac{1}{2} = \frac{2}{3} \, \text{kg·m}^2$$

#### 1.5.3 转动定律

**力矩**

力矩是力使物体转动效果的物理量。

**力矩的定义**：
$$\vec{M} = \vec{r} \times \vec{F}$$

其中 $\vec{r}$ 为从转轴到力作用点的位置矢量。

**力矩的大小**：
$$M = rF\sin\theta = Fd$$

其中 $d = r\sin\theta$ 为力臂。

**力矩的单位**：N·m

**力矩的方向**：右手螺旋定则确定。

**转动定律**

刚体绕固定轴的转动定律：
$$M = I\alpha$$

其中：
- $M$ 为合外力矩
- $I$ 为转动惯量
- $\alpha$ 为角加速度

<details>
<summary><strong>转动定律的推导</strong></summary>

**从牛顿第二定律出发**：
对于刚体上的第 $i$ 个质点：
$$F_{i\text{切}} = m_i a_{i\text{切}} = m_i r_i \alpha$$

**力矩**：$M_i = r_i F_{i\text{切}} = m_i r_i^2 \alpha$

**对所有质点求和**：
$$\sum M_i = \sum m_i r_i^2 \alpha = \alpha \sum m_i r_i^2 = I\alpha$$

即：$M = I\alpha$
</details>

**转动定律与平动定律的对比**：
| 平动 | 转动 |
|------|------|
| $F = ma$ | $M = I\alpha$ |
| 质量 $m$ | 转动惯量 $I$ |
| 加速度 $a$ | 角加速度 $\alpha$ |

**例题16**：质量为 $m = 1 \, \text{kg}$、半径为 $r = 0.5 \, \text{m}$ 的圆盘，绕过中心且垂直于盘面的轴转动。在圆盘边缘施加切向力 $F = 2 \, \text{N}$，求角加速度。

**解答**：
圆盘的转动惯量：$I = \frac{1}{2}mr^2 = \frac{1}{2} \times 1 \times (0.5)^2 = 0.125 \, \text{kg·m}^2$

力矩：$M = Fr = 2 \times 0.5 = 1 \, \text{N·m}$

根据转动定律：$\alpha = \frac{M}{I} = \frac{1}{0.125} = 8 \, \text{rad/s}^2$

#### 1.5.4 角动量守恒

**角动量**

角动量是描述刚体转动状态的物理量。

**质点的角动量**：
$$\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$$

**刚体的角动量**：
$$\vec{L} = I\vec{\omega}$$

**角动量的单位**：kg·m²/s

**角动量定理**

合外力矩的冲量矩等于角动量的变化量。

$$\vec{M} = \frac{d\vec{L}}{dt}$$

$$\int_{t_1}^{t_2} \vec{M} dt = \Delta \vec{L} = \vec{L}_2 - \vec{L}_1$$

**角动量守恒定律**

当刚体所受的合外力矩为零时，角动量保持不变。

$$\vec{L} = I\vec{\omega} = \text{常数}$$

**角动量守恒的情况**：
1. **合外力矩为零**
2. **内力矩相互抵消**
3. **转轴光滑，无摩擦力矩**

**角动量守恒的应用**：
- 花样滑冰运动员收拢手臂提高转速
- 直升机尾翼的作用
- 陀螺仪的稳定性

**例题17**：质量为 $m = 60 \, \text{kg}$ 的花样滑冰运动员，以 $\omega_1 = 3 \, \text{rad/s}$ 的角速度旋转时，转动惯量 $I_1 = 6 \, \text{kg·m}^2$。当她收拢手臂后，转动惯量变为 $I_2 = 2 \, \text{kg·m}^2$，求收拢后的角速度。

**解答**：
根据角动量守恒：$I_1\omega_1 = I_2\omega_2$

$$\omega_2 = \frac{I_1\omega_1}{I_2} = \frac{6 \times 3}{2} = 9 \, \text{rad/s}$$

#### 1.5.5 转动动能

**转动动能**

刚体转动时具有的动能。

$$E_k = \frac{1}{2}I\omega^2$$

**转动动能与平动动能的比较**：
- 平动动能：$E_{k\text{平}} = \frac{1}{2}mv^2$
- 转动动能：$E_{k\text{转}} = \frac{1}{2}I\omega^2$

**转动动能定理**

合外力矩所做的功等于转动动能的变化量。

$$W = \Delta E_k = \frac{1}{2}I\omega_2^2 - \frac{1}{2}I\omega_1^2$$

**力矩做功**：
$$W = \int M d\theta$$

对于恒力矩：$W = M\Delta\theta$

**例题18**：质量为 $m = 4 \, \text{kg}$、半径为 $r = 0.3 \, \text{m}$ 的圆盘，绕过中心且垂直于盘面的轴转动。初始角速度 $\omega_1 = 10 \, \text{rad/s}$，制动后停止。求制动过程中摩擦力矩所做的功。

**解答**：
圆盘的转动惯量：$I = \frac{1}{2}mr^2 = \frac{1}{2} \times 4 \times (0.3)^2 = 0.18 \, \text{kg·m}^2$

初始转动动能：$E_{k1} = \frac{1}{2}I\omega_1^2 = \frac{1}{2} \times 0.18 \times 10^2 = 9 \, \text{J}$

最终转动动能：$E_{k2} = 0$

摩擦力矩做功：$W = E_{k2} - E_{k1} = 0 - 9 = -9 \, \text{J}$

#### 1.5.6 刚体的平面运动

**平面运动的分析方法**

1. **基点法**：选择基点，将运动分解为随基点的平动和绕基点的转动
2. **瞬心法**：找到瞬时转动中心

**瞬心**

瞬心是刚体在该瞬间速度为零的点。

**瞬心的确定**：
1. 已知两点速度方向：两速度垂线交点
2. 已知一点速度方向和另一点速度大小：作垂线找交点
3. 纯滚动：接触点为瞬心

**纯滚动**

物体在粗糙面上滚动而不滑动。

**纯滚动的条件**：$v = \omega r$

**纯滚动的运动学关系**：
- 质心速度：$v_c = \omega r$
- 质心加速度：$a_c = \alpha r$

**纯滚动的动力学分析**：
以圆柱体在水平面上纯滚动为例：

**受力分析**：
- 重力：$mg$（竖直向下）
- 支持力：$N$（竖直向上）
- 摩擦力：$f$（水平方向）

**质心运动方程**：
$$f = ma_c$$

**转动方程**：
$$fr = I\alpha$$

**纯滚动条件**：
$$a_c = \alpha r$$

**例题19**：质量为 $m = 2 \, \text{kg}$、半径为 $r = 0.2 \, \text{m}$ 的圆柱体在水平面上纯滚动，质心加速度 $a_c = 2 \, \text{m/s}^2$，求摩擦力。

**解答**：
圆柱体的转动惯量：$I = \frac{1}{2}mr^2 = \frac{1}{2} \times 2 \times (0.2)^2 = 0.04 \, \text{kg·m}^2$

转动方程：$fr = I\alpha$

纯滚动条件：$\alpha = \frac{a_c}{r} = \frac{2}{0.2} = 10 \, \text{rad/s}^2$

摩擦力：$f = \frac{I\alpha}{r} = \frac{0.04 \times 10}{0.2} = 2 \, \text{N}$

### 1.6 机械振动

机械振动是物体在平衡位置附近的往复运动。振动现象在自然界和工程技术中非常普遍。

#### 1.6.1 简谐运动

**简谐运动的定义**

物体在跟偏离平衡位置的位移大小成正比，并且总是指向平衡位置的力的作用下的运动。

**简谐运动方程**

位移：$x = A\cos(\omega t + \phi)$

速度：$v = \frac{dx}{dt} = -A\omega\sin(\omega t + \phi)$

加速度：$a = \frac{dv}{dt} = -A\omega^2\cos(\omega t + \phi) = -\omega^2x$

其中：
- $A$ 为振幅（m）
- $\omega$ 为角频率（rad/s）
- $\phi$ 为初相（rad）
- $\omega t + \phi$ 为相位（rad）

**简谐运动的特征量**

1. **振幅 $A$**：振动的最大位移
2. **周期 $T$**：完成一次完整振动所需时间
   $$T = \frac{2\pi}{\omega}$$
3. **频率 $f$**：单位时间内完成的振动次数
   $$f = \frac{1}{T} = \frac{\omega}{2\pi}$$
4. **角频率 $\omega$**：$\omega = 2\pi f = \frac{2\pi}{T}$

**简谐运动的动力学特征**

从牛顿第二定律：$F = ma = -m\omega^2x$

回复力：$F = -kx$

其中 $k = m\omega^2$ 为等效劲度系数。

**简谐运动的周期**：
$$T = 2\pi\sqrt{\frac{m}{k}}$$

**常见简谐振动系统**：

1. **水平弹簧振子**：$T = 2\pi\sqrt{\frac{m}{k}}$
2. **竖直弹簧振子**：$T = 2\pi\sqrt{\frac{m}{k}}$（平衡位置发生变化，但周期不变）
3. **单摆**：$T = 2\pi\sqrt{\frac{l}{g}}$（小角度近似）
4. **复摆**：$T = 2\pi\sqrt{\frac{I}{mgd}}$

<details>
<summary><strong>单摆周期的推导</strong></summary>

**问题**：求单摆在小角度振动时的周期。

**受力分析**：
- 重力：$mg$（竖直向下）
- 拉力：$T$（沿绳方向）

**切向运动方程**：
$$-mg\sin\theta = ml\frac{d^2\theta}{dt^2}$$

**小角度近似**：$\sin\theta \approx \theta$

**得**：$\frac{d^2\theta}{dt^2} + \frac{g}{l}\theta = 0$

**与标准简谐运动方程对比**：$\frac{d^2\theta}{dt^2} + \omega^2\theta = 0$

**得**：$\omega = \sqrt{\frac{g}{l}}$

**周期**：$T = \frac{2\pi}{\omega} = 2\pi\sqrt{\frac{l}{g}}$
</details>

**简谐运动的图像**

- **x-t 图像**：余弦曲线
- **v-t 图像**：正弦曲线
- **a-t 图像**：余弦曲线（与 x-t 图像反相）

**例题20**：质量为 $m = 0.5 \, \text{kg}$ 的物体连接在劲度系数 $k = 50 \, \text{N/m}$ 的弹簧上，做简谐运动。求：
(1) 振动的周期
(2) 如果振幅 $A = 0.1 \, \text{m}$，求最大速度和最大加速度

**解答**：
(1) 周期：$T = 2\pi\sqrt{\frac{m}{k}} = 2\pi\sqrt{\frac{0.5}{50}} = 2\pi\sqrt{0.01} = 0.628 \, \text{s}$

(2) 角频率：$\omega = \frac{2\pi}{T} = \frac{2\pi}{0.628} = 10 \, \text{rad/s}$

最大速度：$v_{\text{max}} = A\omega = 0.1 \times 10 = 1 \, \text{m/s}$

最大加速度：$a_{\text{max}} = A\omega^2 = 0.1 \times 10^2 = 10 \, \text{m/s}^2$

#### 1.6.2 简谐运动的合成

**同方向简谐运动的合成**

当两个简谐运动频率相同时，合成后仍为简谐运动。

**一般情况**：
$$x_1 = A_1\cos(\omega t + \phi_1)$$
$$x_2 = A_2\cos(\omega t + \phi_2)$$

**合成结果**：
$$x = A\cos(\omega t + \phi)$$

其中：
$$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\phi_2 - \phi_1)}$$

$$\tan\phi = \frac{A_1\sin\phi_1 + A_2\sin\phi_2}{A_1\cos\phi_1 + A_2\cos\phi_2}$$

**特殊情况**：
1. **同相**：$\phi_2 - \phi_1 = 0$，$A = A_1 + A_2$
2. **反相**：$\phi_2 - \phi_1 = \pi$，$A = |A_1 - A_2|$

**不同频率简谐运动的合成**

当两个简谐运动频率不同时，合成运动不是简谐运动。

**拍现象**：
当两个频率相近的简谐运动合成时，会出现振幅时大时小的现象，称为拍。

**拍频**：$f_{\text{拍}} = |f_1 - f_2|$

**垂直方向简谐运动的合成**

**李萨如图形**：
当两个互相垂直的简谐运动合成时，质点的轨迹为李萨如图形。

- 频率比为整数比时，轨迹为闭合曲线
- 频率比不同时，轨迹为复杂曲线

#### 1.6.3 阻尼振动

**阻尼振动方程**

考虑阻尼力 $F_d = -\gamma v$ 的影响，运动方程为：
$$\frac{d^2x}{dt^2} + 2\beta\frac{dx}{dt} + \omega_0^2x = 0$$

其中：
- $\beta = \frac{\gamma}{2m}$ 为阻尼系数
- $\omega_0 = \sqrt{\frac{k}{m}}$ 为固有角频率

**阻尼振动的三种情况**：

1. **欠阻尼（$\beta < \omega_0$）**：
   $$x = A_0 e^{-\beta t}\cos(\omega t + \phi)$$
   其中 $\omega = \sqrt{\omega_0^2 - \beta^2}$

2. **临界阻尼（$\beta = \omega_0$）**：
   $$x = (A + Bt)e^{-\beta t}$$

3. **过阻尼（$\beta > \omega_0$）**：
   $$x = A_1 e^{-\beta_1 t} + A_2 e^{-\beta_2 t}$$

**阻尼振动的特征**：
- 振幅随时间指数衰减
- 周期略大于无阻尼时的周期
- 能量不断耗散

**对数减缩**：
$$\delta = \ln\frac{A_n}{A_{n+1}} = \beta T$$

其中 $A_n$ 为第 $n$ 个振幅。

**品质因数**：
$$Q = \frac{\omega_0}{2\beta}$$

#### 1.6.4 受迫振动

**受迫振动方程**

在周期性外力作用下的振动：
$$\frac{d^2x}{dt^2} + 2\beta\frac{dx}{dt} + \omega_0^2x = f_0\cos\omega t$$

其中 $f_0 = \frac{F_0}{m}$ 为外力振幅。

**受迫振动的稳态解**：
$$x = A\cos(\omega t + \phi)$$

其中：
$$A = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}$$

$$\tan\phi = -\frac{2\beta\omega}{\omega_0^2 - \omega^2}$$

**受迫振动的特征**：
1. 稳态时振动频率等于驱动力频率
2. 振幅与驱动力频率有关
3. 存在相位差

**共振现象**

当驱动力频率等于系统的固有频率时，振幅达到最大值，称为共振。

**共振频率**：
$$\omega_r = \sqrt{\omega_0^2 - 2\beta^2}$$

当阻尼很小时：$\omega_r \approx \omega_0$

**共振振幅**：
$$A_{\text{max}} = \frac{f_0}{2\beta\sqrt{\omega_0^2 - \beta^2}}$$

**共振的物理意义**：
- 小驱动力可获得大振动
- 工程中需避免共振
- 某些情况下需要利用共振

**例题21**：一受迫振动系统的固有频率 $\omega_0 = 10 \, \text{rad/s}$，阻尼系数 $\beta = 1 \, \text{s}^{-1}$，驱动力频率 $\omega = 8 \, \text{rad/s}$，驱动力振幅 $f_0 = 5 \, \text{m/s}^2$，求稳态振幅。

**解答**：
$$A = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}$$

$$A = \frac{5}{\sqrt{(10^2 - 8^2)^2 + 4 \times 1^2 \times 8^2}}$$

$$A = \frac{5}{\sqrt{(100 - 64)^2 + 256}} = \frac{5}{\sqrt{36^2 + 256}} = \frac{5}{\sqrt{1296 + 256}} = \frac{5}{\sqrt{1552}} \approx 0.127 \, \text{m}$$

#### 1.6.5 振动的能量

**简谐振动的能量**

动能：$E_k = \frac{1}{2}mv^2 = \frac{1}{2}m\omega^2A^2\sin^2(\omega t + \phi)$

势能：$E_p = \frac{1}{2}kx^2 = \frac{1}{2}kA^2\cos^2(\omega t + \phi)$

总能量：$E = E_k + E_p = \frac{1}{2}kA^2 = \frac{1}{2}m\omega^2A^2 = \text{常数}$

**能量特点**：
- 总能量守恒
- 动能和势能相互转化
- 振幅决定总能量大小

**阻尼振动的能量**：
$$E = E_0 e^{-2\beta t}$$

**受迫振动的能量**：
稳态时，振动系统的能量保持不变，阻尼损耗的能量由驱动力补充。

### 1.7 机械波

机械波是机械振动在弹性介质中的传播。波是能量和信息的携带者。

#### 1.7.1 机械波的产生与传播

**波的产生条件**

1. **波源**：产生机械振动的物体
2. **介质**：能够传播机械振动的弹性物质
3. **能量**：维持振动的能量供给

**波的传播机制**

波在介质中的传播是通过介质质点的振动实现的：
1. 介质质点在平衡位置附近振动
2. 振动状态在介质中传播
3. 质点本身不随波迁移

**机械波的分类**：

1. **按质点振动方向与波传播方向的关系**：
   - **横波**：质点振动方向垂直于波传播方向
   - **纵波**：质点振动方向平行于波传播方向

2. **按波阵面形状**：
   - **平面波**：波阵面为平面
   - **球面波**：波阵面为球面
   - **柱面波**：波阵面为柱面

**波速与波长**

**波速 $v$**：波在介质中传播的速度
- 取决于介质的弹性性质和密度
- 与波的频率和振幅无关

**波长 $\lambda$**：一个完整波的长度
- 相邻两个同相位点之间的距离
- $\lambda = vT = \frac{v}{f}$

**频率 $f$**：波源的振动频率
- 由波源决定
- 在传播过程中保持不变

**周期 $T$**：完成一次完整振动的时间
- $T = \frac{1}{f}$

**基本关系**：$v = \lambda f = \frac{\lambda}{T}$

**例题22**：声波在空气中的传播速度为 $340 \, \text{m/s}$，频率为 $500 \, \text{Hz}$，求波长。

**解答**：
$$\lambda = \frac{v}{f} = \frac{340}{500} = 0.68 \, \text{m}$$

#### 1.7.2 平面简谐波

**平面简谐波方程**

设波沿 $x$ 轴正方向传播，波源在 $x = 0$ 处的振动方程为：
$$y_0 = A\cos(\omega t + \phi)$$

则平面简谐波方程为：
$$y = A\cos\left[\omega\left(t - \frac{x}{v}\right) + \phi\right]$$

或：
$$y = A\cos\left(2\pi\frac{t}{T} - 2\pi\frac{x}{\lambda} + \phi\right)$$

**波动方程的标准形式**：
$$y = A\cos(\omega t - kx + \phi)$$

其中波数 $k = \frac{2\pi}{\lambda}$ 称为波矢。

**波动方程的物理意义**：
- $t$ 固定时，$y$ 随 $x$ 的变化表示某一时刻的波形
- $x$ 固定时，$y$ 随 $t$ 的变化表示某一质点的振动
- $y$ 随 $t$ 和 $x$ 的变化表示波的传播

**波速的物理意义**：
波速 $v$ 是振动状态（相位）的传播速度，也称为相速度。

**波的能量传播**

介质中质点的动能：
$$dE_k = \frac{1}{2}(dm)v^2 = \frac{1}{2}\rho dV \omega^2A^2\sin^2\left[\omega\left(t - \frac{x}{v}\right)\right]$$

介质中质点的势能：
$$dE_p = \frac{1}{2}(dm)\omega^2A^2\sin^2\left[\omega\left(t - \frac{x}{v}\right)\right]$$

总能量：
$$dE = dE_k + dE_p = \rho dV \omega^2A^2\sin^2\left[\omega\left(t - \frac{x}{v}\right)\right]$$

**能量密度**：
$$w = \frac{dE}{dV} = \rho\omega^2A^2\sin^2\left[\omega\left(t - \frac{x}{v}\right)\right]$$

**平均能量密度**：
$$\bar{w} = \frac{1}{2}\rho\omega^2A^2$$

**能流密度（波的强度）**：
$$I = \bar{w}v = \frac{1}{2}\rho\omega^2A^2v$$

**波的能量特点**：
1. 能量随振动周期变化
2. 能量向前传播
3. 强度与振幅的平方成正比

#### 1.7.3 波的叠加原理

**波的叠加原理**

当多列波在同一介质中相遇时，每列波都独立地保持自己的特性（频率、波长、振动方向等）继续传播，在相遇区域中介质质点的振动是各列波单独引起振动的矢量和。

**波的干涉**

当两列频率相同、振动方向相同、相位差恒定的波相遇时，会产生干涉现象。

**相干条件**：
1. 频率相同
2. 振动方向相同
3. 相位差恒定

**干涉加强和减弱的条件**：

设两列波的波动方程：
$$y_1 = A_1\cos\left(\omega t - kx + \phi_1\right)$$
$$y_2 = A_2\cos\left(\omega t - kx + \phi_2\right)$$

合成波：$y = y_1 + y_2$

**相位差**：$\Delta\phi = \phi_2 - \phi_1$

**干涉条件**：
- **加强**：$\Delta\phi = 2n\pi$ 或 $\Delta\phi = 2n\pi + 2k\frac{x}{\lambda}$，其中 $k = \frac{2\pi}{\lambda}$
- **减弱**：$\Delta\phi = (2n+1)\pi$ 或 $\Delta\phi = (2n+1)\pi + 2k\frac{x}{\lambda}$

**用波程差表示**：
设两波到达某点的波程差为 $\delta$

- **加强**：$\delta = n\lambda$（$n = 0, 1, 2, \ldots$）
- **减弱**：$\delta = (2n+1)\frac{\lambda}{2}$（$n = 0, 1, 2, \ldots$）

**例题23**：两列相干波在空间某点相遇，波程差 $\delta = 2 \, \text{cm}$，波长 $\lambda = 8 \, \text{cm}$，求干涉结果。

**解答**：
波程差与波长的比值：$\frac{\delta}{\lambda} = \frac{2}{8} = 0.25$

由于 $\delta = \frac{\lambda}{4} = (2 \times 0 + 1)\frac{\lambda}{2}$，属于减弱条件。

该点为干涉减弱点。

#### 1.7.4 惠更斯原理

**惠更斯原理**

介质中波动传到的任意一点，都可看作是发射子波的波源，在其后任意时刻，这些子波的包络面就是新的波阵面。

**惠更斯原理的应用**：
1. **波的反射**：入射角等于反射角
2. **波的折射**：$\frac{\sin i}{\sin r} = \frac{v_1}{v_2} = n_{21}$
3. **波的衍射**：波可以绕过障碍物传播

**波的衍射**

波在传播过程中遇到障碍物或小孔时，能绕过障碍物继续传播的现象。

**衍射条件**：
- 障碍物或孔的尺寸与波长差不多或更小
- 波长越长，衍射现象越明显

**衍射的应用**：
- 声波的衍射（能绕过障碍物）
- 无线电波的衍射
- 光学中的衍射现象

#### 1.7.5 声波

**声波的特性**

声波是纵波，在介质中以声速传播。

**声速**：
- 空气中：$v \approx 340 \, \text{m/s}$（20°C）
- 水中：$v \approx 1450 \, \text{m/s}$
- 钢铁中：$v \approx 5000 \, \text{m/s}$

**声速公式**：
$$v = \sqrt{\frac{B}{\rho}}$$

其中 $B$ 为体积模量，$\rho$ 为密度。

**声强级**

**声强**：声波的平均能流密度
$$I = \frac{P}{S}$$

其中 $P$ 为声功率，$S$ 为面积。

**声强级**：
$$\beta = 10\log_{10}\frac{I}{I_0}$$

其中 $I_0 = 10^{-12} \, \text{W/m}^2$ 为基准声强（人耳刚能听到的声强）。

单位：分贝（dB）

**常见声源的声强级**：
- 轻声耳语：约 20 dB
- 正常对话：约 60 dB
- 闹钟：约 80 dB
- 摇滚音乐会：约 120 dB

**多普勒效应**

当波源或观察者相对于介质运动时，观察者接收到的频率与波源实际频率不同的现象。

**多普勒公式**：
$$f' = f\frac{v \pm v_0}{v \mp v_s}$$

其中：
- $f'$ 为观察者接收到的频率
- $f$ 为波源频率
- $v$ 为波速
- $v_0$ 为观察者速度（向波源为正）
- $v_s$ 为波源速度（向观察者为正）

**多普勒效应的应用**：
- 雷达测速
- 医学超声诊断
- 天体物理中的红移现象

**例题24**：火车以 $v_s = 20 \, \text{m/s}$ 的速度驶向静止的观察者，汽笛频率 $f = 400 \, \text{Hz}$，声速 $v = 340 \, \text{m/s}$，求观察者听到的频率。

**解答**：
观察者静止，$v_0 = 0$
波源向观察者运动，$v_s$ 为正

$$f' = f\frac{v}{v - v_s} = 400 \times \frac{340}{340 - 20} = 400 \times \frac{340}{320} = 425 \, \text{Hz}$$

#### 1.7.6 驻波

**驻波的产生**

两列频率相同、振幅相等、传播方向相反的相干波叠加，形成驻波。

**驻波方程**：
设两列波：
$$y_1 = A\cos(\omega t - kx)$$
$$y_2 = A\cos(\omega t + kx)$$

合成波：
$$y = y_1 + y_2 = 2A\cos(kx)\cos(\omega t)$$

**驻波的特征**：
1. **波腹**：$\cos(kx) = \pm 1$，振幅最大
   位置：$kx = n\pi$，即 $x = n\frac{\lambda}{2}$

2. **波节**：$\cos(kx) = 0$，振幅为零
   位置：$kx = (n+\frac{1}{2})\pi$，即 $x = (n+\frac{1}{2})\frac{\lambda}{2}$

3. **相位**：同一波节两侧的质点振动相位相反

**驻波的应用**：
- 弦乐器的发声
- 管乐器的发声
- 光学中的法布里-珀罗干涉仪

**例题25**：一弦长 $L = 1 \, \text{m}$，两端固定，求基频和前三个泛频的波长和频率。

**解答**：
两端固定为波节，所以：
$$L = n\frac{\lambda_n}{2}$$

$$\lambda_n = \frac{2L}{n}$$

基频（$n = 1$）：$\lambda_1 = 2L = 2 \, \text{m}$

泛频：
- $n = 2$：$\lambda_2 = 1 \, \text{m}$
- $n = 3$：$\lambda_3 = \frac{2}{3} \, \text{m}$
- $n = 4$：$\lambda_4 = 0.5 \, \text{m}$

**力学解题方法总结**

   - 受力分析：画出受力图，标明所有受力
   - 建立方程：根据牛顿第二定律列方程
   - 特殊方法：整体法、隔离法、假设法
   - 求解：解方程并分析结果

3. **能量问题**：
   - 动能定理：适用于单个物体或系统
   - 机械能守恒：适用于只有保守力做功的系统
   - 功能原理：适用于有非保守力做功的情况

4. **动量问题**：

   - 转动惯量计算：点质量、连续刚体、平行轴定理

## 2. 热学

> 📌 **重点章节**：理解微观与宏观的关系，掌握统计物理思想
> 
> 🎯 **学习重点**：从分子动理论理解热现象，掌握热力学定律

热学是研究物质热现象及其规律的科学，包括分子动理论和热力学两大部分。分子动理论从微观角度研究热现象，而热力学从宏观角度研究热现象的基本规律。

### 2.1 气体动理论

#### 2.1.1 分子动理论基本假设

分子动理论基于以下三个基本假设：

1. **物质由大量分子组成**：任何物质都是由大量分子组成的，分子之间有间隙
2. **分子永不停息地做无规则运动**：分子在不停地做无规则的热运动
3. **分子间存在相互作用力**：分子间存在引力和斥力，统称分子力

这些假设能够很好地解释布朗运动、扩散现象等实验事实。

#### 2.1.2 理想气体状态方程

**理想气体模型**：
- 分子本身的体积可以忽略不计
- 分子间的相互作用力可以忽略不计
- 分子碰撞是完全弹性的

**理想气体状态方程**：

$$PV = nRT = \frac{N}{N_A}RT$$

其中：
- $P$ 为气体压强（Pa）
- $V$ 为气体体积（m³）
- $n$ 为物质的量（mol）
- $T$ 为热力学温度（K）
- $R = 8.314$ J/(mol·K) 为气体常数
- $N$ 为分子数
- $N_A = 6.022 \times 10^{23}$ mol⁻¹ 为阿伏伽德罗常数

也可以写成：

$$PV = NkT$$

其中 $k = \frac{R}{N_A} = 1.38 \times 10^{-23}$ J/K 为玻尔兹曼常数。

<details>
<summary><strong>理想气体状态方程的推导</strong></summary>

**从实验定律推导**：

1. **玻意耳定律**：$V \propto \frac{1}{P}$（温度不变）
2. **查理定律**：$V \propto T$（压强不变）
3. **盖-吕萨克定律**：$P \propto T$（体积不变）

综合以上定律，可得：
$$PV \propto T$$

引入比例常数 $nR$，得到：
$$PV = nRT$$

**从分子动理论推导**：

从理想气体压强公式 $p = \frac{1}{3}nm\overline{v^2}$ 和平均平动动能 $\overline{\varepsilon_k} = \frac{1}{2}m\overline{v^2} = \frac{3}{2}kT$，可得：
$$p = \frac{2}{3}n\overline{\varepsilon_k} = nkT$$

其中 $n = \frac{N}{V}$ 为分子数密度。

因此：
$$pV = NkT = nRT$$

</details>

#### 2.1.3 理想气体的压强公式

![热学_分子运动](imgs/热学_分子运动.png)

**压强的微观解释**：
气体压强是大量气体分子对容器壁持续碰撞的宏观表现。

**理想气体压强公式**：

$$p = \frac{1}{3}nm\overline{v^2}$$

其中：
- $n = \frac{N}{V}$ 为分子数密度（m⁻³）
- $m$ 为单个分子的质量（kg）
- $\overline{v^2}$ 为分子速率平方的平均值（m²/s²）

<details>
<summary><strong>压强公式的推导</strong></summary>

**推导过程**：

1. **单个分子的碰撞**：
   考虑一个质量为 $m$ 的分子，以速度 $\vec{v} = (v_x, v_y, v_z)$ 撞向垂直于 $x$ 轴的器壁。

   碰撞前动量：$p_x = mv_x$
   碰撞后动量：$p_x' = -mv_x$
   动量变化：$\Delta p_x = p_x' - p_x = -2mv_x$

2. **单位时间内碰撞次数**：
   分子在 $x$ 方向上运动距离为 $v_x$，单位时间内与器壁碰撞次数为 $\frac{v_x}{2l}$（$l$ 为容器边长）。

3. **单位时间内动量变化**：
   $$\Delta p_x = (-2mv_x) \times \frac{v_x}{2l} = -\frac{mv_x^2}{l}$$

4. **所有分子的贡献**：
   所有分子对器壁的冲量为：
   $$I_x = \sum_{i=1}^N \Delta p_{ix} = -\frac{m}{l}\sum_{i=1}^N v_{ix}^2$$

5. **压强**：
   根据牛顿第三定律，器壁对分子的反作用力大小等于分子对器壁的作用力：
   $$F_x = \frac{I_x}{\Delta t} = \frac{m}{l\Delta t}\sum_{i=1}^N v_{ix}^2$$

   压强：$p = \frac{F_x}{S} = \frac{F_x}{l^2}$

   $$p = \frac{m}{l^3\Delta t}\sum_{i=1}^N v_{ix}^2 = \frac{mN}{V}\frac{\sum_{i=1}^N v_{ix}^2}{N\Delta t}$$

6. **统计平均**：
   $$\overline{v_x^2} = \frac{\sum_{i=1}^N v_{ix}^2}{N}$$

   对于各向同性的气体：$\overline{v_x^2} = \overline{v_y^2} = \overline{v_z^2} = \frac{1}{3}\overline{v^2}$

   因此：
   $$p = \frac{Nm}{V}\overline{v_x^2} = \frac{1}{3}\frac{Nm}{V}\overline{v^2} = \frac{1}{3}nm\overline{v^2}$$

</details>

#### 2.1.4 温度的本质

**温度的微观意义**：
温度是分子平均平动动能的量度。

**能量均分定理**：
在热平衡状态下，物质分子的每个自由度都具有相同的平均动能 $\frac{1}{2}kT$。

**理想气体的平均动能**：

- **平均平动动能**：
  $$\overline{\varepsilon_k} = \frac{1}{2}m\overline{v^2} = \frac{3}{2}kT$$

- **单原子分子**（3个平动自由度）：
  $$\overline{\varepsilon} = \frac{3}{2}kT$$

- **双原子分子**（3个平动自由度 + 2个转动自由度）：
  $$\overline{\varepsilon} = \frac{5}{2}kT$$

- **多原子分子**（3个平动自由度 + 3个转动自由度）：
  $$\overline{\varepsilon} = \frac{6}{2}kT = 3kT$$

<details>
<summary><strong>能量均分定理的推导</strong></summary>

**推导过程**：

1. **分子运动自由度**：
   - 平动自由度：3个（x、y、z方向）
   - 转动自由度：线性分子2个，非线性分子3个
   - 振动自由度：每个振动模式2个（动能 + 势能）

2. **统计平均**：
   根据麦克斯韦速率分布，可以证明：
   $$\overline{v_x^2} = \overline{v_y^2} = \overline{v_z^2} = \frac{1}{3}\overline{v^2}$$

3. **平均平动动能**：
   $$\overline{\varepsilon_k} = \frac{1}{2}m\overline{v_x^2} + \frac{1}{2}m\overline{v_y^2} + \frac{1}{2}m\overline{v_z^2} = \frac{3}{2} \times \frac{1}{2}m\overline{v_x^2}$$

   由压强公式 $p = \frac{1}{3}nm\overline{v^2}$ 和状态方程 $p = nkT$，可得：
   $$\frac{1}{3}m\overline{v^2} = kT \Rightarrow \overline{\varepsilon_k} = \frac{3}{2}kT$$

4. **能量均分**：
   每个自由度贡献 $\frac{1}{2}kT$ 的平均动能，因此：
   $$\overline{\varepsilon} = \frac{i}{2}kT$$

   其中 $i$ 为总自由度数目。

</details>

#### 2.1.5 麦克斯韦速率分布

![热学_麦克斯韦分布](imgs/热学_麦克斯韦分布.png)

**速率分布函数**：

麦克斯韦速率分布函数为：

$$f(v) = 4\pi \left(\frac{m}{2\pi kT}\right)^{3/2} v^2 e^{-\frac{mv^2}{2kT}}$$

其中：
- $f(v)dv$ 表示速率在 $v$ 到 $v+dv$ 范围内的分子数占总分子数的比例
- $m$ 为分子质量
- $T$ 为热力学温度
- $k$ 为玻尔兹曼常数

**三种统计速率**：

1. **最概然速率** $v_p$：
   $$v_p = \sqrt{\frac{2kT}{m}} = \sqrt{\frac{2RT}{M}}$$

2. **平均速率** $\overline{v}$：
   $$\overline{v} = \sqrt{\frac{8kT}{\pi m}} = \sqrt{\frac{8RT}{\pi M}}$$

3. **方均根速率** $v_{rms}$：
   $$v_{rms} = \sqrt{\frac{3kT}{m}} = \sqrt{\frac{3RT}{M}}$$

其中 $M$ 为摩尔质量。

**速率关系**：
$$v_p < \overline{v} < v_{rms}$$

#### 2.1.6 气体动理论的应用

**分子平均自由程**：
$$\overline{\lambda} = \frac{1}{\sqrt{2}\pi d^2 n}$$

其中 $d$ 为分子直径，$n$ 为分子数密度。

**分子平均碰撞频率**：
$$\overline{Z} = \sqrt{2}\pi d^2 n \overline{v}$$

### 2.2 热力学第一定律

#### 2.2.1 准静态过程

**准静态过程**：
如果系统在变化过程中的每一个中间状态都无限接近平衡态，这样的过程称为准静态过程。

**准静态过程的特征**：
- 过程无限缓慢
- 系统始终处于平衡态
- 可以用状态参量描述过程

**p-V图**：
在p-V图上，准静态过程可以用一条曲线表示。

#### 2.2.2 功和热量

**体积功**：
当系统体积发生变化时，系统对外做的功为：

$$W = \int_{V_1}^{V_2} p \, dV$$

其中：
- $W > 0$：系统对外做功
- $W < 0$：外界对系统做功

**热量**：
热量是系统与外界之间由于温度不同而传递的能量。

**热容量**：
$$C = \frac{dQ}{dT}$$

**摩尔热容**：
$$C_m = \frac{C}{n} = \frac{1}{n}\frac{dQ}{dT}$$

**定容摩尔热容** $C_{V,m}$：
$$C_{V,m} = \frac{1}{n}\left(\frac{dQ}{dT}\right)_V$$

**定压摩尔热容** $C_{p,m}$：
$$C_{p,m} = \frac{1}{n}\left(\frac{dQ}{dT}\right)_p$$

**迈耶公式**：
$$C_{p,m} - C_{V,m} = R$$

**比热容比**：
$$\gamma = \frac{C_{p,m}}{C_{V,m}}$$

#### 2.2.3 内能

**内能的概念**：
系统的内能是系统内所有分子动能和分子势能的总和。

**理想气体的内能**：
对于理想气体，分子间势能为零，内能只包括分子动能：

$$U = \frac{i}{2}nRT$$

其中 $i$ 为分子自由度。

**内能的改变**：
- 理想气体内能只与温度有关
- $\Delta U = \frac{i}{2}nR\Delta T$

#### 2.2.4 热力学第一定律

**热力学第一定律**：
能量既不能创造也不能消灭，只能从一种形式转化为另一种形式，或者从一个物体转移到另一个物体。

**数学表达式**：
$$\Delta U = Q - W$$

其中：
- $\Delta U$ 为系统内能的增量
- $Q$ 为系统吸收的热量
- $W$ 为系统对外做的功

**符号约定**：
- 系统吸热：$Q > 0$
- 系统放热：$Q < 0$
- 系统对外做功：$W > 0$
- 外界对系统做功：$W < 0$

<details>
<summary><strong>热力学第一定律的推导</strong></summary>

**从能量守恒推导**：

1. **能量守恒定律**：
   在任何过程中，系统的总能量保持不变。

2. **系统能量变化**：
   系统能量的变化包括：
   - 内能的变化 $\Delta U$
   - 与外界交换的能量（热量 $Q$ 和功 $W$）

3. **能量守恒方程**：
   $$\Delta U = Q - W$$

4. **微分形式**：
   $$dU = \delta Q - \delta W$$

   其中 $\delta Q$ 和 $\delta W$ 不是全微分，因为 $Q$ 和 $W$ 与过程有关。

**从分子动理论推导**：

1. **分子动能变化**：
   温度变化时，分子平均动能变化：
   $$\Delta \overline{\varepsilon_k} = \frac{i}{2}k\Delta T$$

2. **内能变化**：
   $$U = N\overline{\varepsilon_k} = \frac{i}{2}NkT = \frac{i}{2}nRT$$

3. **热量传递**：
   热量传递导致内能变化：
   $$Q = \Delta U + W$$

</details>

#### 2.2.5 理想气体的等值过程

**等温过程**（$T = \text{常数}$）：

- 过程方程：$pV = \text{常数}$
- 内能变化：$\Delta U = 0$
- 热量：$Q = W = nRT\ln\frac{V_2}{V_1} = nRT\ln\frac{p_1}{p_2}$
- $p-V$ 图：双曲线

**等容过程**（$V = \text{常数}$）：

- 过程方程：$\frac{p}{T} = \text{常数}$
- 功：$W = 0$
- 热量：$Q = \Delta U = nC_{V,m}\Delta T$
- $p-V$ 图：垂直线

**等压过程**（$p = \text{常数}$）：

- 过程方程：$\frac{V}{T} = \text{常数}$
- 功：$W = p(V_2 - V_1) = nR\Delta T$
- 热量：$Q = nC_{p,m}\Delta T$
- 内能变化：$\Delta U = nC_{V,m}\Delta T$
- $p-V$ 图：水平线

**绝热过程**（$Q = 0$）：

- 过程方程：$pV^\gamma = \text{常数}$ 或 $TV^{\gamma-1} = \text{常数}$
- 热量：$Q = 0$
- 功：$W = -\Delta U = -nC_{V,m}\Delta T$
- 内能变化：$\Delta U = nC_{V,m}\Delta T$
- $p-V$ 图：比等温线更陡的曲线

<details>
<summary><strong>绝热过程方程的推导</strong></summary>

**推导过程**：

1. **绝热条件**：
   $$Q = 0$$

2. **热力学第一定律**：
   $$\Delta U = -W$$

3. **内能变化**：
   $$dU = nC_{V,m}dT$$

4. **功的表达式**：
   $$W = \int_{V_1}^{V_2} p \, dV$$

5. **微分形式的热力学第一定律**：
   $$nC_{V,m}dT = -p \, dV$$

6. **理想气体状态方程微分**：
   $$pdV + Vdp = nRdT$$

7. **联立方程**：
   $$nC_{V,m}dT = -p \, dV$$
   $$nRdT = pdV + Vdp$$

8. **消去 $dT$**：
   $$\frac{C_{V,m}}{R}(pdV + Vdp) = -p \, dV$$

9. **整理**：
   $$C_{V,m}pdV + C_{V,m}Vdp = -Rp \, dV$$

   $$(C_{V,m} + R)pdV = -C_{V,m}Vdp$$

10. **代入迈耶公式**：
    $$C_{p,m}pdV = -C_{V,m}Vdp$$

11. **分离变量**：
    $$\frac{dp}{p} = -\gamma\frac{dV}{V}$$

12. **积分**：
    $$\ln p = -\gamma \ln V + \text{常数}$$

    $$\ln(pV^\gamma) = \text{常数}$$

    $$pV^\gamma = \text{常数}$$

</details>

#### 2.2.6 热力学过程对比

| 过程类型 | 过程方程 | 热量Q | 功W | 内能变化ΔU | 特点 |
|---------|----------|--------|-----|------------|------|
| 等温过程 | $pV = \text{常数}$ | $Q = W = nRT\ln\frac{V_2}{V_1}$ | $W = nRT\ln\frac{V_2}{V_1}$ | $\Delta U = 0$ | 内能不变，吸热做功 |
| 等容过程 | $\frac{p}{T} = \text{常数}$ | $Q = nC_{V,m}\Delta T$ | $W = 0$ | $\Delta U = nC_{V,m}\Delta T$ | 体积不变，不做功 |
| 等压过程 | $\frac{V}{T} = \text{常数}$ | $Q = nC_{p,m}\Delta T$ | $W = p\Delta V = nR\Delta T$ | $\Delta U = nC_{V,m}\Delta T$ | 压强不变，吸热膨胀 |
| 绝热过程 | $pV^\gamma = \text{常数}$ | $Q = 0$ | $W = -nC_{V,m}\Delta T$ | $\Delta U = nC_{V,m}\Delta T$ | 不交换热量，内能变化做功 |

> 1. 热力学第一定律是能量守恒定律在热现象中的具体应用
> 2. 注意符号约定：系统吸热Q>0，系统对外做功W>0
> 3. 理想气体内能只与温度有关，与体积和压强无关

### 2.3 热力学第二定律

#### 2.3.1 热力学第二定律

**开尔文表述**：
不可能制造出从单一热源吸热并全部用来做功而不产生其他影响的循环热机。

**克劳修斯表述**：
不可能把热量从低温物体传到高温物体而不引起其他变化。

**两种表述的等价性**：
开尔文表述和克劳修斯表述是等价的，可以用反证法证明。

#### 2.3.2 卡诺循环

![热学_卡诺循环](imgs/热学_卡诺循环.png)

**卡诺循环**：
由两个等温过程和两个绝热过程组成的可逆循环。

**卡诺热机效率**：
$$\eta = 1 - \frac{T_2}{T_1}$$

其中：
- $T_1$ 为高温热源温度
- $T_2$ 为低温热源温度

**卡诺制冷机制冷系数**：
$$\varepsilon = \frac{T_2}{T_1 - T_2}$$

<details>
<summary><strong>卡诺循环效率的推导</strong></summary>

**卡诺循环的四个过程**：

1. **过程1→2**：等温膨胀（温度 $T_1$）
   - 吸热：$Q_1 = nRT_1\ln\frac{V_2}{V_1}$
   - 功：$W_{12} = Q_1$

2. **过程2→3**：绝热膨胀
   - 热量：$Q = 0$
   - 功：$W_{23} = -\Delta U_{23} = -nC_{V,m}(T_2 - T_1)$

3. **过程3→4**：等温压缩（温度 $T_2$）
   - 放热：$Q_2 = nRT_2\ln\frac{V_4}{V_3}$
   - 功：$W_{34} = Q_2$

4. **过程4→1**：绝热压缩
   - 热量：$Q = 0$
   - 功：$W_{41} = -\Delta U_{41} = -nC_{V,m}(T_1 - T_2)$

**总功**：
$$W = W_{12} + W_{23} + W_{34} + W_{41} = Q_1 + Q_2$$

**效率**：
$$\eta = \frac{W}{Q_1} = \frac{Q_1 + Q_2}{Q_1} = 1 + \frac{Q_2}{Q_1}$$

**绝热过程的关系**：
由绝热过程方程 $TV^{\gamma-1} = \text{常数}$：
$$\frac{T_1}{T_2} = \left(\frac{V_3}{V_2}\right)^{\gamma-1} = \left(\frac{V_4}{V_1}\right)^{\gamma-1}$$

因此：
$$\frac{V_2}{V_1} = \frac{V_3}{V_4}$$

**热量比**：
$$\frac{Q_2}{Q_1} = \frac{nRT_2\ln\frac{V_4}{V_3}}{nRT_1\ln\frac{V_2}{V_1}} = \frac{T_2}{T_1}\frac{\ln\frac{V_4}{V_3}}{\ln\frac{V_2}{V_1}} = -\frac{T_2}{T_1}$$

**效率**：
$$\eta = 1 - \frac{T_2}{T_1}$$

</details>

#### 2.3.3 熵

**熵的概念**：
熵是系统无序度的量度，是热力学中非常重要的概念。

**克劳修斯不等式**：
$$\oint \frac{\delta Q}{T} \leq 0$$

等号对应可逆过程，不等号对应不可逆过程。

**熵的定义**：
对于可逆过程，熵的定义为：
$$dS = \frac{\delta Q_{rev}}{T}$$

**熵变计算**：
$$\Delta S = \int_{1}^{2} \frac{\delta Q_{rev}}{T}$$

**熵增加原理**：
对于孤立系统：
$$\Delta S \geq 0$$

等号对应可逆过程，不等号对应不可逆过程。

<details>
<summary><strong>熵的统计解释</strong></summary>

**玻尔兹曼熵公式**：
$$S = k\ln\Omega$$

其中：
- $S$ 为熵
- $k$ 为玻尔兹曼常数
- $\Omega$ 为系统的微观状态数

**熵的统计意义**：
- 熵是系统无序度的量度
- 微观状态数越多，系统越无序，熵越大
- 不可逆过程总是向熵增加的方向进行

**麦克斯韦妖佯谬**：
如果存在能够区分分子速度的"麦克斯韦妖"，就可以降低系统熵，这违反了热力学第二定律。这说明信息处理与热力学之间存在深刻联系。

</details>

#### 2.3.4 熵的计算

**理想气体等温过程熵变**：
$$\Delta S = nR\ln\frac{V_2}{V_1} = nR\ln\frac{p_1}{p_2}$$

**理想气体等容过程熵变**：
$$\Delta S = nC_{V,m}\ln\frac{T_2}{T_1}$$

**理想气体等压过程熵变**：
$$\Delta S = nC_{p,m}\ln\frac{T_2}{T_1}$$

**理想气体绝热过程熵变**：
$$\Delta S = 0$$

**相变过程熵变**：
$$\Delta S = \frac{Q}{T} = \frac{\Delta H}{T}$$

其中 $\Delta H$ 为相变焓。

**热传导过程熵变**：
高温物体熵变：$\Delta S_1 = -\frac{Q}{T_1}$
低温物体熵变：$\Delta S_2 = \frac{Q}{T_2}$
总熵变：$\Delta S = Q\left(\frac{1}{T_2} - \frac{1}{T_1}\right) > 0$

#### 2.3.5 自由能

**亥姆霍兹自由能**：
$$F = U - TS$$

在恒温恒容条件下，系统趋向于自由能减少的状态。

**吉布斯自由能**：
$$G = H - TS = U + pV - TS$$

在恒温恒压条件下，系统趋向于吉布斯自由能减少的状态。

### 2.4 相变

#### 2.4.1 相变的基本概念

**相**：
系统中物理性质均匀的部分称为相。

**相变**：
物质从一种相转变为另一种相的过程。

**相变类型**：
- 一级相变：有潜热，有体积变化（如熔化、汽化）
- 二级相变：无潜热，无体积变化（如超导转变）

#### 2.4.2 相变潜热

**熔化热**：
单位质量的物质从固态完全熔化为液态所需的热量。

**汽化热**：
单位质量的物质从液态完全汽化为气态所需的热量。

**升华热**：
单位质量的物质从固态直接升华为气态所需的热量。

#### 2.4.3 相图

**相图的组成**：
- 熔点曲线（固-液平衡线）
- 沸点曲线（液-气平衡线）
- 升华曲线（固-气平衡线）
- 三相点（固、液、气三相共存点）
- 临界点（液-气分界线的终点）

**水的相图特点**：
- 三相点：0.01℃，611.657 Pa
- 冰点：0℃，1 atm（由于压力增加，冰点降低）

### 2.5 热传导

#### 2.5.1 热传导的基本规律

**傅里叶定律**：
单位时间内通过单位面积的热量（热流密度）与温度梯度成正比：

$$\vec{q} = -k\nabla T$$

其中：
- $\vec{q}$ 为热流密度（W/m²）
- $k$ 为热导率（W/(m·K)）
- $\nabla T$ 为温度梯度（K/m）

**热传导方程**：
$$\frac{\partial T}{\partial t} = \alpha\nabla^2 T$$

其中 $\alpha = \frac{k}{\rho c_p}$ 为热扩散率。

#### 2.5.2 热传导的典型情况

**稳态热传导**：
温度分布不随时间变化。

- **平壁热传导**：
  $$q = \frac{k}{\delta}(T_1 - T_2)$$

- **圆筒壁热传导**：
  $$q = \frac{2\pi kL(T_1 - T_2)}{\ln\frac{r_2}{r_1}}$$

- **球壁热传导**：
  $$q = \frac{4\pi k(T_1 - T_2)}{\frac{1}{r_1} - \frac{1}{r_2}}$$

**非稳态热传导**：
温度分布随时间变化。

**集总参数法**：
当物体内部温度均匀时（Bi < 0.1）：
$$\frac{T - T_\infty}{T_0 - T_\infty} = e^{-\frac{hA}{\rho Vc_p}t}$$

其中：
- $h$ 为表面传热系数
- $A$ 为换热面积
- $V$ 为物体体积
- $\rho$ 为密度
- $c_p$ 为比热容

#### 2.5.3 对流传热

**牛顿冷却定律**：
$$q = h(T_s - T_\infty)$$

其中：
- $h$ 为表面传热系数（W/(m²·K)）
- $T_s$ 为固体表面温度
- $T_\infty$ 为流体温度

**自然对流**：
由于温度差引起的密度差导致的流动。

**强制对流**：
由于外力（泵、风机等）引起的流动。

#### 2.5.4 热辐射

**斯特藩-玻尔兹曼定律**：
黑体的辐射力：
$$E_b = \sigma T^4$$

其中 $\sigma = 5.670 \times 10^{-8}$ W/(m²·K⁴) 为斯特藩常数。

**基尔霍夫定律**：
$$\frac{E}{\alpha} = E_b$$

即物体的辐射力与吸收率的比值等于同温度下黑体的辐射力。

**维恩位移定律**：
$$\lambda_m T = b$$

其中 $b = 2.898 \times 10^{-3}$ m·K 为维恩位移常数。

### 静电场

![电磁学_电场线](imgs/电磁学_电场线.png)

#### 基本概念

**电场强度（$\vec{E}$）**
电场强度是描述电场强弱和方向的物理量，定义为试探电荷在电场中受到的力与其电荷量的比值：

$$\vec{E} = \frac{\vec{F}}{q_0}$$

单位：N/C 或 V/m

**电势（$V$）**
电势是描述电场能量特性的物理量，定义为将单位正电荷从该点移动到无穷远时电场力所做的功：

$$V = \frac{W}{q_0} = -\int_{\infty}^{r} \vec{E} \cdot d\vec{l}$$

单位：V

**电势能（$W_e$）**
电荷在电场中具有的势能：

$$W_e = qV$$

单位：J

**电位移矢量（$\vec{D}$）**
描述电介质中电场的辅助物理量：

$$\vec{D} = \varepsilon_0\vec{E} + \vec{P}$$

其中 $\vec{P}$ 为电极化强度。

**电容（$C$）**
导体储存电荷的能力：

$$C = \frac{Q}{U}$$

单位：F（法拉）

**电容器储能**
$$W = \frac{1}{2}CU^2 = \frac{Q^2}{2C} = \frac{1}{2}QU$$

#### 重要定律

<details>
<summary><strong>库仑定律的详细推导与适用条件</strong></summary>

**内容：** 两个静止点电荷之间的相互作用力与它们电荷量的乘积成正比，与它们之间距离的平方成反比，作用力的方向沿两点电荷的连线。

**公式：**
$$\vec{F} = \frac{1}{4\pi\varepsilon_0} \frac{q_1 q_2}{r^2} \hat{r}$$

其中：
- $\varepsilon_0 = 8.85 \times 10^{-12} C^2/(N \cdot m^2)$ 为真空介电常数
- $\hat{r}$ 为从源电荷指向试探电荷的单位矢量

**实验基础：**
1. **库仑扭秤实验：** 库仑通过精密的扭秤实验，测量了两个带电小球之间的作用力
2. **平方反比律：** 实验发现作用力与距离的平方成反比
3. **电荷量关系：** 作用力与两电荷量的乘积成正比

**力的叠加原理：**
对于多个点电荷，任意点电荷受到的力是其他各点电荷对该电荷作用力的矢量和：
$$\vec{F} = \sum_{i=1}^{n} \vec{F_i}$$

**连续带电体：**
对于连续分布的电荷，需要进行积分：
$$d\vec{F} = \frac{1}{4\pi\varepsilon_0} \frac{dq_1 dq_2}{r^2} \hat{r}$$
$$\vec{F} = \int d\vec{F}$$

**适用条件：**
1. 静止电荷（相对观察者静止）
2. 真空或均匀介质
3. 点电荷模型（电荷分布尺度 << 观察距离）
4. 非相对论条件（v << c）

**物理意义：**
库仑定律是静电学的基础，揭示了电荷间相互作用的本质，为后续电场理论奠定基础。

</details>

<details>
<summary><strong>高斯定理</strong></summary>

**内容：** 通过任意闭合曲面的电通量等于该闭合曲面所包围的电荷代数和除以真空介电常数。

**公式：**
$$\oint_S \vec{E} \cdot d\vec{S} = \frac{Q_{enc}}{\varepsilon_0}$$

**推导过程：**

1. **点电荷情况：** 对于点电荷 $q$，以点电荷为中心作半径为 $r$ 的球面
   - 电场强度：$E = \frac{1}{4\pi\varepsilon_0} \frac{q}{r^2}$
   - 球面面积：$S = 4\pi r^2$
   - 电通量：$\Phi_E = ES = \frac{q}{\varepsilon_0}$

2. **任意闭合曲面：** 通过任意闭合曲面的电通量等于通过以其为中心包围该电荷的球面的电通量

3. **多个点电荷：** 电通量满足叠加原理
   $$\oint_S \vec{E} \cdot d\vec{S} = \sum_i \frac{q_i}{\varepsilon_0}$$

4. **连续分布电荷：**
   $$\oint_S \vec{E} \cdot d\vec{S} = \frac{1}{\varepsilon_0} \int_V \rho dV$$

其中 $\rho$ 为电荷体密度。

</details>

| 点电荷 | 单个点电荷 | $V = \frac{1}{4\pi\varepsilon_0} \frac{q}{r}$ |
| 电偶极子 | 两个等量异号电荷 | $V = \frac{1}{4\pi\varepsilon_0} \frac{p\cos\theta}{r^2}$ |
| 均匀带电球面 | 球面外 | $V = \frac{1}{4\pi\varepsilon_0} \frac{Q}{r}$ |
| 均匀带电球面 | 球面内 | $V = \frac{1}{4\pi\varepsilon_0} \frac{Q}{R}$ |
| 均匀带电球体 | 球面外 | $V = \frac{1}{4\pi\varepsilon_0} \frac{Q}{r}$ |
| 均匀带电球体 | 球面内 | $V = \frac{1}{4\pi\varepsilon_0} \frac{Q}{2R}\left(3 - \frac{r^2}{R^2}\right)$ |
| 无限长均匀带电直线 | 直线外 | $V = -\frac{\lambda}{2\pi\varepsilon_0} \ln r + C$ |
| 无限大均匀带电平面 | 平面两侧 | $V = -\frac{\sigma}{2\varepsilon_0} x + C$ |
| 均匀带电圆环 | 轴线上 | $V = \frac{1}{4\pi\varepsilon_0} \frac{Q}{\sqrt{x^2 + R^2}}$ |
| 均匀带电圆盘 | 轴线上 | $V = \frac{\sigma}{2\varepsilon_0}\left(\sqrt{x^2 + R^2} - x\right)$ |

#### 电容器

**平行板电容器**
$$C = \varepsilon_0\varepsilon_r\frac{S}{d}$$

其中 $\varepsilon_r$ 为相对介电常数，$S$ 为极板面积，$d$ 为极板间距。

**圆柱形电容器**
$$C = \frac{2\pi\varepsilon_0\varepsilon_r l}{\ln\frac{R_2}{R_1}}$$

其中 $l$ 为长度，$R_1$、$R_2$ 为内外半径。

**球形电容器**
$$C = 4\pi\varepsilon_0\varepsilon_r\frac{R_1R_2}{R_2 - R_1}$$

其中 $R_1$、$R_2$ 为内外半径。

**电容器的能量**
$$W = \frac{1}{2}CU^2 = \frac{Q^2}{2C} = \frac{1}{2}QU$$

**电场能量密度**
$$w_e = \frac{1}{2}\varepsilon_0\varepsilon_rE^2$$

#### 典型例题

**例题1：点电荷电场强度的计算**
> **题目：** 两个点电荷 $q_1 = 4.0 \times 10^{-6} C$ 和 $q_2 = -3.0 \times 10^{-6} C$ 分别位于点 A(0, 0) 和点 B(0.3, 0) 处，求点 C(0.4, 0.3) 处的电场强度。

> **解答：**
> 1. 计算各点到C点的距离：
>    - $r_{AC} = \sqrt{(0.4-0)^2 + (0.3-0)^2} = 0.5$ m
>    - $r_{BC} = \sqrt{(0.4-0.3)^2 + (0.3-0)^2} = \sqrt{0.01 + 0.09} = 0.316$ m

> 2. 计算各点电荷在C点产生的电场强度：
>    - $E_1 = \frac{1}{4\pi\varepsilon_0} \frac{q_1}{r_{AC}^2} = 9.0 \times 10^9 \times \frac{4.0 \times 10^{-6}}{0.5^2} = 1.44 \times 10^5$ N/C
>    - $E_2 = \frac{1}{4\pi\varepsilon_0} \frac{|q_2|}{r_{BC}^2} = 9.0 \times 10^9 \times \frac{3.0 \times 10^{-6}}{0.316^2} = 2.70 \times 10^5$ N/C

> 3. 确定方向并计算合场强：
>    - $\vec{E}_1$ 沿AC方向，$\vec{E}_2$ 沿BC方向
>    - $E_{Cx} = E_1 \cos\theta_1 + E_2 \cos\theta_2$
>    - $E_{Cy} = E_1 \sin\theta_1 + E_2 \sin\theta_2$
>    - 最终结果：$\vec{E} = (2.88 \times 10^5, 1.58 \times 10^5)$ N/C

**例题2：高斯定理的应用**
> **题目：** 半径为 $R$ 的均匀带电球体，体电荷密度为 $\rho$，求球体内外的电场分布。

> **解答：**
> 1. **球面外（$r > R$）：**
>    - 取高斯面为半径 $r$ 的同心球面
>    - $\oint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{Q}{\varepsilon_0}$
>    - $Q = \frac{4}{3}\pi R^3 \rho$
>    - $E = \frac{1}{4\pi\varepsilon_0} \frac{Q}{r^2}$

> 2. **球面内（$r < R$）：**
>    - 取高斯面为半径 $r$ 的同心球面
>    - $\oint \vec{E} \cdot d\vec{S} = E \cdot 4\pi r^2 = \frac{Q_{enc}}{\varepsilon_0}$
>    - $Q_{enc} = \frac{4}{3}\pi r^3 \rho$
>    - $E = \frac{\rho r}{3\varepsilon_0}$

**例题3：欧姆定律的微观解释**
> **题目：** 金属导体中自由电子的数密度为 $n = 8.5 \times 10^{28} m^{-3}$，电子迁移率 $\mu = 4.2 \times 10^{-3} m^2/(V·s)$，求铜的电阻率。

> **解答：**
> 1. 根据欧姆定律的微分形式：$\vec{J} = \sigma \vec{E}$
> 2. 电流密度与电子漂移速度的关系：$J = ne\mu E$
> 3. 因此电导率：$\sigma = ne\mu$
> 4. 电阻率：$\rho = \frac{1}{\sigma} = \frac{1}{ne\mu}$
> 5. 代入数值：$\rho = \frac{1}{8.5 \times 10^{28} \times 1.6 \times 10^{-19} \times 4.2 \times 10^{-3}} = 1.76 \times 10^{-8} \Omega·m$

### 恒定电流

#### 基本概念

**电流强度（I）**
单位时间内通过导体横截面的电荷量：

$$I = \frac{dq}{dt}$$

**电流密度（J）**
单位时间内通过单位面积的电荷量：

$$\vec{J} = \frac{dI}{dS} \hat{n}$$

**欧姆定律**
导体中的电流与电压成正比，与电阻成反比：

$$U = IR$$

或微分形式：

$$\vec{J} = \sigma \vec{E}$$

其中 $\sigma$ 为电导率，$\sigma = \frac{1}{\rho}$，$\rho$ 为电阻率。

#### 电阻计算

| 形状 | 条件 | 电阻公式 |
|------|------|----------|
| 圆柱形导体 | 均匀材料 | $R = \rho \frac{l}{S}$ |
| 球形导体 | 内外半径 $R_1, R_2$ | $R = \frac{\rho}{4\pi} (\frac{1}{R_1} - \frac{1}{R_2})$ |
| 同轴电缆 | 内半径 $a$，外半径 $b$ | $R = \frac{\rho}{2\pi l} \ln\frac{b}{a}$ |
| 半球形接地电极 | 半径 $R$ | $R = \frac{\rho}{2\pi R}$ |
| 矩形导体 | 长$l$宽$b$高$h$ | $R = \rho\frac{l}{bh}$ |

#### 恒定电流重要物理量

| 物理量 | 符号 | 定义 | 计算公式 | 单位 |
|--------|------|------|----------|------|
| 电流强度 | $I$ | 单位时间内通过导体横截面的电荷量 | $I = \frac{dq}{dt}$ | A |
| 电流密度 | $\vec{J}$ | 单位时间内通过单位面积的电荷量 | $\vec{J} = \frac{dI}{dS}\hat{n}$ | A/m² |
| 电阻率 | $\rho$ | 导体材料的电学性质 | $\rho = \frac{1}{\sigma}$ | Ω·m |
| 电导率 | $\sigma$ | 导体导电能力的强弱 | $\sigma = \frac{1}{\rho}$ | S/m |
| 电动势 | $\varepsilon$ | 电源提供的非静电力做功能力 | $\varepsilon = \frac{W_{非静}}{q}$ | V |
| 功率 | $P$ | 单位时间内消耗的能量 | $P = UI = I^2R = \frac{U^2}{R}$ | W |

#### 基尔霍夫定律

**第一定律（电流定律）**
流入节点的电流之和等于流出节点的电流之和：

$$\sum I_{入} = \sum I_{出}$$

或

$$\sum I_i = 0$$

**第二定律（电压定律）**
沿闭合回路的电势降之和等于零：

$$\sum U_i = 0$$

#### 典型例题

**例题4：基尔霍夫定律的应用**
> **题目：** 电路如图所示，$R_1 = 10\Omega$，$R_2 = 20\Omega$，$R_3 = 30\Omega$，$E_1 = 12V$，$E_2 = 6V$，求各支路电流。

> **解答：**
> 1. **设定电流方向：** 设 $I_1$、$I_2$、$I_3$ 分别为通过 $R_1$、$R_2$、$R_3$ 的电流

> 2. **列节点电流方程（KCL）：**
>    在节点A：$I_1 = I_2 + I_3$

> 3. **列回路电压方程（KVL）：**
>    - 回路1（$E_1$ → $R_1$ → $R_2$ → $E_1$）：
>      $E_1 - I_1R_1 - I_2R_2 = 0$
>    - 回路2（$E_2$ → $R_3$ → $R_2$ → $E_2$）：
>      $E_2 - I_3R_3 - I_2R_2 = 0$

> 4. **代入数值求解：**
>    - $12 - 10I_1 - 20I_2 = 0$
>    - $6 - 30I_3 - 20I_2 = 0$
>    - $I_1 = I_2 + I_3$

> 5. **解得：** $I_1 = 0.5A$，$I_2 = 0.35A$，$I_3 = 0.15A$

**例题5：电阻的计算**
> **题目：** 同轴电缆内外导体半径分别为 $a = 1mm$，$b = 5mm$，长度 $l = 100m$，材料电阻率 $\rho = 1.7 \times 10^{-8} \Omega·m$，求内外导体间的绝缘电阻。

> **解答：**
> 1. **建立坐标系：** 取径向方向为电流方向

> 2. **取微元：** 在半径 $r$ 处取厚度 $dr$ 的薄圆筒

> 3. **微元电阻：** $dR = \rho \frac{dr}{dS} = \rho \frac{dr}{2\pi rl}$

> 4. **积分求总电阻：**
>    $$R = \int_a^b dR = \int_a^b \rho \frac{dr}{2\pi rl} = \frac{\rho}{2\pi l} \ln\frac{b}{a}$$

> 5. **代入数值：**
>    $$R = \frac{1.7 \times 10^{-8}}{2\pi \times 100} \ln\frac{5}{1} = 1.12 \times 10^{-10} \Omega$$

### 磁场

![电磁学_磁感线](imgs/电磁学_磁感线.png)

#### 基本概念

**磁感应强度（B）**
描述磁场强弱和方向的物理量，定义为运动电荷在磁场中受到的洛伦兹力：

$$\vec{F} = q(\vec{v} \times \vec{B})$$

**磁场强度（H）**
在磁介质中的辅助物理量：

$$\vec{B} = \mu_0 \vec{H} + \mu_0 \vec{M}$$

其中 $\vec{M}$ 为磁化强度，$\mu_0 = 4\pi \times 10^{-7} H/m$ 为真空磁导率。

#### 重要定律

<details>
<summary><strong>毕奥-萨伐尔定律的详细推导与应用</strong></summary>

**内容：** 载流导线中电流元 $Id\vec{l}$ 在空间某点产生的磁感应强度与电流元大小成正比，与电流元到该点的距离的平方成反比，与电流元方向和径向方向的夹角正弦成正比。

**公式：**
$$d\vec{B} = \frac{\mu_0}{4\pi} \frac{Id\vec{l} \times \hat{r}}{r^2}$$

其中：
- $\mu_0 = 4\pi \times 10^{-7} H/m$ 为真空磁导率
- $Id\vec{l}$ 为电流元矢量
- $\hat{r}$ 为从电流元指向场点的单位矢量
- $r$ 为电流元到场点的距离

**推导过程：**

1. **实验基础：** 毕奥和萨伐尔通过实验发现，载流导线产生的磁场满足以下规律：
   - 磁场强度与电流强度成正比
   - 与距离成反比
   - 方向垂直于电流元和径向方向组成的平面

2. **矢量形式：** 考虑电流元的方向性，磁场应满足矢量叉乘关系：
   $$d\vec{B} \parallel Id\vec{l} \times \hat{r}$$

3. **比例常数：** 通过实验确定比例常数，得到完整的毕奥-萨伐尔定律

4. **积分形式：** 对于任意载流导线，磁感应强度为：
   $$\vec{B} = \int d\vec{B} = \frac{\mu_0}{4\pi} \int \frac{Id\vec{l} \times \hat{r}}{r^2}$$

**典型应用：**

1. **无限长直导线：**
   $$B = \frac{\mu_0 I}{2\pi r}$$

2. **圆形电流圆心处：**
   $$B = \frac{\mu_0 I}{2R}$$

3. **载流直螺线管：**
   $$B = \mu_0 nI$$（内部）
   $$B = 0$$（外部）

**物理意义：**
毕奥-萨伐尔定律是稳恒磁场的基本定律，类似于静电场中的库仑定律，为磁场计算提供了理论基础。

</details>

<details>
<summary><strong>安培定律（安培环路定理）</strong></summary>

**内容：** 磁感应强度沿任意闭合回路的线积分等于该闭合回路所包围的传导电流代数和的 $\mu_0$ 倍。

**公式：**
$$\oint_L \vec{B} \cdot d\vec{l} = \mu_0 I_{enc}$$

**推导过程：**

1. **无限长直导线：** 以导线为中心作半径为 $r$ 的圆形闭合回路
   - 磁感应强度：$B = \frac{\mu_0 I}{2\pi r}$
   - 环路积分：$\oint_L \vec{B} \cdot d\vec{l} = B \cdot 2\pi r = \mu_0 I$

2. **任意闭合回路：** 磁感应强度沿任意闭合回路的线积分等于通过该回路所包围面积的电流的 $\mu_0$ 倍

3. **多个电流：** 满足叠加原理
   $$\oint_L \vec{B} \cdot d\vec{l} = \mu_0 \sum I_i$$

4. **微分形式：**
   $$\nabla \times \vec{B} = \mu_0 \vec{J}$$

其中 $\vec{J}$ 为电流密度矢量。

**应用条件：**
- 稳恒电流
- 真空或均匀介质
- 闭合路径任意选取

</details>

#### 洛伦兹力

**运动电荷在磁场中的受力：**

$$\vec{F} = q(\vec{v} \times \vec{B})$$

**载流导线在磁场中的受力：**

$$d\vec{F} = I(d\vec{l} \times \vec{B})$$

$$\vec{F} = I(\vec{l} \times \vec{B})$$

#### 磁矩

**载流线圈的磁矩：**

$$\vec{m} = I\vec{S} = IS\hat{n}$$

其中 $\vec{S}$ 为线圈面积矢量，方向与电流方向满足右手螺旋定则。

#### 典型例题

**例题6：载流圆环的磁场计算**
> **题目：** 半径为 $R = 10cm$ 的圆形线圈，通有电流 $I = 5A$，求线圈轴线上距离中心 $x = 8cm$ 处的磁感应强度。

> **解答：**
> 1. **应用毕奥-萨伐尔定律：** 对于圆环上任意电流元 $Id\vec{l}$

> 2. **对称性分析：** 由于轴对称性，合磁场方向沿轴线方向

> 3. **计算过程：**
>    - 电流元到场点的距离：$r = \sqrt{R^2 + x^2}$
>    - 电流元与径向的夹角：$\theta = \arctan\frac{R}{x}$
>    - 磁感应强度：$dB = \frac{\mu_0}{4\pi} \frac{Idl \sin\theta}{r^2}$

> 4. **积分计算：**
>    $$B = \int dB \cos\phi = \frac{\mu_0 I R^2}{2(R^2 + x^2)^{3/2}}$$

> 5. **代入数值：**
>    $$B = \frac{4\pi \times 10^{-7} \times 5 \times (0.1)^2}{2(0.1^2 + 0.08^2)^{3/2}} = 1.12 \times 10^{-5} T$$

**例题7：带电粒子在磁场中的运动**
> **题目：** 电子以 $v = 10^6 m/s$ 的速度垂直进入 $B = 0.1T$ 的均匀磁场，求电子的轨道半径和运动周期。

> **解答：**
> 1. **受力分析：** 电子受洛伦兹力 $F = evB$，提供向心力

> 2. **轨道半径：** 
>    $$evB = \frac{mv^2}{R} \Rightarrow R = \frac{mv}{eB}$$

> 3. **代入数值：**
>    $$R = \frac{9.11 \times 10^{-31} \times 10^6}{1.6 \times 10^{-19} \times 0.1} = 5.7 \times 10^{-5} m$$

> 4. **运动周期：**
>    $$T = \frac{2\pi R}{v} = \frac{2\pi m}{eB} = 3.6 \times 10^{-10} s$$

**例题8：载流导线在磁场中的受力**
> **题目：** 长 $l = 20cm$ 的直导线通有 $I = 10A$ 电流，置于 $B = 0.5T$ 的均匀磁场中，导线与磁场方向成 $30^\circ$ 角，求导线受到的安培力。

> **解答：**
> 1. **安培力公式：** $F = BIl\sin\theta$

> 2. **代入数值：**
>    $$F = 0.5 \times 10 \times 0.2 \times \sin30^\circ = 0.5 N$$

> 3. **方向判断：** 根据左手定则确定

### 电磁感应

![电磁学_电磁感应_v2](imgs/电磁学_电磁感应_v2.png)

#### 基本概念

**电磁感应现象**
变化的磁场产生电场的现象，由法拉第发现。

**感应电动势**
由电磁感应产生的电动势：

$$\varepsilon = -\frac{d\Phi_B}{dt}$$

其中 $\Phi_B = \int_S \vec{B} \cdot d\vec{S}$ 为磁通量。

#### 重要定律

<details>
<summary><strong>法拉第电磁感应定律的详细推导</strong></summary>

**内容：** 穿过闭合回路的磁通量发生变化时，回路中产生感应电动势，其大小与磁通量变化率成正比，方向由楞次定律确定。

**公式：**
$$\varepsilon = -\frac{d\Phi_B}{dt}$$

**法拉第实验发现：**
1. **磁铁运动实验：** 当磁铁插入或拔出线圈时，线圈中产生电流
2. **电流变化实验：** 当一个线圈中的电流变化时，相邻线圈中产生电流
3. **运动导体实验：** 导体在磁场中运动时产生电动势

**理论推导：**

1. **磁通量变化：** 设闭合回路的磁通量为 $\Phi_B = \int_S \vec{B} \cdot d\vec{S}$

2. **感应电动势定义：** 根据电动势的定义：
   $$\varepsilon = \oint_L \vec{E} \cdot d\vec{l}$$

3. **法拉第定律积分形式：** 实验发现感应电动势与磁通量变化率成正比：
   $$\varepsilon = -\frac{d\Phi_B}{dt} = -\frac{d}{dt}\int_S \vec{B} \cdot d\vec{S}$$

4. **微分形式：** 利用斯托克斯定理：
   $$\oint_L \vec{E} \cdot d\vec{l} = \int_S (\nabla \times \vec{E}) \cdot d\vec{S}$$
   $$\nabla \times \vec{E} = -\frac{\partial \vec{B}}{\partial t}$$

**楞次定律的深入理解：**

**内容：** 感应电流的方向总是阻碍引起感应电流的磁通量变化。

**物理意义：**
- 体现了能量守恒定律
- 感应电流产生的磁场总是反抗原磁场的变化
- 是电磁感应现象中"阻碍"作用的体现

**判断方法：**
1. 确定原磁通量的方向和变化趋势
2. 感应电流产生的磁场方向与原磁场变化相反
3. 用右手螺旋定则确定感应电流方向

**具体应用：**
- 楞次定律可独立使用，不依赖法拉第定律的符号约定
- 在电磁感应问题中，楞次定律提供了判断感应电流方向的统一方法

**能量角度解释：**
感应电流的"阻碍"作用实际上是能量守恒的体现。如果感应电流促进原磁通量变化，就会形成正反馈，导致能量无限增长，这违反了能量守恒定律。

- 互感：$\varepsilon_{21} = -M\frac{dI_1}{dt}$

### 交流电路

![电磁学_交流电_v2](imgs/电磁学_交流电_v2.png)

#### 基本概念

**交流电**
大小和方向随时间周期性变化的电流：

$$i(t) = I_m\sin(\omega t + \phi)$$

其中：
- $I_m$ 为电流最大值（幅值）
- $\omega = 2\pi f$ 为角频率
- $f$ 为频率
- $\phi$ 为初相位

**有效值**
交流电的有效值等于产生相同热效应的直流电的值：

$$I = \frac{I_m}{\sqrt{2}}, \quad U = \frac{U_m}{\sqrt{2}}$$

#### 阻抗

**电阻的阻抗**
纯电阻的阻抗为实数：

$$Z_R = R$$

**电感的阻抗**
感抗：

$$Z_L = j\omega L = jX_L$$

其中 $X_L = \omega L$ 为感抗。

**电容的阻抗**
容抗：

$$Z_C = \frac{1}{j\omega C} = -jX_C$$

其中 $X_C = \frac{1}{\omega C}$ 为容抗。

**RLC串联电路**
总阻抗：

$$Z = R + j(\omega L - \frac{1}{\omega C}) = R + j(X_L - X_C)$$

阻抗大小：

$$|Z| = \sqrt{R^2 + (X_L - X_C)^2}$$

阻抗角：

$$\phi = \arctan\frac{X_L - X_C}{R}$$

#### 交流电路定律

**欧姆定律（交流形式）**
$$\dot{U} = \dot{I}Z$$

其中 $\dot{U}$、$\dot{I}$ 为电压、电流的复数表示（相量）。

**基尔霍夫定律（交流形式）**
- 电流定律：$\sum \dot{I} = 0$
- 电压定律：$\sum \dot{U} = 0$

#### 功率

**瞬时功率**
$$p(t) = u(t)i(t) = U_mI_m\cos(\omega t + \phi_u)\cos(\omega t + \phi_i)$$

**有功功率（平均功率）**
$$P = UI\cos\phi = I^2R$$

其中 $\cos\phi$ 为功率因数。

**无功功率**
$$Q = UI\sin\phi = I^2(X_L - X_C)$$

**视在功率**
$$S = UI = I^2|Z|$$

功率三角形：
$$S = \sqrt{P^2 + Q^2}$$

#### 谐振

**串联谐振（电压谐振）**
当 $X_L = X_C$ 时发生谐振：

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

谐振时：
- 阻抗最小：$Z_{min} = R$
- 电流最大：$I_{max} = \frac{U}{R}$
- 功率因数最大：$\cos\phi = 1$

**并联谐振（电流谐振）**
当 $X_L = X_C$ 时发生谐振：

$$\omega_0 = \frac{1}{\sqrt{LC}}$$

谐振时：
- 阻抗最大：$Z_{max} = \frac{L}{RC}$
- 总电流最小：$I_{min} = \frac{U}{Z_{max}}$

**品质因数**
$$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR}$$

表示谐振电路的选频特性。

#### 交流电路分析

| 电路类型 | 阻抗 | 电流 | 功率因数 | 特点 |
|----------|------|------|----------|------|
| 纯电阻 | $Z = R$ | $I = \frac{U}{R}$ | $\cos\phi = 1$ | 电压电流同相 |
| 纯电感 | $Z = j\omega L$ | $I = \frac{U}{\omega L}$ | $\cos\phi = 0$ | 电压超前电流90° |
| 纯电容 | $Z = \frac{1}{j\omega C}$ | $I = U\omega C$ | $\cos\phi = 0$ | 电压滞后电流90° |

| RC串联 | $Z = R - j\frac{1}{\omega C}$ | $I = \frac{U}{\sqrt{R^2 + (\frac{1}{\omega C})^2}}$ | $\cos\phi = \frac{R}{\sqrt{R^2 + (\frac{1}{\omega C})^2}}$ | 电压滞后电流 |

**串联谐振特性**
- 谐振频率：$\omega_0 = \frac{1}{\sqrt{LC}}$
- 阻抗最小：$Z_{min} = R$
- 电流最大：$I_{max} = \frac{U}{R}$
- 品质因数：$Q = \frac{\omega_0 L}{R}$
- 带宽：$\Delta\omega = \frac{\omega_0}{Q}$

- 谐振频率：$\omega_0 = \frac{1}{\sqrt{LC}}$
- 阻抗最大：$Z_{max} = \frac{L}{RC}$
- 电流最小：$I_{min} = \frac{U}{Z_{max}}$
- 品质因数：$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR}$
- 带宽：$\Delta\omega = \frac{\omega_0}{Q}$

#### 典型例题

**例题12：RLC串联谐振电路**
> **题目：** RLC串联电路中，$R = 10\Omega$，$L = 0.1H$，$C = 100\mu F$，电源电压 $U = 5V$，求谐振时的电流和各元件电压。

> **解答：**

> 2. **谐振时阻抗：** $Z = R = 10\Omega$

> 3. **谐振电流：** $I = \frac{U}{Z} = \frac{5}{10} = 0.5A$

> 4. **各元件电压：**
>    - 电阻电压：$U_R = IR = 0.5 \times 10 = 5V$
>    - 电感电压：$U_L = I\omega_0 L = 0.5 \times 316.2 \times 0.1 = 15.8V$
>    - 电容电压：$U_C = \frac{I}{\omega_0 C} = \frac{0.5}{316.2 \times 100 \times 10^{-6}} = 15.8V$

> 5. **品质因数：** $Q = \frac{\omega_0 L}{R} = \frac{316.2 \times 0.1}{10} = 3.16$

**例题13：交流电路的功率计算**
> **题目：** 某负载的电压 $u(t) = 10\sqrt{2}\cos(100\pi t)V$，电流 $i(t) = 2\sqrt{2}\cos(100\pi t - \frac{\pi}{6})A$，求有功功率、无功功率和功率因数。

> **解答：**
> 1. **有效值：** $U = 10V$，$I = 2A$

> 2. **功率因数：** $\cos\phi = \cos(-\frac{\pi}{6}) = \cos\frac{\pi}{6} = 0.866$

> 3. **有功功率：** $P = UI\cos\phi = 10 \times 2 \times 0.866 = 17.32W$

> 4. **无功功率：** $Q = UI\sin\phi = 10 \times 2 \times 0.5 = 10var$

> 5. **视在功率：** $S = UI = 20VA$

> 6. **功率三角形验证：** $S = \sqrt{P^2 + Q^2} = \sqrt{17.32^2 + 10^2} = 20VA$ ✓

**例题14：变压器的电压变换**
> **题目：** 理想变压器原线圈 $N_1 = 1000$ 匝，副线圈 $N_2 = 500$ 匝，原边电压 $U_1 = 220V$，求副边电压和电流关系。

> 4. **功率关系：** $U_1 I_1 = U_2 I_2$（理想变压器）

### 麦克斯韦电磁理论

#### 麦克斯韦方程组（积分形式）

**1. 高斯定理（电场）**
$$\oint_S \vec{E} \cdot d\vec{S} = \frac{Q_{enc}}{\varepsilon_0}$$

**2. 高斯定理（磁场）**
$$\oint_S \vec{B} \cdot d\vec{S} = 0$$

**3. 法拉第电磁感应定律**
$$\oint_L \vec{E} \cdot d\vec{l} = -\frac{d}{dt}\int_S \vec{B} \cdot d\vec{S}$$

**4. 安培环路定理（含位移电流）**
$$\oint_L \vec{B} \cdot d\vec{l} = \mu_0\left(I_{enc} + \varepsilon_0\frac{d}{dt}\int_S \vec{E} \cdot d\vec{S}\right)$$

#### 麦克斯韦方程组（微分形式）

**1. 高斯定理（电场）**
$$\nabla \cdot \vec{E} = \frac{\rho}{\varepsilon_0}$$

**2. 高斯定理（磁场）**
$$\nabla \cdot \vec{B} = 0$$

**3. 法拉第电磁感应定律**
$$\nabla \times \vec{E} = -\frac{\partial \vec{B}}{\partial t}$$

**4. 安培环路定理（含位移电流）**
$$\nabla \times \vec{B} = \mu_0\vec{J} + \mu_0\varepsilon_0\frac{\partial \vec{E}}{\partial t}$$

$$W = \int_V \left(\frac{1}{2}\varepsilon_0E^2 + \frac{1}{2\mu_0}B^2\right)dV$$

**电磁场动量**
电磁场的动量密度：
$$\vec{g} = \frac{\vec{S}}{c^2} = \frac{1}{c^2\mu_0}\vec{E} \times \vec{B}$$

**电磁场压力**
电磁波对物体的辐射压力：
$$p = \frac{S}{c}$$（完全吸收）
$$p = \frac{2S}{c}$$（完全反射）

其中 $S$ 为坡印廷矢量的平均值。

#### 电磁场的边界条件

在两种不同介质的分界面上，电磁场满足以下边界条件：

**电场的边界条件**
- 法向分量：$D_{1n} - D_{2n} = \sigma_f$
- 切向分量：$E_{1t} = E_{2t}$

**磁场的边界条件**
- 法向分量：$B_{1n} = B_{2n}$
- 切向分量：$H_{1t} - H_{2t} = \vec{K}_f$

其中：
- $\sigma_f$ 为自由电荷面密度
- $\vec{K}_f$ 为自由电流面密度
- 下标 $n$ 表示法向分量，$t$ 表示切向分量
- 下标 1、2 分别表示两种介质中的场量

#### 电磁学的对称性

**电与磁的对偶关系**

| 电学量 | 磁学量 | 关系 |
|--------|--------|------|
| 电荷 $q$ | 磁荷 $q_m$ | 对偶 |
| 电场 $\vec{E}$ | 磁场 $\vec{H}$ | 对偶 |
| 电位移 $\vec{D}$ | 磁感应强度 $\vec{B}$ | 对偶 |
| 电容率 $\varepsilon$ | 磁导率 $\mu$ | 对偶 |
| 电势 $V$ | 磁势 $V_m$ | 对偶 |
| 电流 $I$ | 磁流 $I_m$ | 对偶 |

这种对偶性在求解电磁场问题时很有用，可以通过对偶原理将电学问题的解转化为磁学问题的解。

#### 电磁波

**电磁波方程**
从麦克斯韦方程组可以推导出电磁波方程：

$$\nabla^2 \vec{E} = \mu_0\varepsilon_0\frac{\partial^2 \vec{E}}{\partial t^2}$$

$$\nabla^2 \vec{B} = \mu_0\varepsilon_0\frac{\partial^2 \vec{B}}{\partial t^2}$$

**电磁波的速度**
$$v = \frac{1}{\sqrt{\mu_0\varepsilon_0}} = 3 \times 10^8 m/s = c$$

**平面电磁波**
电场和磁场满足：
$$\vec{E} \perp \vec{B} \perp \vec{v}$$

$$E = cB$$

**电磁波的能量**
电磁波的能量密度：
$$w = w_e + w_m = \frac{1}{2}\varepsilon_0 E^2 + \frac{1}{2\mu_0}B^2 = \varepsilon_0 E^2 = \frac{B^2}{\mu_0}$$

坡印廷矢量（能流密度）：
$$\vec{S} = \frac{1}{\mu_0}\vec{E} \times \vec{B}$$

#### 典型例题

**例题15：平面电磁波的特性分析**
> **题目：** 某平面电磁波的电场强度为 $\vec{E} = E_0 \cos(kz - \omega t)\hat{x}$，求磁感应强度和能流密度。

> **解答：**
> 1. **磁场关系：** 由麦克斯韦方程组可得 $B_0 = \frac{E_0}{c}$

> 2. **磁感应强度：** $\vec{B} = \frac{E_0}{c} \cos(kz - \omega t)\hat{y}$

> 3. **能流密度（坡印廷矢量）：**
>    $$\vec{S} = \frac{1}{\mu_0} \vec{E} \times \vec{B} = \frac{E_0^2}{\mu_0 c} \cos^2(kz - \omega t)\hat{z}$$

> 4. **平均能流密度：** $\langle S \rangle = \frac{E_0^2}{2\mu_0 c}$

**例题16：电磁场的能量密度计算**
> **题目：** 某区域电场强度 $E = 10^4 V/m$，磁感应强度 $B = 0.1T$，求该区域的电磁能量密度。

> **解答：**
> 1. **电场能量密度：** $w_e = \frac{1}{2}\varepsilon_0 E^2$

> 2. **磁场能量密度：** $w_m = \frac{B^2}{2\mu_0}$

> 3. **总能量密度：** $w = w_e + w_m$

> 4. **数值计算：**
>    - $w_e = \frac{1}{2} \times 8.85 \times 10^{-12} \times (10^4)^2 = 4.43 \times 10^{-4} J/m^3$
>    - $w_m = \frac{(0.1)^2}{2 \times 4\pi \times 10^{-7}} = 3.98 \times 10^3 J/m^3$
>    - $w = 3.98 \times 10^3 J/m^3$（磁场能量占主导）

**例题17：电磁波的辐射压力**
> **题目：** 太阳光垂直照射到地球表面的能流密度为 $S = 1.4 \times 10^3 W/m^2$，求光对地面的辐射压力。

> **解答：**
> 1. **完全吸收情况：** $p = \frac{S}{c}$

> 2. **完全反射情况：** $p = \frac{2S}{c}$

> 3. **数值计算：**
>    - $c = 3 \times 10^8 m/s$
>    - $p_{吸收} = \frac{1.4 \times 10^3}{3 \times 10^8} = 4.67 \times 10^{-6} Pa$
>    - $p_{反射} = 9.34 \times 10^{-6} Pa$

## 5. 近代物理

> 📌 **重点章节**：理解现代物理的基本概念和理论
>

近代物理是20世纪初发展起来的物理学理论，主要包括相对论和量子论两大部分。相对论揭示了高速运动物体的运动规律，量子论则揭示了微观世界的运动规律。

### 5.1 狭义相对论

狭义相对论是爱因斯坦在1905年提出的理论，它统一了空间和时间，揭示了物质与能量的关系。

#### 5.1.1 狭义相对论的基本假设

**相对性原理**：
所有惯性参考系中的物理定律都有相同的数学形式，即在任何惯性参考系中，物理规律都是相同的。

**光速不变原理**：
在真空中，光速c是恒定不变的，与光源和观察者的运动状态无关。

这两个基本假设构成了狭义相对论的理论基础。

#### 5.1.2 洛伦兹变换

<details>
<summary><strong>洛伦兹变换的推导</strong></summary>

**推导过程**：

设两个惯性参考系S和S'，S'相对S以速度v沿x轴方向运动。

**坐标变换关系**：
从光速不变原理出发，考虑一束沿x轴传播的光：
$$x = ct, \quad x' = ct'$$

假设变换关系为线性形式：
$$x' = a(x - vt)$$
$$t' = b(t - cx)$$

其中a、b、c为待定系数。

**光速不变条件**：
$$x'^2 = c^2t'^2$$

代入变换关系：
$$a^2(x - vt)^2 = c^2[b(t - cx)]^2$$

展开并整理：
$$a^2(x^2 - 2vxt + v^2t^2) = c^2b^2(t^2 - 2cxt + c^2x^2)$$

比较x²项系数：
$$a^2 = c^2b^2c^2 = b^2c^4$$

比较v²t²项系数：
$$a^2v^2 = c^2b^2$$

比较-2vxt项系数：
$$-2a^2v = -2c^2b^2c = -2b^2c^3$$

**解得系数**：
从-2vxt项系数方程：
$$a^2v = b^2c^3$$

结合a² = b²c⁴：
$$b^2c^4v = b^2c^3 \Rightarrow c^4v = c^3 \Rightarrow c = \frac{1}{v}$$

这显然不合理，说明假设有误。

**修正的线性变换**：
正确的变换形式应为：
$$x' = \gamma(x - vt)$$
$$t' = \gamma(t - \frac{v}{c^2}x)$$

其中$\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}$为洛伦兹因子。

**验证**：
对于光信号：$x = ct$
$$x' = \gamma(ct - vt) = \gamma c(t - \frac{v}{c}x)$$
$$t' = \gamma(t - \frac{v}{c^2} \cdot ct) = \gamma t(1 - \frac{v}{c})$$

$$x' = \gamma c \cdot \frac{t(1 - \frac{v}{c})}{1 - \frac{v}{c}} = ct'$$

满足光速不变条件。
</details>

**洛伦兹变换公式**：

对于两个惯性参考系S和S'，S'相对S以速度v沿x轴方向运动，洛伦兹变换为：

$$x' = \gamma(x - vt)$$
$$y' = y$$
$$z' = z$$
$$t' = \gamma\left(t - \frac{vx}{c^2}\right)$$

其中：
- $\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}$为洛伦兹因子
- c为真空中光速
- v为S'相对S的运动速度

**逆变换**：
$$x = \gamma(x' + vt')$$
$$t = \gamma\left(t' + \frac{vx'}{c^2}\right)$$

**速度变换公式**：

沿x轴方向的速度变换：
$$u_x = \frac{u_x' + v}{1 + \frac{vu_x'}{c^2}}$$

垂直方向的速度变换：
$$u_y = \frac{u_y'}{\gamma\left(1 + \frac{vu_x'}{c^2}\right)}$$

#### 5.1.3 相对论的时空效应

**同时性的相对性**：

在一个惯性参考系中同时发生的两个事件，在另一个相对运动的惯性参考系中不一定同时发生。

设S系中两个事件同时发生：$t_1 = t_2$，位置分别为$x_1$和$x_2$

在S'系中：
$$\Delta t' = \gamma\left(\Delta t - \frac{v\Delta x}{c^2}\right) = -\gamma\frac{v\Delta x}{c^2}$$

只有当$\Delta x = 0$时（同一地点），才有$\Delta t' = 0$。

**时间膨胀**：

![近代物理_时间膨胀](imgs/近代物理_时间膨胀.png)

设S'系中某点发生的事件，固有时间为$\Delta \tau$（S'系中同一地点的时间间隔）

在S系中观测的时间间隔为：
$$\Delta t = \gamma\Delta \tau = \frac{\Delta \tau}{\sqrt{1 - \frac{v^2}{c^2}}}$$

即：$\Delta t > \Delta \tau$，时间膨胀了。

**长度收缩**：

![近代物理_长度收缩](imgs/近代物理_长度收缩.png)

设物体在S'系中静止，固有长度为$L_0$

在S系中观测的长度为：
$$L = \frac{L_0}{\gamma} = L_0\sqrt{1 - \frac{v^2}{c^2}}$$

即：$L < L_0$，长度收缩了。

#### 5.1.4 相对论动力学

<details>
<summary><strong>质速关系的推导</strong></summary>

**推导过程**：

1. **动量守恒**：
在相对论中，动量守恒仍然成立：
$$\vec{p} = m\vec{v}$$

2. **力的定义**：
$$\vec{F} = \frac{d\vec{p}}{dt} = \frac{d}{dt}(m\vec{v})$$

3. **能量守恒**：
考虑一个物体在力F作用下从静止开始运动：
$$dW = F \cdot ds = v \cdot dp$$

4. **积分计算**：
$$W = \int_0^v v \cdot dp = \int_0^v v \cdot d\left(\frac{m_0 v}{\sqrt{1 - v^2/c^2}}\right)$$

令$\beta = v/c$，则：
$$d\left(\frac{\beta}{\sqrt{1 - \beta^2}}\right) = \frac{d\beta}{(1 - \beta^2)^{3/2}}$$

$$W = \int_0^v \frac{m_0 v^2}{(1 - v^2/c^2)^{3/2}} \cdot \frac{dv}{v}$$

$$W = m_0 c^2 \int_0^{\beta} \frac{\beta^2}{(1 - \beta^2)^{3/2}} d\beta$$

5. **积分结果**：
令$\beta = \sin\theta$，则$d\beta = \cos\theta d\theta$：
$$W = m_0 c^2 \int_0^{\arcsin\beta} \frac{\sin^2\theta}{\cos^3\theta} \cos\theta d\theta$$

$$W = m_0 c^2 \int_0^{\arcsin\beta} \sin^2\theta \sec^2\theta d\theta$$

$$W = m_0 c^2 \int_0^{\arcsin\beta} \tan^2\theta d\theta$$

$$W = m_0 c^2 \left[\frac{1}{\sqrt{1 - \beta^2}} - 1\right]$$

$$W = \frac{m_0 c^2}{\sqrt{1 - v^2/c^2}} - m_0 c^2$$

6. **质速关系**：
$$W = \Delta E = \Delta mc^2$$

其中：
$$\Delta m = \frac{m_0}{\sqrt{1 - v^2/c^2}} - m_0$$

因此：
$$m = \frac{m_0}{\sqrt{1 - v^2/c^2}}$$

</details>

**质速关系**：
$$m = \frac{m_0}{\sqrt{1 - \frac{v^2}{c^2}}}$$

其中：
- $m$为相对论质量
- $m_0$为静质量
- $v$为物体运动速度

**相对论动量**：
$$\vec{p} = m\vec{v} = \frac{m_0\vec{v}}{\sqrt{1 - \frac{v^2}{c^2}}}$$

**相对论动能**：
$$E_k = mc^2 - m_0c^2 = \frac{m_0c^2}{\sqrt{1 - \frac{v^2}{c^2}}} - m_0c^2$$

**质能关系**：
$$E = mc^2 = \frac{m_0c^2}{\sqrt{1 - \frac{v^2}{c^2}}}$$

总能量包括动能和静能：
$$E = E_k + m_0c^2$$

**能量动量关系**：
$$E^2 = (pc)^2 + (m_0c^2)^2$$

**例题**：一个电子的动能为0.5 MeV，求其速度和质量。

**解答**：
电子静质量：$m_0 = 9.11 \times 10^{-31}$ kg
电子静能：$E_0 = m_0c^2 = 0.511$ MeV

相对论动能：$E_k = E - E_0 = 0.5$ MeV
总能量：$E = E_k + E_0 = 1.011$ MeV

由$E = \frac{m_0c^2}{\sqrt{1 - v^2/c^2}}$：
$$\frac{E}{E_0} = \frac{1}{\sqrt{1 - v^2/c^2}} = \frac{1.011}{0.511} = 1.98$$

$$1 - \frac{v^2}{c^2} = \frac{1}{1.98^2} = 0.255$$

$$v = c\sqrt{1 - 0.255} = 0.863c$$

相对论质量：$m = \gamma m_0 = 1.98m_0$

### 5.2 量子物理基础

量子物理是研究微观粒子运动规律的物理学理论，它揭示了微观世界的量子性质。

#### 5.2.1 经典物理的困难

**紫外灾难**：

维恩公式和瑞利-金斯公式都不能正确描述黑体辐射的能量分布：

- 维恩公式（短波）：$E(\lambda, T) = \frac{2\pi hc^2}{\lambda^5}e^{-\frac{hc}{\lambda kT}}$
- 瑞利-金斯公式（长波）：$E(\lambda, T) = \frac{2\pi ckT}{\lambda^4}$

实验表明，在短波区域维恩公式符合较好，在长波区域瑞利-金斯公式符合较好，但两个公式都不能完整描述实验曲线。

**光电效应**：

当光照射到金属表面时，电子会从金属中逸出。实验发现：
1. 存在截止频率$\nu_0$，低于此频率的光不能产生光电效应
2. 光电子的动能与入射光强无关，只与频率有关
3. 光电子的数目与光强成正比
4. 光电效应是瞬时的

经典波动理论无法解释这些现象。

**康普顿效应**：

当X射线照射到电子上时，散射光的波长会发生变化：
$$\Delta \lambda = \lambda' - \lambda = \frac{h}{m_0c}(1 - \cos\theta)$$

其中$\theta$为散射角，$\frac{h}{m_0c} = 2.43 \times 10^{-12}$ m为康普顿波长。

#### 5.2.2 普朗克量子假说

<details>
<summary><strong>普朗克公式的推导</strong></summary>

**推导过程**：

1. **能量量子化假设**：
   黑体辐射腔壁中的振子只能处于特定的能量状态：
   $$E_n = nh\nu, \quad n = 0, 1, 2, 3, \ldots$$

2. **玻尔兹曼分布**：
   处于能量$E_n$的振子数目：
   $$N_n = N_0 e^{-\frac{E_n}{kT}} = N_0 e^{-\frac{nh\nu}{kT}}$$

3. **平均能量**：
   $$\overline{E} = \frac{\sum_{n=0}^{\infty} E_n e^{-\frac{E_n}{kT}}}{\sum_{n=0}^{\infty} e^{-\frac{E_n}{kT}}}$$

4. **几何级数求和**：
   $$\sum_{n=0}^{\infty} e^{-\frac{nh\nu}{kT}} = \frac{1}{1 - e^{-\frac{h\nu}{kT}}}$$

   $$\sum_{n=0}^{\infty} n e^{-\frac{nh\nu}{kT}} = \frac{e^{-\frac{h\nu}{kT}}}{(1 - e^{-\frac{h\nu}{kT}})^2}$$

5. **计算平均能量**：
   $$\overline{E} = \frac{h\nu e^{-\frac{h\nu}{kT}}}{1 - e^{-\frac{h\nu}{kT}}} = \frac{h\nu}{e^{\frac{h\nu}{kT}} - 1}$$

6. **普朗克公式**：
   辐射能量密度：
   $$u(\nu, T) = \frac{8\pi\nu^2}{c^3} \cdot \frac{h\nu}{e^{\frac{h\nu}{kT}} - 1}$$

   用波长表示：
   $$u(\lambda, T) = \frac{8\pi hc}{\lambda^5} \cdot \frac{1}{e^{\frac{hc}{\lambda kT}} - 1}$$

</details>

**普朗克量子假说**：
黑体辐射的振子能量是量子化的，只能取分立值：
$$E_n = nh\nu, \quad n = 0, 1, 2, 3, \ldots$$

其中：
- $h = 6.626 \times 10^{-34}$ J·s为普朗克常数
- $\nu$为振子频率
- $n$为量子数

**普朗克公式**：
黑体辐射的能量密度分布为：
$$u(\lambda, T) = \frac{8\pi hc}{\lambda^5} \cdot \frac{1}{e^{\frac{hc}{\lambda kT}} - 1}$$

这个公式与实验结果完全符合，圆满解决了紫外灾难问题。

#### 5.2.3 爱因斯坦光量子理论

**光量子假说**：
爱因斯坦提出光具有粒子性，光由一份一份的光量子（光子）组成，每个光子的能量为：
$$E = h\nu$$

其中：
- $h$为普朗克常数
- $\nu$为光的频率

**光电效应方程**：

![近代物理_光电效应原理](imgs/近代物理_光电效应原理.png)

当光子照射到金属表面时，将能量全部传递给电子：
$$h\nu = W_0 + E_k$$

其中：
- $h\nu$为光子能量
- $W_0$为逸出功（金属的电子结合能）
- $E_k$为光电子的最大动能

**截止频率**：
当$E_k = 0$时：
$$\nu_0 = \frac{W_0}{h}$$

只有频率大于$\nu_0$的光才能产生光电效应。

**例题**：钠的逸出功为2.28 eV，求其截止波长。

**解答**：
$$W_0 = 2.28 \text{ eV} = 2.28 \times 1.602 \times 10^{-19} \text{ J} = 3.65 \times 10^{-19} \text{ J}$$

截止频率：
$$\nu_0 = \frac{W_0}{h} = \frac{3.65 \times 10^{-19}}{6.626 \times 10^{-34}} = 5.51 \times 10^{14} \text{ Hz}$$

截止波长：
$$\lambda_0 = \frac{c}{\nu_0} = \frac{3 \times 10^8}{5.51 \times 10^{14}} = 5.44 \times 10^{-7} \text{ m} = 544 \text{ nm}$$

#### 5.2.4 玻尔原子理论

**原子光谱**：

![近代物理_氢原子光谱](imgs/近代物理_氢原子光谱.png)

氢原子光谱具有线状结构，各谱线频率满足里德伯公式：
$$\frac{1}{\lambda} = R\left(\frac{1}{n_1^2} - \frac{1}{n_2^2}\right)$$

其中$R = 1.097 \times 10^7$ m⁻¹为里德伯常数。

**玻尔假设**：

1. **定态假设**：原子只能处于一系列不连续的能量状态（定态）中，在定态中电子绕核运动但不辐射能量。

2. **量子化条件**：电子的角动量是量子化的：
   $$L = n\hbar, \quad n = 1, 2, 3, \ldots$$

3. **跃迁假设**：原子在两个定态之间跃迁时，吸收或辐射光子：
   $$h\nu = |E_n - E_m|$$

**玻尔模型**：

电子绕核做圆周运动，向心力由库仑力提供：
$$\frac{mv^2}{r} = \frac{1}{4\pi\varepsilon_0}\frac{e^2}{r^2}$$

由角动量量子化条件：
$$mvr = n\hbar$$

**解得轨道半径**：
$$r_n = \frac{4\pi\varepsilon_0\hbar^2}{me^2}n^2 = a_0n^2$$

其中$a_0 = 0.529 \times 10^{-10}$ m为玻尔半径。

**能级公式**：
$$E_n = -\frac{me^4}{32\pi^2\varepsilon_0^2\hbar^2}\frac{1}{n^2} = -\frac{13.6}{n^2} \text{ eV}$$

**例题**：求氢原子从n=3跃迁到n=2时辐射的光子波长。

**解答**：
$$E_3 = -\frac{13.6}{3^2} = -1.51 \text{ eV}$$
$$E_2 = -\frac{13.6}{2^2} = -3.40 \text{ eV}$$

能量差：
$$\Delta E = E_2 - E_3 = -3.40 - (-1.51) = -1.89 \text{ eV}$$

光子能量：
$$E = |\Delta E| = 1.89 \text{ eV} = 1.89 \times 1.602 \times 10^{-19} \text{ J} = 3.03 \times 10^{-19} \text{ J}$$

波长：
$$\lambda = \frac{hc}{E} = \frac{6.626 \times 10^{-34} \times 3 \times 10^8}{3.03 \times 10^{-19}} = 6.56 \times 10^{-7} \text{ m} = 656 \text{ nm}$$

#### 5.2.5 德布罗意物质波

**物质波假说**：
德布罗意提出，所有物质粒子都具有波动性，其波长为：
$$\lambda = \frac{h}{p} = \frac{h}{mv}$$

其中$p$为粒子的动量。

**电子衍射实验**：

戴维孙-革末实验证实了电子的波动性，电子束在晶体表面衍射，衍射图样与X射线衍射相似。

**波粒二象性**：
任何物质都具有波粒二象性：
- 波动性：$\lambda = \frac{h}{p}$
- 粒子性：$E = h\nu$

### 5.3 原子结构

原子结构理论描述了电子在原子中的运动规律，是理解化学元素性质的基础。

#### 5.3.1 量子力学基本概念

**波函数**：
在量子力学中，粒子的状态用波函数$\psi(\vec{r}, t)$描述。

**薛定谔方程**：

时间依赖薛定谔方程：
$$i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$$

定态薛定谔方程：
$$\hat{H}\psi = E\psi$$

其中$\hat{H}$为哈密顿算符。

**概率密度**：
在空间某点$\vec{r}$处发现粒子的概率密度为：
$$w(\vec{r}) = |\psi(\vec{r})|^2$$

**归一化条件**：
$$\int |\psi(\vec{r})|^2 d\tau = 1$$

#### 5.3.2 氢原子

**氢原子的薛定谔方程**：

在球坐标系中，氢原子的定态薛定谔方程为：
$$-\frac{\hbar^2}{2m}\nabla^2\psi - \frac{e^2}{4\pi\varepsilon_0 r}\psi = E\psi$$

**分离变量法**：
设$\psi(r, \theta, \phi) = R(r)\Theta(\theta)\Phi(\phi)$

**量子数**：

氢原子的波函数由三个量子数确定：
- 主量子数$n = 1, 2, 3, \ldots$（决定能量）
- 角量子数$l = 0, 1, 2, \ldots, n-1$（决定角动量）
- 磁量子数$m_l = -l, -l+1, \ldots, 0, \ldots, l-1, l$（决定角动量方向）

**能级公式**：
$$E_n = -\frac{me^4}{32\pi^2\varepsilon_0^2\hbar^2}\frac{1}{n^2} = -\frac{13.6}{n^2} \text{ eV}$$

**径向波函数**：
$$R_{nl}(r) = \sqrt{\left(\frac{2}{na_0}\right)^3\frac{(n-l-1)!}{2n[(n+l)!]^3}} e^{-\frac{r}{na_0}} \left(\frac{2r}{na_0}\right)^l L_{n-l-1}^{2l+1}\left(\frac{2r}{na_0}\right)$$

其中$L_{n-l-1}^{2l+1}$为拉盖尔多项式。

**电子云**：

电子在原子中的分布用电子云描述，不同轨道具有不同的形状：
- s轨道（$l=0$）：球形对称
- p轨道（$l=1$）：哑铃形
- d轨道（$l=2$）：花瓣形
- f轨道（$l=3$）：更复杂的形状

**径向概率分布**：
$$P(r) = 4\pi r^2 |R_{nl}(r)|^2$$

表示在半径$r$到$r+dr$的球壳内发现电子的概率。

#### 5.3.3 多电子原子

**泡利不相容原理**：
在同一个原子中，不能有两个或两个以上的电子具有完全相同的四个量子数$(n, l, m_l, m_s)$。

**电子自旋**：
电子具有内禀角动量（自旋），自旋量子数$s = \frac{1}{2}$，自旋磁量子数$m_s = \pm\frac{1}{2}$。

**能量最小原理**：
原子处于基态时，电子总是先占据能量最低的轨道。

**电子排布规则**：

1. **泡利不相容原理**：每个轨道最多容纳2个电子，自旋相反
2. **能量最小原理**：电子按能量从低到高依次填充
3. **洪特规则**：在简并轨道（能量相同）中，电子尽量分占不同轨道且自旋平行

**电子组态**：
用$n^l$表示电子组态，如：
- 碳原子：$1s^22s^22p^2$
- 氧原子：$1s^22s^22p^4$
- 铁原子：$[Ar]4s^23d^6$

**周期表结构**：
- s区：$ns^1-2$（ⅠA、ⅡA族）
- p区：$ns^2np^{1-6}$（ⅢA-ⅧA族）
- d区：$(n-1)d^{1-10}ns^{0-2}$（ⅠB-ⅧB族）
- f区：$(n-2)f^{1-14}(n-1)d^{0-2}ns^2$（镧系、锕系）

#### 5.3.4 重点公式总结

| 公式名称 | 数学表达式 | 说明 |
|---------|------------|------|
| 薛定谔方程 | $i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$ | 量子力学基本方程 |
| 氢原子能级 | $E_n = -\frac{13.6}{n^2}$ eV | 氢原子能级 |
| 径向概率分布 | $P(r) = 4\pi r^2 \|R_{nl}(r)\|^2$ | 电子径向分布 |
| 角动量量子化 | $L = \sqrt{l(l+1)}\hbar$ | 角动量大小 |
| 角动量z分量 | $L_z = m_l\hbar$ | 角动量分量 |
| 自旋角动量 | $S = \sqrt{s(s+1)}\hbar$ | 自旋角动量 |

**例题**：计算氢原子基态电子的径向概率分布最大值位置。

**解答**：
基态：$n=1, l=0$
径向波函数：$R_{10}(r) = 2a_0^{-3/2}e^{-r/a_0}$

径向概率分布：
$$P(r) = 4\pi r^2 |R_{10}(r)|^2 = 4\pi r^2 \cdot 4a_0^{-3}e^{-2r/a_0} = 16\pi a_0^{-3}r^2e^{-2r/a_0}$$

求极值：
$$\frac{dP}{dr} = 16\pi a_0^{-3}\left(2re^{-2r/a_0} - \frac{2r^2}{a_0}e^{-2r/a_0}\right) = 0$$

$$2r - \frac{2r^2}{a_0} = 0 \Rightarrow r = a_0$$

因此，基态电子在$r = a_0$处出现的概率最大。

### 5.4 激光与光谱

激光与光谱学是现代物理学的重要分支，在科学研究和技术应用中具有重要意义。

#### 5.4.1 激光原理

**原子能级间的跃迁**：

1. **自发辐射**：
   原子处于激发态时，会自发跃迁到低能级，同时辐射光子。
   $$A_{21} = \frac{dN_2}{dt}\bigg|_{自发} = -A_{21}N_2$$

2. **受激吸收**：
   原子处于低能级时，吸收光子跃迁到高能级。
   $$\frac{dN_1}{dt}\bigg|_{吸收} = -B_{12}\rho(\nu)N_1$$

3. **受激辐射**：
   处于激发态的原子在入射光子的激发下跃迁到低能级，辐射出与入射光相同的光子。
   $$\frac{dN_2}{dt}\bigg|_{受激} = -B_{21}\rho(\nu)N_2$$

**爱因斯坦系数关系**：
$$A_{21} = \frac{8\pi h\nu^3}{c^3}B_{21}$$
$$B_{12} = B_{21}$$

**粒子数反转**：

正常情况下，低能级粒子数大于高能级粒子数：$N_1 > N_2$

要实现激光放大，需要：$N_2 > N_1$（粒子数反转）

**三能级系统**：

1. 泵浦光将粒子从$E_1$激发到$E_3$
2. 粒子快速从$E_3$无辐射跃迁到$E_2$（亚稳态）
3. 在$E_2$和$E_1$之间实现受激辐射

**四能级系统**：

1. 泵浦光将粒子从$E_1$激发到$E_4$
2. 粒子快速从$E_4$无辐射跃迁到$E_3$（亚稳态）
3. 在$E_3$和$E_2$之间实现受激辐射
4. 粒子快速从$E_2$无辐射跃迁到$E_1$

**激光器结构**：

1. **工作物质**：提供增益的激活介质
2. **泵浦源**：提供能量实现粒子数反转
3. **光学谐振腔**：提供光反馈和选频
   - 全反射镜：反射率接近100%
   - 部分反射镜：允许部分光输出

#### 5.4.2 激光特性

**相干性**：
- 时间相干性：激光具有很长的相干长度
- 空间相干性：激光具有很好的方向性

**方向性**：
激光的发散角很小，接近衍射极限：
$$\theta \approx \frac{\lambda}{D}$$

其中$D$为激光器孔径直径。

**单色性**：
激光的频谱宽度很窄，相对带宽可达$\frac{\Delta\nu}{\nu} \sim 10^{-15}$。

**高亮度**：
激光的亮度比普通光源高几个到十几个数量级。

**例题**：一台氦氖激光器，波长为632.8 nm，发散角为1 mrad，光斑直径为1 mm，计算其亮度。

**解答**：
发散角：$\theta = 1$ mrad = 10⁻³ rad
立体角：$\Omega = \pi\theta^2 = \pi \times 10^{-6}$ sr

光斑面积：$A = \pi r^2 = \pi \times (0.5 \times 10^{-3})^2 = 7.85 \times 10^{-7}$ m²

亮度：$B = \frac{P}{A\Omega}$

假设激光功率$P = 1$ mW：
$$B = \frac{10^{-3}}{7.85 \times 10^{-7} \times \pi \times 10^{-6}} = 4.06 \times 10^{8} \text{ W/(m²·sr)}$$

#### 5.4.3 原子光谱

**光谱的分类**：

1. **发射光谱**：
   - 连续光谱：炽热固体、液体发出
   - 线状光谱：稀薄气体原子发出
   - 带状光谱：分子发出

2. **吸收光谱**：
   连续光谱通过低温气体后，某些波长被吸收，形成暗线光谱。

**氢原子光谱**：

- **莱曼系**（紫外）：$\frac{1}{\lambda} = R(\frac{1}{1^2} - \frac{1}{n^2})$, $n = 2, 3, 4, \ldots$
- **巴尔末系**（可见）：$\frac{1}{\lambda} = R(\frac{1}{2^2} - \frac{1}{n^2})$, $n = 3, 4, 5, \ldots$
- **帕邢系**（红外）：$\frac{1}{\lambda} = R(\frac{1}{3^2} - \frac{1}{n^2})$, $n = 4, 5, 6, \ldots$
- **布喇开系**（红外）：$\frac{1}{\lambda} = R(\frac{1}{4^2} - \frac{1}{n^2})$, $n = 5, 6, 7, \ldots$
- **普丰德系**（红外）：$\frac{1}{\lambda} = R(\frac{1}{5^2} - \frac{1}{n^2})$, $n = 6, 7, 8, \ldots$

**光谱分析**：
每种元素都有其特征光谱，可以用来：
- 鉴别元素
- 分析物质成分
- 研究原子结构

#### 5.4.4 重点公式总结

| 公式名称 | 数学表达式 | 说明 |
|---------|------------|------|
| 自发辐射概率 | $A_{21}$ | 自发跃迁概率 |
| 受激吸收概率 | $B_{12}\rho(\nu)$ | 吸收跃迁概率 |
| 受激辐射概率 | $B_{21}\rho(\nu)$ | 受激跃迁概率 |
| 爱因斯坦关系 | $A_{21} = \frac{8\pi h\nu^3}{c^3}B_{21}$ | 系数关系 |
| 莱曼系公式 | $\frac{1}{\lambda} = R(\frac{1}{1^2} - \frac{1}{n^2})$ | 氢原子光谱 |
| 巴尔末系公式 | $\frac{1}{\lambda} = R(\frac{1}{2^2} - \frac{1}{n^2})$ | 氢原子光谱 |

### 5.5 核物理

核物理研究原子核的结构、性质和变化规律，是现代物理学的重要组成部分。

#### 5.5.1 原子核的结构

**原子核的组成**：

原子核由质子和中子组成：
- 质子（p）：电荷$+e$，质量$m_p = 1.6726 \times 10^{-27}$ kg
- 中子（n）：电荷$0$，质量$m_n = 1.6749 \times 10^{-27}$ kg

原子核表示：${}_Z^AX$
- $A$：质量数（质子数+中子数）
- $Z$：原子序数（质子数）
- $N = A - Z$：中子数

**核力**：

核子是强相互作用，核力具有以下特点：
1. **强相互作用**：比电磁力强约100倍
2. **短程力**：作用范围约$10^{-15}$ m
3. **饱和性**：每个核子只与邻近核子相互作用
4. **电荷无关性**：质子间、中子间、质子中子间核力基本相同

**核能级**：

原子核也具有能级结构：
- 基态：最低能量状态
- 激发态：较高能量状态
- 退激：激发态向低能级跃迁，辐射γ光子

#### 5.5.2 放射性衰变

**衰变类型**：

1. **α衰变**：
   $${}_Z^AX \rightarrow {}_{Z-2}^{A-4}Y + {}_2^4He$$

   特点：
   - 放出α粒子（氦核）
   - 衰变能：$Q_\alpha = [M_X - M_Y - M_{He}]c^2$
   - 穿透能力弱（纸就能阻挡）

2. **β⁻衰变**：
   $${}_Z^AX \rightarrow {}_{Z+1}^{A}Y + e^- + \bar{\nu}_e$$

   特点：
   - 中子转化为质子
   - 放出电子和反中微子
   - 衰变能：$Q_\beta = [M_X - M_Y]c^2$

3. **β⁺衰变**：
   $${}_Z^AX \rightarrow {}_{Z-1}^{A}Y + e^+ + \nu_e$$

   特点：
   - 质子转化为中子
   - 放出正电子和中微子
   - 需要额外能量

4. **γ衰变**：
   $${}_Z^AX^* \rightarrow {}_Z^AX + \gamma$$

   特点：
   - 原子核从激发态跃迁到基态
   - 放出γ光子
   - 不改变核结构

**衰变规律**：

放射性衰变遵循指数规律：
$$N = N_0 e^{-\lambda t}$$

其中：
- $N_0$：初始原子核数
- $N$：t时刻原子核数
- $\lambda$：衰变常数

**半衰期**：
$$T_{1/2} = \frac{\ln 2}{\lambda} = \frac{0.693}{\lambda}$$

**平均寿命**：
$$\tau = \frac{1}{\lambda}$$

**活度**：
$$A = \lambda N = A_0 e^{-\lambda t}$$

单位：贝克勒尔（Bq），1 Bq = 1次衰变/秒

**例题**：碳-14的半衰期为5730年，求1克碳-14的活度。

**解答**：
碳-14原子数：
$$N = \frac{1 \times 10^{-3}}{14 \times 1.66 \times 10^{-27}} = 4.3 \times 10^{22}$$

衰变常数：
$$\lambda = \frac{\ln 2}{T_{1/2}} = \frac{0.693}{5730 \times 365 \times 24 \times 3600} = 3.83 \times 10^{-12} \text{ s}^{-1}$$

活度：
$$A = \lambda N = 3.83 \times 10^{-12} \times 4.3 \times 10^{22} = 1.65 \times 10^{11} \text{ Bq} = 165 \text{ GBq}$$

#### 5.5.3 核反应

**核反应方程**：
$${}_Z^AX + {}_a^bC \rightarrow {}_Z'^A'Y + {}_c^dD$$

反应前后质量数和电荷数守恒：
- 质量数守恒：$A + b = A' + d$
- 电荷数守恒：$Z + a = Z' + c$

**反应能（Q值）**：
$$Q = [M_X + M_C - M_Y - M_D]c^2$$

- $Q > 0$：放能反应
- $Q < 0$：吸能反应

**反应截面**：
$$\sigma = \frac{\text{单位时间内发生的反应数}}{\text{入射粒子流密度} \times \text{靶核数密度} \times \text{靶厚度}}$$

单位：靶恩（b），1 b = 10⁻²⁸ m²

**核反应类型**：

1. **散射**：
   - 弹性散射：$A + a \rightarrow A + a$
   - 非弹性散射：$A + a \rightarrow A^* + a$

2. **核反应**：
   - 裂变：${}_0^1n + {}_{92}^{235}U \rightarrow {}_{56}^{141}Ba + {}_{36}^{92}Kr + 3{}_0^1n$
   - 聚变：${}_1^2H + {}_1^3H \rightarrow {}_2^4He + {}_0^1n$

#### 5.5.4 核裂变与核聚变

**核裂变**：

重核分裂为中等质量核的过程：
- 典型裂变：${}_{92}^{235}U + {}_0^1n \rightarrow {}_{56}^{141}Ba + {}_{36}^{92}Kr + 3{}_0^1n$
- 每次裂变释放约200 MeV能量
- 产生2-3个中子，可引起链式反应

**核聚变**：

轻核聚合成较重核的过程：
- 典型聚变：${}_1^2H + {}_1^3H \rightarrow {}_2^4He + {}_0^1n + 17.6$ MeV
- 太阳能量来源：质子-质子链
- 需要极高温度（>10⁸ K）克服库仑势垒

**核能的应用**：

1. **核电站**：
   - 利用核裂变释放的热能发电
   - 主要燃料：${}_{92}^{235}U$、${}_{94}^{239}Pu$
   - 典型功率：1000 MW

2. **核武器**：
   - 原子弹：核裂变链式反应
   - 氢弹：核聚变反应

3. **核聚变能源**：
   - 清洁能源
   - 燃料丰富（海水中的氘）
   - 技术难点：约束高温等离子体

#### 5.5.5 重点公式总结

| 公式名称 | 数学表达式 | 说明 |
|---------|------------|------|
| 衰变定律 | $N = N_0 e^{-\lambda t}$ | 放射性衰变 |
| 半衰期 | $T_{1/2} = \frac{\ln 2}{\lambda}$ | 半衰期计算 |
| 衰变能 | $Q = [M_X - M_Y]c^2$ | α衰变能 |
| 反应能 | $Q = [M_X + M_C - M_Y - M_D]c^2$ | 核反应能 |
| 质能关系 | $E = mc^2$ | 核能计算 |
| 裂变能 | 约200 MeV | 每次裂变释放能量 |
| 聚变能 | 约4 MeV | 每次聚变释放能量 |

**例题**：计算${}_{92}^{235}U$裂变释放的能量。

**解答**：
裂变反应：${}_{92}^{235}U + {}_0^1n \rightarrow {}_{56}^{141}Ba + {}_{36}^{92}Kr + 3{}_0^1n$

各粒子质量（原子质量单位）：
- ${}_{92}^{235}U$：235.0439 u
- ${}_0^1n$：1.0087 u
- ${}_{56}^{141}Ba$：140.9144 u
- ${}_{36}^{92}Kr$：91.9262 u

反应前后质量差：
$$\Delta m = (235.0439 + 1.0087) - (140.9144 + 91.9262 + 3 \times 1.0087)$$
$$= 236.0526 - 235.8667 = 0.1859 \text{ u}$$

能量释放：
$$E = \Delta m c^2 = 0.1859 \times 931.5 \text{ MeV} = 173.2 \text{ MeV}$$

实际释放能量约200 MeV（考虑其他可能的裂变产物）。
