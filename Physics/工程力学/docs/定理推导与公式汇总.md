## 静力学重要定理

### 力的合成定理

#### 平行四边形法则 ⭐
两个力可以合成为一个合力，合力的大小和方向由以这两个力为邻边所构成的平行四边形的对角线确定。

**数学表达式**：
$$\vec{F_R} = \vec{F_1} + \vec{F_2}$$

**合力的大小**：
$$F_R = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$$

<details>
<summary>平行四边形法则推导过程</summary>

设两个力 $\vec{F_1}$ 和 $\vec{F_2}$ 作用在同一点O，夹角为 $\theta$。

根据矢量加法的几何意义：
1. 以 $\vec{F_1}$ 和 $\vec{F_2}$ 为邻边作平行四边形
2. 对角线即为合力 $\vec{F_R}$
3. 由余弦定理可得：
   $$F_R^2 = F_1^2 + F_2^2 - 2F_1F_2\cos(180°-\theta)$$
   $$F_R^2 = F_1^2 + F_2^2 + 2F_1F_2\cos\theta$$

因此：$F_R = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$
</details>

#### 三角形法则 ⭐
将两个力首尾相接，合力为从第一个力的起点到第二个力的终点的连线。

#### 多边形法则 ⭐
多个力的合成可以连续使用三角形法则，最终合力为从第一个力的起点到最后一个力的终点的连线。

**多边形法则的数学表达式**：
$$\vec{F_R} = \vec{F_1} + \vec{F_2} + \vec{F_3} + ... + \vec{F_n}$$

### 力的平衡定理

#### 平面汇交力系平衡 ⭐
平面汇交力系平衡的充要条件是：合力为零。

**数学表达式**：
$$\vec{F_R} = \sum_{i=1}^{n} \vec{F_i} = 0$$

**平衡方程**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$

#### 平面一般力系平衡 ⭐
平面一般力系平衡的充要条件是：
1. 合力为零：$\vec{F_R} = 0$
2. 合力矩为零：$\vec{M_O} = 0$

**平衡方程**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$
$$\sum M_O = 0$$

<details>
<summary>平面一般力系平衡条件的推导</summary>

对于平面一般力系，我们可以将其向任一点O简化：

1. **主矢**：$\vec{F_R} = \sum \vec{F_i}$
2. **主矩**：$M_O = \sum M_O(\vec{F_i})$

平衡时，主矢和主矩都必须为零：
- $\vec{F_R} = 0$ 保证物体不发生移动
- $M_O = 0$ 保证物体不发生转动

因此得到三个独立的平衡方程。
</details>

#### 空间一般力系平衡 ⭐
**平衡方程**：
$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0$$
$$\sum M_x = 0, \quad \sum M_y = 0, \quad \sum M_z = 0$$

### 摩擦定律

#### 静摩擦定律（库仑定律）⭐
静摩擦力的大小在零与最大静摩擦力之间：
$$0 \leq f_s \leq f_{s\max}$$

**最大静摩擦力**：
$$f_{s\max} = \mu_s N$$

其中：
- $\mu_s$：静摩擦系数
- $N$：法向反力

#### 动摩擦定律
动摩擦力的大小为：
$$f_k = \mu_k N$$

其中 $\mu_k$ 为动摩擦系数，通常 $\mu_k < \mu_s$。

---

### 自锁条件

#### 摩擦角 ⭐
**定义**：全反力与法线方向的夹角称为摩擦角。

**摩擦角公式**：
$$\tan\varphi = \frac{f_s}{N} = \mu_s$$

其中 $\varphi$ 为摩擦角。

#### 自锁现象 ⭐
**定义**：当主动力的合力作用线位于摩擦角内时，无论主动力多大，物体都保持静止，这种现象称为自锁。

**自锁条件**：
$$\alpha \leq \varphi$$

<details>
<summary>自锁现象的证明</summary>

设物体受主动力 $\vec{P}$ 和全反力 $\vec{R}$ 作用，平衡时：
$$\vec{P} + \vec{R} = 0$$

即 $\vec{P} = -\vec{R}$，说明两力大小相等、方向相反、作用线共线。

全反力 $\vec{R}$ 与法线的夹角为 $\varphi$，当 $\alpha \leq \varphi$ 时，全反力的作用线总能通过主动力的作用点，使物体保持平衡。

因此自锁条件为：$\alpha \leq \varphi = \arctan\mu_s$
</details>

## 运动学重要定理

### 速度合成定理

#### 绝对速度
$$\vec{v_a} = \vec{v_e} + \vec{v_r}$$

其中：
- $\vec{v_a}$：绝对速度
- $\vec{v_e}$：牵连速度
- $\vec{v_r}$：相对速度

#### 速度合成定理
**一般形式**：
$$\vec{v_a} = \vec{v_e} + \vec{v_r}$$

**分量形式**：
$$v_{ax} = v_{ex} + v_{rx}$$
$$v_{ay} = v_{ey} + v_{ry}$$
$$v_{az} = v_{ez} + v_{rz}$$

<details>
<summary>速度合成定理推导</summary>

设动点M相对于动参考系S'运动，动参考系S'相对于定参考系S运动。

在dt时间内：
1. 动点M的绝对位移：$d\vec{r_a}$
2. 牵连位移：$d\vec{r_e}$（动参考系上与M重合点的位移）
3. 相对位移：$d\vec{r_r}$（动点在动参考系中的位移）

由位移合成：
$$d\vec{r_a} = d\vec{r_e} + d\vec{r_r}$$

两边除以dt：
$$\frac{d\vec{r_a}}{dt} = \frac{d\vec{r_e}}{dt} + \frac{d\vec{r_r}}{dt}$$

即：
$$\vec{v_a} = \vec{v_e} + \vec{v_r}$$
</details>

---

### 加速度合成定理

#### 绝对加速度
$$\vec{a_a} = \vec{a_e} + \vec{a_r} + \vec{a_c}$$

其中：
- $\vec{a_a}$：绝对加速度
- $\vec{a_e}$：牵连加速度
- $\vec{a_r}$：相对加速度
- $\vec{a_c}$：科氏加速度

#### 科氏加速度
$$\vec{a_c} = 2\vec{\omega_e} \times \vec{v_r}$$

其中 $\vec{\omega_e}$ 为动参考系的角速度。

<details>
<summary>加速度合成定理推导</summary>

对速度合成公式两边求导：
$$\frac{d\vec{v_a}}{dt} = \frac{d\vec{v_e}}{dt} + \frac{d\vec{v_r}}{dt}$$

其中：
1. $\frac{d\vec{v_a}}{dt} = \vec{a_a}$（绝对加速度）
2. $\frac{d\vec{v_e}}{dt} = \vec{a_e}$（牵连加速度）
3. $\frac{d\vec{v_r}}{dt} = \vec{a_r} + \vec{a_c}$（相对加速度 + 科氏加速度）

因此：
$$\vec{a_a} = \vec{a_e} + \vec{a_r} + \vec{a_c}$$
</details>

## 动力学重要定理

### 牛顿第二定律 ⭐

#### 基本形式
$$\vec{F} = m\vec{a} = m\frac{d^2\vec{r}}{dt^2}$$

#### 分量形式
$$\begin{cases}
F_x = m\ddot{x} \\
F_y = m\ddot{y} \\
F_z = m\ddot{z}
\end{cases}$$

#### 变质量系统
$$\vec{F} = \frac{d}{dt}(m\vec{v}) = m\frac{d\vec{v}}{dt} + \vec{v}\frac{dm}{dt}$$

<details>
<summary>牛顿第二定律推导</summary>

从牛顿第一定律可知，物体在不受力时保持静止或匀速直线运动状态。

当有外力作用时，实验表明：
1. 加速度与力成正比：$\vec{a} \propto \vec{F}$
2. 加速度与质量成反比：$\vec{a} \propto \frac{1}{m}$

因此：
$$\vec{F} \propto m\vec{a}$$

引入比例常数k（在国际单位制中k=1），得：
$$\vec{F} = m\vec{a}$$
</details>

---

### 动量定理

#### 质点的动量定理 ⭐
**微分形式**：
$$\frac{d\vec{p}}{dt} = \vec{F}$$

**积分形式**（冲量-动量定理）：
$$\int_{t_1}^{t_2} \vec{F}dt = \vec{p}_2 - \vec{p}_1 = m\vec{v}_2 - m\vec{v}_1$$

其中 $\vec{p} = m\vec{v}$ 为动量。

#### 质点系的动量定理
**微分形式**：
$$\frac{d\vec{P}}{dt} = \sum_{i=1}^n \vec{F}_i^{(e)} = \vec{F}^{(e)}$$

**积分形式**：
$$\int_{t_1}^{t_2} \vec{F}^{(e)}dt = \vec{P}_2 - \vec{P}_1$$

<details>
<summary>质点系动量定理推导</summary>

对于质点系中的第$i$个质点：
$$m_i\frac{d^2\vec{r}_i}{dt^2} = \vec{F}_i^{(e)} + \sum_{j=1}^n \vec{F}_{ij}^{(i)}$$

对所有质点求和：
$$\sum_{i=1}^n m_i\frac{d^2\vec{r}_i}{dt^2} = \sum_{i=1}^n \vec{F}_i^{(e)} + \sum_{i=1}^n \sum_{j=1}^n \vec{F}_{ij}^{(i)}$$

根据牛顿第三定律，内力之和为零：
$$\sum_{i=1}^n \sum_{j=1}^n \vec{F}_{ij}^{(i)} = 0$$

因此：
$$\sum_{i=1}^n m_i\frac{d^2\vec{r}_i}{dt^2} = \sum_{i=1}^n \vec{F}_i^{(e)}$$

即：
$$\frac{d^2}{dt^2}\left(\sum_{i=1}^n m_i\vec{r}_i\right) = \vec{F}^{(e)}$$
</details>

### 动能定理

#### 质点的动能定理 ⭐
**微分形式**：
$$dT = \vec{F} \cdot d\vec{r} = F\cos\alpha ds$$

**积分形式**：
$$T_2 - T_1 = \int_{M_1}^{M_2} \vec{F} \cdot d\vec{r} = W_{12}$$

其中：
- $T = \frac{1}{2}mv^2$ 为动能
- $W_{12}$ 为力 $\vec{F}$ 从位置1到位置2所作的功

#### 质点系的动能定理
**柯尼希定理**：
$$T = T_c + T_{rc}$$

其中：
- $T_c = \frac{1}{2}Mv_c^2$：质心的动能
- $T_{rc} = \sum_{i=1}^n \frac{1}{2}m_iv_{ri}^2$：相对于质心的动能

<details>
<summary>动能定理推导</summary>

从牛顿第二定律：
$$\vec{F} = m\frac{d\vec{v}}{dt}$$

两边点乘位移微分 $d\vec{r} = \vec{v}dt$：
$$\vec{F} \cdot d\vec{r} = m\frac{d\vec{v}}{dt} \cdot \vec{v}dt = m\vec{v} \cdot d\vec{v}$$

右边：
$$m\vec{v} \cdot d\vec{v} = \frac{1}{2}m d(\vec{v} \cdot \vec{v}) = \frac{1}{2}m d(v^2) = d\left(\frac{1}{2}mv^2\right)$$

因此：
$$\vec{F} \cdot d\vec{r} = dT$$

积分得：
$$\int_{M_1}^{M_2} \vec{F} \cdot d\vec{r} = T_2 - T_1$$
</details>

---

### 机械能守恒定律

#### 保守力与势能
重力、弹性力、万有引力等都是保守力。

#### 机械能守恒 ⭐
$$T + V = \text{常量}$$

其中：
- $T$：动能
- $V$：势能

<details>
<summary>机械能守恒定律推导</summary>

对于保守力，存在势能函数 $V$，使得：
$$\vec{F} = -\nabla V = -\frac{\partial V}{\partial x}\vec{i} - \frac{\partial V}{\partial y}\vec{j} - \frac{\partial V}{\partial z}\vec{k}$$

保守力所作的功：
$$W = \int \vec{F} \cdot d\vec{r} = -\int dV = V_1 - V_2$$

根据动能定理：
$$T_2 - T_1 = W = V_1 - V_2$$

整理得：
$$T_1 + V_1 = T_2 + V_2 = \text{常量}$$
</details>

## 材料力学重要定理

### 虎克定律 ⭐

#### 基本形式
$$\sigma = E\varepsilon$$

其中：
- $\sigma$：正应力
- $E$：弹性模量（杨氏模量）
- $\varepsilon$：线应变

#### 轴向拉伸/压缩
$$\Delta L = \frac{FL_0}{EA}$$

<details>
<summary>虎克定律推导</summary>

从材料试验可知，在弹性范围内，应力与应变成正比：

1. **应力-应变关系**：$\sigma = E\varepsilon$
2. **应变定义**：$\varepsilon = \frac{\Delta L}{L_0}$
3. **应力定义**：$\sigma = \frac{F}{A}$

因此：
$$\frac{F}{A} = E\frac{\Delta L}{L_0}$$

整理得：
$$\Delta L = \frac{FL_0}{EA}$$
</details>

#### 剪切虎克定律
$$\tau = G\gamma$$

其中：
- $\tau$：剪应力
- $G$：剪切模量
- $\gamma$：剪应变

---

### 欧拉公式 ⭐

#### 压杆稳定临界载荷
$$P_{cr} = \frac{\pi^2EI}{(μL)^2}$$

其中：
- $E$：弹性模量
- $I$：最小惯性矩
- $μ$：长度系数
- $L$：压杆长度

#### 长度系数
- 两端铰支：$μ = 1$
- 一端固定一端自由：$μ = 2$
- 两端固定：$μ = 0.5$
- 一端固定一端铰支：$μ = 0.7$

<details>
<summary>欧拉公式推导</summary>

对于细长压杆，假设其失稳时的挠曲线为正弦函数：
$$y = \delta\sin\frac{\pi x}{L}$$

弯矩与曲率的关系：
$$M = -EI\frac{d^2y}{dx^2}$$

临界状态下：
$$M = P_{cr}y$$

因此：
$$-EI\frac{d^2y}{dx^2} = P_{cr}y$$

代入挠曲线方程：
$$-EI\left(-\delta\frac{\pi^2}{L^2}\sin\frac{\pi x}{L}\right) = P_{cr}\delta\sin\frac{\pi x}{L}$$

化简得：
$$P_{cr} = \frac{\pi^2EI}{L^2}$$

考虑不同约束条件，引入长度系数μ：
$$P_{cr} = \frac{\pi^2EI}{(μL)^2}$$
</details>

### 强度理论

#### 第三强度理论（最大剪应力理论）⭐
$$\sigma_{r3} = \sqrt{\sigma^2 + 4\tau^2} \leq [\sigma]$$

#### 第四强度理论（形状改变比能理论）⭐
$$\sigma_{r4} = \sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]$$

#### 平面应力状态的主应力
$$\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}$$

<details>
<summary>强度理论推导</summary>

**第三强度理论（最大剪应力理论）**：

该理论认为，材料的破坏主要取决于最大剪应力。

对于纯剪切应力状态，$\sigma = 0$，$\tau = \tau_{max}$，有：
$$\sigma_{r3} = 2\tau_{max}$$

对于复杂应力状态，最大剪应力为：
$$\tau_{max} = \frac{1}{2}\sqrt{(\sigma_x - \sigma_y)^2 + 4\tau_{xy}^2}$$

因此相当应力为：
$$\sigma_{r3} = \sqrt{(\sigma_x - \sigma_y)^2 + 4\tau_{xy}^2}$$

对于单向拉伸（$\sigma_x = \sigma$，$\sigma_y = 0$，$\tau_{xy} = 0$）：
$$\sigma_{r3} = \sigma$$

**第四强度理论（形状改变比能理论）**：

该理论认为，材料的破坏主要取决于形状改变比能。

形状改变比能：
$$u_d = \frac{1+\nu}{3E}[(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2]$$

相当应力：
$$\sigma_{r4} = \sqrt{\frac{1}{2}[(\sigma_1 - \sigma_2)^2 + (\sigma_2 - \sigma_3)^2 + (\sigma_3 - \sigma_1)^2]}$$

对于平面应力状态（$\sigma_3 = 0$）：
$$\sigma_{r4} = \sqrt{\sigma_1^2 + \sigma_2^2 - \sigma_1\sigma_2}$$
</details>

## 结构力学重要定理

### 虚功原理 ⭐

#### 外虚功
$$\delta W_e = \sum F_i \delta \Delta_i$$

#### 内虚功
$$\delta W_i = \int_V \sigma_{ij} \delta \varepsilon_{ij} dV$$

#### 虚功方程
$$\delta W_e = \delta W_i$$

<details>
<summary>虚功原理推导</summary>

考虑一个线性弹性结构，其应变能为：
$$U = \int_V \frac{1}{2}\sigma_{ij}\varepsilon_{ij}dV$$

对于外力$P_i$，对应的位移为$\Delta_i$。当外力有增量$dP_i$时，应变能的增量为：
$$dU = \frac{\partial U}{\partial P_i}dP_i$$

另一方面，外力增量$dP_i$所作的功为$dP_i \cdot \Delta_i$，而原有外力在对应位移增量上所作的功为$P_i \cdot d\Delta_i$。

根据能量守恒：
$$dU = dP_i \cdot \Delta_i$$

因此：
$$\frac{\partial U}{\partial P_i} = \Delta_i$$

这就是卡氏第一定理，也是虚功原理的一种形式。
</details>

---

### 卡氏定理

#### 卡氏第一定理
$$\Delta_i = \frac{\partial U}{\partial P_i}$$

#### 卡氏第二定理
$$\Delta_i = \int \frac{M\bar{M}}{EI}dx$$

其中 $\bar{M}$ 为在 $i$ 方向施加单位力时的弯矩。

<details>
<summary>卡氏定理推导</summary>

**卡氏第一定理**：

应变能 $U$ 是外力 $P_i$ 的函数：
$$U = U(P_1, P_2, ..., P_n)$$

外力作功：
$$W = \sum \frac{1}{2}P_i\Delta_i$$

对于弹性系统：
$$U = W = \sum \frac{1}{2}P_i\Delta_i$$

对 $P_k$ 求偏导：
$$\frac{\partial U}{\partial P_k} = \frac{1}{2}\Delta_k + \frac{1}{2}P_k\frac{\partial \Delta_k}{\partial P_k} + \sum_{i \neq k}\frac{1}{2}P_i\frac{\partial \Delta_i}{\partial P_k}$$

根据麦克斯韦互等定理：$\frac{\partial \Delta_i}{\partial P_k} = \frac{\partial \Delta_k}{\partial P_i}$

因此：
$$\frac{\partial U}{\partial P_k} = \Delta_k$$

**卡氏第二定理**：

对于梁结构，应变能：
$$U = \int \frac{M^2}{2EI}dx$$

根据卡氏第一定理：
$$\Delta_i = \frac{\partial U}{\partial P_i} = \int \frac{M}{EI}\frac{\partial M}{\partial P_i}dx$$

令 $\bar{M} = \frac{\partial M}{\partial P_i}$（单位力产生的弯矩），则：
$$\Delta_i = \int \frac{M\bar{M}}{EI}dx$$
</details>

### 力法方程

#### 基本方程
$$\delta_{11}X_1 + \Delta_{1P} = 0$$

#### 多余未知量的力法方程
$$\begin{cases}
\delta_{11}X_1 + \delta_{12}X_2 + \Delta_{1P} = 0 \\
\delta_{21}X_1 + \delta_{22}X_2 + \Delta_{2P} = 0
\end{cases}$$

#### 位移计算公式
$$\delta_{ij} = \int \frac{M_iM_j}{EI}ds + \int \frac{N_iN_j}{EA}ds + \int \frac{kQ_iQ_j}{GA}ds$$

$$\Delta_{iP} = \int \frac{M_iM_P}{EI}ds + \int \frac{N_iN_P}{EA}ds + \int \frac{kQ_iQ_P}{GA}ds$$

<details>
<summary>力法方程推导</summary>

力法的基本思想是将超静定结构转化为静定基本结构，以多余约束力为基本未知量。

1. **基本结构**：解除多余约束，得到静定结构
2. **变形协调条件**：基本结构在多余约束处的位移应等于原结构的位移
3. **建立方程**：根据变形协调条件建立力法方程

对于一次超静定结构：
$$\delta_{11}X_1 + \Delta_{1P} = 0$$

其中：
- $\delta_{11}$：$X_1 = 1$ 时在 $X_1$ 方向的位移
- $\Delta_{1P}$：荷载作用下在 $X_1$ 方向的位移

对于多次超静定结构：
$$[\delta]\{X\} + \{\Delta_P\} = 0$$
</details>

---

### 位移法方程

#### 基本方程
$$\begin{bmatrix}
k_{11} & k_{12} & \cdots & k_{1n} \\
k_{21} & k_{22} & \cdots & k_{2n} \\
\vdots & \vdots & \ddots & \vdots \\
k_{n1} & k_{n2} & \cdots & k_{nn}
\end{bmatrix}
\begin{Bmatrix}
\Delta_1 \\
\Delta_2 \\
\vdots \\
\Delta_n
\end{Bmatrix}
=
\begin{Bmatrix}
P_1 \\
P_2 \\
\vdots \\
P_n
\end{Bmatrix}$$

或简写为：
$$[K]\{\Delta\} = \{P\}$$

<details>
<summary>位移法方程推导</summary>

位移法的基本思想是以节点位移为基本未知量，建立平衡方程。

1. **基本未知量**：节点线位移和角位移
2. **基本体系**：加入附加约束阻止节点位移
3. **平衡条件**：节点平衡方程

对于每个节点位移 $\Delta_i$，建立平衡方程：
$$\sum k_{ij}\Delta_j = P_i$$

其中 $k_{ij}$ 为刚度系数，表示当 $\Delta_j = 1$ 时在 $\Delta_i$ 方向产生的反力。
</details>

## 流体力学重要定理

### 帕斯卡定律 ⭐

#### 基本内容
在密闭容器中的静止流体，任意一点压强的变化会等值传递到流体的所有点。

**数学表达式**：
$$\Delta p_1 = \Delta p_2 = \Delta p_3 = \cdots$$

#### 液压传动原理
$$\frac{F_1}{A_1} = \frac{F_2}{A_2}$$

<details>
<summary>帕斯卡定律推导</summary>

从流体微元受力平衡考虑：

1. **微元立方体分析：**
   - 尺寸：$dx \times dy \times dz$
   - 密度：$\rho$
   - 质量：$\rho dxdydz$

2. **x方向平衡：**
   $$p_x dy dz - (p_x + \frac{\partial p}{\partial x} dx)dy dz = 0$$
   $$\frac{\partial p}{\partial x} = 0$$

3. **y方向平衡：**
   $$p_y dx dz - (p_y + \frac{\partial p}{\partial y} dy)dx dz = 0$$
   $$\frac{\partial p}{\partial y} = 0$$

4. **z方向平衡：**
   $$p_z dx dy - (p_z + \frac{\partial p}{\partial z} dz)dx dy - \rho g dx dy dz = 0$$
   $$\frac{\partial p}{\partial z} + \rho g = 0$$

5. **结论：**
   $$\frac{\partial p}{\partial x} = \frac{\partial p}{\partial y} = 0$$

   即：压强在水平方向上处处相等，变化只发生在垂直方向。
</details>

---

### 连续性方程 ⭐

#### 一维流动连续性方程
$$\rho_1 A_1 v_1 = \rho_2 A_2 v_2 = \dot{m} = 常数$$

#### 不可压缩流体
$$A_1 v_1 = A_2 v_2 = Q = 常数$$

其中 $Q$ 为体积流量。

<details>
<summary>连续性方程推导</summary>

**控制体分析：**

1. **控制体选取：**
   - 入口：截面积$A_1$，流速$v_1$，密度$\rho_1$
   - 出口：截面积$A_2$，流速$v_2$，密度$\rho_2$

2. **质量守恒：**
   $$\dot{m}_{入口} = \dot{m}_{出口}$$

3. **质量流量表达式：**
   $$\dot{m} = \rho A v$$

4. **连续性方程：**
   $$\rho_1 A_1 v_1 = \rho_2 A_2 v_2$$

5. **不可压缩流体（$\rho_1 = \rho_2 = \rho$）：**
   $$A_1 v_1 = A_2 v_2$$
</details>

---

### 伯努利方程 ⭐

#### 理想流体伯努利方程
$$p_1 + \frac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g z_2 = 常数$$

#### 实际流体伯努利方程
$$p_1 + \frac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g z_2 + h_w$$

其中 $h_w$ 为水头损失。

<details>
<summary>伯努利方程推导</summary>

**沿流线的积分推导：**

1. **欧拉运动方程：**
   $$\frac{Dv}{Dt} = -\frac{1}{\rho}\frac{\partial p}{\partial s} - g\frac{\partial z}{\partial s}$$

2. **稳定流动：**
   $$v\frac{dv}{ds} = -\frac{1}{\rho}\frac{dp}{ds} - g\frac{dz}{ds}$$

3. **积分：**
   $$\int v dv = -\int \frac{1}{\rho} dp - \int g dz$$

4. **不可压缩流体（$\rho = 常数$）：**
   $$\frac{v^2}{2} + \frac{p}{\rho} + gz = 常数$$

5. **除以$g$得水头形式：**
   $$\frac{v^2}{2g} + \frac{p}{\rho g} + z = H = 常数$$
</details>

---

### 雷诺数

#### 基本定义
$$Re = \frac{\rho v D}{\mu} = \frac{v D}{\nu}$$

其中：
- $Re$：雷诺数（无量纲）
- $\rho$：密度 (kg/m³)
- $v$：流速 (m/s)
- $D$：特征长度 (m)
- $\mu$：动力粘度 (Pa·s)
- $\nu$：运动粘度 (m²/s)

#### 流动状态判断
- **层流：** $Re < 2300$
- **过渡流：** $2300 \leq Re \leq 4000$
- **湍流：** $Re > 4000$

<details>
<summary>雷诺数物理意义</summary>

**雷诺数的物理意义：**

1. **惯性力与粘性力之比：**
   $$Re = \frac{\text{惯性力}}{\text{粘性力}} = \frac{\rho v^2 L^2}{\mu v L} = \frac{\rho v L}{\mu}$$

2. **流动稳定性指标：**
   - $Re$小：粘性力占主导，流动稳定
   - $Re$大：惯性力占主导，流动不稳定

3. **无量纲特性：**
   - 不随流速、管径等绝对大小变化
   - 只与流动状态有关
</details>
