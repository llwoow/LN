## 1. 流体静力学

### 1.1 流体基本性质

#### 1.1.1 密度与比重
⭐ **重点考点：密度计算**

**密度定义：**
$$\rho = \frac{m}{V}$$

其中：
- $\rho$：密度 (kg/m³)
- $m$：质量 (kg)
- $V$：体积 (m³)

**比重定义：**
$$S = \frac{\rho}{\rho_w}$$

其中：
- $S$：比重（无量纲）
- $\rho_w$：水的密度 (1000 kg/m³)

**常见流体密度：**
- 水：1000 kg/m³
- 空气：1.225 kg/m³
- 汞：13600 kg/m³
- 油类：800-900 kg/m³

#### 1.1.2 粘度特性

⭐ **重点考点：动力粘度与运动粘度**

**动力粘度（绝对粘度）：**
$$\mu = \frac{\tau}{\frac{du}{dy}}$$

其中：
- $\mu$：动力粘度 (Pa·s)
- $\tau$：剪切应力 (Pa)
- $\frac{du}{dy}$：速度梯度 (s⁻¹)

**运动粘度：**
$$\nu = \frac{\mu}{\rho}$$

其中：
- $\nu$：运动粘度 (m²/s)
- $\mu$：动力粘度 (Pa·s)
- $\rho$：密度 (kg/m³)

**常见流体粘度（20°C）：**
- 水：$\mu = 1.002 \times 10^{-3}$ Pa·s
- 空气：$\mu = 1.81 \times 10^{-5}$ Pa·s
- 甘油：$\mu = 1.49$ Pa·s

<details>
<summary>牛顿流体与非牛顿流体</summary>

**牛顿流体：**
- 剪切应力与速度梯度成正比
- 关系：$\tau = \mu \frac{du}{dy}$
- 代表：空气、水、酒精等

**非牛顿流体：**
- 剪切应力与速度梯度非线性关系
- 常见类型：
  - 假塑性流体：$\tau = K(\frac{du}{dy})^n$ (n < 1)
  - 膨胀性流体：$\tau = K(\frac{du}{dy})^n$ (n > 1)
  - 宾汉流体：$\tau = \tau_0 + \mu_p\frac{du}{dy}$
</details>

### 1.2 流体静压强

#### 1.2.1 压强定义与单位

⭐ **重点考点：压强计算与单位换算**

**压强定义：**
$$p = \frac{F}{A}$$

其中：
- $p$：压强 (Pa)
- $F$：垂直作用力 (N)
- $A$：受力面积 (m²)

**常用单位换算：**
- 1 Pa = 1 N/m²
- 1 kPa = 1000 Pa
- 1 MPa = 10⁶ Pa
- 1 bar = 10⁵ Pa
- 1 atm = 101325 Pa ≈ 101.325 kPa
- 1 mmHg = 133.322 Pa
- 1 mmH₂O = 9.807 Pa

#### 1.2.2 静压强分布规律

⭐ **重点考点：静压强计算公式**

**静压强基本公式：**
$$p = p_0 + \rho gh$$

其中：
- $p_0$：表面压强 (Pa)
- $\rho$：流体密度 (kg/m³)
- $g$：重力加速度 (9.81 m/s²)
- $h$：液体深度 (m)

**相对压强：**
$$p_{相对} = p - p_{atm}$$

**绝对压强：**
$$p_{绝对} = p_{相对} + p_{atm}$$

<details>
<summary>静压强推导过程</summary>

从流体微元分析出发：

1. **微元受力分析：**
   - 上表面：$pA$
   - 下表面：$(p + dp)A$
   - 侧面：$p_{侧}A_{侧}$
   - 重力：$\rho g A dz$

2. **平衡条件：**
   $$pA - (p + dp)A - \rho g A dz = 0$$

3. **简化得：**
   $$-dp = \rho g dz$$

4. **积分：**
   $$\int_{p_0}^{p} dp = -\int_{0}^{h} \rho g dz$$
   
   $$p = p_0 + \rho gh$$
</details>

#### 1.2.3 等压面概念

⭐ **重点考点：等压面识别**

**等压面定义：**
在同一水平面上，压强相等的点构成的面称为等压面。

**等压面特性：**
- 等压面是水平面（重力场中）
- 等压面上压强处处相等
- 自由液面是等压面

**等压面方程：**
$$p = constant$$

### 1.3 帕斯卡定律

⭐ **重点考点：帕斯卡定律应用**

**帕斯卡定律：**
在密闭容器中的静止流体，任意一点压强的变化会等值传递到流体的所有点。

**数学表达式：**
$$\Delta p_1 = \Delta p_2 = \Delta p_3 = \cdots$$

<details>
<summary>帕斯卡定律推导</summary>

从流体微元受力平衡考虑：

1. **微元立方体分析：**
   - 尺寸：$dx \times dy \times dz$
   - 密度：$\rho$
   - 质量：$\rho dxdydz$

2. **x方向平衡：**
   $$p_x dy dz - (p_x + \frac{\partial p}{\partial x} dx)dy dz = 0$$
   $$\frac{\partial p}{\partial x} = 0$$

3. **y方向平衡：**
   $$p_y dx dz - (p_y + \frac{\partial p}{\partial y} dy)dx dz = 0$$
   $$\frac{\partial p}{\partial y} = 0$$

4. **z方向平衡：**
   $$p_z dx dy - (p_z + \frac{\partial p}{\partial z} dz)dx dy - \rho g dx dy dz = 0$$
   $$\frac{\partial p}{\partial z} + \rho g = 0$$

5. **结论：**
   $$\frac{\partial p}{\partial x} = \frac{\partial p}{\partial y} = 0$$

   即：压强在水平方向上处处相等，变化只发生在垂直方向。
</details>

#### 1.3.1 液压传动原理

**液压传动基本方程：**
$$\frac{F_1}{A_1} = \frac{F_2}{A_2}$$

**液压放大倍数：**
$$\frac{F_2}{F_1} = \frac{A_2}{A_1} = \left(\frac{d_2}{d_1}\right)^2$$

其中：
- $F_1, F_2$：作用力 (N)
- $A_1, A_2$：活塞面积 (m²)
- $d_1, d_2$：活塞直径 (m)

### 1.4 典型例题

**例题1：静水压强计算**

⭐ **解题思路：**
1. 确定参考平面
2. 计算各点深度
3. 应用静压强公式

*题目：* 某水箱水深3m，求水面下1m、2m、3m处的绝对压强和相对压强。

*解答：*
已知：$h_1 = 1m, h_2 = 2m, h_3 = 3m, \rho = 1000 kg/m³, p_{atm} = 101325 Pa$

**相对压强：**
- $p_1 = \rho gh_1 = 1000 \times 9.81 \times 1 = 9810$ Pa
- $p_2 = \rho gh_2 = 1000 \times 9.81 \times 2 = 19620$ Pa  
- $p_3 = \rho gh_3 = 1000 \times 9.81 \times 3 = 29430$ Pa

**绝对压强：**
- $p_{1绝对} = p_1 + p_{atm} = 9810 + 101325 = 111135$ Pa
- $p_{2绝对} = p_2 + p_{atm} = 19620 + 101325 = 120945$ Pa
- $p_{3绝对} = p_3 + p_{atm} = 29430 + 101325 = 130755$ Pa

**例题2：液压传动计算**

⭐ **解题思路：**
1. 应用帕斯卡定律
2. 利用面积比关系
3. 计算力的放大倍数

*题目：* 液压传动系统中，小活塞直径$d_1 = 0.1m$，大活塞直径$d_2 = 0.3m$，在小活塞上施加$F_1 = 1000N$的力，求大活塞能产生的力$F_2$。

*解答：*
根据帕斯卡定律：
$$\frac{F_1}{A_1} = \frac{F_2}{A_2}$$

$$\frac{F_2}{F_1} = \frac{A_2}{A_1} = \left(\frac{d_2}{d_1}\right)^2 = \left(\frac{0.3}{0.1}\right)^2 = 9$$

$$F_2 = 9 \times F_1 = 9 \times 1000 = 9000N$$

## 2. 流体动力学基础

### 2.1 基本概念

#### 2.1.1 流动类型

⭐ **重点考点：流动类型判断**

**按时间变化分类：**
- **稳定流动：** $\frac{\partial}{\partial t} = 0$
- **非稳定流动：** $\frac{\partial}{\partial t} \neq 0$

**按空间变化分类：**
- **一维流动：** 只有一个空间坐标变化
- **二维流动：** 两个空间坐标变化
- **三维流动：** 三个空间坐标变化

**按流线形状分类：**
- **平行流动：** 流线相互平行
- **渐变流动：** 流线接近平行
- **急变流动：** 流线明显弯曲

#### 2.1.2 流线与流管

**流线定义：**
在某一瞬间，流体中一条曲线，其上每一点的切线方向与该点速度方向相同。

**流线方程：**
$$\frac{dx}{u_x} = \frac{dy}{u_y} = \frac{dz}{u_z}$$

**流管定义：**
由流线围成的管状曲面。

**流管特性：**
- 流管内流体不能流出
- 流管外流体不能流入
- 有效截面积为流管横截面积

### 2.2 连续性方程

⭐ **重点考点：连续性方程应用**

**一维流动连续性方程：**
$$\rho_1 A_1 v_1 = \rho_2 A_2 v_2 = \dot{m} = 常数$$

其中：
- $\rho$：密度 (kg/m³)
- $A$：截面积 (m²)
- $v$：流速 (m/s)
- $\dot{m}$：质量流量 (kg/s)

**不可压缩流体（$\rho = 常数$）：**
$$A_1 v_1 = A_2 v_2 = Q = 常数$$

其中：
- $Q$：体积流量 (m³/s)

**流速与截面积关系：**
$$v_2 = v_1 \frac{A_1}{A_2}$$

<details>
<summary>连续性方程推导</summary>

**控制体分析：**

1. **控制体选取：**
   - 入口：截面积$A_1$，流速$v_1$，密度$\rho_1$
   - 出口：截面积$A_2$，流速$v_2$，密度$\rho_2$

2. **质量守恒：**
   $$\dot{m}_{入口} = \dot{m}_{出口}$$

3. **质量流量表达式：**
   $$\dot{m} = \rho A v$$

4. **连续性方程：**
   $$\rho_1 A_1 v_1 = \rho_2 A_2 v_2$$

5. **不可压缩流体（$\rho_1 = \rho_2 = \rho$）：**
   $$A_1 v_1 = A_2 v_2$$
</details>

### 2.3 伯努利方程

⭐ **重点考点：伯努利方程应用与能量分析**

**理想流体伯努利方程：**
$$p_1 + \frac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g z_2 = 常数$$

**实际流体伯努利方程：**
$$p_1 + \frac{1}{2}\rho v_1^2 + \rho g z_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g z_2 + h_w$$

其中：
- $h_w$：水头损失 (m)
- $z$：位置水头 (m)
- $\frac{p}{\rho g}$：压强水头 (m)
- $\frac{v^2}{2g}$：速度水头 (m)

**伯努利方程物理意义：**
$$z + \frac{p}{\rho g} + \frac{v^2}{2g} = H = 常数$$

其中$H$为总水头。

<details>
<summary>伯努利方程推导</summary>

**沿流线的积分推导：**

1. **欧拉运动方程：**
   $$\frac{Dv}{Dt} = -\frac{1}{\rho}\frac{\partial p}{\partial s} - g\frac{\partial z}{\partial s}$$

2. **稳定流动：**
   $$v\frac{dv}{ds} = -\frac{1}{\rho}\frac{dp}{ds} - g\frac{dz}{ds}$$

3. **积分：**
   $$\int v dv = -\int \frac{1}{\rho} dp - \int g dz$$

4. **不可压缩流体（$\rho = 常数$）：**
   $$\frac{v^2}{2} + \frac{p}{\rho} + gz = 常数$$

5. **除以$g$得水头形式：**
   $$\frac{v^2}{2g} + \frac{p}{\rho g} + z = H = 常数$$
</details>

#### 2.3.1 能量损失

⭐ **重点考点：能量损失计算**

**总水头损失：**
$$h_w = h_f + h_j$$

其中：
- $h_f$：沿程水头损失 (m)
- $h_j$：局部水头损失 (m)

**沿程水头损失（达西公式）：**
$$h_f = \lambda \frac{L}{D} \frac{v^2}{2g}$$

其中：
- $\lambda$：沿程阻力系数
- $L$：管长 (m)
- $D$：管径 (m)

**局部水头损失：**
$$h_j = \zeta \frac{v^2}{2g}$$

其中：
- $\zeta$：局部阻力系数

### 2.4 典型例题

**例题3：连续性方程应用**

⭐ **解题思路：**
1. 应用连续性方程
2. 计算流速变化
3. 分析流量关系

*题目：* 水管直径从$d_1 = 0.2m$缩小到$d_2 = 0.1m$，已知上游流速$v_1 = 2m/s$，求下游流速$v_2$和体积流量$Q$。

*解答：*
根据连续性方程：
$$A_1 v_1 = A_2 v_2 = Q$$

$$v_2 = v_1 \frac{A_1}{A_2} = v_1 \frac{d_1^2}{d_2^2} = 2 \times \left(\frac{0.2}{0.1}\right)^2 = 2 \times 4 = 8 m/s$$

体积流量：
$$Q = A_1 v_1 = \frac{\pi d_1^2}{4} v_1 = \frac{\pi \times 0.2^2}{4} \times 2 = 0.0628 m^3/s$$

**例题4：伯努利方程应用**

⭐ **解题思路：**
1. 选择基准面
2. 确定已知量和未知量
3. 应用伯努利方程
4. 求解未知量

*题目：* 水箱底部有一小孔，孔径$d = 0.02m$，水箱水深$H = 2m$，求孔口流速和流量（忽略能量损失）。

*解答：*
**基准面：** 选取孔口中心为基准面

**伯努利方程：**
水箱水面：$z_1 = 2m, p_1 = p_{atm}, v_1 \approx 0$
孔口：$z_2 = 0, p_2 = p_{atm}, v_2 = ?$

$$\frac{p_{atm}}{\rho g} + 0 + 2 = \frac{p_{atm}}{\rho g} + 0 + \frac{v_2^2}{2g}$$

$$2 = \frac{v_2^2}{2g}$$

$$v_2 = \sqrt{2gH} = \sqrt{2 \times 9.81 \times 2} = \sqrt{39.24} = 6.26 m/s$$

**流量：**
$$Q = A v_2 = \frac{\pi d^2}{4} v_2 = \frac{\pi \times 0.02^2}{4} \times 6.26 = 0.00197 m^3/s$$

## 3. 管路流动

### 3.1 流动状态

#### 3.1.1 层流与湍流

⭐ **重点考点：流动状态判断**

**雷诺数定义：**
$$Re = \frac{\rho v D}{\mu} = \frac{v D}{\nu}$$

其中：
- $Re$：雷诺数（无量纲）
- $\rho$：密度 (kg/m³)
- $v$：流速 (m/s)
- $D$：特征长度 (m)
- $\mu$：动力粘度 (Pa·s)
- $\nu$：运动粘度 (m²/s)

**流动状态判断：**
- **层流：** $Re < 2300$
- **过渡流：** $2300 \leq Re \leq 4000$
- **湍流：** $Re > 4000$

**临界雷诺数：**
- 圆管：$Re_{cr} = 2300$
- 非圆管：$Re_{cr} = \frac{4R_h v}{\nu}$

其中$R_h$为水力半径。

<details>
<summary>雷诺数物理意义</summary>

**雷诺数的物理意义：**

1. **惯性力与粘性力之比：**
   $$Re = \frac{\text{惯性力}}{\text{粘性力}} = \frac{\rho v^2 L^2}{\mu v L} = \frac{\rho v L}{\mu}$$

2. **流动稳定性指标：**
   - $Re$小：粘性力占主导，流动稳定
   - $Re$大：惯性力占主导，流动不稳定

3. **无量纲特性：**
   - 不随流速、管径等绝对大小变化
   - 只与流动状态有关
</details>

#### 3.1.2 圆管层流

**层流速度分布（抛物线分布）：**
$$u(r) = \frac{\Delta p}{4\mu L}(R^2 - r^2)$$

其中：
- $u(r)$：距离管轴$r$处的流速 (m/s)
- $R$：管半径 (m)
- $\Delta p$：压强差 (Pa)
- $L$：管长 (m)

**最大流速（管轴处）：**
$$u_{max} = \frac{\Delta p R^2}{4\mu L}$$

**平均流速：**
$$v = \frac{u_{max}}{2} = \frac{\Delta p R^2}{8\mu L}$$

**层流沿程阻力系数：**
$$\lambda = \frac{64}{Re}$$

**层流水头损失：**
$$h_f = \frac{32\mu L v}{\rho g D^2} = \frac{64}{Re} \frac{L}{D} \frac{v^2}{2g}$$

#### 3.1.3 圆管湍流

**湍流速度分布（经验公式）：**
- **1/7次方定律：** $u(r) = u_{max}(1-\frac{r}{R})^{1/7}$
- **对数分布：** $\frac{u}{u_*} = \frac{1}{\kappa} \ln(\frac{y u_*}{\nu}) + B$

其中：
- $u_*$：摩阻流速 = $\sqrt{\frac{\tau_w}{\rho}}$
- $\kappa$：卡门常数 ≈ 0.4
- $B$：常数 ≈ 5.5

**湍流沿程阻力系数：**

1. **光滑管（布拉修斯公式）：**
   $$\lambda = \frac{0.3164}{Re^{0.25}} \quad (4000 < Re < 10^5)$$

2. **粗糙管（科尔布鲁克公式）：**
   $$\frac{1}{\sqrt{\lambda}} = -2\log\left(\frac{\Delta}{3.7D} + \frac{2.51}{Re\sqrt{\lambda}}\right)$$

3. **完全粗糙管（尼古拉兹公式）：**
   $$\lambda = \frac{1}{[2\log(\frac{D}{2\Delta}) + 1.14]^2}$$

其中$\Delta$为绝对粗糙度。

### 3.2 沿程阻力

⭐ **重点考点：沿程阻力计算**

**达西-韦斯巴赫公式：**
$$h_f = \lambda \frac{L}{D} \frac{v^2}{2g}$$

**摩阻流速：**
$$u_* = \sqrt{\frac{\tau_w}{\rho}} = \sqrt{\frac{\lambda}{8}} v$$

**壁面剪切应力：**
$$\tau_w = \lambda \frac{\rho v^2}{8}$$

**水力直径：**
$$D_h = \frac{4A}{P}$$

其中：
- $A$：过流断面面积
- $P$：湿周

#### 3.2.1 莫迪图

**莫迪图用途：**
- 查取沿程阻力系数$\lambda$
- 考虑相对粗糙度$\frac{\Delta}{D}$的影响
- 适用于工程计算

**莫迪图分区：**
1. **层流区：** $\lambda = \frac{64}{Re}$
2. **过渡区：** $\lambda$随$Re$和$\frac{\Delta}{D}$变化
3. **湍流光滑区：** $\lambda = f(Re)$
4. **湍流过渡区：** $\lambda = f(Re, \frac{\Delta}{D})$
5. **湍流粗糙区：** $\lambda = f(\frac{\Delta}{D})$

### 3.3 局部阻力

⭐ **重点考点：局部阻力计算**

**局部水头损失：**
$$h_j = \zeta \frac{v^2}{2g}$$

其中$\zeta$为局部阻力系数。

#### 3.3.1 常见局部阻力系数

**突然扩大：**
$$\zeta = \left(1 - \frac{A_1}{A_2}\right)^2$$

**突然缩小：**
$$\zeta = \left(\frac{1}{\varepsilon} - 1\right)^2$$

其中$\varepsilon = \frac{A_2}{A_1}$为收缩比。

**进口：**
- **锐缘进口：** $\zeta = 0.5$
- **圆角进口：** $\zeta = 0.2-0.3$

**出口：**
- **自由出流：** $\zeta = 1.0$
- **淹没出流：** $\zeta = 1.0$

**弯头：**
- **90°弯头：** $\zeta = 0.2-1.0$
- **45°弯头：** $\zeta = 0.1-0.5$

**阀门：**
- **全开闸阀：** $\zeta = 0.1-0.2$
- **半开闸阀：** $\zeta = 1.0-2.0$
- **全开球阀：** $\zeta = 0.05-0.1$

#### 3.3.2 当量长度法

**当量长度定义：**
将局部阻力转换为相同阻力损失的直管长度。

**计算公式：**
$$L_e = \zeta \frac{D}{\lambda}$$

**总水头损失：**
$$h_w = \lambda \frac{L + \sum L_e}{D} \frac{v^2}{2g}$$

### 3.4 典型例题

**例题5：雷诺数计算与流动状态判断**

⭐ **解题思路：**
1. 计算雷诺数
2. 判断流动状态
3. 选择相应公式

*题目：* 水在管径$D = 0.1m$的圆管中流动，流速$v = 2m/s$，水温20°C（$\nu = 1.004 \times 10^{-6} m^2/s$），判断流动状态。

*解答：*

**判断：** 湍流

**例题6：沿程水头损失计算**

⭐ **解题思路：**
1. 确定流动状态
2. 选择阻力系数公式
3. 计算沿程损失

*题目：* 直径$D = 0.2m$的钢管，长度$L = 1000m$，输送水流量$Q = 0.1m^3/s$，水温20°C，相对粗糙度$\frac{\Delta}{D} = 0.001$，求沿程水头损失。

*解答：*
**基本参数：**
$$v = \frac{Q}{A} = \frac{0.1}{\pi \times 0.2^2/4} = 3.18 m/s$$
$$Re = \frac{vD}{\nu} = \frac{3.18 \times 0.2}{1.004 \times 10^{-6}} = 633865 > 4000 \text{（湍流）}$$

**阻力系数计算：**
使用科尔布鲁克公式：
$$\frac{1}{\sqrt{\lambda}} = -2\log\left(\frac{0.001}{3.7} + \frac{2.51}{633865\sqrt{\lambda}}\right)$$

迭代求解得：$\lambda \approx 0.018$

**沿程水头损失：**
$$h_f = \lambda \frac{L}{D} \frac{v^2}{2g} = 0.018 \times \frac{1000}{0.2} \times \frac{3.18^2}{2 \times 9.81} = 46.4 m$$

## 4. 边界层概念

### 4.1 边界层理论基础

#### 4.1.1 边界层定义

⭐ **重点考点：边界层概念**

**边界层定义：**
在粘性流体绕固体表面流动时，紧贴固体表面的薄层流体，由于粘性作用，速度从壁面上的零值逐渐增加到主流速度，这一薄层称为边界层。

**边界层厚度：**
$$\delta = \frac{y}{u_\infty} = 0.99$$

其中：
- $\delta$：边界层厚度 (m)
- $u_\infty$：主流速度 (m/s)
- $y$：距离壁面的距离 (m)

#### 4.1.2 边界层形成

**边界层发展过程：**
1. **层流边界层：** $Re_x < 5 \times 10^5$
2. **转捩区：** $5 \times 10^5 < Re_x < 3 \times 10^6$
3. **湍流边界层：** $Re_x > 3 \times 10^6$

其中$x$为沿程距离，$Re_x = \frac{u_\infty x}{\nu}$

<details>
<summary>边界层形成机理</summary>

**粘性效应分析：**

1. **壁面无滑移条件：**
   $$u(y=0) = 0$$

2. **速度梯度：**
   $$\frac{\partial u}{\partial y} \neq 0 \text{（在壁面附近）}$$

3. **粘性剪切应力：**
   $$\tau = \mu \frac{\partial u}{\partial y}$$

4. **边界层特征：**
   - 厚度很小：$\delta \ll L$
   - 速度梯度大：$\frac{\partial u}{\partial y} \gg 1$
   - 粘性效应显著
</details>

### 4.2 边界层方程

#### 4.2.1 普朗特边界层方程

**二维稳态边界层方程：**

1. **连续性方程：**
   $$\frac{\partial u}{\partial x} + \frac{\partial v}{\partial y} = 0$$

2. **动量方程：**
   $$u\frac{\partial u}{\partial x} + v\frac{\partial u}{\partial y} = -\frac{1}{\rho}\frac{\partial p}{\partial x} + \nu\frac{\partial^2 u}{\partial y^2}$$

**边界条件：**
- $y = 0$：$u = 0, v = 0$
- $y = \delta$：$u = u_\infty$
- $y \to \infty$：$u = u_\infty$

#### 4.2.2 边界层厚度计算

**层流边界层厚度：**
$$\delta = \frac{5.0x}{\sqrt{Re_x}}$$

**湍流边界层厚度：**
$$\delta = \frac{0.37x}{Re_x^{1/5}}$$

**位移厚度：**
$$\delta^* = \int_0^\infty \left(1 - \frac{u}{u_\infty}\right)dy$$

**动量厚度：**
$$\theta = \int_0^\infty \frac{u}{u_\infty}\left(1 - \frac{u}{u_\infty}\right)dy$$

### 4.3 边界层分离

⭐ **重点考点：边界层分离条件**

#### 4.3.1 分离现象

**边界层分离定义：**
当流体流经曲面壁面时，由于逆压梯度的作用，边界层内的流体速度逐渐减小，最终在壁面处发生倒流，导致边界层脱离壁面的现象。

**分离条件：**
$$\left(\frac{\partial u}{\partial y}\right)_{y=0} = 0$$

**分离点特征：**
- 壁面剪切应力为零：$\tau_w = 0$
- 壁面速度梯度为零：$\frac{\partial u}{\partial y}|_{y=0} = 0$
- 出现回流现象

#### 4.3.2 压强梯度影响

**顺压梯度（$\frac{dp}{dx} < 0$）：**
- 加速流动
- 边界层不易分离
- 边界层厚度增长缓慢

**逆压梯度（$\frac{dp}{dx} > 0$）：**
- 减速流动
- 边界层容易分离
- 边界层厚度快速增长

### 4.4 阻力系数

⭐ **重点考点：阻力系数计算**

#### 4.4.1 摩擦阻力系数

**平板局部摩擦系数：**
$$C_f = \frac{\tau_w}{\frac{1}{2}\rho u_\infty^2}$$

**平板平均摩擦系数：**

1. **层流：**
   $$C_f = \frac{1.328}{\sqrt{Re_L}}$$

2. **湍流：**
   $$C_f = \frac{0.455}{(\log Re_L)^{2.58}}$$

其中$Re_L = \frac{u_\infty L}{\nu}$为基于板长的雷诺数。

#### 4.4.2 压差阻力系数

**压差阻力产生原因：**
- 边界层分离
- 尾涡形成
- 压强分布不对称

**压差阻力系数：**
$$C_d = \frac{D_d}{\frac{1}{2}\rho u_\infty^2 A}$$

其中：
- $D_d$：压差阻力 (N)
- $A$：投影面积 (m²)

#### 4.4.3 总阻力系数

**总阻力系数：**
$$C_D = C_f + C_d$$

**阻力分解：**
- **摩阻：** 由粘性剪切应力产生
- **压差：** 由压强分布不对称产生

### 4.5 典型例题

**例题7：边界层厚度计算**

⭐ **解题思路：**
1. 判断流动状态
2. 选择相应公式
3. 计算边界层厚度

*题目：* 平板长度$L = 1m$，主流速度$u_\infty = 10m/s$，流体运动粘度$\nu = 1.5 \times 10^{-5} m^2/s$，求板末端边界层厚度。

*解答：*
**雷诺数计算：**
$$Re_L = \frac{u_\infty L}{\nu} = \frac{10 \times 1}{1.5 \times 10^{-5}} = 6.67 \times 10^5 > 5 \times 10^5$$

**流动状态：** 湍流边界层

**边界层厚度：**
$$\delta = \frac{0.37L}{Re_L^{1/5}} = \frac{0.37 \times 1}{(6.67 \times 10^5)^{0.2}} = 0.0187 m = 18.7 mm$$

**例题8：阻力系数计算**

⭐ **解题思路：**
1. 计算雷诺数
2. 判断流动区域
3. 计算阻力系数
4. 计算阻力

*题目：* 平板长度$L = 2m$，宽度$b = 1m$，主流速度$u_\infty = 5m/s$，运动粘度$\nu = 1.0 \times 10^{-6} m^2/s$，求平板总阻力。

*解答：*
**雷诺数：**
$$Re_L = \frac{u_\infty L}{\nu} = \frac{5 \times 2}{1.0 \times 10^{-6}} = 10^7 > 3 \times 10^6$$

**流动状态：** 湍流边界层

**平均摩擦系数：**
$$C_f = \frac{0.455}{(\log Re_L)^{2.58}} = \frac{0.455}{(\log 10^7)^{2.58}} = \frac{0.455}{(7)^{2.58}} = 0.0026$$

**平板面积：**
$$A = L \times b = 2 \times 1 = 2 m^2$$

**总阻力：**
$$D = C_f \times \frac{1}{2}\rho u_\infty^2 \times A = 0.0026 \times \frac{1}{2} \times 1000 \times 5^2 \times 2 = 65 N$$

## 总结

### 重点公式汇总

⭐ **必考公式：**

1. **静压强：** $p = p_0 + \rho gh$
2. **帕斯卡定律：** $\frac{F_1}{A_1} = \frac{F_2}{A_2}$
3. **连续性方程：** $A_1 v_1 = A_2 v_2$
4. **伯努利方程：** $p + \frac{1}{2}\rho v^2 + \rho gz = 常数$
5. **雷诺数：** $Re = \frac{vD}{\nu}$
6. **达西公式：** $h_f = \lambda \frac{L}{D} \frac{v^2}{2g}$
7. **层流阻力系数：** $\lambda = \frac{64}{Re}$
8. **边界层厚度：** $\delta = \frac{5.0x}{\sqrt{Re_x}}$（层流）

### 解题要点

1. **仔细审题：** 明确已知量和求解量
