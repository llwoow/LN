## 1. 轴向拉伸和压缩

### 1.1 基本概念

⭐**轴向拉伸**：杆件受到沿轴线方向的外力作用，使杆件长度增加的现象。

⭐**轴向压缩**：杆件受到沿轴线方向的外力作用，使杆件长度减少的现象。

### 1.2 应力分析

⭐**正应力**（轴向应力）：
$$\sigma = \frac{F}{A}$$

其中：
- $F$：轴向力（N）
- $A$：横截面面积（mm²）
- $\sigma$：正应力（MPa）

⭐**平均正应力**：
$$\sigma_m = \frac{\sum F}{A}$$

⭐**最大正应力**（在危险点处）：
$$\sigma_{max} = \frac{F_{max}}{A}$$

### 1.3 应变分析

⭐**线应变**：
$$\varepsilon = \frac{\Delta L}{L_0}$$

其中：
- $\Delta L$：轴向变形量（mm）
- $L_0$：原始长度（mm）
- $\varepsilon$：线应变（无量纲）

⭐**横向应变**：
$$\varepsilon' = -\nu\varepsilon$$

其中 $\nu$ 为泊松比。

<details>
<summary><strong>虎克定律推导</strong></summary>

从材料试验可知，在弹性范围内，应力与应变成正比：

$$\sigma = E\varepsilon$$

其中 $E$ 为弹性模量（杨氏模量）。

对于轴向拉伸：
$$\varepsilon = \frac{\Delta L}{L_0}$$

因此：
$$\Delta L = \frac{FL_0}{EA}$$

这就是轴向拉伸的虎克定律。
</details>

### 1.4 虎克定律

⭐**虎克定律**：
$$\sigma = E\varepsilon$$

或写成：
$$\Delta L = \frac{FL_0}{EA}$$

其中：
- $E$：弹性模量（MPa）
- $EA$：拉压刚度

### 1.5 泊松比

⭐**泊松比**：
$$\nu = -\frac{\varepsilon'}{\varepsilon}$$

其中：
- $\varepsilon'$：横向应变
- $\varepsilon$：纵向应变

常见材料的泊松比：
- 钢材：$\nu = 0.25-0.33$
- 铸铁：$\nu = 0.23-0.27$
- 混凝土：$\nu = 0.16-0.18$

### 1.6 典型例题

**例题1**：钢杆长2m，横截面面积100mm²，受到50kN的轴向拉力作用。求：
(1) 正应力
(2) 线应变
(3) 伸长量
(4) 横向收缩量

已知：$E = 200GPa$，$\nu = 0.3$

**解：**
(1) 正应力：$\sigma = \frac{F}{A} = \frac{50 \times 10^3}{100} = 500$ MPa

(2) 线应变：$\varepsilon = \frac{\sigma}{E} = \frac{500 \times 10^6}{200 \times 10^9} = 0.0025$

(3) 伸长量：$\Delta L = \varepsilon L_0 = 0.0025 \times 2000 = 5$ mm

(4) 横向收缩量：$\varepsilon' = -\nu\varepsilon = -0.3 \times 0.0025 = -0.00075$

## 2. 剪切和挤压

### 2.1 剪切

⭐**剪应力**：
$$\tau = \frac{F_s}{A}$$

其中：
- $F_s$：剪切力（N）
- $A$：剪切面面积（mm²）
- $\tau$：剪应力（MPa）

⭐**剪切虎克定律**：
$$\tau = G\gamma$$

其中：
- $G$：剪切模量（GPa）
- $\gamma$：剪应变（弧度）

### 2.2 挤压

⭐**挤压应力**：
$$\sigma_{bs} = \frac{F_{bs}}{A_{bs}}$$

其中：
- $F_{bs}$：挤压力（N）
- $A_{bs}$：挤压面积（mm²）

⭐**挤压面积计算**：
- 圆柱面接触：$A_{bs} = d \times h$
- 平面接触：$A_{bs} = \frac{\pi}{4}(D^2 - d^2)$

其中：
- $d$：孔径
- $h$：接触高度
- $D$：外径

### 2.3 剪切变形

⭐**剪切变形**：
$$\gamma = \frac{\tau}{G} = \frac{F_s}{AG}$$

### 2.4 典型例题

**例题2**：铆钉连接两块钢板，铆钉直径20mm，承受剪切力80kN。求剪应力和剪切变形。

已知：$G = 80GPa$

**解：**
(1) 剪切面积：$A = \frac{\pi d^2}{4} = \frac{\pi \times 20^2}{4} = 314.16$ mm²

(2) 剪应力：$\tau = \frac{F_s}{A} = \frac{80 \times 10^3}{314.16} = 254.6$ MPa

(3) 剪切变形：$\gamma = \frac{\tau}{G} = \frac{254.6 \times 10^6}{80 \times 10^9} = 0.00318$

## 3. 扭转

### 3.1 基本概念

⭐**扭矩**：使构件产生扭转变形的外力偶矩。

⭐**扭转变形**：构件在扭矩作用下，其横截面绕轴线发生相对转动的变形。

### 3.2 扭转应力

⭐**扭转剪应力**：
$$\tau = \frac{T}{W_p}$$

其中：
- $T$：扭矩（N·mm）
- $W_p$：极惯性矩（mm³）

⭐**圆形截面极惯性矩**：
$$W_p = \frac{\pi d^3}{16} = \frac{\pi D^3}{32}$$

其中：
- $d$：内径
- $D$：外径

⭐**空心圆截面**：
$$W_p = \frac{\pi D^3}{32}(1 - \alpha^4)$$

其中 $\alpha = \frac{d}{D}$

### 3.3 扭转角

⭐**扭转角**：
$$\phi = \frac{TL}{GJ}$$

其中：
- $L$：杆长
- $G$：剪切模量
- $J$：极惯性矩（$J = \frac{\pi d^4}{32}$）

⭐**单位长度扭转角**：
$$\theta = \frac{\phi}{L} = \frac{T}{GJ}$$

### 3.4 扭转刚度

⭐**扭转刚度**：
$$k = \frac{GJ}{L}$$

<details>
<summary><strong>扭转剪应力分布推导</strong></summary>

对于圆轴扭转，剪应力沿半径线性分布：

$$\tau = \frac{Tr}{J}$$

在表面处（$r = \frac{d}{2}$）：
$$\tau_{max} = \frac{T \cdot \frac{d}{2}}{J} = \frac{T}{W_p}$$

其中 $W_p = \frac{2J}{d} = \frac{\pi d^3}{16}$
</details>

### 3.5 典型例题

**例题3**：钢制圆轴，直径50mm，长1m，承受扭矩2kN·m。求：
(1) 最大剪应力
(2) 扭转角
(3) 单位长度扭转角

已知：$G = 80GPa$

**解：**
(1) 极惯性矩：$J = \frac{\pi d^4}{32} = \frac{\pi \times 50^4}{32} = 612,341$ mm⁴

(2) 最大剪应力：$\tau_{max} = \frac{T}{W_p} = \frac{2 \times 10^6}{\frac{\pi \times 50^3}{16}} = 40.7$ MPa

(3) 扭转角：$\phi = \frac{TL}{GJ} = \frac{2 \times 10^6 \times 1000}{80 \times 10^3 \times 612,341} = 0.0407$ rad = 2.33°

(4) 单位长度扭转角：$\theta = \frac{\phi}{L} = 4.07 \times 10^{-5}$ rad/mm

## 4. 弯曲

### 4.1 基本概念

⭐**梁**：主要承受弯曲载荷的构件。

⭐**纯弯曲**：梁的横截面上只有弯矩，没有剪力的弯曲。

⭐**横力弯曲**：梁的横截面上既有弯矩又有剪力的弯曲。

### 4.2 弯曲正应力

⭐**弯曲正应力**：
$$\sigma = \frac{My}{I_z}$$

其中：
- $M$：弯矩（N·mm）
- $y$：到中性轴的距离（mm）
- $I_z$：惯性矩（mm⁴）

⭐**最大弯曲正应力**：
$$\sigma_{max} = \frac{M}{W_z}$$

其中 $W_z = \frac{I_z}{y_{max}}$ 为弯曲截面系数。

⭐**矩形截面**：
$$I_z = \frac{bh^3}{12}, \quad W_z = \frac{bh^2}{6}$$

⭐**圆形截面**：
$$I_z = \frac{\pi d^4}{64}, \quad W_z = \frac{\pi d^3}{32}$$

### 4.3 弯曲剪应力

⭐**弯曲剪应力**（矩形截面）：
$$\tau = \frac{F_sS_z^*}{bI_z}$$

其中：
- $F_s$：剪力（N）
- $S_z^*$：静矩（mm³）
- $b$：截面宽度（mm）

⭐**矩形截面最大剪应力**：
$$\tau_{max} = \frac{3F_s}{2A}$$

其中 $A = bh$ 为截面面积。

### 4.4 梁的变形

⭐**挠度微分方程**：
$$EI\frac{d^4y}{dx^4} = q(x)$$

⭐**转角方程**：
$$\theta = \frac{dy}{dx} = \frac{1}{EI}\int M(x)dx$$

⭐**挠度方程**：
$$y = \frac{1}{EI}\int\int M(x)dx^2$$

<details>
<summary><strong>弯曲正应力公式推导</strong></summary>

基于平面假设和虎克定律：

1. 平面假设：变形前为平面的横截面，变形后仍为平面
2. 虎克定律：$\sigma = E\varepsilon$
3. 几何关系：$\varepsilon = \frac{y}{\rho}$
4. 静力平衡：$\int\sigma dA = M$

最终得到：$\sigma = \frac{My}{I}$
</details>

### 4.5 典型例题

**例题4**：简支梁，长度3m，承受均布载荷10kN/m。梁为矩形截面200×300mm。求：
(1) 最大弯矩
(2) 最大正应力
(3) 最大剪应力

**解：**
(1) 最大弯矩：$M_{max} = \frac{qL^2}{8} = \frac{10 \times 3^2}{8} = 11.25$ kN·m

(2) 惯性矩：$I_z = \frac{bh^3}{12} = \frac{200 \times 300^3}{12} = 450 \times 10^6$ mm⁴

(3) 最大正应力：$\sigma_{max} = \frac{M_{max}y_{max}}{I_z} = \frac{11.25 \times 10^6 \times 150}{450 \times 10^6} = 3.75$ MPa

(4) 最大剪应力：$\tau_{max} = \frac{3F_s}{2A} = \frac{3 \times 15 \times 10^3}{2 \times 200 \times 300} = 0.375$ MPa

## 5. 组合变形

### 5.1 拉弯组合

⭐**组合应力**：
$$\sigma = \sigma_N + \sigma_M = \frac{N}{A} \pm \frac{My}{I_z}$$

⭐**危险点位置**：最大拉应力和最大压应力分别出现在截面的两侧。

### 5.2 弯扭组合

⭐**弯扭组合强度理论**：

**最大剪应力理论**：
$$\sigma_{r3} = \sqrt{\sigma^2 + 4\tau^2}$$

**最大正应力理论**：
$$\sigma_{r4} = \frac{1}{2}\left[\sigma + \sqrt{\sigma^2 + 4\tau^2}\right]$$

⭐**第三强度理论（用于塑性材料）**：
$$\sigma_{r3} = \sqrt{\sigma^2 + 4\tau^2} \leq [\sigma]$$

⭐**第四强度理论（用于塑性材料）**：
$$\sigma_{r4} = \sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]$$

### 5.3 复合应力状态

⭐**平面应力状态**：
$$\sigma_{1,2} = \frac{\sigma_x + \sigma_y}{2} \pm \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}$$

⭐**最大剪应力**：
$$\tau_{max} = \sqrt{\left(\frac{\sigma_x - \sigma_y}{2}\right)^2 + \tau_{xy}^2}$$

### 5.4 典型例题

**例题5**：圆形截面杆件，同时承受轴向拉力50kN和扭矩1kN·m。直径100mm。求危险点的相当应力。

**解：**
(1) 轴向正应力：$\sigma = \frac{N}{A} = \frac{50 \times 10^3}{\frac{\pi \times 100^2}{4}} = 6.37$ MPa

(2) 扭转剪应力：$\tau = \frac{T}{W_p} = \frac{1 \times 10^6}{\frac{\pi \times 100^3}{16}} = 5.09$ MPa

(3) 第三强度理论：$\sigma_{r3} = \sqrt{\sigma^2 + 4\tau^2} = \sqrt{6.37^2 + 4 \times 5.09^2} = 11.8$ MPa

(4) 第四强度理论：$\sigma_{r4} = \sqrt{\sigma^2 + 3\tau^2} = \sqrt{6.37^2 + 3 \times 5.09^2} = 10.9$ MPa

## 6. 压杆稳定

### 6.1 基本概念

⭐**压杆稳定**：细长压杆在轴向压力作用下，突然发生侧向弯曲而丧失承载能力的现象。

⭐**临界载荷**：压杆保持直线平衡状态的最大载荷。

### 6.2 欧拉公式

⭐**欧拉公式**：
$$P_{cr} = \frac{\pi^2EI}{(μL)^2}$$

其中：
- $E$：弹性模量
- $I$：最小惯性矩
- $μ$：长度系数
- $L$：压杆长度

⭐**长度系数**：
- 两端铰支：$μ = 1$
- 一端固定一端自由：$μ = 2$
- 两端固定：$μ = 0.5$
- 一端固定一端铰支：$μ = 0.7$

### 6.3 临界应力

⭐**临界应力**：
$$\sigma_{cr} = \frac{P_{cr}}{A} = \frac{\pi^2E}{(μL/r)^2}$$

其中 $r = \sqrt{\frac{I}{A}}$ 为惯性半径。

⭐**柔度**（长细比）：
$$\lambda = \frac{μL}{r}$$

### 6.4 稳定系数

⭐**稳定系数**：
$$\phi = \frac{\sigma_{cr}}{\sigma_s} = \frac{P_{cr}}{P_s}$$

其中 $P_s = A\sigma_s$ 为强度极限载荷。

⭐**经验公式**（直线公式）：
$$\sigma_{cr} = a - b\lambda$$

其中 $a$、$b$ 为与材料有关的常数。

### 6.5 典型例题

**例题6**：钢制压杆，长度2m，两端铰支，矩形截面100×50mm。求临界载荷和临界应力。

已知：$E = 200GPa$

**解：**
(1) 最小惯性矩：$I_{min} = \frac{50 \times 100^3}{12} = 4.17 \times 10^6$ mm⁴

(2) 惯性半径：$r = \sqrt{\frac{I_{min}}{A}} = \sqrt{\frac{4.17 \times 10^6}{5000}} = 28.9$ mm

(3) 柔度：$\lambda = \frac{μL}{r} = \frac{1 \times 2000}{28.9} = 69.2$

(4) 临界载荷：$P_{cr} = \frac{\pi^2EI}{(μL)^2} = \frac{\pi^2 \times 200 \times 10^3 \times 4.17 \times 10^6}{2000^2} = 206$ kN

(5) 临界应力：$\sigma_{cr} = \frac{P_{cr}}{A} = \frac{206 \times 10^3}{5000} = 41.2$ MPa

## 7. 冲击载荷

### 7.1 基本概念

⭐**冲击载荷**：在极短时间内突然施加在构件上的载荷。

⭐**冲击应力**：冲击载荷作用下构件内产生的应力。

### 7.2 冲击应力计算

⭐**自由落体冲击**：
$$\sigma_d = \sigma_{st} \sqrt{\frac{v^2}{g\delta_{st}}}$$

其中：
- $\sigma_{st}$：静载应力
- $v$：冲击速度
- $g$：重力加速度
- $\delta_{st}$：静载变形

⭐**冲击系数**：
$$K_d = \frac{\sigma_d}{\sigma_{st}} = \sqrt{1 + \frac{2h}{\delta_{st}}}$$

其中 $h$ 为落体高度。

### 7.3 能量法

⭐**机械能守恒**：
$$\frac{1}{2}mv^2 = U_d$$

其中 $U_d$ 为构件的变形能。

⭐**变形能**：
$$U_d = \frac{1}{2}P_d\delta_d$$

### 7.4 典型例题

**例题7**：钢杆长1m，截面面积1000mm²，一端固定，另一端受重量1kN的物体从高度0.5m处自由落下冲击。求最大冲击应力和动荷系数。

已知：$E = 200GPa$

**解：**
(1) 静载应力：$\sigma_{st} = \frac{P}{A} = \frac{1000}{1000} = 1$ MPa

(2) 静载变形：$\delta_{st} = \frac{PL}{EA} = \frac{1000 \times 1000}{200 \times 10^3 \times 1000} = 0.005$ mm

(3) 冲击系数：$K_d = \sqrt{1 + \frac{2h}{\delta_{st}}} = \sqrt{1 + \frac{2 \times 500}{0.005}} = 447.2$

(4) 最大冲击应力：$\sigma_d = K_d\sigma_{st} = 447.2 \times 1 = 447.2$ MPa

## 8. 疲劳强度和疲劳分析

### 8.1 基本概念

⭐**疲劳破坏**：材料在循环载荷作用下发生的破坏现象。

⭐**循环载荷**：大小和方向随时间周期性变化的载荷。

⭐**疲劳寿命**：构件在循环载荷作用下达到破坏时的循环次数。

### 8.2 S-N曲线

⭐**S-N曲线**：应力幅值与疲劳寿命之间的关系曲线。

$$\sigma_a^N = \sigma_f'$$

其中：
- $\sigma_a$：应力幅值
- $N$：循环次数
- $\sigma_f'$：疲劳强度系数

⭐**疲劳极限**：当循环次数趋向无穷大时，材料能够承受的最大应力幅值。

### 8.3 疲劳强度计算

⭐**疲劳强度条件**：
$$\sigma_a \leq \frac{\sigma_{-1}}{K_fS}$$

其中：
- $\sigma_{-1}$：对称循环疲劳极限
- $K_f$：疲劳缺口系数
- $S$：安全系数

⭐**平均应力修正**：
$$\sigma_a' = \sigma_a \frac{\sigma_{-1}}{\sigma_{-1} - \psi\sigma_m}$$

其中：
- $\sigma_m$：平均应力
- $\psi$：敏感系数

### 8.4 影响疲劳强度的因素

⭐**应力集中**：$K_t = \frac{\sigma_{max}}{\sigma_{nom}}$

⭐**表面质量系数**：
$$\beta = \beta_1\beta_2\beta_3$$

其中：
- $\beta_1$：表面加工系数
- $\beta_2$：表面强化系数
- $\beta_3$：尺寸系数

### 8.5 典型例题

**例题8**：钢制构件，对称循环疲劳极限250MPa，应力集中系数1.8，表面质量系数0.85，安全系数1.5。求允许的最大应力幅值。

**解：**
(1) 疲劳缺口系数：$K_f = 1 + q(K_t - 1) = 1 + 0.7(1.8 - 1) = 1.56$

(2) 允许应力幅值：$\sigma_a \leq \frac{\sigma_{-1}}{K_fS} = \frac{250}{1.56 \times 1.5} = 106.8$ MPa

(3) 考虑表面质量：$\sigma_a \leq \beta \times 106.8 = 0.85 \times 106.8 = 90.8$ MPa

## 9. 断裂力学基础

### 9.1 基本概念

⭐**断裂力学**：研究含裂纹构件强度和裂纹扩展规律的学科。

⭐**应力强度因子**：描述裂纹尖端应力场强度的参数。

### 9.2 应力强度因子

⭐**应力强度因子**：
$$K = Y\sigma\sqrt{\pi a}$$

其中：
- $Y$：几何形状因子
- $\sigma$：远场应力
- $a$：裂纹长度的一半

⭐**临界应力强度因子**（断裂韧性）：
$$K_{IC} = Y\sigma_c\sqrt{\pi a}$$

### 9.3 裂纹扩展

⭐**Paris定律**：
$$\frac{da}{dN} = C(\Delta K)^m$$

其中：
- $a$：裂纹长度
- $N$：循环次数
- $\Delta K$：应力强度因子幅值
- $C$、$m$：材料常数

### 9.4 断裂判据

⭐**线弹性断裂判据**：
$$K \leq K_{IC}$$

⭐**弹塑性断裂判据**（J积分）：
$$J \leq J_{IC}$$

### 9.5 典型例题

**例题9**：含中心裂纹的无限大板，裂纹长度20mm，断裂韧性50MPa·√m。求临界应力。

**解：**
(1) 裂纹半长：$a = 10$ mm = 0.01 m

(2) 几何形状因子：$Y = 1.0$（中心裂纹）

(3) 临界应力：$\sigma_c = \frac{K_{IC}}{Y\sqrt{\pi a}} = \frac{50}{1.0 \times \sqrt{\pi \times 0.01}} = 894$ MPa

## 10. 实验应力分析

### 10.1 基本概念

⭐**实验应力分析**：通过实验方法测定构件内应力和变形的学科。

### 10.2 电阻应变片

⭐**应变片工作原理**：基于电阻丝的几何尺寸变化引起电阻值变化的原理。

⭐**应变片灵敏系数**：
$$K = \frac{\Delta R/R}{\varepsilon}$$

其中：
- $\Delta R$：电阻变化量
- $R$：原始电阻
- $\varepsilon$：应变

### 10.3 惠斯通电桥

⭐**单臂电桥**：
$$\Delta U = \frac{K\varepsilon U_0}{4}$$

⭐**半桥**：
$$\Delta U = \frac{K\varepsilon U_0}{2}$$

⭐**全桥**：
$$\Delta U = K\varepsilon U_0$$

### 10.4 典型应变测量

⭐**单向应力状态**：
$$\sigma = E\varepsilon$$

⭐**平面应力状态**：
$$\varepsilon_x = \frac{1}{E}(\sigma_x - \nu\sigma_y)$$
$$\varepsilon_y = \frac{1}{E}(\sigma_y - \nu\sigma_x)$$

⭐**主应力计算**：
$$\sigma_{1,2} = \frac{E}{2}\left[\frac{\varepsilon_x + \varepsilon_y}{1-\nu} \pm \frac{\sqrt{2}}{1+\nu}\sqrt{(\varepsilon_x - \varepsilon_y)^2 + \gamma_{xy}^2}\right]$$

### 10.5 其他实验方法

⭐**光弹性法**：基于材料的双折射现象。

⭐**云纹法**：基于几何遮光原理。

⭐**脆性涂层法**：基于涂层开裂模式。

### 10.6 典型例题

**例题10**：45°应变花测得：$\varepsilon_0 = 200\mu\varepsilon$，$\varepsilon_{45} = 150\mu\varepsilon$，$\varepsilon_{90} = 100\mu\varepsilon$。求主应力和主方向。

已知：$E = 200GPa$，$\nu = 0.3$

**解：**
(1) 计算剪应变：$\gamma_{xy} = 2\varepsilon_{45} - \varepsilon_0 - \varepsilon_{90} = 2 \times 150 - 200 - 100 = 0$

(2) 主应变：$\varepsilon_{1,2} = \frac{\varepsilon_0 + \varepsilon_{90}}{2} \pm \frac{\sqrt{2}}{2}\sqrt{(\varepsilon_0 - \varepsilon_{90})^2 + \gamma_{xy}^2}$

$$\varepsilon_1 = \frac{200 + 100}{2} + \frac{\sqrt{2}}{2}\sqrt{(200-100)^2 + 0} = 207.1\mu\varepsilon$$

$$\varepsilon_2 = \frac{200 + 100}{2} - \frac{\sqrt{2}}{2}\sqrt{(200-100)^2 + 0} = 92.9\mu\varepsilon$$

(3) 主应力：$\sigma_1 = \frac{E}{1-\nu^2}(\varepsilon_1 + \nu\varepsilon_2) = \frac{200 \times 10^3}{1-0.3^2}(207.1 + 0.3 \times 92.9) = 49.4$ MPa

$$\sigma_2 = \frac{E}{1-\nu^2}(\varepsilon_2 + \nu\varepsilon_1) = \frac{200 \times 10^3}{1-0.3^2}(92.9 + 0.3 \times 207.1) = 30.6$$ MPa

## 总结

材料力学是工程设计的重要基础，主要研究构件在载荷作用下的强度、刚度和稳定性问题。通过对应力、应变、位移的分析，可以：

1. **强度计算**：确保构件在载荷作用下不发生破坏
2. **刚度计算**：控制构件的变形在允许范围内
3. **稳定性分析**：防止细长构件失稳
4. **疲劳分析**：考虑循环载荷的影响
5. **实验验证**：通过实验方法验证理论计算结果

⭐**重点掌握内容**：
- 各种基本变形的应力应变计算
- 组合变形的分析方法
- 强度理论的应用
- 疲劳强度的评估方法
- 实验应力分析技术

这些知识为机械设计、结构设计等工程实践提供了重要的理论基础。
