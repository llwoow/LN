## 1. 点的运动描述

### 1.1 直线运动

#### 1.1.1 基本概念 ⭐

**运动方程**：$s = f(t)$

**速度**：
$$v = \frac{ds}{dt} = f'(t)$$

**加速度**：
$$a = \frac{dv}{dt} = \frac{d^2s}{dt^2} = f''(t)$$

#### 1.1.2 匀变速直线运动 ⭐

**基本公式**：
- 速度公式：$v = v_0 + at$
- 位移公式：$s = v_0t + \frac{1}{2}at^2$
- 速度-位移关系：$v^2 = v_0^2 + 2as$
