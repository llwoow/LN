## 考试重点清单

### ⭐⭐⭐ 必考核心内容（占分60-70%）

#### 静力学基础
- **力的合成与分解**
  - 平行四边形法则：$F_R = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$
  - 正交分解法：$F_x = F\cos\theta$，$F_y = F\sin\theta$
  - 多边形法则应用

- **平面力系平衡**
  - 基本方程：$\sum F_x = 0$，$\sum F_y = 0$，$\sum M_O = 0$
  - 二力矩形式和三力矩形式的应用条件
  - 约束反力确定（柔索、光滑接触、铰链、固定端）

- **摩擦问题**
  - 静摩擦定律：$0 \leq f_s \leq \mu_s N$
  - 自锁条件：$\alpha \leq \varphi = \arctan\mu_s$
  - 临界状态法解题

#### 动力学基础
- **牛顿三定律应用**
  - 第二定律：$\vec{F} = m\vec{a}$
  - 运动微分方程建立
  - 质点系动量定理：$\frac{d\vec{P}}{dt} = \vec{F}^{(e)}$

- **动能定理**
  - 质点动能定理：$T_2 - T_1 = W_{12}$
  - 机械能守恒：$T + V = 常数$
  - 功率计算：$P = \vec{F} \cdot \vec{v}$

- **振动基础**
  - 无阻尼自由振动：$x = A\cos(\omega_n t + \phi)$
  - 固有频率：$\omega_n = \sqrt{\frac{k}{m}}$
  - 共振条件

#### 材料力学核心
- **基本变形**
  - 轴向拉压：$\sigma = \frac{F}{A}$，$\Delta L = \frac{FL_0}{EA}$
  - 扭转：$\tau = \frac{T}{W_p}$，$\phi = \frac{TL}{GJ}$
  - 弯曲：$\sigma = \frac{My}{I_z}$，$\tau = \frac{3F_s}{2A}$（矩形截面）

- **组合变形**
  - 拉弯组合：$\sigma = \frac{N}{A} \pm \frac{My}{I_z}$
  - 弯扭组合强度理论
    - 第三强度理论：$\sigma_{r3} = \sqrt{\sigma^2 + 4\tau^2}$
    - 第四强度理论：$\sigma_{r4} = \sqrt{\sigma^2 + 3\tau^2}$

- **压杆稳定**
  - 欧拉公式：$P_{cr} = \frac{\pi^2EI}{(\mu L)^2}$
  - 柔度计算：$\lambda = \frac{\mu L}{r}$

#### 流体力学基础
- **流体静力学**
  - 静压强公式：$p = p_0 + \rho gh$
  - 帕斯卡定律：$\frac{F_1}{A_1} = \frac{F_2}{A_2}$

- **流体动力学**
  - 连续性方程：$A_1v_1 = A_2v_2$
  - 伯努利方程：$p + \frac{1}{2}\rho v^2 + \rho gz = 常数$
  - 雷诺数：$Re = \frac{vD}{\nu}$

### ⭐⭐ 重要内容（占分20-25%）

#### 结构力学
- **静定结构分析**
  - 截面法、节点法、截面法
  - 内力图绘制（弯矩图、剪力图）
  - 零力杆判断

- **超静定结构**
  - 力法基本思想：$\delta_{11}X_1 + \Delta_{1P} = 0$
  - 位移法基本方程：$[K]\{\Delta\} = \{P\}$
  - 对称性利用

- **能量法**
  - 虚功原理：$\delta W_e = \delta W_i$
  - 卡氏定理：$\Delta_i = \frac{\partial U}{\partial P_i}$
  - 莫尔积分：$\Delta = \int \frac{M\bar{M}}{EI}dx$

#### 运动学
- **点的运动**
  - 直线运动：$v = \frac{ds}{dt}$，$a = \frac{dv}{dt}$
  - 曲线运动：自然坐标系分解

- **刚体运动**
  - 平面运动：速度合成、加速度合成
  - 转动方程：$\alpha = \frac{d\omega}{dt}$

### ⭐ 扩展内容（占分10-15%）

### 知识关联说明

#### 1. 静力学是所有章节的基础
- **与动力学的联系**：静力学平衡是动力学特殊形式（加速度为零）
- **与材料力学的联系**：内力计算基于平衡条件
- **与结构力学的联系**：结构分析的基本方法

#### 2. 运动学与动力学的递进关系
- **运动学**：只研究运动几何性质，不涉及力
- **动力学**：研究运动与力的关系
- **振动分析**：动力学在特殊系统中的应用

#### 3. 材料力学与结构力学的层次关系
- **材料力学**：研究单个构件的强度、刚度、稳定性
- **结构力学**：研究构件组成的结构体系的整体性能
- **递进关系**：构件 → 结构体系

#### 4. 流体力学的独立性
- 有自己的基本定律（帕斯卡、伯努利等）
- 与固体力学在边界处有耦合
- 工程应用广泛

## 常用解题方法和技巧

### 1. 静力学解题步骤

#### 标准解题流程
```
1. 明确研究对象
   ↓
2. 画受力图（关键步骤！）
   ↓
3. 建立坐标系
   ↓
4. 列平衡方程
   ↓
5. 求解未知量
   ↓
6. 校核结果
```

#### 受力图绘制技巧
- **主动力**：已知力（重力、载荷等）
- **约束反力**：根据约束类型判断
  - 柔索：沿柔索方向，背离物体
  - 光滑接触：沿法线方向，指向物体
  - 铰链：通过铰链中心，方向待定
  - 固定端：两个正交分力 + 一个力偶

#### 平衡方程选择策略
- **平面汇交力系**：两个方程（∑Fx=0, ∑Fy=0）
- **平面一般力系**：三个方程
  - 基本形式：∑Fx=0, ∑Fy=0, ∑MO=0
  - 二力矩形式：∑Fx=0, ∑MA=0, ∑MB=0
  - 三力矩形式：∑MA=0, ∑MB=0, ∑MC=0

### 2. 动力学解题方法

#### 牛顿第二定律法
**适用条件**：已知力求运动
```
1. 分析受力
2. 建立坐标系
3. 列方程：F = ma
4. 求解运动方程
```

#### 动能定理法
**适用条件**：已知力求位移/速度
```
1. 分析始末状态
2. 计算动能变化
3. 计算功：W = ∫F·ds
4. 应用：T2 - T1 = W12
```

#### 动量定理法
**适用条件**：碰撞、冲击问题
```
1. 分析系统
2. 考虑内力外力
3. 应用：∑Fext = dP/dt
4. 或用冲量-动量定理
```

### 3. 材料力学解题技巧

#### 强度计算步骤
```
1. 外力分析 → 内力计算
2. 内力分析 → 应力计算
3. 应力分析 → 强度校核
4. 变形分析 → 刚度校核
```

#### 组合变形分析方法
1. **分解法**：将组合变形分解为基本变形
2. **分别计算**：每种基本变形产生的应力
3. **叠加原理**：应力叠加（注意方向）
4. **强度理论**：选择合适的强度理论

#### 压杆稳定分析
1. **判定类型**：长细比判断
2. **计算临界载荷**：欧拉公式或经验公式
3. **稳定校核**：σ ≤ [σ]st

### 4. 结构力学分析方法

#### 静定结构分析
- **梁**：截面法求内力，绘制内力图
- **桁架**：节点法/截面法求杆件内力
- **刚架**：分段分析，注意刚节点特性

#### 超静定结构分析
**力法步骤**：
```
1. 确定超静定次数
2. 选取基本结构
3. 建立力法方程
4. 计算系数和自由项
5. 求解多余约束力
6. 绘制内力图
```

**位移法步骤**：
```
1. 确定基本未知量
2. 建立位移法方程
3. 计算刚度系数
4. 求解节点位移
5. 计算杆件内力
```

#### 能量法应用
- **虚功原理**：求位移/内力
- **卡氏定理**：求指定位置位移
- **莫尔积分**：结构位移计算

### 5. 流体力学解题策略

#### 流体静力学问题
```
1. 确定参考平面
2. 计算各点深度
3. 应用静压强公式
4. 注意绝对压强与相对压强
```

#### 流体动力学问题
```
1. 选取控制体
2. 应用连续性方程（质量守恒）
3. 应用伯努利方程（能量守恒）
4. 考虑能量损失
```

#### 管路流动问题
```
1. 判断流动状态（Re数）
2. 选择阻力系数公式
3. 计算沿程损失和局部损失
4. 总水头损失计算
```

## 常见错误和注意事项

### 1. 静力学常见错误

#### 受力图错误
❌ **错误**：漏画约束反力
✅ **正确**：根据约束类型完整画出所有约束反力

❌ **错误**：约束反力方向判断错误
✅ **正确**：根据约束特性和主动力方向综合判断

#### 平衡方程错误
❌ **错误**：方程数量不足
✅ **正确**：独立方程数等于未知量数

❌ **错误**：力矩符号判断错误
✅ **正确**：统一采用逆时针为正（或顺时针为正）

### 2. 动力学常见错误

#### 坐标系选择
❌ **错误**：坐标系选择不当导致计算复杂
✅ **正确**：选择与主要运动方向一致的坐标系

#### 定理应用错误
❌ **错误**：动能定理中忽略某些力的功
✅ **正确**：计算所有力的功，包括重力、弹力等

❌ **错误**：动量定理中内力外力混淆
✅ **正确**：动量定理只考虑外力，内力相互抵消

### 3. 材料力学常见错误

#### 应力计算错误
❌ **错误**：组合变形中应力直接相加
✅ **正确**：考虑应力方向，区分拉压应力

❌ **错误**：截面几何性质计算错误
✅ **正确**：熟练掌握常用截面几何性质计算

#### 强度理论应用
❌ **错误**：材料性质与强度理论不匹配
✅ **正确**：脆性材料用第一、二强度理论，塑性材料用第三、四强度理论

### 4. 结构力学常见错误

#### 超静定次数判断
❌ **错误**：超静定次数计算错误
✅ **正确**：n = r - m（约束反力数 - 独立平衡方程数）

#### 基本结构选择
❌ **错误**：基本结构选择不当
✅ **正确**：选择静定且稳定的基本结构

### 5. 流体力学常见错误

#### 压强概念混淆
❌ **错误**：绝对压强与相对压强混淆
✅ **正确**：明确题目要求的是什么压强

#### 伯努利方程应用
❌ **错误**：忽略能量损失
✅ **正确**：实际流体要考虑水头损失

❌ **错误**：基准面选择不当
✅ **正确**：选择合适的基准面简化计算

### 6. 通用注意事项

#### 单位统一
- 长度：m, mm
- 力：N, kN
- 应力：Pa, MPa
- 密度：kg/m³
- 粘度：Pa·s, m²/s

#### 符号规定
- 力的符号：拉为正，压为负
- 弯矩符号：上凸为正
- 剪力符号：顺时针为正
- 角度符号：逆时针为正

#### 近似处理
- 小变形假设
- 材料线弹性假设
- 平面假设（梁理论）
- 不可压缩假设（流体力学）

```
A ----●---------●---- B
      |         |
     10kN     15kN
```
已知：AB = 6m，AC = 2m，CB = 4m

**解题要点**：
1. 画受力图
2. 列平衡方程
3. 求解并校核

**评分标准**：
- 受力图正确（3分）
- 平衡方程正确（4分）
- 计算正确（3分）

#### 题型2：动力学综合题
**例题**：质量m的小球从高度h处自由下落，求落地时的速度

**解题要点**：
1. 机械能守恒法
2. 运动学方法验证

**评分标准**：
- 方法选择正确（2分）
- 计算过程正确（5分）
- 结果正确（3分）

#### 题型3：材料力学强度计算
**例题**：拉弯组合构件的强度校核

**解题要点**：
1. 内力分析

3. 强度理论应用

**评分标准**：
- 内力分析正确（3分）
- 应力计算正确（4分）
- 强度校核正确（3分）

#### 题型4：结构力学分析
**例题**：静定桁架内力计算

**解题要点**：
1. 零力杆判断
2. 选择合适方法（节点法/截面法）

**评分标准**：
- 方法选择正确（2分）
- 计算过程正确（6分）
- 结果正确（2分）

#### 题型5：流体力学计算
