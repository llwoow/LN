## 1. 力的基本概念和性质

### 1.1 力的定义
**力**是物体间的相互作用，使物体的运动状态发生改变或使物体发生变形。

### 1.2 力的三要素 ⭐
1. **大小**：力的大小表示力的强弱程度
2. **方向**：力的方向包括作用线方向和指向
3. **作用点**：力在物体上的作用位置

**注意**：三要素中任何一个改变，力的作用效果都会改变。

### 1.3 力的表示方法
1. **图示法**：用带箭头的线段表示力
   - 箭头表示力的方向
   - 线段长度按比例表示力的大小
   - 箭头起点表示力的作用点

2. **符号法**：用字母表示力
   - 一般用 $\vec{F}$ 或 $\overrightarrow{F}$ 表示
   - 大小用 $F = |\vec{F}|$ 表示

### 1.4 力的单位
- **国际单位制（SI）**：牛顿（N）
- **工程单位制**：千克力（kgf）
- **换算关系**：$1 \text{kgf} = 9.8 \text{N}$

### 1.5 力的基本性质
1. **力的可传递性**：作用于刚体上的力，可以沿其作用线移动到刚体上的任意一点，而不改变力对刚体的作用效应。
2. **力的独立性原理**：几个力同时作用于同一物体上所产生的运动效果等于每一个力单独作用时所产生的运动效果的叠加。

## 2. 力的合成与分解

### 2.1 力的合成

#### 2.1.1 平行四边形法则 ⭐
两个力可以合成为一个合力，合力的大小和方向由以这两个力为邻边所构成的平行四边形的对角线确定。

**数学表达式**：
$$\vec{F_R} = \vec{F_1} + \vec{F_2}$$

**合力的大小**：
$$F_R = \sqrt{F_1^2 + F_2^2 + 2F_1F_2\cos\theta}$$

其中 $\theta$ 为两力之间的夹角。

<details>
<parameter name="summary">平行四边形法则推导
#### 2.1.2 三角形法则 ⭐
将两个力首尾相接，合力为从第一个力的起点到第二个力的终点的连线。

#### 2.1.3 多边形法则 ⭐
多个力的合成可以连续使用三角形法则，最终合力为从第一个力的起点到最后一个力的终点的连线。

**多边形法则的数学表达式**：
$$\vec{F_R} = \vec{F_1} + \vec{F_2} + \vec{F_3} + ... + \vec{F_n}$$

### 2.2 力的分解

#### 2.2.1 正交分解法 ⭐
将一个力分解为两个互相垂直的分力。

**分解公式**：
$$F_x = F\cos\theta$$
$$F_y = F\sin\theta$$

其中 $\theta$ 为力与x轴的夹角。

#### 2.2.2 斜分解法
将一个力分解为任意两个方向的分力。

**分解公式**：
$$\frac{F_1}{\sin\alpha} = \frac{F_2}{\sin\beta} = \frac{F}{\sin\gamma}$$

其中 $\alpha$、$\beta$、$\gamma$ 为三角形各角。

<details>
<summary>力的正交分解推导过程</summary>

设力 $\vec{F}$ 与x轴夹角为 $\theta$，则在x轴和y轴上的投影分别为：

$$F_x = F\cos\theta$$
$$F_y = F\sin\theta$$

根据勾股定理：
$$F = \sqrt{F_x^2 + F_y^2}$$

这说明正交分解保持了力的完整性。
</details>

### 2.3 典型例题

**例题1**：已知两个力 $F_1 = 30\text{N}$，$F_2 = 40\text{N}$，夹角 $\theta = 90^\circ$，求合力。

**解题思路**：
1. 使用平行四边形法则
2. 由于 $\theta = 90^\circ$，$\cos\theta = 0$
3. 合力大小：$F_R = \sqrt{30^2 + 40^2} = 50\text{N}$
4. 合力方向：$\tan\alpha = \frac{40}{30} = \frac{4}{3}$，所以 $\alpha = 53.13^\circ$

## 3. 力的平衡条件

### 3.1 平面汇交力系平衡 ⭐

#### 3.1.1 平衡条件
平面汇交力系平衡的充要条件是：合力为零。

**数学表达式**：
$$\vec{F_R} = \sum_{i=1}^{n} \vec{F_i} = 0$$

#### 3.1.2 平衡方程
**解析法**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$

**几何法**：力多边形自行封闭。

### 3.2 平面一般力系平衡

#### 3.2.1 平衡条件 ⭐
平面一般力系平衡的充要条件是：
1. 合力为零：$\vec{F_R} = 0$
2. 合力矩为零：$\vec{M_O} = 0$

#### 3.2.2 平衡方程
**基本形式**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$
$$\sum M_O = 0$$

**二力矩形式**（O点不在合力作用线上）：
$$\sum F_x = 0$$
$$\sum M_A = 0$$
$$\sum M_B = 0$$

其中A、B两点的连线不能垂直于x轴。

**三力矩形式**（A、B、C三点不共线）：
$$\sum M_A = 0$$
$$\sum M_B = 0$$
$$\sum M_C = 0$$

<details>
<summary>平面一般力系平衡条件的推导</summary>

对于平面一般力系，我们可以将其向任一点O简化：

1. **主矢**：$\vec{F_R} = \sum \vec{F_i}$
2. **主矩**：$M_O = \sum M_O(\vec{F_i})$

平衡时，主矢和主矩都必须为零：
- $\vec{F_R} = 0$ 保证物体不发生移动
- $M_O = 0$ 保证物体不发生转动

因此得到三个独立的平衡方程。
</details>

### 3.3 空间力系平衡

#### 3.3.1 空间汇交力系平衡
**平衡方程**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$
$$\sum F_z = 0$$

#### 3.3.2 空间一般力系平衡 ⭐
**平衡方程**：
$$\sum F_x = 0$$
$$\sum F_y = 0$$
$$\sum F_z = 0$$
$$\sum M_x = 0$$
$$\sum M_y = 0$$
$$\sum M_z = 0$$

## 4. 约束与约束反力

### 4.1 约束的基本概念
**约束**：限制物体运动的其他物体。
**约束反力**：约束对物体的反作用力。

### 4.2 常见约束类型 ⭐

#### 4.2.1 柔索约束
- **特点**：只能承受拉力，不能承受压力
- **约束反力**：沿柔索方向，指向背离被约束物体
- **代表**：绳索、链条、皮带

#### 4.2.2 光滑接触约束
- **特点**：只能限制物体沿接触面法线方向的运动
- **约束反力**：沿接触面法线方向，指向被约束物体
- **代表**：光滑接触面、滚珠轴承

#### 4.2.3 铰链约束
- **特点**：限制物体在平面内的移动，但不限制转动
- **约束反力**：通过铰链中心，方向待定
- **代表**：销钉连接、轴承

**铰链约束反力的表示方法**：
1. **分解法**：用两个正交分力表示
2. **几何法**：用合力表示，方向待定

#### 4.2.4 固定端约束（插入端）
- **特点**：既限制移动又限制转动
- **约束反力**：两个正交分力和一个力偶矩
- **代表**：插入墙内的梁、焊接连接

### 4.3 约束反力方向判断 ⭐

**判断原则**：
1. **主动力方向已知**：根据主动力方向判断约束反力方向
2. **约束特性**：根据约束本身的特性判断
3. **平衡条件**：根据平衡条件确定

## 5. 平面力系平衡问题

### 5.1 解题步骤 ⭐

1. **选取研究对象**：明确要分析的物体或物体系统
2. **画受力图**：
   - 画主动力（已知力）
   - 画约束反力（未知力）
   - 标明力的方向和作用点
3. **建立坐标系**：选择合适的坐标轴
4. **列平衡方程**：
   - 根据力系类型选择合适的平衡方程
   - 列出所有独立方程
5. **求解**：解方程组求得未知量
6. **校核**：验证结果的合理性

### 5.2 典型例题

**例题2**：求图示梁的支座反力
```
    A ----●---------●---- B
          |         |
         10kN     15kN
```
已知：AB = 6m，AC = 2m，CB = 4m

**解题步骤**：

1. **选取研究对象**：梁AB
2. **画受力图**：
   - 主动力：$F_1 = 10\text{kN}$，$F_2 = 15\text{kN}$
   - 约束反力：$R_A$（A点支座反力），$R_B$（B点支座反力）

3. **建立坐标系**：以A点为原点，x轴水平向右，y轴竖直向上

4. **列平衡方程**：
   - $\sum F_x = 0$：$R_{Ax} = 0$
   - $\sum F_y = 0$：$R_A + R_B - 10 - 15 = 0$
   - $\sum M_A = 0$：$R_B \times 6 - 10 \times 2 - 15 \times 6 = 0$

5. **求解**：
   从力矩方程：$6R_B = 20 + 90 = 110$，得 $R_B = 18.33\text{kN}$
   从力方程：$R_A = 25 - 18.33 = 6.67\text{kN}$

6. **校核**：$\sum M_B = 6.67 \times 6 - 10 \times 4 = 40 - 40 = 0$ ✓

### 5.3 常见错误分析

1. **受力图错误**：漏画或多画力，方向错误
2. **坐标系选择不当**：导致计算复杂
3. **方程选择错误**：未选择足够的独立方程
4. **符号错误**：力矩符号判断错误

## 6. 空间力系平衡

### 6.1 空间汇交力系

#### 6.1.1 平衡条件
空间汇交力系平衡的充要条件是：合力为零。

#### 6.1.2 平衡方程
$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0$$

### 6.2 空间一般力系

#### 6.2.1 平衡条件
空间一般力系平衡的充要条件是：
1. 主矢为零：$\vec{F_R} = \sum \vec{F_i} = 0$
2. 主矩为零：$\vec{M_O} = \sum \vec{M_O}(\vec{F_i}) = 0$

#### 6.2.2 平衡方程
**基本形式**：
$$\sum F_x = 0, \quad \sum F_y = 0, \quad \sum F_z = 0$$
$$\sum M_x = 0, \quad \sum M_y = 0, \quad \sum M_z = 0$$

### 6.3 空间力系平衡问题的解题特点

1. **坐标系选择**：通常选择与结构主要方向一致的坐标系
2. **力矩计算**：注意力对轴的矩的计算
3. **投影分解**：将空间力分解到三个坐标轴上

**例题3**：空间桁架节点平衡
已知节点O受三个力：$F_1 = 100\text{N}$（沿x轴），$F_2 = 150\text{N}$（与x、y轴夹角均为60°），求$F_3$。

**解题思路**：
1. 将各力分解到x、y、z轴
2. 列三个方向的平衡方程
3. 解得$F_3$的大小和方向

## 7. 摩擦问题

### 7.1 摩擦的基本概念

#### 7.1.1 摩擦的分类
1. **静摩擦**：物体开始运动前的摩擦
2. **动摩擦**：物体运动时的摩擦
3. **滚动摩擦**：滚动时的摩擦

#### 7.1.2 摩擦的作用
- **阻碍作用**：摩擦力阻碍物体运动
- **驱动作用**：摩擦力也可以作为驱动力（如传送带）

### 7.2 静摩擦 ⭐

#### 7.2.1 静摩擦定律（库仑定律）
静摩擦力的大小在零与最大静摩擦力之间：
$$0 \leq f_s \leq f_{s\max}$$

**最大静摩擦力**：
$$f_{s\max} = \mu_s N$$

其中：
- $\mu_s$：静摩擦系数
- $N$：法向反力

#### 7.2.2 静摩擦的判断
1. **假设法**：假设物体处于平衡状态
2. **比较法**：比较所需摩擦力与最大静摩擦力

### 7.3 动摩擦

#### 7.3.1 动摩擦定律
动摩擦力的大小为：
$$f_k = \mu_k N$$

其中 $\mu_k$ 为动摩擦系数，通常 $\mu_k < \mu_s$。

### 7.4 摩擦角与自锁现象 ⭐

#### 7.4.1 摩擦角
**定义**：全反力与法线方向的夹角称为摩擦角。

**摩擦角公式**：
$$\tan\varphi = \frac{f_s}{N} = \mu_s$$

其中 $\varphi$ 为摩擦角。

#### 7.4.2 自锁现象 ⭐
**定义**：当主动力的合力作用线位于摩擦角内时，无论主动力多大，物体都保持静止，这种现象称为自锁。

**自锁条件**：
$$\alpha \leq \varphi$$

其中 $\alpha$ 为主动力合力与法线的夹角。

<details>
<summary>自锁现象的证明</summary>

设物体受主动力 $\vec{P}$ 和全反力 $\vec{R}$ 作用，平衡时：
$$\vec{P} + \vec{R} = 0$$

即 $\vec{P} = -\vec{R}$，说明两力大小相等、方向相反、作用线共线。

全反力 $\vec{R}$ 与法线的夹角为 $\varphi$，当 $\alpha \leq \varphi$ 时，全反力的作用线总能通过主动力的作用点，使物体保持平衡。

因此自锁条件为：$\alpha \leq \varphi = \arctan\mu_s$
</details>

### 7.5 摩擦问题的解题方法

#### 7.5.1 临界状态法
1. **假设临界状态**：假设物体处于即将运动的临界状态
2. **列平衡方程**：此时摩擦力达到最大值
3. **判断**：比较计算值与临界值，判断实际状态

#### 7.5.2 例题分析

**例题4**：重为G的物体置于倾角为α的斜面上，求：
1. 维持物体不滑动的最小力F
2. 维持物体不下滑的最小力F

**解题步骤**：

**情况1：维持不滑动（沿斜面向上拉）**
- 受力分析：重力G、法向反力N、拉力F、摩擦力f
- 平衡方程：
  - 沿斜面：$F - G\sin\alpha - f = 0$
  - 垂直斜面：$N - G\cos\alpha = 0$
- 临界状态：$f = \mu_s N$
- 解得：$F_{\min} = G(\sin\alpha + \mu_s\cos\alpha)$

**情况2：维持不下滑（沿斜面向下推）**
- 平衡方程：
  - 沿斜面：$F + f - G\sin\alpha = 0$
  - 垂直斜面：$N - G\cos\alpha = 0$
- 临界状态：$f = \mu_s N$
- 解得：$F_{\min} = G(\sin\alpha - \mu_s\cos\alpha)$

**自锁条件**：当 $\alpha \leq \arctan\mu_s$ 时，$F_{\min} \leq 0$，即无需外力物体也能保持静止。

### 7.6 重要结论 ⭐

1. **摩擦力方向**：总是阻碍相对运动或相对运动趋势
2. **摩擦力大小**：
   - 静摩擦：$0 \leq f_s \leq \mu_s N$
   - 动摩擦：$f_k = \mu_k N$
3. **自锁条件**：$\alpha \leq \varphi = \arctan\mu_s$
4. **摩擦角**：$\tan\varphi = \mu_s$
