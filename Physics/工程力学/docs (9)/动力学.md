## 1. 质点动力学基本定律

### 1.1 牛顿三定律 ⭐

#### 第一定律（惯性定律）
**内容**：任何质点都保持静止或匀速直线运动状态，直到有外力迫使它改变这种状态为止。

**数学表达式**：
$$\vec{F} = 0 \Rightarrow \vec{v} = \text{常量}$$

**重要概念**：
- 惯性：物体保持原有运动状态的性质
- 惯性参考系：牛顿定律适用的参考系

#### 第二定律（加速度定律）⭐
**内容**：质点的加速度与作用在它上面的力成正比，与质点的质量成反比，加速度的方向与力的方向相同。

**数学表达式**：
$$\vec{F} = m\vec{a} = m\frac{d^2\vec{r}}{dt^2}$$

**分量形式**：
$$\begin{cases}
F_x = m\ddot{x} \\
F_y = m\ddot{y} \\
F_z = m\ddot{z}
\end{cases}$$

#### 第三定律（作用与反作用定律）⭐
**内容**：两个质点之间的相互作用力总是大小相等，方向相反，且沿同一直线作用。

**数学表达式**：
$$\vec{F}_{12} = -\vec{F}_{21}$$

### 1.2 惯性系与非惯性系

#### 惯性参考系
- 牛顿定律成立的参考系
- 相对于惯性系做匀速直线运动的参考系也是惯性系

#### 非惯性参考系
- 相对于惯性系做变速运动的参考系
- 需要引入惯性力：$\vec{F}_i = -m\vec{a}_0$

<details>
<summary>重要定理推导</summary>

**从牛顿第二定律推导运动微分方程**

对于质点系：
$$\sum_{i=1}^n \vec{F}_i = \sum_{i=1}^n m_i \vec{a}_i = \frac{d}{dt}\left(\sum_{i=1}^n m_i \vec{v}_i\right)$$

这正是动量定理的表达式。
</details>

## 2. 质点运动微分方程

### 2.1 直角坐标系中的运动微分方程 ⭐

**基本方程**：
$$m\frac{d^2x}{dt^2} = F_x, \quad m\frac{d^2y}{dt^2} = F_y, \quad m\frac{d^2z}{dt^2} = F_z$$

**矢量形式**：
$$m\frac{d^2\vec{r}}{dt^2} = \vec{F}$$

### 2.2 自然坐标系中的运动微分方程

**切向和法向分解**：
$$\begin{cases}
m\frac{dv}{dt} = F_t = \sum F \cos\alpha \\
m\frac{v^2}{\rho} = F_n = \sum F \sin\alpha
\end{cases}$$

其中：
- $v$：质点速度
- $\rho$：轨迹曲率半径
- $F_t$：切向分力
- $F_n$：法向分力

**运动微分方程**：
$$\frac{dv}{dt} = \frac{d^2s}{dt^2} = \frac{F_t}{m}$$

### 2.3 极坐标系中的运动微分方程 ⭐

**径向和切向分量**：
$$\begin{cases}
m(\ddot{r} - r\dot{\theta}^2) = F_r \\
m(r\ddot{\theta} + 2\dot{r}\dot{\theta}) = F_\theta
\end{cases}$$

其中：
- $r$：径向坐标
- $\theta$：角坐标
- $F_r$：径向分力
- $F_\theta$：切向分力

<details>
<summary>典型例题</summary>

**例题1：抛射运动**
已知：质量为$m$的质点，以初速度$v_0$与水平面成$\alpha$角抛出。
求：运动轨迹方程

**解题思路**：
1. 建立坐标系：原点为抛出点，x轴水平，y轴竖直向上
2. 列出运动微分方程：
   $$m\ddot{x} = 0, \quad m\ddot{y} = -mg$$
3. 积分求解：
   $$\dot{x} = v_0\cos\alpha, \quad \dot{y} = v_0\sin\alpha - gt$$
   $$x = v_0\cos\alpha \cdot t, \quad y = v_0\sin\alpha \cdot t - \frac{1}{2}gt^2$$
4. 消去参数$t$得轨迹方程：
   $$y = x\tan\alpha - \frac{gx^2}{2v_0^2\cos^2\alpha}$$

**例题2：圆周运动**
已知：质量为$m$的小球在半径为$R$的圆周上运动，角速度为$\omega$。
求：小球所受的向心力

**解题思路**：
1. 采用自然坐标系
2. 法向加速度：$a_n = \frac{v^2}{R} = \omega^2R$
3. 向心力：$F_n = m\omega^2R$
</details>

## 3. 动量定理和动量矩定理

### 3.1 质点的动量定理 ⭐

#### 质点的动量
$$\vec{p} = m\vec{v}$$

#### 动量定理
**微分形式**：
$$\frac{d\vec{p}}{dt} = \vec{F}$$

**积分形式**（冲量-动量定理）：
$$\int_{t_1}^{t_2} \vec{F}dt = \vec{p}_2 - \vec{p}_1 = m\vec{v}_2 - m\vec{v}_1$$

**冲量**：
$$\vec{I} = \int_{t_1}^{t_2} \vec{F}dt$$

### 3.2 质点系的动量定理

#### 质点系的动量
$$\vec{P} = \sum_{i=1}^n m_i\vec{v}_i = M\vec{v}_c$$

其中$M$为质点系总质量，$\vec{v}_c$为质心速度。

#### 质点系动量定理
**微分形式**：
$$\frac{d\vec{P}}{dt} = \sum_{i=1}^n \vec{F}_i^{(e)} = \vec{F}^{(e)}$$

**积分形式**：
$$\int_{t_1}^{t_2} \vec{F}^{(e)}dt = \vec{P}_2 - \vec{P}_1$$

### 3.3 质点的动量矩定理

#### 质点对固定点的动量矩
$$\vec{L}_O = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$$

#### 动量矩定理
$$\frac{d\vec{L}_O}{dt} = \vec{M}_O = \vec{r} \times \vec{F}$$

### 3.4 质点系对固定点的动量矩定理

$$\frac{d\vec{L}_O}{dt} = \sum_{i=1}^n \vec{M}_{O_i}^{(e)} = \vec{M}_O^{(e)}$$

### 3.5 质点系对质心的动量矩定理 ⭐

$$\frac{d\vec{L}_c}{dt} = \vec{M}_c^{(e)}$$

其中$\vec{L}_c$为质点系对质心的动量矩。

<details>
<summary>重要定理推导</summary>

**质点系动量定理的推导**

对于质点系中的第$i$个质点：
$$m_i\frac{d^2\vec{r}_i}{dt^2} = \vec{F}_i^{(e)} + \sum_{j=1}^n \vec{F}_{ij}^{(i)}$$

对所有质点求和：
$$\sum_{i=1}^n m_i\frac{d^2\vec{r}_i}{dt^2} = \sum_{i=1}^n \vec{F}_i^{(e)} + \sum_{i=1}^n \sum_{j=1}^n \vec{F}_{ij}^{(i)}$$

根据牛顿第三定律，内力之和为零：
$$\sum_{i=1}^n \sum_{j=1}^n \vec{F}_{ij}^{(i)} = 0$$

因此：
$$\sum_{i=1}^n m_i\frac{d^2\vec{r}_i}{dt^2} = \sum_{i=1}^n \vec{F}_i^{(e)}$$

即：
$$\frac{d^2}{dt^2}\left(\sum_{i=1}^n m_i\vec{r}_i\right) = \vec{F}^{(e)}$$

设质心坐标：
$$\vec{r}_c = \frac{\sum_{i=1}^n m_i\vec{r}_i}{M}$$

则：
$$M\frac{d^2\vec{r}_c}{dt^2} = \vec{F}^{(e)}$$

这表明质点系的运动可以简化为质心的运动。
</details>

## 4. 动能定理

### 4.1 质点的动能

#### 质点的动能
$$T = \frac{1}{2}mv^2$$

#### 质点的动能定理 ⭐
**微分形式**：
$$dT = \vec{F} \cdot d\vec{r} = F\cos\alpha ds$$

**积分形式**：
$$T_2 - T_1 = \int_{M_1}^{M_2} \vec{F} \cdot d\vec{r} = W_{12}$$

其中$W_{12}$为力$\vec{F}$从位置1到位置2所作的功。

### 4.2 质点系的动能

#### 质点系的动能
$$T = \sum_{i=1}^n \frac{1}{2}m_iv_i^2 = T_c + T_{rc}$$

其中：
- $T_c = \frac{1}{2}Mv_c^2$：质心的动能
- $T_{rc} = \sum_{i=1}^n \frac{1}{2}m_iv_{ri}^2$：相对于质心的动能

#### 柯尼希定理
质点系的动能等于质心的动能加上各质点相对于质心的动能之和。

### 4.3 功和功率

#### 功的计算
**恒力功**：
$$W = \vec{F} \cdot \vec{s} = Fs\cos\alpha$$

**变力功**：
$$W = \int_{M_1}^{M_2} \vec{F} \cdot d\vec{r}$$

**常见力的功**：
- 重力：$W = mg(h_1 - h_2)$
- 弹性力：$W = \frac{1}{2}kx_1^2 - \frac{1}{2}kx_2^2$
- 摩擦力：$W = -fN \cdot s$

#### 功率
**平均功率**：
$$P = \frac{W}{t}$$

**瞬时功率**：
$$P = \vec{F} \cdot \vec{v} = Fv\cos\alpha$$

### 4.4 机械能守恒定律 ⭐

#### 保守力
重力、弹性力、万有引力等都是保守力。

#### 机械能守恒
$$T + V = \text{常量}$$

其中$V$为势能。

<details>
<summary>典型例题</summary>

**例题3：单摆运动**
已知：质量为$m$的单摆，摆长为$l$，初始时摆角为$\theta_0$，初速度为零。
求：摆角为$\theta$时的角速度

**解题思路**：
1. 应用机械能守恒定律
2. 初始机械能：$T_1 + V_1 = 0 + mg(l - l\cos\theta_0)$
3. 任意位置机械能：$T_2 + V_2 = \frac{1}{2}mv^2 + mg(l - l\cos\theta)$
4. 机械能守恒：
   $$\frac{1}{2}mv^2 + mg(l - l\cos\theta) = mg(l - l\cos\theta_0)$$
5. 整理得：
   $$v = \sqrt{2gl(\cos\theta - \cos\theta_0)}$$
6. 角速度：
   $$\omega = \frac{v}{l} = \sqrt{\frac{2g}{l}(\cos\theta - \cos\theta_0)}$$

**例题4：碰撞问题**
已知：质量分别为$m_1$和$m_2$的两个小球，碰撞前速度分别为$v_1$和$v_2$。
求：碰撞后的速度（假设为完全弹性碰撞）

**解题思路**：
1. 应用动量守恒定律：
   $$m_1v_1 + m_2v_2 = m_1v_1' + m_2v_2'$$
2. 应用动能守恒定律（完全弹性碰撞）：
   $$\frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2 = \frac{1}{2}m_1v_1'^2 + \frac{1}{2}m_2v_2'^2$$
3. 解得：
   $$v_1' = \frac{(m_1-m_2)v_1 + 2m_2v_2}{m_1+m_2}$$
   $$v_2' = \frac{(m_2-m_1)v_2 + 2m_1v_1}{m_1+m_2}$$
</details>

## 5. 机械振动基础

### 5.1 自由振动

#### 无阻尼自由振动 ⭐

**运动微分方程**：
$$m\ddot{x} + kx = 0$$

**通解**：
$$x = A\cos(\omega_n t + \phi)$$

其中：
- $\omega_n = \sqrt{\frac{k}{m}}$：固有频率
- $A$：振幅
- $\phi$：初相位

**周期**：
$$T = \frac{2\pi}{\omega_n} = 2\pi\sqrt{\frac{m}{k}}$$

#### 有阻尼自由振动

**运动微分方程**：
$$m\ddot{x} + c\dot{x} + kx = 0$$

**特征方程**：
$$mr^2 + cr + k = 0$$

**解的情况**：
1. **欠阻尼**（$c < c_{cr}$）：$r = -\delta \pm i\omega_d$
   $$x = Ae^{-\delta t}\cos(\omega_d t + \phi)$$
   
2. **临界阻尼**（$c = c_{cr}$）：$r = -\delta$
   $$x = (A + Bt)e^{-\delta t}$$
   
3. **过阻尼**（$c > c_{cr}$）：$r_{1,2} = -\delta \pm \sqrt{\delta^2 - \omega_n^2}$
   $$x = Ae^{r_1t} + Be^{r_2t}$$

其中：
- $\delta = \frac{c}{2m}$：衰减系数
- $\omega_d = \sqrt{\omega_n^2 - \delta^2}$：阻尼振动频率
- $c_{cr} = 2\sqrt{mk}$：临界阻尼系数

### 5.2 强迫振动

#### 无阻尼强迫振动

**运动微分方程**：
$$m\ddot{x} + kx = F_0\sin\omega t$$

**通解**：
$$x = A\cos(\omega_n t + \phi) + \frac{F_0}{m(\omega_n^2 - \omega^2)}\sin\omega t$$

**特殊情况**：
- **共振**（$\omega = \omega_n$）：振幅无限增大
  $$x = \frac{F_0}{2m\omega_n}t\cos(\omega_n t + \phi)$$

#### 有阻尼强迫振动 ⭐

**运动微分方程**：
$$m\ddot{x} + c\dot{x} + kx = F_0\sin\omega t$$

**稳态解**：
$$x = B\sin(\omega t - \theta)$$

其中：
- **振幅**：$B = \frac{F_0}{\sqrt{(k-m\omega^2)^2 + (c\omega)^2}}$
- **相位差**：$\tan\theta = \frac{c\omega}{k-m\omega^2}$

**放大系数**：
$$\beta = \frac{B}{B_0} = \frac{1}{\sqrt{(1-r^2)^2 + (2\zeta r)^2}}$$

其中：
- $r = \frac{\omega}{\omega_n}$：频率比
- $\zeta = \frac{c}{c_{cr}}$：阻尼比
- $B_0 = \frac{F_0}{k}$：静力位移

### 5.3 振动系统的能量

#### 无阻尼振动
$$E = \frac{1}{2}kA^2 = \text{常量}$$

#### 有阻尼振动
$$E = \frac{1}{2}kA^2e^{-2\delta t}$$

<details>
<summary>重要公式汇总</summary>

**基本参数**：
- 固有频率：$\omega_n = \sqrt{\frac{k}{m}}$
- 临界阻尼：$c_{cr} = 2\sqrt{mk}$
- 阻尼比：$\zeta = \frac{c}{c_{cr}}$
- 衰减系数：$\delta = \zeta\omega_n$
- 阻尼频率：$\omega_d = \omega_n\sqrt{1-\zeta^2}$

**共振条件**：
- 无阻尼：$\omega = \omega_n$
- 有阻尼：$\omega_r = \omega_n\sqrt{1-2\zeta^2}$（$\zeta < \frac{1}{\sqrt{2}}$）
</details>

## 6. 多自由度系统振动

### 6.1 两自由度系统

#### 运动微分方程
$$\begin{cases}
m_1\ddot{x}_1 + k_{11}x_1 + k_{12}x_2 = F_1 \\
m_2\ddot{x}_2 + k_{21}x_1 + k_{22}x_2 = F_2
\end{cases}$$

**矩阵形式**：
$$[M]\{\ddot{x}\} + [K]\{x\} = \{F\}$$

其中：
- $[M]$：质量矩阵
- $[K]$：刚度矩阵
- $\{x\}$：位移向量
- $\{F\}$：力向量

#### 自由振动分析

**假设解**：$\{x\} = \{X\}e^{i\omega t}$

**特征方程**：
$$\det([K] - \omega^2[M]) = 0$$

**解得的特征值**：$\omega_1^2, \omega_2^2, ..., \omega_n^2$（固有频率的平方）

**对应的特征向量**：$\{X\}^{(1)}, \{X\}^{(2)}, ..., \{X\}^{(n)}$（振型向量）

### 6.2 模态分析 ⭐

#### 振型的正交性
$$\{X\}^{(i)T}[M]\{X\}^{(j)} = 0 \quad (i \neq j)$$
$$\{X\}^{(i)T}[K]\{X\}^{(j)} = 0 \quad (i \neq j)$$

#### 模态矩阵
$$[\Phi] = \begin{bmatrix}
\{X\}^{(1)} & \{X\}^{(2)} & \cdots & \{X\}^{(n)}
\end{bmatrix}$$

#### 主坐标
$$\{q\} = [\Phi]^T[M]\{x\}$$

#### 解耦的运动方程
$$\ddot{q}_i + \omega_i^2q_i = Q_i$$

其中$Q_i$为第$i$阶模态力。

### 6.3 强迫振动分析

#### 模态叠加法
1. 将物理坐标转换为主坐标
2. 求解各单自由度系统的响应
3. 叠加各模态响应得到总响应

**主坐标下的响应**：
$$q_i(t) = \frac{Q_i}{m_i\omega_i^2}\left[1 - \cos(\omega_i t + \phi_i)\right]$$

**物理坐标下的响应**：
$$\{x(t)\} = \sum_{i=1}^n q_i(t)\{X\}^{(i)}$$

<details>
<summary>典型例题</summary>

**例题5：双摆系统**
已知：两个质量为$m$的质点，摆长均为$l$。
求：系统的固有频率和振型

**解题思路**：
1. 建立运动微分方程：
   $$\begin{cases}
   2m\ddot{\theta}_1 + mg\theta_1 + mg(\theta_1 - \theta_2) = 0 \\
   m\ddot{\theta}_2 + mg\theta_2 + mg(\theta_2 - \theta_1) = 0
   \end{cases}$$

2. 整理为标准形式：
   $$\begin{cases}
   2\ddot{\theta}_1 + 2\frac{g}{l}\theta_1 - \frac{g}{l}\theta_2 = 0 \\
   \ddot{\theta}_2 - \frac{g}{l}\theta_1 + 2\frac{g}{l}\theta_2 = 0
   \end{cases}$$

3. 特征方程：
   $$\det\begin{bmatrix}
   2\omega^2 - 2\frac{g}{l} & \frac{g}{l} \\
   \frac{g}{l} & \omega^2 - 2\frac{g}{l}
   \end{bmatrix} = 0$$

4. 解得固有频率：
   $$\omega_1^2 = \frac{g}{l}, \quad \omega_2^2 = 3\frac{g}{l}$$

5. 振型：
   - 第一阶：$\theta_1 = \theta_2$（同相）
   - 第二阶：$\theta_1 = -\theta_2$（反相）
</details>

## 7. 碰撞问题

### 7.1 碰撞的基本概念

#### 碰撞过程
1. **变形阶段**：物体相互接触，产生弹性或塑性变形
2. **恢复阶段**：物体恢复变形或保持变形状态

#### 碰撞力的特点
- 作用时间短（$10^{-3} \sim 10^{-5}$s）
- 作用力大（可达$10^4 \sim 10^6$N）
- 变化复杂

### 7.2 恢复系数 ⭐

#### 恢复系数的定义
$$e = \frac{v_{2n} - v_{1n}}{u_{1n} - u_{2n}}$$

其中：
- $u_{1n}, u_{2n}$：碰撞前两物体的法向速度分量
- $v_{1n}, v_{2n}$：碰撞后两物体的法向速度分量

#### 特殊情况
- **完全弹性碰撞**：$e = 1$
- **完全非弹性碰撞**：$e = 0$
- **一般碰撞**：$0 < e < 1$

### 7.3 一维碰撞 ⭐

#### 完全弹性碰撞
**动量守恒**：
$$m_1u_1 + m_2u_2 = m_1v_1 + m_2v_2$$

**动能守恒**：
$$\frac{1}{2}m_1u_1^2 + \frac{1}{2}m_2u_2^2 = \frac{1}{2}m_1v_1^2 + \frac{1}{2}m_2v_2^2$$

**解得**：
$$v_1 = \frac{(m_1-m_2)u_1 + 2m_2u_2}{m_1+m_2}$$
$$v_2 = \frac{(m_2-m_1)u_2 + 2m_1u_1}{m_1+m_2}$$

#### 完全非弹性碰撞
**动量守恒**：
$$m_1u_1 + m_2u_2 = (m_1+m_2)v$$

**碰撞后速度**：
$$v = \frac{m_1u_1 + m_2u_2}{m_1+m_2}$$

#### 一般碰撞
**动量守恒**：
$$m_1u_1 + m_2u_2 = m_1v_1 + m_2v_2$$

**恢复系数**：
$$e = \frac{v_2 - v_1}{u_1 - u_2}$$

**解得**：
$$v_1 = u_1 - \frac{m_2(1+e)}{m_1+m_2}(u_1 - u_2)$$
$$v_2 = u_2 + \frac{m_1(1+e)}{m_1+m_2}(u_1 - u_2)$$

### 7.4 二维碰撞

#### 碰撞方程
**动量守恒**：
$$\begin{cases}
m_1u_{1x} + m_2u_{2x} = m_1v_{1x} + m_2v_{2x} \\
m_1u_{1y} + m_2u_{2y} = m_1v_{1y} + m_2v_{2y}
\end{cases}$$

**恢复系数**：
$$e = \frac{v_{2n} - v_{1n}}{u_{1n} - u_{2n}}$$

其中$n$为碰撞点的公法线方向。

### 7.5 碰撞中的能量损失

#### 动能损失
$$\Delta T = \frac{1}{2}\frac{m_1m_2}{m_1+m_2}(1-e^2)(u_1-u_2)^2$$

#### 能量损失系数
$$\eta = \frac{\Delta T}{T_1} = \frac{m_2(1-e^2)}{m_1+m_2}\frac{(u_1-u_2)^2}{u_1^2}$$

**例题6：球与固定面的碰撞**
已知：质量为$m$的小球，以速度$v_0$与水平面成$\alpha$角撞击地面。
求：碰撞后的速度和方向

**解题思路**：
1. 分解速度：
   - 水平分量：$u_x = v_0\cos\alpha$
   - 竖直分量：$u_y = v_0\sin\alpha$

2. 碰撞后：
   - 水平速度不变：$v_x = v_0\cos\alpha$
   - 竖直速度反向：$v_y = -ev_0\sin\alpha$

3. 碰撞后速度大小：
   $$v = \sqrt{v_x^2 + v_y^2} = v_0\sqrt{\cos^2\alpha + e^2\sin^2\alpha}$$

4. 碰撞后方向：
   $$\tan\beta = \frac{|v_y|}{v_x} = \frac{e\sin\alpha}{\cos\alpha} = e\tan\alpha$$

**例题7：三个球的连续碰撞**
已知：质量分别为$m_1, m_2, m_3$的三个球，$m_1$以速度$v_0$撞击静止的$m_2$，$m_2$再撞击静止的$m_3$。
求：最终各球的速度（完全弹性碰撞）

**解题思路**：
1. 第一阶段：$m_1$与$m_2$碰撞
   $$v_1' = \frac{m_1-m_2}{m_1+m_2}v_0, \quad v_2' = \frac{2m_1}{m_1+m_2}v_0$$

2. 第二阶段：$m_2$与$m_3$碰撞
   $$v_2'' = \frac{m_2-m_3}{m_2+m_3}v_2', \quad v_3' = \frac{2m_2}{m_2+m_3}v_2'$$

3. 特殊情况：
   - 若$m_1 = m_2 = m_3 = m$：
     $$v_1'' = 0, \quad v_2'' = 0, \quad v_3'' = v_0$$
