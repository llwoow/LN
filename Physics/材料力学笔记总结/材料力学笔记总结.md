## 1. 绪论与基本概念

### 1.1 材料力学的任务

材料力学是研究构件在**外力作用下**的：
- **强度**：构件抵抗破坏的能力
- **刚度**：构件抵抗变形的能力  
- **稳定性**：构件保持原有平衡形式的能力

### 1.2 基本假设

#### 变形固体基本假设
1. **连续性假设**：材料无空隙，均匀连续
2. **均匀性假设**：材料各部分性能相同
3. **各向同性假设**：材料各方向性能相同
4. **小变形假设**：变形远小于构件尺寸

### 1.3 构件的分类

| 构件类型 | 几何特征 | 主要变形形式 |
|---------|---------|-------------|
| **杆件** | 长度>>截面尺寸 | 轴向拉压、剪切、扭转、弯曲 |
| **板壳** | 厚度<<其他尺寸 | 平面应力、弯曲 |
| **块体** | 三维尺寸相近 | 三维应力状态 |

### 1.4 内力与应力

#### 1.4.1 内力的概念
内力是构件内部各部分之间的相互作用力，由外力引起。

**截面法求内力步骤：**
1. 假想切开构件
2. 保留任一部分为研究对象
3. 用内力代替两部分间的相互作用
4. 建立平衡方程求内力

#### 1.4.2 应力概念

**正应力** $\sigma$：垂直于截面的应力分量
- 拉应力：正，指向截面外法线方向
- 压应力：负，指向截面内法线方向

**剪应力** $\tau$：平行于截面的应力分量

<details>
<summary><strong>应力的数学定义</strong></summary>

对于构件内某点，取包含该点的微元体，其截面积为 $dA$，该截面上内力为 $dF$，则：

**正应力**：$\sigma = \lim_{dA \to 0} \frac{dF_n}{dA}$

**剪应力**：$\tau = \lim_{dA \to 0} \frac{dF_t}{dA}$

其中 $dF_n$ 为垂直于截面的内力分量，$dF_t$ 为平行于截面的内力分量。
</details>

### 1.5 应变概念

**线应变** $\varepsilon$：单位长度的变形量
- 正应变：$\varepsilon = \lim_{dl \to 0} \frac{\Delta dl}{dl}$
- 剪应变：$\gamma = \lim_{dl \to 0} \frac{\Delta s}{dl}$（角度变化）

## 2. 轴向拉压

### 2.1 轴向拉压的概念

**轴向拉压**：构件受到沿轴线方向的载荷作用，截面产生均匀正应力。

**特点**：
- 杆件轴线保持直线
- 各截面变形相同
- 应力应变均匀分布

### 2.2 轴向拉压的内力

**轴力** $N$：截面上的内力，符号规定：
- 拉为正，压为负

**轴力方程**：$N(x) = F_1 + F_2 + ...$（截面左侧外力代数和）

### 2.3 轴向拉压的应力

<details>
<summary><strong>应力的推导过程</strong></summary>

**假设**：
1. 变形前为平面，变形后仍为平面（平面假设）
2. 各纤维纵向变形相同（均匀性假设）

**推导过程**：

1. **平衡条件**：$\sum F_x = 0$
   $$N - \int_A \sigma dA = 0$$
   $$N = \int_A \sigma dA$$

2. **平面假设**：各点应变相同 $\varepsilon = \varepsilon_0$

3. **均匀性假设**：应力相同 $\sigma = \sigma_0$

4. **结果**：
   $$\sigma = \frac{N}{A}$$

**结论**：轴向拉压时，正应力均匀分布。
</details>

**正应力公式**：
$$\sigma = \frac{N}{A}$$

其中：$N$ - 轴力，$A$ - 截面面积

### 2.4 轴向拉压的应变

<details>
<summary><strong>虎克定律的推导</strong></summary>

**线弹性阶段**：应力与应变成正比

**虎克定律**：
$$\sigma = E\varepsilon$$

其中 $E$ 为弹性模量（杨氏模量）。

**轴向应变**：
$$\varepsilon = \frac{\sigma}{E} = \frac{N}{EA}$$

**轴向变形**：
$$\Delta l = \int_0^l \varepsilon dx = \int_0^l \frac{N(x)}{EA(x)}dx$$

对于等截面等轴力：
$$\Delta l = \frac{Nl}{EA}$$
</details>

### 2.5 横向变形

<details>
<summary><strong>泊松比的概念</strong></summary>

**泊松比** $\nu$：横向应变与轴向应变的比值

$$\nu = -\frac{\varepsilon_{横向}}{\varepsilon_{轴向}}$$

**横向应变**：
$$\varepsilon_{横向} = -\nu\varepsilon_{轴向} = -\nu\frac{\sigma}{E}$$

**体积应变**：
$$\varepsilon_V = \varepsilon_{轴向} + 2\varepsilon_{横向} = \frac{\sigma}{E}(1 - 2\nu)$$
</details>

### 2.6 强度条件

**强度条件**：
$$\sigma_{max} = \frac{N_{max}}{A} \leq [\sigma] = \frac{\sigma_{allow}}{n_s}$$

其中：
- $[\sigma]$ - 许用应力
- $n_s$ - 安全系数
- $\sigma_{allow}$ - 材料极限应力

### 2.7 刚度条件

**刚度条件**：
$$\Delta l_{max} \leq [\Delta l]$$

其中 $[\Delta l]$ 为许用变形量。

### 2.8 常见题型总结

| 题型 | 解题步骤 | 关键公式 |
|------|---------|---------|
| **强度校核** | 1. 求轴力 $N$<br>2. 求应力 $\sigma = N/A$<br>3. 校核 $\sigma \leq [\sigma]$ | $\sigma = N/A$ |
| **截面设计** | 1. 由强度条件求 $A$<br>2. 确定截面尺寸 | $A \geq \frac{N}{[\sigma]}$ |
| **变形计算** | 1. 分段计算<br>2. 叠加各段变形 | $\Delta l = \sum \frac{N_i l_i}{EA_i}$ |

## 3. 剪切

### 3.1 剪切的概念

**剪切**：构件受到大小相等、方向相反、作用线平行且相距很近的两个力的作用。

**剪切面**：两力作用线之间的截面

### 3.2 剪应力

**剪应力公式**：
$$\tau = \frac{Q}{A}$$

其中：$Q$ - 剪力，$A$ - 剪切面面积

### 3.3 剪切虎克定律

<details>
<summary><strong>剪切虎克定律的推导</strong></summary>

**剪应变**：$\gamma = \frac{\Delta s}{l}$

**剪切虎克定律**：
$$\tau = G\gamma$$

其中 $G$ 为剪切弹性模量。

**三个弹性常数的关系**：
$$G = \frac{E}{2(1 + \nu)}$$

$$K = \frac{E}{3(1 - 2\nu)}$$ （体积弹性模量）

**各向同性材料的弹性常数关系**：
$$\frac{E}{G} = 2(1 + \nu)$$
$$\frac{E}{K} = 3(1 - 2\nu)$$
</details>

### 3.4 剪切强度条件

**强度条件**：
$$\tau_{max} = \frac{Q_{max}}{A} \leq [\tau]$$

### 3.5 挤压强度

**挤压应力**：
$$\sigma_{bs} = \frac{F_{bs}}{A_{bs}}$$

其中：$F_{bs}$ - 挤压载荷，$A_{bs}$ - 挤压面积

**挤压强度条件**：
$$\sigma_{bs} \leq [\sigma_{bs}]$$

## 4. 扭转

### 4.1 扭转的概念

**扭转**：构件受到绕轴线作用的力偶，截面产生剪应力。

**扭转轴**：主要承受扭转的杆件

### 4.2 扭矩

**扭矩** $T$：截面上的内力偶矩，符号规定：
- 右手螺旋定则：拇指指向截面外法线方向为正

**扭矩方程**：$T(x) = M_1 + M_2 + ...$（截面左侧外力偶矩代数和）

### 4.3 扭转剪应力

<details>
<summary><strong>扭转剪应力的推导</strong></summary>

**平面假设**：
1. 变形前为平面的截面，变形后仍保持平面
2. 半径仍保持直线
3. 圆周长度不变

**推导过程**：

1. **几何关系**：$r d\theta = \gamma dl$
   
   其中：$\gamma$ - 剪应变，$d\theta$ - 扭转角，$dl$ - 长度微元

2. **剪切虎克定律**：$\tau = G\gamma$

3. **静力关系**：$T = \int_A \tau r dA$

4. **结果**（圆形截面）：
   $$\tau_{\rho} = \frac{T\rho}{I_p}$$

   其中：$\rho$ - 到圆心的距离，$I_p$ - 极惯性矩

**圆形截面**：
- 实心圆：$I_p = \frac{\pi d^4}{32} = \frac{\pi D^4}{32}$
- 空心圆：$I_p = \frac{\pi}{32}(D^4 - d^4)$

**最大剪应力**：
$$\tau_{max} = \frac{T}{W_p}$$

其中 $W_p = \frac{I_p}{\rho_{max}}$ 为抗扭截面模量。
</details>

**扭转剪应力公式**：
$$\tau_{\rho} = \frac{T\rho}{I_p}$$

**最大剪应力**：
$$\tau_{max} = \frac{T}{W_p}$$

其中：
- $I_p = \frac{\pi d^4}{32}$（实心圆）
- $W_p = \frac{\pi d^3}{16}$（实心圆）

### 4.4 扭转角

<details>
<summary><strong>扭转角的计算</strong></summary>

**单位长度扭转角**：
$$\theta = \frac{d\phi}{dx} = \frac{T}{GI_p}$$

**扭转角**：
$$\phi = \int_0^l \theta dx = \int_0^l \frac{T(x)}{GI_p(x)}dx$$

对于等截面等扭矩：
$$\phi = \frac{Tl}{GI_p}$$

**刚度条件**：
$$\theta_{max} = \frac{T_{max}}{GI_p} \leq [\theta]$$
</details>

### 4.5 扭转强度条件

**强度条件**：
$$\tau_{max} = \frac{T_{max}}{W_p} \leq [\tau]$$

### 4.6 扭转刚度条件

**刚度条件**：
$$\theta_{max} = \frac{T_{max}}{GI_p} \leq [\theta]$$

### 4.7 常见截面抗扭性能

| 截面类型 | 极惯性矩 $I_p$ | 抗扭截面模量 $W_p$ | 特点 |
|---------|---------------|-------------------|------|
| **实心圆** | $\frac{\pi d^4}{32}$ | $\frac{\pi d^3}{16}$ | 简单，制造方便 |
| **空心圆** | $\frac{\pi(D^4 - d^4)}{32}$ | $\frac{\pi(D^4 - d^4)}{16D}$ | 材料利用率高 |
| **薄壁圆管** | $2\pi r^3 t$ | $2\pi r^2 t$ | 抗扭性能好 |

## 5. 弯曲内力

### 5.1 弯曲的概念

**弯曲**：构件受到垂直于轴线的载荷作用，轴线由直线变为曲线。

**弯曲梁**：主要承受弯曲的构件

### 5.2 梁的基本类型

| 梁的类型 | 支承方式 | 典型载荷 | 特点 |
|---------|---------|---------|------|
| **简支梁** | 铰支座 + 辊支座 | 集中力、分布力 | 结构简单 |
| **悬臂梁** | 固定支座 | 自由端载荷 | 变形大 |
| **外伸梁** | 简支 + 外伸 | 多种载荷 | 应用广泛 |

### 5.3 弯曲内力

#### 5.3.1 剪力 $Q$ 和弯矩 $M$

**剪力** $Q$：截面上的内力，符号规定：
- 左侧向上、右侧向下为正

**弯矩** $M$：截面上的内力偶矩，符号规定：
- 使梁产生下凸变形为正（上侧受压，下侧受拉）

#### 5.3.2 内力方程和内力图

<details>
<summary><strong>剪力、弯矩与载荷的关系</strong></summary>

**微分关系**：

1. **剪力与载荷的关系**：
   $$\frac{dQ}{dx} = -q(x)$$

2. **弯矩与剪力的关系**：
   $$\frac{dM}{dx} = Q(x)$$

**积分关系**：

1. **剪力**：
   $$Q(x) = Q(x_0) - \int_{x_0}^x q(x)dx$$

2. **弯矩**：
   $$M(x) = M(x_0) + \int_{x_0}^x Q(x)dx$$

**边界条件**：
- 简支端：$M = 0$
- 固定端：$M \neq 0, Q \neq 0$
- 自由端：$M = 0, Q = 0$
</details>

#### 5.3.3 常见载荷下的内力图

| 载荷类型 | 剪力图特点 | 弯矩图特点 | 最大弯矩位置 |
|---------|-----------|-----------|-------------|
| **集中力** | 集中力处突变 | 集中力处转折 | 集中力作用处 |
| **集中力偶** | 连续 | 力偶处突变 | 力偶作用处 |
| **均布载荷** | 直线 | 抛物线 | 梁中点 |
| **三角形载荷** | 抛物线 | 三次曲线 | 最大载荷处 |

### 5.4 叠加法求内力

**叠加原理**：当载荷作用在线弹性范围内时，复杂载荷下的内力等于各简单载荷单独作用下内力的代数和。

**步骤**：
1. 将复杂载荷分解为简单载荷
2. 分别求各简单载荷下的内力
3. 叠加得到总内力

## 6. 弯曲应力

### 6.1 纯弯曲

**纯弯曲**：梁段内只有弯矩，无剪力。

### 6.2 弯曲正应力

<details>
<summary><strong>弯曲正应力的推导</strong></summary>

**基本假设**：
1. **平面假设**：变形前为平面的截面，变形后仍保持平面
2. **纵向纤维互不挤压**：各纵向纤维只受轴向力

**推导过程**：

1. **几何关系**：
   - 中性层曲率半径：$\rho$
   - 梁高：$h$
   - 到中性层距离：$y$
   
   纤维长度变化：$\Delta dl = y d\theta$
   
   线应变：$\varepsilon = \frac{\Delta dl}{dl} = \frac{y}{\rho}$

2. **物理关系**（虎克定律）：
   $$\sigma = E\varepsilon = \frac{Ey}{\rho}$$

3. **静力平衡**：
   - 轴向力平衡：$\int_A \sigma dA = 0$
   - 弯矩平衡：$M = \int_A \sigma y dA$

4. **中性轴位置**：
   由 $\int_A \sigma dA = 0$ 得：
   $$\int_A \frac{Ey}{\rho} dA = 0 \Rightarrow \int_A y dA = 0$$
   说明中性轴通过截面形心。

5. **曲率公式**：
   $$\frac{1}{\rho} = \frac{M}{EI_z}$$
   
   其中 $I_z = \int_A y^2 dA$ 为中性轴惯性矩。

6. **最终公式**：
   $$\sigma = \frac{My}{I_z}$$

**最大正应力**：
$$\sigma_{max} = \frac{M}{W_z}$$

其中 $W_z = \frac{I_z}{y_{max}}$ 为抗弯截面模量。
</details>

**弯曲正应力公式**：
$$\sigma = \frac{My}{I_z}$$

**最大正应力**：
$$\sigma_{max} = \frac{M}{W_z}$$

其中：
- $I_z$ - 截面对中性轴的惯性矩
- $W_z$ - 抗弯截面模量

### 6.3 常见截面的几何性质

| 截面形状 | 惯性矩 $I_z$ | 抗弯截面模量 $W_z$ | 特点 |
|---------|-------------|-------------------|------|
| **矩形** | $\frac{bh^3}{12}$ | $\frac{bh^2}{6}$ | 常用截面 |
| **圆形** | $\frac{\pi d^4}{64}$ | $\frac{\pi d^3}{32}$ | 对称性好 |
| **工字形** | $\frac{BH^3 - bh^3}{12}$ | $\frac{BH^3 - bh^3}{6H}$ | 抗弯性能好 |

### 6.4 弯曲剪应力

<details>
<summary><strong>弯曲剪应力的推导</strong></summary>

**剪应力分布假设**：
1. 剪应力方向平行于剪力
2. 剪应力沿宽度均匀分布

**矩形截面剪应力**：

1. **微元平衡**：
   $$\frac{dQ}{dx} = -q(x)$$

2. **剪应力公式**：
   $$\tau = \frac{QS_z^*}{I_z b}$$

   其中：
   - $S_z^*$ - 静矩
   - $b$ - 截面宽度
   - $I_z$ - 惯性矩

3. **矩形截面剪应力分布**：
   $$\tau = \frac{3Q}{2A}(1 - \frac{4y^2}{h^2})$$

4. **最大剪应力**：
   $$\tau_{max} = \frac{3Q}{2A}$$

**薄壁截面剪应力**：
- 工字形截面：腹板承担主要剪力
- T形截面：腹板和翼缘共同承担
</details>

**弯曲剪应力公式**：
$$\tau = \frac{QS_z^*}{I_z b}$$

**矩形截面最大剪应力**：
$$\tau_{max} = \frac{3Q}{2A}$$

### 6.5 弯曲强度条件

**正应力强度条件**：
$$\sigma_{max} = \frac{M_{max}}{W_z} \leq [\sigma]$$

**剪应力强度条件**：
$$\tau_{max} = \frac{Q_{max}S_z^*}{I_z b} \leq [\tau]$$

**组合强度条件**：
$$\sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]$$ （第三强度理论）

## 7. 弯曲变形

### 7.1 弯曲变形的概念

**挠度** $w$：梁轴线上某点的垂直位移

**转角** $\theta$：梁轴线上某点的切线斜率

### 7.2 梁的挠曲线微分方程

<details>
<summary><summary>挠曲线微分方程的推导</strong></summary>

**几何关系**：
曲率公式：$\frac{1}{\rho} = \frac{d^2w}{dx^2}/[1 + (\frac{dw}{dx})^2]^{3/2}$

**小变形假设**：
$\frac{dw}{dx} << 1$，因此：
$$\frac{1}{\rho} \approx \frac{d^2w}{dx^2}$$

**物理关系**：
$$\frac{1}{\rho} = \frac{M}{EI}$$

**挠曲线微分方程**：
$$EI\frac{d^2w}{dx^2} = M(x)$$

**高阶微分方程**：
$$EI\frac{d^3w}{dx^3} = Q(x)$$
$$EI\frac{d^4w}{dx^4} = q(x)$$
</details>

**挠曲线微分方程**：
$$EI\frac{d^2w}{dx^2} = M(x)$$

### 7.3 积分法求变形

<details>
<summary><strong>积分法求解步骤</strong></summary>

**步骤**：

1. **建立坐标系**：选择合适的坐标原点
2. **列弯矩方程**：$M(x)$
3. **建立微分方程**：$EIw'' = M(x)$
4. **积分一次**：$EIw' = \int M(x)dx + C_1$
5. **积分二次**：$EIw = \int[\int M(x)dx + C_1]dx + C_2$
6. **确定积分常数**：利用边界条件和连续条件
7. **求挠度和转角**

**边界条件**：
- 铰支座：$w = 0$
- 固定端：$w = 0, w' = 0$
- 自由端：$M = 0, Q = 0$

**连续条件**：
- 变截面处：$w, w'$ 连续
- 集中力作用处：$w'$ 不连续
- 集中力偶作用处：$w$ 不连续
</details>

### 7.4 叠加法求变形

**叠加原理**：复杂载荷下的变形等于各简单载荷单独作用下变形的代数和。

**常见简单载荷的变形公式**：

| 载荷类型 | 最大挠度 | 最大转角 |
|---------|---------|---------|
| **简支梁中点集中力** | $w_{max} = \frac{Fl^3}{48EI}$ | $\theta_{max} = \frac{Fl^2}{16EI}$ |
| **简支梁均布载荷** | $w_{max} = \frac{5ql^4}{384EI}$ | $\theta_{max} = \frac{ql^3}{24EI}$ |
| **悬臂梁端部集中力** | $w_{max} = \frac{Fl^3}{3EI}$ | $\theta_{max} = \frac{Fl^2}{2EI}$ |
| **悬臂梁均布载荷** | $w_{max} = \frac{ql^4}{8EI}$ | $\theta_{max} = \frac{ql^3}{6EI}$ |

### 7.5 刚度条件

**挠度刚度条件**：
$$w_{max} \leq [w]$$

**转角刚度条件**：
$$\theta_{max} \leq [\theta]$$

## 8. 组合变形

### 8.1 组合变形的概念

**组合变形**：构件同时承受两种或两种以上基本变形。

**分析方法**：
1. **分解**：将组合变形分解为基本变形
2. **计算**：分别计算各基本变形的应力
3. **叠加**：将各基本变形的应力叠加
4. **校核**：按强度理论校核强度

### 8.2 常见组合变形

#### 8.2.1 拉（压）弯组合

**应力叠加**：
$$\sigma = \sigma_N + \sigma_M = \frac{N}{A} + \frac{My}{I_z}$$

**强度条件**：
$$\sigma_{max} = \frac{N}{A} + \frac{M_{max}}{W_z} \leq [\sigma]$$

#### 8.2.2 弯扭组合

**应力状态**：
- 弯曲正应力：$\sigma = \frac{M}{W}$
- 扭转剪应力：$\tau = \frac{T}{W_p}$

**强度条件**：
- 第三强度理论：$\sqrt{\sigma^2 + 4\tau^2} \leq [\sigma]$
- 第四强度理论：$\sqrt{\sigma^2 + 3\tau^2} \leq [\sigma]$

#### 8.2.3 拉（压）弯扭组合

**应力叠加**：
$$\sigma = \sigma_N + \sigma_M = \frac{N}{A} + \frac{M}{W}$$
$$\tau = \tau_T = \frac{T}{W_p}$$

**强度条件**：
- 第三强度理论：$\sqrt{(\frac{N}{A} + \frac{M}{W})^2 + 4(\frac{T}{W_p})^2} \leq [\sigma]$
- 第四强度理论：$\sqrt{(\frac{N}{A} + \frac{M}{W})^2 + 3(\frac{T}{W_p})^2} \leq [\sigma]$

### 8.3 偏心拉压

<details>
<summary><strong>偏心拉压的推导</strong></summary>

**偏心距**：载荷作用线到截面形心的距离

**偏心拉压分析**：

1. **载荷分解**：
   - 轴向力：$N = F$
   - 弯矩：$M_y = F \cdot e_z$，$M_z = F \cdot e_y$

2. **应力叠加**：
   $$\sigma = \frac{N}{A} + \frac{M_y z}{I_y} + \frac{M_z y}{I_z}$$

3. **应力分布**：
   - 截面一侧：$\sigma_{max} = \frac{N}{A} + \frac{M_y}{W_y} + \frac{M_z}{W_z}$
   - 截面另一侧：$\sigma_{min} = \frac{N}{A} - \frac{M_y}{W_y} - \frac{M_z}{W_z}$

4. **中性轴**：
   $$\frac{N}{A} + \frac{M_y z}{I_y} + \frac{M_z y}{I_z} = 0$$

**截面核心**：
使截面不产生拉应力的偏心距范围称为截面核心。
</details>

## 9. 压杆稳定

### 9.1 稳定性的概念

**稳定性**：构件保持原有平衡状态的能力。

**失稳**：构件在载荷作用下突然发生较大变形而丧失承载能力的现象。

### 9.2 欧拉公式

<details>
<summary><strong>欧拉公式的推导</strong></summary>

**两端铰支压杆的临界载荷**：

1. **挠曲线微分方程**：
   $$EI\frac{d^2w}{dx^2} = -M = -F_{cr}w$$

2. **微分方程**：
   $$\frac{d^2w}{dx^2} + k^2w = 0$$
   
   其中 $k^2 = \frac{F_{cr}}{EI}$

3. **通解**：
   $$w = A\sin kx + B\cos kx$$

4. **边界条件**：
   - $x = 0$：$w = 0$ → $B = 0$
   - $x = l$：$w = 0$ → $A\sin kl = 0$

5. **临界条件**：
   $\sin kl = 0$，即 $kl = n\pi$（$n = 1, 2, 3, ...$）

6. **临界载荷**：
   $$F_{cr} = \frac{n^2\pi^2EI}{l^2}$$

**最小临界载荷**（$n = 1$）：
$$F_{cr} = \frac{\pi^2EI}{l^2}$$

**欧拉公式**：
$$F_{cr} = \frac{\pi^2EI}{(\mu l)^2}$$

其中 $\mu$ 为长度系数。
</details>

**欧拉公式**：
$$F_{cr} = \frac{\pi^2EI}{(\mu l)^2}$$

其中：
- $\mu$ - 长度系数
- $l$ - 压杆长度
- $I$ - 最小惯性矩

### 9.3 不同约束条件下的长度系数

| 约束条件 | 长度系数 $\mu$ | 临界载荷 $F_{cr}$ |
|---------|---------------|------------------|
| **两端铰支** | 1.0 | $\frac{\pi^2EI}{l^2}$ |
| **一端固定一端自由** | 2.0 | $\frac{\pi^2EI}{(2l)^2}$ |
| **两端固定** | 0.5 | $\frac{\pi^2EI}{(0.5l)^2}$ |
| **一端固定一端铰支** | 0.7 | $\frac{\pi^2EI}{(0.7l)^2}$ |

### 9.4 临界应力

**临界应力**：
$$\sigma_{cr} = \frac{F_{cr}}{A} = \frac{\pi^2E}{\lambda^2}$$

其中 $\lambda = \frac{\mu l}{i}$ 为柔度（长细比），$i = \sqrt{\frac{I}{A}}$ 为惯性半径。

### 9.5 欧拉公式的适用范围

<details>
<summary><strong>临界应力的分类</strong></summary>

**按柔度分类**：

1. **大柔度杆**（$\lambda \geq \lambda_p$）：
   $$\sigma_{cr} = \frac{\pi^2E}{\lambda^2}$$

2. **中柔度杆**（$\lambda_0 \leq \lambda < \lambda_p$）：
   $$\sigma_{cr} = a - b\lambda$$

3. **小柔度杆**（$\lambda < \lambda_0$）：
   $$\sigma_{cr} = \sigma_s$$（屈服强度）

**界限柔度**：
- $\lambda_p = \pi\sqrt{\frac{E}{\sigma_p}}$（比例极限对应的柔度）
- $\lambda_0 = \pi\sqrt{\frac{E}{\sigma_s}}$（屈服强度对应的柔度）

**经验公式**：
- 直线公式：$\sigma_{cr} = a - b\lambda$
- 抛物线公式：$\sigma_{cr} = \sigma_0 - b\lambda^2$
</details>

### 9.6 压杆稳定条件

**稳定条件**：
$$\sigma_{cr} = \frac{F_{cr}}{A} \geq n_{st}[\sigma]$$

或
$$F_{cr} \geq n_{st}F$$

其中 $n_{st}$ 为稳定安全系数。

## 10. 动载荷与疲劳强度

### 10.1 动载荷的概念

**动载荷**：大小、方向或作用点随时间变化的载荷。

**动应力**：由动载荷引起的应力。

### 10.2 动载荷的类型

| 类型 | 特点 | 例子 |
|------|------|------|
| **惯性载荷** | 构件作变速运动 | 起重机吊钩 |
| **冲击载荷** | 载荷在极短时间内作用 | 锤击、碰撞 |
| **交变载荷** | 载荷大小方向周期性变化 | 齿轮、连杆 |
| **随机载荷** | 载荷无确定性规律 | 汽车行驶 |

### 10.3 惯性载荷

**等加速直线运动**：
$$\sigma_d = \sigma_s(1 + \frac{a}{g})$$

其中：
- $\sigma_d$ - 动应力
- $\sigma_s$ - 静应力
- $a$ - 加速度
- $g$ - 重力加速度

### 10.4 冲击载荷

<details>
<summary><strong>冲击载荷的分析</strong></summary>

**机械能守恒**：
$$\frac{1}{2}mv^2 = \frac{1}{2}k\delta^2$$

其中：
- $m$ - 冲击物质量
- $v$ - 冲击速度
- $k$ - 被冲击构件刚度
- $\delta$ - 变形量

**冲击动荷因数**：
$$K_d = \sqrt{\frac{v^2}{g\delta_s}}$$

**冲击应力**：
$$\sigma_d = K_d\sigma_s$$

**弹性体冲击**：
- 弹性体：$K_d = 1 + \sqrt{1 + \frac{2h}{\delta_s}}$
- 塑性体：$K_d = 1 + \sqrt{1 + \frac{2h}{\delta_s}}$（近似）

其中 $h$ - 冲击高度。
</details>

### 10.5 疲劳强度

#### 10.5.1 疲劳的概念

**疲劳破坏**：构件在交变载荷作用下，经过一定循环次数后发生的突然断裂。

**疲劳过程**：
1. **裂纹萌生**：应力集中处产生微裂纹
2. **裂纹扩展**：裂纹逐渐扩展
3. **突然断裂**：剩余截面不足以承受载荷

#### 10.5.2 交变应力的参数

**循环特征**：
$$r = \frac{\sigma_{min}}{\sigma_{max}}$$

**应力幅**：
$$\sigma_a = \frac{\sigma_{max} - \sigma_{min}}{2}$$

**平均应力**：
$$\sigma_m = \frac{\sigma_{max} + \sigma_{min}}{2}$$

**应力范围**：
$$\Delta\sigma = \sigma_{max} - \sigma_{min}$$

#### 10.5.3 疲劳极限

<details>
<summary><strong>疲劳极限的概念</strong></summary>

**疲劳极限** $\sigma_r$：材料在交变载荷作用下，能承受无限次循环而不发生疲劳破坏的最大应力。

**持久疲劳极限**：当循环次数 $N \to \infty$ 时的疲劳极限。

**疲劳曲线**（S-N曲线）：
$$\sigma^N = C$$

其中 $N$ 为循环次数，$C$ 为常数。

**常用对数形式**：
$$\log\sigma = \log C - \frac{1}{m}\log N$$

其中 $m$ 为材料常数。
</details>

#### 10.5.4 影响疲劳强度的因素

| 因素 | 影响 | 提高措施 |
|------|------|---------|
| **应力集中** | 显著降低疲劳强度 | 优化结构设计 |
| **表面质量** | 表面缺陷降低强度 | 表面强化处理 |
| **尺寸效应** | 尺寸增大强度降低 | 合理选材 |
| **加载频率** | 高频加载影响较小 | 控制加载频率 |
| **环境因素** | 腐蚀环境降低强度 | 防护处理 |

#### 10.5.5 疲劳强度计算

**无限寿命设计**：
$$\sigma_{max} \leq \frac{\sigma_{-1}}{n_f}$$

其中：
- $\sigma_{-1}$ - 对称循环疲劳极限
- $n_f$ - 疲劳安全系数

**有限寿命设计**：
$$\sigma_{max} \leq \frac{\sigma_r}{n_f}$$

其中 $\sigma_r$ 为有限寿命疲劳极限。

#### 10.5.6 疲劳强度安全系数

<details>
<summary><strong>疲劳安全系数的计算</strong></summary>

**对称循环**：
$$n_f = \frac{\sigma_{-1}}{\sigma_{max}}$$

**非对称循环**：
$$n_f = \frac{\sigma_{-1}}{\sigma_a + \psi\sigma_m}$$

其中 $\psi = \frac{2\sigma_{-1}}{\sigma_0} - 1$ 为材料常数。

**考虑应力集中**：
$$n_f = \frac{\sigma_{-1}}{k_t\sigma_a + \psi\sigma_m}$$

其中 $k_t$ 为有效应力集中系数。

**考虑尺寸和表面系数**：
$$n_f = \frac{\sigma_{-1}}{k_t k_s k_f \sigma_a + \psi\sigma_m}$$

其中：
- $k_s$ - 尺寸系数
- $k_f$ - 表面系数
</details>
