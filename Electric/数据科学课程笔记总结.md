## 统计学基础

### 1.1 概率分布

#### 常见概率分布对比表

| 分布类型 | 概率密度函数 | 参数 | 均值 | 方差 | 应用场景 |
|---------|-------------|------|------|------|----------|
| 正态分布 $N(\mu,\sigma^2)$ | $f(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu, \sigma$ | $\mu$ | $\sigma^2$ | 连续数据，自然现象 |
| 泊松分布 $Pois(\lambda)$ | $P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$ | $\lambda$ | $\lambda$ | 计数数据，事件发生频率 |
| 二项分布 $Bin(n,p)$ | $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$ | $n, p$ | $np$ | $np(1-p)$ | 伯努利试验，独立事件 |
| 指数分布 $Exp(\lambda)$ | $f(x) = \lambda e^{-\lambda x}$ | $\lambda$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ | 等待时间，寿命分析 |

#### 中心极限定理
<details>
<parameter name="summary>点击展开：中心极限定理推导</summary>

**定理陈述：**
设 $X_1, X_2, ..., X_n$ 为独立同分布的随机变量，期望为 $\mu$，方差为 $\sigma^2$，则当 $n \to \infty$ 时：

$$\frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$$

**推导过程：**

1. **特征函数法：**
   - 设 $X_i$ 的特征函数为 $\phi_X(t)$
   - 标准化变量 $Y_i = \frac{X_i - \mu}{\sigma}$
   - 独立同分布情况下，$\sum_{i=1}^n Y_i$ 的特征函数为 $[\phi_Y(t)]^n$

2. **泰勒展开：**
   $$\phi_Y(t) = 1 + it \cdot E[Y] + \frac{(it)^2}{2!}E[Y^2] + o(t^2) = 1 - \frac{t^2}{2} + o(t^2)$$

3. **极限计算：**
   $$[\phi_Y(t)]^n = \left(1 - \frac{t^2}{2} + o(t^2)\right)^n \xrightarrow{n\to\infty} e^{-t^2/2}$$

4. **结论：**
   特征函数收敛到标准正态分布的特征函数，因此分布收敛到 $N(0,1)$
</details>

### 1.2 假设检验

#### 常用假设检验方法对比

| 检验类型 | 适用条件 | 检验统计量 | 拒绝域 | 功效函数 |
|---------|---------|-----------|--------|----------|
| t检验 | 正态分布，总体方差未知 | $t = \frac{\bar{X} - \mu_0}{s/\sqrt{n}}$ | $\|t\| > t_{\alpha/2}(n-1)$ | $P(\text{拒绝}H_0\|H_1\text{为真})$ |
| 卡方检验 | 分类数据 | $\chi^2 = \sum\frac{(O_i - E_i)^2}{E_i}$ | $\chi^2 > \chi^2_{\alpha}(df)$ | 依赖于自由度 |
| F检验 | 方差齐性 | $F = \frac{s_1^2}{s_2^2}$ | $F > F_{\alpha}(n_1-1,n_2-1)$ | $F$分布的右尾概率 |

#### p值计算
<details>
<parameter name="summary>点击展开：p值计算详解</summary>

**p值的定义：**
在原假设 $H_0$ 为真的条件下，观察到当前或更极端样本结果的概率。

**计算步骤：**

1. **确定检验统计量：**
   - 样本均值：$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$
   - 样本方差：$s^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$

2. **标准化：**
   $$t = \frac{\bar{X} - \mu_0}{s/\sqrt{n}} \sim t(n-1)$$

3. **计算p值：**
   - 双侧检验：$p = 2P(T > |t|)$，其中 $T \sim t(n-1)$
   - 单侧检验：$p = P(T > t)$ 或 $p = P(T < t)$

**实例计算：**
设 $n=25$，$\bar{X}=102$，$\mu_0=100$，$s=8$，则：
$$t = \frac{102-100}{8/\sqrt{25}} = \frac{2}{1.6} = 1.25$$
查t分布表：$P(|T| > 1.25) = 2 \times 0.1126 = 0.2252$
</details>

#### 缺失值处理方法

**1. 删除法**
```python
# 删除含有缺失值的行
df.dropna(axis=0)

# 删除含有缺失值的列
df.dropna(axis=1)

# 删除缺失值比例超过阈值的行
df.dropna(thresh=len(df.columns)*0.8)
```

**2. 插补法**
<details>
<parameter name="summary>点击展开：插补方法详解</summary>

**均值插补：**
```python
df['column'].fillna(df['column'].mean())
```
- 优点：简单快速
- 缺点：改变分布，降低方差

**中位数插补：**
```python
df['column'].fillna(df['column'].median())
```
- 优点：对异常值鲁棒
- 缺点：可能偏离真实值

**众数插补：**
```python
df['column'].fillna(df['column'].mode()[0])
```
- 适用于分类变量

**KNN插补：**
```python
from sklearn.impute import KNNImputer
imputer = KNNImputer(n_neighbors=5)
df_imputed = imputer.fit_transform(df)
```
- 考虑邻近样本的相似性

**多重插补（MI）：**
```python
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer
imputer = IterativeImputer()
df_imputed = imputer.fit_transform(df)
```
- 考虑不确定性，多次插补
</details>

### 2.2 数据变换

#### 标准化方法对比

| 方法 | 公式 | 适用场景 | 特点 |
|------|------|---------|------|
| Z-score标准化 | $z = \frac{x - \mu}{\sigma}$ | 正态分布数据 | 保持分布形状 |
| Min-Max标准化 | $x' = \frac{x - x_{min}}{x_{max} - x_{min}}$ | 范围已知 | 映射到[0,1] |
| 鲁棒标准化 | $x' = \frac{x - median}{IQR}$ | 含有异常值 | 对异常值鲁棒 |

#### Box-Cox变换
<details>
<parameter name="summary>点击展开：Box-Cox变换推导</summary>

**变换公式：**
$$y(\lambda) = \begin{cases}
\frac{y^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0 \\
\ln(y) & \text{if } \lambda = 0
\end{cases}$$

**最优参数选择：**
使用最大似然估计选择 $\lambda$：

1. **似然函数：**
   $$L(\lambda) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(y_i(\lambda) - \mu_\lambda)^2}{2\sigma_\lambda^2}\right)$$

2. **对数似然：**
   $$\ln L(\lambda) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma_\lambda^2) - \frac{1}{2\sigma_\lambda^2}\sum_{i=1}^n(y_i(\lambda) - \mu_\lambda)^2$$

3. **优化：**
   $$\hat{\lambda} = \arg\max_{\lambda} \ln L(\lambda)$$

**Python实现：**
```python
from scipy import stats
# 寻找最优lambda
transformed_data, lambda_optimal = stats.boxcox(original_data)
print(f"最优lambda: {lambda_optimal:.4f}")
```
</details>

### 3.2 线性回归

#### 最小二乘估计推导
<details>
<parameter name="summary>点击展开：最小二乘估计详细推导</summary>

**问题设定：**
给定数据集 $\{(x_i, y_i)\}_{i=1}^n$，寻找线性关系：
$$y_i = \beta_0 + \beta_1 x_{i1} + \beta_2 x_{i2} + ... + \beta_p x_{ip} + \epsilon_i$$

矩阵形式：$\mathbf{y} = \mathbf{X}\boldsymbol{\beta} + \boldsymbol{\epsilon}$

其中：
- $\mathbf{y} = [y_1, y_2, ..., y_n]^T$ (n×1)
- $\mathbf{X}$ (n×(p+1)) 包含截距项
- $\boldsymbol{\beta} = [\beta_0, \beta_1, ..., \beta_p]^T$ ((p+1)×1)
- $\boldsymbol{\epsilon}$ (n×1) 误差项

**最小二乘目标：**
$$\min_{\boldsymbol{\beta}} \sum_{i=1}^n \epsilon_i^2 = \min_{\boldsymbol{\beta}} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2$$

**求导过程：**

1. **目标函数：**
   $$S(\boldsymbol{\beta}) = (\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^T(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})$$

2. **展开：**
   $$S(\boldsymbol{\beta}) = \mathbf{y}^T\mathbf{y} - 2\boldsymbol{\beta}^T\mathbf{X}^T\mathbf{y} + \boldsymbol{\beta}^T\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$

3. **对$\boldsymbol{\beta}$求导：**
   $$\frac{\partial S}{\partial \boldsymbol{\beta}} = -2\mathbf{X}^T\mathbf{y} + 2\mathbf{X}^T\mathbf{X}\boldsymbol{\beta}$$

4. **令导数为0：**
   $$\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \mathbf{X}^T\mathbf{y}$$

5. **解得：**
   $$\hat{\boldsymbol{\beta}} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}$$

**性质证明：**

*无偏性：*
$$E[\hat{\boldsymbol{\beta}}] = E[(\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T E[\mathbf{y}] = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{X}\boldsymbol{\beta} = \boldsymbol{\beta}$$

*方差：*
$$Var(\hat{\boldsymbol{\beta}}) = \sigma^2(\mathbf{X}^T\mathbf{X})^{-1}$$
</details>

#### 正则化回归

**Ridge回归（L2正则化）**
$$\min_{\boldsymbol{\beta}} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda\|\boldsymbol{\beta}\|^2$$

解：$\hat{\boldsymbol{\beta}}_{ridge} = (\mathbf{X}^T\mathbf{X} + \lambda\mathbf{I})^{-1}\mathbf{X}^T\mathbf{y}$

**Lasso回归（L1正则化）**
$$\min_{\boldsymbol{\beta}} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda\|\boldsymbol{\beta}\|_1$$

**Elastic Net**
$$\min_{\boldsymbol{\beta}} \|\mathbf{y} - \mathbf{X}\boldsymbol{\beta}\|^2 + \lambda_1\|\boldsymbol{\beta}\|_1 + \lambda_2\|\boldsymbol{\beta}\|^2$$

### 3.3 逻辑回归

#### 逻辑回归推导
<details>
<summary>点击展开：逻辑回归最大似然估计推导</summary>

**模型设定：**
$$P(Y=1|\mathbf{x}) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + ... + \beta_p x_p)}} = \frac{e^{\mathbf{x}^T\boldsymbol{\beta}}}{1 + e^{\mathbf{x}^T\boldsymbol{\beta}}}$$

$$P(Y=0|\mathbf{x}) = \frac{1}{1 + e^{\mathbf{x}^T\boldsymbol{\beta}}}$$

**似然函数：**
对于独立观测：
$$L(\boldsymbol{\beta}) = \prod_{i=1}^n [p_i]^{y_i}[1-p_i]^{1-y_i}$$

其中 $p_i = P(Y_i=1|\mathbf{x}_i) = \frac{e^{\mathbf{x}_i^T\boldsymbol{\beta}}}{1 + e^{\mathbf{x}_i^T\boldsymbol{\beta}}}$

**对数似然：**
$$\ell(\boldsymbol{\beta}) = \sum_{i=1}^n [y_i \ln p_i + (1-y_i)\ln(1-p_i)]$$

$$= \sum_{i=1}^n \left[y_i \ln\left(\frac{e^{\mathbf{x}_i^T\boldsymbol{\beta}}}{1 + e^{\mathbf{x}_i^T\boldsymbol{\beta}}}\right) + (1-y_i)\ln\left(\frac{1}{1 + e^{\mathbf{x}_i^T\boldsymbol{\beta}}}\right)\right]$$

$$= \sum_{i=1}^n \left[y_i \mathbf{x}_i^T\boldsymbol{\beta} - \ln(1 + e^{\mathbf{x}_i^T\boldsymbol{\beta}})\right]$$

**梯度计算：**
$$\frac{\partial \ell}{\partial \boldsymbol{\beta}} = \sum_{i=1}^n \left[y_i \mathbf{x}_i - \frac{e^{\mathbf{x}_i^T\boldsymbol{\beta}}}{1 + e^{\mathbf{x}_i^T\boldsymbol{\beta}}}\mathbf{x}_i\right] = \sum_{i=1}^n (y_i - p_i)\mathbf{x}_i$$

**牛顿-拉夫森方法：**
$$\boldsymbol{\beta}^{(t+1)} = \boldsymbol{\beta}^{(t)} - \left[\frac{\partial^2 \ell}{\partial \boldsymbol{\beta}\partial \boldsymbol{\beta}^T}\right]^{-1}\frac{\partial \ell}{\partial \boldsymbol{\beta}}$$

其中Hessian矩阵：
$$\frac{\partial^2 \ell}{\partial \boldsymbol{\beta}\partial \boldsymbol{\beta}^T} = -\sum_{i=1}^n p_i(1-p_i)\mathbf{x}_i\mathbf{x}_i^T$$
</details>

### 3.4 决策树

#### ID3算法
<details>
<summary>点击展开：ID3算法信息增益计算</summary>

**信息熵定义：**
$$H(Y) = -\sum_{k=1}^K p_k \log_2 p_k$$

其中 $p_k$ 是类别k的概率。

**条件熵：**
$$H(Y|X) = -\sum_{j=1}^J p_j \sum_{k=1}^K p_{k|j} \log_2 p_{k|j}$$

**信息增益：**
$$IG(X) = H(Y) - H(Y|X)$$

**实例计算：**
设数据集包含10个样本，6个正例，4个负例。

1. **根节点熵：**
   $$H(Y) = -\frac{6}{10}\log_2\frac{6}{10} - \frac{4}{10}\log_2\frac{4}{10} = 0.971$$

2. **按特征A分割：**
   - A=1: 4个样本（3正1负）
   - A=0: 6个样本（3正3负）

   $$H(Y|A) = \frac{4}{10}H(Y|A=1) + \frac{6}{10}H(Y|A=0)$$
   $$= \frac{4}{10}(-\frac{3}{4}\log_2\frac{3}{4} - \frac{1}{4}\log_2\frac{1}{4}) + \frac{6}{10}(-\frac{3}{6}\log_2\frac{3}{6} - \frac{3}{6}\log_2\frac{3}{6})$$
   $$= \frac{4}{10}(0.811) + \frac{6}{10}(1.0) = 0.924$$

3. **信息增益：**
   $$IG(A) = 0.971 - 0.924 = 0.047$$

选择信息增益最大的特征作为分裂节点。
</details>

#### CART算法

**基尼指数：**
$$Gini(Y) = 1 - \sum_{k=1}^K p_k^2$$

**回归树最小化：**
$$\min_{s,j} \left[\min_{c_1} \sum_{x_i \in R_1(j,s)} (y_i - c_1)^2 + \min_{c_2} \sum_{x_i \in R_2(j,s)} (y_i - c_2)^2\right]$$

最优分割：$c_1 = mean(y_i|x_i \in R_1)$，$c_2 = mean(y_i|x_i \in R_2)$

### 3.5 支持向量机

#### SVM优化问题推导
<details>
<parameter name="summary>点击展开：SVM优化问题详细推导</summary>

**线性可分情况：**

1. **间隔定义：**
   对于超平面 $\mathbf{w}^T\mathbf{x} + b = 0$，函数间隔为：
   $$\hat{\gamma}_i = y_i(\mathbf{w}^T\mathbf{x}_i + b)$$

   几何间隔为：
   $$\gamma_i = \frac{\hat{\gamma}_i}{\|\mathbf{w}\|}$$

2. **优化目标：**
   $$\max_{\mathbf{w},b} \frac{2}{\|\mathbf{w}\|} \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1$$

   等价于：
   $$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1$$

3. **拉格朗日函数：**
   $$\mathcal{L}(\mathbf{w},b,\boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|^2 - \sum_{i=1}^n \alpha_i[y_i(\mathbf{w}^T\mathbf{x}_i + b) - 1]$$

4. **KKT条件：**
   - 原始约束：$y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1$
   - 对偶约束：$\alpha_i \geq 0$
   - 互补松弛：$\alpha_i[y_i(\mathbf{w}^T\mathbf{x}_i + b) - 1] = 0$

**软间隔SVM：**
引入松弛变量 $\xi_i \geq 0$：
$$\min_{\mathbf{w},b,\boldsymbol{\xi}} \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_{i=1}^n \xi_i$$

约束条件：
$$y_i(\mathbf{w}^T\mathbf{x}_i + b) \geq 1 - \xi_i$$
$$\xi_i \geq 0$$

**核技巧：**
通过核函数 $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i)^T\phi(\mathbf{x}_j)$，在特征空间中计算内积：
$$\max_{\boldsymbol{\alpha}} \sum_{i=1}^n \alpha_i - \frac{1}{2}\sum_{i=1}^n\sum_{j=1}^n \alpha_i\alpha_j y_i y_j K(\mathbf{x}_i, \mathbf{x}_j)$$

常见核函数：
- 线性核：$K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T\mathbf{x}_j$
- 多项式核：$K(\mathbf{x}_i, \mathbf{x}_j) = (\mathbf{x}_i^T\mathbf{x}_j + 1)^d$
- RBF核：$K(\mathbf{x}_i, \mathbf{x}_j) = \exp(-\gamma\|\mathbf{x}_i - \mathbf{x}_j\|^2)$
</details>

#### Random Forest算法
<details>
<summary>点击展开：Random Forest详细原理</summary>

**算法步骤：**

1. **Bootstrap采样：**
   从原始数据集D中有放回地随机抽取m个样本子集 $D_1, D_2, ..., D_m$

2. **随机特征选择：**
   对于每个节点，随机选择k个特征子集进行最优分割

3. **构建决策树：**
   对每个样本子集 $D_i$，使用CART算法构建决策树 $T_i$

4. **集成预测：**
   - 分类：投票法 $y = \arg\max_{c} \sum_{i=1}^m I(T_i(\mathbf{x}) = c)$
   - 回归：平均法 $y = \frac{1}{m}\sum_{i=1}^m T_i(\mathbf{x})$

**误差分析：**

设单棵树的泛化误差为 $E_1$，则m棵树组成的森林的泛化误差为：
$$E_m \leq \bar{\rho} \cdot \frac{E_1}{m} + \frac{\bar{s}^2(1-\bar{\rho}^2)}{m}$$

其中：
- $\bar{\rho}$：树间相关系数的平均值
- $\bar{s}$：单棵树的平均强度
- 当 $\bar{\rho} < 1$ 且 $m \to \infty$ 时，$E_m \to 0$

**特征重要性：**
$$Importance(X_j) = \frac{1}{m}\sum_{i=1}^m \sum_{t \in T_i} I(j \in splits_t) \cdot p_t \cdot \Delta_{impurity}$$

其中 $p_t$ 是到达节点t的样本比例，$\Delta_{impurity}$ 是分割带来的不纯度减少。
</details>

#### AdaBoost算法
<details>
<summary>点击展开：AdaBoost权重更新推导</summary>

**算法流程：**

1. **初始化权重：**
   $$D_1(i) = \frac{1}{n}, \quad i = 1,2,...,n$$

2. **训练弱分类器：**
   在权重分布 $D_t$ 下训练分类器 $h_t$

3. **计算误差率：**
   $$\epsilon_t = P_{i \sim D_t}[h_t(x_i) \neq y_i] = \sum_{i: h_t(x_i) \neq y_i} D_t(i)$$

4. **计算分类器权重：**
   $$\alpha_t = \frac{1}{2}\ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$$

5. **更新权重：**
   $$D_{t+1}(i) = \frac{D_t(i)\exp(-\alpha_t y_i h_t(x_i))}{Z_t}$$

   其中 $Z_t$ 是归一化因子：
   $$Z_t = 2\sqrt{\epsilon_t(1-\epsilon_t)}$$

**理论分析：**

*权重更新公式推导：*

对于正确分类的样本（$y_i h_t(x_i) = 1$）：
$$D_{t+1}(i) = \frac{D_t(i)\exp(-\alpha_t)}{Z_t} = \frac{D_t(i)\sqrt{\frac{\epsilon_t}{1-\epsilon_t}}}{Z_t}$$

对于错误分类的样本（$y_i h_t(x_i) = -1$）：
$$D_{t+1}(i) = \frac{D_t(i)\exp(\alpha_t)}{Z_t} = \frac{D_t(i)\sqrt{\frac{1-\epsilon_t}{\epsilon_t}}}{Z_t}$$

*指数损失函数：*
AdaBoost的优化目标是最小化指数损失：
$$\min_{f} \sum_{i=1}^n \exp(-y_i f(x_i))$$

其中 $f(x) = \sum_{t=1}^T \alpha_t h_t(x)$。

对 $f(x)$ 求导并令导数为0，可得到权重更新公式。
</details>

## 深度学习

### 4.1 神经网络基础

#### 反向传播算法
<details>
<summary>点击展开：反向传播算法详细推导</summary>

**网络结构：**
设L层神经网络，第l层有 $n_l$ 个神经元，权重矩阵 $\mathbf{W}^{(l)}$，偏置 $\mathbf{b}^{(l)}$，激活函数 $g^{(l)}$。

**前向传播：**
$$\mathbf{z}^{(l)} = \mathbf{W}^{(l)}\mathbf{a}^{(l-1)} + \mathbf{b}^{(l)}$$
$$\mathbf{a}^{(l)} = g^{(l)}(\mathbf{z}^{(l)})$$

其中 $\mathbf{a}^{(0)} = \mathbf{x}$（输入）。

**损失函数：**
$$J(\mathbf{W},\mathbf{b}) = \frac{1}{m}\sum_{i=1}^m J^{(i)}(\mathbf{W},\mathbf{b}) + \frac{\lambda}{2m}\sum_{l=1}^L \|\mathbf{W}^{(l)}\|_F^2$$

其中 $J^{(i)}$ 是第i个样本的损失，$\lambda$ 是正则化参数。

**梯度计算：**

1. **输出层梯度：**
   $$\delta^{(L)} = \nabla_{\mathbf{a}^{(L)}}J \odot g'^{(L)}(\mathbf{z}^{(L)})$$

2. **隐藏层梯度（反向传播）：**
   $$\delta^{(l)} = ((\mathbf{W}^{(l+1)})^T\delta^{(l+1)}) \odot g'^{(l)}(\mathbf{z}^{(l)})$$

3. **权重和偏置梯度：**
   $$\nabla_{\mathbf{W}^{(l)}}J = \delta^{(l)}(\mathbf{a}^{(l-1)})^T + \frac{\lambda}{m}\mathbf{W}^{(l)}$$
   $$\nabla_{\mathbf{b}^{(l)}}J = \delta^{(l)}$$

**矩阵形式：**
设 $\mathbf{A}^{(l)} = [\mathbf{a}^{(1)}, \mathbf{a}^{(2)}, ..., \mathbf{a}^{(m)}]$，则：
$$\nabla_{\mathbf{W}^{(l)}}J = \frac{1}{m}\mathbf{\delta}^{(l)}(\mathbf{A}^{(l-1)})^T + \frac{\lambda}{m}\mathbf{W}^{(l)}$$

其中 $\mathbf{\delta}^{(l)} = [\delta^{(l)}_1, \delta^{(l)}_2, ..., \delta^{(l)}_m]$。
</details>

### 4.2 卷积神经网络

#### 卷积操作
<details>
<summary>点击展开：卷积操作数学原理</summary>

**一维卷积：**
$$(f * g)[n] = \sum_{m=-\infty}^{\infty} f[m]g[n-m]$$

**二维卷积：**
$$(f * g)[i,j] = \sum_{m=-\infty}^{\infty}\sum_{n=-\infty}^{\infty} f[m,n] \cdot g[i-m,j-n]$$

**卷积神经网络中的卷积：**
实际上使用交叉相关：
$$(I * K)[i,j] = \sum_{m=0}^{k_h-1}\sum_{n=0}^{k_w-1} I[i+m,j+n] \cdot K[m,n]$$

其中：
- $I$：输入图像，尺寸 $(H_{in}, W_{in})$
- $K$：卷积核，尺寸 $(k_h, k_w)$
- 输出尺寸：$(H_{out}, W_{out}) = (H_{in} - k_h + 1, W_{in} - k_w + 1)$

**填充（Padding）：**
- Valid：不填充，输出尺寸减小
- Same：填充使输出尺寸与输入相同
  $$pad_h = \lfloor k_h/2 \rfloor, \quad pad_w = \lfloor k_w/2 \rfloor$$

**步幅（Stride）：**
$$H_{out} = \lfloor \frac{H_{in} + 2pad_h - k_h}{stride_h} \rfloor + 1$$

**多通道卷积：**
$$(I * K)[i,j] = \sum_{c=1}^{C_{in}} \sum_{m=0}^{k_h-1}\sum_{n=0}^{k_w-1} I_c[i+m,j+n] \cdot K_c[m,n] + b$$

其中 $C_{in}$ 是输入通道数。
</details>

### 4.3 循环神经网络

#### LSTM网络
<details>
<summary>点击展开：LSTM单元详细推导</summary>

**LSTM单元结构：**

遗忘门：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$
输入门：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$
候选值：$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$
细胞状态：$C_t = f_t * C_{t-1} + i_t * \tilde{C}_t$
输出门：$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$
隐藏状态：$h_t = o_t * \tanh(C_t)$

**矩阵形式：**
设 $X_t = [h_{t-1}, x_t]^T$，则：
$$\begin{bmatrix}
i_t \\
f_t \\
o_t \\
\tilde{C}_t
\end{bmatrix} = 
\begin{bmatrix}
\sigma \\
\sigma \\
\sigma \\
\tanh
\end{bmatrix}
\begin{bmatrix}
W_i \\
W_f \\
W_o \\
W_C
\end{bmatrix} X_t + 
\begin{bmatrix}
b_i \\
b_f \\
b_o \\
b_C
\end{bmatrix}$$

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
$$h_t = o_t \odot \tanh(C_t)$$

**梯度传播：**

通过时间反向传播（BPTT）：

1. **隐藏状态梯度：**
   $$\frac{\partial h_t}{\partial h_{t-1}} = \frac{\partial h_t}{\partial C_t} \frac{\partial C_t}{\partial h_{t-1}} + \frac{\partial h_t}{\partial o_t} \frac{\partial o_t}{\partial h_{t-1}}$$

2. **细胞状态梯度：**
   $$\frac{\partial C_t}{\partial C_{t-1}} = f_t$$

3. **梯度消失问题：**
   $$\frac{\partial C_t}{\partial C_{t-1}} = \prod_{k=1}^t f_k$$

   当 $f_k < 1$ 时，连乘会导致梯度消失。LSTM通过门控机制缓解这个问题。
</details>

```python
def target_encode(train_series, train_target, test_series, smoothing=1):
    """
    Target编码实现
    """
    # 计算全局平均值
    global_mean = train_target.mean()
    
    # 计算每个类别的统计值
    category_stats = train_series.groupby(train_series).agg({
        train_target.name: ['count', 'mean']
    }).reset_index()
    
    category_stats.columns = ['category', 'count', 'mean']
    
    # 应用贝叶斯平滑
    category_stats['smoothed_mean'] = (
        (category_stats['count'] * category_stats['mean'] + global_mean * smoothing) /
        (category_stats['count'] + smoothing)
    )
    
    # 创建编码映射
    encode_map = dict(zip(category_stats['category'], category_stats['smoothed_mean']))
    
    # 编码训练和测试数据
    train_encoded = train_series.map(encode_map).fillna(global_mean)
    test_encoded = test_series.map(encode_map).fillna(global_mean)
    
    return train_encoded, test_encoded
```

```python
def loo_encode(train_series, train_target, test_series):
    """
    Leave-One-Out编码，避免数据泄露
    """
    global_mean = train_target.mean()
    encoded_values = []
    
    for i in range(len(train_series)):
        # 排除当前样本计算平均值
        mask = train_series.index != i
        category_mean = train_target[mask & (train_series == train_series.iloc[i])].mean()

    test_encoded = test_series.map(
        train_series.groupby(train_series).apply(
            lambda x: train_target[train_series == x.name].mean()
        )
    ).fillna(global_mean)
    
    return pd.Series(encoded_values, index=train_series.index), test_encoded
```

### 6.3 特征降维

#### 主成分分析（PCA）
<details>
<summary>点击展开：PCA数学原理推导</summary>

**问题设定：**
给定数据矩阵 $X \in \mathbb{R}^{n \times p}$，寻找线性变换 $W \in \mathbb{R}^{p \times k}$，使得：
$$Z = XW$$

其中 $Z \in \mathbb{R}^{n \times k}$ 是降维后的数据。

**目标函数：**
最小化重构误差：
$$\min_{W} \|X - XWW^T\|^2_F$$

**等价形式：**
$$\max_{W} \text{tr}(W^T X^T X W) \quad \text{s.t.} \quad W^T W = I$$

**求解过程：**

1. **中心化数据：**
   $$\tilde{X} = X - \mathbf{1}\mu^T$$
   其中 $\mu = \frac{1}{n}X^T\mathbf{1}$ 是均值向量。

2. **协方差矩阵：**
   $$C = \frac{1}{n-1}\tilde{X}^T\tilde{X}$$

3. **特征值分解：**
   $$C = V\Lambda V^T$$

   其中：
   - $V = [v_1, v_2, ..., v_p]$ 是特征向量矩阵
   - $\Lambda = \text{diag}(\lambda_1, \lambda_2, ..., \lambda_p)$ 是特征值矩阵

4. **主成分：**
   $$W = [v_1, v_2, ..., v_k]$$

5. **降维数据：**
   $$Z = \tilde{X}W$$

**解释方差：**
第i个主成分的解释方差比例为：
$$\frac{\lambda_i}{\sum_{j=1}^p \lambda_j}$$

累积解释方差：
$$\text{Cumulative Variance Ratio} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{j=1}^p \lambda_j}$$

**Python实现：**
```python
from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler

# 标准化
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA降维
pca = PCA(n_components=0.95)  # 保留95%的方差
X_pca = pca.fit_transform(X_scaled)

print(f"主成分数量: {pca.n_components_}")
print(f"解释方差比例: {pca.explained_variance_ratio_}")
print(f"累积解释方差: {pca.explained_variance_ratio_.cumsum()}")
```
</details>

## 模型评估与选择

### 7.1 评估指标

#### 分类指标对比

| 指标 | 公式 | 适用场景 | 特点 |
|------|------|---------|------|
| 准确率 | $\frac{TP+TN}{TP+TN+FP+FN}$ | 类别平衡 | 对不平衡数据敏感 |
| 精确率 | $\frac{TP}{TP+FP}$ | 关注假阳性 | 控制误报率 |
| 召回率 | $\frac{TP}{TP+FN}$ | 关注假阴性 | 控制漏报率 |
| F1分数 | $2 \times \frac{Precision \times Recall}{Precision + Recall}$ | 综合指标 | 平衡精确率和召回率 |
| AUC | $\int_0^1 TPR(FPR^{-1}(x))dx$ | 排序质量 | 不受阈值影响 |

#### 回归指标
<details>
<summary>点击展开：回归指标详细计算</summary>

**均方误差（MSE）：**
$$MSE = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2$$

```python
from sklearn.metrics import mean_squared_error
mse = mean_squared_error(y_true, y_pred)
```

**均方根误差（RMSE）：**
$$RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^n (y_i - \hat{y}_i)^2}$$

```python
rmse = np.sqrt(mse)
```

**平均绝对误差（MAE）：**
$$MAE = \frac{1}{n}\sum_{i=1}^n |y_i - \hat{y}_i|$$

```python
from sklearn.metrics import mean_absolute_error
mae = mean_absolute_error(y_true, y_pred)
```

**决定系数（R²）：**
$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum_{i=1}^n (y_i - \hat{y}_i)^2}{\sum_{i=1}^n (y_i - \bar{y})^2}$$

```python
from sklearn.metrics import r2_score
r2 = r2_score(y_true, y_pred)
```

**调整R²：**
$$R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}$$

其中p是特征数量，n是样本数量。

**平均绝对百分比误差（MAPE）：**
$$MAPE = \frac{100\%}{n}\sum_{i=1}^n \left|\frac{y_i - \hat{y}_i}{y_i}\right|$$

```python
def mape(y_true, y_pred):
    return np.mean(np.abs((y_true - y_pred) / y_true)) * 100
```

**选择建议：**
- MSE/RMSE：对大误差敏感，适合连续值预测
- MAE：对异常值鲁棒，适合有离群点的数据
- R²：衡量模型解释能力，适合模型比较
- MAPE：相对误差，适合不同尺度的比较
</details>

```python
from sklearn.model_selection import BaseCrossValidator

class GroupKFold(BaseCrossValidator):
    def __init__(self, n_splits=5):
        self.n_splits = n_splits
    
    def split(self, X, y=None, groups=None):
        if groups is None:
            raise ValueError("groups参数不能为空")
        
        groups = np.array(groups)
        unique_groups = np.unique(groups)
        n_groups = len(unique_groups)
        
        # 确保每个fold都有足够的组
        if n_groups < self.n_splits:
            raise ValueError(f"组数量({n_groups})不能少于折数({self.n_splits})")
        
        for i in range(self.n_splits):
            # 选择验证集的组
            test_groups = unique_groups[i::self.n_splits]
            test_mask = np.isin(groups, test_groups)
            
            train_indices = np.where(~test_mask)[0]
            test_indices = np.where(test_mask)[0]
            
            yield train_indices, test_indices

# 使用示例
group_kfold = GroupKFold(n_splits=5)
scores = cross_val_score(model, X, y, cv=group_kfold, groups=groups)
```

#### 贝叶斯优化
<details>
<summary>点击展开：贝叶斯优化原理</summary>

**高斯过程回归：**
假设目标函数 $f(\mathbf{x})$ 服从高斯过程：
$$f(\mathbf{x}) \sim \mathcal{GP}(m(\mathbf{x}), k(\mathbf{x}, \mathbf{x}'))$$

其中：
- $m(\mathbf{x})$ 是均值函数，通常取常数
- $k(\mathbf{x}, \mathbf{x}')$ 是协方差函数（核函数）

**RBF核函数：**
$$k(\mathbf{x}, \mathbf{x}') = \sigma^2 \exp\left(-\frac{\|\mathbf{x} - \mathbf{x}'\|^2}{2l^2}\right)$$

**获取函数（Acquisition Function）：**

1. **期望改进（Expected Improvement, EI）：**
   $$EI(\mathbf{x}) = E[\max(0, f_{best} - f(\mathbf{x}))]$$
   
   其中 $f_{best}$ 是当前最优值。

2. **改进概率（Probability of Improvement, PI）：**
   $$PI(\mathbf{x}) = P(f(\mathbf{x}) \geq f_{best} + \xi)$$
   
   其中 $\xi$ 是探索参数。

3. **置信上界（Upper Confidence Bound, UCB）：**
   $$UCB(\mathbf{x}) = \mu(\mathbf{x}) + \kappa \sigma(\mathbf{x})$$
   
   其中 $\mu(\mathbf{x})$ 和 $\sigma(\mathbf{x})$ 是高斯过程的均值和标准差。

**优化流程：**

1. 初始化：随机选择几个初始点
2. 训练高斯过程模型
3. 计算获取函数
4. 选择下一个评估点
5. 更新模型
6. 重复步骤2-5直到收敛

**Python实现（使用scikit-optimize）：**
```python
from skopt import gp_minimize
from skopt.space import Real, Integer
from skopt.utils import use_named_args

# 定义搜索空间
space = [
    Integer(1, 20, name='max_depth'),
    Real(0.01, 1.0, name='learning_rate'),
    Integer(10, 1000, name='n_estimators')
]

# 目标函数
@use_named_args(space)
def objective(**params):
    model = RandomForestRegressor(**params, random_state=42)
    scores = cross_val_score(model, X, y, cv=5, scoring='neg_mean_squared_error')
    return -scores.mean()  # 最小化负分数

    func=objective,
    dimensions=space,
    n_calls=50,
    random_state=42
)

print(f"最优分数: {-result.fun:.4f}")
```
