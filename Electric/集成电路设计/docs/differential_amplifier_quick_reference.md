# 差分放大器设计快速参考

## 核心概念
**差模信号**: Vid = Vin1 - Vin2（有用信号）  
**共模信号**: Vic = (Vin1 + Vin2)/2（干扰信号）  
**差分放大**: 放大差模，抑制共模  
**关键指标**: CMRR = |Ad|/|Ac|（越大越好）

## 关键公式

### 基本增益公式
- **差模增益**: `Ad = -gm × Rc`
- **共模增益**: `Ac = -Rc/(2 × ro)`
- **共模抑制比**: `CMRR = |Ad|/|Ac| = gm × ro`

### 输入阻抗
- **BJT**: `Rid ≈ 2 × β × rπ`
- **MOSFET**: `Rid ≈ 2/gm`

### 跨导计算
- **BJT**: `gm = IC/VT = IC/26mV`
- **MOSFET**: `gm = 2ID/(VGS-VTH)`

```
差模增益: Ad = -gm × Rc
```

## 误差控制

### 元件失配
- **电阻失配**: ΔR/R → CMRR下降
- **VBE失配**: ΔVBE → 失调电压
- **β失配**: Δβ → 失调电流
- **控制**: 0.1%精度匹配电阻

### 电流源非理想性
- **输出电阻有限**: ro → 共模增益增加
- **温度系数**: TC → 温漂
- **改善**: 威尔逊电流源、级联结构

### 频率限制
- **Miller效应**: 降低高频增益
- **负载电容**: 限制带宽
- **补偿**: Miller补偿技术

## 优化策略

### 精密匹配技术
```
电阻匹配：
- 精度：0.1%或更好
- 温度系数：<50ppm/°C
- 布局：对称设计

激光修调：
- 精度：0.01%
- 应用：高精度场合
- 成本：较高
```

### 改进电流源
```
威尔逊电流源：
- 结构：三级晶体管
- 优点：高输出电阻、低温漂
- 应用：精密放大器

级联电流源：
- 结构：共源-共栅
- 优点：极高输出电阻
- 应用：超精密场合
```

### 温度补偿
```
被动补偿：
- 原理：温度系数匹配
- 方法：使用同类型器件
- 效果：减小温漂

主动补偿：
- 原理：温度传感器补偿
- 方法：数字/模拟补偿
- 精度：ppm级别
```

## 故障排除

### 常见问题
| 问题 | 症状 | 原因 | 解决方案 |
|------|------|------|----------|
| CMRR不足 | 共模干扰大 | 电阻失配 | 精密匹配 |
| 失调过大 | 零输入有输出 | VBE失配 | 激光修调 |

| 功耗过大 | 发热严重 | 偏置电流 | 优化设计 |

## 快速计算器

```python
# 差分放大器设计计算
def differential_amplifier_design():
    """
    差分放大器快速设计计算
    """
    import math
    
    # 输入参数
    Ad_target = 100  # 目标差模增益
    CMRR_target = 80  # 目标CMRR (dB)
    I_bias = 1e-3    # 偏置电流 1mA
    VT = 26e-3       # 热电压 26mV
    
    # 基本计算
    gm = I_bias / VT  # 跨导
    Rc = Ad_target / gm  # 负载电阻
    ro_required = 10**(CMRR_target/20) / gm  # 所需输出电阻
    
    print(f"跨导 gm = {gm*1e3:.1f} mS")
    print(f"负载电阻 Rc = {Rc:.1f} kΩ")
    print(f"所需输出电阻 ro = {ro_required/1e6:.1f} MΩ")
    
    # 性能预估
    input_impedance = 2 / gm
    bandwidth_estimate = 1 / (2 * math.pi * Rc * 10e-12)  # 假设10pF负载
    
    print(f"输入阻抗 = {input_impedance/1e6:.1f} MΩ")
    print(f"预估带宽 = {bandwidth_estimate/1e6:.1f} MHz")

# 使用示例
differential_amplifier_design()
```
