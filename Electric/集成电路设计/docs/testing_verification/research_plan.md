# 集成电路测试和验证方法研究计划

## 研究目标
深入研究集成电路的测试和验证方法，重点收集测试覆盖率计算、良率模型、可靠性评估公式等关键信息。

## 研究范围
1. 可测试性设计(DFT)
2. 故障模型和测试生成
3. 验证方法学
4. 良率分析
5. 可靠性测试
