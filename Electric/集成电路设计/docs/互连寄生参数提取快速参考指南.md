# 互连寄生参数提取快速参考指南

## 核心公式速查

### 电阻提取

| 类型 | 公式 | 说明 |
|------|------|------|
| 基本定义 | `R = V/i` | 欧姆定律 |
| 材料相关 | `R = ρL/S` | 电阻率公式 |
| 矩形导体 | `R = ρL/(HW)` | 几何参数 |
| 多端结构 | N×N矩阵 | 复杂网络 |

### 电容提取

| 类型 | 公式 | 说明 |
|------|------|------|
| 基本定义 | `C = Q/V` | 电容定义 |
| 平行板 | `C = (ε₀εᵣS)/d` | 平行板电容器 |
| 真空介电常数 | `ε₀ = 8.85×10⁻¹²` | C²/N·m² |
| 拉普拉斯方程 | `∇²u = 0` | 介质区域 |

### 电感提取

| 类型 | 公式 | 说明 |
|------|------|------|
| 阻抗矩阵 | `Z(ω) = R(ω) + jωL(ω)` | 频率相关 |
| PEEC模型 | 包含R, L, C | 完整模型 |
| 部分电感 | 环路相互作用 | 无需预知环路 |

## 关键概念

### 高频效应
- **皮肤效应**: 电流趋向表面，增加有效电阻
- **邻近效应**: 相邻导体磁场相互作用
- **互电阻**: 超高频下变得可见

### 数值方法
- **BEM**: 边界元方法，适合复杂边界
- **ICCG**: 不完全Cholesky共轭梯度法
- **多重网格**: 快速收敛的大规模求解

### 边界条件
- **导体表面**: 电位已知 (Dirichlet)
- **Neumann边界**: 电场法向分量为零

## 快速决策流程

### 电阻提取选择
1. **简单结构** → 使用基本公式 `R = ρL/(HW)`
2. **两端器件** → 单一电阻值
3. **多端网络** → 矩阵方法

### 电容提取选择
1. **平行板** → 直接使用公式
2. **复杂结构** → BEM数值方法
3. **高频** → 考虑频率效应

### 电感提取选择
1. **低频** → 准静态近似
2. **高频** → 频率相关模型
3. **复杂互连** → PEEC模型

## 重要参数

### 材料属性
- **铜电阻率**: ~1.7×10⁻⁸ Ω·m
- **铝电阻率**: ~2.8×10⁻⁸ Ω·m
- **SiO₂介电常数**: ~3.9

### 几何参数
- **线宽**: 纳米到微米级
- **线厚**: 几十纳米到微米
- **间距**: 纳米级（先进工艺）

## 常见问题解决

### 收敛问题
- 检查网格质量
- 调整求解器参数
- 考虑多尺度建模

### 精度问题
- 验证边界条件
- 检查材料参数
- 验证几何建模

### 计算效率
- 选择合适的求解器
- 利用对称性
- 并行计算
