### 文档内容结构

#### 1. 过渡故障模型 (Transition Fault Model)
- **定义**: 检测信号从0到1或1到0转换的时序问题
- **数学公式**: `T_delay > T_specified`
- **应用**: 高速数字电路快速验证、早期设计阶段时序验证

#### 2. 门延迟故障模型 (Gate Delay Fault Model)
- **定义**: 逻辑门传播延迟超过规范值的故障模型
- **数学表示**: `D_G = { (gate_input_pattern, delay_value) | delay_value > T_gate_max }`
- **应用**: 中等复杂度电路详细测试、工艺变化影响分析

#### 3. 路径延迟故障模型 (Path Delay Fault Model)
- **定义**: 整个信号路径累积延迟超过规范值
- **数学公式**: `delay_path(P) = Σ(delay_gate_j) + Σ(delay_wire_k)`
- **应用**: 高复杂度电路完整验证、关键时序路径分析

#### 4. 段延迟故障模型 (Segment Delay Fault Model)
- **定义**: 电路段（包含多个门）的延迟故障
- **数学表示**: `D_S = { delay_segment(S) > T_segment_specified }`
- **应用**: 大规模电路折中测试、工业级产品量产测试

### 核心技术内容

#### 数学公式汇总
1. **过渡故障检测**: `T_delay > T_specified`
2. **门延迟故障**: 激活条件 + 传播条件 + 观测条件
3. **路径延迟**: `delay_path(P) = Σ(delay_gate_j) + Σ(delay_wire_k)`
4. **段延迟故障**: 段内所有元素延迟之和

#### 测试方法
- **Launch-Capture测试**: 双时钟周期测试方法
- **扫描链测试**: 移位-功能-移出序列
- **BIST测试**: LFSR → CUT → MISR结构
