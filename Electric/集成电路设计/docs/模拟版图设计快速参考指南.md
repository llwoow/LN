# 模拟版图设计快速参考指南

## 器件匹配核心公式

### 1. 随机失配标准偏差
```
σ(ΔR/R) = A/√(W×L)
```
- A: 匹配常数 (工艺相关)
- W: 器件宽度
- L: 器件长度

### 2. 电容匹配关系
```
C = ε×A/d = ε×(P×r)/d
```
- A/P = 常数 → 匹配电容
- ε: 介电常数
- d: 介质厚度
- P: 周长
- r: 等效半径

### 3. 电阻计算
```
R = ρ×L/(W×t)
```
- ρ: 电阻率
- L: 长度
- W: 宽度  
- t: 厚度

## 匹配设计规则

### 共质心布局四原则
1. **质心重合**: 所有器件几何中心相同
2. **对称性**: 具有旋转或镜像对称
3. **方向一致**: 相同晶体取向
4. **最小距离**: 器件间距离最小化

### 交叉指状布局模式
```
器件A: 1-3-5-7
器件B: 2-4-6-8
```

### 虚拟器件应用
- **电容**: 接地虚拟电容补偿边界效应
- **电阻**: 连接/非连接虚拟电阻补偿刻蚀差异
