## 1. 故障模型分类和定义 (Fault Model Classification and Definition)

### 1.1 故障模型概述
故障模型是对物理缺陷（Physical Defects）在电路逻辑行为层面上的抽象。由于物理缺陷种类繁多（如金属断路、短路、杂质污染等），直接分析它们非常复杂，因此需要通过故障模型来简化分析过程。

### 1.2 结构性故障模型 (Structural Fault Models)

#### 1.2.1 固定型故障模型 (Stuck-at Fault Model)
**定义**: 电路中的某条信号线永久性地固定为逻辑'0'或逻辑'1'

**分类**:
- **Stuck-at-0 (s-a-0)**: 信号线固定为逻辑0
- **Stuck-at-1 (s-a-1)**: 信号线固定为逻辑1

**关键假设**:
- **单一故障假设 (Single Fault Assumption)**: 在任何时刻，电路中只存在一个固定型故障
- 这个假设极大地简化了分析，并且实践证明，能够检测绝大多数单一固定型故障的测试集，也能检测到很高比例的其他类型故障和多重故障

**优点**: 简单、有效，是工业界和学术界最常用、最基础的模型

#### 1.2.2 桥接故障模型 (Bridging Fault Model)
**定义**: 两条或多条本不应相连的信号线之间发生了意外的短路

**分类**:
- **AND-Bridge**: 短路后的逻辑行为表现为两条线的逻辑与（AND）
- **OR-Bridge**: 短路后的逻辑行为表现为两条线的逻辑或（OR）
- **Dominant-Bridge**: 其中一条线的值会覆盖另一条线

#### 1.2.3 开路故障模型 (Open Fault Model)
**定义**: 一条信号线发生断路

**在CMOS电路中的表现**:
- **Stuck-Open Fault**: 导致CMOS逻辑门中的某个晶体管永久关闭，可能使得输出端悬空，形成一个记忆状态（Sequential Behavior），需要两向量测试序列来检测
- **Stuck-On Fault**: 导致某个晶体管永久导通，在特定输入下会产生从Vdd到GND的直流通路，增加静态功耗（IDDQ测试可检测）

#### 1.2.4 延迟故障模型 (Delay Fault Model)
**定义**: 故障不改变电路的稳态逻辑功能，但会增加信号在某条路径上的传播延迟，可能导致电路在额定工作频率下出错

**分类**:
- **Transition Fault (转换故障)**: 假设单个门的延迟显著增加，导致信号的上升（slow-to-rise）或下降（slow-to-fall）转换过慢
- **Path Delay Fault (路径延迟故障)**: 考虑从一个触发器到另一个触发器的一整条路径上的累积延迟超过了时钟周期

### 1.3 功能性故障模型 (Functional Fault Models)
不关心电路的具体结构，而是从功能模块（如加法器、RAM）的规范来描述故障。例如：
- 对于一个加法器，一个功能性故障可能是"执行了减法操作"
- 对于RAM，故障模型包括地址译码器故障、存储单元故障等

## 2. 故障等价性 (Fault Equivalence)

### 2.1 概念定义
如果两个故障 `f1` 和 `f2`，任何能够检测 `f1` 的测试向量（Test Vector）也都能检测 `f2`，反之亦然，那么 `f1` 和 `f2` 就是**等价的 (Equivalent)**。

**数学表示**: `T(f1) = T(f2)`
其中 `T(f)` 是能够检测故障 `f` 的所有测试向量的集合。

### 2.2 目的
识别并移除等价的故障可以减小需要分析的故障列表的规模，从而降低测试生成（ATPG）和故障仿真（Fault Simulation）的计算复杂度。

### 2.3 基于门级的等价性算法/规则

#### 2.3.1 AND/NAND门
- **AND门**: 任何一个输入的 `s-a-0` 等价于输出的 `s-a-0`
  - `{input_i s-a-0}` ⇔ `{output s-a-0}`
- **NAND门**: 任何一个输入的 `s-a-0` 等价于输出的 `s-a-1`
  - `{input_i s-a-0}` ⇔ `{output s-a-1}`

#### 2.3.2 OR/NOR门
- **OR门**: 任何一个输入的 `s-a-1` 等价于输出的 `s-a-1`
  - `{input_i s-a-1}` ⇔ `{output s-a-1}`
- **NOR门**: 任何一个输入的 `s-a-1` 等价于输出的 `s-a-0`
  - `{input_i s-a-1}` ⇔ `{output s-a-0}`

#### 2.3.3 NOT/Buffer门
- **NOT门**: 
  - 输入的 `s-a-0` 等价于输出的 `s-a-1`
  - 输入的 `s-a-1` 等价于输出的 `s-a-0`
- **Buffer门**:
  - 输入的 `s-a-0` 等价于输出的 `s-a-0`
  - 输入的 `s-a-1` 等价于输出的 `s-a-1`

#### 2.3.4 扇出点 (Fanout Stem)
- 扇出点的 `s-a-0` 等价于所有扇出分支（Branches）的 `s-a-0` 同时发生
- 扇出点的 `s-a-1` 等价于所有扇出分支的 `s-a-1` 同时发生

### 2.4 等价性实例分析
考虑一个两输入与门 `G`，输入为 `A` 和 `B`，输出为 `Z`。

**可能的单一固定型故障**: 6个
- `A s-a-0`, `A s-a-1`, `B s-a-0`, `B s-a-1`, `Z s-a-0`, `Z s-a-1`

**等价分析**:
- 根据等价规则，`A s-a-0`、`B s-a-0` 和 `Z s-a-0` 是等价的
- 要检测 `Z s-a-0`，需要使 `Z` 的正常值为 `1`，即输入 `AB=11`
- 此时，如果存在 `A s-a-0` 或 `B s-a-0`，输出 `Z` 同样会变为 `0`
- 因此，`T(A s-a-0) = T(B s-a-0) = T(Z s-a-0) = {11}`

**等价故障集**: `{A s-a-0, B s-a-0, Z s-a-0}`

## 3. 故障压缩技术和方法 (Fault Collapsing)

### 3.1 故障优势性 (Fault Dominance)

#### 3.1.1 概念定义
如果所有能检测故障 `f2` 的测试向量也都能检测故障 `f1`，那么称 `f1` **优势于** `f2`。

**数学表示**: `T(f2) ⊂ T(f1)`

#### 3.1.2 应用原理
在故障列表中，我们可以移除优势故障 `f1`。因为只要我们找到了一个用于检测被优势故障 `f2` 的测试，它就必然能检测 `f1`。检测 `f2` 是一个更强的约束。

#### 3.1.3 基于门级的优势性规则
- **AND/NAND门**: 输出的 `s-a-1` 优势于所有输入的 `s-a-1`
- **OR/NOR门**: 输出的 `s-a-0` 优势于所有输入的 `s-a-0`

### 3.2 故障压缩方法

#### 3.2.1 压缩步骤
1. **生成初始故障列表**: 对电路中每一条线，都列出 `s-a-0` 和 `s-a-1` 两个故障
2. **应用等价性**: 将等价的故障分组，每组只保留一个代表性故障
3. **应用优势性**: 移除所有被其他故障优势的故障
4. **最终得到"折叠后的故障列表" (Collapsed Fault List)**

#### 3.2.2 故障压缩实例
对于两输入与门 `G(A, B, Z)`:

**步骤1: 初始列表 (6个)**
```
{A/0, A/1, B/0, B/1, Z/0, Z/1}
```
（用 `/` 表示 `s-a`）

**步骤2: 应用等价性**
- `E1 = {A/0, B/0, Z/0}`。保留 `Z/0` 作为代表
- 其他故障不等价
- 列表变为：`{Z/0, A/1, B/1, Z/1}`

**步骤3: 应用优势性**
- `Z/1` 优势于 `A/1`。`T(A/1) = {01}`，`T(B/1) = {10}`，`T(Z/1) = {01, 10}`
- 所以 `T(A/1) ⊂ T(Z/1)` 且 `T(B/1) ⊂ T(Z/1)`
- 我们可以移除 `Z/1`

**步骤4: 折叠后的故障列表 (3个)**
```
{A/1, B/1, Z/0}
```

**压缩效果**: 初始的 `2 * (n+1) = 6` 个故障被压缩到了 `n+1 = 3` 个

## 4. 测试覆盖率计算方法 (Test Coverage Calculation)

### 4.1 定义
故障覆盖率是衡量一个测试集 `T` 对一个给定故障列表 `F` 检测能力的百分比。

### 4.2 计算公式
```
Fault Coverage (FC) = (Number of Detected Faults) / (Total Number of Faults in Collapsed List) × 100%
```

**参数说明**:
- `Nd`: 已检测到的故障数量
- `Nf`: 折叠后故障列表中的总故障数
- `FC`: 故障覆盖率百分比

### 4.3 基于故障仿真的覆盖率计算算法

#### 4.3.1 算法伪代码
```pseudocode
function calculate_fault_coverage(circuit, test_vectors, fault_list):
    total_faults = size(fault_list)
    detected_fault_list = new set()

    for each vector in test_vectors:
        // 1. 模拟正常电路，获取正确输出
        good_circuit_output = simulate(circuit, vector)

        // 2. 遍历尚未检测出的故障
        for each fault in fault_list:
            if fault is not in detected_fault_list:
                // 3. 注入故障并模拟
                faulty_circuit = inject_fault(circuit, fault)
                faulty_circuit_output = simulate(faulty_circuit, vector)

                // 4. 比较输出，判断是否检测到
                if faulty_circuit_output != good_circuit_output:
                    add fault to detected_fault_list

    // 5. 计算覆盖率
    num_detected_faults = size(detected_fault_list)
    coverage = (num_detected_faults / total_faults) * 100
    return coverage, detected_fault_list
```

#### 4.3.2 算法步骤详解
1. **初始化**: 设置总故障数和已检测故障集合
2. **正常电路仿真**: 对每个测试向量，计算无故障电路的期望输出
3. **故障仿真**: 对每个尚未检测出的故障：
   - 注入故障
   - 仿真带故障的电路
   - 比较故障输出和期望输出
   - 若不一致，则将该故障标记为"已检测"
4. **覆盖率计算**: 使用公式计算最终覆盖率

## 5. 故障检测和诊断方法 (Fault Detection and Diagnosis)

### 5.1 故障检测 (Fault Detection)

#### 5.1.1 目标
判断电路中**是否存在**来自故障列表中的故障。输出是 "Go/No-Go" (通过/不通过)。

#### 5.1.2 方法
通过施加测试向量并比较芯片的实际输出与期望输出来完成。这个过程依赖于**自动测试模式生成 (ATPG)** 算法（如 D-Algorithm, PODEM, FAN）来创建高效的测试向量。

### 5.2 故障诊断 (Fault Diagnosis)

#### 5.2.1 目标
在检测到故障后，进一步**定位**故障的具体位置和类型。

#### 5.2.2 故障字典法 (Fault Dictionary)

**离线阶段**:
- 对故障列表中的每一个故障，仿真其在给定测试集下的输出响应（称为故障签名, Fault Signature）
- 将所有故障及其签名存储在一个"字典"中

**在线阶段**:
- 将测试失败的芯片的实际输出签名与字典中的条目进行匹配
- 最接近的匹配项即为最可能的故障

**缺点**: 字典规模可能非常巨大

#### 5.2.3 效应-原因分析 (Effect-Cause Analysis)

**步骤**:
1. 从观察到错误的输出引脚（效应）开始，向电路内部反向追溯
2. 分析所有可能导致该错误输出的路径和门，形成一个候选故障集合
3. 利用更多的测试向量或诊断测试，逐步缩小候选故障集，最终定位故障

## 6. 自动测试模式生成 (ATPG) 算法

### 6.1 D-Algorithm 核心思想
`D`和`D-bar (D')`是用来表示信号差异的符号：
- `D`: 代表正常值为1、故障值为0
- `D'`: 代表正常值为0、故障值为1

### 6.2 D-Algorithm 伪代码
```pseudocode
function D_Algorithm(circuit, target_fault):
    // 1. 故障激活 (Fault Activation)
    // 在故障点设置一个 D 或 D' 值
    // 例如，对于 line 'L' s-a-0 故障，需要设置输入使 'L' 的正常值为 1
    // 这会在 'L' 处产生一个 D 值 (Good=1, Faulty=0)
    set_value(L, D)

    // 2. 故障传播 (Fault Propagation)
    // 选择一条从故障点到主输出的路径
    // 逐级设置路径上逻辑门的其它输入，使得 D 或 D' 能传播到下一级
    // 例如，要将 D 从AND门的一个输入传播到输出，其它输入必须都为 1
    propagate_D_to_primary_output()

    // 3. 合理性证明 (Justification)
    // 反向回溯，为在传播和激活步骤中设置的内部信号值找到一组一致的主输入值
    // 这通常是一个递归的、可能需要回溯的过程
    justify_internal_values()

    if justification_successful:
        return primary_input_vector // 返回找到的测试向量
    else:
        // 如果失败，回溯并尝试其他传播路径或激活条件
        backtrack_and_retry()
        return failure
```

## 7. 关键数学公式总结

### 7.1 故障覆盖率公式
```
FC = (Nd / Nf) × 100%
```
- `Nd`: 已检测到的故障数量
- `Nf`: 折叠后故障列表中的总故障数

### 7.2 故障等价性判定
```
T(f1) = T(f2)  ⟺  f1 等价于 f2
```
其中 `T(f)` 是能够检测故障 `f` 的所有测试向量的集合。

### 7.3 故障优势性判定
```
T(f2) ⊂ T(f1)  ⟺  f1 优势于 f2
```

### 7.4 故障压缩效率
对于n输入门：
- 原始故障数: `2 × (n + 1)` （包括输出线）
- 压缩后故障数: `n + 1`
- 压缩比: `2:1`

## 8. 实际应用考虑

### 8.1 工业界应用
- **固定型故障模型**仍然是最主要的故障模型
- **故障压缩**是现代ATPG工具的标准预处理步骤
- **故障覆盖率**通常要求达到95%以上

### 8.2 挑战和发展方向
- **多重故障**: 实际电路中可能同时存在多个故障
- **新型故障模型**: 纳米尺度下的新型缺陷机制
- **机器学习**: 在故障诊断和测试生成中的应用

---

## 9. 总结

故障建模是VLSI测试领域的核心理论基础。通过故障模型、故障等价性、故障压缩和覆盖率计算等关键技术，能够有效地：
1. 简化复杂的物理缺陷分析
2. 提高测试生成的效率
3. 评估测试质量
4. 指导测试向量的生成

这些理论和方法在实际VLSI设计和制造中发挥着重要作用，是确保芯片质量和可靠性的关键技术手段。
