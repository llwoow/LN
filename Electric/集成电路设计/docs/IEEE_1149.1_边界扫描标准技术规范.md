# IEEE 1149.1边界扫描标准技术规范

## 概述

IEEE 1149.1标准（也称为JTAG - Joint Test Action Group）是一种用于集成电路测试的标准化边界扫描架构。该标准定义了测试访问端口（TAP）和边界扫描测试电路的规范，使得在印刷电路板（PCB）级别进行测试和调试成为可能。

## 1. 边界扫描架构（Boundary Scan Architecture）

### 1.1 基本原理

边界扫描架构通过在芯片的每个I/O引脚处集成边界扫描单元（Boundary Scan Cell），形成一条贯穿芯片的测试数据链路。这些单元可以在正常工作模式和测试模式之间切换，实现对芯片引脚状态的完全控制和对内部信号的访问。

### 1.2 核心组件

1. **测试访问端口（TAP）**
2. **TAP控制器**
3. **指令寄存器（IR）**
4. **测试数据寄存器（TDR）组**
5. **边界扫描寄存器（BSR）**
6. **旁路寄存器（BYPASS）**
7. **器件识别寄存器（IDCODE）**

### 1.3 边界扫描单元结构

每个边界扫描单元包含：
- **并行输入/输出路径**
- **串行移位路径**
- **模式控制逻辑**
- **时钟控制逻辑**

## 2. TAP控制器（Test Access Port Controller）

### 2.1 TAP信号定义

TAP控制器使用以下5个信号：
- **TCK（Test Clock）**：测试时钟输入
- **TMS（Test Mode Select）**：测试模式选择输入
- **TDI（Test Data In）**：测试数据输入
- **TDO（Test Data Out）**：测试数据输出
- **TRST（Test Reset）**：测试复位输入（可选）

### 2.2 TAP控制器状态机

TAP控制器实现一个16状态的有限状态机：

#### 主要状态组：

**复位状态组：**
- Test-Logic-Reset
- Run-Test-Idle

**数据寄存器路径：**
- Select-DR-Scan
- Capture-DR
- Shift-DR
- Exit1-DR
- Pause-DR
- Exit2-DR
- Update-DR

**指令寄存器路径：**
- Select-IR-Scan
- Capture-IR
- Shift-IR
- Exit1-IR
- Pause-IR
- Exit2-IR
- Update-IR

### 2.3 状态转换规则

状态转换由TMS信号在TCK上升沿决定：
- TMS=0：保持在当前状态或进入下一状态
- TMS=1：进入测试逻辑复位状态

### 2.4 控制器功能

TAP控制器负责：
1. 解析TMS信号序列
2. 控制数据流方向
3. 管理时钟使能
4. 协调指令和数据操作

## 3. 测试数据寄存器（TDR）

### 3.1 必需寄存器

#### 3.1.1 边界扫描寄存器（BSR）
- **功能**：存储芯片I/O引脚的边界扫描数据
- **结构**：由多个边界扫描单元串联组成
- **位宽**：等于芯片I/O引脚数量
- **操作**：支持串行移位、并行捕获和更新

#### 3.1.2 旁路寄存器（BYPASS）
- **功能**：为多芯片链提供最短测试路径
- **结构**：单位移位寄存器
- **操作**：在Capture-DR状态加载'0'，在Update-DR状态保持

### 3.2 可选寄存器

#### 3.2.1 器件识别寄存器（IDCODE）
- **功能**：提供器件标识信息
- **结构**：32位移位寄存器
- **格式**：
  - 位31：始终为'1'
  - 位30-28：版本号
  - 位27-12：器件型号
  - 位11-1：制造商标识
  - 位0：始终为'1'

#### 3.2.2 用户自定义寄存器
- **功能**：访问芯片内部测试功能
- **结构**：根据具体应用定义
- **操作**：遵循标准TAP操作序列

### 3.3 寄存器选择逻辑

寄存器选择由当前指令寄存器的内容决定：
- **指令编码**：决定哪个寄存器连接到TDI-TDO路径
- **默认选择**：如果指令未明确指定寄存器，优先选择BSR

## 4. 指令寄存器（IR）

### 4.1 指令寄存器结构

- **长度**：由具体器件决定，通常为2-8位
- **组成**：移位寄存器 + 锁存器
- **操作**：在IR路径上进行串行移位和并行更新

### 4.2 必需指令

#### 4.2.1 BYPASS指令
- **编码**：全'1'序列
- **功能**：选择旁路寄存器
- **效果**：TDI直接连接到TDO，绕过BSR

#### 4.2.2 SAMPLE/PRELOAD指令
- **编码**：特定器件定义
- **功能**：
  - SAMPLE：捕获I/O引脚当前状态
  - PRELOAD：将数据预加载到BSR输出锁存器

#### 4.2.3 EXTEST指令
- **编码**：特定器件定义
- **功能**：
  - 将BSR数据驱动到I/O引脚
  - 捕获外部电路响应

### 4.3 可选指令

#### 4.3.1 INTEST指令
- **功能**：测试芯片内部逻辑
- **操作**：驱动内部节点到输出，捕获输入响应

#### 4.3.2 IDCODE指令
- **功能**：读取器件识别寄存器
- **操作**：将IDCODE寄存器连接到TDI-TDO路径

#### 4.3.3 USERCODE指令
- **功能**：读取用户自定义器件代码
- **操作**：类似于IDCODE指令

### 4.4 指令执行流程

1. **选择IR路径**：TAP控制器进入Select-IR-Scan
2. **移位阶段**：在Shift-IR状态下串行移位指令数据
3. **退出阶段**：通过Exit1-IR、Pause-IR、Exit2-IR
4. **更新阶段**：在Update-IR状态下锁存新指令
5. **执行阶段**：执行新指令指定的操作

## 5. 边界扫描单元详细设计

### 5.1 边界扫描单元类型

#### 5.1.1 输入单元
- **功能**：捕获输入信号
- **结构**：
  - 输入缓冲器
  - 捕获触发器
  - 串行移位寄存器
  - 输出控制逻辑

#### 5.1.2 输出单元
- **功能**：控制输出信号
- **结构**：
  - 输入控制逻辑
  - 串行移位寄存器
  - 更新锁存器
  - 输出驱动器和三态控制

#### 5.1.3 双向单元
- **功能**：控制双向I/O引脚
- **结构**：组合输入和输出单元功能

### 5.2 单元操作模式

1. **正常模式**：信号直接通过，不受边界扫描影响
2. **测试模式**：
   - 捕获模式：采样输入信号
   - 移位模式：串行传输数据
   - 更新模式：驱动输出信号

### 5.3 时序要求

- **建立时间**：数据在时钟上升沿前必须稳定
- **保持时间**：数据在时钟上升沿后必须保持稳定
- **传播延迟**：从输入到输出的最大延迟

## 6. 测试数据流管理

### 6.1 数据移位操作

- **方向**：从TDI到TDO（LSB优先）
- **时钟**：在TCK上升沿移位
- **同步**：与TAP控制器状态机同步

### 6.2 数据捕获和更新

- **捕获时机**：在Capture-DR/IR状态的TCK上升沿
- **更新时机**：在Update-DR/IR状态的TCK上升沿
- **数据保持**：在Pause状态期间保持数据不变

### 6.3 多芯片链管理

- **串联连接**：TDO连接到下一个芯片的TDI
- **同步操作**：所有芯片共享相同的TCK和TMS
- **独立控制**：每个芯片的TRST独立控制
