## 🎯 核心概念速览

### 1. 运算放大器带宽特性
```
✅ 3dB带宽: f_{-3dB} = f_T / A_CL
✅ 开环增益: A_OL(f) = A_DC / (1 + jf/f_P)
✅ 单极点模型: A_OL(s) = A_DC / (1 + s/ω_P)
```

### 2. 增益带宽积(GBW)

**基本公式**:
```
GBW = A_CL × f_{-3dB} = 常数
```

**应用设计表**:

| 应用类型 | 带宽 | 增益 | 所需GBW |
|---------|-----|-----|---------|
| 音频放大 | 20kHz | 10 | 200kHz |
| 仪表放大 | 1MHz | 100 | 100MHz |
| RF应用 | 100MHz | 1 | 100MHz |
| 视频放大 | 10MHz | 2 | 20MHz |

### 3. 频率响应分析

**Bode图特性**:
- **低频**: 0dB/dec, 0°相位
- **截止频率**: -3dB, -45°相位
- **高频**: -20dB/dec, -90°相位

**闭环响应**:
```
A_CL(jω) = A_OL(jω) / [1 + β × A_OL(jω)]
```

### 4. 稳定性分析

**相位裕度**:
```
PM = 180° + ∠A_OL(jω_GC)
稳定性准则: PM > 45°
```

**增益裕度**:
```
GM = -20log|A_OL(jω_PC)|
稳定性准则: GM > 10dB
```

### 5. 带宽平坦性

**定义**:
```
Flatness = 20log|A_CL(f)| - 20log|A_CL(f_REF)|
```

**典型指标**:
- **±0.1dB**: 高精度应用
- **±0.5dB**: 一般应用  
- **±1dB**: 宽松要求

## 🔧 设计应用要点

### 带宽设计流程
1. **确定需求**: 带宽、增益、精度
2. **选择运放**: GBW ≥ 10×所需带宽
3. **反馈网络**: 电阻、电容、补偿
4. **验证测试**: 频率响应、稳定性

### 常见问题解决

**带宽不足**:
- 检查运放GBW规格
- 验证负载条件
- 优化补偿网络

**振荡问题**:
- 测量相位裕度
- 检查PCB布局
- 优化反馈网络

**平坦性差**:
- 测量频率响应
- 检查寄生电容
- 优化网络设计

### 应用实例

**音频系统**:
- 带宽: 20Hz-20kHz
- 平坦性: ±0.1dB
- 所需GBW: ≥200kHz

**仪表系统**:
- 带宽: DC-100kHz
- 平坦性: ±0.01dB
- 所需GBW: ≥10MHz

**视频系统**:
- 带宽: DC-10MHz
- 平坦性: ±0.5dB
- 所需GBW: ≥10MHz

## 📊 关键公式速查

### 基本关系
```
GBW = A_CL × f_{-3dB}
f_{-3dB} = GBW / A_CL
```

### 传递函数
```
A_OL(s) = A_DC / (1 + s/ω_P)
A_CL(s) = A_OL(s) / [1 + βA_OL(s)]
```

### 稳定性
```
PM = 180° + ∠A_OL(jω_GC) > 45°
GM = -20log|A_OL(jω_PC)| > 10dB
```

3. **优化平坦性**: 根据应用需求设计平坦性指标
4. **验证测试**: 通过实际测试验证设计目标
