## 1. 寄生提取概述

### 1.1 基本概念

**互连定义**: 互连是电路中的导电路径，用于连接功能器件（器件、门电路、模块等）。

**理想行为 vs 实际影响**:
- **理想情况**: 导线仅连接功能器件，不影响设计性能
- **实际情况**: 对于深亚微米(DSM)设计，这种假设不可接受

### 1.2 互连的重要性

- 互连考虑对电路设计至关重要
- 功能器件对互连高度敏感
- 互连严重影响电路速度和功耗性能
- 过去30年的技术发展已接近极限

### 1.3 寄生提取的主要方法

1. **电阻提取** (Resistance Extraction)
2. **电容提取** (Capacitance Extraction)  
3. **电感和阻抗(RLC)提取** (Inductance and Impedance RLC Extraction)

## 2. 电阻提取

### 2.1 问题表述

#### 2.1.1 简单结构电阻公式

**基本定义**:
```
R = V/i
```

**材料相关公式**:
```
R = ρL/S
```

其中：
- ρ: 电阻率
- L: 导体长度
- S: 截面积

**矩形导体电阻**:
```
R = ρL/(HW)
```

其中：
- H: 导体高度
- W: 导体宽度

#### 2.1.2 两端结构

- **定义**: 具有两个连接点的器件
- **电阻值**: R = V/i
- **特点**: 产生单一电阻值

#### 2.1.3 多端（端口）结构

- **矩阵表示**: N×N电阻矩阵
- **特点**: 对角线元素未定义
- **应用**: 复杂互连网络的电阻提取

## 3. 电容提取

### 3.1 基本电容公式

#### 3.1.1 平行板电容器

**基本定义**:
```
V = φ₁ - φ₂  (电压差)
Q, -Q        (电荷)
C = Q/V      (电容定义)
```

**平行板电容器公式**:
```
C = (ε₀εᵣS)/d
```

**参数说明**:
- ε₀ = 8.85×10⁻¹² C²/N·m² (真空介电常数)
- εᵣ: 相对介电常数
- S: 极板面积
- d: 极板间距

### 3.2 其他常见电容器类型

1. **指状电容器** (Interdigital capacitor)
2. **同轴电容器** (Coaxial capacitor)

### 3.3 3-D数值方法 - 直接BEM

#### 3.3.1 场方程和边界条件

**拉普拉斯方程** (在介质区域):
```
∇·ε∇u = 0
∇²u = ∂²u/∂x² + ∂²u/∂y² + ∂²u/∂z² = 0
```

**边界条件**:
- **导体表面** (Γᵤ): u已知
- **Neumann边界**: Eₙ = ∂u/∂n = 0

#### 3.3.2 电场定义

**散度**:
```
∇·E = ρ/ε
```

**电场**:
```
E = -∇u
```

#### 3.3.3 有限域模型

- **Neumann边界条件**
- **QBEM算法内部处理**

## 4. 电感提取

### 4.1 片上互连电感模型

#### 4.1.1 部分电感模型 (Partial Inductance Model)

**特点**:
- 用于表示环路相互作用，无需预先知道环路信息
- 包含磁场耦合信息
- 提供环路电感的部分表示

#### 4.1.2 PEEC模型 (Partial Element Equivalent Circuit)

**组成部分**:
- 部分电感 (Partial inductance)
- 电容 (Capacitance)
- 电阻 (Resistance)

**应用**:
- IC互连电路仿真
- 提供足够的精度
- 适用于复杂互连结构分析

### 4.2 两平行线示例

- 展示部分电感模型的实际应用
- 说明互连间的磁场耦合效应

## 5. 频率相关效应

### 5.1 高频考虑因素

#### 5.1.1 非均匀电流分布效应

**皮肤效应**:
- 高频下电流趋向导体表面流动
- 导致有效电阻增加

**邻近效应**:
- 相邻导体间的磁场相互作用
- 影响电流分布模式

#### 5.1.2 R和L的联合提取

- **原因**: 频率依赖性和耦合效应
- **方法**: 同时提取R和部分L，而非独立处理

#### 5.1.3 电容效应分离分析

**磁准静态(MQS)近似**:
- 电容效应单独分析
- 假设光速在感兴趣区域内为无穷大
- 电磁场分别处理（磁场：L,R；电场：C）

#### 5.1.4 环境依赖性

- **磁场相互作用**: L和R值都依赖于环境
- **电容影响**: 寄生电容影响L和R的提取
- **耦合效应**: 不同参数间存在相互影响

### 5.2 问题表述

#### 5.2.1 终端对表示

- **双端口网络**: Vc1, Ic1; Vc2, Ic2
- **通用终端对**: 适用于复杂互连结构

#### 5.2.2 阻抗提取

**基本阻抗矩阵方程**:
```
[Z₁₁(ω)  Z₁₂(ω)] [Ic1]   [Vc1]
[Z₂₁(ω)  Z₂₂(ω)] [Ic2] = [Vc2]
```

#### 5.2.3 详细阻抗矩阵

**频率相关阻抗表达式**:
```
[R₁₁(ω) + jωL₁₁(ω)  R₁₂(ω) + jωL₁₂(ω)] [Ic1]   [Vc1]
[R₂₁(ω) + jωL₂₁(ω)  R₂₂(ω) + jωL₂₂(ω)] [Ic2] = [Vc2]
```

**参数说明**:
- Rᵢᵢ(ω): 端口i的自电阻（频率相关）
- jωLᵢᵢ(ω): 端口i的自电感（频率相关）
- Rᵢⱼ(ω): 端口i和j之间的互电阻
- jωLᵢⱼ(ω): 端口i和j之间的互电感

### 5.3 超高频效应

**互电阻可见性**:
- 在超高频下，互电阻Rᵢⱼ变得不可忽略
- 增加了提取过程的复杂性
- 需要考虑更全面的耦合效应

## 6. 数值方法

### 6.1 矩阵求解方法

#### 6.1.1 稀疏高斯消元 (Sparse Gaussian Elimination)

**特点**:
- 适用于中等规模问题
- 时间复杂度：O(n³)
- 存储复杂度：O(n²)

#### 6.1.2 不完全Cholesky共轭梯度法 (ICCG)

**特点**:
- 适用于大规模稀疏矩阵
- 良好的收敛性
- 存储效率高

#### 6.1.3 多重网格方法 (Multigrid)

**特点**:
- 适用于大规模问题
- 快速收敛
- 可扩展性好

### 6.2 边界元方法 (BEM) 基础

#### 6.2.1 麦克斯韦方程组

**控制方程**:
- **法拉第定律**: ∇×E = -∂B/∂t
- **安培定律**: ∇×H = J + ∂D/∂t
- **连续性方程**: ∇·J = -∂ρ/∂t

**其他已知方程**:
- **电场高斯定律**: ∇·D = ρ
- **磁场高斯定律**: ∇·B = 0

**导体本构方程**:
- J = σE (欧姆定律)
- D = εE (电位移定义)

#### 6.2.2 波动方程

**电场波动方程**:
```
∇²E - με∂²E/∂t² = 0
```

## 7. 技术总结

### 7.1 关键要点

1. **多物理场耦合**: 电阻、电容、电感提取需要考虑相互耦合
2. **频率依赖性**: 高频下参数提取更加复杂
3. **环境敏感性**: 提取结果受周围环境影响
4. **数值方法**: 需要高效的数值算法处理大规模问题

### 7.2 工程应用考虑

1. **精度要求**: 不同应用对精度要求不同
2. **计算效率**: 需要平衡精度和计算时间
3. **可扩展性**: 方法应适用于不同规模的电路
4. **工具集成**: 提取工具需要与设计流程集成

### 7.3 发展趋势

1. **多尺度建模**: 从纳米到系统级的一致性建模
2. **机器学习**: 利用AI技术提高提取效率
3. **3D建模**: 更精确的三维结构建模
4. **协同仿真**: 电-热-机械多物理场协同分析
