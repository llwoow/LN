## 🎯 核心概念速览

### 1. 理想运放模型
```
✅ 无限开环增益: A_ol → ∞
✅ 无限输入阻抗: R_in → ∞  
✅ 零输出阻抗: R_out → 0
✅ 虚短: V+ = V-
✅ 虚断: I+ = I- = 0
```

### 2. 关键传递函数

| 电路类型 | 传递函数 | 闭环增益 |
|---------|---------|---------|
| 反相放大器 | V_out/V_in = -R_f/R₁ | A_cl = -R_f/R₁ |
| 非反相放大器 | V_out/V_in = 1 + R_f/R₁ | A_cl = 1 + R_f/R₁ |
| 差分放大器 | V_out = (R_f/R₁)(V₂-V₁) | A_cl = R_f/R₁ |

### 3. 反馈系统核心公式
```
闭环增益: A_cl = A/(1 + Aβ)
误差函数: 1/A_cl = β + 1/A
高增益极限: A_cl → 1/β (A → ∞)
```

### 4. 频率响应特性

**开环响应**:
```
A_ol(s) = A_dc/(1 + s/ω_p)
增益带宽积: GBW = A_dc × f_p
```

**闭环带宽**:
```
f_cl = GBW/A_cl_dc
```

### 5. 稳定性分析
```
相位裕度: PM = 180° + ∠A(jω_gc)
增益裕度: GM = -20log|A(jω_pc)|
稳定性准则: PM > 45°, GM > 10dB
```

## 🔧 实际应用要点

### 常见应用电路
- **电压跟随器**: A_cl = 1
- **积分器**: A_cl(s) = -1/(sRC)  
- **微分器**: A_cl(s) = -sRC
- **有源滤波器**: 多阶设计

### 设计考虑
1. **增益选择**: 满足精度和带宽需求
2. **频率补偿**: 确保稳定性
3. **噪声分析**: 1/f噪声和热噪声
4. **负载驱动**: 输出能力评估

### 实际限制
- 有限开环增益 → 增益误差
- 有限输入阻抗 → 负载效应  
- 非零输出阻抗 → 驱动限制
- 频率限制 → 带宽约束

---

## 📊 关键参数关系

```
开环增益 × 带宽 = 常数 (GBW)
闭环增益 × 闭环带宽 = 开环增益 × 开环带宽
相位裕度 > 45° 确保稳定性
```
