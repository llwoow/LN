# 故障模型和ATPG技术要点摘要

## 核心故障模型

### 1. 固定型故障 (Stuck-at Fault)
- **模型**: 节点固定为0或1
- **应用**: 最基础和广泛使用的模型

### 2. 桥接故障 (Bridging Fault)  
- **AND桥接**: 故障值 = A AND B
- **OR桥接**: 故障值 = A OR B
- **主导桥接**: X Dom y (x主导y的值)

### 3. 延迟故障 (Delay Fault)
- **路径延迟故障**: 考虑路径延迟累积
- **转换故障**: 节点大幅延迟
- **段延迟故障**: 特定路径段延迟

### 4. 转换故障 (Transition Fault)
- **建模**: 每个转换故障 = 2个固定型故障
- **类型**: 慢上升(STR)、慢下降(STF)
- **应用**: 工业界最常用

## 关键ATPG算法

### 1. D算法
- **值域**: {0, 1, X, D, D̄}
- **D**: 1/0 (正常1/故障0)
- **D̄**: 0/1 (正常0/故障1)
- **核心**: 维护D-前沿和J-前沿

### 2. PODEM算法
- **特点**: 仅在主输入决策
- **优势**: 无内部冲突
- **关键**: X-路径概念

### 3. FAN算法
- **改进**: 扩展PODEM
- **头条线**: 无扇出锥输出
- **多目标**: 减少冲突

## 重要数学公式

### 1. 故障检测概率
```
单故障检测概率: P_detect(f) = |Tf| / 2^n
N次检测概率: 1 - (1 - P_detect(f))^N
```

### 2. 最小检测概率 (引理1)
```
最难检测故障概率: 2^(-nmax)
其中nmax为最大主输出锥的主输入数
```

### 3. 布尔差分
```
∂f/∂x = f(x) XOR f(x=0)
检测条件: f XOR f' = 1
```

## 测试向量生成方法

### 1. 随机测试
- **基础**: N个随机向量
- **加权**: 偏置输入概率
- **检测概率**: 基于向量集合大小

### 2. 确定性ATPG
- **目标**: 激发故障 + 传播效应
- **搜索**: 分支限界法
- **回溯**: 冲突时返回

### 3. 遗传算法ATPG
- **群体**: 候选解集合
- **适应度**: 质量评估函数
- **操作**: 选择、交叉、变异

## 延迟测试技术

### 1. Launch-on-Capture
- **V2**: 由V1通过电路功能导出
- **优势**: 真正速度测试，易于ATPG集成

### 2. Launch-on-Shift  
- **V2**: V1的1位移位
- **类型**: One-hot、Aligned、Staggered

### 3. Enhanced Scan
- **V1,V2**: 不相关向量
- **覆盖率**: 最高
- **代价**: 需要增强扫描单元

## 路径延迟故障分类

### 1. 鲁棒可测试
- **条件**: 不受其他延迟影响
- **验证**: 可独立验证路径正确性

### 2. 非鲁棒可测试
- **条件**: 仅在无其他延迟故障时有效
- **应用**: 实际测试中常用

### 3. 不可测试
- **假路径**: 转换无法传播
- **静态不可敏化**: 无法设置非控制值

## 故障检测策略

### 1. N-Detect ATPG
- **目标**: 每个故障检测N次
- **优势**: 提高缺陷覆盖率
- **应用**: 增强测试质量

### 2. 测试集压缩
- **组合**: 集合覆盖算法
- **序列**: 向量恢复算法
- **目标**: 最小化测试集大小

### 3. 不可测试故障识别
- **FIRE算法**: 基于冲突分析
- **单线冲突**: s=0 AND s=1
- **多线冲突**: 非法值组合

## 工业应用要点

### 1. 转换故障优势
- **线性复杂度**: 故障数与电路规模成正比
- **简单建模**: 转换为固定型故障
- **广泛支持**: 工业界标准

### 2. 混合ATPG方法
- **GA + 确定性**: 结合全局搜索和精确求解
- **交替执行**: 发挥各自优势
- **种子技术**: 加速收敛

### 3. 性能指标
- **故障覆盖率**: 检测故障比例
- **测试时间**: 生成和应用时间
- **测试数据量**: 存储和传输成本
