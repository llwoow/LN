# IEEE 1149.1 TAP控制器状态机详细技术规范

## TAP控制器状态机完整实现

### 状态机概述

IEEE 1149.1标准的TAP控制器实现了一个16状态的有限状态机，用于控制测试数据寄存器和指令寄存器的操作。状态转换完全由TMS信号在TCK上升沿时的值决定。

## 状态机详细定义

### 状态编码和转换表

| 状态名称 | 状态编号 | TMS=0转换 | TMS=1转换 | 主要功能 |
|---------|---------|-----------|-----------|----------|
| Test-Logic-Reset | 0 | Run-Test-Idle (1) | Test-Logic-Reset (0) | 复位状态 |
| Run-Test-Idle | 1 | Run-Test-Idle (1) | Select-DR-Scan (2) | 空闲运行 |
| Select-DR-Scan | 2 | Capture-DR (3) | Select-IR-Scan (6) | 选择数据寄存器路径 |
| Capture-DR | 3 | Shift-DR (4) | Exit1-DR (5) | 捕获数据寄存器 |
| Shift-DR | 4 | Shift-DR (4) | Exit1-DR (5) | 移位数据寄存器 |
| Exit1-DR | 5 | Pause-DR (7) | Update-DR (8) | 退出数据寄存器移位 |
| Pause-DR | 7 | Pause-DR (7) | Exit2-DR (9) | 暂停数据寄存器移位 |
| Exit2-DR | 9 | Shift-DR (4) | Update-DR (8) | 继续数据寄存器移位 |
| Update-DR | 8 | Run-Test-Idle (1) | Select-DR-Scan (2) | 更新数据寄存器 |
| Select-IR-Scan | 6 | Capture-IR (10) | Test-Logic-Reset (0) | 选择指令寄存器路径 |
| Capture-IR | 10 | Shift-IR (11) | Exit1-IR (12) | 捕获指令寄存器 |
| Shift-IR | 11 | Shift-IR (11) | Exit1-IR (12) | 移位指令寄存器 |
| Exit1-IR | 12 | Pause-IR (13) | Update-IR (14) | 退出指令寄存器移位 |
| Pause-IR | 13 | Pause-IR (13) | Exit2-IR (15) | 暂停指令寄存器移位 |
| Exit2-IR | 15 | Shift-IR (11) | Update-IR (14) | 继续指令寄存器移位 |
| Update-IR | 14 | Run-Test-Idle (1) | Select-DR-Scan (2) | 更新指令寄存器 |

### 状态机操作流程

#### 数据寄存器操作序列

1. **选择数据寄存器路径**
   - Test-Logic-Reset → Run-Test-Idle → Select-DR-Scan

2. **完整数据寄存器操作**
   ```
   Capture-DR → Shift-DR → Exit1-DR → Pause-DR → Exit2-DR → Update-DR
   ```

3. **快速数据寄存器操作**
   ```
   Capture-DR → Shift-DR → Exit1-DR → Update-DR
   ```

#### 指令寄存器操作序列

1. **选择指令寄存器路径**
   - Select-DR-Scan → Select-IR-Scan

2. **完整指令寄存器操作**
   ```
   Capture-IR → Shift-IR → Exit1-IR → Pause-IR → Exit2-IR → Update-IR
   ```

3. **快速指令寄存器操作**
   ```
   Capture-IR → Shift-IR → Exit1-IR → Update-IR
   ```

## 指令编码详细规范

### 指令寄存器长度定义

指令寄存器长度由具体器件定义，常见长度为：
- 2位：简单器件
- 4位：标准器件
- 8位：复杂器件
- 16位：高度集成器件

### 必需指令编码

#### BYPASS指令
- **编码**：全'1'序列（长度N位全为1）
- **示例**：
  - 2位：11
  - 4位：1111
  - 8位：11111111
- **功能**：选择旁路寄存器，提供1位延迟路径

#### SAMPLE/PRELOAD指令
- **编码**：器件特定编码
- **功能**：
  - SAMPLE：在Capture-DR时采样输入引脚状态
  - PRELOAD：在Update-DR时预加载输出数据
- **操作流程**：
  1. 移位阶段：将数据移入BSR
  2. 更新阶段：将数据锁存到输出锁存器

#### EXTEST指令
- **编码**：器件特定编码
- **功能**：外部测试模式
- **操作**：
  - Capture-DR：捕获外部电路响应
  - Shift-DR：串行移出响应数据
  - Update-DR：驱动测试向量到输出

### 可选指令编码

#### INTEST指令
- **编码**：器件特定编码
- **功能**：内部测试模式
- **操作**：
  - 驱动内部节点到输出引脚
  - 捕获输入响应到BSR

#### IDCODE指令
- **编码**：器件特定编码
- **功能**：读取器件识别码
- **IDCODE格式**（32位）：
  ```
  [31]    = 1 (必须为1)
  [30:28] = 版本号
  [27:12] = 器件型号
  [11:1]  = 制造商代码
  [0]     = 1 (必须为1)
  ```

#### USERCODE指令
- **编码**：器件特定编码
- **功能**：读取用户自定义代码
- **格式**：32位用户定义数据

#### CLAMP指令
- **编码**：器件特定编码
- **功能**：将输出固定为预定义值
- **操作**：在Update-DR时将BSR数据驱动到输出

#### HIGHZ指令
- **编码**：器件特定编码
- **功能**：将所有输出置于高阻态
- **操作**：禁用所有输出驱动

### 寄存器选择表

| 指令类型 | 选择的寄存器 | 描述 |
|---------|-------------|------|
| EXTEST | BSR | 边界扫描寄存器 |
| SAMPLE/PRELOAD | BSR | 边界扫描寄存器 |
| INTEST | BSR | 边界扫描寄存器 |
| BYPASS | BYPASS | 旁路寄存器 |
| IDCODE | IDCODE | 器件识别寄存器 |
| USERCODE | USERCODE | 用户代码寄存器 |
| CLAMP | BSR | 边界扫描寄存器 |

## 数据流控制

### TDI-TDO数据路径

1. **路径选择**：根据当前指令选择寄存器
2. **数据移位**：在Shift-DR/IR状态进行串行移位
3. **数据捕获**：在Capture-DR/IR状态加载数据
4. **数据更新**：在Update-DR/IR状态锁存数据

### 时序控制

#### 时钟域
- **TCK**：测试时钟，独立于系统时钟
- **同步操作**：所有TAP操作与TCK同步

#### 建立和保持时间
- **TDI建立时间**：数据在TCK上升沿前稳定时间
- **TDI保持时间**：数据在TCK上升沿后保持时间
- **TMS建立时间**：模式选择信号建立时间

### 数据完整性

#### 奇偶校验
- **可选功能**：某些器件支持奇偶校验
- **实现方式**：在数据流中插入校验位

#### 错误检测
- **超时检测**：检测无效状态序列
- **数据校验**：验证移位数据的有效性

## 多器件链管理


1. **共享信号**：

2. **独立操作**：
