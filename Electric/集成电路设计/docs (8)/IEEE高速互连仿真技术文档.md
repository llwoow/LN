## 1. 引言

### 1.1 高速互连的定义

**"高速互连"**是指传播信号在端点之间传播所需时间不能被忽略的互连。

#### 1.1.1 电气长度分类

- **电气短互连**: 在最高工作频率下，互连长度物理上短于波长的约1/10
- **电气长互连**: 否则被称为"电气长"

#### 1.1.2 频率定义

对于梯形脉冲，频率与上升时间的关系为：

```
f_max ≈ 0.35 / t_rise
```

例如：
- 上升时间 0.1ns → 最大频率约 3GHz
- 最小波长约 10cm

### 1.2 高速互连问题

#### 1.2.1 主要挑战

- **混合频域/时域问题**: 分布式传输线在频域描述，非线性器件在时域描述
- **CPU开销**: 大型网络的仿真计算量大

#### 1.2.2 影响因素

主要决策因素：
- 互连长度
- 横截面尺寸
- 信号边沿速率
- 时钟速度
- 逻辑电平
- 介质材料
- 导体电阻

## 2. 高速互连效应

### 2.1 传播延迟

- **定义**: 信号从传输线一端传播到另一端需要有限时间
- **延迟计算**: 飞行时间 = 走线长度 / 传播速度
- **上升时间退化**: 接收端上升时间 > 源端上升时间

### 2.2 衰减

#### 2.2.1 欧姆损耗
- **频率特性**: 高频时由于电流分布不均匀而更显著
- **集肤效应**: 电流集中在导体表面附近

#### 2.2.2 传导损耗
- **介质损耗**: 与介质的介电损耗因子成正比
- **频率依赖**: 也是频率的函数

### 2.3 信号反射和振铃

#### 2.3.1 反射机制

**反射系数公式**:
```
ρ = (Z_load - Z₀) / (Z_load + Z₀)
```

#### 2.3.2 不连续性类型

**分布式不连续**:
- 介质沿走线长度变化
- PCB多层间的阻抗控制问题

**集总不连续**:
- 连接器
- 过孔
- 正交布线
- Flip-chip焊球
- 引线键合

#### 2.3.3 过冲和下冲

- **下冲**: 端接阻抗 < 特性阻抗时发生
- **过冲**: 端接阻抗 > 特性阻抗时发生
- **振铃**: 随互连延迟增加而增加

### 2.4 串扰

#### 2.4.1 串扰机制

- **电磁耦合**: 通过互电容和互电感耦合
- **噪声电压-电流**: 可能导致意外开关
- **系统故障**: 高速设计中的主要约束

#### 2.4.2 模态分析

- **主导传播模式**: 基于主导传播模式研究
- **线性组合**: 任何一般激励的响应是模态响应的线性组合

## 3. 分布式传输线方程

### 3.1电报员方程

对于单导体传输线：

```
∂V/∂z = -L ∂I/∂t - RI
∂I/∂z = -C ∂V/∂t - GV
```

### 3.2 频域表示

拉普拉斯变换后：
```
dV/dz = -Z(s)I
dI/dz = -Y(s)V
```

其中：
- Z(s) = R + sL (单位长度阻抗)
- Y(s) = G + sC (单位长度导纳)

### 3.3 传播常数

```
γ = √(Z(s)Y(s)) = α + jβ
```

- α: 衰减常数 (nepers/m)
- β: 相位常数 (radians/m)

### 3.4 多导体传输线 (MTL)

#### 3.4.1 矩阵形式

```
dV/dz = -Z(s)I
dI/dz = -Y(s)V
```

其中：
- V, I: 电压和电流向量
- Z(s), Y(s): 阻抗和导纳矩阵

#### 3.4.2 MTL特性

- **对称性**: R, L, G, C 矩阵对称且正定
- **模态变换**: 通过模态变换矩阵解耦
- **特征值问题**: 特征方程 det(ZY - γ²I) = 0

### 3.5 MTL戳记 (Stamp)

#### 3.5.1 Y参数形式

```
[I₁]   [Y₁₁  Y₁₂] [V₁]
[I₂] = [Y₂₁  Y₂₂] [V₂]
```

#### 3.5.2 矩阵指数形式

```
[V₂]   [A  B] [V₁]
[I₂] = [C  D] [I₁]
```

#### 3.5.3 ABCD参数

```
[V₁]   [A  B] [V₂]
[I₁] = [C  D] [-I₂]
```

## 4. 电路方程公式化

### 4.1 修改节点分析 (MNA)

#### 4.1.1 线性网络

时域MNA方程：
```
Gx(t) + Cx'(t) = Bu(t)
```

频域形式：
```
(G + sC)x(s) = Bu(s)
```

#### 4.1.2 非线性网络

```
Gx(t) + Cx'(t) + f(x(t)) = Bu(t)
```

其中 f(x) 是非线性函数。

### 4.2 分布式元素公式化

#### 4.2.1 线性子网络

包含分布式元素的频域方程：
```
[G + sC + Y(s)]x(s) = Bu(s)
```

#### 4.2.2 通用非线性电路

```
Gx(t) + Cx'(t) + f(x(t)) + ΓᵀI_dist(t) = Bu(t)
```

### 4.3 仿真瓶颈

#### 4.3.1 混合频域/时域问题

- **分布式元素**: 频域描述
- **非线性器件**: 时域描述
- **传统求解器限制**: 如SPICE无法直接处理

#### 4.3.2 CPU开销

- **频域仿真**: 每个频率点都需要LU分解
- **时域仿真**: 每个时间点都需要牛顿迭代
- **矩阵规模**: 互连网络的矩阵通常很大

## 5. 基于传输线宏模型的仿真技术

### 5.1 传统离散化方法

#### 5.1.1 分段方法

将传输线分成N段，每段长度为Δz：

- **电气短段**: Δz << λ (在感兴趣频率下)
- **集总模型**: 每段用电阻R、电感L、电容C、电导G表示

#### 5.1.2 段数计算

对于3dB截止频率：
```
f_3dB = 1/(2π√(LC))
```

关系式：
```
N ≈ τ_total / (t_rise/10)
```

**示例**:
- 上升时间: 0.2ns
- 走线长度: 10cm
- 单位延迟: 70.7ps
- 需要段数: 35段

### 5.2 特性方法 (Method of Characteristics)

#### 5.2.1 基本原理

将传输线的偏微分方程转换为包含时延控制源的常微分方程。

#### 5.2.2 频域解

对于无损耗线：
```
V₂ = e^(-sτ)(V₁ - Z₀I₁) + Z₀I₂
I₂ = e^(-sτ)(I₁ - V₁/Z₀) + V₂/Z₀
```

其中 τ 是传播延迟。

#### 5.2.3 时域实现

无损耗情况下：
```
v₂(t-τ) = v₁(t-τ) - Z₀i₁(t-τ)
i₂(t-τ) = i₁(t-τ) - v₁(t-τ)/Z₀
```

### 5.3 传递函数近似

#### 5.3.1 最小二乘拟合

将频率响应拟合为复有理函数：
```
H(s) = Σ[k=1 to N] [rₖ/(s - pₖ)] + c
```

#### 5.3.2 稳定性保证

- **左半平面极点**: 通过拟合实部（偶函数）确保稳定性
- **极点计算**: 计算分母多项式的根
- **残数计算**: 通过匹配实部和虚部数据

### 5.4 Chebyshev多项式

#### 5.4.1 展开形式

```
V(z,t) = Σ[n=0 to N] vₙ(t)Tₙ(ξ)
I(z,t) = Σ[n=0 to N] iₙ(t)Tₙ(ξ)
```

其中 ξ 是归一化空间坐标。

#### 5.4.2 优势

- **非均匀线**: 可处理非均匀线参数
- **精度**: 与直接集总分段相比用更少变量达到更好精度
- **限制**: 不保证无源性

### 5.5 紧致有限差分

#### 5.5.1 空间离散化

```
αV'(zⱼ₋₁) + V'(zⱼ) + αV'(zⱼ₊₁) = β[V(zⱼ₊₁) - V(zⱼ₋₁)]/(2Δz)
```

#### 5.5.2 优势

- **精度**: 与直接分段相比用更少变量
- **无源性**: 保证宏模型的无源性
- **端点处理**: 需要适当的端点修正

### 5.6 指数Padé近似

#### 5.6.1 矩阵有理函数

```
e^(Aτ) ≈ P(q)/Q(q)
```

其中 P 和 Q 是用闭式Padé有理函数表示的多项式矩阵。

#### 5.6.2 优势

- **闭式解**: 所有系数预先已知
- **无病态**: 不受直接Padé应用常见病态影响
- **无源性**: 保证降阶模型的无源性

## 6. 基于模型降阶的仿真算法

### 6.1 主导极点概念

#### 6.1.1 极点分类

- **主导极点**: 接近虚轴，对系统时间和频率特性有显著影响
- **非主导极点**: 远离虚轴，影响较小

#### 6.1.2 矩匹配技术 (MMT)

**核心思想**: 无论系统中存在多少极点，只有主导极点就足以准确表征给定系统。

### 6.2 矩的概念

#### 6.2.1 传递函数矩

传递函数在 s=0 处的泰勒级数展开：
```
H(s) = m₀ + m₁s + m₂s² + m₃s³ + ...
```

#### 6.2.2 时域矩

矩与冲激响应的关系：
```
mₖ = ∫[0 to ∞] t^k h(t) dt
```

#### 6.2.3 Elmore延迟

Elmore延迟匹配第一矩：
```
τ_d ≈ m₁ = ∫[0 to ∞] t h(t) dt
```

### 6.3 算法分类

#### 6.3.1 显式矩匹配

- **AWE**: 渐近波形评估
- **CFH**: 复频率跳跃
- 直接匹配矩

#### 6.3.2 隐式矩匹配

- **PVL**: Padé via Lanczos
- **PRIMA**: 被动约化互连宏模型算法
- 基于Krylov子空间

## 7. 显式矩匹配技术

### 7.1 Padé近似

#### 7.1.1 近似形式

将传递函数近似为有理函数：
```
H(s) ≈ P(s)/Q(s) = (b₀ + b₁s + ... + bₘs^m)/(a₀ + a₁s + ... + aₙs^n)
```

#### 7.1.2 矩匹配

通过匹配前 (m+n+1) 个矩：
```
m₀, m₁, ..., m_{m+n}
```

#### 7.1.3 系数求解

**分母系数** (通过Toeplitz矩阵):
```
[m₀  m₁  m₂ ... mₙ] [aₙ]   [mₙ₊₁]
[m₁  m₀  m₁ ... mₙ₋₁] [aₙ₋₁] = [mₙ₊₂]
[ ...  ...  ...  ... ] [ ... ] [ ... ]
[mₙ  mₙ₋₁ mₙ₋₂ ... m₀] [a₀]   [m₂ₙ₊₁]
```

**分子系数**: 通过匹配剩余矩求解

### 7.2 矩计算

#### 7.2.1 集总电路矩

对于MNA方程：
```
(G + sC)x(s) = Bu(s)
```

矩的递推关系：
```
m₀ = -G⁻¹B
m₁ = -G⁻¹Cm₀
m₂ = -G⁻¹Cm₁
...
```

#### 7.2.2 传输线矩

对于指数戳记：
```
e^(Aτ) = I + Aτ + (Aτ)²/2! + (Aτ)³/3! + ...
```

递推关系：
```
M₀ = I
M₁ = AM₀
M₂ = AM₁/2
M₃ = AM₂/3
...
```

### 7.3 AWE限制

#### 7.3.1 数值问题

- **病态Toeplitz矩阵**: 随矩阵大小增加而恶化
- **不稳定极点**: Padé常产生右半平面极点
- **精度衰减**: 远离展开点时精度下降
- **无误差估计**: 不提供误差界限估计

#### 7.3.2 极点数量限制

单次展开通常只能获得6-8个准确极点。

### 7.4 复频率跳跃 (CFH)

#### 7.4.1 多点展开

CFH将矩匹配扩展到复平面中多个展开点（跳跃）。

#### 7.4.2 二分搜索算法

**基于传递函数的搜索**:
1. 在频率范围内选择两个初始点
2. 计算两个点的传递函数
3. 在中间点比较传递函数值
4. 如果误差超过阈值，继续搜索
5. 重复直到达到精度要求

**基于极点的搜索**:
1. 在相邻展开点比较极点
2. 如果找到匹配极点，停止搜索
3. 否则在两点间插入新点

#### 7.4.3 优势

- **准确性**: 在整个频率范围内提供准确性
- **误差控制**: 提供误差准则
- **极点集**: 生成准确的极点集

## 8. Krylov子空间技术

### 8.1 直接Padé问题

#### 8.1.1 病态原因

当显式计算高阶矩时：
```
mₖ = (-G⁻¹C)^k G⁻¹B
```

对于大的k，序列快速收敛到最大特征值的特征向量，导致矩矩阵的行几乎平行。

#### 8.1.2 特征值与极点关系

对于系统：
```
H(s) = cᵀ(sI - A)⁻¹b
```

- **极点**: 是 A 特征值的倒数
- **主导极点**: 对应最大特征值的极点

### 8.2 正交矩阵

#### 8.2.1 定义

实矩阵 Q 是正交的，如果：
```
QᵀQ = I
```

#### 8.2.2 性质

- **单位范数**: ||qᵢ||₂ = 1
- **正交性**: qᵢᵀqⱼ = 0 (i ≠ j)
- **逆矩阵**: Q⁻¹ = Qᵀ

### 8.3 QR分解

#### 8.3.1 分解形式

对于 m×n 矩阵 A (m ≥ n)：
```
A = QR
```

其中：
- Q: m×m 正交矩阵
- R: m×n 上三角矩阵

#### 8.3.2 计算方法

- **修正Gram-Schmidt正交化**
- **Householder变换**
- **Givens旋转**

### 8.4 上Hessenberg矩阵

#### 8.4.1 定义

矩阵 H 是上Hessenberg，如果：
```
hᵢⱼ = 0 (i > j+1)
```

#### 8.4.2 伴随形式

```
H = [h₁₁ h₁₂ h₁₃ ... h₁ₙ]
    [h₂₁ h₂₂ h₂₃ ... h₂ₙ]
    [0   h₃₂ h₃₃ ... h₃ₙ]
    [... ... ... ... ...]
    [0   0   ... hₙₙ₋₁ hₙₙ]
```

### 8.5 Arnoldi算法

#### 8.5.1 Krylov子空间

Krylov子空间：
```
Kₖ(A,v) = span{v, Av, A²v, ..., Aᵏ⁻¹v}
```

#### 8.5.2 Arnoldi过程

**算法步骤**:
1. q₁ = v/||v||
2. 对 k = 1,2,...,m:
   - hᵢₖ = qᵢᵀAqₖ (i = 1 to k)
   - w = Aqₖ - Σ[i=1 to k] hᵢₖqᵢ
   - hₖ₊₁ₖ = ||w||
   - qₖ₊₁ = w/hₖ₊₁ₖ

#### 8.5.3 优势

- **正交基**: 生成Krylov子空间的正交基
- **避免病态**: 避免直接矩计算的病态问题
- **部分约化**: 可以只计算所需数量的列

### 8.6 电路降阶

#### 8.6.1 变量变换

通过正交矩阵 Q 映射：
```
x = Qz
```

其中 x 是原始变量，z 是降阶变量。

#### 8.6.2 降阶系统

```
(G̃ + sC̃)z(s) = B̃u(s)
```

其中：
```
G̃ = QᵀGQ
C̃ = QᵀCQ
B̃ = QᵀB
```

#### 8.6.3 传递函数

```
H̃(s) = B̃ᵀ(G̃ + sC̃)⁻¹B̃
```

#### 8.6.4 矩匹配性质

降阶系统保留前 2k 个矩，而直接Padé只保留前 k 个矩。

### 8.7 多端口降阶

#### 8.7.1 块矩

对于多端口系统：
```
Mₖ = (G⁻¹C)^k G⁻¹B
```

其中 B 是 m×p 矩阵（p 是端口数）。

#### 8.7.2 块Arnoldi

使用块矩构造Krylov子空间：
```
Kₖ(A,B) = span{B, AB, A²B, ..., Aᵏ⁻¹B}
```

#### 8.7.3 块Hessenberg形式

生成块上Hessenberg矩阵 Hₖ。

## 9. 无源性保持

### 9.1 无源性定义

#### 9.1.1 网络无源性

网络不能产生超过其吸收的能量，且任何无源性端接都不会使系统不稳定。

#### 9.1.2 数学条件

对于导纳矩阵 Y(s) 表示的网络是无源的，当且仅当：

1. **正实性**: Y(s) + Y*(s) ≥ 0 (对所有 Re(s) > 0)
2. **PR矩阵**: 对所有 Re(s) > 0 和任意向量 x，有 x*Y(s)x 的实部 ≥ 0

### 9.2 无源性重要性

#### 9.2.1 稳定性问题

稳定但不无源的宏模型在连接到其他无源系统时可能导致不稳定。

#### 9.2.2 人工振荡

非无源网络的瞬态仿真可能遇到人工振荡。

### 9.3 PRIMA算法

#### 9.3.1 经典Arnoldi问题

经典Arnoldi在方程 (G + sC)x = Bu 上应用，不保持无源性。

#### 9.3.2 PRIMA方法

在原始方程上应用Arnoldi：
```
Gx + Cẋ = Bu
```

#### 9.3.3 全等变换

使用全等变换：
```
G̃ = QᵀGQ
C̃ = QᵀCQ
```

#### 9.3.4 无源性证明

如果原始 G 和 C 是对称非负定的，则降阶模型是无源的。

### 9.4 MNA公式兼容性

#### 9.4.1 公式化条件

```
G = [G₁₁  G₁₂]    C = [C₁₁  C₁₂]
    [G₂₁  G₂₂]        [C₂₁  C₂₂]
```

满足：
- G₁₁ 对称非负定
- C₁₁ 对称非负定
- G₂₁ = -G₁₂ᵀ, G₂₂ = -G₂₂ᵀ

#### 9.4.2 元素贡献

- **电阻**: 对G₁₁有正贡献
- **电容**: 对C₁₁有正贡献
- **电感**: 对C₁₁有负贡献（需特殊处理）

## 性能分析

### 1. 计算复杂度

#### 1.1 直接仿真
- **频域**: O(N³f) (N: 矩阵大小, f: 频率点数)
- **时域**: O(N³T) (T: 时间步数)

#### 1.2 模型降阶
- **AWE**: O(N²k) (k: 匹配矩数)
- **Arnoldi**: O(N²m) (m: 降阶阶数)
- **PRIMA**: 类似于Arnoldi

### 2. 精度分析

#### 2.1 矩匹配精度
- **匹配矩数**: 决定近似精度
- **展开点**: 影响频率响应精度
- **极点位置**: 主导极点重要性

#### 2.2 收敛性
- **Padé收敛**: 受展开点影响
- **Arnoldi收敛**: 随阶数增加
- **CFH收敛**: 二分搜索控制

### 3. 稳定性

#### 3.1 数值稳定性
- **条件数**: 矩阵良态性
- **舍入误差**: 浮点运算影响
- **算法选择**: 稳定算法重要性

#### 3.2 系统稳定性
- **无源性**: 保证与无源系统连接稳定
- **极点位置**: 左半平面要求
- **Lyapunov稳定性**: 系统矩阵性质
