# 延迟故障模型技术文档

## 概述

延迟故障模型是数字电路测试和验证中的重要概念，主要用于检测电路中的时序问题。本文详细介绍了过渡故障、门延迟故障、路径延迟故障和段延迟故障等主要模型的定义、数学公式和应用方法。

## 1. 过渡故障模型（Transition Fault Model）

### 1.1 定义
过渡故障模型是最简单的延迟故障模型，主要检测电路中信号从0到1（上升沿）或从1到0（下降沿）的转换是否在规定时间内完成。

### 1.2 数学表示
对于一个逻辑门或连线，过渡故障可以表示为：
- 上升过渡故障：slow-to-rise (STR)
- 下降过渡故障：slow-to-fall (STF)

### 1.3 检测条件
```
T_delay > T_specified
```
其中：
- T_delay：实际传播延迟
- T_specified：规范规定的最大允许延迟

### 1.4 应用方法
1. **测试向量生成**：生成能够激励目标过渡的输入向量对
2. **时序约束**：确保测试时钟周期足够长以检测延迟故障
3. **故障检测**：通过比较实际输出与期望输出检测故障

## 2. 门延迟故障模型（Gate Delay Fault Model）

### 2.1 定义
门延迟故障模型假设逻辑门本身的传播延迟超过其规范值，每个逻辑门可能存在独立的延迟故障。

### 2.2 数学模型
对于一个n输入逻辑门G，其延迟故障可以表示为：

```
D_G = { (gate_input_pattern, delay_value) | delay_value > T_gate_max }
```

其中：
- T_gate_max：门电路的最大允许延迟
- gate_input_pattern：导致最大延迟的输入模式

### 2.3 检测条件
门延迟故障的检测需要满足以下条件：
1. **激活条件**：输入向量必须激活目标门
2. **传播条件**：故障效应必须能够传播到电路输出
3. **观测条件**：输出端的时序差异必须可观测

### 2.4 数学公式
```
F_detected = ∃(v_in, v_test) such that:
- v_in activates the fault
- v_test propagates fault effect to output
- T_propagation > T_clock_period
```

## 3. 路径延迟故障模型（Path Delay Fault Model）

### 3.1 定义
路径延迟故障模型考虑整个信号路径上的累积延迟，每个从输入到输出的路径都可能存在延迟故障。

### 3.2 数学表示
对于一条从输入i到输出o的路径P，其延迟故障表示为：

```
D_P = { delay_path(P) > T_path_specified }
```

路径延迟的计算公式：
```
delay_path(P) = Σ(delay_gate_j) + Σ(delay_wire_k)
```

其中：
- delay_gate_j：路径P上第j个门的延迟
- delay_wire_k：路径P上第k段连线的延迟

### 3.3 路径分类
1. **敏感路径**：对输入变化敏感的路径
2. **非敏感路径**：对输入变化不敏感的路径
3. **冗余路径**：不影响电路功能的路径

### 3.4 检测条件
路径延迟故障检测需要：
1. **路径激活**：输入向量必须激活目标路径
2. **路径敏化**：故障效应必须沿路径传播
3. **时序检测**：累积延迟超过时钟周期

### 3.5 数学公式
路径延迟故障的检测条件：
```
∃ input_vector v such that:
- P is activated by v
- P is sensitized by v  
- delay_path(P) > T_clock
```

## 4. 段延迟故障模型（Segment Delay Fault Model）

### 4.1 定义
段延迟故障模型是路径延迟故障和门延迟故障的折中，将电路划分为若干段（segment），每个段包含一个或多个逻辑门。

### 4.2 数学表示
对于一个段S，其延迟故障表示为：
```
D_S = { delay_segment(S) > T_segment_specified }
```

段延迟的计算：
```
delay_segment(S) = Σ(delay_gate_i) + Σ(delay_wire_j)
```

其中S是路径的一个连续子集。

### 4.3 段划分策略
1. **固定长度段**：每段包含固定数量的门
2. **功能相关段**：基于功能单元划分
3. **时序相关段**：基于时序路径划分

### 4.4 检测优势
- 减少了需要测试的故障数量
- 保持了较好的故障覆盖率
- 降低了测试向量生成的复杂度

## 5. 延迟故障测试方法

### 5.1 .launch-capture 测试方法

#### 5.1.1 基本原理
```
Clock 1: 加载输入向量V1 (Launch)
Clock 2: 捕获输出向量V2 (Capture)
```

#### 5.1.2 数学模型
测试时钟周期：
```
T_test = T_launch + T_capture + T_margin
```

其中：
- T_launch：launch时钟周期
- T_capture：capture时钟周期  
- T_margin：时序裕量

### 5.2 扫描链测试

#### 5.2.1 时序约束
```
T_scan_clock ≥ T_setup + T_hold + T_clock_skew
```

#### 5.2.2 延迟测试序列
1. **扫描移位**：将测试向量加载到扫描链
2. **功能时钟**：执行功能操作
3. **扫描移出**：捕获并移出响应

### 5.3 自测试方法（BIST）

#### 5.3.1 内置自测试结构
```
LFSR → CUT → MISR
```

其中：
- LFSR：线性反馈移位寄存器（测试向量生成器）
- CUT：被测电路
- MISR：多输入签名寄存器（响应压缩器）

#### 5.3.2 故障检测条件
```
signature_fault ≠ signature_golden
```

- 时序sign-off验证

## 7. 实际应用示例

### 7.1 组合逻辑电路延迟测试

考虑一个4位加法器电路：

```verilog
module adder_4bit (
    input [3:0] a, b,
    input cin,
    output [3:0] sum,
    output cout
);
```

**过渡故障测试向量对**：
```
V1: a=0000, b=0000, cin=0 → 期望输出: sum=0000, cout=0
V2: a=1111, b=0000, cin=1 → 期望输出: sum=0000, cout=1
```

**路径延迟测试**：
- 关键路径：cin → cout
- 延迟预算：T_cin_to_cout = 4 × T_gate + 3 × T_wire

### 7.2 时序逻辑电路延迟测试

考虑一个D触发器：

```verilog
module d_flip_flop (
    input clk, d,
    output reg q
);
always @(posedge clk)
    q <= d;
```

**建立时间故障测试**：
```
T_setup_violation = T_data_arrival - T_clock_arrival < 0
```

**保持时间故障测试**：
```
T_hold_violation = T_data_change - T_clock_arrival < 0
```

```python
# 延迟故障测试向量生成示例
def generate_transition_vectors(circuit):
    vectors = []
    for gate in circuit.gates:
        # 生成上升过渡测试向量
        rise_vector = generate_rise_test_vector(gate)
        # 生成下降过渡测试向量
        fall_vector = generate_fall_test_vector(gate)
        vectors.extend([rise_vector, fall_vector])

def calculate_path_delay(path):
    total_delay = 0
    for element in path.elements:
        if element.type == 'gate':
            total_delay += element.gate_delay
        elif element.type == 'wire':
            total_delay += element.wire_delay
    return total_delay
```

## 10. 总结

延迟故障模型是数字电路测试领域的核心技术，不同的模型适用于不同的应用场景：

1. **过渡故障模型**：简单高效，适用于快速验证
2. **门延迟故障模型**：平衡了覆盖率和复杂度
3. **路径延迟故障模型**：提供最完整的时序验证
4. **段延迟故障模型**：工业应用的最佳选择

选择合适的延迟故障模型需要考虑电路复杂度、性能要求、测试时间和成本等因素。随着集成电路技术的不断发展，延迟故障测试技术也在持续演进，以应对新的挑战。
