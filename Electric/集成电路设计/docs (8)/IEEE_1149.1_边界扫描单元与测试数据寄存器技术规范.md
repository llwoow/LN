# IEEE 1149.1 边界扫描单元与测试数据寄存器技术规范

## 概述

本文档详细描述了IEEE 1149.1标准中边界扫描单元（Boundary Scan Cell）和测试数据寄存器（Test Data Register）的技术实现规范，包括硬件结构、操作模式、时序要求和应用方法。

## 1. 边界扫描单元（BSC）详细设计

### 1.1 边界扫描单元类型分类

#### 1.1.1 输入型边界扫描单元（Input BSC）

**功能特性：**
- 捕获外部输入信号
- 提供串行测试数据路径
- 支持正常信号传递

**硬件结构：**
```verilog
module input_bsc (
    input wire clk,           // TCK时钟
    input wire mode,          // 模式控制
    input wire capture_en,    // 捕获使能
    input wire shift_en,      // 移位使能
    input wire update_en,     // 更新使能
    input wire system_in,     // 系统输入信号
    input wire scan_in,       // 扫描输入（TDI）
    output wire scan_out,     // 扫描输出（TDO）
    output wire system_out    // 系统输出信号
);
```

**内部实现：**
```verilog
// 捕获触发器
always @(posedge clk) begin
    if (capture_en)
        capture_reg <= system_in;
end

// 移位寄存器
always @(posedge clk) begin
    if (shift_en)
        shift_reg <= {scan_in, shift_reg[MSB-1:0]};
end

// 更新锁存器
always @(posedge clk) begin
    if (update_en)
        update_reg <= shift_reg[0];
end

// 输出选择逻辑
assign system_out = mode ? update_reg : system_in;
assign scan_out = shift_reg[MSB-1];
```

#### 1.1.2 输出型边界扫描单元（Output BSC）

**功能特性：**
- 控制输出信号驱动
- 提供测试数据输出
- 支持三态控制

**硬件结构：**
```verilog
module output_bsc (
    input wire clk,
    input wire mode,
    input wire capture_en,
    input wire shift_en,
    input wire update_en,
    input wire system_in,     // 系统内部信号
    input wire scan_in,
    output wire scan_out,
    output wire system_out,
    output wire output_enable // 输出使能控制
);
```

**三态控制实现：**
```verilog
// 输出使能逻辑
assign output_enable = mode ? 1'b1 : 1'bz;

// 输出驱动逻辑
assign system_out = mode ? update_reg : system_in;

// 捕获逻辑
always @(posedge clk) begin
    if (capture_en)
        capture_reg <= system_in;
end
```

#### 1.1.3 双向型边界扫描单元（Bidirectional BSC）

**功能特性：**
- 控制双向I/O引脚
- 支持输入和输出模式
- 动态方向控制

**硬件结构：**
```verilog
module bidirectional_bsc (
    input wire clk,
    input wire mode,
    input wire io_mode,       // I/O方向控制
    input wire capture_en,
    input wire shift_en,
    input wire update_en,
    input wire system_io,     // 系统I/O信号
    input wire scan_in,
    output wire scan_out,
    output wire system_io_out,
    output wire output_enable
);
```

**双向控制逻辑：**
```verilog
// 方向控制
assign output_enable = mode ? ~io_mode : 1'bz;

// 数据路径选择
assign system_io_out = mode ? update_reg : system_io;

// 输入捕获（当方向为输入时）
always @(posedge clk) begin
    if (capture_en && !io_mode)
        capture_reg <= system_io;
end
```

### 1.2 边界扫描单元操作模式

#### 1.2.1 正常模式（Normal Mode）

**特征：**
- 信号直接通过，不受边界扫描影响
- 系统性能不受影响
- 边界扫描电路处于低功耗状态

**实现：**
```verilog
assign system_io = mode ? 1'bz : system_io_in;
assign system_io_out = mode ? update_reg : system_io_in;
```

#### 1.2.2 测试模式（Test Mode）

**捕获阶段（Capture Phase）：**
- 在TCK上升沿捕获输入信号
- 加载固定测试模式（如'0'、'1'、或输入信号）
- 为移位阶段准备数据

**移位阶段（Shift Phase）：**
- 串行移位数据通过边界扫描链
- LSB首先移出到TDO
- 支持双向数据流

**更新阶段（Update Phase）：**
- 将移位寄存器数据锁存到输出锁存器
- 驱动输出信号或控制信号
- 完成测试向量应用

### 1.3 边界扫描单元时序规范

#### 1.3.1 时钟要求

**TCK信号特性：**
- 最大频率：通常10-100 MHz（取决于工艺）
- 占空比：40%-60%
- 上升/下降时间：< 10 ns

**建立和保持时间：**
```verilog
// 时序约束示例
// 输入信号建立时间
specify
    $setup(system_in, posedge clk, 2ns);
    $hold(posedge clk, system_in, 1ns);
endspecify
```

#### 1.3.2 数据路径延迟

**关键路径延迟：**
- 捕获路径延迟：< 5 ns
- 移位路径延迟：< 3 ns
- 更新路径延迟：< 4 ns

#### 1.3.3 功耗特性

**各模式功耗：**
- 正常模式：< 1 μA/MHz
- 测试模式：< 10 μA/MHz
- 复位模式：< 0.1 μA

## 2. 测试数据寄存器详细规范

### 2.1 边界扫描寄存器（BSR）

#### 2.1.1 BSR结构

**寄存器组成：**
```verilog
module boundary_scan_register (
    input wire clk,
    input wire tdi,
    input wire tms,
    input wire capture_dr,
    input wire shift_dr,
    input wire update_dr,
    input wire [N-1:0] system_inputs,
    output wire [N-1:0] system_outputs,
    output wire tdo
);
parameter N = 8; // 寄存器宽度

// 边界扫描单元数组
genvar i;
generate
    for (i = 0; i < N; i = i + 1) begin : bsc_array
        boundary_scan_cell bsc_inst (
            .clk(clk),
            .mode(tms), // 使用TMS作为模式控制
            .capture_en(capture_dr),
            .shift_en(shift_dr),
            .update_en(update_dr),
            .system_io(system_io[i]),
            .scan_in(i == 0 ? tdo : bsc_array[i-1].scan_out),
            .scan_out(bsc_out[i]),
            .system_io_out(system_outputs[i])
        );
    end
endgenerate

assign tdo = bsc_out[N-1];
```

#### 2.1.2 BSR操作序列

**数据加载序列：**
1. **选择数据寄存器路径**
   ```
   TMS序列: 0 → 1 → 0 → 0 (Select-DR-Scan)
   ```

2. **捕获阶段**
   ```
   TMS序列: 0 → 0 (Capture-DR)
   动作: 捕获输入信号到捕获寄存器
   ```

3. **移位阶段**
   ```
   TMS序列: 0 (Shift-DR)
   动作: 串行移位数据 N 个时钟周期
   ```

4. **更新阶段**
   ```
   TMS序列: 1 → 0 (Update-DR)
   动作: 更新输出锁存器
   ```

#### 2.1.3 BSR数据格式

**标准数据格式：**
```
位位置: [N-1] [N-2] ... [1] [0]
        ↑                   ↑
       TDO                 TDI
```

**示例（8位BSR）：**
```
移位前: [D7][D6][D5][D4][D3][D2][D1][D0]
移位1:  [X] [D7][D6][D5][D4][D3][D2][D1]
移位2:  [X] [X] [D7][D6][D5][D4][D3][D2]
...
移位8:  [X] [X] [X] [X] [X] [X] [X] [D7]
```

### 2.2 旁路寄存器（BYPASS）

#### 2.2.1 BYPASS寄存器结构

**单位移位寄存器：**
```verilog
module bypass_register (
    input wire clk,
    input wire tdi,
    input wire capture_dr,
    input wire shift_dr,
    output wire tdo
);

reg bypass_reg;

// 捕获逻辑：加载'0'
always @(posedge clk) begin
    if (capture_dr)
        bypass_reg <= 1'b0;
    else if (shift_dr)
        bypass_reg <= tdi;
end

assign tdo = bypass_reg;
endmodule
```

#### 2.2.2 BYPASS操作

**操作时序：**
1. **捕获阶段**：自动加载'0'
2. **移位阶段**：1位延迟通过
3. **更新阶段**：无操作（单位寄存器）

**应用场景：**
- 多芯片链中的路径优化
- 跳过不需要测试的器件
- 减少测试时间

### 2.3 器件识别寄存器（IDCODE）

#### 2.3.1 IDCODE寄存器结构

**32位移位寄存器：**
```verilog
module idcode_register (
    input wire clk,
    input wire tdi,
    input wire capture_dr,
    input wire shift_dr,
    output wire tdo,
    output wire [31:0] idcode_data
);

// IDCODE数据格式
parameter [31:0] IDCODE_VALUE = 32'h12345678;

// 移位寄存器
reg [31:0] shift_reg;

always @(posedge clk) begin
    if (capture_dr)
        shift_reg <= IDCODE_VALUE;
    else if (shift_dr)
        shift_reg <= {tdi, shift_reg[31:1]};
end

assign tdo = shift_reg[0];
assign idcode_data = shift_reg;
endmodule
```

#### 2.3.2 IDCODE格式规范

**32位IDCODE定义：**
```
位[31]    = 1 (必须为1)
位[30:28] = 版本号 (Version)
位[27:12] = 器件型号 (Part Number)
位[11:1]  = 制造商代码 (Manufacturer ID)
位[0]     = 1 (必须为1)
```

**制造商代码分配：**
```
0x001: AMD
0x00E: Intel
0x01A: Texas Instruments
0x02D: Motorola
0x03B: National Semiconductor
...
```

**器件型号示例：**
```
器件型号格式: [15位制造商特定编码]
示例: 0x12345 (特定器件编码)
```

## 3. 寄存器选择和控制逻辑

### 3.1 寄存器选择器

**多路选择器实现：**
```verilog
module register_selector (
    input wire [IR_WIDTH-1:0] instruction,
    input wire tdi,
    input wire capture_dr,
    input wire shift_dr,
    input wire update_dr,
    output wire tdo,
    // 寄存器输入输出接口
    input wire [N-1:0] bsr_data_in,
    output wire [N-1:0] bsr_data_out,
    input wire bypass_data_in,
    output wire bypass_data_out,
    input wire [31:0] idcode_data,
    input wire [31:0] usercode_data
);

wire [N-1:0] bsr_tdo;
wire bypass_tdo;
wire idcode_tdo;
wire usercode_tdo;

// 寄存器实例化
boundary_scan_register bsr_inst (
    .clk(clk),
    .tdi(tdi),
    .capture_dr(capture_dr),
    .shift_dr(shift_dr),
    .update_dr(update_dr),
    .data_in(bsr_data_in),
    .data_out(bsr_data_out),
    .tdo(bsr_tdo)
);

bypass_register bypass_inst (
    .clk(clk),
    .tdi(tdi),
    .capture_dr(capture_dr),
    .shift_dr(shift_dr),
    .tdo(bypass_tdo)
);

idcode_register idcode_inst (
    .clk(clk),
    .tdi(tdi),
    .capture_dr(capture_dr),
    .shift_dr(shift_dr),
    .data(idcode_data),
    .tdo(idcode_tdo)
);

usercode_register usercode_inst (
    .clk(clk),
    .tdi(tdi),
    .capture_dr(capture_dr),
    .shift_dr(shift_dr),
    .data(usercode_data),
    .tdo(usercode_tdo)
);

// 选择逻辑
always @(*) begin
    case (instruction)
        BYPASS_CODE: tdo = bypass_tdo;
        IDCODE_CODE: tdo = idcode_tdo;
        USERCODE_CODE: tdo = usercode_tdo;
        default: tdo = bsr_tdo; // BSR作为默认选择
    endcase
end
endmodule
```

### 3.2 指令译码器

**指令译码实现：**
```verilog
module instruction_decoder (
    input wire [IR_WIDTH-1:0] instruction,
    output reg select_bypass,
    output reg select_idcode,
    output reg select_usercode,
    output reg select_bsr,
    output reg bsr_mode,
    output reg bypass_mode
);

always @(*) begin
    // 默认值
    select_bypass = 1'b0;
    select_idcode = 1'b0;
    select_usercode = 1'b0;
    select_bsr = 1'b0;
    bsr_mode = 1'b0;
    bypass_mode = 1'b0;
    
    case (instruction)
        BYPASS_CODE: begin
            select_bypass = 1'b1;
            bypass_mode = 1'b1;
        end
        
        IDCODE_CODE: begin
            select_idcode = 1'b1;
        end
        
        USERCODE_CODE: begin
            select_usercode = 1'b1;
        end
        
        EXTEST_CODE, SAMPLE_CODE, PRELOAD_CODE, INTEST_CODE: begin
            select_bsr = 1'b1;
            bsr_mode = 1'b1;
        end
        
        default: begin
            select_bsr = 1'b1; // 默认选择BSR
        end
    endcase
end
endmodule
```

### 4.2 数据完整性保证

#### 4.2.1 奇偶校验

**奇偶校验实现：**
```verilog
module parity_checker (
    input wire clk,
    input wire [DATA_WIDTH-1:0] data,
    input wire parity_bit_in,
    output wire parity_bit_out,
    output wire parity_error
);

reg [DATA_WIDTH:0] extended_data;
reg calculated_parity;

always @(posedge clk) begin
    extended_data = {parity_bit_in, data};
    calculated_parity = ^extended_data; // 异或运算计算奇偶性
end

assign parity_bit_out = calculated_parity;
assign parity_error = (calculated_parity != parity_bit_in);
endmodule
```

#### 4.2.2 错误检测和纠正

**汉明码实现：**
```verilog
module hamming_encoder (
    input wire [DATA_WIDTH-1:0] data_in,
    output wire [CODE_WIDTH-1:0] code_out
);

parameter DATA_WIDTH = 8;
parameter CODE_WIDTH = 13; // 8位数据需要13位汉明码

reg [CODE_WIDTH-1:0] hamming_code;

// 汉明码生成逻辑
always @(*) begin
    hamming_code[0] = data_in[0] ^ data_in[1] ^ data_in[3] ^ data_in[4] ^ data_in[6];
    hamming_code[1] = data_in[0] ^ data_in[2] ^ data_in[3] ^ data_in[5] ^ data_in[6];
    hamming_code[2] = data_in[1] ^ data_in[2] ^ data_in[3];
    hamming_code[3] = data_in[0] ^ data_in[1] ^ data_in[2] ^ data_in[4] ^ data_in[5] ^ data_in[6];
    hamming_code[4] = data_in[4] ^ data_in[6];
    hamming_code[5] = data_in[5] ^ data_in[6];
    hamming_code[6] = data_in[0];
    hamming_code[7] = data_in[1];
    hamming_code[8] = data_in[2];
    hamming_code[9] = data_in[3];
    hamming_code[10] = data_in[4];
    hamming_code[11] = data_in[5];
    hamming_code[12] = data_in[6];
end

assign code_out = hamming_code;
endmodule
```

## 5. 性能优化技术

### 5.1 速度优化

#### 5.1.1 流水线设计

**流水线边界扫描单元：**
```verilog
module pipelined_bsc (
    input wire clk,
    input wire [DATA_WIDTH-1:0] data_in,
    input wire scan_in,
    input wire shift_en,
    input wire update_en,
    output wire [DATA_WIDTH-1:0] data_out,
    output wire scan_out
);

reg [DATA_WIDTH-1:0] pipeline_reg;
reg [DATA_WIDTH-1:0] shift_reg;

// 第一级：输入捕获

    pipeline_reg <= data_in;
end

// 第二级：移位操作
always @(posedge clk) begin

        shift_reg <= {scan_in, pipeline_reg[DATA_WIDTH-1:1]};
end

// 输出更新
always @(posedge clk) begin
    if (update_en)
        data_out <= shift_reg[0];
end

assign scan_out = shift_reg[DATA_WIDTH-1];
endmodule
```

```verilog
module low_power_bsc (
```

```python
class InterconnectTestGenerator:
    def __init__(self, netlist):
        self.netlist = netlist
        
    def generate_vectors(self):
        """生成互连测试向量"""
        vectors = []
        
        for net in self.netlist.nets:
            # 生成驱动向量
            drive_vector = self.generate_drive_vector(net)
            # 生成响应向量
            response_vector = self.generate_response_vector(net)
            vectors.append((drive_vector, response_vector))
            
        return vectors
    
    def generate_drive_vector(self, net):
        """生成驱动测试向量"""
        vector = {}
        
        # 为每个连接的引脚生成测试向量
        for pin in net.pins:
            if pin.direction == 'output':
                vector[pin] = self.generate_output_vector(pin)
            elif pin.direction == 'input':
                vector[pin] = self.generate_input_vector(pin)
                
        return vector
    
    def generate_output_vector(self, pin):
        """为输出引脚生成测试向量"""
        # 生成全0、全1、跳变序列
        return {
            'all_zero': 0,
            'all_one': 1,
            'alternating': 0xAA if pin.width > 1 else 0,
            'walking_one': 1 << (pin.width - 1) if pin.width > 1 else 1
        }
```

```python
class StuckAtFault:
    def __init__(self, node, fault_type):
```

#### 7.1.2 桥接故障模型

**桥接故障检测：**
```python
class BridgingFault:
    def __init__(self, node1, node2, fault_type):
        self.node1 = node1
        self.node2 = node2
        self.fault_type = fault_type  # 'AND', 'OR', 'XOR'
    
    def detect_fault(self, circuit):
        """检测桥接故障"""
        val1 = circuit.get_node_value(self.node1)
        val2 = circuit.get_node_value(self.node2)
        
        if self.fault_type == 'AND':
            expected = val1 & val2
        elif self.fault_type == 'OR':
            expected = val1 | val2
        elif self.fault_type == 'XOR':
            expected = val1 ^ val2
            
        actual = circuit.get_node_value(self.node1)
        return expected != actual
```

### 7.2 诊断算法

#### 7.2.1 比较诊断

**诊断实现：**
```python
class DiagnosticEngine:
    def __init__(self, golden_circuit, test_circuit):
        self.golden = golden_circuit
        self.test = test_circuit
        
    def diagnose(self, test_vectors):
        """执行故障诊断"""
        faults = []
        
        for vector in test_vectors:
            golden_response = self.golden.simulate(vector)
            test_response = self.test.simulate(vector)
            
            if golden_response != test_response:
                fault_info = self.analyze_difference(golden_response, test_response)
                faults.append(fault_info)
                
        return self.localize_faults(faults)
    
    def analyze_difference(self, expected, actual):
        """分析响应差异"""
        differences = []
        
        for i, (exp, act) in enumerate(zip(expected, actual)):
            if exp != act:
                differences.append({
                    'position': i,
                    'expected': exp,
                    'actual': act,
                    'fault_probability': self.calculate_probability(exp, act)
                })
                
        return differences
```

#### 7.2.2 模式匹配诊断

**模式识别：**
```python
class PatternMatchingDiagnostic:
    def __init__(self):
        self.fault_patterns = self.load_fault_patterns()
        
    def match_pattern(self, response_vector):
        """匹配故障模式"""
        matches = []
        
        for pattern in self.fault_patterns:
            similarity = self.calculate_similarity(response_vector, pattern.response)
            if similarity > 0.8:  # 相似度阈值
                matches.append((pattern, similarity))
                
        return sorted(matches, key=lambda x: x[1], reverse=True)
    
    def calculate_similarity(self, vector1, vector2):
        """计算向量相似度"""
        matches = sum(1 for a, b in zip(vector1, vector2) if a == b)
        return matches / len(vector1)
```
