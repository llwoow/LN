## 摘要

本文提出了一种基于双离散几何方法(DGMs)的IC互连寄生电容工艺变化敏感度计算方法。该方法解决了集成电路制造工艺变化对电容提取精度影响的关键挑战。作者开发了基于DGM的敏感度分析框架，利用对偶公式的互补能量界限特性，相比传统有限元方法(FEM)在计算效率和精度方面都有显著改善。该方法利用标量电势作为未知量，通过对工艺参数的构成矩阵求导来推导敏感度矩阵。该方法通过数值实例验证，在10%工艺变化下误差低于1%，在25%变化下误差低于6%。

## 1. 引言

### 1.1 研究背景

随着集成电路工艺节点的不断缩小，制造工艺变化对电路性能的影响变得越来越显著。互连寄生电容作为影响信号完整性和功耗的关键参数，其对工艺变化的敏感度分析对于电路设计和优化具有重要意义。

### 1.2 现有方法的局限性

传统的电容提取方法主要基于有限元方法(FEM)，但在处理工艺变化敏感度分析时存在以下问题：
- 计算效率低，需要对每个工艺参数变化重新计算
- 几何空间离散化误差较大
- 缺乏互补能量界限特性来加速收敛

### 1.3 本文贡献

本文的主要贡献包括：
1. 提出基于双离散几何方法的电容敏感度计算框架
2. 利用标量电势作为未知量，简化了敏感度分析
3. 实现系数矩阵重用策略，提高计算效率
4. 通过互补能量界限特性减少几何离散化误差
5. 提供上界和下界解，提高结果可靠性

## 2. 双离散几何方法理论基础

### 2.1 数学基础

#### 2.1.1 基本方程组

电磁学的基本方程组为：
```
curl e = 0
div d = ρ
```

其中：
- e 为电场强度
- d 为电位移
- ρ 为电荷密度
- ε 为介电常数

构成方程为：
```
d = εe
```

#### 2.1.2 离散外微分公式

基于离散外微分理论，原网格和对偶网格的关系通过Hodge映射建立：

**原网格-对偶网格方程组**：
```
G^T d̄_D = -ρ̄_D
D d̄_P = -ρ̄_P
```

**构成定律**：
```
d̄_D = M_P^ε ē_P
d̄_P = M_D^ε ē_D
```

**势函数表示**：
```
ē_P = -G v̄_P
ē_D = -D^T v̄_D
```

其中：
- G 为梯度算子
- D 为散度算子
- v̄_P 和 v̄_D 分别为原网格和对偶网格的电势

### 2.2 互补能量界限特性

双离散几何方法的一个重要特性是互补能量界限特性，这是DGM和FEM在数值方法中独有的特性：

1. **收敛加速**: 互补能量界限可以加速收敛过程
2. **误差减少**: 减少几何空间离散化误差
3. **结果验证**: 提供上界和下界解来验证计算结果

## 3. 电容提取数学公式

### 3.1 系统方程

电容提取的系统方程为：
```
M v = b
```

其中M是工艺参数p的函数，边界矩阵M的维度为ne×ne：
```
M = [M_e    N  ]
    [N^T  L  ]
```

### 3.2 电容系数计算

电容系数的计算公式为：
```
C_ij = g_j^T M v = g_0j^T (N^T v_e + L v_0i)
```

其中g_j为第j个导体的电荷向量。

---

## 4. 敏感度分析数学推导

### 4.1 电势敏感度

对系统方程M v = b两边关于工艺参数p_r求导：
```
M_e dv_e/dp_r = -∂M_e/∂p_r v_e - ∂N/∂p_r v_0i
```

### 4.2 电容敏感度

电容对工艺参数的敏感度为：
```
∂C_ij/∂p_r = g_j^T (∂M/∂p_r v + M dv/dp)
```

### 4.3 元素级导数

矩阵元素的导数为：
```
∂m_eiP/∂p_r = (ε_e/2) ∂cot(α_i)/∂p_r
```

其中α_i为三角形元素的角度。

## 5. 计算方法与实现

### 5.1 空间离散化

#### 5.1.1 网格生成
- **原网格**: 使用Delaunay三角剖分生成
- **对偶网格**: 通过Hodge映射构造
- **自由度**: 在原网格和对偶网格的顶点上定义标量电势

#### 5.1.2 网格统计
在名义情况下，测试用例的网格统计为：
- 节点数: 45,508
- 三角形数: 90,546  
- 边数: 136,053

### 5.2 边界条件处理

#### 5.2.1 导体边界条件
使用Dirichlet边界条件处理导体边界：
```
v = V_0 (导体表面)
```

#### 5.2.2 截断计算域处理
对于截断的计算域，添加额外顶点来处理边界条件。

### 5.3 系数矩阵重用策略

为了提高计算效率，敏感度分析中重用名义参数计算的系数矩阵：
1. 计算名义参数下的系数矩阵M
2. 在敏感度计算中直接使用M，避免重复计算
3. 只计算矩阵导数∂M/∂p_r和电势导数dv/dp

## 6. 工艺变化建模

### 6.1 主要工艺参数

本文主要考虑以下工艺参数的变化：
- **线宽W**: 互连线的宽度
- **线厚T**: 互连线的厚度

### 6.2 参数变化范围

工艺参数的变化范围设置为：
- 线宽W: -25% 到 +25%
- 线厚T: -25% 到 +25%

### 6.3 几何参数敏感度

几何参数的变化通过以下方式影响电容：
1. 改变导体与介质之间的几何关系
2. 影响电场分布和电通量密度
3. 导致电容系数矩阵的变化

## 7. 验证结果与误差分析

### 7.1 测试用例

使用4导体静电系统进行验证：
- 导体数量: 4个
- 参数变化: 线宽W和线厚T
- 变化范围: -25% 到 +25%

### 7.2 精度验证

#### 7.2.1 10%工艺变化
- **误差**: < 1%
- **验证方法**: 与场求解器结果比较
- **结论**: 优秀的一致性

#### 7.2.2 25%工艺变化  
- **误差**: < 6%
- **验证方法**: 与场求解器结果比较
- **结论**: 可接受的精度

### 7.3 误差来源分析

误差主要来源包括：
1. **离散化误差**: 空间离散化引起的误差
2. **边界近似**: 截断计算域的边界近似
3. **数值计算**: 矩阵求解的数值误差

## 8. 方法优势与特点

### 8.1 理论优势

#### 8.1.1 互补能量界限特性
- 独有的互补能量界限特性（仅DGM和FEM具备）
- 加速收敛过程
- 减少几何空间离散化误差

#### 8.1.2 几何维度代数化
- 通过几何维度比直接代数化物理定律
- 简化实现复杂度
- 相比边基公式更简单

#### 8.1.3 变分正确性
- 通过路径积分确保电通量计算的变分正确性
- 兼容原网格和对偶公式用于误差界限

### 8.2 计算优势

#### 8.2.1 矩阵重用策略
- 重用名义参数计算的系数矩阵
- 节省计算时间
- 减少计算误差

#### 8.2.2 标量势函数
- 使用标量电势作为未知量
- 相比FEM的矢量电势更简单
- 便于敏感度分析

### 8.3 扩展性

#### 8.3.1 三维扩展
- 方法易于扩展到三维情况
- 保持相同的理论基础

#### 8.3.2 高阶敏感度
- 兼容伴随方法用于二阶敏感度分析
- 支持更复杂的敏感度计算

## 9. 与传统方法比较

### 9.1 与有限元方法(FEM)比较

| 特性 | DGM方法 | 传统FEM |
|------|---------|---------|
| 未知量类型 | 标量电势 | 矢量电势 |
| 互补能量界限 | 有 | 有 |
| 实现复杂度 | 较低 | 较高 |
| 敏感度计算 | 直接矩阵求导 | 复杂 |
| 矩阵重用 | 支持 | 不支持 |

### 9.2 与其他数值方法比较

| 特性 | DGM方法 | 边界元法 | 积分方程法 |
|------|---------|----------|------------|
| 互补能量界限 | 有 | 无 | 无 |
| 几何适应性 | 好 | 一般 | 差 |
| 计算效率 | 高 | 中等 | 低 |
| 内存需求 | 中等 | 低 | 高 |

## 12. 结论

本文提出的基于双离散几何方法的IC互连寄生电容敏感度分析方法具有以下主要特点：

1. **理论基础扎实**: 基于离散外微分理论，具有严格的数学基础
2. **计算效率高**: 通过矩阵重用策略和互补能量界限特性显著提高计算效率
3. **精度可靠**: 在10%工艺变化下误差低于1%，25%变化下误差低于6%
4. **扩展性强**: 易于扩展到三维情况和二阶敏感度分析
5. **实用价值高**: 为先进工艺节点的工艺变化分析提供了有效工具

该方法为集成电路设计中的工艺变化分析提供了新的技术手段，对于提高设计可靠性和优化设计效率具有重要意义。随着工艺节点的不断缩小，该方法的应用价值将越来越突出。
