## 1. 半导体器件基础

### 1.1 PN结理论

#### 1.1.1 PN结的形成与特性

**PN结定义**: P型半导体和N型半导体结合形成的特殊结构

![PN结结构图](imgs/pn-junction-semiconductor-diagram.jpg)
*图1-1: PN结结构示意图，显示P型和N型半导体的结合以及内建电场*

**内建电场**: 
- P区：空穴浓度高
- N区：电子浓度高
- 扩散运动：空穴→N区，电子→P区
- 漂移运动：少数载流子在电场作用下运动

**内建电势**:
$$V_{bi} = \frac{kT}{q}\ln\left(\frac{N_A \cdot N_D}{n_i^2}\right)$$

其中：
- $k$ = 玻尔兹曼常数 ($1.38 \times 10^{-23}$ J/K)
- $T$ = 绝对温度 (K)
- $q$ = 电子电荷 ($1.6 \times 10^{-19}$ C)
- $N_A$ = 受主浓度
- $N_D$ = 施主浓度
- $n_i$ = 本征载流子浓度

<details>
<summary>点击展开：PN结内建电势推导过程</summary>

**推导过程**:

1. **载流子浓度分布**:
   - P区空穴浓度: $p_p = N_A$
   - N区空穴浓度: $p_n = \frac{n_i^2}{N_D}$
   - N区电子浓度: $n_n = N_D$
   - P区电子浓度: $n_p = \frac{n_i^2}{N_A}$

2. **扩散电流密度**:
   - 空穴扩散电流: $J_{pD} = qD_p\frac{dp}{dx}$
   - 电子扩散电流: $J_{nD} = qD_n\frac{dn}{dx}$

3. **热平衡条件**: 扩散电流 = 漂移电流
   $$qD_p\frac{dp}{dx} = q\mu_p pE$$

4. **积分求解**: 
   $$\int_{p_p}^{p_n} \frac{dp}{p} = -\frac{q}{kT}\int_{0}^{V_{bi}} E dx$$

5. **得到内建电势**:
   $$\ln\left(\frac{p_p}{p_n}\right) = \frac{qV_{bi}}{kT}$$
   $$V_{bi} = \frac{kT}{q}\ln\left(\frac{N_A \cdot N_D}{n_i^2}\right)$$
</details>

#### 1.1.2 PN结的伏安特性

![二极管伏安特性曲线](imgs/diode_iv_characteristic_curve_diagram.jpg)
*图1-2: 二极管伏安特性曲线，显示正向偏置、反向偏置和击穿区域*

**正向偏置** ($V > 0$):
$$I = I_S\left(e^{\frac{qV}{kT}} - 1\right)$$

其中：
- $I_S$ = 反向饱和电流
- $V$ = 外加电压

**反向偏置** ($V < 0$):
$$I \approx -I_S$$

**温度特性**:
$$I_S = AT^3e^{-\frac{E_g}{kT}}$$

其中：
- $A$ = 常数
- $E_g$ = 禁带宽度

### 1.2 二极管及其应用

#### 1.2.1 二极管的主要参数

| 参数名称 | 符号 | 典型值 | 说明 |
|---------|------|--------|------|
| 正向压降 | $V_F$ | 0.7V (Si) | 正向导通时的电压降 |
| 反向电流 | $I_R$ | nA-μA | 反向偏置时的漏电流 |
| 反向击穿电压 | $V_{BR}$ | 50V-1000V | 反向击穿时的电压 |
| 最大整流电流 | $I_{F(max)}$ | 100mA-10A | 最大允许正向电流 |
| 结电容 | $C_j$ | pF级 | PN结的等效电容 |

#### 1.2.2 二极管的应用电路

**整流电路**:

1. **半波整流**:
   $$V_o = \frac{V_m}{\pi}$$

2. **全波整流**:
   $$V_o = \frac{2V_m}{\pi}$$

3. **桥式整流**:
   $$V_o = \frac{2V_m}{\pi}$$

**稳压电路**:

**齐纳二极管稳压**:
$$V_o = V_Z$$

其中 $V_Z$ 为齐纳电压。

**稳压条件**:
- 输入电压: $V_{in} > V_Z + V_R$
- 限流电阻: $R = \frac{V_{in} - V_Z}{I_Z + I_L}$

### 1.3 双极性晶体管(BJT)

![BJT结构图](imgs/npn-pnp-bjt-transistor-structure-diagram.jpg)
*图1-3: NPN和PNP型BJT晶体管结构示意图*

#### 1.3.1 BJT的结构与工作原理

![BJT符号](imgs/npn-pnp-bjt-transistor-schematic-symbols.jpg)
*图1-4: NPN和PNP型BJT晶体管电路符号*

**三种工作状态**:

| 工作状态 | 发射结 | 集电结 | 电流关系 |
|---------|--------|--------|----------|
| 放大区 | 正偏 | 反偏 | $I_C = \beta I_B$ |
| 饱和区 | 正偏 | 正偏 | $I_C < \beta I_B$ |
| 截止区 | 反偏 | 反偏 | $I_C \approx 0$ |

**电流关系**:
$$I_E = I_B + I_C$$
$$I_C = \beta I_B$$
$$I_E = (1 + \beta)I_B$$

#### 1.3.2 BJT的主要参数

**直流参数**:
- 电流放大系数: $\beta = \frac{I_C}{I_B}$
- 发射极电流放大系数: $\alpha = \frac{I_C}{I_E} = \frac{\beta}{1+\beta}$
- 基极-发射极电压: $V_{BE} \approx 0.7V$ (Si管)

**交流参数**:
- 输入电阻: $r_{be} = r_{bb'} + (1+\beta)\frac{V_T}{I_E}$
- 输出电阻: $r_{ce} = \frac{V_A}{I_C}$
- 跨导: $g_m = \frac{I_C}{V_T}$

其中：
- $V_T = \frac{kT}{q} \approx 26mV$ (室温)
- $r_{bb'}$ = 基区体电阻
- $V_A$ = 厄尔利电压

#### 1.3.3 BJT放大电路分析

**共射极放大电路**:

电压增益:
$$A_v = -\frac{\beta R_L'}{r_{be}}$$

其中 $R_L' = R_C \parallel R_L$

输入电阻:
$$R_i = R_B \parallel r_{be}$$

输出电阻:
$$R_o = R_C$$

**共集电极放大电路(射极跟随器)**:

电压增益:
$$A_v = \frac{(1+\beta)R_E}{r_{be} + (1+\beta)R_E} \approx 1$$

输入电阻:
$$R_i = R_B \parallel [(1+\beta)R_E]$$

输出电阻:
$$R_o = \frac{r_{be} + R_S'}{1+\beta}$$

其中 $R_S' = R_S \parallel R_B$

### 1.4 场效应晶体管(MOSFET、JFET)

#### 1.4.1 MOSFET的工作原理

![MOSFET输出特性](imgs/mosfet_output_characteristics_graph_id_vs_vds.jpg)
*图1-5: MOSFET输出特性曲线，显示不同栅极电压下的漏极电流特性*

**增强型MOSFET**:

阈值电压:
$$V_{th} = \frac{t_{ox}}{\varepsilon_{ox}}\left[\sqrt{2\varepsilon_s q N_A |2\phi_F|} + \phi_F\right]$$

其中：
- $t_{ox}$ = 氧化层厚度
- $\varepsilon_{ox}$ = 氧化层介电常数
- $\varepsilon_s$ = 硅介电常数
- $\phi_F$ = 费米势

**漏极电流** (饱和区):
$$I_D = \frac{1}{2}\mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{th})^2$$

其中：
- $\mu_n$ = 电子迁移率
- $C_{ox}$ = 氧化层单位面积电容
- $W/L$ = 沟道宽长比

#### 1.4.2 JFET的工作原理

**夹断电压**:
$$V_P = \frac{qN_A a^2}{2\varepsilon_s}$$

其中 $a$ 为沟道厚度。

**饱和漏极电流**:
$$I_{DSS} = \frac{q^2 N_A^2 a^3}{6\varepsilon_s L}$$

**漏极电流** (饱和区):
$$I_D = I_{DSS}\left(1 - \frac{V_{GS}}{V_P}\right)^2$$

#### 1.4.3 FET放大电路分析

**共源极放大电路**:

跨导:
$$g_m = \frac{2I_D}{V_{GS} - V_{th}}$$

电压增益:
$$A_v = -g_m R_D$$

输入电阻:
$$R_i = R_G$$

输出电阻:
$$R_o = R_D$$

## 2. 基本放大电路

![BJT共射放大电路](imgs/common-emitter-bjt-amplifier-circuit-diagram.jpg)
*图2-1: BJT共射放大电路原理图*

### 2.1 单级放大电路分析

#### 2.1.1 静态工作点分析

**BJT共射放大电路静态分析**:

基极电流:
$$I_B = \frac{V_{CC} - V_{BE}}{R_B}$$

集电极电流:
$$I_C = \beta I_B$$

集电极-发射极电压:
$$V_{CE} = V_{CC} - I_C R_C$$

**MOSFET共源放大电路静态分析**:

栅极电流:
$$I_G \approx 0$$

栅极电压:
$$V_G = V_{DD} \frac{R_{G2}}{R_{G1} + R_{G2}}$$

漏极电流:
$$I_D = \frac{1}{2}\mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{th})^2$$

漏极-源极电压:
$$V_{DS} = V_{DD} - I_D R_D$$

#### 2.1.2 动态分析

**BJT放大电路小信号模型**:

输入电阻:
$$r_{be} = r_{bb'} + (1+\beta)\frac{V_T}{I_E}$$

电压增益:
$$A_v = -\frac{\beta R_L'}{r_{be}}$$

功率增益:
$$A_p = A_v \cdot A_i = A_v \cdot \beta$$

**MOSFET放大电路小信号模型**:

跨导:
$$g_m = \frac{2I_D}{V_{GS} - V_{th}}$$

电压增益:
$$A_v = -g_m R_D$$

输出电阻:
$$R_o = R_D$$

#### 2.1.3 频率特性

**上限截止频率**:
$$f_H = \frac{1}{2\pi\tau_H}$$

其中 $\tau_H$ 为高频时间常数。

**下限截止频率**:
$$f_L = \frac{1}{2\pi\tau_L}$$

其中 $\tau_L$ 为低频时间常数。

**通频带**:
$$BW = f_H - f_L$$

**增益带宽积**:
$$GBW = A_v \cdot BW = \text{常数}$$

### 2.2 多级放大电路

#### 2.2.1 级间耦合方式

| 耦合方式 | 特点 | 适用场合 |
|---------|------|----------|
| 阻容耦合 | 直流隔离，交流耦合 | 交流放大器 |
| 直接耦合 | 频率响应好 | 直流放大器 |
| 变压器耦合 | 阻抗匹配 | 功率放大器 |
| 光电耦合 | 电气隔离 | 抗干扰场合 |

#### 2.2.2 多级放大电路分析

**电压增益**:
$$A_v = A_{v1} \cdot A_{v2} \cdot \ldots \cdot A_{vn}$$

**输入电阻**:
$$R_i = R_{i1}$$

**输出电阻**:
$$R_o = R_{on}$$

**功率增益**:
$$A_p = A_{v1} A_{v2} \ldots A_{vn} \cdot \frac{R_L}{R_{i1}}$$

#### 2.2.3 密勒定理

**输入等效电阻**:
$$R_i = \frac{R_o}{1 - A_v}$$

**输出等效电阻**:
$$R_o = R_o(1 - A_v)$$

其中 $A_v$ 为电压增益。

### 2.3 频率特性与补偿

#### 2.3.1 频率失真

**幅度失真**: 不同频率分量的增益不同

**相位失真**: 不同频率分量的相位偏移不同

**总失真系数**:
$$THD = \frac{\sqrt{V_2^2 + V_3^2 + \ldots + V_n^2}}{V_1}$$

其中 $V_1$ 为基波电压，$V_2, V_3, \ldots, V_n$ 为各次谐波电压。

#### 2.3.2 频率补偿

**主极点补偿**:
$$A_v(s) = \frac{A_{v0}}{(1 + s/\omega_1)(1 + s/\omega_2)}$$

**零极点补偿**:
$$A_v(s) = A_{v0} \frac{(1 + s/\omega_z)}{(1 + s/\omega_p)}$$

**相位裕度**:
$$PM = 180^\circ - \angle A_v(j\omega_{gc})$$

其中 $\omega_{gc}$ 为增益 crossover 频率。

## 3. 差分放大电路

![差分放大电路](imgs/differential_amplifier_op_amp_circuit_diagram.png)
*图3-1: 差分放大电路原理图*

### 3.1 差分放大原理

![差分放大器传输特性](imgs/differential-amplifier-transfer-characteristic-curve.jpg)
*图3-2: 差分放大器传输特性曲线*

#### 3.1.1 基本差分放大器

**差模信号**: $v_{id} = v_{i1} - v_{i2}$

**共模信号**: $v_{ic} = \frac{v_{i1} + v_{i2}}{2}$

**差模增益**:
$$A_{vd} = \frac{v_{od}}{v_{id}}$$

**共模增益**:
$$A_{vc} = \frac{v_{oc}}{v_{ic}}$$

**共模抑制比**:
$$CMRR = \left|\frac{A_{vd}}{A_{vc}}\right| = 20\log_{10}\left|\frac{A_{vd}}{A_{vc}}\right| \text{(dB)}$$

#### 3.1.2 差分放大器分析

**双端输出**:
$$v_o = A_{vd}(v_{i1} - v_{i2})$$

**单端输出**:
$$v_o = \frac{A_{vd}}{2}(v_{i1} - v_{i2})$$

**差模输入电阻**:
$$R_{id} = 2r_{be}$$

**共模输入电阻**:
$$R_{ic} = \frac{r_{be}}{1 + \beta}$$

<details>
<summary>点击展开：差分放大器详细分析推导</summary>

**详细分析过程**:

1. **静态分析**:
   - 假设对称电路: $I_{C1} = I_{C2} = \frac{I_{EE}}{2}$
   - 基极电流: $I_{B1} = I_{B2} = \frac{I_{EE}}{2(1+\beta)}$
   - 发射极电压: $V_E = -V_{BE}$

2. **差模信号分析**:
   - 输入差模信号时，一管电流增加，另一管减少
   - 发射极电流变化: $\Delta I_E = \frac{v_{id}}{2r_e}$
   - 集电极电压变化: $\Delta V_C = -\frac{\beta v_{id}}{2r_{be}}$
   - 差模增益: $A_{vd} = -\frac{\beta R_C}{r_{be}}$

3. **共模信号分析**:
   - 输入共模信号时，两管电流同时变化
   - 发射极电压变化: $\Delta V_E = \frac{v_{ic}}{2}(1 + \frac{1}{\beta})$
   - 共模增益: $A_{vc} = -\frac{R_C}{2r_e}$

4. **CMRR计算**:
   $$CMRR = \frac{\beta R_C}{r_{be}} \cdot \frac{2r_e}{R_C} = 2\beta\frac{r_e}{r_{be}}$$
   其中 $r_e = \frac{V_T}{I_E}$
</details>

### 3.2 共模抑制比

#### 3.2.1 影响CMRR的因素

**工艺参数**:
- $\beta$ 失配: $\frac{\Delta\beta}{\beta}$
- $V_{BE}$ 失配: $\Delta V_{BE}$
- $R_C$ 失配: $\frac{\Delta R_C}{R_C}$

**CMRR表达式**:
$$CMRR = \frac{A_{vd}}{A_{vc}} = \frac{1}{\sqrt{\left(\frac{\Delta\beta}{\beta}\right)^2 + \left(\frac{\Delta V_{BE}}{V_T}\right)^2 + \left(\frac{\Delta R_C}{R_C}\right)^2}}$$

#### 3.2.2 提高CMRR的方法

1. **增大发射极电阻**:
   $$A_{vc} = -\frac{R_C}{2(R_E + r_e)}$$

2. **使用电流源**:
   - 提高等效发射极电阻
   - 减少温度漂移

3. **工艺匹配**:
   - 版图对称设计
   - 相同几何尺寸

### 3.3 电流源偏置

#### 3.3.1 基本电流源

**镜像电流源**:
$$I_{C2} = I_{C1} = \frac{R_2}{R_1}(V_{CC} - V_{BE})$$

**精度改进**:
$$I_{C2} = I_{C1}\frac{R_E}{R_E + r_e}$$

#### 3.3.2 威尔逊电流源

**输出电流**:
$$I_{C3} = I_{C1}\frac{1 + \frac{1}{\beta}}{1 + \frac{2}{\beta} + \frac{1}{\beta^2}} \approx I_{C1}$$

**输出电阻**:
$$R_o \approx \beta^2 r_{ce}$$

#### 3.3.3 多路电流源

**比例电流源**:
$$I_{C2} = I_{C1}\frac{R_1}{R_2}$$

**基准电流**:
$$I_{REF} = \frac{V_{CC} - V_{BE}}{R}$$

### 4.2 理想运放模型

#### 4.2.1 理想运放特性

| 参数 | 理想值 | 实际值 |
|------|--------|--------|
| 开环增益 $A_{vo}$ | $\infty$ | $10^5 - 10^7$ |
| 输入电阻 $R_i$ | $\infty$ | $10^6 - 10^{12}\Omega$ |
| 输出电阻 $R_o$ | 0 | $10-100\Omega$ |
| 带宽 BW | $\infty$ | $1-10$MHz |
| 共模抑制比 CMRR | $\infty$ | $80-120$dB |

#### 4.2.2 虚短与虚断

**虚短** (Virtual Short):
$$v_+ = v_-$$

**虚断** (Virtual Open):
$$i_+ = i_- = 0$$

**虚地** (Virtual Ground):
当 $v_+ = 0$ 时，$v_- = 0$

#### 4.2.3 运放基本方程

**输出电压**:
$$v_o = A_{vo}(v_+ - v_-)$$

**输入电流**:
$$i_+ = \frac{v_+}{R_i}$$
$$i_- = \frac{v_-}{R_i}$$

**输出电流**:
$$i_o = \frac{v_o}{R_o}$$

### 4.3 基本参数分析

#### 4.3.1 直流参数

**输入失调电压** $V_{OS}$:
$$V_{OS} = |V_{BE1} - V_{BE2}|$$

**输入失调电流** $I_{OS}$:
$$I_{OS} = |I_{B1} - I_{B2}|$$

**输入偏置电流** $I_B$:
$$I_B = \frac{I_{B1} + I_{B2}}{2}$$

#### 4.3.2 交流参数

**开环增益** $A_{vo}$:
$$A_{vo} = \frac{v_o}{v_{id}}$$

**单位增益带宽** $f_T$:
$$f_T = A_{vo} \cdot f_{-3dB}$$

**转换速率** $SR$:
$$SR = \frac{dv_o}{dt}\bigg|_{max}$$

#### 4.3.3 温度漂移

**失调电压温漂**:
$$\frac{dV_{OS}}{dT}$$

**失调电流温漂**:
$$\frac{dI_{OS}}{dT}$$

**偏置电流温漂**:
$$\frac{dI_B}{dT}$$

## 5. 运放的线性应用

### 5.1 比例运算电路

#### 5.1.1 反相比例放大器

**电路结构**:
- 输入信号接反相端
- 同相端接地
- 反馈电阻 $R_f$ 连接输出与反相端

**电压增益**:
$$A_v = -\frac{R_f}{R_1}$$

**输入电阻**:
$$R_i = R_1$$

**输出电阻**:
$$R_o \approx 0$$

<details>
<summary>点击展开：反相比例放大器详细分析</summary>

**分析过程**:

1. **虚地原理**: $v_- = v_+ = 0$

2. **节点电流方程**:
   $$\frac{v_i - v_-}{R_1} = \frac{v_- - v_o}{R_f}$$

3. **代入虚地条件**:
   $$\frac{v_i}{R_1} = -\frac{v_o}{R_f}$$

4. **求解电压增益**:
   $$v_o = -\frac{R_f}{R_1}v_i$$
   $$A_v = -\frac{R_f}{R_1}$$

5. **输入电阻计算**:
   由于虚地，$R_i = R_1$

6. **输出电阻计算**:
   由于深度负反馈，$R_o \approx 0$
</details>

#### 5.1.2 同相比例放大器

**电路结构**:
- 输入信号接同相端
- 反馈电阻连接输出与反相端
- 反相端通过电阻接地

**电压增益**:
$$A_v = 1 + \frac{R_f}{R_1}$$

**输入电阻**:
$$R_i \approx \infty$$

**输出电阻**:
$$R_o \approx 0$$

#### 5.1.3 差分放大器

**电压增益**:
$$A_v = \frac{R_f}{R_1} \cdot \frac{v_{i2} - v_{i1}}{v_{i2} - v_{i1}}$$

**共模抑制**:
$$CMRR = \frac{R_f/R_1}{R_3/R_2}$$

### 5.2 求和运算电路

#### 5.2.1 反相求和电路

**输出电压**:
$$v_o = -\left(\frac{R_f}{R_1}v_{i1} + \frac{R_f}{R_2}v_{i2} + \ldots + \frac{R_f}{R_n}v_{in}\right)$$

**特殊情况** ($R_1 = R_2 = \ldots = R_n = R$):
$$v_o = -\frac{R_f}{R}(v_{i1} + v_{i2} + \ldots + v_{in})$$

#### 5.2.2 同相求和电路

**输出电压**:
$$v_o = \left(1 + \frac{R_f}{R_1}\right)\left(\frac{R_2}{R_2 + R_3 + \ldots + R_n}v_{i2} + \ldots\right)$$

### 5.3 积分与微分电路

#### 5.3.1 积分电路

**输出电压**:
$$v_o(t) = -\frac{1}{RC}\int_0^t v_i(\tau)d\tau + v_o(0)$$

**传递函数**:
$$A_v(s) = -\frac{1}{sRC}$$

**频率特性**:
- 低频增益大
- 高频增益小
- 具有积分特性

#### 5.3.2 微分电路

**输出电压**:
$$v_o(t) = -RC\frac{dv_i(t)}{dt}$$

**传递函数**:
$$A_v(s) = -sRC$$

**频率特性**:
- 高频增益大
- 低频增益小
- 具有微分特性

### 5.4 有源滤波器

![有源带通滤波器](imgs/active_band_pass_filter_circuit_diagram.jpg)
*图5-1: 有源带通滤波器电路原理图，由高通滤波、放大和低通滤波三级组成*

#### 5.4.1 一阶有源滤波器

**低通滤波器**:
$$A_v(s) = \frac{A_{v0}}{1 + \frac{s}{\omega_0}}$$

其中 $\omega_0 = \frac{1}{RC}$，$A_{v0}$ 为直流增益。

**高通滤波器**:
$$A_v(s) = \frac{A_{v0}s/\omega_0}{1 + s/\omega_0}$$

#### 5.4.2 二阶有源滤波器

**二阶低通**:
$$A_v(s) = \frac{A_{v0}\omega_0^2}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

其中 $Q$ 为品质因数。

**二阶高通**:
$$A_v(s) = \frac{A_{v0}s^2}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

**二阶带通**:
$$A_v(s) = \frac{A_{v0}\frac{\omega_0}{Q}s}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

#### 5.4.3 滤波器设计参数

| 滤波器类型 | 截止频率 | 品质因数 | 增益 |
|-----------|----------|----------|------|
| 低通 | $f_c = \frac{1}{2\pi RC}$ | $Q = \frac{1}{\sqrt{2}}$ | $A_{v0}$ |
| 高通 | $f_c = \frac{1}{2\pi RC}$ | $Q = \frac{1}{\sqrt{2}}$ | $A_{v0}$ |
| 带通 | $f_0 = \frac{1}{2\pi RC}$ | $Q = \frac{f_0}{BW}$ | $A_{v0}$ |

### 5.5 仪表放大器

#### 5.5.1 三运放仪表放大器

**差模增益**:
$$A_{vd} = \left(1 + \frac{2R_1}{R_G}\right)\frac{R_3}{R_2}$$

**共模抑制比**:
$$CMRR = \frac{A_{vd}}{A_{vc}} \approx \frac{A_{vd}}{CMRR_{op}}$$

其中 $CMRR_{op}$ 为运放的共模抑制比。

#### 5.5.2 仪表放大器特点

1. **高输入阻抗**: $R_i \approx \infty$
2. **高共模抑制比**: $CMRR > 80$dB
3. **低失调电压**: $V_{OS} < 1$mV
4. **低漂移**: 温度稳定性好

## 6. 运放的非线性应用

### 6.1 比较器电路

#### 6.1.1 单限比较器

**电路结构**:
- 运放开环工作
- 输入信号接反相端
- 参考电压接同相端

**输出状态**:
- $v_i > V_{REF}$: $v_o = V_{OL}$
- $v_i < V_{REF}$: $v_o = V_{OH}$

**传输特性**:
$$v_o = \begin{cases}
V_{OH} & v_i < V_{REF} \\
V_{OL} & v_i > V_{REF}
\end{cases}$$

#### 6.1.2 滞回比较器

**电路结构**:
- 正反馈网络
- 阈值电压由反馈决定

**上门限电压**:
$$V_{TH+} = V_{REF} + \frac{R_1}{R_1 + R_2}(V_{OH} - V_{REF})$$

**下门限电压**:
$$V_{TH-} = V_{REF} + \frac{R_1}{R_1 + R_2}(V_{OL} - V_{REF})$$

**滞回宽度**:
$$\Delta V_{TH} = V_{TH+} - V_{TH-} = \frac{R_1}{R_1 + R_2}(V_{OH} - V_{OL})$$

<details>
<summary>点击展开：滞回比较器详细分析</summary>

**分析过程**:

1. **正反馈分析**:
   - 反馈系数: $F = \frac{R_1}{R_1 + R_2}$
   - 反馈电压: $v_f = F(v_o - V_{REF}) + V_{REF}$

2. **上门限分析**:
   - 当 $v_o = V_{OH}$ 时
   - $v_f = F(V_{OH} - V_{REF}) + V_{REF}$
   - 翻转条件: $v_i = v_f$
   - $V_{TH+} = F(V_{OH} - V_{REF}) + V_{REF}$

3. **下门限分析**:
   - 当 $v_o = V_{OL}$ 时
   - $v_f = F(V_{OL} - V_{REF}) + V_{REF}$
   - 翻转条件: $v_i = v_f$
   - $V_{TH-} = F(V_{OL} - V_{REF}) + V_{REF}$

4. **滞回特性**:
   - 输入上升时，在 $V_{TH+}$ 翻转
   - 输入下降时，在 $V_{TH-}$ 翻转
   - 具有抗干扰能力
</details>

#### 6.1.3 双限比较器

**电路结构**:
- 两个参考电压
- 窗口检测功能

**输出状态**:
- $V_{REF1} < v_i < V_{REF2}$: $v_o = V_{OH}$
- $v_i < V_{REF1}$ 或 $v_i > V_{REF2}$: $v_o = V_{OL}$

### 6.2 整流与检波电路

#### 6.2.1 精密整流电路

**半波整流**:
$$v_o = \begin{cases}
0 & v_i > 0 \\
-\frac{R_f}{R_1}v_i & v_i < 0
\end{cases}$$

**全波整流**:
$$v_o = \left|\frac{R_f}{R_1}v_i\right|$$

#### 6.2.2 峰值检波器

**电路原理**:
- 电容存储峰值
- 二极管单向导通
- 运放隔离负载

**峰值保持**:
$$v_o(t) = \max[v_i(\tau), 0 \leq \tau \leq t]$$

**放电时间常数**:
$$\tau = R_L C$$

### 6.3 限幅与钳位电路

#### 6.3.1 限幅电路

**上限幅**:
$$v_o = \min(v_i, V_{lim})$$

**下限幅**:
$$v_o = \max(v_i, V_{lim})$$

**双向限幅**:
$$v_o = \begin{cases}
V_{lim+} & v_i > V_{lim+} \\
v_i & V_{lim-} \leq v_i \leq V_{lim+} \\
V_{lim-} & v_i < V_{lim-}
\end{cases}$$

#### 6.3.2 钳位电路

**正钳位**:
$$v_o = v_i + V_{clamp}$$ (当 $v_i + V_{clamp} < 0$ 时)

**负钳位**:
$$v_o = v_i - V_{clamp}$$ (当 $v_i - V_{clamp} > 0$ 时)

## 7. 反馈放大电路

![反馈放大电路框图](imgs/negative-feedback-amplifier-block-diagram.jpg_f6)
*图7-1: 负反馈放大电路系统框图*

### 7.1 反馈分类与判别

#### 7.1.1 反馈的分类

| 分类依据 | 类型 | 特点 |
|---------|------|------|
| 反馈信号性质 | 电压反馈、电流反馈 | 影响输出阻抗 |
| 输入连接方式 | 串联反馈、并联反馈 | 影响输入阻抗 |
| 反馈极性 | 正反馈、负反馈 | 影响稳定性 |
| 反馈频率特性 | 直流反馈、交流反馈 | 影响频率响应 |

#### 7.1.2 反馈判别方法

**电压反馈 vs 电流反馈**:
- 断开负载 $R_L$，观察输出变化
- 输出电压不变 → 电压反馈
- 输出电流不变 → 电流反馈

**串联反馈 vs 并联反馈**:
- 输入信号与反馈信号连接方式
- 电压相加 → 串联反馈
- 电流相加 → 并联反馈

**正反馈 vs 负反馈**:
- 瞬时极性法
- 输出变化与输入变化方向相同 → 正反馈
- 输出变化与输入变化方向相反 → 负反馈

#### 7.1.3 反馈组态

| 输入方式 | 输出方式 | 反馈组态 | 典型应用 |
|---------|---------|---------|----------|
| 串联 | 电压 | 电压串联 | 高输入阻抗放大器 |
| 串联 | 电流 | 电流串联 | 跨阻放大器 |
| 并联 | 电压 | 电压并联 | 电流放大器 |
| 并联 | 电流 | 电流并联 | 跨导放大器 |

### 7.2 负反馈对性能的影响

#### 7.2.1 对增益的影响

**闭环增益**:
$$A_f = \frac{A}{1 + AF}$$

其中：
- $A$ = 开环增益
- $F$ = 反馈系数
- $1 + AF$ = 反馈深度

**增益变化**:
$$\frac{dA_f}{A_f} = \frac{1}{1 + AF}\frac{dA}{A}$$

#### 7.2.2 对输入电阻的影响

**串联反馈**:
$$R_{if} = R_i(1 + AF)$$

**并联反馈**:
$$R_{if} = \frac{R_i}{1 + AF}$$

#### 7.2.3 对输出电阻的影响

**电压反馈**:
$$R_{of} = \frac{R_o}{1 + AF}$$

**电流反馈**:
$$R_{of} = R_o(1 + AF)$$

#### 7.2.4 对带宽的影响

**上限频率**:
$$f_{Hf} = f_H(1 + AF)$$

**下限频率**:
$$f_{Lf} = \frac{f_L}{1 + AF}$$

**增益带宽积不变**:
$$A_{vf} \cdot BW_f = A_v \cdot BW$$

#### 7.2.5 对非线性失真的影响

**总谐波失真**:
$$THD_f = \frac{THD}{1 + AF}$$

**互调失真**:
$$IMD_f = \frac{IMD}{1 + AF}$$

### 7.3 稳定性分析

#### 7.3.1 稳定性判据

**奈奎斯特判据**:
- 闭环系统稳定 ⇔ $A(j\omega)F(j\omega)$ 轨迹不包围 (-1, j0) 点

**相位裕度**:
$$PM = 180^\circ + \angle[A(j\omega_{gc})F(j\omega_{gc})]$$

其中 $\omega_{gc}$ 为增益 crossover 频率。

**增益裕度**:
$$GM = -20\log_{10}|A(j\omega_{pc})F(j\omega_{pc})|$$

其中 $\omega_{pc}$ 为相位 crossover 频率。

#### 7.3.2 频率补偿

**主极点补偿**:
- 增加一个低频极点
- 降低相位变化速率
- 保证相位裕度 > 45°

**超前补偿**:
- 引入零点补偿相位滞后
- 提高相位裕度
- 增大单位增益带宽

**滞后补偿**:
- 降低高频增益
- 改善稳定性
- 减小带宽

#### 7.3.3 补偿网络设计

**Miller补偿**:
$$C_m \approx \frac{1}{2\pi f_T R_C}$$

**RC补偿**:
$$R_c C_c = \frac{1}{2\pi f_c}$$

其中 $f_c$ 为补偿后的主极点频率。

## 8. 功率放大电路

![功率放大器效率特性](imgs/power-amplifier-efficiency-curves-class-a-vs-b.jpg)
*图8-1: A类和B类功率放大器效率特性曲线对比*

### 8.1 功率放大器的分类

![AB类功率放大器电路](imgs/class-ab-audio-power-amplifier-circuit-diagram.jpg)
*图8-2: AB类互补对称功率放大器电路原理图*

#### 8.1.1 按工作点分类

| 类型 | 工作点 | 导通角 | 效率 | 失真 |
|------|--------|--------|------|------|
| 甲类 | 线性区 | 360° | ≤ 25% | 最小 |
| 乙类 | 截止区 | 180° | ≤ 78.5% | 较大 |
| 甲乙类 | 线性区+截止区 | 180°-360° | 25%-78.5% | 较小 |
| 丙类 | 深度截止区 | < 180° | > 78.5% | 很大 |

#### 8.1.2 效率计算

**甲类功率放大器**:
$$\eta = \frac{P_o}{P_{CC}} = \frac{V_{CC}I_C/2}{V_{CC}I_C} = 50\%$$

**乙类功率放大器**:
$$\eta = \frac{P_o}{P_{CC}} = \frac{V_{CC}^2/2\pi R_L}{V_{CC}^2/\pi R_L} = 25\%$$

**理论最大效率**:
$$\eta_{max} = \frac{\pi}{4} \approx 78.5\%$$

### 8.2 互补对称功率放大器

#### 8.2.1 OCL电路(无输出电容)

**电路结构**:
- NPN和PNP管互补对称
- 双电源供电
- 直接耦合输出

**输出功率**:
$$P_o = \frac{V_{CC}^2}{2R_L}$$

**电源功率**:
$$P_{CC} = \frac{2V_{CC}^2}{\pi R_L}$$

**效率**:
$$\eta = \frac{P_o}{P_{CC}} = \frac{\pi}{4} = 78.5\%$$

#### 8.2.2 OTL电路(无输出变压器)

**电路结构**:
- 单电源供电
- 输出电容耦合
- 虚地偏置

**输出功率**:
$$P_o = \frac{V_{CC}^2}{8R_L}$$

**效率**:
$$\eta = \frac{\pi}{4} = 78.5\%$$

#### 8.2.3 BTL电路(桥式功率放大器)

**输出功率**:
$$P_o = \frac{V_{CC}^2}{2R_L}$$

**电源利用率**:
- 相同电源电压下，BTL功率是OCL的4倍
- 相同功率下，BTL电源电压是OCL的1/2

### 8.3 功率管的散热与保护

#### 8.3.1 散热设计

**热阻**:
$$R_{th} = \frac{T_j - T_a}{P_c}$$

其中：
- $R_{th}$ = 热阻
- $T_j$ = 结温
- $T_a$ = 环境温度
- $P_c$ = 集电极功耗

**散热片设计**:
$$R_{th(ja)} = R_{th(jc)} + R_{th(cs)} + R_{th(sa)}$$

其中：
- $R_{th(jc)}$ = 结到壳热阻
- $R_{th(cs)}$ = 壳到散热器热阻
- $R_{th(sa)}$ = 散热器到环境热阻

#### 8.3.2 过载保护

**过流保护**:
- 发射极电阻检测
- 电流限制电路

**过压保护**:
- 齐纳二极管钳位
- 瞬态抑制器

**过热保护**:
- 热敏电阻检测
- 温度开关控制

### 8.4 功率放大器性能指标

#### 8.4.1 输出功率指标

**额定输出功率** $P_o$:
- 规定的失真度下的最大输出功率

**最大输出功率** $P_{om}$:
- 不考虑失真时的最大输出功率

**音乐功率** $P_{music}$:
- 实际音乐信号的平均功率

#### 8.4.2 失真指标

**总谐波失真** $THD$:
$$THD = \frac{\sqrt{V_2^2 + V_3^2 + \ldots + V_n^2}}{V_1}$$

**互调失真** $IMD$:
$$IMD = \frac{\sqrt{P_{2f_1 \pm f_2} + P_{2f_2 \pm f_1}}}{P_{f_1} + P_{f_2}}$$

#### 8.4.3 频率响应

**功率带宽** $BW_p$:
- 输出功率下降3dB的频率范围

**信噪比** $S/N$:
$$S/N = 20\log_{10}\frac{V_s}{V_n}$$

其中 $V_s$ 为信号电压，$V_n$ 为噪声电压。

## 9. 振荡电路

![振荡波形图](imgs/common_oscillator_waveforms_diagram.jpg)

### 9.1 振荡器基本原理

![波形发生器电路](imgs/astable_multivibrator_circuit_diagram.jpg)
*图9-2: 多谐振荡器电路原理图，用于产生方波信号*

#### 9.1.1 振荡条件

**幅度条件**:
$$|A(\omega)F(\omega)| = 1$$

**相位条件**:
$$\angle A(\omega)F(\omega) = 2n\pi$$ (n为整数)

**巴克豪森判据**:
- 环路增益等于1
- 环路相移为0°或360°的整数倍

#### 9.1.2 振荡器的分类

| 振荡类型 | 选频网络 | 频率稳定性 | 应用场合 |
|---------|----------|------------|----------|
| LC振荡器 | LC谐振回路 | 中等 | 高频振荡 |
| RC振荡器 | RC选频网络 | 较低 | 低频振荡 |
| 晶体振荡器 | 石英晶体 | 很高 | 精密时钟 |
| 压控振荡器 | 可变电容 | 可调 | 频率合成 |

#### 9.1.3 起振条件

**起振条件**:
$$|A(\omega_0)F(\omega_0)| > 1$$

**振幅稳定**:
- 非线性元件限制振幅
- 负反馈稳定工作点

**频率稳定**:
- 高Q值选频网络
- 温度补偿
- 稳频措施

### 9.2 LC振荡器

#### 9.2.1 互感耦合振荡器

**Hartley振荡器**:
- 反馈线圈与振荡线圈互感耦合
- 频率: $f_0 = \frac{1}{2\pi\sqrt{L_{eq}C}}$
- 其中 $L_{eq} = L_1 + L_2 + 2M$

**Colpitts振荡器**:
- 电容分压反馈
- 频率: $f_0 = \frac{1}{2\pi\sqrt{L\frac{C_1C_2}{C_1+C_2}}}$

#### 9.2.2 三点式振荡器

**电感三点式(Hartley)**:
- 反馈点: 电感抽头
- 优点: 容易起振
- 缺点: 高次谐波多

**电容三点式(Colpitts)**:
- 反馈点: 电容分压
- 优点: 波形好，频率稳定
- 缺点: 起振较难

#### 9.2.3 克拉泼振荡器

**电路特点**:
- 在Colpitts基础上增加电容C3
- 频率稳定性更高
- 频率: $f_0 = \frac{1}{2\pi\sqrt{L\frac{C_1C_2C_3}{C_1C_2 + C_2C_3 + C_1C_3}}}$

### 9.3 RC振荡器

#### 9.3.1 文氏电桥振荡器

**选频网络**:
$$F(j\omega) = \frac{1}{3 + j\left(\frac{\omega}{\omega_0} - \frac{\omega_0}{\omega}\right)}$$

其中 $\omega_0 = \frac{1}{RC}$

**振荡条件**:
- 频率: $f_0 = \frac{1}{2\pi RC}$
- 增益: $A_v = 3$

**频率调节**:
- 同时改变R或C
- 保持RC乘积不变

#### 9.3.2 相移振荡器

**RC相移网络**:
- 每级RC网络相移60°
- 三级相移180°
- 总相移360°

**振荡频率**:
$$f_0 = \frac{1}{2\pi\sqrt{6}RC}$$

**起振条件**:
$$A_v > 29$$

#### 9.3.3 双T网络振荡器

**选频特性**:
- 中心频率: $f_0 = \frac{1}{2\pi RC}$
- 选择性: Q值较高
- 相移: 180°

**应用特点**:
- 频率稳定性好
- 波形失真小
- 适用于窄带滤波

### 9.4 晶体振荡器

#### 9.4.1 石英晶体特性

**等效电路**:
- $C_q$: 动态电容
- $L_q$: 动态电感
- $R_q$: 动态电阻
- $C_0$: 静态电容

**谐振频率**:
- 串联谐振: $f_s = \frac{1}{2\pi\sqrt{L_qC_q}}$
- 并联谐振: $f_p = \frac{1}{2\pi\sqrt{L_q\frac{C_qC_0}{C_q+C_0}}}$

**品质因数**:
$$Q = \frac{1}{R_q}\sqrt{\frac{L_q}{C_q}}$$

#### 9.4.2 晶体振荡器电路

**串联型晶体振荡器**:
- 晶体工作在串联谐振点
- 阻抗最小，相移为0
- 适用于频率合成

**并联型晶体振荡器**:
- 晶体工作在并联谐振点
- 呈感性，等效电感
- 适用于时钟振荡

#### 9.4.3 温度补偿

**温度系数**:
$$\frac{df}{fdt} = \frac{1}{2}\left(\frac{1}{L_q}\frac{dL_q}{dt} - \frac{1}{C_q}\frac{dC_q}{dt}\right)$$

**补偿方法**:
- 变容二极管补偿
- 热敏电阻网络
- 数字温度补偿

### 9.5 波形发生电路

#### 9.5.1 方波发生器

**电路结构**:
- 滞回比较器 + RC积分
- 充放电时间常数不同

**振荡频率**:
$$f_0 = \frac{1}{2RC\ln\left(\frac{1+F}{1-F}\right)}$$

其中 $F = \frac{R_1}{R_1+R_2}$

**占空比**:
$$D = \frac{T_1}{T_1+T_2} = \frac{\ln\left(\frac{1+F}{1-F}\right)}{\ln\left(\frac{1+F}{1-F}\right) + \ln\left(\frac{1+F}{1-F}\right)}$$

#### 9.5.2 三角波发生器

**电路组成**:
- 积分器 + 滞回比较器
- 对称充放电

**振荡频率**:
$$f_0 = \frac{R_1}{4R_2R_3C}$$

**幅度**:
$$V_{om} = \frac{R_2}{R_1}V_{sat}$$

#### 9.5.3 锯齿波发生器

**非对称充放电**:
- 充电时间常数小
- 放电时间常数大

**频率**:
$$f_0 = \frac{1}{T_1 + T_2} = \frac{1}{\tau_1\ln\left(\frac{V_{TH+}}{V_{TH-}}\right) + \tau_2\ln\left(\frac{V_{TH+}}{V_{TH-}}\right)}$$

### 10.3 线性稳压器

#### 10.3.1 串联型稳压器

- 调整管与负载串联

**输出电压**:
$$V_o = V_{REF}\left(1 + \frac{R_2}{R_1}\right)$$

**稳压系数**:
$$S_v = \frac{\Delta V_o/V_o}{\Delta V_i/V_i}$$

**输出电阻**:
$$R_o = \frac{R_1 \parallel R_2}{\beta A_{vo}}$$

#### 10.3.2 并联型稳压器

**基本原理**:
- 调整管与负载并联
- 调节分流电流

**输出电压**:

**适用场合**:

- 输入电压变化大

#### 10.3.3 集成稳压器

**可调稳压器**:

- LM337: 负电压可调

### 10.4 开关稳压器

#### 10.4.1 Buck变换器(降压型)

**工作原理**:
- 开关管导通时，电感储能
- 开关管关断时，电感释能

**输出电压**:
$$V_o = D \cdot V_i$$

其中 $D = \frac{t_{on}}{T}$ 为占空比。

**电感设计**:
$$L = \frac{V_o(1-D)}{f_s \Delta I_L}$$

**电容设计**:
$$C = \frac{\Delta I_L}{8f_s \Delta V_o}$$

#### 10.4.2 Boost变换器(升压型)

**输出电压**:
$$V_o = \frac{V_i}{1-D}$$

**电感设计**:
$$L = \frac{V_i D}{f_s \Delta I_L}$$

#### 10.4.3 Buck-Boost变换器(升降压型)

**输出电压**:
$$V_o = -\frac{D}{1-D}V_i$$

**极性**: 输出与输入反相

#### 10.4.4 开关稳压器控制方式

**PWM控制**:
- 脉冲宽度调制
- 频率固定，宽度可调
- 适用于功率较大场合

**PFM控制**:
- 脉冲频率调制
- 宽度固定，频率可调
- 适用于轻载场合

**PSM控制**:
- 脉冲跳跃调制
- 跳过部分脉冲
- 轻载效率高

### 10.5 稳压电源性能指标

#### 10.5.1 稳压性能指标

**电压调整率** $S_v$:
$$S_v = \frac{\Delta V_o/V_o}{\Delta V_i/V_i} \times 100\%$$

**负载调整率** $S_l$:
$$S_l = \frac{\Delta V_o/V_o}{\Delta I_o/I_o} \times 100\%$$

**温度系数** $S_T$:
$$S_T = \frac{\Delta V_o/V_o}{\Delta T} \times 100\%/\!^\circ\!C$$

#### 10.5.2 纹波与噪声

**纹波电压** $V_r$:
- 低频周期性波动
- 与输入电压频率相关

**噪声电压** $V_n$:
- 高频随机波动
- 开关噪声、器件噪声

**纹波抑制比** $RR$:
$$RR = 20\log_{10}\frac{V_{ri}}{V_{ro}}$$

其中 $V_{ri}$ 为输入纹波，$V_{ro}$ 为输出纹波。

#### 10.5.3 效率与功率

**转换效率** $\eta$:
$$\eta = \frac{P_o}{P_i} \times 100\%$$

**功率损耗** $P_{loss}$:
$$P_{loss} = P_i - P_o$$

**热设计**:
$$T_j = T_a + P_{loss} \cdot R_{th}$$

## 11. 调制解调电路

### 11.1 幅度调制与解调

#### 11.1.1 幅度调制原理

**调幅信号表达式**:
$$s_{AM}(t) = [A_c + m(t)] \cos(\omega_c t)$$

其中：
- $A_c$ = 载波幅度
- $m(t)$ = 调制信号
- $\omega_c$ = 载波角频率

**调制度**:
$$m = \frac{A_m}{A_c}$$

其中 $A_m$ 为调制信号幅度。

**频谱分析**:
$$S_{AM}(\omega) = \pi A_c[\delta(\omega - \omega_c) + \delta(\omega + \omega_c)] + \frac{1}{2}[M(\omega - \omega_c) + M(\omega + \omega_c)]$$

#### 11.1.2 调幅电路

**集电极调幅**:
- 调制信号加在集电极
- 适用于高电平调幅

**基极调幅**:
- 调制信号加在基极
- 适用于低电平调幅

**调制效率**:
$$\eta_{AM} = \frac{\text{边带功率}}{\text{总功率}} = \frac{m^2/2}{1 + m^2/2}$$

#### 11.1.3 调幅解调电路

**包络检波**:
- 二极管检波
- RC滤波
- 适用于普通调幅信号

**同步检波**:
- 乘积检波
- 需要同步载波
- 适用于抑制载波调幅

**检波效率**:
$$\eta_d = \frac{V_o}{V_{am}}$$

其中 $V_{am}$ 为调幅信号包络幅度。

### 11.2 频率调制与解调

#### 11.2.1 频率调制原理

**调频信号表达式**:
$$s_{FM}(t) = A_c \cos\left[\omega_c t + k_f \int_0^t m(\tau)d\tau\right]$$

**瞬时频率**:
$$f_i(t) = f_c + \frac{k_f}{2\pi}m(t)$$

**调频指数**:
$$\beta = \frac{k_f A_m}{\omega_m}$$

其中 $\omega_m$ 为调制信号角频率。

**带宽估算**:
- Carson公式: $BW = 2(\beta + 1)f_m$
- 窄带调频: $BW \approx 2f_m$
- 宽带调频: $BW \approx 2\beta f_m$

#### 11.2.2 调频电路

**直接调频**:
- 压控振荡器
- 调制信号控制振荡频率
- 频率稳定度较差

**间接调频**:
- 先调相再转调频
- 频率稳定度高
- 电路复杂

**变容二极管调频**:
- 反向偏置的变容二极管
- 电容随调制信号变化
- 频率变化: $\Delta f = \frac{1}{4\pi\sqrt{LC}} \cdot \frac{\Delta C}{C}$

#### 11.2.3 调频解调电路

**鉴频器**:
- 斜率鉴频器
- 相位鉴频器
- 锁相环鉴频

**鉴频特性**:
$$V_o = k_d (f - f_0)$$

其中 $k_d$ 为鉴频灵敏度。

**锁相环鉴频**:
- PLL跟踪输入频率
- VCO控制电压即为解调输出
- 线性鉴频范围: $\pm \frac{\omega_L}{2\pi}$

### 11.3 数字调制技术

#### 11.3.1 ASK(幅移键控)

**信号表达式**:
$$s_{ASK}(t) = \begin{cases}
A_c \cos(\omega_c t) & \text{发送"1"} \\
0 & \text{发送"0"}
\end{cases}$$

**功率谱密度**:
$$P_{ASK}(f) = \frac{A_c^2}{4}[P_s(f-f_c) + P_s(f+f_c)]$$

其中 $P_s(f)$ 为基带信号功率谱。

#### 11.3.2 FSK(频移键控)

**信号表达式**:
$$s_{FSK}(t) = \begin{cases}
A_c \cos(\omega_1 t) & \text{发送"1"} \\
A_c \cos(\omega_2 t) & \text{发送"0"}
\end{cases}$$

**最小频率间隔**:
$$\Delta f = \frac{1}{2T_b}$$

其中 $T_b$ 为码元宽度。

#### 11.3.3 PSK(相移键控)

**BPSK信号**:
$$s_{BPSK}(t) = A_c \cos(\omega_c t + \phi_k)$$

其中 $\phi_k = 0$ 或 $\pi$。

**QPSK信号**:
$$s_{QPSK}(t) = A_c \cos(\omega_c t + \phi_k)$$

其中 $\phi_k = \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$。

**误码率**:
- BPSK: $P_b = Q\left(\sqrt{\frac{2E_b}{N_0}}\right)$
- QPSK: $P_b = Q\left(\sqrt{\frac{2E_b}{N_0}}\right)$

### 11.4 混频电路

#### 11.4.1 混频原理

**混频信号**:
$$v_o(t) = k \cdot v_s(t) \cdot v_{lo}(t)$$

其中：
- $v_s(t)$ = 输入信号
- $v_{lo}(t)$ = 本振信号
- $k$ = 混频增益

**输出频率**:
$$f_o = |f_s \pm f_{lo}|$$

**中频选择**:
$$f_{IF} = |f_s - f_{lo}|$$

#### 11.4.2 混频器电路

**二极管混频器**:
- 线性混频
- 变频损耗: $L_c = 6-10$dB

**三极管混频器**:
- 非线性混频
- 变频增益: $G_c = 10-20$dB

**场效应管混频器**:
- 平方律混频
- 动态范围大

#### 11.4.3 混频器性能指标

**变频增益** $G_c$:
$$G_c = \frac{P_{IF}}{P_{RF}}$$

**噪声系数** $F_c$:
$$F_c = \frac{SNR_{in}}{SNR_{out}}$$

**镜像抑制比** $IRR$:
$$IRR = \frac{P_{IF}}{P_{image}}$$

**交调失真**:
$$IM3 = \frac{P_{3rd}}{P_{fundamental}}$$

## 12. 信号处理电路

### 12.1 采样保持电路

#### 12.1.1 采样保持原理

**采样过程**:
$$v_o(t) = v_i(t_n)$$ (当开关导通时)

**保持过程**:
$$v_o(t) = v_o(t_n)$$ (当开关断开时)

其中 $t_n$ 为采样时刻。

**采样定理**:
$$f_s \geq 2f_{max}$$

其中 $f_s$ 为采样频率，$f_{max}$ 为信号最高频率。

#### 12.1.2 采样保持电路

**基本电路**:
- 模拟开关
- 保持电容
- 缓冲放大器

**采样时间**:
$$t_{acq} = \frac{C_h}{g_m} \ln\left(\frac{\Delta V_{error}}{V_{step}}\right)$$

其中：
- $C_h$ = 保持电容
- $g_m$ = 放大器跨导
- $\Delta V_{error}$ = 允许误差
- $V_{step}$ = 输入阶跃电压

**保持模式**:
$$v_o(t) = v_o(t_h) + \frac{I_{leak}}{C_h}(t - t_h)$$

其中 $I_{leak}$ 为漏电流。

#### 12.1.3 采样保持器性能指标

**孔径时间** $t_A$:
- 从保持命令到开关完全断开的时间
- 影响采样精度

**孔径抖动** $\Delta t_A$:
- 孔径时间的不确定性
- 影响SNR

**获取时间** $t_{acq}$:
- 从采样命令到输出达到指定精度的时间
- 决定最高采样率

**保持阶跃**:
- 开关断开瞬间的输出跳变
- 理想值为0

### 12.2 峰值检波器

#### 12.2.1 峰值检波原理

**峰值保持**:
$$v_{peak}(t) = \max[v_i(\tau), \tau \leq t]$$

**检测条件**:
- 当 $v_i > v_{peak}$ 时，$v_o = v_i$
- 当 $v_i < v_{peak}$ 时，$v_o = v_{peak}$

#### 12.2.2 精密峰值检波器

**电路结构**:
- 运放 + 二极管
- 正反馈加速
- 保持电容存储

**工作原理**:
1. **跟踪模式**: $v_i > v_o$，二极管导通，$v_o$跟随$v_i$
2. **保持模式**: $v_i < v_o$，二极管截止，$v_o$保持峰值

**响应时间**:
$$t_{response} = \frac{C_h}{g_m} \ln\left(\frac{V_{peak}}{V_{error}}\right)$$

#### 12.2.3 峰值检波器应用

**包络检波**:
- AM信号包络提取
- 检波时间常数: $\tau = R_L C_D$

**峰值检测**:
- 脉冲幅度测量
- 峰值保持显示

**自动增益控制**:
- 检测信号幅度
- 控制放大器增益

### 12.3 精密整流电路

#### 12.3.1 半波精密整流

**电路原理**:
- 运放 + 二极管
- 负反馈线性化

**输出特性**:
$$v_o = \begin{cases}
-\frac{R_f}{R_1}v_i & v_i > 0 \\
0 & v_i < 0
\end{cases}$$

**精度分析**:
- 二极管压降被运放补偿
- 整流精度: $\frac{V_D}{\beta A_{vo}}$

#### 12.3.2 全波精密整流

**绝对值电路**:
$$v_o = \left|\frac{R_f}{R_1}v_i\right|$$

**电路结构**:
- 两个半波整流器
- 求和放大器

**传递函数**:
$$v_o = \frac{R_f}{R_1}|v_i|$$

#### 12.3.3 精密整流应用

**有效值检测**:
$$V_{rms} = \sqrt{\frac{1}{T}\int_0^T v_i^2(t)dt}$$

**平均值检测**:
$$V_{avg} = \frac{1}{T}\int_0^T |v_i(t)|dt$$

**功率测量**:
$$P = \frac{V_{rms}^2}{R}$$

### 12.4 基准电压源

#### 12.4.1 齐纳二极管基准

**温度系数**:
$$\frac{dV_Z}{dT} = \alpha_{V_Z}$$

**典型值**:
- 6.2V齐纳管: $\alpha \approx +2mV/^\circ\!C$
- 5.1V齐纳管: $\alpha \approx -1.5mV/^\circ\!C$

**温度补偿**:
$$V_{ref} = V_Z + V_{BE}$$

#### 12.4.2 带隙基准

**带隙电压**:
$$V_{BG} = V_{BE} + \frac{kT}{q}\ln\left(\frac{I_1}{I_2}\right)$$

**温度补偿**:
- 正温度系数: $\frac{kT}{q}\ln\left(\frac{I_1}{I_2}\right)$
- 负温度系数: $V_{BE}$
- 适当比例可实现零温度系数

**典型值**:
$$V_{BG} \approx 1.205V$$

#### 12.4.3 基准源性能指标

**初始精度**:
$$\frac{\Delta V_{ref}}{V_{ref}} \times 100\%$$

**温度系数**:
$$\frac{\Delta V_{ref}}{V_{ref} \Delta T} \times 10^6/^\circ\!C$$

**长期稳定性**:
$$\frac{\Delta V_{ref}}{V_{ref}}/\text{year}$$

**噪声**:
$$V_n = \sqrt{\int_{f_1}^{f_2} S_v(f)df}$$

### 12.5 电荷转移器件

#### 12.5.1 电荷耦合器件(CCD)

**工作原理**:
- MOS电容存储电荷
- 时钟脉冲转移电荷
- 电荷量表示信号幅度

**转移效率**:
$$\eta = \frac{Q_{out}}{Q_{in}}$$

**转移损失**:
$$\epsilon = 1 - \eta$$

#### 12.5.2 电荷注入器件(CID)

**结构特点**:
- 双层多晶硅电极
- 电荷在两个电极间转移
- 非破坏性读出

**读出方式**:
1. 注入读出: 电荷注入衬底
2. 转移读出: 电荷转移到读出节点

#### 12.5.3 应用领域

**图像传感**:

- 工业检测

**信号处理**:
- 延迟线

- 相关器

**存储器**:

$$A_v = \frac{v_o}{v_i}$$
