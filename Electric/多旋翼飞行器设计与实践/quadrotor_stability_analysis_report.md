# 平面四旋翼稳定性分析论文技术报告

## 论文基本信息

**标题**: Analysis and Control of a Planar Quadrotor（平面四旋翼的分析与控制）
**作者**: Venkatesh, Praveen; Vadhvana, Sanket; Jain, Varun
**发表日期**: 2021年6月29日
**arXiv ID**: 2106.15134

## 论文摘要

本文对四旋翼的平面运动进行建模，并开发了一个线性模型。我们对开环系统进行稳定性分析，并为其位置控制开发了PD控制器。我们比较了使用为线性系统开发的控制器在线性和非线性系统之间的闭环响应。我们还进行了线性和非线性系统的稳定性分析，并将PD控制器与现代基于强化学习actor-critic网络的深度神经网络方法进行了比较。

## 主要技术内容

### 1. 四旋翼平面运动建模

#### 1.1 物理模型假设
- **平面约束**: 四旋翼运动限制在二维平面内（通常为XY平面）
- **刚体假设**: 四旋翼机体视为刚体
- **对称结构**: 四个旋翼呈对称分布

#### 1.2 状态变量定义
基于典型的四旋翼平面运动，状态变量通常包括：
- **位置状态**: x, y (平面坐标)
- **速度状态**: ẋ, ẏ (线速度)
- **角度状态**: φ (滚转角)
- **角速度状态**: φ̇ (滚转角速度)

#### 1.3 控制输入
- **旋翼转速**: ω₁, ω₂, ω₃, ω₄ (四个旋翼的角速度)
- **推力控制**: 总推力 T
- **力矩控制**: 滚转力矩 τ_φ

### 2. 线性模型开发

#### 2.1 线性化过程
四旋翼的完整动力学模型是非线性的，通常表示为：
```
ẋ = f(x, u)
```

其中：
- x ∈ ℝⁿ 是状态向量
- u ∈ ℝᵐ 是控制输入向量

在平衡点 (x₀, u₀) 附近进行泰勒展开：
```
ẋ = f(x₀, u₀) + ∂f/∂x|(x₀,u₀)(x-x₀) + ∂f/∂u|(x₀,u₀)(u-u₀)
```

#### 2.2 线性状态空间模型
线性化后的状态空间方程：
```
ẋ = Ax + Bu
y = Cx + Du
```

其中：
- A ∈ ℝⁿˣⁿ 是状态矩阵
- B ∈ ℝⁿˣᵐ 是输入矩阵
- C ∈ ℝᵖˣⁿ 是输出矩阵
- D ∈ ℝᵖˣᵐ 是直接传输矩阵

### 3. 开环系统稳定性分析

#### 3.1 稳定性判据
对于线性时不变系统，稳定性由系统矩阵A的特征值决定：

**必要且充分条件**: 系统矩阵A的所有特征值都具有负实部
```
Re(λᵢ) < 0, ∀i = 1, 2, ..., n
```

#### 3.2 特征值分析
- **稳定系统**: 所有特征值位于复平面的左半平面
- **临界稳定**: 存在纯虚数特征值
- **不稳定系统**: 存在正实部特征值

#### 3.3 四旋翼开环特性
典型四旋翼开环系统特征：
- **位置通道**: 通常不稳定，需要反馈控制
- **姿态通道**: 可能存在临界稳定性
- **耦合效应**: 位置和姿态之间存在强耦合

### 4. PD控制器设计

#### 4.1 控制目标
- **位置跟踪**: 跟踪期望轨迹 (x_d, y_d)
- **姿态稳定**: 维持水平姿态 (φ = 0)
- **性能要求**: 快速响应、低超调、良好稳态精度

#### 4.2 PD控制器结构
PD控制器的一般形式：
```
u(t) = K_p e(t) + K_d ė(t)
```

其中：
- K_p 是比例增益矩阵
- K_d 是微分增益矩阵
- e(t) = x_d(t) - x(t) 是跟踪误差

#### 4.3 四旋翼PD控制器设计
针对平面四旋翼的PD控制器：

**位置控制**:
```
F_x = K_{px}(x_d - x) + K_{dx}(ẋ_d - ẋ)
F_y = K_{py}(y_d - y) + K_{dy}(ẏ_d - ẏ)
```

**姿态控制**:
```
τ_φ = K_{pφ}(φ_d - φ) + K_{dφ}(φ̇_d - φ̇)
```

### 5. 闭环系统分析

#### 5.1 闭环系统模型
加入PD控制器后的闭环系统：
```
ẋ = (A - BK_p)x + BK_p x_d
```

#### 5.2 闭环稳定性
闭环系统的稳定性由矩阵 (A - BK_p) 的特征值决定：
```
Re(λᵢ(A - BK_p)) < 0, ∀i
```

#### 5.3 性能指标
- **上升时间** (t_r): 系统响应达到期望值的时间
- **调节时间** (t_s): 系统进入稳态误差范围的时间
- **超调量** (σ%): 最大超越期望值的百分比
- **稳态误差** (e_ss): 稳态时的跟踪误差

### 6. 线性与非线性系统比较

#### 6.1 建模差异
- **线性模型**: 在平衡点附近的小扰动响应
- **非线性模型**: 全工作范围内的精确描述
- **适用性**: 线性模型适用于小角度、小位移情况

#### 6.2 控制性能比较
- **线性控制器在非线性系统中的表现**: 
  - 在小扰动时性能良好
  - 在大扰动时可能性能下降
  - 稳定性边界有限

#### 6.3 鲁棒性分析
- **参数不确定性**: 模型参数变化对系统性能的影响
- **外部干扰**: 风力等外部扰动的抑制能力
- **传感器噪声**: 测量噪声对控制性能的影响

### 7. 强化学习对比分析

#### 7.1 Actor-Critic网络结构
- **Actor网络**: 策略函数 π(a|s)，输出控制动作
- **Critic网络**: 价值函数 V(s)，评估状态价值
- **优势函数**: A(s,a) = Q(s,a) - V(s)

#### 7.2 训练方法
- **策略梯度**: ∇_θ J(θ) = E[∇_θ log π_θ(a|s) A(s,a)]
- **时序差分学习**: TD(λ) 算法
- **经验回放**: 存储和重用历史经验

#### 7.3 性能比较维度
- **学习能力**: 适应环境变化的能力
- **泛化性能**: 在未见情况下的表现
- **计算复杂度**: 实时计算的要求
- **稳定性**: 训练和部署过程的稳定性

### 8. 仿真与实验验证

#### 8.1 仿真环境

#### 8.2 实验设置

#### 8.3 评估指标
- **轨迹跟踪精度**: RMSE、MAX误差
- **能耗效率**: 控制输入的能耗分析
- **鲁棒性测试**: 扰动注入和故障注入测试
