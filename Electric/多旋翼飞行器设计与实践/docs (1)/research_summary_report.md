## 提取的数学内容

### 1. 核心数学方程

#### 状态向量定义
```
x = [px, py, pz, vx, vy, vz, φ, θ, ψ, p, q, r]ᵀ
```

#### 动力学方程
```
ṗ = v
v̇ = (1/m)F_thrust + g·ẑ - (1/m)D·v
ω̇ = I⁻¹(τ - ω × (I·ω))
```

#### 旋转矩阵
```
R = R_z(ψ) · R_y(θ) · R_x(φ)
```

### 2. 控制算法

#### PID控制器
```
u(t) = Kp·e(t) + Ki·∫e(τ)dτ + Kd·ė(t)
```

#### LQR最优控制
```
u* = -Kx, 其中 K = R⁻¹BᵀP
```

#### 滑模控制
```
s = c₁x₁ + x₂
u = -ksgn(s) - f(x)
```

### 3. 观测器设计

#### 扩展卡尔曼滤波器
```

```

### 4. 轨迹规划
