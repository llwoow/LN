## 核心概念

叶片元素理论 (BET) 将翼型空气动力学融入到转子分析中，与只考虑半径作为设计变量的动量理论形成对比。

**核心假设**: 转子叶片由独立运行的翼型截面组成。

## 重要数学定义

### 1. 无量纲参数定义
- **流入比** (inflow ratio): λ = v_i/(ΩR)
- **无量纲径向位置**: r = y/R  
- **实度** (solidity): σ = NcR/(πR²) = Nc/(πR)

其中：
- v_i = 诱导速度
- Ω = 角速度
- R = 转子半径
- y = 径向位置
- N = 叶片数量
- c = 弦长

## 推力计算方程

### 2. 叶片元素推力微分
**基本推力微分方程**:
```
dF_Z = dL cosφ - dD sinφ ≈ N dL
```

其中：
- dF_Z = 推力微分
- dL = 升力微分
- dD = 阻力微分
- φ = 流动角

### 3. 推力系数微分
**推力系数微分方程**:
```
dC_T = (σ/2) C_l r² dr
```

其中：
- C_T = 推力系数
- σ = 实度
- C_l = 升力系数
- r = 无量纲径向位置

### 4. 线性α变化情况下的积分推力系数
**完整推力系数方程**:
```
C_T = (σ/6) C_l_α (θ_0 - 3/2 √(C_T/2))
```

其中：
- C_l_α = 升力曲线斜率
- θ_0 = collective pitch（总距）

### 5. 总距计算
**从推力系数求解总距**:
```
θ_0 = 6C_T/(σ C_l_α) + 3/2 √(C_T/2)
```

## 叶片扭转情况下的方程

### 6. 线性叶片扭转的推力系数
**考虑叶片扭转的推力系数**:
```
C_T = (σ/2) C_l_α [θ_0/3 + θ_tω/4 - λ/2] = (σ/2) C_l_α [θ_75/3 - λ/2]
```

其中：
- θ_tω = 扭转率
- θ_75 = 75%半径处的总距

## 理论假设

### 7. 基本假设
1. **均匀流入**: 假设转子盘面上的流入是均匀的
2. **无扭转叶片**: 初始假设叶片无扭转
3. **刚性叶片**: 叶片假设为刚性
4. **无叶片间干扰**: 忽略叶片之间的相互干扰

### 8. 理论扩展
- 扩展到非均匀流入情况导致**叶片元素动量理论** (BEMT)
- 由 Alfred Gessow 发展的Blade Element Momentum Theory

## 关键特征

### 9. 与动量理论的对比
- **动量理论**: 仅考虑半径作为设计变量
- **叶片元素理论**: 融入翼型空气动力学，考虑弦长变化

### 10. 设计变量
叶片元素理论允许考虑的设计变量包括：
- 叶片数量 (N)
- 弦长分布 (c(y))
- 翼型选择
- 叶片扭转分布

## 技术应用

这些方程用于：
- 转子推力计算
- 螺旋桨性能预测
- 直升机旋翼设计
- 无人机螺旋桨优化

## 理论意义

叶片元素理论为理解螺旋桨和直升机旋翼的空气动力学提供了数学基础，是现代转子设计的重要工具。该理论将经典的翼型空气动力学与转子流动相结合，为精确的性能预测和设计优化提供了可能。
