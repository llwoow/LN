## 核心计算公式

### 1. 推力计算公式
```
T = CT × ρ × n² × D⁴
```
其中：
- T: 推力 (N)
- CT: 推力系数 (无量纲)
- ρ: 空气密度 (kg/m³)
- n: 螺旋桨转速 (rps)
- D: 螺旋桨直径 (m)

### 2. 功率计算
```
P = CP × ρ × n³ × D⁵
```
其中：
- P: 功率 (W)
- CP: 功率系数 (无量纲)

### 3. 效率计算
```
η = T × V / P
```
其中：
- η: 效率
- T: 推力 (N)
- V: 前进速度 (m/s)
- P: 功率 (W)

### 4. 续航时间计算
```
Flight Time = (Battery Capacity × Battery Voltage × Efficiency) / (Power Consumption)
```

### 5. 推重比计算
```
TWR = Total Thrust / Total Weight
```

## 输入参数详解

### 1. 机体参数
- **总重量**: 包括机体、电池、载荷等所有重量
- **机体尺寸**: 轴距、对角距离等几何参数
- **旋翼数量**: 3、4、6、8等配置
- **旋翼布局**: 十字形、H形、Y形等

### 2. 电机参数
- **电机型号**: 从数据库选择或手动输入
- **KV值**: 每伏特转速
- **内阻**: 电机线圈电阻
- **最大功率**: 连续功率和峰值功率
- **效率曲线**: 不同负载下的效率特性

### 3. 螺旋桨参数
- **直径**: 螺旋桨直径 (英寸或毫米)
- **螺距**: 螺旋桨螺距 (英寸)
- **叶片数量**: 通常为2叶片或3叶片
- **材料**: 塑料、碳纤维、木材等
- **桨型**: 对称翼型、弯刀型等

### 4. 电池参数
- **容量**: mAh容量
- **电压**: 单节电压和串联数量
- **放电倍率**: C值 (最大放电电流)
- **内阻**: 电池内阻
- **重量**: 电池重量

### 5. 环境参数
- **海拔高度**: 影响空气密度
- **温度**: 影响空气密度和电机性能
- **湿度**: 对空气密度有轻微影响
- **风速**: 考虑风阻影响

## 输出结果分析

### 1. 性能指标
- **悬停功耗**: 悬停时的总功耗
- **悬停续航**: 以当前配置悬停的最长时间
- **最大推力**: 所有电机同时工作时的最大推力
- **推重比**: 推力与重力的比值
- **最大速度**: 理论最大飞行速度
- **爬升率**: 最大爬升速度

### 2. 效率分析
- **系统效率**: 电机-螺旋桨组合的总体效率
- **电机效率**: 电机本身的效率
- **螺旋桨效率**: 螺旋桨的气动效率
- **功率密度**: 单位重量的功率输出

### 3. 热管理
- **电机温升**: 计算电机工作温度
- **电池温升**: 电池放电时的温升
- **散热需求**: 确定散热措施需求

### 4. 安全性评估
- **冗余度**: 故障情况下的性能保持
- **过载能力**: 短时间过载工作的能力
- **失电保护**: 电池电压过低时的保护机制
