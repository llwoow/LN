## 1. 四旋翼动力学模型

### 1.1 坐标系定义
- **惯性坐标系** (World Frame): {W} - 固定坐标系
- **机体坐标系** (Body Frame): {B} - 固连在四旋翼上的坐标系

### 1.2 状态向量
```
x = [px, py, pz, vx, vy, vz, φ, θ, ψ, p, q, r]ᵀ
```
其中：
- px, py, pz: 位置坐标 (m)
- vx, vy, vz: 速度 (m/s)
- φ, θ, ψ: 欧拉角 - 滚转、俯仰、偏航 (rad)
- p, q, r: 机体角速度 (rad/s)

### 1.3 基本动力学方程

#### 1.3.1 线运动方程
```
ṗx = vx
ṗy = vy  
ṗz = vz

v̇x = (T/m)(cosφ sinθ cosψ + sinφ sinψ) - (kx/m)vx
v̇y = (T/m)(cosφ sinθ sinψ - sinφ cosψ) - (ky/m)vy
v̇z = (T/m)(cosφ cosθ) - g - (kz/m)vz
```

#### 1.3.2 角运动方程
```
φ̇ = p + sinφ tanθ q + cosφ tanθ r
θ̇ = cosφ q - sinφ r
ψ̇ = (sinφ/cosθ) q + (cosφ/cosθ) r

ṗ = (1/Ixx)[τx - (Izz - Iyy)qr]
q̇ = (1/Iyy)[τy - (Ixx - Izz)pr]  
ṙ = (1/Izz)[τz - (Iyy - Ixx)pq]
```

## 2. 控制系统架构

### 2.1 层级控制结构
```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   位置控制器    │───▶│   速度控制器    │───▶│   姿态控制器    │
│  (Position)     │    │   (Velocity)    │    │   (Attitude)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
         │                       │                       │
         ▼                       ▼                       ▼
    ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   期望位置        │    │   期望速度       │    │   期望姿态       │
│   [px,py,pz]      │    │   [vx,vy,vz]     │    │   [φ,θ,ψ]        │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### 2.2 控制输入
```
u = [T, τx, τy, τz]ᵀ
```
其中：
- T: 总推力 (N)
- τx, τy, τz: 三轴力矩 (N·m)

## 3. PID控制器设计

### 3.1 位置控制器
```
T_desired = m[g + kpz(ẑ - pz) + kdz(ż - vz) + kiz∫(ẑ - pz)dt]

φ_desired = (1/g)[kx(x_setpoint - px) + kdx(0 - vx) + kix∫(x_setpoint - px)dt]sinψ
           - (1/g)[ky(y_setpoint - py) + kdy(0 - vy) + kiy∫(y_setpoint - py)dt]cosψ

θ_desired = (1/g)[kx(x_setpoint - px) + kdx(0 - vx) + kix∫(x_setpoint - px)dt]cosψ  
           + (1/g)[ky(y_setpoint - py) + kdy(0 - vy) + kiy∫(y_setpoint - py)dt]sinψ
```

### 3.2 姿态控制器
```
τx = kpφ(φ_desired - φ) + kdφ(0 - p) + kiφ∫(φ_desired - φ)dt
τy = kpθ(θ_desired - θ) + kdθ(0 - q) + kiθ∫(θ_desired - θ)dt
τz = kpψ(ψ_desired - ψ) + kdψ(0 - r) + kiψ∫(ψ_desired - ψ)dt
```

## 4. 线性化模型

### 4.1 小扰动线性化
围绕悬停状态 (φ=θ=ψ=0, p=q=r=0) 线性化：

```
ẋ = Ax + Bu
```

其中系统矩阵A和输入矩阵B为：

```
A = [0₃ₓ₃    I₃ₓ₃    0₃ₓ₃    0₃ₓ₃]
    [0₃ₓ₃    0₃ₓ₃    0₃ₓ₃    0₃ₓ₃]
    [0₃ₓ₃    0₃ₓ₃    0₃ₓ₃    I₃ₓ₃]
    [0₃ₓ₃    0₃ₓ₃    0₃ₓ₃    0₃ₓ₃]

B = [0₃ₓ₄]
    [0₃ₓ₄]
    [0₃ₓ₄]
    [B₃ₓ₄]
```

### 4.2 传递函数
位置控制回路的传递函数：
```
G(s) = Kp + Kd·s + Ki/s
```

## 5. 稳定性分析

### 5.1 李雅普诺夫稳定性
选择李雅普诺夫函数：
```
V(x) = 1/2 xᵀPx
```
其中P为正定矩阵，稳定性条件：
```
V̇(x) = xᵀ(AᵀP + PA)x < 0
```

### 5.2 根轨迹分析
控制系统的极点位置决定了系统的响应特性：
- 极点位于左半平面 → 稳定
- 极点靠近虚轴 → 响应慢
- 极点远离虚轴 → 响应快但可能振荡

## 6. 观测器设计

### 6.1 卡尔曼滤波器
状态估计方程：
```
x̂(k|k) = x̂(k|k-1) + K[k](y(k) - Cx̂(k|k-1))
K[k] = P(k|k-1)Cᵀ(CP(k|k-1)Cᵀ + R)⁻¹
P(k|k) = (I - K[k]C)P(k|k-1)
```

### 6.2 扩展卡尔曼滤波器 (EKF)
用于非线性系统的状态估计：
```
F = ∂f/∂x|x̂
H = ∂h/∂x|x̂
```

## 7. 轨迹规划

### 7.1 多项式轨迹
n次多项式轨迹：
```
p(t) = a₀ + a₁t + a₂t² + ... + an·tⁿ
```

### 7.2 最小snap轨迹
最小化急动度(jerk)的轨迹：
```
J = ∫[p⁽³⁾(t)]²dt
```

## 8. 鲁棒控制

### 8.1 H∞控制
最小化闭环传递函数的H∞范数：
```
||Tzw||∞ < γ
```

### 8.2 滑模控制
滑模面设计：
```
s = cx + ċ
```

控制律：
```
u = -ksgn(s)
```

## 9. 故障检测与容错控制

### 9.1 故障检测
残差计算：
```
r = y - ŷ
```

### 9.2 容错控制
当检测到执行器故障时的控制重新分配：
```
u_faulty = T_faulty† u_desired
```
