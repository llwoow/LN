## 核心技术规格摘要

### 🎯 RTK定位精度
- **水平精度**: 0.01 m + 1 ppm (RTK模式)
- **垂直精度**: 0.01 m + 1 ppm (RTK模式)
- **收敛时间**: < 10秒 (多系统配置)

### 🛰️ 卫星系统支持
| 系统 | 频段 | 特点 |
|-----|------|------|
| GPS | L1, L2 | 美国GPS |
| GLONASS | L1, L2 | 俄罗斯GLONASS |
| Galileo | E1, E5a, E5b | 欧盟Galileo |
| BeiDou | B1, B2 | 中国北斗 |
| QZSS | L1, L2, L6 | 日本准天顶 |
| SBAS | L1 | 广域增强系统 |

### ⚡ 功耗与电气特性
- **电源电压**: 2.7V - 3.6V (典型3.3V)
- **工作电流**: 300 mA (典型)
- **备份电流**: 15 μA
- **工作温度**: -40°C 至 +85°C

### 🔌 接口类型
- **UART**: 9600-921600 baud, 默认38400-8-N-1
- **SPI**: 支持 (通过D_SEL引脚选择)
- **I2C**: 0-400 kHz (Fast-mode)
- **USB**: 2.0 Full Speed (12 Mbit/s)

### 📐 机械规格
- **尺寸**: 17.0 × 22.0 × 2.4 mm
- **重量**: 1.8 g
- **封装**: LGA表面贴装

## 集成建议要点

### 📡 天线设计要求
1. **必须使用有源天线**
2. 移动基站应用建议使用相同类型天线
3. 天线安装应保持相同方向
4. 需要良好的接地平面设计

### 🔧 PCB设计考虑
1. 遵循u-blox集成手册建议
2. 专用硬件准备在设计阶段完成
3. 考虑去板残留尺寸的禁布区设计
4. 稳定的3.3V电源供应
