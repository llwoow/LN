## 1. 核心动力学方程

### 1.1 坐标系与状态定义

#### 坐标系
- **惯性坐标系** (World Frame): {W} - 固定坐标系
- **机体坐标系** (Body Frame): {B} - 固连在四旋翼上的坐标系

#### 状态向量
```
x = [px, py, pz, vx, vy, vz, φ, θ, ψ, p, q, r]ᵀ
```

其中：
- px, py, pz: 位置坐标 (m)
- vx, vy, vz: 速度 (m/s)  
- φ, θ, ψ: 欧拉角 - 滚转、俯仰、偏航 (rad)
- p, q, r: 机体角速度 (rad/s)

### 1.2 完整非线性动力学模型

#### 线运动方程
```
ṗx = vx
ṗy = vy  
ṗz = vz

v̇x = (T/m)(cosφ sinθ cosψ + sinφ sinψ) - (kx/m)vx
v̇y = (T/m)(cosφ sinθ sinψ - sinφ cosψ) - (ky/m)vy
v̇z = (T/m)(cosφ cosθ) - g - (kz/m)vz
```

#### 角运动方程
```
φ̇ = p + sinφ tanθ q + cosφ tanθ r
θ̇ = cosφ q - sinφ r
ψ̇ = (sinφ/cosθ) q + (cosφ/cosθ) r

ṗ = (1/Ixx)[τx - (Izz - Iyy)qr]
q̇ = (1/Iyy)[τy - (Ixx - Izz)pr]  
ṙ = (1/Izz)[τz - (Iyy - Ixx)pq]
```

### 1.3 紧凑形式的动力学方程

```
ṗ = v

v̇ = (1/m)F_thrust + g·ẑ - (1/m)D·v

Ṙ = R·[0  -r  q]
      [r   0 -p]
      [-q  p  0]

ω̇ = I⁻¹(τ - ω × (I·ω))
```

其中：
- F_thrust = [0, 0, T]ᵀ (总推力向量)
- D = diag([kx, ky, kz]) (阻力系数矩阵)
- I = diag([Ixx, Iyy, Izz]) (惯性张量)
- ω = [p, q, r]ᵀ (角速度向量)
- τ = [τx, τy, τz]ᵀ (力矩向量)

## 2. 旋转矩阵与姿态表示

### 2.1 机体到惯性坐标系的旋转矩阵

```
R = R_z(ψ) · R_y(θ) · R_x(φ)

R_x(φ) = [1      0       0    ]
         [0   cos(φ)  -sin(φ)]
         [0   sin(φ)   cos(φ)]

R_y(θ) = [ cos(θ)   0   sin(θ)]
         [   0      1      0   ]
         [-sin(θ)   0   cos(θ)]

R_z(ψ) = [cos(ψ)  -sin(ψ)  0]
         [sin(ψ)   cos(ψ)  0]
         [  0        0      1]
```

### 2.2 四元数表示

```
q = [w, x, y, z]ᵀ = [cos(φ/2), sin(φ/2), 0, 0] · 
                    [cos(θ/2), 0, sin(θ/2), 0] · 
                    [cos(ψ/2), 0, 0, sin(ψ/2)]
```

四元数到欧拉角的转换：
```
φ = atan2(2(wx + yz), 1 - 2(x² + y²))
θ = arcsin(2(wy - zx))
ψ = atan2(2(wz + xy), 1 - 2(y² + z²))
```

## 3. 推进系统数学模型

### 3.1 电机动力学模型

```
ωi = ω_base + Δωi

T = b(ω1² + ω2² + ω3² + ω4²)

τx = b·l(ω4² - ω2²)
τy = b·l(ω3² - ω1²)  
τz = d(ω1² - ω2² + ω3² - ω4²)
```

其中：
- ωi: 第i个电机角速度
- b: 推力系数
- l: 电机到重心的距离
- d: 阻力系数

### 3.2 控制输入

```
u = [T, τx, τy, τz]ᵀ
```

其中：
- T: 总推力 (N)
- τx, τy, τz: 三轴力矩 (N·m)

## 4. 控制器设计数学框架

### 4.1 PID控制器通用形式

```
u(t) = Kp·e(t) + Ki·∫e(τ)dτ + Kd·ė(t)
```

离散形式：
```
u[k] = Kp·e[k] + Ki·T·s[k] + Kd/T·(e[k] - e[k-1])

其中 s[k] = s[k-1] + e[k] (积分项累积)
```

### 4.2 级联PID控制器

#### 位置环:
```
T_des = m·(g + kpz·e_pz + kdz·e_vz + kiz·∫e_pz dt)
```

#### 速度环:
```
a_des = [ax_des, ay_des, az_des]ᵀ
      = kpx·e_px + kdx·e_vx + kix·∫e_px dt
        (类似计算ay_des, az_des)
```

#### 姿态环:
```
φ_des = (1/g)(ax_des·sinψ - ay_des·cosψ)
θ_des = (1/g)(ax_des·cosψ + ay_des·sinψ)
ψ_des = ψ_cmd
```

### 4.3 反步控制法 (Backstepping)

```
步骤1: 设计虚拟控制量
α₁ = -k₁e₁ + x₁d

步骤2: 设计实际控制量  
α₂ = -k₂e₂ - e₁ + ṙ₁d + α̇₁

其中:
e₁ = x₁ - x₁d (跟踪误差)
e₂ = x₂ - α₁ (误差变量)
```

## 5. 线性控制理论

### 5.1 状态空间模型

```
ẋ = Ax + Bu
y = Cx + Du

A = [0₃    I₃    0₃    0₃]
    [0₃    0₃    0₃    0₃]
    [0₃    0₃    0₃    I₃]
    [0₃    0₃    0₃    0₃]

B = [0₃]
    [0₃]
    [0₃]
    [B₃]
```

### 5.2 LQR控制器

```
J = ∫[xᵀQx + uᵀRu]dt

最优控制律: u* = -Kx
K = R⁻¹BᵀP

其中P满足Riccati方程:
AᵀP + PA - PBR⁻¹BᵀP + Q = 0
```

### 5.3 极点配置

```
期望特征多项式:
(s - λ₁)(s - λ₂)...(s - λₙ) = 0

增益矩阵:
K = [a₀-a₁, a₁-a₂, ..., aₙ₋₁-aₙ, aₙ]
```

## 6. 观测器设计

### 6.1 线性观测器

```
x̂̇ = Ax̂ + Bu + L(y - ŷ)
ŷ = Cx̂

其中L为观测器增益矩阵
```

### 6.2 扩展卡尔曼滤波器 (EKF)

```
预测步骤:
x̂ₖ₊₁|ₖ = f(x̂ₖ|ₖ, uₖ)
Pₖ₊₁|ₖ = FₖPₖ|ₖFₖᵀ + Qₖ

更新步骤:
Kₖ₊₁ = Pₖ₊₁|ₖHₖ₊₁ᵀ(Hₖ₊₁Pₖ₊₁|ₖHₖ₊₁ᵀ + Rₖ₊₁)⁻¹
x̂ₖ₊₁|ₖ₊₁ = x̂ₖ₊₁|ₖ + Kₖ₊₁(yₖ₊₁ - h(x̂ₖ₊₁|ₖ))
Pₖ₊₁|ₖ₊₁ = (I - Kₖ₊₁Hₖ₊₁)Pₖ₊₁|ₖ
```

## 7. 轨迹规划数学模型

### 7.1 最小snap轨迹

```
p(t) = a₀ + a₁t + a₂t² + a₃t³ + a₄t⁴ + a₅t⁵

边界条件:
p(0) = p₀, ṗ(0) = v₀, p̈(0) = a₀
p(T) = p₁, ṗ(T) = v₁, p̈(T) = a₁

求解系数矩阵:
[a₀]   [1  0   0    0     0     0 ][p₀]
[a₁] = [0  1   0    0     0     0 ][v₀]
[a₂]   [0  0   2    0     0     0 ][a₀]
[a₃]   [1  T  T²   T³    T⁴    T⁵][p₁]
[a₄]   [0  1  2T   3T²   4T³   5T⁴][v₁]
[a₅]   [0  0   2    6T    12T²  20T³][a₁]
```

### 7.2 Dubins路径

对于给定的起点p₀，终点p₁，最小转弯半径R：

```
情况1: 左转-直线-左转 (LSL)
情况2: 左转-直线-右转 (LSR)  
情况3: 右转-直线-左转 (RSL)
情况4: 右转-直线-右转 (RSR)

每种情况的路径长度:
L = R·(α + β) + √(d² - 2R²(1 - cos(α + β)))
```

## 8. 鲁棒控制

### 8.1 滑模控制

```
滑模面: s = c₁x₁ + x₂

控制律: u = -ksgn(s) - f(x)

其中k > 0为切换增益，f(x)为已知部分补偿
```

### 8.2 H∞控制

```
最小化问题:
min ||Tzw||∞

约束条件:
AᵀP + PA + CᵀC + P(BBᵀ/γ² - 2I)P = 0

最优控制器:
u = -BᵀPx/γ²
```

## 9. 故障诊断与容错控制

### 9.1 残差生成

```
r = y - Cx̂

故障检测:
|r| > τ_threshold → 故障发生
```

### 9.2 故障估计

```
故障模型: u_f = Df·f

故障估计:
f̂ = (DᵀD)⁻¹Dᵀ(r - Cx̂)
```

## 10. 自适应控制

### 10.1 模型参考自适应控制 (MRAC)

```
参考模型:
ẋm = Amxm + Bm·r

自适应律:
θ̇̂ = -ΓΦᵀe

其中:
e = x - xm
Φ = [xᵀ, uᵀ]ᵀ
θ̂ = [Am̂, B̂m]ᵀ
```

### 10.2 参数自适应

```
参数更新:
θ̇̂ = -γ·∂J/∂θ̂

其中J为性能指标函数
```

## 11. 优化算法

### 11.1 模型预测控制 (MPC)

```
min Σ[k=0 to N-1] (x[k]ᵀQx[k] + u[k]ᵀRu[k])
s.t. x[k+1] = Ax[k] + Bu[k]
     x[0] = x₀
     x[N] = xₙ
```

### 11.2 梯度下降法

```
θ[k+1] = θ[k] - α·∇J(θ[k])

其中α为学习率，∇J为梯度
```

## 12. 稳定性分析

### 12.1 李雅普诺夫稳定性

选择李雅普诺夫函数：
```
V(x) = 1/2 xᵀPx
```

其中P为正定矩阵，稳定性条件：
```
V̇(x) = xᵀ(AᵀP + PA)x < 0
```

### 12.2 滤波器算法

```
低通滤波器: y[n] = α·x[n] + (1-α)·y[n-1]

互补滤波器:
α = τ/(τ + dt)
angle = α·(angle + gyro·dt) + (1-α)·accel
```

## 13. 数值实现注意事项

### 13.1 数值稳定性
- 使用四元数避免万向锁问题
- 避免除零操作
- 合理设置积分上下限

### 13.2 计算复杂度
- 实时性要求: 控制频率 > 100Hz
- 矩阵运算优化
- 避免不必要的浮点运算

### 13.3 传感器融合
```
加速度计: 测量比力 (非重力加速度)
陀螺仪: 测量角速度
磁力计: 测量航向
GPS: 测量位置和速度
```
