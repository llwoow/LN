## 欧拉角基础理论

### 定义
欧拉角是描述三维旋转的三个角度参数，通常用于描述刚体在三维空间中的方向。在航空航天中，欧拉角常用于描述飞行器的姿态。

### 标准欧拉角表示
对于航空航天应用，最常用的是ZYX欧拉角序列（也称为导航角或姿态角）：

- **偏航角 (Yaw, ψ)**: 绕Z轴的旋转角度，描述飞行器相对于北方的偏转
- **俯仰角 (Pitch, θ)**: 绕Y轴的旋转角度，描述飞行器上下俯仰
- **滚转角 (Roll, φ)**: 绕X轴的旋转角度，描述飞行器左右滚转

### 数学表示
```
欧拉角向量: [φ, θ, ψ] = [滚转角, 俯仰角, 偏航角]
角度范围: 
- 滚转角 φ ∈ [-π, π]
- 俯仰角 θ ∈ [-π/2, π/2] 
- 偏航角 ψ ∈ [-π, π]
```

## 旋转矩阵

### 基本旋转矩阵

#### X轴旋转矩阵（滚转）
```
R_x(φ) = [1      0       0    ]
         [0   cos(φ) -sin(φ)]
         [0   sin(φ)  cos(φ)]
```

#### Y轴旋转矩阵（俯仰）
```
R_y(θ) = [ cos(θ)  0  sin(θ)]
         [   0     1     0   ]
         [-sin(θ)  0  cos(θ)]
```

#### Z轴旋转矩阵（偏航）
```
R_z(ψ) = [cos(ψ) -sin(ψ) 0]
         [sin(ψ)  cos(ψ) 0]
         [   0       0    1]
```

### 组合旋转矩阵

对于ZYX欧拉角序列，总旋转矩阵为：
```
R = R_z(ψ) × R_y(θ) × R_x(φ)
```

展开后的完整形式：
```
R = [cos(θ)cos(ψ)                    cos(θ)sin(ψ)                   -sin(θ)    ]
    [sin(φ)sin(θ)cos(ψ)-cos(φ)sin(ψ)  sin(φ)sin(θ)sin(ψ)+cos(φ)cos(ψ)  sin(φ)cos(θ)]
    [cos(φ)sin(θ)cos(ψ)+sin(φ)sin(ψ)  cos(φ)sin(θ)sin(ψ)-sin(φ)cos(ψ)  cos(φ)cos(θ)]
```

## 坐标变换

### 常用坐标系

#### 1. 地心惯性坐标系 (ECI)
- 原点：地球中心
- X轴：指向春分点
- Y轴：在赤道平面内，与X轴成90度
- Z轴：指向北极

#### 2. 地球固定坐标系 (ECEF)
- 原点：地球中心
- X轴：指向赤道与本初子午线交点
- Y轴：在赤道平面内，与X轴成90度
- Z轴：指向北极

#### 3. 导航坐标系 (NED)
- 原点：飞行器质心
- X轴：指向北方
- Y轴：指向东方
- Z轴：指向下方

#### 4. 机体坐标系 (Body)
- 原点：飞行器质心
- X轴：指向机头方向
- Y轴：指向右翼方向
- Z轴：指向下方

### 坐标变换矩阵

#### 从机体坐标系到导航坐标系的变换
```
C_b^n = R_z(ψ) × R_y(θ) × R_x(φ)
```

其中C_b^n表示从机体坐标系(b)到导航坐标系(n)的变换矩阵。

#### 从导航坐标系到机体坐标系的变换
```
C_n^b = (C_b^n)^T = R_x(-φ) × R_y(-θ) × R_z(-ψ)
```

## 航空航天应用实例

### 1. 飞行器姿态控制

#### 姿态角计算
给定机体坐标系下的角速度ω_b = [p, q, r]^T，姿态角的时间导数为：
```
φ̇ = p + q sin(φ)tan(θ) + r cos(φ)tan(θ)
θ̇ = q cos(φ) - r sin(φ)
ψ̇ = q sin(φ)sec(θ) + r cos(φ)sec(θ)
```

其中sec(θ) = 1/cos(θ)

#### 姿态控制律
典型的PID姿态控制器：
```
δ_aileron = K_pφ(φ_ref - φ) + K_dφ(p_ref - p) + ∫K_iφ(φ_ref - φ)dt
δ_elevator = K_pθ(θ_ref - θ) + K_dθ(q_ref - q) + ∫K_iθ(θ_ref - θ)dt
δ_rudder = K_pψ(ψ_ref - ψ) + K_dψ(r_ref - r) + ∫K_iψ(ψ_ref - ψ)dt
```

### 2. 导航计算

#### 速度变换
从机体坐标系到导航坐标系的速度变换：
```
v_n = C_b^n × v_b
```

其中v_b是机体坐标系下的速度向量，v_n是导航坐标系下的速度向量。

#### 位置更新
```
ṗ_n = v_n
```

### 3. 传感器数据处理

#### IMU数据变换
加速度计和陀螺仪通常在机体坐标系中测量，需要变换到导航坐标系：
```
a_n = C_b^n × a_b
ω_n = C_b^n × ω_b
```

#### 磁力计校准
磁力计数据需要从机体坐标系变换到导航坐标系进行地磁参考：
```
m_n = C_b^n × m_b
```

## 四元数与欧拉角的关系

### 四元数表示
四元数q = [w, x, y, z]可以表示为：
```
q = cos(φ/2) + i sin(φ/2) + j sin(φ/2) + k sin(φ/2)
```

### 欧拉角到四元数的转换
```
w = cos(φ/2)cos(θ/2)cos(ψ/2) + sin(φ/2)sin(θ/2)sin(ψ/2)
x = sin(φ/2)cos(θ/2)cos(ψ/2) - cos(φ/2)sin(θ/2)sin(ψ/2)
y = cos(φ/2)sin(θ/2)cos(ψ/2) + sin(φ/2)cos(θ/2)sin(ψ/2)
z = cos(φ/2)cos(θ/2)sin(ψ/2) - sin(φ/2)sin(θ/2)cos(ψ/2)
```

### 四元数到欧拉角的转换
```
φ = atan2(2(wx + yz), 1 - 2(x² + y²))
θ = asin(2(wy - xz))
ψ = atan2(2(wz + xy), 1 - 2(y² + z²))
```

## 实际工程应用

### 1. 无人机飞行控制

#### 姿态估计
使用扩展卡尔曼滤波器融合IMU、GPS和磁力计数据：
```
状态向量: x = [φ, θ, ψ, p, q, r, b_ax, b_ay, b_az, b_gx, b_gy, b_gz]^T
```

#### 轨迹跟踪
```
ẋ_desired = v_desired
ẏ_desired = v_desired
ż_desired = v_desired
ψ̇_desired = (ψ_target - ψ_current)/τ
```

### 2. 导弹制导

#### 视线坐标系变换
```
C_los = R_z(γ) × R_y(λ)
```
其中γ是方位角，λ是俯仰角。

#### 制导指令计算
```
a_cmd = N × (λ̇ × v_target) + a_target
```

### 3. 卫星姿态控制

#### 姿态动力学
```
I × ω̇ + ω × (I × ω) = τ_external
```

其中I是惯性矩阵，τ_external是外部力矩。

#### 姿态确定
使用星敏感器确定姿态：
```
q_estimated = f(sun_vector, star_vector, magnetometer_data)
```

### 4. 航空器稳定性分析

#### 小扰动线性化
围绕稳态点线性化运动方程：
```
ẋ = A × x + B × u
```

其中A是系统矩阵，B是控制矩阵。

#### 特征值分析
通过分析矩阵A的特征值确定系统稳定性：
```
λ_i = α_i ± jβ_i
```

稳定条件：所有特征值的实部小于零。

## 数值计算注意事项

### 1. 奇异性问题
欧拉角表示存在奇异性（万向锁），当俯仰角接近±90°时：
- 偏航角和滚转角变得不确定
- 数值计算可能出现不稳定

### 2. 数值稳定性
- 使用双精度浮点数
- 避免直接计算大角度的正弦余弦
- 采用数值稳定的算法

### 3. 角度归一化
```
def normalize_angle(angle):
    while angle > π:
        angle -= 2π
    while angle < -π:
        angle += 2π
    return angle
```

## 总结

欧拉角、旋转矩阵和坐标变换是航空航天工程中的基础数学工具。它们在以下方面发挥关键作用：

1. **飞行器姿态控制**: 实时计算和调整飞行器姿态
2. **导航定位**: 将传感器数据转换到合适的坐标系
3. **轨迹规划**: 在不同坐标系间进行路径计算
4. **传感器融合**: 整合多种传感器数据获得准确状态估计
5. **仿真验证**: 在数字仿真中模拟真实飞行环境

掌握这些数学工具对于航空航天工程师来说是必不可少的，它们构成了现代飞行控制、导航和制导系统的数学基础。
