# MS5611-01BA03 气压传感器完整技术规格报告

## 概述
MS5611-01BA03是MEAS Switzerland生产的新一代高分辨率高度计传感器，具有SPI和I2C总线接口，专为高度计和变送器优化，具有10厘米的高度分辨率。

## 1. 气压和温度测量精度、量程、分辨率

### 气压测量
- **量程**：
  - 全精度范围：450-1100 mbar
  - 扩展范围：10-1200 mbar
  - 线性范围：10-1200 mbar

- **精度**：
  - 25°C, 750 mbar：±1.5 mbar
  - -20°C至+85°C，450-1100 mbar：±3.5 mbar
  - -40°C至+85°C，450-1100 mbar：±6.0 mbar
  - 自校准后精度：±0.5 mbar (25°C, 700-1100 mbar)

- **分辨率**（根据过采样率OSR）：
  - OSR 4096：0.012 mbar RMS
  - OSR 2048：0.018 mbar RMS
  - OSR 1024：0.027 mbar RMS
  - OSR 512：0.042 mbar RMS
  - OSR 256：0.065 mbar RMS

- **响应时间**：
  - OSR 4096：8.22 ms
  - OSR 2048：4.13 ms
  - OSR 1024：2.08 ms
  - OSR 512：1.06 ms
  - OSR 256：0.54 ms

### 温度测量
- **量程**：-40°C至+85°C
- **精度**：
  - 25°C：±0.8°C
  - -20°C至+85°C：±2.0°C
  - -40°C至+85°C：±4.0°C
- **分辨率**：
  - OSR 4096：0.002°C RMS
  - OSR 2048：0.003°C RMS
  - OSR 1024：0.005°C RMS
  - OSR 512：0.008°C RMS
  - OSR 256：0.012°C RMS

### 长期稳定性
- 气压：±1 mbar/年
- 温度：未明确说明

## 2. 工作电压、功耗、接口类型

### 电气特性
- **工作电压**：1.8V至3.6V（典型3.0V）
- **峰值电流**：转换期间1.4 mA
- **待机电流**：0.02-0.14 µA (25°C)

### 功耗（1次/秒采样率）
- OSR 4096：12.5 µA
- OSR 2048：6.3 µA
- OSR 1024：3.2 µA
- OSR 512：1.7 µA
- OSR 256：0.9 µA

### 接口类型
- **SPI接口**：
  - 时钟频率：最高20 MHz
  - 支持模式0和模式3
  - 引脚：SDI, SDO, SCLK, CSB
- **I2C接口**：
  - 地址：111011Cx（C为CSB引脚的补码）
  - 支持两个不同地址的传感器
  - 引脚：SDA, SCLK

### 协议选择
- PS引脚高电平：I2C模式
- PS引脚低电平：SPI模式

## 3. 校准方法和PROM结构

### 工厂校准
- 每个模块在两个温度和两个压力点进行单独工厂校准
- 计算6个补偿系数以补偿工艺变化和温度变化
- 校准系数存储在128位PROM中

### PROM结构（128位）
- 地址0：工厂数据和设置
- 地址1-6：校准系数（C1-C6）
- 地址7：序列号和CRC校验

### 校准系数
- C1：压力灵敏度（SENST1）
- C2：压力偏移（OFFT1）
- C3：压力灵敏度温度系数（TCS）
- C4：压力偏移温度系数（TCO）
- C5：参考温度（TREF）
- C6：温度系数（TEMPSENS）

### CRC校验
- 4位CRC用于检查内存数据有效性
- 遵循CRC-4编码标准

## 4. 温度补偿算法

### 一阶补偿算法
1. **计算温度差**：dT = D2 - C5 * 2^8
2. **计算实际温度**：TEMP = 2000 + dT * C6 / 2^23
3. **计算偏移**：OFF = C2 * 2^16 + (C4 * dT) / 2^7
4. **计算灵敏度**：SENS = C1 * 2^15 + (C3 * dT) / 2^8
5. **计算补偿压力**：P = (D1 * SENS / 2^21 - OFF) / 2^15

### 二阶温度补偿
- **低温补偿**（TEMP < 20°C）：
  - SENS2 = 5 * (TEMP - 2000)^2 / 2^22
  - T2 = dT^2 / 2^31
  - OFF2 = 5 * (TEMP - 2000)^2 / 2^21

- **极低温补偿**（TEMP < -15°C）：
  - SENS2 = SENS2 + 11 * (TEMP + 1500)^2 / 2^21
  - OFF2 = OFF2 + 7 * (TEMP + 1500)^2

- **最终补偿**：
  - SENS = SENS - SENS2
  - TEMP = TEMP - T2
  - OFF = OFF - OFF2

## 5. 应用场景和集成建议

### 应用场景
- 移动高度计/气压计系统
- 自行车电脑
- 变送器
- 医疗报警高度感应
- 室内导航
- 天气预报设备
- 无人机高度控制
- 智能手表和运动设备

### 集成建议

#### 硬件设计
- **去耦电容**：VDD引脚附近放置100nF陶瓷电容
- **PCB布局**：避免在传感器开口周围走线
- **封装**：QFN 5.0 x 3.0 x 1.0 mm³
- **焊接**：参考应用笔记AN808

#### 软件实现
1. **初始化序列**：
   - 上电后发送复位命令
   - 读取PROM校准系数
   - 验证CRC校验

2. **测量序列**：
   - 发送D1转换命令（压力）
   - 发送D2转换命令（温度）
   - 等待转换完成
   - 读取ADC结果

3. **数据处理**：
   - 应用一阶和二阶温度补偿算法
   - 计算最终压力和温度值

#### 性能优化
- 根据应用需求选择合适的OSR设置
- 平衡精度和功耗
- 实施适当的滤波算法
- 考虑自校准功能

### 装配注意事项
- 使用真空吸嘴进行自动贴装
- 在Class 10,000或更好的洁净室条件下装配
- 使用免清洁焊膏
- 防止颗粒和灰尘进入传感器开口
- 正确的ESD防护（最高4kV HBM）

## 6. 与BMP280的对比优势

### MS5611-01BA03 vs BMP280对比分析

#### 精度优势
- **气压精度**：MS5611在25°C时可达±1.5 mbar，而BMP280通常为±1 mbar
- **温度精度**：MS5611在25°C时±0.8°C，BMP280为±0.5°C
- **分辨率**：MS5611最高可达0.012 mbar，BMP280为0.01 mbar（相当）

#### 功耗优势
- **待机功耗**：MS5611仅0.02-0.14 µA，BMP280约0.1-1 µA
- **工作功耗**：MS5611最低0.9 µA (OSR 256)，BMP280约3.4 µA
- **峰值电流**：MS5611为1.4 mA，BMP280约7.2 µA

#### 接口优势
- **SPI频率**：MS5611支持最高20 MHz，BMP280仅10 MHz
- **I2C地址**：MS5611支持双地址配置，BMP280固定地址
- **协议选择**：MS5611通过PS引脚灵活选择SPI/I2C

#### 校准优势
- **PROM容量**：MS5611为128位，BMP280为64位
- **校准系数**：MS5611有6个补偿系数，BMP280有3个
- **工厂校准**：MS5611在两个温度和两个压力点校准

#### 应用优势
- **长期稳定性**：MS5611为±1 mbar/年，BMP280为±1 mbar/年
- **温度范围**：MS5611为-40°C至+85°C，BMP280为-40°C至+85°C（相同）
- **压力范围**：MS5611为10-1200 mbar，BMP280为300-1100 mbar

#### 封装优势
- **尺寸**：MS5611为5.0 x 3.0 x 1.0 mm³，BMP280为2.5 x 2.5 x 0.95 mm³
- **封装类型**：两者都是QFN封装
- **引脚数**：MS5611为8引脚，BMP280为8引脚

### 总体评价
MS5611-01BA03在功耗控制、接口灵活性和校准精度方面具有明显优势，特别适合对功耗敏感的应用。而BMP280在尺寸和某些规格上略有优势，但MS5611的综合性能更为均衡，特别适合高精度、低功耗的移动应用。
