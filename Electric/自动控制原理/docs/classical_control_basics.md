第1章 自动控制的基本概念

1.1 自动控制的定义与特点

自动控制,是指无需人的直接干预,利用物理装置使被控量自动按预定规律保持恒定或按预期轨迹变化的工程实践与理论体系。闭环(反馈)控制的核心在于“测量—比较—执行”的闭环回路:输出被测量并反馈至输入端,与给定值比较形成偏差,控制器据此产生控制作用以抑制偏差,从而提升精度与抗干扰能力;开环控制则信号单向传递,结构简单但抗扰性弱[^3][^4][^1]。

从工程演进看,反馈思想贯穿控制理论发展始终。早期以PID为代表的经典控制奠定了“误差驱动—校正”的基本范式;随着状态空间方法兴起,现代控制进一步在结构分解、能控能观性与最优控制上拓展,但反馈的本质始终是“以偏差矫正偏差”,以系统内部信息重构与配置实现性能目标[^15]。

1.2 控制系统分类

控制系统的分类维度多元,不同维度下的系统呈现出不同的分析与设计策略。为清晰对比,表2给出主要分类与特征。

表2 控制系统分类与特征对照表

| 分类维度 | 类型 | 定义/特征 | 典型系统/场景 | 优缺点 |
|---|---|---|---|---|
| 控制方式 | 开环 | 输出不参与控制,信号单向传递;抗扰弱 | 简单顺序控制、家电按程序运行 | 结构简单、稳定;精度受扰动影响 |
|  | 闭环(反馈) | 输出反馈与给定比较,形成偏差控制;抗扰强 | 恒温炉温控制、电机调速、随动系统 | 精度高、抗扰好;可能引发振荡,稳定性需设计 |
| 元件特性 | 线性 | 微分方程线性;满足叠加原理 | 大多数小信号近似下的工程系统 | 可用传递函数/频域法分析 |
|  | 非线性 | 微分方程非线性;不满足叠加 | 继电器、饱和、间隙等 | 需线性化或专门方法 |

|  | 随动 | 输入不可预期,跟踪性能为核心 | 伺服、雷达天线跟踪 | 关注动态跟踪与相位滞后 |
|  | 程序 | 按预定时间轨迹运行 | 数控机床、过程控制 | 关注轨迹误差与加减速性能 |

1.3 基本组成与方块图

闭环系统通常包含:给定环节、检测环节(传感器/变送器)、比较环节(偏差形成)、放大与执行环节(功率驱动)、被控对象(过程/设备)、反馈环节(测量与变换),以及校正环节(补偿器)。在方块图中,信号沿箭头方向传递,比较点形成代数加减,引出点表示信号分发,环节方块表示动态映射,反馈通道形成闭环。扰动可等效为在对象或前向通道某处注入的额外输入,其作用最终体现在输出与偏差的变化上[^3][^1]。

1.4 性能指标与典型输入

工程上,控制系统性能的三维评价是“稳定性—准确性—快速性”。稳定性是前提,指系统受扰后能回到平衡态;准确性用稳态误差衡量,反映长期跟踪或调节精度;快速性用峰值时间、上升时间与调节时间等暂态指标衡量,反映过渡过程的快慢与振荡程度[^4][^5]。

典型输入信号包括阶跃、斜坡(速度)、抛物线(加速度)、脉冲与正弦。选择这些“基函数”是因为它们可作为常见实际输入的近似基,便于统一分析与设计,且在时域与频域具有良好可计算性[^5][^6]。表3汇总定义与工程含义。

表3 典型输入信号定义与工程意义

| 输入 | 数学定义(单边) | 拉氏变换 | 工程意义 |
|---|---|---|---|
| 单位阶跃 1(t) | 1, t≥0 | 1/s | 电源合闸、设定值突变、负荷突加/突卸 |
| 单位斜坡 t·1(t) | t, t≥0 | 1/s² | 恒速跟踪、匀速变化指令 |
| 单位抛物线 (t²/2)·1(t) | t²/2, t≥0 | 1/s³ | 匀加速轨迹、变加速过程 |
| 单位脉冲 δ(t) | 冲激,∫δ(t)dt=1 | 1 | 短时冲击、扰动脉冲、建模激励 |
| 正弦 A·sin(ωt)·1(t) | A sin(ωt) | Aω/(s²+ω²) | 周期扰动、谐波响应、频域实验 |

第2章 控制系统的数学模型

2.1 微分方程的建立与线性化

从物理系统到数学模型,第一步是建立时域常微分方程(ODE)。以电阻-电容(RC)电路、转动惯量-阻尼系统与电枢控制直流电机为例,列写关于电量/位移/转速等的平衡方程,得到线性或非线性ODE。线性定常系统满足叠加与齐次性,ODE的解由零输入响应与零状态响应叠加而成;这为“模态分解”与“传递函数”方法奠定基础[^10][^14]。

非线性系统在平衡点附近可进行小偏差线性化:对非线性函数在平衡点做泰勒展开并保留一阶项,得到线性化方程。线性化是局部有效的近似,其合理性取决于“吸引域”与“稳定平衡点”的存在与范围;当工作点大范围变化或扰动使状态脱离吸引域时,线性化模型可能失效,需回到非线性分析与设计[^14]。

2.2 传递函数的定义与性质

在零初始条件下,线性定常系统的传递函数定义为输出与输入的拉普拉斯变换之比:G(s) = C(s)/R(s)。其一般形式为
G(s) = N(s)/D(s) = (b₀s^m + b₁s^{m−1} + … + b_m)/(a₀s^n + a₁s^{n−1} + … + a_n),
亦可写成零极点形式与时间常数形式。重要性质包括:仅适用于线性定常系统;表征系统内在动态特性,与输入形式无关;满足物理现实性条件 m ≤ n;系数为实数;传递函数的拉氏逆变换即脉冲响应 g(t),因此 G(s) 完整描述系统在时域的冲激响应特性;对单输入单输出(SISO)系统成立,对多输入多输出(MIMO)可用传递函数矩阵推广[^7][^10][^8]。

零极点的物理意义明确:极点决定系统的固有运动模态与稳定性/快速性(极点实部越负,衰减越快);零点不形成模态,但影响各模态在响应中的权重分布;传递系数(含静态增益)决定稳态传递关系。表5汇总性质与物理意义,便于教学时快速对照[^7][^8]。

表5 传递函数性质与物理意义对照

| 性质 | 内容 | 物理意义/工程含义 |
|---|---|---|
| 适用范围 | 线性定常(LTI) | 非线性/时变需其他方法或局部线性化 |
| 形式 | 有理真分式,m≤n;系数为实数 | 保证因果与稳定储备的可分析性 |
| 零极点 | G(s)=k∏(s−z_i)/∏(s−p_j) | 极点定模态与稳定性;零点配比权重 |
| 脉冲响应 | g(t)=L⁻¹[G(s)] | 时域完全表征 |
| 静态增益 | G(0)=K | 决定稳态传递比 |
| 与输入无关 | 表征系统固有特性 | 设计与参数整定的基础 |

2.3 典型环节的传递函数

复杂系统常可分解为典型环节的串联/并联/反馈组合。掌握每个环节的传递函数、参数与响应特征,是“读图—建模—化简”的基本功。表6给出常用环节总览[^8][^7]。

表6 典型环节汇总表

| 环节 | 传递函数 | 参数含义 | 响应特征/要点 |
|---|---|---|---|
| 比例(放大) | K | K为增益 | 输出与输入成正比,无滞后 |
| 惯性(非周期) | K/(Ts+1) | T时间常数 | 指数上升,单调无振荡 |
| 积分 | K/s 或 1/(T_i s) | T_i积分时间常数 | 输出随时间累积,具记忆;稳态增益无穷大 |
| 理想微分 | Ts | T时间常数 | 预测变化,易放大噪声 |
| 一阶微分(比例微分) | K(τs+1) | τ时间常数 | 提高阻尼与动态响应 |
| 二阶振荡 | ω_n²/(s²+2ζω_n s+ω_n²) | ω_n无阻尼自然频率,ζ阻尼比 | 欠阻尼振荡,超调与阻尼相关 |
| 延迟(滞后) | e^{−τs} | τ滞后时间 | 相位滞后,不利于稳定 |

工程上,比例-积分-微分(PID)控制正是这些典型环节的线性组合,利用“积分消除稳态误差”“微分提供阻尼与预测”“比例提供闭环增益”来实现“稳、准、快”的协调[^8]。

2.4 方块图化简与梅森公式

方块图等效变换包括:串联相乘、并联相加、反馈化简(注意正负反馈与闭环传递函数的标准形式)。在复杂系统中,逐级等效变换容易出错或繁琐,梅森增益公式(Mason’s Gain Formula)提供了直接从信号流图或结构图求取总传递函数的系统化方法:总传递函数 T = (Σ P_k Δ_k) / Δ,其中 Δ 为特征式(考虑所有回路及互不接触回路),P_k 为前向通路增益,Δ_k 为对应前向通路的余因子。关键在于正确识别所有前向通路、回路及其接触关系,并准确计算符号与增益[^10][^11]。

表7给出常见等效变换与梅森公式要素清单,建议在习题课中配合多例题强化“识别—列式—计算”的流程。

表7 方块图等效变换与梅森公式要素

| 要素 | 定义/规则 | 常见错误 |
|---|---|---|
| 串联 | 传递函数相乘 | 遗漏负载效应 |
| 并联 | 传递函数相加 | 符号错误(正负号) |

| 前向通路 | 从输入到输出不重复经过节点 | 漏计或重复计 |
| 回路 | 闭合路径,考虑接触/不接触 | 漏计互不接触回路对Δ的贡献 |

2.5 信号流图与状态空间表达式

信号流图以节点表示变量、支路表示增益,提供了与结构图等价的系统描述。梅森公式在流图上尤其便利:可直接读出前向通路与回路集合并计算Δ[^10]。

状态空间表达式是现代控制的基石:ẋ = Ax + Bu,y = Cx + Du。状态变量是能够完全表征系统内部运动的一组最小变量,状态转移矩阵 e^{At} 描述自由运动。对单输入单输出系统,传递函数与状态空间可通过矩阵分式实现互转。结构分解(如能控/能观标准型)揭示系统的能控性与能观性,是设计状态反馈与观测器的理论前提[^13]。

为便于对照,表8汇总状态空间与传递函数之间的转换要点。

表8 状态空间与传递函数互转要点

| 主题 | 要点 | 说明 |
|---|---|---|
| 状态空间 | ẋ=Ax+Bu, y=Cx+Du | A,B,C,D为实常数矩阵 |
| 传递函数 | G(s)=C(sI−A)^{-1}B+D | 要求初始条件为零 |
| 互转 | 由传递函数分子分母系数构造能控/能观标准型 | 注意D为直接传输项 |
| 结构分解 | 能控/能观分解、约旦标准型 | 反映能控/能观性与零极点的关系 |

第3章 时域分析法

3.1 一阶与二阶系统的时域响应

一阶系统的标准形式为 Tc'(t)+c(t)=Kr(t)。单位阶跃响应为 h(t)=K(1−e^{−t/T}),t>0。常用经验指标:延迟时间 td≈0.69T,上升时间 tr≈2.2T,调节时间 ts≈3T(Δ=5%)或≈4T(Δ=2%)。这些指标为“读图估算参数”与“由参数估计性能”提供了快捷通道[^6][^5]。

二阶系统的标准形式为 c''(t)+2ζω_n c'(t)+ω_n² c(t)=ω_n² r(t)。阻尼比 ζ 决定响应类型:
- 无阻尼(ζ=0):等幅振荡;
- 欠阻尼(0<ζ<1):衰减振荡,存在超调;
- 临界阻尼(ζ=1):最快无超调接近稳态;
- 过阻尼(ζ>1):响应缓慢、无超调。

欠阻尼条件下的常用指标近似:峰值时间 tp≈π/(ω_n√(1−ζ²)),最大超调量 Mp≈exp(−ζπ/√(1−ζ²)),调节时间 ts≈3.5/(ζω_n)(Δ=5%)或≈4.5/(ζω_n)(Δ=2%)。这些近似在工程估算与参数整定中极为实用[^12][^6]。

3.2 高阶系统的时域响应与主导极点

高阶系统的单位阶跃响应是各一阶与二阶模态的线性叠加。若所有极点均具负实部,则瞬态分量随时间衰减,系统稳定。工程上,常用“闭环主导极点”法将高阶系统近似降阶:选择距离虚轴最近、且其周围无其他零极点的极点(或一对共轭复极点)作为主导极点,要求其“实部绝对值比其他极点小5倍以上”。在此近似下,可按主导极点对应的二阶(或一阶)系统估算动态性能指标,极大简化分析与设计[^12][^6]。

3.3 稳定性的定义与劳斯判据

稳定性是“能否收敛”的问题。对线性定常系统,稳定性充要条件是闭环特征根(传递函数极点)全部位于s左半平面(实部为负)。劳斯判据提供了不求解高次方程而判定稳定性的代数方法:构造劳斯表,检查首列符号变化与特殊情形(某行首列为零用ε替代;全零行由辅助方程求根补齐),并可结合虚轴交点求取临界增益[^5][^6]。

3.4 稳态误差的计算与分析

稳态误差 ess 反映“稳态时有多准”。其计算可用终值定理:ess = lim_{s→0} sE(s),其中 E(s) 为误差的拉氏变换。对单位反馈系统,误差传递函数 Φ_e(s) = 1/(1+G(s)),据此可计算不同输入下的 ess。工程上按开环传递函数 G(s) 的型别(0型、Ⅰ型、Ⅱ型)分类讨论:0型对阶跃有限误差、对斜坡/抛物线无限误差;Ⅰ型对阶跃零误差、对斜坡有限误差、对抛物线无限误差;Ⅱ型对阶跃/斜坡零误差、对抛物线有限误差。速度误差系数 K_v、加速度误差系数 K_a 分别用于Ⅰ型/Ⅱ型系统在斜坡/抛物线输入下的误差定量[^5][^6]。

|---|---|---|---|

3.5 根轨迹的基本概念与绘制规则

根轨迹法研究闭环极点随参数(通常为根轨迹增益 K_g)变化的轨迹,核心是幅值方程与相角方程:
- 1 + K_g G(s)H(s) = 0(幅值方程);
- ∠G(s)H(s) = (2k+1)π(180°根轨迹)或 2kπ(零度根轨迹)(相角方程)。

九大基本法则提供了绘制根轨迹的系统规则:连续性、对称性、分支数、起点与终点、渐近线、实轴段判定、分离点/会合点、与虚轴交点、出射角/入射角。关键计算包括渐近线的夹角与交点(σ_a、θ_a)、分离点坐标 d 满足 ∑1/(d−p_j)=∑1/(d−z_i)、出/入射角计算等。表14给出九法则速查,建议在习题课中用“草图—定量—校验”的流程训练[^9][^11][^16]。

重要定理与公式的详细推导(教学用)

拉氏变换与传递函数的推导

对线性定常系统,时域 ODE 可写为 a_n y^{(n)} + … + a_0 y = b_m u^{(m)} + … + b_0 u。取拉氏变换并应用零初始条件,得到 (a_n s^n + … + a_0)Y(s) = (b_m s^m + … + b_0)U(s),于是传递函数定义为 G(s) = Y(s)/U(s) = N(s)/D(s)。这一定义将微分运算转化为代数运算,极大简化了系统分析。传递函数的拉氏逆变换即脉冲响应 g(t),因此 G(s) 与 g(t) 等价,时域与复域描述统一于拉氏变换框架[^7][^10]。

线性化的小偏差法与适用范围

对非线性函数 f(x) 在平衡点 x_0 附近做泰勒展开:f(x)≈f(x_0)+f'(x_0)(x−x_0)。令 Δx = x−x_0,得线性化方程 Δẋ = A Δx + B Δu。线性化有效的范围受吸引域与扰动幅度限制;当工作点变化大或存在强非线性(饱和、间隙、滞环)时,需回到非线性分析与设计[^14]。

劳斯判据的代数稳定性原理

劳斯判据基于多项式系数与行列式(赫尔维茨行列式)的符号判定。将特征多项式排成劳斯表,首列符号保持同号则无右半平面根;出现符号变化则右半平面根数目等于变化次数。特殊行(首列为零或全零)需用极限思想(ε替代)或辅助方程(由全零行对应偶次多项式求根)处理,以保证判据的连续性与完整性[^5][^6]。

主导极点法的合理性与误差来源

主导极点法基于“模态衰减速度与极点距离虚轴远近成正比”的事实。若主导极点实部绝对值远小于其他极点(工程上取≥5倍差距),则非主导模态快速衰减,对总响应影响小,可忽略;响应主要由主导模态决定,从而将高阶系统近似为低阶系统。误差来源包括:非主导模态的残余影响、零点作用、模型近似范围外的参数变化。适用条件不满足时,近似可能失真,需回到完整高阶分析[^12][^6]。

根轨迹的幅值/相角条件与九大法则的证明要点

根轨迹满足两条基本方程:幅值方程 |G(s)H(s)| = 1/K_g 与相角方程 ∠G(s)H(s) = (2k+1)π(180°轨迹)或 2kπ(零度轨迹)。九大法则分别由这两条方程与复变函数性质推导而来:连续性与对称性源于根的共轭成对与增益连续变化;分支数与起点终点由特征方程的阶次与零点/极点分布决定;渐近线由 s→∞ 时的渐近行为导出(比较分子分母阶次与系数和);实轴段判定基于共轭复零极点到实轴的相角贡献成对抵消;分离点对应重根,可用导数条件或回路增益平衡导出;虚轴交点由 s=jω 的临界稳定条件得到;出/入射角由相角平衡方程在小邻域内的线性化近似得到[^9][^11][^16]。

总结与学习建议

前三章构成了经典控制理论的“概念—模型—方法”闭环:从“自动控制的定义与分类”明确问题边界与评价维度;到“数学模型(ODE、传递函数、典型环节、结构图与梅森、信号流图、状态空间)”建立分析工具;再到“时域分析(一阶/二阶/高阶、稳定性、稳态误差、根轨迹)”将模型转化为性能判定与设计依据。教学与备考的关键在于:

- 以“定义—性质—公式—例题—易错”五步法组织知识,形成稳定的解题套路;
- 强化“梅森公式—劳斯判据—根轨迹九法则”的三大工具训练,配合“主导极点法”的工程近似;
- 重视“稳、准、快”的统一:稳定性是前提,稳态误差与动态指标需分别分析,避免混用;
- 适度引入现代控制的结构分解视角(能控/能观),为后续状态反馈与观测器设计铺路。

进一步阅读与扩展建议:参考经典教材与课程讲义以系统化梳理知识;结合MATLAB/Simulink进行建模与仿真,验证指标计算与根轨迹绘制;在实验课中搭建典型环节与闭环系统,观察阶跃/斜坡/正弦输入下的响应与误差,提升“理论—仿真—实验”的一致性[^1][^2]。
