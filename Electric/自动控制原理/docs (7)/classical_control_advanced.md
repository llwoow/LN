## 第4章:根轨迹法

根轨迹法由Evans于1948年提出,是一种以图解方式描绘闭环特征根随参数(通常取根轨迹增益 K*)变化轨迹的工程方法。其最大价值在于:对高阶系统无需显式求解代数方程,即可把握闭环极点的走向、稳定边界与动态性能趋势,从而为设计提供直观依据[^1][^2][^14]。

### 4.1 基本概念与根轨迹方程

根轨迹定义为:当开环传递函数中某一参数(典型为根轨迹增益 K*)从 0 连续变化至 ∞ 时,闭环特征方程的根在 s 复平面上描出的轨迹。根轨迹分支数等于开环极点数 n,每条分支从开环极点(K*=0 时)出发,终止于开环零点(或无穷远处,K*→∞ 时)[^1][^2]。

闭环特征方程与根轨迹方程分别为:
- 闭环特征方程:1 + G(s)H(s) = 0。
- 根轨迹方程:G(s)H(s) = -1。

将开环传递函数写成首1型因子形式 G(s)H(s) = K* ∏(s - z_i) / ∏(s - p_j),则根轨迹方程的两种等价条件为:
- 幅值条件:|G(s)H(s)| = 1(等价于 K* ∏|s - p_j| / ∏|s - z_i| = 1)。
- 相角条件:∠G(s)H(s) = (2k + 1)π(k = 0, ±1, ±2, …)。

这两条条件是根轨迹作图与判别的“基石”:相角条件用于确定轨迹的几何位置,幅值条件用于计算轨迹上特定点对应的增益值 K*[^1][^2]。

为帮助读者快速把握关键公式,表4-1汇总了根轨迹法的核心方程与参数。

表4-1 根轨迹法关键公式与参数对照表
| 项目 | 公式/含义 |
|---|---|
| 闭环特征方程 | 1 + G(s)H(s) = 0 |
| 根轨迹方程 | G(s)H(s) = -1 |
| 幅值条件 | |G(s)H(s)| = 1 ⇔ K* ∏|s - p_j| / ∏|s - z_i| = 1 |
| 相角条件 | ∠G(s)H(s) = (2k + 1)π |
| 首1型开环传递函数 | G(s)H(s) = K* ∏(s - z_i) / ∏(s - p_j) |
| 渐近线夹角 | φ_a = (2k + 1)π / (n - m) |
| 渐近线交点(重心) | σ_a = (∑ p_j - ∑ z_i) / (n - m) |

上述渐近线公式仅在 n > m 时成立,用于刻画轨迹在无穷远处的走向;当 n = m 时,轨迹将终止于零点而不存在无穷远渐近线[^2]。

### 4.2 绘制规则与步骤

根轨迹的绘制遵循一套经验与理论结合的法则。正确运用这些法则,可在不依赖数值解的情况下快速绘出“草图”,再在关键位置用幅角/幅值条件精化。

- 实轴段判据:180°根轨迹(负反馈)上,某点右侧实轴上开环零、极点数目之和为奇数;0°根轨迹(正反馈)上,该和为偶数。该判据用于确定实轴上的轨迹区段[^1][^2]。
- 渐近线:当 n > m 时存在 (n - m) 条渐近线,夹角 φ_a 与交点 σ_a 如表4-1所示。渐近线揭示了轨迹在远离有限零极点时的整体走向[^2]。
- 分离/汇合点:当根轨迹在实轴上相遇又分开(或反向汇合)时,存在重根点。常用方法包括基于特征方程的导数法或利用等效“吸引力”的几何直觉(零点对轨迹有“吸引”作用,极点间存在“排斥”)来估算位置与分支数[^1][^2]。
- 出射角/入射角:在复平面极点或零点附近的轨迹切向角度,可通过局部相角平衡关系求得,用于精确轨迹在复域的走向[^1]。
- 虚轴交点与临界增益:令 s = jω 代入特征方程,分别令实部与虚部为零,解得穿越频率 ω 与临界增益 K*_cr。该点对应闭环稳定性边界[^1]。

绘制步骤建议如下:先求开环零极点并判断分支数与渐近线;用实轴段判据确定实轴轨迹;估算分离/汇合点与出射/入射角;再求虚轴交点与临界增益;最后用幅值条件在关键点(如期望阻尼比对应的点)上计算增益,完成设计或校核[^1][^2][^14]。

### 4.3 180°根轨迹与0°根轨迹

根轨迹分为两类:180°根轨迹对应负反馈系统,其相角条件为 (2k + 1)π;0°根轨迹对应正反馈系统,其相角条件为 2kπ。两者的实轴判据、渐近线夹角与作图细节存在差异,尤其在多回路或符号处理不当的场景中,误判反馈极性会导致整图方向性错误[^2][^1]。

表4-2 180°根轨迹 vs 0°根轨迹对比
| 项目 | 180°根轨迹(负反馈) | 0°根轨迹(正反馈) |
|---|---|---|
| 相角条件 | (2k + 1)π | 2kπ |
| 实轴判据 | 右侧零极点个数之和为奇数 | 右侧零极点个数之和为偶数 |
| 渐近线夹角 | (2k + 1)π / (n - m) | 2kπ / (n - m) |
| 常见场景 | 单回路负反馈、典型教材默认情形 | 正反馈、多回路符号处理后 |
| 易错点 | 忽略符号导致相角条件误用 | 未正确识别正反馈或等效符号 |

在多回路系统中,建议先明确回路符号与等效开环传递函数的符号,再判定根轨迹类型,避免从一开始就“方向性”错误[^2]。

### 4.4 参数根轨迹与根轨迹族

除增益 K* 外,系统其他参数(如时间常数 T、阻尼比 ζ、零点位置 α 等)变化时,同样可绘制参数根轨迹。常用方法是构造等效开环传递函数,使特征方程呈现 1 + G_eq(s) = 0 的形式,再对目标参数应用相同绘制法则。根轨迹族则是在不同参数组合下的一簇轨迹,便于进行灵敏度分析与设计权衡[^1][^2]。

表4-3 参数根轨迹构造方法与适用场景
| 目标参数 | 构造等效开环 | 适用场景 | 备注 |
|---|---|---|---|
| K*(增益) | 原型 G(s)H(s) | 默认根轨迹 | 幅值条件直接求 K* |
| T(时间常数) | 将含 T 的因子归入 G_eq | 时域/频域参数整定 | 关注对转折频率与阻尼的影响 |
| ζ(阻尼比) | 将 ζ 归入 G_eq | 二阶环节主导系统 | 与超调、带宽耦合 |
| 零点位置 α | 引入 (s + α) 因子 | 动态响应塑形 | 零点有“吸引”作用,改变分支走向 |

### 4.5 根轨迹与系统性能

根轨迹与时域性能之间存在明确的几何—指标耦合关系:

- 阻尼比 ζ 与超调量 σ%:欠阻尼时,闭环极点在左半平面成共轭复根,阻尼比越小,超调量越大;典型二阶系统有 σ% = exp(-ζπ/√(1-ζ²))。在根轨迹上,等阻尼比线给出希望的极点分布约束[^3]。
- 自然频率 ωn 与调节时间 ts:调节时间近似与 1/(ζωn) 成比例,提高 ωn 可加快响应,但可能降低稳定裕度。根轨迹上沿等 ζ 线移动到更高 ωn 位置,意味着更快的响应与更大的 K*[^3]。
- 稳态误差与型别:增加积分环节(在原点处增加极点)可降低稳态误差,但会改变根轨迹的分支走向与稳定性边界,需要综合权衡。静态速度误差系数 Kv 与轨迹上的增益值相关,一型系统在斜坡输入下的稳态误差与 Kv 成反比[^1][^3]。

表4-4 根轨迹位置与时域性能指标映射
| 极点位置 | 阻尼特性 | 动态指标(趋势) | 稳态误差(趋势) |
|---|---|---|---|
| 远离虚轴(大 ωn) | 可能欠阻尼 | 快速、但可能大超调 | 低(增益高时) |
| 靠近虚轴(小 ωn) | 阻尼增强 | 缓慢、超调小 | 高(增益低时) |
| 纯实根(过阻尼) | 高阻尼 | 缓慢、无振荡 | 取决于型别与增益 |
| 穿越虚轴 | 临界稳定 | 持续振荡 | 不适用(边界) |

该映射为“由指标到轨迹”的逆向设计提供直觉:若希望降低超调,则沿等 ζ 线调整增益与零点位置;若希望缩短调节时间,则在保持足够 ζ 的前提下提高 ωn,寻找合适的 K* 与零点配置[^1][^3]。

## 第5章:频域分析法

频域分析以正弦稳态响应为基础,通过几何图形(奈奎斯特图与伯德图)揭示系统稳定性与性能。与时域法相比,频域法具备良好的工程可操作性与实验可测性,尤其适用于基于开环特性推断闭环稳定性的设计流程[^3][^4][^7][^13]。

### 5.1 频率特性与典型环节

频率特性定义为:稳定的线性定常系统在正弦输入下,输出稳态分量与输入的复数比。记 G(jω) = U(ω) + jV(ω) = A(ω)e^{jφ(ω)},其中 A(ω) 为幅频特性,φ(ω) 为相频特性。典型环节包括比例、积分、微分、惯性、一阶微分、振荡、二阶微分与延时环节等,其频率特性可按标准公式计算与近似[^3][^4]。

表5-1 典型环节频率特性汇总
| 环节 | 传递函数 | 幅频 A(ω) | 相频 φ(ω) | 关键参数/性质 |
|---|---|---|---|---|
| 比例 | K | K | 0° | 增益按 dB 表示为 20lgK |
| 积分 | 1/s | 1/ω | -90° | 低频增益高,高频衰减 |
| 微分 | s | ω | +90° | 高频增益高,放大噪声风险 |
| 惯性 | 1/(Ts + 1) | 1/√((Tω)² + 1) | -arctan(Tω) | 转折频率 ω = 1/T |
| 一阶微分 | Ts + 1 | √((Tω)² + 1) | arctan(Tω) | 转折频率 ω = 1/T |
| 振荡 | 1/(T²s² + 2ζTs + 1) | 1/√((1 - (ω/ωn)²)² + (2ζω/ωn)²) | -arctan(2ζ(ω/ωn)/(1 - (ω/ωn)²)) | ωn = 1/T;谐振频率 ωr = ωn√(1 - 2ζ²);峰值 Mr = 1/(2ζ√(1 - ζ²)) |
| 二阶微分 | T²s² + 2ζTs + 1 | √((1 - (ω/ωn)²)² + (2ζω/ωn)²) | +arctan(2ζ(ω/ωn)/(1 - (ω/ωn)²)) | 与振荡环节对偶 |
| 延时 | e^{-τs} | 1 | -57.3τω(度) | 相位滞后与频率线性增长 |

上述公式为后续伯德图渐近近似与奈奎斯特图描绘提供基础。特别地,振荡环节的谐振频率与峰值仅在 ζ < 1/√2 时出现,这也是工程上通过峰值 Mr 估计阻尼比的依据[^3][^4]。

### 5.2 奈奎斯特图与伯德图

奈奎斯特图(Nyquist plot)是将 ω 从 0 → ∞ 变化时的 G(jω) 在复平面上描出的轨迹;伯德图(Bode plot)分别绘制对数幅频 L(ω) = 20lgA(ω) 与相频 φ(ω),横坐标采用对数分度。伯德图的“乘除转加减”特性使得手工绘制渐近线极为便捷,适合工程快速估算与设计[^3][^4][^7]。

为便于对比,表5-2总结两种图示法的特点与适用场景。

表5-2 奈奎斯特图 vs 伯德图对比
| 维度 | 奈奎斯特图 | 伯德图 |
|---|---|---|
| 信息密度 | 同时反映幅值与相位 | 幅值与相位分图,信息分层 |
| 稳定性判据 | 直接观察与 (-1, j0) 的包围关系 | 通过对数频率下的穿越数与相位裕度 |
| 手工绘制难度 | 需计算实部/虚部或幅值/相位,曲线易交错 | 渐近线近似易操作,关键频率点修正 |
| 适用场景 | 理论分析、相位穿越细节 | 工程设计、快速扫频与校正 |
| 典型用途 | Z=P-R 判据、包围圈数统计 | 截止频率、相位裕度、幅值裕度估算 |

伯德图的渐近线近似要点:在每个转折频率处按环节斜率变化调整(如惯性环节在 ω = 1/T 处由 0 dB/dec 转为 -20 dB/dec;振荡环节转为 -40 dB/dec),并在谐振附近对峰值进行局部修正;相频曲线在转折点附近按 ±45°(惯性)或 ±90°(振荡)趋势变化,结合环节相位表达式进行细化[^3][^4]。

### 5.3 最小相位与非最小相位

最小相位系统是指开环零点与极点均位于左半 s 平面的系统,其幅频与相频特性一一对应,系统在给定幅频下的相位滞后最小。非最小相位系统则包含右半平面零点或极点,或存在纯延时环节,导致相位滞后显著增大,稳定性与动态响应受限。工程上,最小相位系统更适合快速、平稳的闭环设计;非最小相位系统需在相位滞后与增益之间谨慎权衡[^3][^4]。

表5-3 最小相位 vs 非最小相位系统对比
| 维度 | 最小相位 | 非最小相位 |
|---|---|---|
| 零极点分布 | 左半平面(含原点极点按型别处理) | 包含右半平面零点/极点或延时 |
| 相位范围 | 相对较小,随频率平滑变化 | 显著增大,可能跨越 -180° |
| 稳定性风险 | 较低(合理设计下) | 较高(需额外相位裕度) |
| 设计要点 | 以截止频率与相位裕度为主 | 避开相位陷阱,降低增益或加超前校正 |

### 5.4 奈奎斯特稳定判据

奈奎斯特稳定判据通过开环频率特性 G(jω)H(jω) 与临界点 (-1, j0) 的几何关系判断闭环稳定性。核心公式为 Z = P - R,其中 Z 为闭环右半平面极点数,P 为开环右半平面极点数,R 为奈奎斯特曲线逆时针包围 (-1, j0) 的圈数。闭环稳定的充要条件是 Z = 0,即 R = P[^7][^13]。

表5-4 奈奎斯特判据符号与条件
| 符号 | 含义 |
|---|---|
| Z | 闭环右半平面极点数 |
| P | 开环右半平面极点数 |
| R | 奈奎斯特曲线逆时针包围 (-1, j0) 的圈数 |
| 稳定条件 | Z = 0 ⇔ R = P |

应用该判据时的常见注意点包括:半闭合路径的选择与频率延拓、穿越负实轴时的方向性判定(自上而下为负穿越,自下而上为正穿越)、开环含积分环节( s = 0 极点)时的路径处理等。掌握这些细节,能显著提高判别准确性与效率[^7][^13]。

### 5.5 稳定裕度与频域性能指标

稳定裕度衡量系统接近临界稳定的程度,是频域设计的核心指标:

- 相位裕度 γ:定义为 γ = 180° + ∠G(jωc)H(jωc),其中 ωc 为截止频率(开环幅值等于 1 或 0 dB 对应的频率)。典型工程范围为 30°–60°[^3][^4]。
- 幅值裕度 Lg:定义为 Lg = -20lg|G(jωg)H(jωg)|,其中 ωg 为相位穿越频率(相角为 -180° 对应的频率)。典型工程范围为 6–20 dB[^3][^4]。
- 截止频率与带宽:截止频率越高,系统快速性越好,但噪声与相位滞后风险增加。设计中需在 γ 与 ωc 之间寻求平衡[^3][^4]。

表5-5 稳定裕度定义与工程范围
| 指标 | 定义 | 工程范围(参考) |
|---|---|---|
| 相位裕度 γ | 180° + ∠G(jωc)H(jωc) | 30°–60° |
| 幅值裕度 Lg | -20lg|G(jωg)H(jωg)| | 6–20 dB |
| 截止频率 ωc | |G(jωc)H(jωc)| = 1 (0 dB) | 越高越快,但需兼顾噪声与相位 |

二阶系统中,相位裕度与阻尼比存在近似关系:ζ 增大,γ 随之增大,σ% 随之减小。这一关系为频域—时域指标转换提供便利,有助于以 γ 目标直接指导设计[^3]。

### 5.6 频域设计方法与实例

频域设计通常遵循“由目标到校正”的逆向流程:先依据时域指标(超调、调节时间)或稳定裕度目标(γ、Lg)设定截止频率与相位裕度,再选择合适的校正装置(超前、滞后、滞后-超前或PID)以调整幅频与相频,最终达到目标。超前校正通过相位提升与高频增益增加提高 γ 与 ωc;滞后校正通过低频增益提升改善稳态误差,同时避免在 ωc 附近引入过大相位滞后;滞后-超前综合两者优势,PID则在结构上融合积分与微分作用[^3][^4][^7]。

表5-6 频域设计步骤与目标映射
| 步骤 | 目标/输入 | 设计动作 | 校验 |
|---|---|---|---|
| 指标设定 | σ%、ts 或 γ、Lg | 设定 ωc 与 γ 目标 | 核对与时域指标一致性 |
| 校正选择 | 动态/稳态优先级 | 超前/滞后/滞后-超前/PID | 绘制校正后伯德/奈氏图 |
| 参数整定 | 转折频率与增益 | 配置零点/极点与增益 | 计算 γ、Lg 与带宽 |
| 仿真验证 | 时域响应 | 阶跃/斜坡/扰动响应 | 调整参数直至满足全部指标 |

该流程强调“图—指标—校正”的闭环:用伯德图快速扫频与估算,用奈奎斯特图核验稳定裕度与穿越细节,再以时域仿真验证设计结果[^3][^4][^7]。

## 第6章:状态空间分析法

状态空间法以内部状态变量为基础,提供比经典频域法更一般的系统描述与设计框架。其核心优势在于:可直接处理多输入多输出(MIMO)系统、便于极点配置与观测器设计,并与最优控制等现代方法自然衔接[^9]。

### 6.1 基本概念与模型建立

状态空间表达式由状态方程与输出方程构成:
- ẋ = Ax + Bu
- y = Cx + Du

其中 x ∈ R^n 为状态向量,u ∈ R^m 为输入,y ∈ R^p 为输出,A、B、C、D 为相应维数的矩阵。状态变量的选择不唯一,但应能完全描述系统的动态行为。常见建模路径包括:由微分方程列写(相变量法)、由传递函数实现(直接、串联、并联)、由对角线或约当标准型变换得到规范型等[^9]。

表6-1 状态空间模型基本矩阵与维度
| 矩阵 | 含义 | 维度 |
|---|---|---|
| A | 系统矩阵(状态动力学) | n × n |
| B | 输入矩阵 | n × m |
| C | 输出矩阵 | p × n |
| D | 前馈矩阵 | p × m |

在实现层面,传递函数的有理分式可转化为状态空间模型(能控标准型、能观标准型、对角/约当型),不同实现对应不同的数值性质与设计便利性(如能控/能观结构对极点配置与观测器设计的影响)[^9]。

### 6.2 状态方程求解

齐次状态方程 ẋ = Ax 的解由状态转移矩阵 φ(t) = e^{At} 给出:x(t) = e^{At} x(0) + ∫_0^t e^{A(t-τ)} Bu(τ)dτ。非齐次解可分解为状态转移与输入卷积两部分。数值求解常用方法包括:矩阵指数计算、离散化方法(如零阶保持采样)、以及基于特征值/特征向量的解析对角化(当 A 可对角化时)[^9]。

表6-2 状态方程求解方法与适用条件
| 方法 | 核心思想 | 适用条件 | 备注 |
|---|---|---|---|
| 状态转移矩阵 | e^{At} | A 已知 | 解析/数值均可 |
| 拉普拉斯变换 | (sI - A)^{-1} | 可进行拉氏变换 | 与频域法衔接 |
| 数值积分 | 欧龙/龙格-库塔 | 一般线性系统 | 适合仿真 |
| 离散化 | 采样保持 | 数字实现 | 与控制器实现相关 |

这些方法为仿真与设计提供了坚实的计算基础,尤其在 MATLAB 等工具中,状态转移矩阵与离散化函数可直接调用,便于快速验证设计[^9]。

### 6.3 可控性与可观测性

- 可控性(能控性):若存在有限时间内控制输入 u(t),使系统从任意初始状态转移到任意目标状态,则称系统完全可控。判据为能控性矩阵 [B, AB, ..., A^{n-1}B] 满秩。
- 可观测性(能观性):若在有限时间通过输出 y(t) 观测唯一确定初始状态,则称系统完全可观测。判据为能观性矩阵 [C; CA; ...; CA^{n-1}] 满秩。

表6-3 可控/可观测判据与秩条件
| 性质 | 判据矩阵 | 满秩条件 |
|---|---|---|
| 完全可控 | [B, AB, ..., A^{n-1}B] | rank = n |
| 完全可观测 | [C; CA; ...; CA^{n-1}] | rank = n |

在不完全可控或不完全可观测的情况下,系统存在不可控/不可观模态,需在设计与实现中予以处理(如通过反馈配置可控模态、观测器重构可观模态)[^9]。

### 6.4 状态反馈与观测器

- 状态反馈:若系统完全可控,则可通过状态反馈 u = -Kx 实现闭环极点任意配置(在复数域共轭对称约束下),从而满足时域性能(上升时间、超调、调节时间)与稳态误差要求。K 的确定可基于极点配置算法或最优控制(如线性二次型调节器,LQR)[^9]。
- 状态观测器:若系统完全可观测,则可构造 Luenberger 观测器 ẋ̂ = A x̂ + B u + L(y - C x̂),通过输出误差校正使估计状态 x̂ 在一定收敛速度下逼近真实状态 x。观测器增益 L 可通过极点配置确定,保证误差动态满足期望的阻尼与速度[^9]。

表6-4 状态反馈与观测器设计要点
| 设计项 | 目标 | 方法 | 校验 |
|---|---|---|---|
| 状态反馈 K | 极点配置 | 能控性满秩 + 配置算法 | 闭环特征值与时域响应 |
| 观测器增益 L | 误差动态收敛 | 能观性满秩 + 配置算法 | 估计误差与噪声影响 |
| 分离特性 | 反馈与观测独立 | K 与 L 分别设计 | 联合系统稳定性 |

在状态反馈与观测器联合使用时,分离原理保证两者的设计可相对独立,但需整体校验闭环稳定性与鲁棒性,避免观测噪声与高频未建模动态对控制性能产生不利影响[^9]。

### 6.5 可控性与可观测性判据的严格证明

#### 6.5.1 可控性判据证明

**定理**: 系统(ẋ = Ax + Bu, y = Cx + Du)完全可控的充要条件是可控性矩阵

$$C_c = [B, AB, A^2B, \ldots, A^{n-1}B]$$

的秩为n，即rank($C_c$) = n。

**证明(必要性)**: 
假设系统完全可控，则存在控制输入u(t)在有限时间内将系统从任意初始状态x(0)转移到任意目标状态x(T)。

考虑齐次方程的解：
$$x(T) = e^{AT}x(0) + \int_0^T e^{A(T-\tau)}Bu(\tau)d\tau$$

整理得：
$$\int_0^T e^{-A\tau}Bu(\tau)d\tau = e^{-AT}x(T) - x(0)$$

将指数函数展开为幂级数：
$$e^{-A\tau} = I - A\tau + \frac{A^2\tau^2}{2!} - \cdots$$

代入积分并交换积分与求和次序：
$$\int_0^T \sum_{k=0}^{\infty} \frac{(-A\tau)^k}{k!}Bu(\tau)d\tau = \sum_{k=0}^{\infty} \frac{(-1)^kA^k}{k!}\int_0^T \tau^k u(\tau)d\tau$$

令$\beta_k = \int_0^T \tau^k u(\tau)d\tau$，则：
$$\sum_{k=0}^{\infty} \frac{(-1)^kA^k\beta_k}{k!} = e^{-AT}x(T) - x(0)$$

由于右侧可以是任意向量(因为x(T)可任意选择)，这意味着向量组$\{B, AB, A^2B, \ldots, A^{n-1}B\}$必须张成整个n维空间，即rank($C_c$) = n。

**证明(充分性)**:
假设rank($C_c$) = n，则矩阵$C_c$的列向量线性无关，张成整个n维空间。

构造控制输入：
$$u(t) = \sum_{k=0}^{n-1} \alpha_k t^k$$

其中$\alpha_k$为待定系数向量。代入状态方程的解：
$$x(T) - e^{AT}x(0) = \int_0^T e^{A(T-\tau)}Bu(\tau)d\tau$$

$$= \int_0^T e^{A(T-\tau)}B\sum_{k=0}^{n-1} \alpha_k \tau^k d\tau$$

$$= \sum_{k=0}^{n-1} \alpha_k \int_0^T e^{A(T-\tau)}B\tau^k d\tau$$

利用Cayley-Hamilton定理，$A^n$可以表示为$A^{n-1}, \ldots, A, I$的线性组合，因此：
$$\int_0^T e^{A(T-\tau)}B\tau^k d\tau = \sum_{j=0}^{n-1} \gamma_{kj} A^j B$$

其中$\gamma_{kj}$为标量系数。于是：
$$x(T) - e^{AT}x(0) = \sum_{k=0}^{n-1} \alpha_k \sum_{j=0}^{n-1} \gamma_{kj} A^j B = \sum_{j=0}^{n-1} (\sum_{k=0}^{n-1} \alpha_k \gamma_{kj}) A^j B$$

令$\beta_j = \sum_{k=0}^{n-1} \alpha_k \gamma_{kj}$，则：
$$x(T) - e^{AT}x(0) = \sum_{j=0}^{n-1} \beta_j A^j B = C_c [\beta_0; \beta_1; \ldots; \beta_{n-1}]$$

由于rank($C_c$) = n，对于任意右侧向量都可以找到合适的$\beta_j$，从而确定$\alpha_k$，构造出相应的控制输入u(t)。因此系统完全可控。□

#### 6.5.2 可观测性判据证明

**定理**: 系统完全可观测的充要条件是可观测性矩阵

$$C_o = \begin{bmatrix} C \\ CA \\ CA^2 \\ \vdots \\ CA^{n-1} \end{bmatrix}$$

的秩为n，即rank($C_o$) = n。

**证明(必要性)**: 
假设系统完全可观测，则对于任意两个不同的初始状态$x_1(0)$和$x_2(0)$，存在有限时间T使得输出轨迹$y_1(t)$和$y_2(t)$不同。

考虑零输入响应：
$$y_1(t) - y_2(t) = C e^{At} (x_1(0) - x_2(0))$$

如果$x_1(0) - x_2(0)$位于矩阵$C_o$的零空间中，即$C_o (x_1(0) - x_2(0)) = 0$，则：
$$C(x_1(0) - x_2(0)) = 0$$
$$CA(x_1(0) - x_2(0)) = 0$$
$$\vdots$$
$$CA^{n-1}(x_1(0) - x_2(0)) = 0$$

利用Cayley-Hamilton定理，$CA^k(x_1(0) - x_2(0)) = 0$对所有k ≥ n也成立，因此：
$$y_1(t) - y_2(t) = C e^{At} (x_1(0) - x_2(0)) = 0$$

这与可观测性假设矛盾。因此，如果系统完全可观测，则$C_o$的零空间必须为{0}，即rank($C_o$) = n。

**证明(充分性)**:
假设rank($C_o$) = n。考虑输出方程：
$$y(t) = Cx(t) = C e^{At} x(0)$$

将指数函数展开：
$$y(t) = C(I + At + \frac{A^2t^2}{2!} + \cdots)x(0)$$

对输出进行采样，构造观测矩阵：
$$Y = \begin{bmatrix} y(t_1) \\ y(t_2) \\ \vdots \\ y(t_n) \end{bmatrix} = \begin{bmatrix} C \\ Ce^{At_2} \\ \vdots \\ Ce^{At_n} \end{bmatrix} x(0)$$

利用Cayley-Hamilton定理，$Ce^{At_k}$可以表示为$C, CA, CA^2, \ldots, CA^{n-1}$的线性组合。因此存在矩阵$\Phi$使得：
$$Y = \Phi C_o x(0)$$

由于rank($C_o$) = n，矩阵$\Phi C_o$也满秩，因此：
$$x(0) = (\Phi C_o)^{-1} Y$$

这表明初始状态$x(0)$可以由有限个时刻的输出观测值唯一确定，即系统完全可观测。□

### 6.6 状态反馈极点配置算法

#### 6.6.1 极点配置算法步骤

极点配置是状态空间设计中的核心方法，其目标是通过状态反馈将闭环系统的极点配置到期望位置。

**算法步骤**:

1. **检查可控性**: 验证可控性矩阵$C_c = [B, AB, \ldots, A^{n-1}B]$的秩是否为n。

2. **选择期望极点**: 根据性能指标(超调量、调节时间等)确定期望闭环极点位置。

3. **构造可控标准型**: 通过相似变换将系统转换为可控标准型。

4. **计算反馈增益**: 在可控标准型下计算反馈增益，然后通过逆变换得到原坐标系下的反馈增益。

#### 6.6.2 极点配置算法实现

**方法一：直接法(Ackermann公式)**

对于单输入单输出(SISO)系统，反馈增益可以通过Ackermann公式直接计算：

$$K = [0, 0, \ldots, 0, 1] C_c^{-1} \phi(A)$$

其中$\phi(\lambda) = (\lambda - \lambda_1)(\lambda - \lambda_2)\cdots(\lambda - \lambda_n)$是期望特征多项式，$\lambda_i$为期望极点。

**方法二：极点配置函数**

在MATLAB中，可以使用`place`函数进行极点配置：

```matlab
% 定义系统矩阵
A = [0 1; 0 -1];
B = [0; 1];

% 期望极点位置
desired_poles = [-2+2j, -2-2j];

% 计算反馈增益
K = place(A, B, desired_poles);

% 验证闭环特征值
eig(A - B*K)
```

**方法三：LQR最优控制**

LQR(Linear Quadratic Regulator)通过最小化二次性能指标来设计状态反馈：

$$\min J = \int_0^{\infty} (x^T Qx + u^T Ru) dt$$

其中Q和R为权重矩阵。通过求解Riccati方程得到最优反馈增益：

$$K = R^{-1}B^T P$$

其中P是Riccati方程的解：
$$A^T P + PA - PBR^{-1}B^T P + Q = 0$$

### 6.7 状态观测器设计

#### 6.7.1 龙伯格观测器设计

当系统状态不能直接测量时，需要设计状态观测器来估计系统状态。龙伯格观测器(Luenberger Observer)是最常用的观测器之一。

**观测器方程**:
$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - C\hat{x})$$

其中$\hat{x}$为状态估计值，L为观测器增益矩阵。

**误差动态**:
定义状态估计误差$e = x - \hat{x}$，则：
$$\dot{e} = (A - LC)e$$

为了使误差快速收敛，需要配置矩阵(A - LC)的特征值到期望位置。

#### 6.7.2 观测器增益计算

**极点配置法**:

1. **检查可观测性**: 验证可观测性矩阵$C_o$的秩是否为n。

2. **选择期望极点**: 根据收敛速度要求选择观测器极点位置(通常比闭环极点更快)。

3. **计算观测器增益**: 通过极点配置算法计算L。

**MATLAB实现**:

```matlab
% 定义系统矩阵
A = [0 1; 0 -1];
C = [1 0];

% 期望观测器极点(比闭环极点更快)
desired_observer_poles = [-5, -6];

% 计算观测器增益
L = place(A', C', desired_observer_poles)';

% 验证观测器特征值
eig(A - L*C)
```

### 6.8 设计实例：倒立摆系统的LQR控制

#### 6.8.1 系统建模

倒立摆系统是一个典型的非线性系统，包括小车和摆杆。系统状态变量包括：
- $x_1$: 小车位置
- $x_2$: 小车速度  
- $x_3$: 摆杆角度
- $x_4$: 摆杆角速度

**非线性动力学方程**:
$$\ddot{x} = \frac{u + ml\dot{\theta}^2\sin\theta - mgl\sin\theta\cos\theta}{M + m\sin^2\theta}$$
$$\ddot{\theta} = \frac{(M+m)g\sin\theta - u\cos\theta - ml\dot{\theta}^2\sin\theta\cos\theta}{(M+m)l - ml\cos^2\theta}$$

其中：
- M: 小车质量
- m: 摆杆质量  
- l: 摆杆半长
- g: 重力加速度
- u: 控制力

**线性化模型**:
在平衡点$\theta = 0$附近线性化，得到状态空间模型：

$$\dot{x} = Ax + Bu$$

其中：
$$A = \begin{bmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & -\frac{mg}{M} & 0 \\ 0 & 0 & 0 & 1 \\ 0 & 0 & \frac{(M+m)g}{Ml} & 0 \end{bmatrix}, \quad B = \begin{bmatrix} 0 \\ \frac{1}{M} \\ 0 \\ -\frac{1}{Ml} \end{bmatrix}$$

#### 6.8.2 LQR控制器设计

**性能指标权重矩阵选择**:

根据控制目标，选择权重矩阵：
- Q矩阵：对角元素表示各状态的权重，通常对角度和角速度赋予更高权重
- R矩阵：控制输入的权重，控制能量消耗

```matlab
% 系统参数
M = 1; m = 0.1; l = 0.5; g = 9.8;

% 状态空间矩阵
A = [0 1 0 0;
     0 0 -m*g/M 0;
     0 0 0 1;
     0 0 (M+m)*g/(M*l) 0];
B = [0; 1/M; 0; -1/(M*l)];

% 权重矩阵
Q = diag([10, 1, 100, 10]);  % 角度权重最高
R = 1;                       % 控制输入权重

% LQR控制器设计
[K, P, eigenvalues] = lqr(A, B, Q, R);

% 显示结果
disp('LQR反馈增益矩阵 K:');
disp(K);
disp('闭环特征值:');
disp(eigenvalues);
```

**仿真结果分析**:

通过仿真可以验证：
1. 倒立摆能够稳定在竖直位置
2. 小车位置能够跟踪参考输入
3. 系统响应满足性能指标要求

#### 6.8.3 状态观测器设计

在实际应用中，某些状态(如速度)可能难以直接测量，需要设计观测器。

```matlab
% 观测器设计
C = [1 0 0 0; 0 0 1 0];  % 可测量的输出(位置和角度)

% 期望观测器极点
observer_poles = [-8, -9, -10, -11];

% 计算观测器增益
L = place(A', C', observer_poles)';

% 观测器系统矩阵
A_obs = A - L*C;

% 验证观测器性能
eig(A_obs)
```

### 6.9 设计实例：直流电机调速系统的PID控制

#### 6.9.1 直流电机数学模型

直流电机的传递函数为：
$$G(s) = \frac{K_t}{Ls + R + K_t K_e / J}$$

其中：
- $K_t$: 转矩常数
- $K_e$: 反电动势常数  
- L: 电枢电感
- R: 电枢电阻
- J: 转动惯量

**状态空间模型**:

选择状态变量：
- $x_1$: 电机转速$\omega$
- $x_2$: 电枢电流$i$

状态方程：
$$\dot{x_1} = \frac{K_t}{J}x_2 - \frac{B}{J}x_1$$
$$\dot{x_2} = -\frac{K_e}{L}x_1 - \frac{R}{L}x_2 + \frac{1}{L}u$$

其中B为阻尼系数。

#### 6.9.2 PID控制器设计

**PID控制规律**:
$$u(t) = K_p e(t) + K_i \int_0^t e(\tau)d\tau + K_d \frac{de(t)}{dt}$$

**Ziegler-Nichols整定方法**:

1. 纯比例控制下，逐渐增大$K_p$直到系统产生持续振荡
2. 记录临界增益$K_u$和振荡周期$T_u$
3. 根据经验公式计算PID参数：
   - $K_p = 0.6K_u$
   - $K_i = \frac{2K_p}{T_u}$  
   - $K_d = \frac{K_p T_u}{8}$

**MATLAB/Simulink仿真**:

```matlab
% 电机参数
Kt = 0.1; Ke = 0.1; L = 0.01; R = 1; J = 0.01; B = 0.001;

% 状态空间模型
A = [-B/J, Kt/J; -Ke/L, -R/L];
B = [0; 1/L];
C = [1, 0];  % 速度输出
D = 0;

% PID控制器参数(通过Z-N方法整定)
Ku = 100; Tu = 0.1;  % 临界参数
Kp = 0.6 * Ku;
Ki = 2 * Kp / Tu;
Kd = Kp * Tu / 8;

% 创建PID控制器
pid_controller = pid(Kp, Ki, Kd);

% 系统仿真
sim('dc_motor_pid_control.slx');
```

**仿真结果分析**:

通过仿真可以观察到：
1. 阶跃响应：快速跟踪，稳态误差为零
2. 扰动响应：对负载扰动的抑制能力
3. 稳态性能：转速稳定在设定值

#### 6.9.3 参数优化与性能分析

**性能指标**:
- 上升时间$t_r$：从10%到90%的时间
- 调节时间$t_s$：进入±5%误差带的时间  
- 超调量$\sigma$：最大超调百分比
- 稳态误差$e_{ss}$：稳态时的跟踪误差

**参数整定策略**:

1. **试凑法**: 根据经验调整PID参数
2. **Cohen-Coon方法**: 适用于有自衡对象
3. **遗传算法优化**: 全局搜索最优参数
4. **粒子群算法**: 智能优化方法

```matlab
% 性能指标计算函数
function [tr, ts, overshoot, ess] = performance_metrics(t, y, ref)
    % 上升时间
    [~, idx_10] = min(abs(y - 0.1*ref));
    [~, idx_90] = min(abs(y - 0.9*ref));
    tr = t(idx_90) - t(idx_10);
    
    % 调节时间(5%误差带)
    idx_ts = find(abs(y - ref) > 0.05*ref, 1, 'last');
    ts = t(idx_ts);
    
    % 超调量
    overshoot = (max(y) - ref) / ref * 100;
    
    % 稳态误差
    ess = abs(y(end) - ref) / ref * 100;
end
```

这些实例展示了状态空间分析法和PID控制在实际工程中的应用，为理论学习提供了具体的数值案例和仿真验证。

## 第7章:线性系统的校正设计

校正设计的任务是在给定对象与性能指标下,选择合适的控制器结构与参数,使闭环系统满足稳定性、快速性、稳态精度与鲁棒性要求。经典方法以串联校正为主(超前、滞后、滞后-超前),并可结合反馈校正与复合校正;PID作为工程上最常用的控制规律,提供了比例、积分、微分的综合作用[^3][^4][^7]。

### 7.1 校正的基本概念与分类

- 串联校正:校正装置与对象串联,位于前向通道,主要改变开环频率特性以达到目标稳定裕度与带宽。
- 反馈校正:通过局部反馈改变对象等效特性,降低参数敏感度或抑制非线性影响。
- 复合校正:前馈与反馈结合,在稳态精度与动态响应上实现兼顾。
- 有源/无源实现:无源校正通常由电阻、电容构成(滞后/超前网络),有源校正由运算放大器与阻容网络实现,可灵活实现PID等复杂规律[^3][^4]。

表7-1 校正方式对比
| 方式 | 结构 | 适用场景 | 优点 | 缺点 |
|---|---|---|---|---|
| 串联 | 前向通道串联 | 频域设计、伯德图主导 | 易于实现与调参 | 对噪声敏感(微分) |
| 反馈 | 局部反馈 | 抑制参数变化/非线性 | 鲁棒性强 | 分析较复杂 |
| 复合 | 前馈+反馈 | 高精度与快速性兼顾 | 综合优势 | 设计复杂 |
| 有源 | 运放+阻容 | PID/复杂网络 | 灵活、可调 | 需电源与器件 |
| 无源 | 阻容网络 | 简单滞后/超前 | 成本低 | 负载效应明显 |

### 7.2 串联校正(超前、滞后、滞后-超前)

- 超前校正:通过相位超前与高频增益提升,提高相位裕度与截止频率,适用于快速性不足或相位裕度偏低的场景。设计时将超前网络的最大相位频率配置在目标截止频率附近,避免引入过多高频噪声[^3][^4]。
- 滞后校正:通过低频增益提升改善稳态误差,同时在截止频率附近引入较小相位滞后,适用于稳态精度不足而动态裕度足够的场景。配置时将滞后网络的两转折频率远离目标截止频率,使其在 ωc 附近相频影响最小[^3][^4]。
- 滞后-超前校正:综合两者优势,滞后部分改善稳态,超前部分提升动态性能。频域设计上常以滞后部分将校正后穿越频率“推到”超前部分最大相位处的频率,再通过超前部分提升相位裕度与带宽[^3][^4]。

表7-2 串联校正参数与频域效果
| 校正 | 主要参数 | 频域效果 | 设计要点 |
|---|---|---|---|
| 超前 | 零点/极点位置、α 比 | 提升相位与 ωc | 最大相位对准 ωc |
| 滞后 | 低频增益、两转折频率 | 低频增益↑、ωc 相位滞后↓ | 转折频率远离 ωc |
| 滞后-超前 | 滞后与超前参数组 | 综合提升 | 先滞后定位,再超前提升 |

### 7.3 反馈校正与复合校正

反馈校正通过内环改变对象等效动态,降低参数敏感度或抑制非线性;复合校正在反馈基础上加入前馈路径,利用已知输入或扰动模型进行“预补偿”,提升稳态精度与动态响应。工程上,复合校正常用于伺服系统与轨迹跟踪任务,在保证鲁棒性的同时提高跟踪性能[^3][^4]。

表7-3 反馈/复合校正结构与适用场景
| 结构 | 适用场景 | 设计关注点 |
|---|---|---|
| 局部反馈 | 参数漂移、非线性显著 | 等效模型与稳定性 |
| 复合校正 | 轨迹跟踪、扰动抑制 | 前馈模型与噪声影响 |

### 7.4 PID控制器设计

PID控制规律定义为 u(t) = Kp e(t) + Ki ∫ e(t) dt + Kd de(t)/dt,频域形式可写为 Kp + Ki/s + Kd s。参数整定可采用 Ziegler–Nichols 方法(临界增益法)或其他经验/模型基础方法;在频域设计中,PID的积分部分提升低频增益以减小稳态误差,微分部分提供相位超前以改善动态裕度,但需注意高频噪声放大与饱和非线性问题[^3][^4]。

表7-4 PID参数与频域/时域影响
| 参数 | 时域作用 | 频域影响 | 风险与注意 |
|---|---|---|---|
| Kp | 增大误差放大倍数 | 提高增益、缩短上升时间 | 超调与稳态误差权衡 |
| Ki | 消除稳态误差 | 低频增益↑ | 积分饱和、低频振荡 |
| Kd | 抑制超调、加快阻尼 | 相位超前↑ | 噪声放大、硬件限制 |

### 7.5 基于根轨迹法的校正设计

根轨迹法校正的核心在于:通过增加零点或移动极点,改变轨迹走向,使期望闭环极点位于目标等 ζ 线与等 ωn 线上。设计步骤通常为:根据性能指标确定希望的闭环极点位置;在开环传递函数中配置零点(吸引轨迹)与调整增益;校验分离/汇合点与虚轴交点,确保稳定性与动态性能满足要求[^1][^2]。

表7-5 根轨迹校正步骤与目标映射
| 步骤 | 目标 | 设计动作 | 校验 |
|---|---|---|---|
| 极点位置设定 | σ%、ts | 等 ζ 线与 ωn 约束 | 核对时域指标 |
| 零点配置 | 轨迹走向 | 增加零点/调整位置 | 分离/汇合点校核 |
| 增益整定 | K* | 幅值条件计算 | 虚轴交点与稳定裕度 |
| 仿真验证 | 综合性能 | 阶跃/斜坡响应 | 调整至满足全部指标 |

### 7.6 基于频域法的校正设计

频域法校正以伯德图与奈奎斯特图为工具,先设定 γ 与 ωc 目标,再选择校正网络并整定参数,最后以奈奎斯特判据核验稳定性。超前网络用于提升 γ 与 ωc;滞后网络用于提升低频增益、减小稳态误差;滞后-超前网络与PID用于综合优化。设计完成后,需以时域仿真验证超调与调节时间是否满足指标[^3][^4][^7]。

表7-6 频域法校正步骤与目标映射
| 步骤 | 目标 | 设计动作 | 校验 |
|---|---|---|---|
| 设定 γ、ωc | 快速性与裕度 | 选择校正网络 | 奈奎斯特判据 |
| 参数整定 | 转折频率与增益 | 配置零极点与 K | 伯德图渐近近似 |
| 仿真验证 | 时域指标 | 阶跃/斜坡响应 | 调整参数直至达标 |

## 综合方法对比与设计桥梁

根轨迹法、频域法与状态空间法在稳定性判据、性能指标与设计流程上形成互补。根轨迹法提供闭环极点的直观走向与稳定性边界;频域法以开环频率特性为桥梁,高效估算稳定裕度与带宽;状态空间法则在多变量与极点配置、观测器设计方面具有不可替代的优势。将三者有机结合,可在不同阶段发挥各自长处[^1][^3][^9]。

- 方法选型建议:若对象为单输入单输出(SISO)且以稳定裕度与带宽为主,频域法优先;若需要直观把握闭环极点走向与动态趋势,根轨迹法更合适;若为多输入多输出(MIMO)或需极点配置与观测器设计,状态空间法应作为主框架。
- 联合设计流程:用频域法快速扫频与设定 γ、ωc 目标;用根轨迹法验证与微调闭环极点位置与增益;在状态空间框架下进行极点配置与观测器设计,实现鲁棒与高性能控制。

表8-1 方法对比与适用场景
| 方法 | 稳定性判据 | 性能指标 | 设计工具 | 适用场景 |
|---|---|---|---|---|
| 根轨迹 | 虚轴交点、轨迹走向 | ζ、ωn、ts、σ% | 零极点图与渐近线 | SISO、直观走向 |
| 频域 | 奈奎斯特判据、γ、Lg | 截止频率、带宽、Mr | 伯德/奈氏图 | 工程快速设计 |
| 状态空间 | 极点配置、分离原理 | 收敛速度、稳态误差 | A、B、C、D矩阵 | MIMO、观测器与最优控制 |

## 图表绘制方法与技巧(跨章节)

图表是控制理论与工程设计的“第二语言”。高质量的图表不仅提升理解效率,更是设计校验的关键证据。

- 根轨迹图:先绘零极点、渐近线与实轴段,再估算分离/汇合点与出射/入射角;在关键点用幅角条件验证轨迹位置,并用幅值条件计算增益。关注虚轴交点与临界增益,避免稳定性误判[^1][^2]。
- 奈奎斯特图:按 ω 从 0 至 ∞ 描点,关注与负实轴的交点与穿越方向,统计包围圈数 R;特别注意开环含积分环节时的路径处理与半闭合路径选择[^7][^13]。
- 伯德图:先绘渐近线,再在转折频率附近进行修正;相位曲线按环节特性与频率叠加原则绘制;截止频率 ωc 与相位裕度 γ 的几何关系可用于快速估算 γ,避免繁复计算[^3][^4]。

表9-1 绘制步骤与常见错误清单
| 图 | 步骤 | 常见错误 | 规避建议 |
|---|---|---|---|
| 根轨迹 | 零极点→渐近线→实轴段→分离/汇合→出射/入射角→虚轴交点 | 符号误用(180°/0°判据混淆)、增益计算错误 | 明确反馈极性、幅值条件校核 |
| 奈奎斯特 | 描点→负实轴穿越→包围圈统计 | 路径选择不当、穿越方向误判 | 熟记 Z=P-R、路径与频率映射 |
| 伯德图 | 渐近线→转折修正→相位叠加 | 转折频率错位、相位修正不足 | 标注关键频率、局部放大修正 |

## 考试重点题型与解题策略

考试侧重“概念—方法—计算—判据”的综合应用。以下为常见题型与策略要点。

- 根轨迹绘制与判别:给定开环传递函数,绘制根轨迹草图,求虚轴交点与临界增益,判断稳定性随增益的变化;注意区分 180°与 0°根轨迹,正确使用实轴判据与渐近线公式[^1][^2]。
- 频域稳定性与裕度计算:给定开环频率特性,绘制奈奎斯特图或伯德图,应用奈奎斯特判据判断闭环稳定,计算相位裕度 γ 与幅值裕度 Lg;以二阶近似关系将 γ 与 ζ、σ% 关联,完成时域指标估算[^3][^7][^13]。
- 状态空间建模与性质:给定微分方程或传递函数,列写状态空间表达式,判断可控/可观测性,设计状态反馈或观测器;掌握能控/能观判据与极点配置方法[^9]。
- 校正设计:给出性能指标,选择校正方式(超前/滞后/滞后-超前/PID),在根轨迹或频域框架下整定参数,并进行稳定性与性能校验;强调“目标—方法—校验”的闭环[^3][^4]。

| 奈奎斯特 | Z=P-R、穿越方向、路径选择 | 描点→负实轴穿越→圈数统计 |

## 定理证明与推导(附录)

本附录汇总核心定理与关键推导,便于教学与备考。

- 根轨迹幅值与相角条件推导:由闭环特征方程 1 + G(s)H(s) = 0,写成 G(s)H(s) = -1;其实部与虚部分别满足幅值与相角条件,得到 |G(s)H(s)| = 1 与 ∠G(s)H(s) = (2k + 1)π;该等价性是根轨迹作图的理论基础[^1][^2]。
- 奈奎斯特判据证明要点:以 s 平面封闭路径映射到 G(s)H(s) 平面,依据幅角原理(零点/极点对相角变化的贡献)建立 Z = P - R 的关系;稳定要求 Z = 0,故 R = P;半闭合路径与积分环节处理是证明中的关键细节[^7][^13]。
- 二阶系统频域—时域指标关系:由典型二阶系统传递函数与阻尼比 ζ、自然频率 ωn 的定义,得到 σ% = exp(-ζπ/√(1-ζ²)) 与 ts(5%) ≈ 3/(ζwn),ts(2%) ≈ 4/(ζwn);相位裕度 γ 与 ζ 的近似关系用于频域设计中的指标转换[^3]。

| 定理/公式 | 关键步骤 | 参考 |
|---|---|---|
| 根轨迹条件 | 特征方程→G(s)H(s)=-1→幅值/相角等价 | [^1][^2] |
| 奈奎斯特判据 | 封闭路径映射→幅角原理→Z=P-R | [^7][^13] |
| 二阶指标关系 | 传递函数→时域响应→近似公式 | [^3] |
