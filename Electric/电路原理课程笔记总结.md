## 第1章：电路基本概念与定律

### 1.1 电路基本概念

#### 1.1.1 电路组成要素

| 元件类型 | 符号 | 特性 | 主要参数 |
|---------|------|------|----------|
| 电阻 | R | 消耗电能 | 阻值R (Ω) |
| 电感 | L | 储存磁场能 | 电感L (H) |
| 电容 | C | 储存电场能 | 电容C (F) |
| 电源 | V/I | 提供能量 | 电压V/电流I |

#### 1.1.2 基本物理量

- **电压（Voltage）**：$V = \frac{dW}{dq}$，单位：伏特（V）
- **电流（Current）**：$I = \frac{dq}{dt}$，单位：安培（A）
- **功率（Power）**：$P = VI = I^2R = \frac{V^2}{R}$，单位：瓦特（W）
- **能量（Energy）**：$W = \int P dt$，单位：焦耳（J）

### 1.2 欧姆定律

#### 1.2.1 欧姆定律表达式

$$V = IR$$

其中：
- $V$：电压（V）
- $I$：电流（A）
- $R$：电阻（Ω）

#### 1.2.2 欧姆定律的推广形式

对于电感和电容：

- **电感**：$v_L = L\frac{di_L}{dt}$
- **电容**：$i_C = C\frac{dv_C}{dt}$

<details>
<summary><strong>欧姆定律推导过程</strong></summary>

欧姆定律的推导基于焦耳定律和能量守恒：

1. **从焦耳定律开始**：$P = I^2R$
2. **功率定义**：$P = \frac{dW}{dt}$
3. **能量积分**：$W = \int P dt = \int I^2R dt$
4. **电压定义**：$V = \frac{dW}{dq} = \frac{dW}{I dt}$
5. **代入得**：$V = \frac{\int I^2R dt}{I dt} = IR$

因此：$V = IR$
</details>

### 1.3 基尔霍夫定律

#### 1.3.1 基尔霍夫电流定律（KCL）

**定律内容**：在任一时刻，流入任一节点的电流之和等于流出该节点的电流之和。

**数学表达式**：
$$\sum_{k=1}^{n} I_k = 0$$

或：
$$\sum_{k=1}^{n} I_{in,k} = \sum_{k=1}^{n} I_{out,k}$$

#### 1.3.2 基尔霍夫电压定律（KVL）

**定律内容**：在任一时刻，沿任一闭合回路的电压降之和等于零。

**数学表达式**：
$$\sum_{k=1}^{n} V_k = 0$$

<details>
<summary><strong>基尔霍夫定律的严格推导</strong></summary>

**KCL的推导**：
基于电荷守恒定律。在节点处，电荷既不能产生也不能消失，因此流入节点的净电荷为零。

设流入节点的电流为正，流出为负：
$$\sum_{k=1}^{n} I_k = 0$$

**KVL的推导**：
基于能量守恒定律和电势的唯一定理。

1. **电势的单值性**：空间中任意两点间的电势差是唯一的
2. **闭合回路**：从起点出发，绕回路一周回到起点，电势变化为零
3. **电压定义**：$V = \phi_{起点} - \phi_{终点}$

因此：$$\sum_{k=1}^{n} V_k = 0$$
</details>

### 1.4 电路元件特性

#### 1.4.1 电阻元件

- **线性电阻**：$v = Ri$
- **非线性电阻**：$v = f(i)$ 或 $i = g(v)$

#### 1.4.2 电感元件

- **电压-电流关系**：$v_L = L\frac{di_L}{dt}$
- **能量存储**：$W_L = \frac{1}{2}Li_L^2$

#### 1.4.3 电容元件

- **电压-电流关系**：$i_C = C\frac{dv_C}{dt}$
- **能量存储**：$W_C = \frac{1}{2}Cv_C^2$

### 1.5 电路基本分析方法

#### 1.5.1 支路电流法

**步骤**：
1. 选定各支路电流的参考方向
2. 应用KCL列写(n-1)个独立节点方程
3. 应用KVL列写(m-n+1)个独立回路方程
4. 求解方程组得到各支路电流

#### 1.5.2 网孔电流法

**基本思想**：以网孔电流为未知量列写KVL方程。

**网孔方程**：
$$\sum_{j=1}^{n} R_{ij}I_{mj} = \sum_{k=1}^{m} V_{mk}$$

其中$R_{ij}$为网孔电阻，$V_{mk}$为网孔电压源。

## 第2章：电路分析方法

### 2.1 支路电流法

#### 2.1.1 方法步骤

1. **确定支路数**：设电路有b条支路，n个节点
2. **列写KCL方程**：对(n-1)个独立节点列方程
3. **列写KVL方程**：对(m-n+1)个独立回路列方程
4. **联立求解**：解b个方程得到各支路电流

#### 2.1.2 支路电流法的矩阵形式

**KCL矩阵形式**：$\mathbf{AI_b = 0}$

**KVL矩阵形式**：$\mathbf{BV_b = 0}$

其中：
- $\mathbf{A}$：节点关联矩阵
- $\mathbf{B}$：回路关联矩阵
- $\mathbf{I_b}$：支路电流向量
- $\mathbf{V_b}$：支路电压向量

### 2.2 网孔电流法

#### 2.2.1 基本原理

网孔电流法是在支路电流法基础上发展起来的，它以网孔电流为独立变量。

#### 2.2.2 网孔方程的建立

对于具有m个网孔的电路，网孔方程组为：

$$\begin{bmatrix}
R_{11} & R_{12} & \cdots & R_{1m} \\
R_{21} & R_{22} & \cdots & R_{2m} \\
\vdots & \vdots & \ddots & \vdots \\
R_{m1} & R_{m2} & \cdots & R_{mm}
\end{bmatrix}
\begin{bmatrix}
I_{m1} \\
I_{m2} \\
\vdots \\
I_{mm}
\end{bmatrix}
=
\begin{bmatrix}
V_{s1} \\
V_{s2} \\
\vdots \\
V_{sm}
\end{bmatrix}$$

其中：
- $R_{ii}$：第i个网孔的自电阻
- $R_{ij}$：第i、j个网孔的互电阻
- $V_{si}$：第i个网孔的电压源代数和

<details>
<summary><strong>网孔电流法推导过程</strong></summary>

1. **网孔电流定义**：设每个网孔有一个环流电流$I_{m1}, I_{m2}, ..., I_{mm}$

2. **支路电流与网孔电流关系**：
   - 公共支路电流：$I_{ij} = I_{mi} - I_{mj}$
   - 独有支路电流：$I_{ii} = I_{mi}$

3. **KVL方程建立**：对第i个网孔列KVL方程
   $$\sum R_{ij}I_{mj} = V_{si}$$

4. **电阻计算**：
   - 自电阻：$R_{ii} = \sum R_{ij}$（网孔i中所有电阻之和）
   - 互电阻：$R_{ij} = -\sum R_{ij}$（网孔i和j公共支路电阻之和，取负号）

5. **电压源代数和**：$V_{si} = \sum V_{si}$（网孔i中所有电压源代数和）
</details>

### 2.3 节点电压法

#### 2.3.1 基本原理

节点电压法以节点电压为独立变量，对具有n个节点的电路，选择一个参考节点，对其余(n-1)个节点列写KCL方程。

#### 2.3.2 节点方程

**节点电压方程矩阵形式**：

$$\mathbf{GV_n = I_s}$$

其中：
- $\mathbf{G}$：节点电导矩阵
- $\mathbf{V_n}$：节点电压向量
- $\mathbf{I_s}$：节点电流源向量

**标量形式**：
$$\sum_{j=1}^{n-1} G_{ij}V_{nj} = \sum_{k=1}^{m} I_{sk}$$

其中：
- $G_{ii}$：节点i的自电导（连接节点i的所有支路电导之和）
- $G_{ij}$：节点i和j之间的互电导（连接两节点间支路电导之和，取负号）

<details>
<summary><strong>节点电压法推导过程</strong></summary>

1. **节点电压定义**：设节点电压为$V_1, V_2, ..., V_{n-1}$（相对于参考节点）

2. **支路电流表示**：
   - 电阻支路：$I_{ij} = G_{ij}(V_i - V_j)$
   - 电流源支路：$I_{is}$（已知）

3. **KCL方程建立**：对第i个节点列KCL方程
   $$\sum_{j} I_{ij} = \sum I_{is}$$

4. **代入支路电流**：
   $$\sum_{j} G_{ij}(V_i - V_j) = \sum I_{is}$$

5. **整理得**：
   $$(\sum_{j} G_{ij})V_i - \sum_{j} G_{ij}V_j = \sum I_{is}$$

6. **定义电导**：
   - 自电导：$G_{ii} = \sum_{j} G_{ij}$
   - 互电导：$G_{ij} = -G_{ij}$（当i≠j时）
</details>

### 2.4 叠加定理

#### 2.4.1 定理内容

在线性电路中，多个独立源共同作用时，任一支路的电流或电压等于各个独立源单独作用时在该支路产生的电流或电压的代数和。

#### 2.4.2 叠加定理的数学表达

$$I = \sum_{k=1}^{m} I_k^{(k)}$$

$$V = \sum_{k=1}^{m} V_k^{(k)}$$

其中上标(k)表示第k个独立源单独作用时的响应。

<details>
<summary><strong>叠加定理的严格证明</strong></summary>

**线性电路的齐次性和可加性**：

1. **齐次性**：如果输入扩大k倍，输出也扩大k倍
   $$f(kx) = kf(x)$$

2. **可加性**：多个输入共同作用的输出等于各输入单独作用输出的和
   $$f(x_1 + x_2) = f(x_1) + f(x_2)$$

3. **线性组合**：对于线性电路，有
   $$f(\sum_{k=1}^{m} a_k x_k) = \sum_{k=1}^{m} a_k f(x_k)$$

4. **应用证明**：设电路有m个独立源
   $$响应 = f(V_{s1}, V_{s2}, ..., V_{sm}, I_{s1}, I_{s2}, ..., I_{sk})$$
   
   $$= f(V_{s1}, 0, ..., 0, 0, ..., 0) + f(0, V_{s2}, ..., 0, 0, ..., 0) + ... + f(0, 0, ..., V_{sm}, 0, ..., I_{sk})$$
   
   $$= 响应_1 + 响应_2 + ... + 响应_m$$
</details>

### 2.5 戴维南定理和诺顿定理

#### 2.5.1 戴维南定理

**定理内容**：任何线性有源二端网络都可以等效为一个电压源串联一个电阻的电路。

**等效参数**：
- **等效电压源**：$V_{th} = V_{oc}$（开路电压）
- **等效电阻**：$R_{th} = \frac{V_{oc}}{I_{sc}}$（输入电阻）

#### 2.5.2 诺顿定理

**定理内容**：任何线性有源二端网络都可以等效为一个电流源并联一个电阻的电路。

**等效参数**：
- **等效电流源**：$I_{no} = I_{sc}$（短路电流）
- **等效电阻**：$R_{no} = \frac{V_{oc}}{I_{sc}}$（输入电阻）

#### 2.5.3 戴维南等效与诺顿等效的关系

$$V_{th} = I_{no}R_{th}$$

$$I_{no} = \frac{V_{th}}{R_{th}}$$

<details>
<summary><strong>戴维南定理的证明</strong></summary>

**证明步骤**：

1. **有源二端网络**：设网络N连接负载$R_L$，端口电压为$V$，电流为$I$

2. **开路情况**：当$R_L = \infty$时，$I = 0$，$V = V_{oc}$

3. **短路情况**：当$R_L = 0$时，$V = 0$，$I = I_{sc}$

4. **一般情况**：设端口电压为$V$，电流为$I$

5. **应用叠加定理**：
   - 独立源单独作用：产生$V_{oc}$和$I_{sc}$
   - 负载$R_L$单独作用：产生电压$-IR_L$

6. **总电压**：$V = V_{oc} - IR_L$

7. **整理得**：$V = V_{oc} - IR_L$

8. **等效电路**：这正是电压源$V_{oc}$串联电阻$R_L$的电路

因此，戴维南定理得证。
</details>

### 2.6 最大功率传输定理

#### 2.6.1 定理内容

当负载电阻等于戴维南等效电阻时，负载获得最大功率。

#### 2.6.2 最大功率条件

$$R_L = R_{th}$$

#### 2.6.3 最大功率值

$$P_{max} = \frac{V_{th}^2}{4R_{th}}$$

<details>
<summary><strong>最大功率传输定理证明</strong></summary>

**证明过程**：

1. **负载功率表达式**：
   $$P_L = I^2R_L = \left(\frac{V_{th}}{R_{th} + R_L}\right)^2 R_L$$

2. **对$R_L$求导**：
   $$\frac{dP_L}{dR_L} = V_{th}^2 \frac{(R_{th} + R_L)^2 - 2R_L(R_{th} + R_L)}{(R_{th} + R_L)^4}$$

3. **令导数为零**：
   $$(R_{th} + R_L)^2 - 2R_L(R_{th} + R_L) = 0$$

4. **求解**：
   $$R_{th} + R_L = 2R_L$$
   $$R_L = R_{th}$$

5. **最大功率值**：
   $$P_{max} = \frac{V_{th}^2}{4R_{th}}$$
</details>

## 第3章：交流电路分析

### 3.1 正弦交流电的基本概念

#### 3.1.1 正弦量的表示方法

**瞬时值表示**：
$$v(t) = V_m\sin(\omega t + \phi)$$

**有效值表示**：
$$V = \frac{V_m}{\sqrt{2}}$$

其中：
- $V_m$：最大值（幅值）
- $\omega$：角频率，$\omega = 2\pi f$
- $\phi$：初相位
- $f$：频率

#### 3.1.2 正弦量的相量表示

**相量形式**：
$$\dot{V} = V\angle\phi = V(\cos\phi + j\sin\phi)$$

**相量与瞬时值的关系**：
$$v(t) = \text{Re}\{\dot{V}e^{j\omega t}\}$$

### 3.2 交流电路元件特性

#### 3.2.1 电阻元件

**电压电流关系**：
$$v_R(t) = Ri_R(t)$$

**相量关系**：
$$\dot{V}_R = R\dot{I}_R$$

**阻抗**：$Z_R = R$（纯实数）

#### 3.2.2 电感元件

**电压电流关系**：
$$v_L(t) = L\frac{di_L(t)}{dt}$$

**相量关系**：
$$\dot{V}_L = j\omega L\dot{I}_L = jX_L\dot{I}_L$$

**阻抗**：$Z_L = j\omega L = jX_L$（纯虚数）
**感抗**：$X_L = \omega L$

#### 3.2.3 电容元件

**电压电流关系**：
$$i_C(t) = C\frac{dv_C(t)}{dt}$$

**相量关系**：
$$\dot{V}_C = \frac{1}{j\omega C}\dot{I}_C = -jX_C\dot{I}_C$$

**阻抗**：$Z_C = \frac{1}{j\omega C} = -jX_C$（纯虚数）
**容抗**：$X_C = \frac{1}{\omega C}$

<details>
<summary><strong>交流元件阻抗推导</strong></summary>

**电感元件推导**：

1. **时域关系**：$v_L(t) = L\frac{di_L(t)}{dt}$

2. **正弦稳态**：$i_L(t) = I_m\sin(\omega t + \phi_i)$

3. **求导**：$\frac{di_L(t)}{dt} = \omega I_m\cos(\omega t + \phi_i) = \omega I_m\sin(\omega t + \phi_i + 90°)$

4. **电压**：$v_L(t) = \omega L I_m\sin(\omega t + \phi_i + 90°)$

5. **相量形式**：
   - 电流相量：$\dot{I}_L = I\angle\phi_i$
   - 电压相量：$\dot{V}_L = \omega LI\angle(\phi_i + 90°) = j\omega L\dot{I}_L$

**电容元件推导**：

1. **时域关系**：$i_C(t) = C\frac{dv_C(t)}{dt}$

2. **正弦稳态**：$v_C(t) = V_m\sin(\omega t + \phi_v)$

3. **求导**：$\frac{dv_C(t)}{dt} = \omega V_m\cos(\omega t + \phi_v) = \omega V_m\sin(\omega t + \phi_v + 90°)$

4. **电流**：$i_C(t) = \omega C V_m\sin(\omega t + \phi_v + 90°)$

5. **相量形式**：
   - 电压相量：$\dot{V}_C = V\angle\phi_v$
   - 电流相量：$\dot{I}_C = \omega CV\angle(\phi_v + 90°) = j\omega C\dot{V}_C$

6. **整理得**：$\dot{V}_C = \frac{1}{j\omega C}\dot{I}_C$
</details>

### 3.3 阻抗和导纳

#### 3.3.1 阻抗的定义

**阻抗**：$Z = \frac{\dot{V}}{\dot{I}} = \frac{V}{I}\angle(\phi_v - \phi_i) = |Z|\angle\theta$

其中：
- $|Z|$：阻抗模值
- $\theta$：阻抗角

#### 3.3.2 阻抗的计算

**串联电路**：
$$Z_{eq} = Z_1 + Z_2 + ... + Z_n$$

**并联电路**：
$$\frac{1}{Z_{eq}} = \frac{1}{Z_1} + \frac{1}{Z_2} + ... + \frac{1}{Z_n}$$

#### 3.3.3 导纳

**导纳定义**：$Y = \frac{1}{Z} = G + jB$

其中：
- $G$：电导
- $B$：电纳

### 3.4 交流电路的功率

#### 3.4.1 瞬时功率

$$p(t) = v(t)i(t) = V_mI_m\sin(\omega t + \phi_v)\sin(\omega t + \phi_i)$$

#### 3.4.2 平均功率（有功功率）

$$P = \frac{1}{T}\int_0^T p(t)dt = VI\cos\phi$$

其中$\cos\phi$为功率因数。

#### 3.4.3 无功功率

$$Q = VI\sin\phi$$

#### 3.4.4 视在功率

$$S = VI = \sqrt{P^2 + Q^2}$$

#### 3.4.5 功率三角形

$$S = P + jQ$$

$$|S| = \sqrt{P^2 + Q^2}$$

$$\tan\phi = \frac{Q}{P}$$

<details>
<summary><strong>交流功率公式推导</strong></summary>

**瞬时功率推导**：

1. **电压电流表达式**：
   - $v(t) = V_m\sin(\omega t + \phi_v)$
   - $i(t) = I_m\sin(\omega t + \phi_i)$

2. **瞬时功率**：
   $$p(t) = v(t)i(t) = V_mI_m\sin(\omega t + \phi_v)\sin(\omega t + \phi_i)$$

3. **使用三角恒等式**：
   $$\sin A\sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

4. **展开**：
   $$p(t) = \frac{V_mI_m}{2}[\cos(\phi_v - \phi_i) - \cos(2\omega t + \phi_v + \phi_i)]$$

**平均功率推导**：

1. **对瞬时功率积分**：
   $$P = \frac{1}{T}\int_0^T p(t)dt = \frac{1}{T}\int_0^T \frac{V_mI_m}{2}\cos(\phi_v - \phi_i)dt - \frac{1}{T}\int_0^T \frac{V_mI_m}{2}\cos(2\omega t + \phi_v + \phi_i)dt$$

2. **第二项积分为零**（余弦函数在一个周期内的平均值为零）

3. **第一项**：
   $$P = \frac{V_mI_m}{2}\cos(\phi_v - \phi_i) = VI\cos\phi$$

其中$V = \frac{V_m}{\sqrt{2}}$，$I = \frac{I_m}{\sqrt{2}}$，$\phi = \phi_v - \phi_i$
</details>

### 3.5 谐振电路

#### 3.5.1 串联谐振

**谐振条件**：$X_L = X_C$，即$\omega L = \frac{1}{\omega C}$

**谐振频率**：$\omega_0 = \frac{1}{\sqrt{LC}}$

**谐振时的特性**：
- 阻抗最小：$Z_0 = R$
- 电流最大：$I_0 = \frac{V}{R}$
- 品质因数：$Q = \frac{\omega_0 L}{R} = \frac{1}{\omega_0 CR}$

#### 3.5.2 并联谐振

**谐振条件**：$B_L = B_C$，即$\frac{1}{\omega L} = \omega C$

**谐振频率**：$\omega_0 = \frac{1}{\sqrt{LC}}$

**谐振时的特性**：
- 阻抗最大：$Z_0 = \frac{L}{RC}$
- 电流最小：$I_0 = \frac{V}{Z_0}$

### 3.6 交流电路的分析方法

#### 3.6.1 相量分析法

1. **将正弦量转换为相量**
2. **将元件参数转换为阻抗**
3. **应用直流电路的分析方法**
4. **将结果转换回时域**

#### 3.6.2 相量图分析法

**相量图的绘制原则**：
1. 选择参考相量（通常选择电流或电压）
2. 按照元件特性绘制各相量
3. 遵循KVL和KCL的相量形式

## 第4章：三相电路

### 4.1 三相电路的基本概念

#### 4.1.1 对称三相电源

**三相电压表达式**：
$$v_A = V_m\sin(\omega t)$$
$$v_B = V_m\sin(\omega t - 120°)$$
$$v_C = V_m\sin(\omega t + 120°)$$

**相量表示**：
$$\dot{V}_A = V\angle0°$$
$$\dot{V}_B = V\angle-120°$$
$$\dot{V}_C = V\angle120°$$

#### 4.1.2 对称三相电源的特性

**电压关系**：
$$\dot{V}_A + \dot{V}_B + \dot{V}_C = 0$$

**线电压与相电压关系**：

对于Y形连接：
- 线电压：$\dot{V}_{AB} = \sqrt{3}V\angle30°$
- 相电压：$\dot{V}_A = V\angle0°$

对于Δ形连接：
- 线电压等于相电压：$\dot{V}_{AB} = \dot{V}_A$

### 4.2 三相电路的连接方式

#### 4.2.1 Y-Y连接（三相四线制）

**线电压与相电压关系**：
$$\dot{V}_{AB} = \dot{V}_A - \dot{V}_B = \sqrt{3}V\angle30°$$
$$\dot{V}_{BC} = \dot{V}_B - \dot{V}_C = \sqrt{3}V\angle-90°$$
$$\dot{V}_{CA} = \dot{V}_C - \dot{V}_A = \sqrt{3}V\angle150°$$

**线电流与相电流关系**：
$$I_L = I_P$$

#### 4.2.2 Y-Δ连接

**线电压与相电压关系**：
$$\dot{V}_{AB} = \dot{V}_{AB'}$$

**线电流与相电流关系**：
$$\dot{I}_A = \sqrt{3}I_{AB}\angle-30°$$

#### 4.2.3 Δ-Y连接

**线电压与相电压关系**：
$$\dot{V}_{AB'} = \frac{1}{\sqrt{3}}\dot{V}_{AB}\angle-30°$$

**线电流与相电流关系**：
$$\dot{I}_A = \dot{I}_{A'}$$

#### 4.2.4 Δ-Δ连接

**线电压与相电压关系**：
$$\dot{V}_{AB} = \dot{V}_{AB'}$$

**线电流与相电流关系**：
$$\dot{I}_A = \sqrt{3}I_{AB}\angle-30°$$

<details>
<summary><strong>三相电路电压电流关系推导</strong></summary>

**Y-Y连接线电压推导**：

1. **相电压**：
   $$\dot{V}_A = V\angle0°$$
   $$\dot{V}_B = V\angle-120°$$

2. **线电压**：
   $$\dot{V}_{AB} = \dot{V}_A - \dot{V}_B = V\angle0° - V\angle-120°$$

3. **计算**：
   $$\dot{V}_{AB} = V(1\angle0° - 1\angle-120°) = V(1 + j0 - (-0.5 - j0.866))$$
   $$= V(1 + 0.5 + j0.866) = V(1.5 + j0.866)$$

4. **转换为极坐标**：
   $$|\dot{V}_{AB}| = \sqrt{1.5^2 + 0.866^2} = \sqrt{2.25 + 0.75} = \sqrt{3}V$$
   $$\angle\dot{V}_{AB} = \tan^{-1}\frac{0.866}{1.5} = 30°$$

因此：$\dot{V}_{AB} = \sqrt{3}V\angle30°$

**Δ-Y连接线电流推导**：

1. **相电流**：
   $$\dot{I}_{AB} = I_P\angle\phi$$
   $$\dot{I}_{BC} = I_P\angle(\phi - 120°)$$
   $$\dot{I}_{CA} = I_P\angle(\phi + 120°)$$

2. **线电流**（以A相为例）：
   $$\dot{I}_A = \dot{I}_{AB} - \dot{I}_{CA}$$

3. **计算**：
   $$\dot{I}_A = I_P\angle\phi - I_P\angle(\phi + 120°)$$
   $$= I_P[1\angle\phi - 1\angle(\phi + 120°)]$$

4. **展开**：
   $$= I_P[\cos\phi + j\sin\phi - \cos(\phi+120°) - j\sin(\phi+120°)]$$
   $$= I_P[\cos\phi + j\sin\phi + 0.5\cos\phi + 0.866\sin\phi - j0.5\sin\phi + 0.866\cos\phi]$$
   $$= I_P[1.5\cos\phi + j(1.866\sin\phi)]$$

5. **结果**：
   $$|\dot{I}_A| = \sqrt{3}I_P, \quad \angle\dot{I}_A = \phi - 30°$$

因此：$\dot{I}_A = \sqrt{3}I_P\angle(\phi - 30°)$
</details>

### 4.3 三相电路的功率

#### 4.3.1 三相功率的计算

**有功功率**：
$$P = \sqrt{3}V_LI_L\cos\phi$$

**无功功率**：
$$Q = \sqrt{3}V_LI_L\sin\phi$$

**视在功率**：
$$S = \sqrt{3}V_LI_L$$

其中：
- $V_L$：线电压
- $I_L$：线电流
- $\cos\phi$：功率因数

#### 4.3.2 三相功率的测量

**两功率表法**：
$$P = P_1 + P_2$$

其中：
- $P_1 = V_{AB}I_A\cos(\angle V_{AB} - \angle I_A)$
- $P_2 = V_{CB}I_C\cos(\angle V_{CB} - \angle I_C)$

### 4.4 不对称三相电路

#### 4.4.1 不对称三相电路的特点

当三相负载不对称时，各相电流不相等，中性线电流不为零：
$$\dot{I}_N = \dot{I}_A + \dot{I}_B + \dot{I}_C \neq 0$$

#### 4.4.2 中性点位移

在Y-Y连接的不对称三相电路中，中性点电位：
$$\dot{V}_N = \frac{\dot{V}_A Y_A + \dot{V}_B Y_B + \dot{V}_C Y_C}{Y_A + Y_B + Y_C + Y_N}$$

其中$Y_N$为中性线导纳。

#### 4.4.3 中性线的作用

- **有中性线**：各相负载电压等于电源相电压
- **无中性线**：负载中性点电位发生位移，各相负载电压不对称

## 第5章：电路的暂态分析

### 5.1 暂态过程的基本概念

#### 5.1.1 稳态与暂态

- **稳态**：电路中的电压和电流不随时间变化或按周期规律变化
- **暂态**：电路从一种稳定状态过渡到另一种稳定状态的过程

#### 5.1.2 换路定律

**换路定律内容**：
1. 换路瞬间，电感电流不能突变：$i_L(0_+) = i_L(0_-)$
2. 换路瞬间，电容电压不能突变：$v_C(0_+) = v_C(0_-)$

**数学表达式**：
$$i_L(0_+) = i_L(0_-)$$
$$v_C(0_+) = v_C(0_-)$$

<details>
<summary><strong>换路定律的物理原理</strong></summary>

**电感电流不能突变的原理**：

1. **电感电压**：$v_L = L\frac{di_L}{dt}$

2. **假设电流突变**：如果$i_L$在$t=0$时刻从$i_L(0_-)$突变到$i_L(0_+)$

3. **所需电压**：$\frac{di_L}{dt} = \frac{i_L(0_+) - i_L(0_-)}{\Delta t}$

4. **无穷大电压**：当$\Delta t \to 0$时，$\frac{di_L}{dt} \to \infty$，需要无穷大电压

5. **实际不可能**：实际电路中不存在无穷大电压，因此电流不能突变

**电容电压不能突变的原理**：

1. **电容电流**：$i_C = C\frac{dv_C}{dt}$

2. **假设电压突变**：如果$v_C$在$t=0$时刻从$v_C(0_-)$突变到$v_C(0_+)$

3. **所需电流**：$\frac{dv_C}{dt} = \frac{v_C(0_+) - v_C(0_-)}{\Delta t}$

4. **无穷大电流**：当$\Delta t \to 0$时，$\frac{dv_C}{dt} \to \infty$，需要无穷大电流

5. **实际不可能**：实际电路中不存在无穷大电流，因此电压不能突变
</details>

### 5.2 一阶电路的暂态分析

#### 5.2.1 RC电路的零输入响应

**电路方程**：
$$RC\frac{dv_C}{dt} + v_C = 0$$

**初始条件**：$v_C(0_+) = V_0$

**解**：
$$v_C(t) = V_0e^{-\frac{t}{RC}} = V_0e^{-\frac{t}{\tau}}$$

**时间常数**：$\tau = RC$

#### 5.2.2 RL电路的零输入响应

**电路方程**：
$$L\frac{di_L}{dt} + Ri_L = 0$$

**初始条件**：$i_L(0_+) = I_0$

**解**：
$$i_L(t) = I_0e^{-\frac{R}{L}t} = I_0e^{-\frac{t}{\tau}}$$

**时间常数**：$\tau = \frac{L}{R}$

#### 5.2.3 RC电路的零状态响应

**电路方程**：
$$RC\frac{dv_C}{dt} + v_C = V_s$$

**初始条件**：$v_C(0_+) = 0$

**解**：
$$v_C(t) = V_s(1 - e^{-\frac{t}{RC}}) = V_s(1 - e^{-\frac{t}{\tau}})$$

#### 5.2.4 RL电路的零状态响应

**电路方程**：
$$L\frac{di_L}{dt} + Ri_L = V_s$$

**初始条件**：$i_L(0_+) = 0$

**解**：
$$i_L(t) = \frac{V_s}{R}(1 - e^{-\frac{R}{L}t}) = \frac{V_s}{R}(1 - e^{-\frac{t}{\tau}})$$

<details>
<summary><strong>一阶电路微分方程求解</strong></summary>

**RC电路零输入响应求解**：

1. **微分方程**：
   $$RC\frac{dv_C}{dt} + v_C = 0$$

2. **标准形式**：
   $$\frac{dv_C}{dt} + \frac{1}{RC}v_C = 0$$

3. **特征方程**：
   $$s + \frac{1}{RC} = 0$$

4. **特征根**：
   $$s = -\frac{1}{RC}$$

5. **通解**：
   $$v_C(t) = Ae^{-\frac{t}{RC}}$$

6. **初始条件**：$v_C(0_+) = V_0$
   $$V_0 = Ae^0 = A$$

7. **特解**：
   $$v_C(t) = V_0e^{-\frac{t}{RC}}$$

**RC电路零状态响应求解**：

1. **微分方程**：
   $$RC\frac{dv_C}{dt} + v_C = V_s$$

2. **标准形式**：
   $$\frac{dv_C}{dt} + \frac{1}{RC}v_C = \frac{V_s}{RC}$$

3. **特征方程**：
   $$s + \frac{1}{RC} = 0$$

4. **特征根**：
   $$s = -\frac{1}{RC}$$

5. **齐次解**：
   $$v_{Ch}(t) = Ae^{-\frac{t}{RC}}$$

6. **特解**（常数）：$v_{Cp} = V_s$

7. **通解**：
   $$v_C(t) = V_s + Ae^{-\frac{t}{RC}}$$

8. **初始条件**：$v_C(0_+) = 0$
   $$0 = V_s + A \Rightarrow A = -V_s$$

9. **特解**：
   $$v_C(t) = V_s(1 - e^{-\frac{t}{RC}})$$
</details>

### 5.3 一阶电路的全响应

#### 5.3.1 全响应的组成

**全响应 = 零输入响应 + 零状态响应**

$$f(t) = f_{zi}(t) + f_{zs}(t)$$

#### 5.3.2 全响应的另一种分解

**全响应 = 稳态分量 + 暂态分量**

$$f(t) = f_{ss}(t) + f_{tr}(t)$$

其中：
- $f_{ss}(t)$：稳态分量（特解）
- $f_{tr}(t)$：暂态分量（齐次解）

### 5.4 二阶电路的暂态分析

#### 5.4.1 RLC串联电路

**微分方程**：
$$L\frac{d^2i}{dt^2} + R\frac{di}{dt} + \frac{1}{C}i = \frac{dv_s}{dt}$$

**特征方程**：
$$Ls^2 + Rs + \frac{1}{C} = 0$$

**特征根**：
$$s_{1,2} = -\frac{R}{2L} \pm \sqrt{\left(\frac{R}{2L}\right)^2 - \frac{1}{LC}}$$

#### 5.4.2 二阶电路的响应类型

根据阻尼系数$\alpha = \frac{R}{2L}$和固有频率$\omega_0 = \frac{1}{\sqrt{LC}}$的关系：

1. **过阻尼**（$\alpha > \omega_0$）：$s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2}$

2. **临界阻尼**（$\alpha = \omega_0$）：$s_{1,2} = -\alpha$

3. **欠阻尼**（$\alpha < \omega_0$）：$s_{1,2} = -\alpha \pm j\sqrt{\omega_0^2 - \alpha^2}$

<details>
<summary><strong>二阶电路特征方程推导</strong></summary>

**RLC串联电路微分方程推导**：

1. **KVL方程**：
   $$v_R + v_L + v_C = v_s$$

2. **元件关系**：
   - $v_R = Ri$
   - $v_L = L\frac{di}{dt}$
   - $i = C\frac{dv_C}{dt} \Rightarrow v_C = \frac{1}{C}\int i dt$

3. **代入KVL**：
   $$Ri + L\frac{di}{dt} + \frac{1}{C}\int i dt = v_s$$

4. **对t求导**：
   $$R\frac{di}{dt} + L\frac{d^2i}{dt^2} + \frac{1}{C}i = \frac{dv_s}{dt}$$

5. **标准形式**：
   $$L\frac{d^2i}{dt^2} + R\frac{di}{dt} + \frac{1}{C}i = \frac{dv_s}{dt}$$

6. **特征方程**（齐次方程）：
   $$Ls^2 + Rs + \frac{1}{C} = 0$$

**响应类型分析**：

1. **判别式**：
   $$\Delta = R^2 - 4\frac{L}{C}$$

2. **阻尼系数**：
   $$\alpha = \frac{R}{2L}, \quad \omega_0 = \frac{1}{\sqrt{LC}}$$

3. **关系**：
   $$\Delta = 4L^2(\alpha^2 - \omega_0^2)$$

4. **三种情况**：
   - $\alpha > \omega_0$：$\Delta > 0$，两个不等的负实根（过阻尼）
   - $\alpha = \omega_0$：$\Delta = 0$，两个相等的负实根（临界阻尼）
   - $\alpha < \omega_0$：$\Delta < 0$，一对共轭复根（欠阻尼）
</details>

### 5.5 冲激响应和阶跃响应

#### 5.5.1 冲激响应

**定义**：电路对单位冲激函数$\delta(t)$的零状态响应。

**冲激函数**：
$$\delta(t) = \begin{cases}
\infty, & t = 0 \\
0, & t \neq 0
\end{cases}$$

$$\int_{-\infty}^{\infty} \delta(t)dt = 1$$

#### 5.5.2 阶跃响应

**定义**：电路对单位阶跃函数$u(t)$的零状态响应。

**阶跃函数**：
$$u(t) = \begin{cases}
0, & t < 0 \\
1, & t \geq 0
\end{cases}$$

#### 5.5.3 冲激响应与阶跃响应的关系

$$h(t) = \frac{d}{dt}[s(t)]$$

$$s(t) = \int_{-\infty}^{t} h(\tau)d\tau$$

其中$h(t)$为冲激响应，$s(t)$为阶跃响应。

## 第6章：复频域分析

### 6.1 拉普拉斯变换

#### 6.1.1 拉普拉斯变换的定义

**正变换**：
$$F(s) = \mathcal{L}[f(t)] = \int_{0}^{\infty} f(t)e^{-st}dt$$

**逆变换**：
$$f(t) = \mathcal{L}^{-1}[F(s)] = \frac{1}{2\pi j}\int_{\sigma-j\infty}^{\sigma+j\infty} F(s)e^{st}ds$$

其中$s = \sigma + j\omega$为复频率。

#### 6.1.2 常用函数的拉普拉斯变换

| 原函数 $f(t)$ | 拉普拉斯变换 $F(s)$ |
|---------------|-------------------|
| $\delta(t)$ | $1$ |
| $u(t)$ | $\frac{1}{s}$ |
| $t$ | $\frac{1}{s^2}$ |
| $e^{-at}$ | $\frac{1}{s+a}$ |
| $\sin(\omega t)$ | $\frac{\omega}{s^2 + \omega^2}$ |
| $\cos(\omega t)$ | $\frac{s}{s^2 + \omega^2}$ |
| $e^{-at}\sin(\omega t)$ | $\frac{\omega}{(s+a)^2 + \omega^2}$ |
| $e^{-at}\cos(\omega t)$ | $\frac{s+a}{(s+a)^2 + \omega^2}$ |

<details>
<summary><strong>拉普拉斯变换基本性质证明</strong></summary>

**线性性质**：
$$\mathcal{L}[af(t) + bg(t)] = aF(s) + bG(s)$$

**证明**：
$$\mathcal{L}[af(t) + bg(t)] = \int_{0}^{\infty}[af(t) + bg(t)]e^{-st}dt$$
$$= a\int_{0}^{\infty}f(t)e^{-st}dt + b\int_{0}^{\infty}g(t)e^{-st}dt$$
$$= aF(s) + bG(s)$$

**微分性质**：
$$\mathcal{L}[\frac{df(t)}{dt}] = sF(s) - f(0_-)$$

**证明**：
$$\mathcal{L}[\frac{df(t)}{dt}] = \int_{0}^{\infty}\frac{df(t)}{dt}e^{-st}dt$$

使用分部积分：$\int u dv = uv - \int v du$

设$u = e^{-st}$，$dv = \frac{df(t)}{dt}dt$

则$du = -se^{-st}dt$，$v = f(t)$

$$\int_{0}^{\infty}\frac{df(t)}{dt}e^{-st}dt = [f(t)e^{-st}]_{0}^{\infty} + s\int_{0}^{\infty}f(t)e^{-st}dt$$
$$= 0 - f(0_-) + sF(s) = sF(s) - f(0_-)$$

**积分性质**：
$$\mathcal{L}[\int_{0}^{t}f(\tau)d\tau] = \frac{F(s)}{s}$$

**证明**：
设$g(t) = \int_{0}^{t}f(\tau)d\tau$

则$\frac{dg(t)}{dt} = f(t)$

使用微分性质：
$$\mathcal{L}[\frac{dg(t)}{dt}] = sG(s) - g(0_-) = sG(s)$$

但$g(0_-) = 0$，所以：
$$\mathcal{L}[f(t)] = sG(s) \Rightarrow G(s) = \frac{F(s)}{s}$$
</details>

### 6.2 拉普拉斯变换的基本性质

#### 6.2.1 线性性质

$$\mathcal{L}[af(t) + bg(t)] = aF(s) + bG(s)$$

#### 6.2.2 微分性质

$$\mathcal{L}[\frac{df(t)}{dt}] = sF(s) - f(0_-)$$

$$\mathcal{L}[\frac{d^2f(t)}{dt^2}] = s^2F(s) - sf(0_-) - f'(0_-)$$

#### 6.2.3 积分性质

$$\mathcal{L}[\int_{0}^{t}f(\tau)d\tau] = \frac{F(s)}{s}$$

#### 6.2.4 延迟性质

$$\mathcal{L}[f(t-a)u(t-a)] = e^{-as}F(s)$$

#### 6.2.5 频移性质

$$\mathcal{L}[e^{-at}f(t)] = F(s+a)$$

#### 6.2.6 卷积性质

$$\mathcal{L}[f_1(t) * f_2(t)] = F_1(s)F_2(s)$$

其中卷积定义为：
$$f_1(t) * f_2(t) = \int_{0}^{t} f_1(\tau)f_2(t-\tau)d\tau$$

### 6.3 电路元件的复频域模型

#### 6.3.1 电阻

**时域关系**：$v_R(t) = Ri_R(t)$

**复频域关系**：$V_R(s) = RI_R(s)$

**阻抗**：$Z_R(s) = R$

#### 6.3.2 电感

**时域关系**：$v_L(t) = L\frac{di_L(t)}{dt}$

**复频域关系**：$V_L(s) = sLI_L(s) - Li_L(0_-)$

**阻抗**：$Z_L(s) = sL$

**初始电流影响**：$V_L(s) = sL[I_L(s) + \frac{i_L(0_-)}{s}]$

#### 6.3.3 电容

**时域关系**：$i_C(t) = C\frac{dv_C(t)}{dt}$

**复频域关系**：$I_C(s) = sCV_C(s) - Cv_C(0_-)$

**阻抗**：$Z_C(s) = \frac{1}{sC}$

**初始电压影响**：$I_C(s) = sC[V_C(s) + \frac{v_C(0_-)}{s}]$

<details>
<summary><strong>电感和电容复频域模型推导</strong></summary>

**电感元件推导**：

1. **时域微分方程**：
   $$v_L(t) = L\frac{di_L(t)}{dt}$$

2. **取拉普拉斯变换**：
   $$\mathcal{L}[v_L(t)] = \mathcal{L}[L\frac{di_L(t)}{dt}]$$

3. **应用微分性质**：
   $$V_L(s) = L[sI_L(s) - i_L(0_-)]$$

4. **整理得**：
   $$V_L(s) = sLI_L(s) - Li_L(0_-)$$

5. **等效电路**：电压源$sLI_L(s)$串联初始电流源$-i_L(0_-)$

**电容元件推导**：

1. **时域微分方程**：
   $$i_C(t) = C\frac{dv_C(t)}{dt}$$

2. **取拉普拉斯变换**：
   $$\mathcal{L}[i_C(t)] = \mathcal{L}[C\frac{dv_C(t)}{dt}]$$

3. **应用微分性质**：
   $$I_C(s) = C[sV_C(s) - v_C(0_-)]$$

4. **整理得**：
   $$I_C(s) = sCV_C(s) - Cv_C(0_-)$$

5. **等效电路**：电流源$sCV_C(s)$并联初始电压源$-v_C(0_-)$
</details>

### 6.4 复频域分析方法

#### 6.4.1 复频域分析的步骤

1. **写出时域微分方程**
2. **对微分方程取拉普拉斯变换**
3. **考虑初始条件**
4. **解代数方程得到象函数**
5. **对结果取逆拉普拉斯变换**

#### 6.4.2 复频域阻抗

**阻抗定义**：$Z(s) = \frac{V(s)}{I(s)}$

**导纳定义**：$Y(s) = \frac{1}{Z(s)} = \frac{I(s)}{V(s)}$

#### 6.4.3 复频域的电路定律

**欧姆定律**：$V(s) = Z(s)I(s)$

**基尔霍夫定律**：
- KCL：$\sum I_k(s) = 0$
- KVL：$\sum V_k(s) = 0$

### 6.5 传递函数

#### 6.5.1 传递函数的定义

**传递函数**：$H(s) = \frac{Y(s)}{X(s)}$

其中$Y(s)$为输出量的拉普拉斯变换，$X(s)$为输入量的拉普拉斯变换。

#### 6.5.2 传递函数的极点零点

**极点**：使$H(s) = \infty$的$s$值，即分母为零的根。

**零点**：使$H(s) = 0$的$s$值，即分子为零的根。

#### 6.5.3 频率响应

**频率响应**：$H(j\omega) = H(s)|_{s=j\omega}$

**幅频特性**：$|H(j\omega)|$

**相频特性**：$\angle H(j\omega)$

## 第7章：傅里叶变换与卷积

### 7.1 周期信号的傅里叶级数

#### 7.1.1 三角形式的傅里叶级数

**表达式**：
$$f(t) = a_0 + \sum_{n=1}^{\infty}[a_n\cos(n\omega_0 t) + b_n\sin(n\omega_0 t)]$$

**系数计算**：
$$a_0 = \frac{1}{T}\int_{T/2}^{-T/2} f(t)dt$$

$$a_n = \frac{2}{T}\int_{T/2}^{-T/2} f(t)\cos(n\omega_0 t)dt$$

$$b_n = \frac{2}{T}\int_{T/2}^{-T/2} f(t)\sin(n\omega_0 t)dt$$

#### 7.1.2 指数形式的傅里叶级数

**表达式**：
$$f(t) = \sum_{n=-\infty}^{\infty} F_n e^{jn\omega_0 t}$$

**系数计算**：
$$F_n = \frac{1}{T}\int_{T/2}^{-T/2} f(t)e^{-jn\omega_0 t}dt$$

#### 7.1.3 傅里叶级数的性质

**奇偶性**：
- 偶函数：$b_n = 0$
- 奇函数：$a_n = 0$（$n \geq 1$）

**线性性质**：$\mathcal{F}[af(t) + bg(t)] = a\mathcal{F}[f(t)] + b\mathcal{F}[g(t)]$

<details>
<summary><strong>傅里叶级数系数推导</strong></summary>

**三角形式系数推导**：

1. **正交性**：
   $$\int_{T/2}^{-T/2} \cos(m\omega_0 t)\cos(n\omega_0 t)dt = \begin{cases}
   0, & m \neq n \\
   T/2, & m = n \neq 0 \\
   T, & m = n = 0
   \end{cases}$$

   $$\int_{T/2}^{-T/2} \sin(m\omega_0 t)\sin(n\omega_0 t)dt = \begin{cases}
   0, & m \neq n \\
   T/2, & m = n \neq 0
   \end{cases}$$

   $$\int_{T/2}^{-T/2} \cos(m\omega_0 t)\sin(n\omega_0 t)dt = 0$$

2. **求$a_0$**：
   $$\int_{T/2}^{-T/2} f(t)dt = \int_{T/2}^{-T/2} a_0 dt = a_0 T$$
   $$a_0 = \frac{1}{T}\int_{T/2}^{-T/2} f(t)dt$$

3. **求$a_n$**：
   $$\int_{T/2}^{-T/2} f(t)\cos(n\omega_0 t)dt = \int_{T/2}^{-T/2} a_n\cos^2(n\omega_0 t)dt = a_n \frac{T}{2}$$
   $$a_n = \frac{2}{T}\int_{T/2}^{-T/2} f(t)\cos(n\omega_0 t)dt$$

4. **求$b_n$**：
   $$\int_{T/2}^{-T/2} f(t)\sin(n\omega_0 t)dt = \int_{T/2}^{-T/2} b_n\sin^2(n\omega_0 t)dt = b_n \frac{T}{2}$$
   $$b_n = \frac{2}{T}\int_{T/2}^{-T/2} f(t)\sin(n\omega_0 t)dt$$

**指数形式推导**：

1. **欧拉公式**：
   $$\cos(n\omega_0 t) = \frac{e^{jn\omega_0 t} + e^{-jn\omega_0 t}}{2}$$
   $$\sin(n\omega_0 t) = \frac{e^{jn\omega_0 t} - e^{-jn\omega_0 t}}{2j}$$

2. **代入三角形式**：
   $$f(t) = a_0 + \sum_{n=1}^{\infty}[a_n\frac{e^{jn\omega_0 t} + e^{-jn\omega_0 t}}{2} + b_n\frac{e^{jn\omega_0 t} - e^{-jn\omega_0 t}}{2j}]$$

3. **整理**：
   $$f(t) = \sum_{n=-\infty}^{\infty} F_n e^{jn\omega_0 t}$$

4. **系数**：
   $$F_n = \begin{cases}
   a_0, & n = 0 \\
   \frac{a_n - jb_n}{2}, & n > 0 \\
   \frac{a_{-n} + jb_{-n}}{2}, & n < 0
   \end{cases}$$
</details>

### 7.2 非周期信号的傅里叶变换

#### 7.2.1 傅里叶变换的定义

**正变换**：
$$F(\omega) = \mathcal{F}[f(t)] = \int_{-\infty}^{\infty} f(t)e^{-j\omega t}dt$$

**逆变换**：
$$f(t) = \mathcal{F}^{-1}[F(\omega)] = \frac{1}{2\pi}\int_{-\infty}^{\infty} F(\omega)e^{j\omega t}d\omega$$

#### 7.2.2 常用函数的傅里叶变换

| 原函数 $f(t)$ | 傅里叶变换 $F(\omega)$ |
|---------------|----------------------|
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| $e^{-at}u(t)$ | $\frac{1}{a + j\omega}$ |
| $\rect(\frac{t}{\tau})$ | $\tau\sinc(\frac{\omega\tau}{2})$ |
| $\sin(\omega_0 t)$ | $j\pi[\delta(\omega + \omega_0) - \delta(\omega - \omega_0)]$ |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega + \omega_0) + \delta(\omega - \omega_0)]$ |

### 7.3 傅里叶变换的性质

#### 7.3.1 线性性质

$$\mathcal{F}[af(t) + bg(t)] = aF(\omega) + bG(\omega)$$

#### 7.3.2 时移性质

$$\mathcal{F}[f(t - t_0)] = F(\omega)e^{-j\omega t_0}$$

#### 7.3.3 频移性质

$$\mathcal{F}[f(t)e^{j\omega_0 t}] = F(\omega - \omega_0)$$

#### 7.3.4 时间缩放性质

$$\mathcal{F}[f(at)] = \frac{1}{|a|}F(\frac{\omega}{a})$$

#### 7.3.5 微分性质

$$\mathcal{F}[\frac{df(t)}{dt}] = j\omega F(\omega)$$

$$\mathcal{F}[\frac{d^nf(t)}{dt^n}] = (j\omega)^n F(\omega)$$

#### 7.3.6 积分性质

$$\mathcal{F}[\int_{-\infty}^{t} f(\tau)d\tau] = \frac{F(\omega)}{j\omega} + \pi F(0)\delta(\omega)$$

#### 7.3.7 帕塞瓦尔定理

$$\int_{-\infty}^{\infty} |f(t)|^2 dt = \frac{1}{2\pi}\int_{-\infty}^{\infty} |F(\omega)|^2 d\omega$$

<details>
<summary><strong>傅里叶变换重要性质证明</strong></summary>

**时移性质证明**：

1. **定义**：
   $$\mathcal{F}[f(t - t_0)] = \int_{-\infty}^{\infty} f(t - t_0)e^{-j\omega t}dt$$

2. **变量代换**：令$\tau = t - t_0$，则$t = \tau + t_0$，$dt = d\tau$

3. **代入**：
   $$\int_{-\infty}^{\infty} f(\tau)e^{-j\omega(\tau + t_0)}d\tau = e^{-j\omega t_0}\int_{-\infty}^{\infty} f(\tau)e^{-j\omega\tau}d\tau$$

4. **结果**：
   $$\mathcal{F}[f(t - t_0)] = e^{-j\omega t_0}F(\omega)$$

**微分性质证明**：

1. **定义**：
   $$\mathcal{F}[\frac{df(t)}{dt}] = \int_{-\infty}^{\infty} \frac{df(t)}{dt}e^{-j\omega t}dt$$

2. **分部积分**：$\int u dv = uv - \int v du$

   设$u = e^{-j\omega t}$，$dv = \frac{df(t)}{dt}dt$

   则$du = -j\omega e^{-j\omega t}dt$，$v = f(t)$

3. **积分**：
   $$[\int_{-\infty}^{\infty} \frac{df(t)}{dt}e^{-j\omega t}dt] = [f(t)e^{-j\omega t}]_{-\infty}^{\infty} + j\omega\int_{-\infty}^{\infty} f(t)e^{-j\omega t}dt$$

4. **边界条件**：假设$f(t)$在$t \to \pm\infty$时趋于零

5. **结果**：
   $$\mathcal{F}[\frac{df(t)}{dt}] = j\omega F(\omega)$$

**帕塞瓦尔定理证明**：

1. **从定义开始**：
   $$\int_{-\infty}^{\infty} |f(t)|^2 dt = \int_{-\infty}^{\infty} f(t)f^*(t)dt$$

2. **傅里叶逆变换**：
   $$f(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} F(\omega)e^{j\omega t}d\omega$$

3. **共轭**：
   $$f^*(t) = \frac{1}{2\pi}\int_{-\infty}^{\infty} F^*(\omega)e^{-j\omega t}d\omega$$

4. **代入**：
   $$\int_{-\infty}^{\infty} |f(t)|^2 dt = \int_{-\infty}^{\infty} f(t)[\frac{1}{2\pi}\int_{-\infty}^{\infty} F^*(\omega)e^{-j\omega t}d\omega]dt$$

5. **交换积分次序**：
   $$= \frac{1}{2\pi}\int_{-\infty}^{\infty} F^*(\omega)[\int_{-\infty}^{\infty} f(t)e^{-j\omega t}dt]d\omega$$

6. **内层积分**：
   $$= \frac{1}{2\pi}\int_{-\infty}^{\infty} F^*(\omega)F(\omega)d\omega$$

7. **结果**：
   $$= \frac{1}{2\pi}\int_{-\infty}^{\infty} |F(\omega)|^2 d\omega$$
</details>

### 7.4 卷积

#### 7.4.1 卷积的定义

**连续时间卷积**：
$$f_1(t) * f_2(t) = \int_{-\infty}^{\infty} f_1(\tau)f_2(t - \tau)d\tau$$

**离散时间卷积**：
$$f_1[n] * f_2[n] = \sum_{k=-\infty}^{\infty} f_1[k]f_2[n - k]$$

#### 7.4.2 卷积的性质

**交换律**：
$$f_1(t) * f_2(t) = f_2(t) * f_1(t)$$

**结合律**：
$$[f_1(t) * f_2(t)] * f_3(t) = f_1(t) * [f_2(t) * f_3(t)]$$

**分配律**：
$$f_1(t) * [f_2(t) + f_3(t)] = f_1(t) * f_2(t) + f_1(t) * f_3(t)$$

#### 7.4.3 卷积定理

**傅里叶变换卷积定理**：
$$\mathcal{F}[f_1(t) * f_2(t)] = F_1(\omega)F_2(\omega)$$

$$\mathcal{F}[f_1(t)f_2(t)] = \frac{1}{2\pi}F_1(\omega) * F_2(\omega)$$

**拉普拉斯变换卷积定理**：
$$\mathcal{L}[f_1(t) * f_2(t)] = F_1(s)F_2(s)$$

<details>
<summary><strong>卷积定理证明</strong></summary>

**傅里叶变换卷积定理证明**：

1. **卷积定义**：
   $$f_1(t) * f_2(t) = \int_{-\infty}^{\infty} f_1(\tau)f_2(t - \tau)d\tau$$

2. **取傅里叶变换**：
   $$\mathcal{F}[f_1(t) * f_2(t)] = \int_{-\infty}^{\infty}[\int_{-\infty}^{\infty} f_1(\tau)f_2(t - \tau)d\tau]e^{-j\omega t}dt$$

3. **交换积分次序**：
   $$= \int_{-\infty}^{\infty} f_1(\tau)[\int_{-\infty}^{\infty} f_2(t - \tau)e^{-j\omega t}dt]d\tau$$

4. **内层积分变量代换**：令$u = t - \tau$，则$t = u + \tau$，$dt = du$

   $$= \int_{-\infty}^{\infty} f_1(\tau)[\int_{-\infty}^{\infty} f_2(u)e^{-j\omega(u + \tau)}du]d\tau$$

5. **分离**：
   $$= \int_{-\infty}^{\infty} f_1(\tau)e^{-j\omega\tau}[\int_{-\infty}^{\infty} f_2(u)e^{-j\omega u}du]d\tau$$

6. **内层积分**：
   $$= \int_{-\infty}^{\infty} f_2(u)e^{-j\omega u}du = F_2(\omega)$$

7. **外层积分**：
   $$= F_2(\omega)\int_{-\infty}^{\infty} f_1(\tau)e^{-j\omega\tau}d\tau = F_2(\omega)F_1(\omega)$$

8. **结果**：
   $$\mathcal{F}[f_1(t) * f_2(t)] = F_1(\omega)F_2(\omega)$$

**拉普拉斯变换卷积定理证明**：

类似傅里叶变换的证明过程，只是积分下限从0开始：

1. **定义**：
   $$f_1(t) * f_2(t) = \int_{0}^{\infty} f_1(\tau)f_2(t - \tau)u(t - \tau)d\tau$$

2. **拉普拉斯变换**：
   $$\mathcal{L}[f_1(t) * f_2(t)] = \int_{0}^{\infty}[\int_{0}^{\infty} f_1(\tau)f_2(t - \tau)u(t - \tau)d\tau]e^{-st}dt$$

3. **交换积分次序并计算**：
   $$= F_1(s)F_2(s)$$
</details>

### 7.5 采样定理

#### 7.5.1 采样定理的内容

**奈奎斯特采样定理**：如果一个连续时间信号$x(t)$的傅里叶变换$X(\omega)$在$|\omega| > \omega_m$时为零，那么该信号可以由采样频率$f_s > 2f_m$的采样点完全恢复。

其中：
- $f_m$：信号的最高频率分量
- $f_s$：采样频率
- $2f_m$：奈奎斯特频率

#### 7.5.2 采样信号的频谱

**理想采样**：
$$x_s(t) = x(t)\sum_{n=-\infty}^{\infty} \delta(t - nT_s)$$

其中$T_s = \frac{1}{f_s}$为采样周期。

**采样信号的频谱**：
$$X_s(\omega) = \frac{1}{T_s}\sum_{n=-\infty}^{\infty} X(\omega - n\omega_s)$$

其中$\omega_s = \frac{2\pi}{T_s} = 2\pi f_s$为采样角频率。

## 第8章：电路的图论分析

### 8.1 电路的图论基础

#### 8.1.1 图的基本概念

**图G的定义**：图G由顶点集合V和边集合E组成，记为$G = (V, E)$。

**电路图的构成**：
- **节点**：对应电路中的节点
- **支路**：对应电路中的元件
- **边**：连接两个节点的线段

#### 8.1.2 图的分类

| 图的类型 | 定义 | 特点 |
|----------|------|------|
| 有向图 | 边具有方向 | 反映电流方向 |
| 无向图 | 边无方向 | 简化分析 |
| 连通图 | 任意两点间有路径 | 实际电路都是连通的 |
| 非连通图 | 存在孤立节点 | 理论分析用 |

#### 8.1.3 图的基本术语

- **路径**：顶点序列$v_0, v_1, ..., v_k$，相邻顶点间有边连接
- **回路**：起点和终点相同的路径
- **树**：包含所有节点但不包含回路的连通子图
- **余树**：树中不包含的边组成的子图
- **基本回路**：余树中每条边与树中路径形成的回路

<details>
<summary><strong>图的矩阵表示方法</strong></summary>

**邻接矩阵**：

对于有$n$个节点的图，邻接矩阵$A$为$n \times n$矩阵：
$$A_{ij} = \begin{cases}
1, & \text{如果节点}i\text{和}j\text{之间有边} \\
0, & \text{否则}
\end{cases}$$

**关联矩阵**：

对于有$n$个节点和$b$条支路的图，关联矩阵$B$为$n \times b$矩阵：
$$B_{ij} = \begin{cases}
1, & \text{如果支路}j\text{离开节点}i \\
-1, & \text{如果支路}j\text{进入节点}i \\
0, & \text{如果支路}j\text{不与节点}i\text{关联}
\end{cases}$$

**回路矩阵**：

对于有$b$条支路和$l$个独立回路的图，回路矩阵$C$为$l \times b$矩阵：
$$C_{ij} = \begin{cases}
1, & \text{如果支路}j\text{在回路}i\text{中且方向一致} \\
-1, & \text{如果支路}j\text{在回路}i\text{中且方向相反} \\
0, & \text{如果支路}j\text{不在回路}i\text{中}
\end{cases}$$

**割集矩阵**：

对于有$b$条支路和$c$个独立割集的图，割集矩阵$Q$为$c \times b$矩阵：
$$Q_{ij} = \begin{cases}
1, & \text{如果支路}j\text{在割集}i\text{中且方向一致} \\
-1, & \text, & \text{如果支路}j\text{在割集}i\text{中且方向相反} \\
0, & \text{如果支路}j\text{不在割集}i\text{中}
\end{cases}$$

### 8.2 电路的拓扑矩阵

#### 8.2.1 节点关联矩阵

**定义**：描述节点与支路关联关系的矩阵。

**性质**：
- 矩阵的秩为$n-1$（$n$为节点数）
- 各行元素之和为零

#### 8.2.2 基本回路矩阵

**定义**：描述回路与支路关系的矩阵。

**性质**：
- 矩阵的秩为$b-n+1$（$b$为支路数，$n$为节点数）
- 与节点关联矩阵正交：$CB^T = 0$

#### 8.2.3 基本割集矩阵

**定义**：描述割集与支路关系的矩阵。

**性质**：
- 矩阵的秩为$n-1$
- 与回路矩阵正交：$QC^T = 0$

### 8.3 拓扑分析的基本定理

#### 8.3.1 基尔霍夫定律的矩阵形式

**KCL的矩阵形式**：
$$\mathbf{BI_b = 0}$$

其中$\mathbf{B}$为节点关联矩阵，$\mathbf{I_b}$为支路电流向量。

**KVL的矩阵形式**：
$$\mathbf{CV_b = 0}$$

其中$\mathbf{C}$为回路矩阵，$\mathbf{V_b}$为支路电压向量。

#### 8.3.2 拓扑约束关系

**支路约束**：
$$\mathbf{V_b = ZI_b}$$

**拓扑约束**：
$$\mathbf{CV_b = 0}$$
$$\mathbf{BI_b = 0}$$

## 第9章：电路的矩阵形式

### 9.1 电路方程的矩阵表示

#### 9.1.1 支路方程的矩阵形式

**一般支路方程**：
$$\mathbf{V_b = ZI_b + V_s - ZI_s}$$

其中：
- $\mathbf{V_b}$：支路电压向量
- $\mathbf{I_b}$：支路电流向量
- $\mathbf{Z}$：支路阻抗矩阵
- $\mathbf{V_s}$：电压源向量
- $\mathbf{I_s}$：电流源向量

#### 9.1.2 节点电压方程的矩阵形式

**一般形式**：
$$\mathbf{Y_nV_n = I_s}$$

其中：
- $\mathbf{Y_n}$：节点导纳矩阵
- $\mathbf{V_n}$：节点电压向量
- $\mathbf{I_s}$：节点电流源向量

#### 9.1.3 网孔电流方程的矩阵形式

**一般形式**：
$$\mathbf{Z_mI_m = V_s}$$

其中：
- $\mathbf{Z_m}$：网孔阻抗矩阵
- $\mathbf{I_m}$：网孔电流向量
- $\mathbf{V_s}$：网孔电压源向量

### 9.2 节点电压法的矩阵分析

#### 9.2.1 节点导纳矩阵的构成

**自导纳**：$Y_{ii} = \sum_{j} Y_{ij}$（连接节点$i$的所有支路导纳之和）

**互导纳**：$Y_{ij} = -Y_{ji}$（连接节点$i$和$j$的支路导纳之和，取负号）

#### 9.2.2 节点电流源的构成

**电流源**：$I_{si} = \sum I_{s}$（流入节点$i$的电流源代数和）

**电压源的处理**：
- 电压源与电阻串联：等效为电流源
- 独立电压源：需要添加辅助方程

<details>
<summary><strong>节点电压法矩阵推导</strong></summary>

**推导过程**：

1. **支路方程**：
   $$I_k = Y_k(V_k - V_s_k)$$

2. **KCL方程**：
   $$\sum_{k} I_k = 0$$

3. **代入支路方程**：
   $$\sum_{k} Y_k(V_k - V_s_k) = 0$$

4. **节点电压表示**：
   对于连接节点$i$的支路$k$：
   $$V_k = V_i - V_j$$

5. **整理**：
   $$V_i\sum_{k} Y_k - \sum_{k} Y_kV_j = \sum_{k} Y_kV_s_k$$

6. **矩阵形式**：
   $$\mathbf{Y_nV_n = I_s}$$

其中：
- $\mathbf{Y_n}$：节点导纳矩阵
- $\mathbf{V_n}$：节点电压向量
- $\mathbf{I_s}$：等效电流源向量
</details>

### 9.3 状态变量分析

#### 9.3.1 状态方程的标准形式

**状态方程**：
$$\dot{\mathbf{x}} = \mathbf{Ax} + \mathbf{Bu}$$

**输出方程**：
$$\mathbf{y} = \mathbf{Cx} + \mathbf{Du}$$

其中：
- $\mathbf{x}$：状态向量
- $\mathbf{u}$：输入向量
- $\mathbf{y}$：输出向量
- $\mathbf{A, B, C, D}$：系统矩阵

#### 9.3.2 状态变量的选择

**状态变量**：
- 电感电流：$i_L$
- 电容电压：$v_C$

**状态方程的建立**：
1. 选择状态变量
2. 列写KCL和KVL方程
3. 消去非状态变量
4. 整理为标准形式

#### 9.3.3 状态方程的求解

**齐次方程**：
$$\dot{\mathbf{x}} = \mathbf{Ax}$$

**解**：$\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0)$

**非齐次方程**：
$$\dot{\mathbf{x}} = \mathbf{Ax} + \mathbf{Bu}$$

**解**：$\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0) + \int_{0}^{t} e^{\mathbf{A}(t-\tau)}\mathbf{Bu}(\tau)d\tau$

### 9.4 稀疏矩阵技术

#### 9.4.1 稀疏矩阵的定义

**稀疏矩阵**：零元素个数远多于非零元素个数的矩阵。

**稀疏度**：$\text{稀疏度} = \frac{\text{零元素个数}}{\text{总元素个数}}$

#### 9.4.2 稀疏矩阵的存储格式

**压缩行存储（CRS）**：
- `val[]`：非零元素值
- `col_ind[]`：列索引
- `row_ptr[]`：行指针

**坐标格式（COO）**：
- `val[]`：非零元素值
- `row[]`：行索引
- `col[]`：列索引

#### 9.4.3 稀疏矩阵的运算

**稀疏矩阵-向量乘法**：
$$y = Ax$$

其中$A$为稀疏矩阵，$x$为向量。

**复杂度**：$O(\text{nnz})$，其中nnz为非零元素个数。

## 第10章：传输线理论

### 10.1 传输线的基本概念

#### 10.1.1 分布参数电路

**与集总参数电路的区别**：

| 特征 | 集总参数电路 | 分布参数电路 |
|------|-------------|-------------|
| 尺寸 | $l \ll \lambda$ | $l \geq \lambda/10$ |
| 参数 | 集中在元件中 | 沿线分布 |
| 方程 | 常微分方程 | 偏微分方程 |
| 应用 | 低频电路 | 高频/微波电路 |

#### 10.1.2 传输线的分布参数

**单位长度参数**：
- $R'$：单位长度电阻（Ω/m）
- $L'$：单位长度电感（H/m）
- $G'$：单位长度电导（S/m）
- $C'$：单位长度电容（F/m）

#### 10.1.3 传输线的分类

**按传输模式**：
- TEM波传输线：双线、同轴线、微带线
- TE/TM波传输线：波导、介质波导

**按损耗特性**：
- 无损耗线：$R' = G' = 0$
- 有损耗线：$R' \neq 0$，$G' \neq 0$

### 10.2 传输线的电报方程

#### 10.2.1 传输线方程的建立

**微元段等效电路**：

```
Rs----L'----Rs----L'----...
       |         |
      C'        C'
       |         |
      G'        G'
       |         |
      Vs--------Vs--------...
```

**基本方程**：
$$\frac{\partial v(x,t)}{\partial x} = -L'\frac{\partial i(x,t)}{\partial t} - R'i(x,t)$$

$$\frac{\partial i(x,t)}{\partial x} = -C'\frac{\partial v(x,t)}{\partial t} - G'v(x,t)$$

#### 10.2.2 正弦稳态分析

**相量形式**：
$$\frac{dV(x)}{dx} = -(R' + j\omega L')I(x) = -ZI(x)$$

$$\frac{dI(x)}{dx} = -(G' + j\omega C')V(x) = -YV(x)$$

其中：
- $Z = R' + j\omega L'$：单位长度阻抗
- $Y = G' + j\omega C'$：单位长度导纳

#### 10.2.3 传输线方程的解

**通解形式**：
$$V(x) = V^+e^{-\gamma x} + V^-e^{\gamma x}$$

$$I(x) = \frac{V^+}{Z_0}e^{-\gamma x} - \frac{V^-}{Z_0}e^{\gamma x}$$

其中：
- $\gamma = \sqrt{ZY} = \alpha + j\beta$：传播常数
- $Z_0 = \sqrt{\frac{Z}{Y}}$：特性阻抗

<details>
<summary><strong>传输线方程求解过程</strong></summary>

**微分方程的建立**：

1. **微元段分析**：
   对于长度为$dx$的传输线段

2. **KVL方程**：
   $$V(x) - [V(x) + \frac{\partial V}{\partial x}dx] = (R' + j\omega L')I(x)dx$$

3. **简化**：
   $$-\frac{\partial V}{\partial x}dx = (R' + j\omega L')I(x)dx$$

4. **整理**：
   $$\frac{\partial V}{\partial x} = -(R' + j\omega L')I(x)$$

5. **KCL方程**：
   $$I(x) - [I(x) + \frac{\partial I}{\partial x}dx] = (G' + j\omega C')V(x)dx$$

6. **整理**：
   $$-\frac{\partial I}{\partial x}dx = (G' + j\omega C')V(x)dx$$

7. **结果**：
   $$\frac{\partial I}{\partial x} = -(G' + j\omega C')V(x)$$

**方程求解**：

1. **对第一个方程求导**：
   $$\frac{d^2V}{dx^2} = -(R' + j\omega L')\frac{dI}{dx}$$

2. **代入第二个方程**：
   $$\frac{d^2V}{dx^2} = (R' + j\omega L')(G' + j\omega C')V(x)$$

3. **定义传播常数**：
   $$\gamma^2 = (R' + j\omega L')(G' + j\omega C')$$

4. **微分方程**：
   $$\frac{d^2V}{dx^2} - \gamma^2V = 0$$

5. **通解**：
   $$V(x) = V^+e^{-\gamma x} + V^-e^{\gamma x}$$

6. **电流解**：
   $$I(x) = \frac{V^+}{Z_0}e^{-\gamma x} - \frac{V^-}{Z_0}e^{\gamma x}$$

其中特性阻抗：$Z_0 = \sqrt{\frac{R' + j\omega L'}{G' + j\omega C'}}$
</details>

### 10.3 传输线的特性参数

#### 10.3.1 特性阻抗

**定义**：$Z_0 = \sqrt{\frac{Z}{Y}} = \sqrt{\frac{R' + j\omega L'}{G' + j\omega C'}}$

**无损耗线**：$Z_0 = \sqrt{\frac{L'}{C'}}$（纯实数）

**有损耗线**：$Z_0 = \sqrt{\frac{R' + j\omega L'}{G' + j\omega C'}}$（复数）

#### 10.3.2 传播常数

**定义**：$\gamma = \alpha + j\beta = \sqrt{ZY}$

其中：
- $\alpha$：衰减常数（Np/m）
- $\beta$：相位常数（rad/m）

**无损耗线**：
- $\alpha = 0$
- $\beta = \omega\sqrt{L'C'}$

**有损耗线**：
- $\alpha = \sqrt{\frac{1}{2}[\sqrt{(R'^2 + \omega^2L'^2)(G'^2 + \omega^2C'^2)} - (R'G' - \omega^2L'C')]}$
- $\beta = \sqrt{\frac{1}{2}[\sqrt{(R'^2 + \omega^2L'^2)(G'^2 + \omega^2C'^2)} + (R'G' - \omega^2L'C')]}$
#### 10.3.3 相速度和群速度

**相速度**：$v_p = \frac{\omega}{\beta}$

**群速度**：$v_g = \frac{d\omega}{d\beta}$

对于无损耗线：$v_p = v_g = \frac{1}{\sqrt{L'C'}}$

### 10.4 传输线的边界条件

#### 10.4.1 负载阻抗

**负载电压**：$V(L) = V_L$

**负载电流**：$I(L) = \frac{V_L}{Z_L}$

#### 10.4.2 反射系数

**定义**：$\Gamma = \frac{V^-}{V^+} = \frac{Z_L - Z_0}{Z_L + Z_0}$

**负载端反射系数**：$\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0}$

**输入端反射系数**：$\Gamma_{in} = \Gamma_L e^{-2\gamma L}$

#### 10.4.3 输入阻抗

**一般表达式**：
$$Z_{in} = Z_0\frac{Z_L + Z_0\tanh(\gamma L)}{Z_0 + Z_L\tanh(\gamma L)}$$

**无损耗线**：
$$Z_{in} = Z_0\frac{Z_L + jZ_0\tan(\beta L)}{Z_0 + jZ_L\tan(\beta L)}$$

### 10.5 传输线的匹配

#### 10.5.1 阻抗匹配

**完全匹配**：$Z_L = Z_0$，此时$\Gamma_L = 0$

**匹配条件**：
- 负载阻抗等于特性阻抗
- 无反射波
- 传输效率最高

#### 10.5.2 驻波比

**定义**：$SWR = \frac{V_{max}}{V_{min}} = \frac{1 + |\Gamma|}{1 - |\Gamma|}$

**驻波比与反射系数的关系**：
$$|\Gamma| = \frac{SWR - 1}{SWR + 1}$$

$$SWR = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

#### 10.5.3 传输功率

**入射功率**：$P^+ = \frac{|V^+|^2}{2Z_0}$

**反射功率**：$P^- = |\Gamma|^2P^+$

**负载功率**：$P_L = P^+ - P^- = P^+(1 - |\Gamma|^2)$

**传输效率**：$\eta = \frac{P_L}{P^+} = 1 - |\Gamma|^2$

## 第11章：非线性电路分析

### 11.1 非线性元件特性

#### 11.1.1 非线性电阻

**一般特性**：$v = f(i)$ 或 $i = g(v)$

**静态电阻**：$R_s = \frac{v}{i}$

**动态电阻**：$r_d = \frac{dv}{di}$

#### 11.1.2 非线性电感

**一般特性**：$\psi = f(i)$ 或 $i = g(\psi)$

**静态电感**：$L_s = \frac{\psi}{i}$

**动态电感**：$l_d = \frac{d\psi}{di}$

#### 11.1.3 非线性电容

**一般特性**：$q = f(v)$ 或 $v = g(q)$

**静态电容**：$C_s = \frac{q}{v}$

**动态电容**：$c_d = \frac{dq}{dv}$

### 11.2 非线性电路的分析方法

#### 11.2.1 图解分析法

**负载线法**：

1. **非线性元件特性曲线**：$i = g(v)$
2. **负载线方程**：$v = V_s - Ri$
3. **交点即为工作点**：$(V_Q, I_Q)$

#### 11.2.2 小信号分析法

**工作点确定**：
1. 直流分析确定工作点$(V_Q, I_Q)$
2. 计算工作点处的动态参数

**小信号等效电路**：
- 非线性电阻：$r_d = \frac{dv}{di}|_{Q}$
- 非线性电感：$l_d = \frac{d\psi}{di}|_{Q}$
- 非线性电容：$c_d = \frac{dq}{dv}|_{Q}$

**小信号分析步骤**：
1. 直流偏置分析确定工作点
2. 计算各元件的动态参数
3. 建立小信号等效电路
4. 求解小信号响应

<details>
<summary><strong>小信号分析法推导</strong></summary>

**基本原理**：

1. **非线性元件特性**：
   $$i = f(v) = f(V_Q + v_s)$$

2. **泰勒级数展开**：
   $$i = f(V_Q) + \frac{df}{dv}|_{V_Q} \cdot v_s + \frac{1}{2}\frac{d^2f}{dv^2}|_{V_Q} \cdot v_s^2 + ...$$

3. **小信号假设**：$v_s \ll V_Q$，高阶项可忽略

4. **线性化**：
   $$i \approx f(V_Q) + \frac{df}{dv}|_{V_Q} \cdot v_s$$

5. **分离直流和交流**：
   - 直流分量：$I_Q = f(V_Q)$
   - 交流分量：$i_s = \frac{df}{dv}|_{V_Q} \cdot v_s$

6. **动态电阻**：
   $$r_d = \frac{dv}{di}|_{Q} = \frac{1}{\frac{df}{dv}|_{V_Q}}$$

**小信号等效电路**：

1. **非线性电阻**：用动态电阻$r_d$代替
2. **非线性电感**：用动态电感$l_d$代替  
3. **非线性电容**：用动态电容$c_d$代替

4. **电路方程**：
   - 直流：$I_Q = f(V_Q)$
   - 交流：$i_s = \frac{v_s}{r_d}$
</details>

### 11.3 非线性电路的稳定性

#### 11.3.1 平衡点的稳定性

**李雅普诺夫稳定性判据**：

对于平衡点$x_0$，如果存在正定函数$V(x)$使得：
- $V(x_0) = 0$
- $V(x) > 0$（当$x \neq x_0$时）
- $\frac{dV}{dt} \leq 0$

则平衡点$x_0$是稳定的。

#### 11.3.2 增量线性化稳定性

**雅可比矩阵**：
$$\mathbf{J} = \frac{\partial \mathbf{f}}{\partial \mathbf{x}}|_{x_0}$$

**稳定性判据**：
- 所有特征值具有负实部：稳定
- 存在正实部特征值：不稳定
- 纯虚数特征值：临界稳定

#### 11.3.3 极限环

**定义**：孤立的闭合轨迹，相邻轨迹既不趋向也不远离它。

**庞加莱-本迪克森判据**：
如果存在一个环域，其边界上向量场都指向环域内部，则环域内存在极限环。

### 11.4 非线性电路的应用

#### 11.4.1 整流电路

**二极管整流**：
- 半波整流：$v_o = v_i \cdot \frac{1 + \text{sgn}(v_i)}{2}$
- 全波整流：$v_o = |v_i|$

**性能指标**：
- 整流效率：$\eta = \frac{P_{dc}}{P_{ac}}$
- 纹波系数：$\gamma = \frac{V_{ripple}}{V_{dc}}$

#### 11.4.2 限幅电路

**串联限幅**：
- 上限幅：$v_o = \min(v_i, V_{ref})$
- 下限幅：$v_o = \max(v_i, V_{ref})$

**并联限幅**：
- 上限幅：当$v_i > V_{ref}$时，$v_o = V_{ref}$
- 下限幅：当$v_i < V_{ref}$时，$v_o = V_{ref}$

#### 11.4.3 比较器

**电压比较器**：
- 简单比较器：$v_o = V_{OH}$（当$v_+ > v_-$时）
- 迟滞比较器：具有两个阈值电压

**施密特触发器**：
- 上阈值：$V_{TH} = V_{ref} + \frac{R_2}{R_1 + R_2}(V_{OH} - V_{OL})$
- 下阈值：$V_{TL} = V_{ref} + \frac{R_2}{R_1 + R_2}(V_{OL} - V_{OH})$

## 第12章：时变电路与小信号分析

### 12.1 时变电路的基本概念

#### 12.1.1 时变元件

**时变电阻**：$R(t)$，$v(t) = R(t)i(t)$

**时变电感**：$L(t)$，$v(t) = \frac{d}{dt}[L(t)i(t)] = L(t)\frac{di(t)}{dt} + i(t)\frac{dL(t)}{dt}$

**时变电容**：$C(t)$，$i(t) = \frac{d}{dt}[C(t)v(t)] = C(t)\frac{dv(t)}{dt} + v(t)\frac{dC(t)}{dt}$

#### 12.1.2 时变电路的特点

- **参数随时间变化**：电路参数不是常数
- **频率变换**：输入频率与输出频率可能不同
- **时变系统**：系统的冲激响应随时间变化

#### 12.1.3 时变电路的分类

**按变化规律**：
- 周期时变：参数按周期规律变化
- 非周期时变：参数无规律变化

**按变化速度**：
- 慢变：参数变化频率$\ll$信号频率
- 快变：参数变化频率$\geq$信号频率

### 12.2 周期时变电路的分析

#### 12.2.1 参量变频原理

**基本原理**：周期时变参数电路具有变频功能。

**变频条件**：
- 时变参数的基频$\omega_p$
- 输入信号频率$\omega_s$
- 输出信号频率：$\omega_s \pm n\omega_p$（$n = 0, 1, 2, ...$）

#### 12.2.2 调幅电路

**时变电导调制**：
$$g(t) = g_0 + g_1\cos(\omega_p t)$$

**输入信号**：$v_s(t) = V_s\cos(\omega_s t)$

**输出电流**：$i(t) = g(t)v_s(t) = g_0V_s\cos(\omega_s t) + \frac{g_1V_s}{2}[\cos(\omega_s + \omega_p)t + \cos(\omega_s - \omega_p)t]$

**频率分量**：
- 载波：$\omega_s$
- 上边带：$\omega_s + \omega_p$
- 下边带：$\omega_s - \omega_p$

#### 12.2.3 参量放大器

**基本原理**：利用时变电抗元件进行能量转换。

**增益条件**：$\omega_p > 2\omega_s$（参量放大）

**三波相互作用**：
- 泵浦波：$\omega_p$
- 信号波：$\omega_s$
- 空闲波：$\omega_i = \omega_p - \omega_s$

<details>
<summary><strong>参量变频理论推导</strong></summary>

**时变电导的傅里叶级数**：

1. **周期时变电导**：
   $$g(t) = g_0 + \sum_{n=1}^{\infty}[g_n\cos(n\omega_p t) + h_n\sin(n\omega_p t)]$$

2. **简化为余弦形式**：
   $$g(t) = g_0 + \sum_{n=1}^{\infty} g_n\cos(n\omega_p t)$$

**输入信号**：
$$v_s(t) = V_s\cos(\omega_s t)$$

**输出电流**：
$$i(t) = g(t)v_s(t) = [g_0 + \sum_{n=1}^{\infty} g_n\cos(n\omega_p t)]V_s\cos(\omega_s t)$$

**使用三角恒等式**：
$$2\cos A\cos B = \cos(A+B) + \cos(A-B)$$

**展开**：
$$i(t) = g_0V_s\cos(\omega_s t) + \frac{V_s}{2}\sum_{n=1}^{\infty} g_n[\cos(\omega_s + n\omega_p)t + \cos(\omega_s - n\omega_p)t]$$

**频率分量分析**：
- 直流分量：无
- 基波分量：$\omega_s$
- 边带分量：$\omega_s \pm n\omega_p$

**变频增益**：
对于$n = 1$：
$$G = \frac{P_{\omega_s \pm \omega_p}}{P_{\omega_s}} = \left(\frac{g_1}{2g_0}\right)^2$$
</details>

### 12.3 小信号分析方法

#### 12.3.1 小信号分析的条件

**基本假设**：
1. 时变参数的幅度变化很小
2. 信号幅度远小于直流偏置
3. 可以进行线性化处理

#### 12.3.2 小信号等效电路

**时变元件的小信号模型**：

1. **时变电阻**：$R(t) = R_0 + r(t)$
   - 直流：$R_0$
   - 交流：$r(t)$

2. **时变电感**：$L(t) = L_0 + l(t)$
   - 直流：$L_0$
   - 交流：$l(t)$

3. **时变电容**：$C(t) = C_0 + c(t)$
   - 直流：$C_0$
   - 交流：$c(t)$

#### 12.3.3 小信号分析方法步骤

1. **直流分析**：确定工作点$(V_0, I_0)$
2. **时变参数分析**：确定$R(t)$、$L(t)$、$C(t)$的时变分量
3. **线性化**：建立小信号等效电路
4. **频域分析**：求解小信号响应

### 12.4 时变电路的应用

#### 12.4.1 调制解调

**幅度调制（AM）**：
- 载波：$\cos(\omega_c t)$
- 调制信号：$m(t)$
- 已调信号：$[1 + km(t)]\cos(\omega_c t)$

**频率调制（FM）**：
- 瞬时频率：$f(t) = f_c + k_f m(t)$
- 已调信号：$\cos[\omega_c t + k_f\int m(\tau)d\tau]$

#### 12.4.2 混频电路

**混频原理**：将两个不同频率的信号相乘，产生和频与差频分量。

**混频器类型**：
- 二极管混频器
- 晶体管混频器
- 场效应管混频器

**混频增益**：
$$G_c = \frac{P_{IF}}{P_{RF}} = \frac{g_1^2 R_L}{4g_0^2}$$

其中$P_{RF}$为射频功率，$P_{IF}$为中频功率。

#### 12.4.3 参量放大器

**工作原理**：
1. 泵浦信号驱动时变电抗元件
2. 能量从泵浦频率转移到信号频率
3. 实现低噪声放大

**噪声特性**：
- 噪声温度：$T_n = T_0(\frac{\omega_s}{\omega_p - \omega_s})$
- 噪声系数：$F = 1 + \frac{T_n}{T_0}$

## 第13章：滤波器设计

### 13.1 滤波器的基本概念

#### 13.1.1 滤波器的分类

**按频率特性分类**：

| 滤波器类型 | 通带 | 阻带 | 特点 |
|------------|------|------|------|
| 低通(LPF) | $0 \sim f_c$ | $f_c \sim \infty$ | 通过低频，抑制高频 |
| 高通(HPF) | $f_c \sim \infty$ | $0 \sim f_c$ | 通过高频，抑制低频 |
| 带通(BPF) | $f_1 \sim f_2$ | $0 \sim f_1, f_2 \sim \infty$ | 通过特定频段 |
| 带阻(BSF) | $0 \sim f_1, f_2 \sim \infty$ | $f_1 \sim f_2$ | 抑制特定频段 |

#### 13.1.2 滤波器的主要参数

**通带特性**：
- 通带截止频率：$f_c$
- 通带波动：$\delta_p$
- 通带衰减：$A_p = -20\log_{10}(1 - \delta_p)$（dB）

**阻带特性**：
- 阻带起始频率：$f_s$
- 阻带衰减：$A_s$（dB）

**相位特性**：
- 相位延迟：$\tau_p = -\frac{d\phi}{d\omega}$
- 群延迟：$\tau_g = -\frac{d\phi}{d\omega}$

#### 13.1.3 滤波器的阶数

**一阶滤波器**：
- 转移函数：$H(s) = \frac{1}{1 + \frac{s}{\omega_c}}$
- 斜率：-20 dB/十倍频程

**二阶滤波器**：
- 转移函数：$H(s) = \frac{\omega_c^2}{s^2 + \frac{\omega_c}{Q}s + \omega_c^2}$
- 斜率：-40 dB/十倍频程

**n阶滤波器**：
- 斜率：-20n dB/十倍频程

### 13.2 巴特沃斯滤波器

#### 13.2.1 巴特沃斯响应特性

**幅度响应**：
$$|H(j\omega)| = \frac{1}{\sqrt{1 + (\frac{\omega}{\omega_c})^{2n}}}$$

其中$n$为滤波器阶数。

**特点**：
- 通带内最平坦
- 过渡带滚降较慢
- 群延迟较大

#### 13.2.2 巴特沃斯多项式

**一阶**：$B_1(s) = s + 1$

**二阶**：$B_2(s) = s^2 + \sqrt{2}s + 1$

**三阶**：$B_3(s) = (s + 1)(s^2 + s + 1)$

**n阶巴特沃斯多项式**：
$$B_n(s) = \prod_{k=1}^{n} (s - e^{j\frac{(2k+n-1)\pi}{2n}})$$

#### 13.2.3 巴特沃斯滤波器设计

**低通滤波器设计步骤**：

1. **确定阶数**：
   $$n \geq \frac{\log_{10}(\sqrt{10^{A_s/10} - 1})}{\log_{10}(\omega_s/\omega_c)}$$

2. **确定极点**：
   $$p_k = \omega_c e^{j\frac{(2k+n-1)\pi}{2n}}, \quad k = 1, 2, ..., n$$

3. **构建转移函数**：
   $$H(s) = \frac{\omega_c^n}{\prod_{k=1}^{n}(s - p_k)}$$

<details>
<summary><strong>巴特沃斯滤波器推导</strong></summary>

**幅度平方函数**：

1. **定义**：
   $$|H(j\omega)|^2 = H(j\omega)H(-j\omega)$$

2. **对于巴特沃斯响应**：
   $$|H(j\omega)|^2 = \frac{1}{1 + (\frac{\omega}{\omega_c})^{2n}}$$

3. **复频域表示**：
   $$|H(j\omega)|^2 = H(s)H(-s)|_{s=j\omega}$$

4. **转移函数**：
   $$H(s)H(-s) = \frac{1}{1 + (\frac{-s^2}{\omega_c^2})^n}$$

**极点计算**：

1. **令分母为零**：
   $$1 + (\frac{-s^2}{\omega_c^2})^n = 0$$

2. **求解**：
   $$(\frac{-s^2}{\omega_c^2})^n = -1 = e^{j\pi}$$

3. **得**：
   $$\frac{-s^2}{\omega_c^2} = e^{j\frac{(2k+1)\pi}{n}}, \quad k = 0, 1, ..., n-1$$

4. **整理**：
   $$s^2 = -\omega_c^2 e^{j\frac{(2k+1)\pi}{n}} = \omega_c^2 e^{j\pi}e^{j\frac{(2k+1)\pi}{n}}$$

5. **开平方**：
   $$s = \pm \omega_c e^{j\frac{(2k+1)\pi}{2n}}$$

6. **选择左半平面极点**：
   $$p_k = \omega_c e^{j\frac{(2k+n-1)\pi}{2n}}, \quad k = 1, 2, ..., n$$

**阶数确定**：

1. **阻带要求**：
   $$|H(j\omega_s)|^2 \leq \frac{1}{1 + 10^{A_s/10}}$$

2. **代入幅度公式**：
   $$\frac{1}{1 + (\frac{\omega_s}{\omega_c})^{2n}} \leq \frac{1}{1 + 10^{A_s/10}}$$

3. **整理**：
   $$(\frac{\omega_s}{\omega_c})^{2n} \geq 10^{A_s/10} - 1$$

4. **求解n**：
   $$n \geq \frac{\log_{10}(\sqrt{10^{A_s/10} - 1})}{\log_{10}(\omega_s/\omega_c)}$$
</details>

### 13.3 切比雪夫滤波器

#### 13.3.1 切比雪夫多项式

**定义**：
$$C_n(x) = \cos(n\cos^{-1}x), \quad |x| \leq 1$$

**递推公式**：
$$C_0(x) = 1$$
$$C_1(x) = x$$
$$C_n(x) = 2xC_{n-1}(x) - C_{n-2}(x)$$

**前几阶多项式**：
- $C_0(x) = 1$
- $C_1(x) = x$
- $C_2(x) = 2x^2 - 1$
- $C_3(x) = 4x^3 - 3x$
- $C_4(x) = 8x^4 - 8x^2 + 1$

#### 13.3.2 切比雪夫响应特性

**幅度响应**：
$$|H(j\omega)| = \frac{1}{\sqrt{1 + \epsilon^2C_n^2(\frac{\omega}{\omega_c})}}$$

其中$\epsilon$为纹波参数。

**特点**：
- 通带内有等纹波
- 过渡带滚降快
- 通带内群延迟变化大

#### 13.3.3 切比雪夫滤波器设计

**参数关系**：
- 通带纹波：$\delta_p = \frac{1}{\sqrt{1 + \epsilon^2}}$
- 通带衰减：$A_p = -10\log_{10}(1 - \delta_p^2)$

**阶数确定**：
$$n \geq \frac{\cosh^{-1}(\sqrt{\frac{10^{A_s/10} - 1}{\epsilon^2}})}{\cosh^{-1}(\omega_s/\omega_c)}$$

### 13.4 椭圆滤波器

#### 13.4.1 椭圆函数滤波器

**幅度响应**：
$$|H(j\omega)| = \frac{1}{\sqrt{1 + \epsilon^2R_n^2(\omega/\omega_c)}}$$

其中$R_n$为n阶雅可比椭圆函数。

**特点**：
- 通带和阻带都有等纹波
- 过渡带最陡峭
- 相位特性最差

#### 13.4.2 椭圆滤波器设计

**设计参数**：
- 通带纹波：$\delta_p$
- 阻带衰减：$A_s$
- 截止频率：$\omega_c$
- 阻带频率：$\omega_s$

**阶数确定**：
$$n \geq \frac{K(k)K(\sqrt{1-k_s^2})}{K(k_s)K(\sqrt{1-k^2})}$$

其中$k$和$k_s$为模数，$K(k)$为第一类完全椭圆积分。

### 13.5 滤波器实现

#### 13.5.1 无源滤波器

**LC滤波器**：
- 结构简单
- 动态范围大
- 频率稳定性好

**LC滤波器类型**：
- 巴特沃斯LC滤波器

- 椭圆LC滤波器

#### 13.5.2 有源滤波器

**运算放大器滤波器**：

1. **一阶低通**：
   $$H(s) = \frac{\omega_c}{s + \omega_c}$$

2. **二阶低通**：
   $$H(s) = \frac{\omega_c^2}{s^2 + \frac{\omega_c}{Q}s + \omega_c^2}$$

3. **二阶带通**：
   $$H(s) = \frac{\frac{\omega_c}{Q}s}{s^2 + \frac{\omega_c}{Q}s + \omega_c^2}$$

**有源滤波器优势**：

#### 13.5.3 开关电容滤波器

**基本原理**：用电容和开关模拟电阻。

**等效电阻**：$R_{eq} = \frac{1}{f_{clk}C}$

**开关电容积分器**：

## 第14章：电路的频率响应

### 14.1 频率响应的基本概念

#### 14.1.1 频率响应函数

**定义**：$H(j\omega) = \frac{Y(j\omega)}{X(j\omega)}$

其中$X(j\omega)$为输入信号的傅里叶变换，$Y(j\omega)$为输出信号的傅里叶变换。

**幅度响应**：$|H(j\omega)|$

**相位响应**：$\angle H(j\omega)$

#### 14.1.2 频率响应的表示方法

**伯德图**：
- 幅度特性：$20\log_{10}|H(j\omega)|$ vs $\log_{10}\omega$
- 相位特性：$\angle H(j\omega)$ vs $\log_{10}\omega$

**奈奎斯特图**：$H(j\omega)$在复平面上的轨迹

**时域响应**：冲激响应$h(t)$和阶跃响应$s(t)$

#### 14.1.3 频率响应的物理意义

**系统对不同频率分量的响应**：
- 幅度变化：$|H(j\omega)|$
- 相位变化：$\angle H(j\omega)$
- 群延迟：$\tau_g = -\frac{d\phi}{d\omega}$

### 14.2 一阶电路的频率响应

#### 14.2.1 RC低通电路

**电路**：
```
R
|
Vin ----+---- Vout
       |
       C
       |
      GND
```

**传递函数**：
$$H(s) = \frac{1}{1 + sRC}$$

**频率响应**：
$$H(j\omega) = \frac{1}{1 + j\omega RC}$$

**幅度响应**：
$$|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}$$

**相位响应**：
$$\angle H(j\omega) = -\tan^{-1}(\omega RC)$$

**截止频率**：$\omega_c = \frac{1}{RC}$

#### 14.2.2 RC高通电路

**电路**：
```
C
|
Vin ----+---- Vout
       |
       R
       |
      GND
```

**传递函数**：
$$H(s) = \frac{sRC}{1 + sRC}$$

**频率响应**：
$$H(j\omega) = \frac{j\omega RC}{1 + j\omega RC}$$

**幅度响应**：
$$|H(j\omega)| = \frac{\omega RC}{\sqrt{1 + (\omega RC)^2}}$$

**相位响应**：
$$\angle H(j\omega) = \frac{\pi}{2} - \tan^{-1}(\omega RC)$$

<details>
<summary><strong>RC电路频率响应推导</strong></summary>

**RC低通电路分析**：

1. **电路方程**：
   $$v_{in} = v_R + v_C = Ri_C + \frac{1}{C}\int i_C dt$$

2. **电流关系**：
   $$i_C = C\frac{dv_C}{dt}$$

3. **输出电压**：
   $$v_{out} = v_C = \frac{1}{C}\int i_C dt$$

4. **拉普拉斯变换**：
   $$V_{in}(s) = RI_C(s) + \frac{1}{sC}I_C(s)$$
   $$V_{out}(s) = \frac{1}{sC}I_C(s)$$

5. **传递函数**：
   $$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \frac{\frac{1}{sC}}{R + \frac{1}{sC}} = \frac{1}{1 + sRC}$$

6. **频率响应**：
   $$H(j\omega) = \frac{1}{1 + j\omega RC}$$

7. **幅度**：
   $$|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega RC)^2}}$$

8. **相位**：
   $$\angle H(j\omega) = -\tan^{-1}(\omega RC)$$

**截止频率定义**：

1. **幅度为1/√2时的频率**：
   $$\frac{1}{\sqrt{1 + (\omega_c RC)^2}} = \frac{1}{\sqrt{2}}$$

2. **求解**：
   $$1 + (\omega_c RC)^2 = 2$$
   $$(\omega_c RC)^2 = 1$$
   $$\omega_c = \frac{1}{RC}$$

3. **功率衰减**：
   $$|H(j\omega_c)|^2 = \frac{1}{2}$$
   对应功率衰减3dB
</details>

### 14.3 二阶电路的频率响应

#### 14.3.1 RLC串联谐振电路

**电路**：
```
L
|
Vin ----+---- Vout
       |
       R
       |
       C
       |
      GND
```

**传递函数**：
$$H(s) = \frac{\frac{1}{LC}}{s^2 + \frac{R}{L}s + \frac{1}{LC}}$$

**标准形式**：
$$H(s) = \frac{\omega_0^2}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

其中：
- $\omega_0 = \frac{1}{\sqrt{LC}}$：谐振角频率
- $Q = \frac{\omega_0 L}{R}$：品质因数

#### 14.3.2 RLC并联谐振电路

**电路**：
```
L
|
Vin ----+----+---- Vout
       |    |
       R    C
       |    |
      GND  GND
```

**传递函数**：
$$H(s) = \frac{s\frac{R}{L}}{s^2 + \frac{R}{L}s + \frac{1}{LC}}$$

**标准形式**：
$$H(s) = \frac{\frac{\omega_0}{Q}s}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

#### 14.3.3 二阶系统的频率特性

**幅度响应**：
$$|H(j\omega)| = \frac{\omega_0^2}{\sqrt{(\omega_0^2 - \omega^2)^2 + (\frac{\omega_0}{Q}\omega)^2}}$$

**相位响应**：
$$\angle H(j\omega) = -\tan^{-1}\left(\frac{\frac{\omega_0}{Q}\omega}{\omega_0^2 - \omega^2}\right)$$

**谐振特性**：
- 串联谐振：阻抗最小，电流最大
- 并联谐振：阻抗最大，电流最小

### 14.4 高阶电路的频率响应

#### 14.4.1 高阶系统的极点零点

**极点的作用**：
- 左半平面极点：稳定，响应衰减
- 右半平面极点：不稳定
- 虚轴极点：临界稳定，持久振荡

**零点的作用**：
- 改变幅度响应的斜率
- 改变相位响应的跳跃

#### 14.4.2 频率响应的分解

**部分分式展开**：
$$H(s) = \sum_{i=1}^{n} \frac{A_i}{s - p_i} + \sum_{j=1}^{m} \frac{B_j}{s - z_j}$$

**时域响应**：
$$h(t) = \sum_{i=1}^{n} A_i e^{p_i t} + \sum_{j=1}^{m} B_j e^{z_j t}$$

**频率响应**：
$$H(j\omega) = \sum_{i=1}^{n} \frac{A_i}{j\omega - p_i} + \sum_{j=1}^{m} \frac{B_j}{j\omega - z_j}$$

#### 14.4.3 根轨迹分析

**根轨迹定义**：当某个参数变化时，系统极点在s平面上的轨迹。

**根轨迹法则**：
1. 根轨迹起始于开环极点，终止于开环零点
2. 根轨迹关于实轴对称
3. 实轴上的根轨迹右侧零极点个数之和为奇数
4. 根轨迹的渐近线与实轴夹角为$\frac{(2k+1)\pi}{n-m}$

### 14.5 频率响应的测量

#### 14.5.1 扫频测量法

**原理**：用扫频信号激励被测系统，测量输出信号的幅度和相位。

**扫频信号**：
$$v_{in}(t) = A\cos(\omega t)$$

**测量参数**：
- 幅度比：$|H(j\omega)| = \frac{V_{out}}{V_{in}}$
- 相位差：$\angle H(j\omega) = \phi_{out} - \phi_{in}$

#### 14.5.2 脉冲测量法

**原理**：用冲激信号激励系统，测量冲激响应，然后计算频率响应。

**冲激响应**：
$$h(t) = \mathcal{L}^{-1}[H(s)]$$

**频率响应**：
$$H(j\omega) = \int_{-\infty}^{\infty} h(t)e^{-j\omega t}dt$$

#### 14.5.3 网络分析仪

**功能**：
- 扫频测量
- 幅度和相位显示
- 多种参数显示（S参数、Z参数、Y参数等）

**优势**：
- 测量精度高
- 动态范围大
- 自动化程度高

## 第15章：二极管与晶体管电路

### 15.1 半导体二极管

#### 15.1.1 PN结原理

**PN结的形成**：
- P区：空穴为多数载流子
- N区：电子为多数载流子
- 扩散运动：P区空穴向N区扩散，N区电子向P区扩散
- 漂移运动：内建电场驱动少数载流子漂移

**内建电势**：
$$V_{bi} = \frac{kT}{q}\ln\left(\frac{N_A N_D}{n_i^2}\right)$$

其中：
- $k$：玻尔兹曼常数
- $T$：绝对温度
- $q$：电子电荷
- $N_A$：受主浓度
- $N_D$：施主浓度
- $n_i$：本征载流子浓度

#### 15.1.2 二极管的伏安特性

**理想二极管方程**：
$$I = I_S\left(e^{\frac{qV}{kT}} - 1\right)$$

其中$I_S$为反向饱和电流。

**实际二极管方程**：
$$I = I_S\left(e^{\frac{qV}{nkT}} - 1\right)$$

其中$n$为理想因子（1-2之间）。

**伏安特性曲线**：
- 正向偏置：$V > 0$，电流指数增长
- 反向偏置：$V < 0$，电流很小（$I \approx -I_S$）
- 击穿区：$|V| > V_{BR}$，电流急剧增加

#### 15.1.3 二极管的等效电路

**直流等效电路**：
- 正向偏置：导通压降$V_D \approx 0.7V$（硅管）
- 反向偏置：开路

**小信号等效电路**：
$$r_d = \frac{nkT}{qI_D} = \frac{26mV}{I_D}(室温)$$

其中$r_d$为动态电阻。

**完整等效电路**：
- 正向偏置：$V_D$串联$r_d$
- 反向偏置：$I_S$并联$r_d$

<details>
<summary><strong>PN结理论推导</strong></summary>

**载流子浓度分布**：

1. **热平衡条件**：
   $$p n = n_i^2$$

2. **P区载流子浓度**：
   $$p_p \approx N_A$$
   $$n_p = \frac{n_i^2}{N_A}$$

3. **N区载流子浓度**：
   $$n_n \approx N_D$$
   $$p_n = \frac{n_i^2}{N_D}$$

**内建电势计算**：

1. **载流子扩散**：
   $$J_n = qD_n\frac{dn}{dx}$$
   $$J_p = qD_p\frac{dp}{dx}$$

2. **漂移电流**：
   $$J_n = q\mu_n nE$$
   $$J_p = q\mu_p pE$$

3. **热平衡条件**：
   $$J_n + J_p = 0$$

4. **电场分布**：
   $$E = -\frac{d\phi}{dx}$$

5. **玻尔兹曼分布**：
   $$n(x) = n(0)e^{\frac{q\phi(x)}{kT}}$$
   $$p(x) = p(0)e^{-\frac{q\phi(x)}{kT}}$$

6. **边界条件**：
   $$n_p = n_n e^{-\frac{qV_{bi}}{kT}}$$
   $$p_p = p_n e^{\frac{qV_{bi}}{kT}}$$

7. **内建电势**：
   $$V_{bi} = \frac{kT}{q}\ln\left(\frac{N_A N_D}{n_i^2}\right)$$

**二极管方程推导**：

1. **连续性方程**：
   $$\frac{d^2n}{dx^2} - \frac{n - n_0}{D_n\tau_n} = 0$$

2. **边界条件**：
   $$n(0) = n_0 e^{\frac{qV}{kT}}$$
   $$n(W) = n_0$$

3. **解**：
   $$n(x) = n_0\left[1 + \frac{e^{\frac{qV}{kT}} - 1}{\sinh(W/L_n)}\sinh\left(\frac{W-x}{L_n}\right)\right]$$

4. **电流密度**：
   $$J_n = qD_n\frac{dn}{dx}|_{x=0} = \frac{qD_n n_i^2}{L_N N_A}\left(e^{\frac{qV}{kT}} - 1\right)$$

5. **总电流**：
   $$I = I_S\left(e^{\frac{qV}{kT}} - 1\right)$$

其中反向饱和电流：$I_S = \frac{qD_n n_i^2}{L_N N_A}A$
</details>

### 15.3 双极性晶体管（BJT）

#### 15.3.1 BJT结构与原理

**NPN晶体管结构**：
- 发射区（N型）：高掺杂
- 基区（P型）：薄、轻掺杂
- 集电区（N型）：低掺杂

**工作原理**：
1. **发射结正偏**：发射区电子注入基区
2. **基区输运**：电子在基区扩散
3. **集电结反偏**：电子被集电区收集

**电流传输方程**：
$$I_E = I_{ES}(e^{\frac{V_{BE}}{V_T}} - 1) + \alpha_R I_{CS}(e^{\frac{V_{BC}}{V_T}} - 1)$$

$$I_C = \alpha_F I_{ES}(e^{\frac{V_{BE}}{V_T}} - 1) + I_{CS}(e^{\frac{V_{BC}}{V_T}} - 1)$$

$$I_B = (1 - \alpha_F)I_{ES}(e^{\frac{V_{BE}}{V_T}} - 1) + (1 - \alpha_R)I_{CS}(e^{\frac{V_{BC}}{V_T}} - 1)$$

#### 15.3.2 BJT的放大特性

**共射极放大器**：

**直流分析**：
$$I_C = \beta I_B$$
$$V_{CE} = V_{CC} - I_C R_C$$

**小信号模型**：
$$g_m = \frac{I_C}{V_T} \approx 40I_C$$
$$r_\pi = \frac{\beta}{g_m} = \frac{\beta V_T}{I_C}$$
$$r_o = \frac{V_A}{I_C}$$

其中$V_A$为厄利电压。

**电压增益**：
$$A_v = -\frac{g_m R_C}{1 + \frac{R_C}{r_o}}$$

**电流增益**：
$$\beta = \frac{I_C}{I_B}$$

#### 15.3.3 BJT的工作状态

**截止状态**：
- $V_{BE} < 0.7V$
- $I_B \approx 0$，$I_C \approx 0$

**放大状态**：
- $V_{BE} \approx 0.7V$
- $V_{BC} < 0$（NPN）
- $I_C = \beta I_B$

**饱和状态**：
- $V_{BE} \approx 0.7V$
- $V_{BC} > 0$（NPN）
- $V_{CE(sat)} \approx 0.2V$

**N沟道JFET结构**：

$$I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$$

**跨导**：
$$g_m = \mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})$$

#### 15.4.3 FET放大器

**共源极放大器**：

**小信号模型**：
- 跨导：$g_m$
- 输出电阻：$r_o$
- 源极电阻：$R_S$

$$A_v = -g_m(R_D || r_o)$$

**输入电阻**：$R_{in} \approx \infty$（MOSFET）

**输出电阻**：$R_{out} \approx R_D || r_o$

## 第16章：场效应管电路

### 16.1 MOSFET基础理论

#### 16.1.1 MOSFET结构与工作原理

**N沟道增强型MOSFET**：

**结构组成**：
- 源极（S）：N型重掺杂
- 漏极（D）：N型重掺杂  
- 栅极（G）：多晶硅或金属
- 衬底（B）：P型半导体
- 氧化层：SiO₂绝缘层

**工作原理**：
1. **截止状态**：$V_{GS} < V_{TH}$，无导电沟道
2. **弱反型**：$V_{GS} > V_{TH}$，形成反型层
3. **强反型**：$V_{GS} \gg V_{TH}$，形成导电沟道

#### 16.1.2 MOSFET的I-V特性

**转移特性**（$V_{DS} > V_{GS} - V_{TH}$）：
$$I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$$

其中：
- $\mu_n$：电子迁移率
- $C_{ox}$：单位面积栅氧化层电容
- $W/L$：沟道宽长比
- $V_{TH}$：阈值电压

**输出特性**：
- 截止区：$V_{GS} < V_{TH}$，$I_D \approx 0$
- 线性区：$V_{DS} < V_{GS} - V_{TH}$，$I_D \propto V_{DS}$
- 饱和区：$V_{DS} > V_{GS} - V_{TH}$，$I_D$基本恒定

#### 16.1.3 MOSFET的小信号模型

**跨导**：
$$g_m = \frac{\partial I_D}{\partial V_{GS}} = \mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})$$

**输出电阻**：
$$r_o = \frac{1}{\lambda I_D}$$

其中$\lambda$为沟道长度调制系数。

**栅源电容**：
$$C_{gs} = \frac{2}{3}WLC_{ox} + C_{ov}$$

**栅漏电容**：
$$C_{gd} = C_{ov}$$

其中$C_{ov}$为栅漏覆盖电容。

<details>
<summary><strong>MOSFET理论推导</strong></summary>

**阈值电压推导**：

1. **表面势**：
   $$\phi_s = \phi_F + \phi_{inv}$$

2. **耗尽层电荷**：
   $$Q_d = -\sqrt{2\varepsilon_s q N_A(2\phi_s)}$$

3. **栅极电荷平衡**：
   $$Q_g + Q_{ox} + Q_d = 0$$

4. **阈值条件**：
   $$\phi_s = 2\phi_F$$

5. **阈值电压**：
   $$V_{TH} = \phi_{ms} + 2\phi_F + \frac{\sqrt{2\varepsilon_s q N_A(2\phi_F)}}{C_{ox}} - \frac{Q_{ox}}{C_{ox}}$$

其中：
- $\phi_{ms}$：金属-半导体功函数差
- $\phi_F$：费米势
- $Q_{ox}$：氧化层固定电荷

**漏极电流推导**：

1. **沟道电荷**：
   $$Q_c(y) = -C_{ox}(V_{GS} - V_{TH} - V(y))$$

2. **电流密度**：
   $$J_n = q\mu_n n E_y = -\mu_n Q_c \frac{dV}{dy}$$

3. **总电流**：
   $$I_D = W\mu_n \int_0^{V_{DS}} Q_c(y)dy$$

4. **积分**：
   $$I_D = \mu_n C_{ox}\frac{W}{L}\int_0^{V_{DS}}(V_{GS} - V_{TH} - V(y))dV(y)$$

5. **线性区结果**：
   $$I_D = \mu_n C_{ox}\frac{W}{L}\left[(V_{GS} - V_{TH})V_{DS} - \frac{V_{DS}^2}{2}\right]$$

6. **饱和区**（$V_{DS} > V_{GS} - V_{TH}$）：
   $$I_D = \frac{1}{2}\mu_n C_{ox}\frac{W}{L}(V_{GS} - V_{TH})^2$$
</details>

$$BW = \frac{GBW}{|A_v|} = \frac{GBW \cdot R_1}{R_f}$$

#### 17.2.2 同相放大器

**电路结构**：
```
Vin ----+---- Vout
       |    |
      +     |
       |    Rf
       |    |
      R1    |
       |    |
      GND  GND
```

**电压增益**：
$$A_v = 1 + \frac{R_f}{R_1}$$

**输入阻抗**：$R_{in} \approx \infty$

**输出阻抗**：$R_{out} \approx 0$

#### 17.2.3 差分放大器

**电路结构**：
```
V1 ----+---- Vout
       |    |
      -     |
       |    Rf
       |    |
V2 ----+    |
       |    |
      +     |
       |    R1
       |    |
      GND  GND
```

**电压增益**：
$$A_{dm} = \frac{R_f}{R_1}$$

**共模抑制比**：
$$CMRR = \frac{A_{dm}}{A_{cm}} = \frac{R_f}{R_1} \cdot \frac{R_{cm}}{R_1}$$

<summary><strong>基本放大电路推导</strong></summary>

**反相放大器分析**：

1. **虚短特性**：$V_- = V_+ = 0$

2. **虚断特性**：$I_- = 0$

3. **KCL方程**：
   $$\frac{V_{in} - V_-}{R_1} + \frac{V_{out} - V_-}{R_f} = 0$$

4. **代入虚短条件**：
   $$\frac{V_{in}}{R_1} + \frac{V_{out}}{R_f} = 0$$

5. **求解**：
   $$V_{out} = -\frac{R_f}{R_1}V_{in}$$

6. **增益**：
   $$A_v = \frac{V_{out}}{V_{in}} = -\frac{R_f}{R_1}$$

**同相放大器分析**：

1. **虚短特性**：$V_+ = V_- = V_{in}$

2. **虚断特性**：$I_- = 0$

3. **KCL方程**：
   $$\frac{V_- - 0}{R_1} + \frac{V_{out} - V_-}{R_f} = 0$$

4. **代入虚短条件**：
   $$\frac{V_{in}}{R_1} + \frac{V_{out} - V_{in}}{R_f} = 0$$

5. **整理**：
   $$\frac{V_{in}}{R_1} = \frac{V_{in} - V_{out}}{R_f}$$

6. **求解**：
   $$V_{out} = V_{in}\left(1 + \frac{R_f}{R_1}\right)$$

7. **增益**：
   $$A_v = 1 + \frac{R_f}{R_1}$$

**差分放大器分析**：

1. **虚短特性**：$V_+ = V_-$

2. **设$V_+ = V_- = V_{cm}$（共模电压）

3. **对反相输入端KCL**：
   $$\frac{V_1 - V_{cm}}{R_1} + \frac{V_{out} - V_{cm}}{R_f} = 0$$

4. **对同相输入端KCL**：
   $$\frac{V_2 - V_{cm}}{R_1} = 0$$

5. **由第4式得**：$V_{cm} = V_2$

6. **代入第3式**：
   $$\frac{V_1 - V_2}{R_1} + \frac{V_{out} - V_2}{R_f} = 0$$

7. **求解**：
   $$V_{out} = \frac{R_f}{R_1}(V_2 - V_1)$$

8. **差模增益**：
   $$A_{dm} = \frac{V_{out}}{V_1 - V_2} = -\frac{R_f}{R_1}$$

### 17.3 运算放大器的频率特性

#### 17.3.1 开环频率响应

**一阶模型**：
$$A_{ol}(s) = \frac{A_{ol0}}{1 + \frac{s}{\omega_p}}$$

其中：
- $A_{ol0}$：直流开环增益
- $\omega_p$：主极点频率

**增益带宽积**：
$$GBW = A_{ol0} \cdot f_p = A_{ol0} \cdot \frac{\omega_p}{2\pi}$$

#### 17.3.2 闭环频率响应

**反相放大器闭环增益**：
$$A_{cl}(s) = -\frac{R_f}{R_1} \cdot \frac{1}{1 + \frac{s}{GBW/A_v}}$$

其中$A_v = \frac{R_f}{R_1}$为闭环增益。

**-3dB带宽**：
$$f_{-3dB} = \frac{GBW}{|A_v|}$$

#### 17.3.3 相位补偿

**米勒补偿**：
- 在输出和反相输入端之间接补偿电容
- 产生主极点，降低相位裕度

**相位裕度**：
$$PM = 180° - \angle A_{ol}(j\omega_{gc})$$

其中$\omega_{gc}$为增益交越频率。

**稳定条件**：$PM > 45°$

## 第18章：数字电路基础

### 18.1 数制与编码

#### 18.1.1 数制系统

**二进制**：
- 基数：2
- 权：$2^n$
- 表示：$(1011.101)_2$

**八进制**：
- 基数：8
- 权：$8^n$
- 表示：$(123.456)_8$

**十六进制**：
- 基数：16
- 权：$16^n$
- 表示：$(AB.CD)_{16}$

**数制转换**：

1. **十进制转二进制**：
   - 整数部分：除2取余
   - 小数部分：乘2取整

2. **二进制转十进制**：
   $$\sum_{i=-m}^{n} b_i \cdot 2^i$$

#### 18.1.2 码制

**原码**：
- 符号位 + 数值位
- 范围：$-(2^{n-1}-1)$ 到 $+(2^{n-1}-1)$

**反码**：
- 正数：反码 = 原码
- 负数：反码 = 原码除符号位外取反

**补码**：
- 正数：补码 = 原码
- 负数：补码 = 反码 + 1
- 范围：$-2^{n-1}$ 到 $+(2^{n-1}-1)$

#### 18.1.3 常用编码

**BCD码**：
- 8421码：用4位二进制表示1位十进制
- 2421码：权值为2、4、2、1
- 余3码：8421码加3

**格雷码**：
- 特点：相邻两个码只有一位不同
- 用途：减少转换误差

**ASCII码**：
- 7位二进制码
- 表示128个字符

### 18.2 逻辑代数基础

#### 18.2.1 基本逻辑运算

**与运算（AND）**：
$$F = A \cdot B = AB$$

**或运算（OR）**：
$$F = A + B$$

**非运算（NOT）**：
$$F = \bar{A}$$

**与非运算（NAND）**：
$$F = \overline{AB}$$

**或非运算（NOR）**：
$$F = \overline{A + B}$$

**异或运算（XOR）**：
$$F = A \oplus B = \bar{A}B + A\bar{B}$$

**同或运算（XNOR）**：
$$F = A \odot B = AB + \bar{A}\bar{B}$$

#### 18.2.2 逻辑代数定律

**交换律**：
$$A + B = B + A$$
$$AB = BA$$

**结合律**：
$$A + (B + C) = (A + B) + C$$
$$A(BC) = (AB)C$$

**分配律**：
$$A(B + C) = AB + AC$$
$$A + BC = (A + B)(A + C)$$

**吸收律**：
$$A + AB = A$$
$$A(A + B) = A$$

**德摩根定律**：
$$\overline{AB} = \bar{A} + \bar{B}$$
$$\overline{A + B} = \bar{A}\bar{B}$$

#### 18.2.3 逻辑函数化简

**代数化简法**：
1. 并项法：$AB + A\bar{B} = A$
2. 吸收法：$A + AB = A$
3. 消去法：$A\bar{B} + B = A + B$
4. 配项法：$AB + \bar{A}C + BC = AB + \bar{A}C$

**卡诺图化简**：
1. 画出卡诺图
2. 找出相邻的1
3. 画包围圈
4. 写出最简表达式

## 第19章：电力电子基础

### 19.1 电力电子器件

#### 19.1.1 功率二极管

**基本特性**：
- 正向压降：$V_F \approx 0.7-1.5V$
- 反向恢复时间：$t_{rr}$
- 反向恢复电荷：$Q_{rr}$

**分类**：
- **普通二极管**：低频应用
- **快恢复二极管**：开关电源
- **肖特基二极管**：低压大电流

**反向恢复特性**：
$$Q_{rr} = \frac{1}{2}I_{RM}t_{rr}$$

其中$I_{RM}$为反向恢复电流最大值。

#### 19.1.2 晶闸管（SCR）

**结构**：四层三端器件（P-N-P-N）

**工作原理**：
1. **正向阻断**：$V_{AK} > 0$，$I_G = 0$
2. **触发导通**：$I_G > I_{GT}$
3. **维持导通**：$I_A > I_H$
4. **关断**：$I_A < I_H$或反向偏置

**主要参数**：
- 正向重复峰值电压：$V_{DRM}$
- 反向重复峰值电压：$V_{RRM}$
- 门极触发电压：$V_{GT}$
- 门极触发电流：$I_{GT}$
- 维持电流：$I_H$

#### 19.1.3 门极可关断晶闸管（GTO）

**特点**：
- 门极正脉冲触发导通
- 门极负脉冲关断
- 关断增益：$\beta_{off} = \frac{I_A}{I_G}$

**应用**：大功率逆变器、变频器

#### 19.1.4 功率晶体管（BJT）

**特性**：
- 电流控制型
- 开关频率：1-10kHz
- 饱和压降：$V_{CE(sat)}$

**基极驱动**：
$$I_B = \frac{I_C}{\beta} + \frac{t_{on}}{t_{storage}}I_C$$

其中$t_{storage}$为存储时间。

#### 19.1.5 功率场效应管（MOSFET）

**特性**：
- 电压控制型
- 开关频率：100kHz-1MHz
- 导通电阻：$R_{DS(on)}$

**开关损耗**：
$$P_{sw} = \frac{1}{2}V_{DS}I_D(t_{on} + t_{off})f_{sw}$$

其中$f_{sw}$为开关频率。

#### 19.1.6 绝缘栅双极晶体管（IGBT）

**特性**：
- 电压控制型
- 开关频率：10-50kHz
- 导通压降：$V_{CE(sat)}$

**等效电路**：MOSFET + BJT

**门极驱动电压**：$V_{GE} = \pm(15-20)V$

<details>
<summary><strong>电力电子器件开关过程分析</strong></summary>

**功率MOSFET开关过程**：

1. **开通过程**：
   - $t_0 - t_1$：栅极电压上升到$V_{GS(th)}$
   - $t_1 - t_2$：漏极电流上升，$V_{DS}$基本不变
   - $t_2 - t_3$：$V_{DS}$下降，$I_D$基本不变
   - $t_3$：完全导通

2. **关断过程**：
   - $t_4 - t_5$：栅极电压下降，$I_D$基本不变
   - $t_5 - t_6$：$V_{DS}$上升，$I_D$下降
   - $t_6$：完全关断

3. **开关损耗**：
   $$P_{on} = \int_{t_1}^{t_3} v_{DS}(t)i_D(t)dt$$
   $$P_{off} = \int_{t_5}^{t_6} v_{DS}(t)i_D(t)dt$$

**IGBT开关过程**：

1. **开通特性**：
   - 延迟时间：$t_{d(on)}$
   - 上升时间：$t_r$
   - 开通时间：$t_{on} = t_{d(on)} + t_r$

2. **关断特性**：
   - 延迟时间：$t_{d(off)}$
   - 下降时间：$t_f$
   - 存储时间：$t_s$
   - 关断时间：$t_{off} = t_{d(off)} + t_s + t_f$

3. **电流拖尾**：
   - 原因：少子存储效应
   - 影响：增加关断损耗
</details>

### 19.2 AC-DC变换器

#### 19.2.1 二极管整流器

**单相半波整流**：

**输出电压**：
$$V_{dc} = \frac{V_m}{\pi}$$

**输出电流**：
$$I_{dc} = \frac{V_{dc}}{R_L}$$

**纹波系数**：
$$\gamma = \frac{V_{r}}{V_{dc}} = 1.21$$

其中$V_r$为纹波电压有效值。

**单相全波整流**：

**输出电压**：
$$V_{dc} = \frac{2V_m}{\pi}$$

**纹波系数**：
$$\gamma = 0.484$$

**三相桥式整流**：

**输出电压**：
$$V_{dc} = \frac{3\sqrt{2}V_{LL}}{\pi}$$

**纹波系数**：
$$\gamma = 0.042$$

#### 19.2.2 可控整流器

**单相桥式全控整流**：

**电阻负载**：
$$V_{dc} = \frac{2V_m}{\pi}\cos\alpha$$

其中$\alpha$为触发延迟角。

**电感负载**：
$$V_{dc} = \frac{2V_m}{\pi}\cos\alpha$$

**三相桥式全控整流**：

**输出电压**：
$$V_{dc} = \frac{3\sqrt{2}V_{LL}}{\pi}\cos\alpha$$

**逆变工作条件**：
- $\alpha > 90°$
- 有源负载
- 需要换流

#### 19.2.3 功率因数校正（PFC）

**Boost PFC电路**：

**工作原理**：
1. 电感储能：开关管导通
2. 电感释能：开关管关断
3. 电容滤波：输出直流

**控制策略**：
- 电流跟踪控制
- 电压外环控制
- 平均电流模式

**功率因数**：
$$PF = \frac{P}{S} = \cos\phi$$

理想情况下$PF = 1$。

### 19.3 DC-DC变换器

#### 19.3.1 降压变换器（Buck）

**电路结构**：
```
Vin ----+---- L ----+---- Vout
       |            |
      M1           C
       |            |
      GND          GND
```

**工作原理**：
- **开关导通**：$V_{in} = L\frac{di_L}{dt} + V_{out}$
- **开关关断**：$0 = L\frac{di_L}{dt} + V_{out}$

**电压增益**：
$$M = \frac{V_{out}}{V_{in}} = D$$

其中$D$为占空比。

**电感电流**：
$$I_L = \frac{V_{out}}{R_L}$$

**临界电感**：
$$L_{crit} = \frac{V_{out}(1 - D)}{2f_s I_{out}}$$

#### 19.3.2 升压变换器（Boost）

**电路结构**：
```
Vin ---- L ----+---- Vout
              |    |
             M1   C
              |    |
             GND  GND
```

**电压增益**：
$$M = \frac{V_{out}}{V_{in}} = \frac{1}{1 - D}$$

**临界电感**：
$$L_{crit} = \frac{V_{in}D(1 - D)^2}{2f_s I_{out}}$$

#### 19.3.3 升降压变换器（Buck-Boost）

**电路结构**：
```
Vin ---- L ----+---- Vout
              |    |
             M1   C
              |    |
             GND  GND
```

**电压增益**：
$$M = \frac{V_{out}}{V_{in}} = \frac{D}{1 - D}$$

**极性**：输出电压与输入电压极性相反。

#### 19.3.4 全桥变换器

**电路结构**：
```
Vin ---- M1 ----+---- Vout
              |    |
             M2   C
              |    |
             GND  GND
```

**工作方式**：
- 双极性调制
- 单极性调制
- 移相控制

**输出电压**：
$$V_{out} = D \cdot V_{in}$$

其中$D$为有效占空比。

### 19.4 DC-AC变换器

#### 19.4.1 电压型逆变器

**单相全桥逆变器**：

**电路结构**：
```
Vin ---- M1 ----+---- Vout
              |    |
             M2   C
              |    |
             GND  GND
```

**输出电压**：
$$v_o(t) = \begin{cases}
+V_{in}, & S_1, S_4 \text{导通} \\
-V_{in}, & S_2, S_3 \text{导通} \\
0, & \text{其他情况}
\end{cases}$$

**基波分量**：
$$v_{o1}(t) = \frac{4V_{in}}{\pi}\sin(\omega t)$$

**总谐波失真**：
$$THD = \frac{\sqrt{\sum_{n=2,3,...} V_n^2}}{V_1}$$

#### 19.4.2 电流型逆变器

**特点**：
- 输入侧为大电感
- 输出侧为电容滤波
- 适合感性负载

**应用**：大型电机驱动

#### 19.4.3 脉宽调制（PWM）

**SPWM调制**：

**调制比**：
$$M_a = \frac{V_{control}}{V_{carrier}}$$

**输出电压**：
$$V_{out} = M_a \cdot \frac{V_{in}}{2}$$

**载波比**：
$$M_f = \frac{f_{carrier}}{f_{modulation}}$$

**SVPWM调制**：

**空间电压矢量**：
$$\vec{V} = \frac{2}{3}(V_a + aV_b + a^2V_c)$$

其中$a = e^{j\frac{2\pi}{3}}$。

### 19.5 软开关技术

#### 19.5.1 零电压开关（ZVS）

**条件**：
- 开关前电压为零
- 开关后电流连续

**应用**：谐振变换器、移相全桥

#### 19.5.2 零电流开关（ZCS）

**条件**：
- 开关前电流为零
- 开关后电压连续

**应用**：准谐振变换器

#### 19.5.3 谐振变换器

**串联谐振变换器**：
- 谐振频率：$f_r = \frac{1}{2\pi\sqrt{LC}}$
- 开关频率：$f_s > f_r$

**并联谐振变换器**：
- 谐振频率：$f_r = \frac{1}{2\pi\sqrt{LC}}$
- 开关频率：$f_s < f_r$

## 第20章：电磁兼容

### 20.1 电磁兼容基础

#### 20.1.1 电磁兼容基本概念

**电磁干扰（EMI）**：
- **传导干扰**：通过导体传播
- **辐射干扰**：通过空间传播

**电磁敏感度（EMS）**：
- 设备对电磁干扰的承受能力

**电磁兼容（EMC）**：
- 设备在电磁环境中正常工作，且不对环境产生电磁干扰

#### 20.1.2 电磁干扰三要素

1. **干扰源**：产生电磁干扰的设备或电路
2. **传播路径**：干扰从干扰源到敏感设备的路径
3. **敏感设备**：受到电磁干扰影响的设备

**干扰抑制原则**：
- 抑制干扰源
- 切断传播路径
- 提高敏感设备抗干扰能力

#### 20.1.3 电磁频谱

**频段划分**：

| 频段 | 频率范围 | 用途 |
|------|----------|------|
| ELF | 3-30Hz | 潜艇通信 |
| VF | 30-300Hz | 电力系统 |
| VLF | 3-30kHz | 远距离通信 |
| LF | 30-300kHz | 导航、广播 |
| MF | 300-3000kHz | AM广播 |
| HF | 3-30MHz | 短波通信 |
| VHF | 30-300MHz | TV、FM广播 |
| UHF | 300-3000MHz | TV、移动通信 |
| SHF | 3-30GHz | 雷达、卫星 |
| EHF | 30-300GHz | 卫星通信 |

### 20.2 传导干扰

#### 20.2.1 共模干扰

**定义**：干扰电压在所有信号线上具有相同的大小和相位。

**产生原因**：
- 地电位差
- 开关电源的开关噪声
- 电缆屏蔽层电流

**抑制方法**：
- 共模扼流圈
- 共模电容
- 接地优化

#### 20.2.2 差模干扰

**定义**：干扰电压在信号线之间具有相反的相位。

**产生原因**：
- 开关管的开关噪声
- 线路电感
- 负载变化

**抑制方法**：
- 差模电感
- 差模电容
- 滤波网络

#### 20.2.3 传导干扰测试

**测试标准**：
- CISPR 22：信息技术设备的传导干扰
- CISPR 11：工业设备的传导干扰

**测试设备**：
- 传导干扰测试接收机
- 人工电源网络（LISN）
- 电压探头

**测试方法**：
1. 设置测试环境
2. 连接LISN和被测设备
3. 测量各频段的传导干扰
4. 与标准限值比较

### 20.3 辐射干扰

#### 20.3.1 近场与远场

**近场**（$r \ll \frac{\lambda}{2\pi}$）：
- 电场为主：$E \propto \frac{1}{r^3}$
- 磁场为主：$H \propto \frac{1}{r^2}$
- 特征阻抗：$Z_0 = \frac{E}{H} \neq 377\Omega$

**远场**（$r \gg \frac{\lambda}{2\pi}$）：
- 平面波
- 特征阻抗：$Z_0 = 377\Omega$
- $E = ZH$

#### 20.3.2 辐射干扰源

**偶极子天线**：
- 电偶极子：短导线
- 磁偶极子：环形导线

**辐射功率**：
$$P_{rad} = \frac{I_0^2 l^2 \eta}{6\pi}\left(\frac{l}{\lambda}\right)^2$$

其中：
- $I_0$：电流幅度
- $l$：天线长度
- $\eta$：波阻抗
- $\lambda$：波长

#### 20.3.3 辐射干扰测试

**测试标准**：
- CISPR 22：辐射干扰测试
- CISPR 11：工业设备辐射干扰

**测试场地**：
- 开阔场（OATS）
- 电波暗室
- 屏蔽室

**测试方法**：
1. 被测设备在转台上旋转
2. 天线在不同高度扫描
3. 测量各频段的辐射干扰
4. 与标准限值比较

### 20.4 干扰抑制技术

#### 20.4.1 滤波技术

**低通滤波器**：
$$H(f) = \frac{1}{\sqrt{1 + (f/f_c)^{2n}}}$$

其中$n$为滤波器阶数。

**插入损耗**：
$$IL = 20\log_{10}\frac{V_1}{V_2}$$

其中$V_1$为无滤波器时的电压，$V_2$为有滤波器时的电压。

**滤波器设计**：
- 确定截止频率
- 选择滤波器类型
- 计算元件参数
- 考虑阻抗匹配

#### 20.4.2 屏蔽技术

**屏蔽效能**：
$$SE = 20\log_{10}\frac{E_0}{E_s}$$

其中$E_0$为无屏蔽时的电场，$E_s$为有屏蔽时的电场。

**屏蔽类型**：
- 电场屏蔽：屏蔽低频电场
- 磁场屏蔽：屏蔽低频磁场
- 电磁屏蔽：屏蔽高频电磁场

**屏蔽材料**：
- 良导体：铜、铝（高频屏蔽）
- 高导磁材料：铁、镍合金（低频屏蔽）
- 导电塑料：塑料基材 + 导电填料

#### 20.4.3 接地技术

**接地类型**：
- **单点接地**：低频电路
- **多点接地**：高频电路
- **混合接地**：宽频带电路

**地线阻抗**：
$$Z_g = R_g + j\omega L_g$$

其中：
- $R_g$：地线电阻
- $L_g$：地线电感

**地线设计原则**：
- 缩短地线长度
- 增加地线宽度
- 避免地环路
- 数字地与模拟地分离

#### 20.4.4 布线技术

**PCB布线规则**：
- 电源线与地线平行布置
- 高速信号线短而直
- 避免平行走线
- 使用过孔最少化

**电缆布线**：
- 信号线与电源线分离
- 使用屏蔽电缆
- 正确端接
- 避免形成天线
