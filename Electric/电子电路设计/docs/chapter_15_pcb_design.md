# 第15章 PCB设计基础

## 15.1 PCB设计的基本流程和设计规范

### 15.1.1 PCB设计流程

PCB设计是一个系统化的工程过程，通常遵循以下步骤：

1. **需求分析和规格制定**
   - 确定功能要求
   - 定义电气特性
   - 制定性能指标
   - 约束条件分析

2. **系统架构设计**
   - 功能模块划分
   - 接口定义
   - 信号流向规划
   - 电源系统设计

3. **原理图设计**
   - 电路原理图绘制
   - 元器件选型
   - 封装定义
   - 网络表生成

4. **PCB布局设计**
   - 板层规划
   - 元器件布局
   - 走线设计
   - 规则检查

5. **仿真验证**
   - 信号完整性仿真
   - 电源完整性分析
   - EMC仿真
   - 热分析

6. **制造文件生成**
   - Gerber文件输出
   - 钻孔文件
   - 装配图
   - 制造说明

### 15.1.2 设计规范

**基本设计规范：**

- **最小线宽/线间距**：根据制造工艺能力确定
  - 内层：≥0.1mm（4mil）
  - 外层：≥0.1mm（4mil）
  
- **过孔尺寸**：
  - 最小孔径：0.2mm（8mil）
  - 最小焊盘：孔径+0.1mm

- **元件间距**：≥0.5mm（20mil）

- **板厚控制**：根据层数和用途确定
  - 4层板：1.6mm±10%
  - 6层板：1.6mm±10%

## 15.2 PCB布局原则

### 15.2.1 元器件布局

**布局原则：**

1. **功能分区**
   - 模拟电路与数字电路分离
   - 高频电路与低频电路分离
   - 大功率与小功率电路分离

2. **信号流向**
   - 遵循信号的自然流向
   - 避免信号回流
   - 减少信号交叉

3. **热管理**
   - 发热元件分散布局
   - 考虑散热通道
   - 避免热敏感器件附近放置发热器件

**布局优化策略：**

```
布局优先级：
1. 时钟电路和高速信号
2. 模拟电路
3. 数字控制电路
4. 电源电路
5. 机械连接件
```

### 15.2.2 信号走线设计

**基本走线规则：**

1. **走线宽度**
   - 电源线：宽线设计，电流密度≤2A/mm²
   - 信号线：根据电流和阻抗要求确定
   - 时钟线：尽量加粗

2. **走线间距**
   - 最小间距≥线宽
   - 高速信号间保持足够间距
   - 避免平行长距离走线

3. **走线拓扑**
   - 点对点走线
   - 星形拓扑（时钟分配）
   - 菊花链拓扑（地址/数据线）

**阻抗控制公式：**

对于微带线：
$$Z_0 = \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln\left(\frac{5.98h}{0.8w + t}\right)$$

对于带状线：
$$Z_0 = \frac{60}{\sqrt{\varepsilon_r}} \ln\left(\frac{4b}{0.67\pi(0.8w + t)}\right)$$

其中：
- $Z_0$：特性阻抗（Ω）
- $\varepsilon_r$：介质常数
- $h$：介质厚度（mm）
- $w$：线宽（mm）
- $t$：铜厚（mm）
- $b$：介质总厚度（mm）

### 15.2.3 地线设计

**地线设计原则：**

1. **单点接地**
   - 适用于低频电路
   - 避免地环路
   - 减少地线阻抗

2. **多点接地**
   - 适用于高频电路
   - 提供低阻抗回流路径
   - 减少地线电感

3. **地平面设计**
   - 连续的地平面
   - 避免地平面分割
   - 保持地平面完整性

**地线阻抗计算：**

$$Z_g = R_g + j\omega L_g$$

其中：
- $Z_g$：地线阻抗
- $R_g = \frac{\rho l}{wt}$：地线电阻
- $L_g$：地线电感
- $\rho$：电阻率
- $l$：地线长度
- $w$：地线宽度
- $t$：地线厚度

## 15.3 信号完整性分析

### 15.3.1 传输线效应

**传输线模型：**

传输线可以用分布式参数模型表示：
- 分布电阻 $R$（Ω/m）
- 分布电感 $L$（H/m）
- 分布电容 $C$（F/m）
- 分布电导 $G$（S/m）

**特性参数：**

传播常数：
$$\gamma = \alpha + j\beta = \sqrt{(R + j\omega L)(G + j\omega C)}$$

特性阻抗：
$$Z_0 = \sqrt{\frac{R + j\omega L}{G + j\omega C}}$$

**无损耗传输线：**
当 $R = G = 0$ 时：
$$Z_0 = \sqrt{\frac{L}{C}}$$
$$\beta = \omega\sqrt{LC}$$
$$\alpha = 0$$

### 15.3.2 反射分析

**反射系数：**

在阻抗不连续处，反射系数为：
$$\Gamma = \frac{Z_L - Z_0}{Z_L + Z_0}$$

其中：
- $\Gamma$：反射系数
- $Z_L$：负载阻抗
- $Z_0$：传输线特性阻抗

**传输系数：**
$$T = \frac{2Z_L}{Z_L + Z_0} = 1 + \Gamma$$

**多次反射：**

当存在多个不连续点时，需要考虑多次反射：
$$V_{total} = V_1 + \Gamma_1 V_2 + \Gamma_1 \Gamma_2 V_3 + \cdots$$

**时域反射分析（TDR）：**

传输线上的电压可以表示为：
$$V(z,t) = V^+(t - \frac{z}{v}) + V^-(t + \frac{z}{v})$$

其中：
- $V^+$：前向传播波
- $V^-$：反向传播波
- $v$：传播速度

### 15.3.3 串扰分析

**近端串扰和远端串扰：**

对于耦合传输线，串扰电压为：

近端串扰：
$$V_{NEXT}(t) = \frac{1}{4}\left(\frac{C_{mL}}{C_{L}} + \frac{L_{mL}}{L_{L}}\right)V_s(t)$$

远端串扰：
$$V_{FEXT}(t) = \frac{1}{2}\left(\frac{C_{mL}}{C_{L}} - \frac{L_{mL}}{L_{L}}\right)\frac{l}{T_r}v_p(t)$$

其中：
- $C_{mL}$：单位长度互容
- $L_{mL}$：单位长度互感
- $C_L$：单位长度对地电容
- $L_L$：单位长度对地电感
- $l$：耦合长度
- $T_r$：信号上升时间
- $v_p$：传播速度

**串扰抑制技术：**

1. **增加走线间距**
   - 3W原则：走线间距≥3倍线宽
   
2. **使用地平面**
   - 提供屏蔽
   - 减少电磁耦合

3. **差分信号设计**
   - 抗共模干扰
   - 减少对外辐射

4. **端接匹配**
   - 消除反射
   - 减少振铃

## 15.4 电磁兼容（EMC）设计原则和抑制技术

### 15.4.1 EMC基本概念

**电磁干扰三要素：**

1. **干扰源**：产生电磁干扰的源头
2. **耦合路径**：干扰传播的途径
3. **敏感设备**：受干扰影响的设备

**EMC设计目标：**
- 减少对外辐射发射
- 提高抗干扰能力
- 满足EMC标准要求

### 15.4.2 辐射发射分析

**基本辐射模型：**

1. **电偶极子辐射**：
   $$E_\theta = \frac{j\omega\mu_0 I l e^{-jkr}}{4\pi r}\sin\theta$$

2. **磁偶极子辐射**：
   $$E_\phi = \frac{j\omega\mu_0 m k e^{-jkr}}{4\pi r}\sin\theta$$

其中：
- $I$：电流
- $l$：电流长度
- $m$：磁矩
- $k = \omega\sqrt{\mu_0\varepsilon_0}$：波数

**PCB辐射机制：**

1. **差模辐射**
   - 来自信号回路
   - 频率较低
   - 辐射功率：$P_d = \frac{320\pi^4 f^4 I^2 A^2}{c^3}$

2. **共模辐射**
   - 来自不期望的电流
   - 频率较高
   - 辐射功率：$P_c = \frac{2\pi f^2 I_c^2 l^2}{3c\varepsilon_0}$

### 15.4.3 传导发射分析

**传导干扰路径：**

1. **共模传导**
   - 通过地平面传播
   - 主要影响低频段

2. **差模传导**
   - 通过电源线传播
   - 主要影响高频段

**传导发射限值：**

根据CISPR 22标准：
- 传导发射：0.15-0.5MHz，56-46dBμV
- 传导发射：0.5-5MHz，46dBμV
- 传导发射：5-30MHz，50dBμV

### 15.4.4 EMC抑制技术

**屏蔽设计：**

1. **屏蔽效能**：
   $$SE = 20\log_{10}\left(\frac{E_0}{E_s}\right) = 20\log_{10}\left(\frac{H_0}{H_s}\right)$$

2. **屏蔽材料选择**：
   - 导电性能
   - 磁导率
   - 厚度
   - 频率特性

**滤波设计：**

1. **低通滤波器**：
   $$H(j\omega) = \frac{1}{1 + j\omega RC}$$

2. **共模扼流圈**：
   - 阻抗：$Z = j\omega L$
   - 差模阻抗：较小
   - 共模阻抗：较大

3. **X/Y电容**：
   - X电容：跨接在火线与零线之间
   - Y电容：跨接在火线/零线与地之间

**接地设计：**

1. **单点接地**：适用于低频
2. **多点接地**：适用于高频
3. **混合接地**：结合两者优点

**PCB布局EMC优化：**

1. **最小化电流回路面积**
2. **控制高速信号走线**
3. **合理放置去耦电容**
4. **避免地平面分割**

## 15.5 电源完整性设计

### 15.5.1 电源分配网络（PDN）

**PDN组成要素：**

1. **电源源头**：DC-DC转换器、LDO等
2. **电源平面**：PCB上的电源层
3. **去耦电容**：提供瞬态电流
4. **负载**：各种芯片和电路

**PDN阻抗模型：**

$$Z_{PDN}(j\omega) = Z_{source} + Z_{plane} + Z_{decoupling}$$

其中：
- $Z_{source}$：电源源头阻抗
- $Z_{plane}$：电源平面阻抗
- $Z_{decoupling}$：去耦网络阻抗

**目标阻抗：**

$$Z_{target} = \frac{V_{dd} \times ripple\_factor}{I_{max}}$$

其中：
- $V_{dd}$：电源电压
- $ripple\_factor$：电压纹波系数（通常5%）
- $I_{max}$：最大瞬态电流

### 15.5.2 去耦电容设计

**去耦电容作用：**

1. **提供瞬态电流**
2. **降低电源阻抗**
3. **抑制电源噪声**

**去耦电容等效模型：**

$$Z_c(j\omega) = R_{ESR} + j\omega L_{ESL} + \frac{1}{j\omega C}$$

自谐振频率：
$$f_{SRF} = \frac{1}{2\pi\sqrt{L_{ESL}C}}$$

**多值去耦策略：**

1. **大容量电容**（10μF-100μF）
   - 低频去耦
   - 大电容值
   - 较高ESL

2. **中容量电容**（1μF-10μF）
   - 中频去耦
   - 平衡容值和ESL

3. **小容量电容**（0.01μF-1μF）
   - 高频去耦
   - 低ESL
   - 贴近IC放置

**去耦电容放置原则：**

1. **贴近芯片电源引脚**
2. **最短的回流路径**
3. **避免过孔串联**
4. **对称放置**

**去耦电容网络阻抗计算：**

$$Z_{total}(f) = \frac{1}{\sum_{i=1}^{n}\frac{1}{Z_i(f)}}$$

其中 $Z_i(f)$ 为各个去耦电容的阻抗。

### 15.5.3 电源平面设计

**电源平面阻抗：**

对于矩形电源平面：
$$Z_{plane} = \frac{\eta d}{w l \sigma} + j\omega\frac{\mu_0 d}{3w l}$$

其中：
- $\eta = \sqrt{\frac{\mu_0}{\varepsilon_0\varepsilon_r}}$：本征阻抗
- $d$：介质厚度
- $w$：平面宽度
- $l$：平面长度
- $\sigma$：电导率

**电源平面分割：**

1. **模拟/数字电源分离**
2. **不同电压域分离**
3. **敏感电路隔离**

**过孔设计：**

过孔电感：
$$L_{via} = 5.08h\left[\ln\left(\frac{4h}{d}\right) + 1\right]$$

其中：
- $h$：过孔长度
- $d$：过孔直径

## 15.6 高速数字电路设计注意事项

### 15.6.1 高速信号特性

**高速信号定义：**

当信号上升时间 $T_r$ 与传输线传播延迟 $T_{pd}$ 满足：
$$T_r \leq 4T_{pd}$$
或
$$f_{knee} = \frac{0.35}{T_r} \geq \frac{c}{4l\sqrt{\varepsilon_r}}$$

其中：
- $f_{knee}$：信号有效带宽
- $c$：光速
- $l$：走线长度

**传输线效应：**

1. **集肤效应**：
   有效穿透深度：
   $$\delta = \sqrt{\frac{2\rho}{\omega\mu}}$$

2. **介质损耗**：
   $$\alpha_d = \frac{\omega\sqrt{\mu\varepsilon}}{2c}\tan\delta$$

### 15.6.2 时钟信号设计

**时钟分配网络：**

1. **树形拓扑**：
   - 平衡负载
   - 最小延迟偏差
   - 适用于低频

2. **H树拓扑**：
   - 几何对称
   - 延迟匹配
   - 适用于高频

**时钟抖动控制：**

相位抖动：
$$J_{phase} = \frac{V_n}{Slew\_Rate}$$

其中：
- $V_n$：噪声电压
- $Slew\_Rate$：信号压摆率

### 15.6.3 差分信号设计

**差分阻抗计算：**

对于边沿耦合微带线：
$$Z_{diff} = 2Z_0\left(1 - 0.48e^{-0.96\frac{s}{h}}\right)$$

其中：
- $Z_0$：单端特性阻抗
- $s$：差分对间距
- $h$：介质厚度

**差分信号优势：**

1. **抗共模干扰**
2. **减少电磁辐射**
3. **提高信号质量**

### 15.6.4 高速连接器设计

**连接器电气特性：**

1. **特性阻抗**：保持连续性
2. **插入损耗**：$S_{21} = -20\log_{10}\left|\frac{V_{out}}{V_{in}}\right|$
3. **回波损耗**：$RL = -20\log_{10}|\Gamma|$
4. **串扰**：NEXT、FEXT

**连接器设计原则：**

1. **阻抗匹配**
2. **信号完整性**
3. **机械可靠性**
4. **制造工艺性**

## 15.7 PCB制造工艺和成本控制

### 15.7.1 PCB制造工艺

**基本制造流程：**

1. **内层制作**
   - 覆铜板裁剪
   - 钻孔定位
   - 图形转移
   - 蚀刻

2. **层压**
   - 内层氧化处理
   - 预浸料叠放
   - 高温高压层压

3. **钻孔**
   - 机械钻孔
   - 激光钻孔
   - 孔金属化

4. **外层制作**
   - 图形转移
   - 蚀刻
   - 阻焊制作
   - 字符印刷

**关键工艺参数：**

1. **线宽/线间距控制**
   - 最小线宽：0.1mm（4mil）
   - 最小间距：0.1mm（4mil）
   - 精度：±0.02mm

2. **孔径控制**
   - 机械钻孔：≥0.2mm
   - 激光钻孔：≥0.1mm
   - 精度：±0.05mm

3. **层压厚度**
   - 标准厚度：1.6mm
   - 精度：±10%

### 15.7.2 表面处理工艺

**常见表面处理：**

1. **HASL（热风整平）**
   - 成本低
   - 可焊性好
   - 表面不平整

2. **ENIG（化学镍金）**
   - 表面平整
   - 可焊性优异
   - 成本较高

3. **OSP（有机可焊性保护剂）**
   - 环保
   - 成本适中
   - 存储要求高

4. **ImAg（化学镀银）**
   - 成本适中
   - 可焊性好
   - 易氧化

### 15.7.3 成本控制策略

**设计阶段成本控制：**

1. **板层数优化**
   - 4层板 vs 6层板
   - 成本增加约50-80%

2. **最小线宽/间距**
   - 4mil vs 6mil
   - 成本增加约20-30%

3. **板尺寸优化**
   - 利用率最大化
   - 拼板设计

4. **孔径优化**
   - 减少特殊孔径
   - 统一孔径规格

**制造阶段成本控制：**

1. **批量生产**
   - 降低单位成本
   - 减少开机费

2. **标准工艺**
   - 使用常规工艺
   - 避免特殊要求

3. **交期优化**
   - 标准交期 vs 加急
   - 成本差异可达50%

**成本估算公式：**

$$Cost = Base\_Cost \times Size\_Factor \times Layer\_Factor \times Process\_Factor$$

其中：
- $Size\_Factor = \frac{Area}{Standard\_Area}$
- $Layer\_Factor = 1 + 0.5 \times (Layers - 2)$
- $Process\_Factor$：工艺复杂度系数

## 15.8 设计检查和验证方法

### 15.8.1 设计规则检查（DRC）

**基本DRC规则：**

1. **间距检查**
   - 走线间距 ≥ 最小间距
   - 过孔间距 ≥ 最小间距
   - 元件间距 ≥ 最小间距

2. **宽度检查**
   - 走线宽度 ≥ 最小宽度
   - 电源线宽度 ≥ 最小宽度
   - 焊盘宽度 ≥ 最小宽度

3. **孔径检查**
   - 过孔孔径 ≥ 最小孔径
   - 焊盘环宽 ≥ 最小环宽
   - 钻孔到走线距离 ≥ 最小距离

**高级DRC规则：**

1. **阻抗控制**
   - 微带线阻抗范围
   - 带状线阻抗范围
   - 差分阻抗匹配

2. **长度匹配**
   - 时钟线长度匹配
   - 差分对长度匹配
   - 总线长度匹配

3. **拓扑规则**
   - 菊花链拓扑检查
   - 星形拓扑检查
   - 避免stub检查

### 15.8.2 电气规则检查（ERC）

**ERC检查项目：**

1. **电源网络检查**
   - 电源引脚连接
   - 电源网络完整性
   - 电源域隔离

2. **信号完整性检查**
   - 未连接引脚
   - 重复连接
   - 冲突驱动

3. **模拟/数字混合**
   - 模拟数字隔离

## 15.9 本章小结

PCB设计是一个复杂的系统工程，需要综合考虑电气性能、机械结构、制造工艺和成本控制等多个方面。本章重点介绍了：

1. **信号完整性**：传输线效应、反射、串扰的分析方法和抑制技术
2. **EMC设计**：辐射发射、传导发射的机理和抑制方法
3. **电源完整性**：PDN设计、去耦电容选择和优化
4. **高速设计**：时钟分配、差分信号、连接器设计
5. **制造工艺**：工艺能力、成本控制、验证方法

良好的PCB设计需要扎实的理论基础、丰富的工程经验和系统化的设计方法。随着电子系统工作频率的不断提高，信号完整性和EMC设计的重要性日益凸显，需要设计工程师具备全面的理论知识和实践能力。
