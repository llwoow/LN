# 第十一章 稳压电源

## 11.1 稳压电源的基本原理和分类

### 11.1.1 稳压电源的基本原理

稳压电源是一种能够提供稳定直流电压的电源设备，其基本工作原理是通过反馈控制机制，使输出电压在输入电压变化、负载变化或环境温度变化的情况下保持恒定。

稳压电源的核心组成包括：
1. **电压调整元件**：根据控制信号调整输出电压
2. **比较放大器**：比较参考电压与输出电压，产生误差信号
3. **参考电压源**：提供稳定的基准电压
4. **反馈网络**：将输出电压的一部分反馈到比较放大器

基本的稳压原理可以用以下数学模型表示：

设输入电压为 $V_{in}$，输出电压为 $V_{out}$，参考电压为 $V_{ref}$，反馈系数为 $\beta$，则：

$$\beta V_{out} = V_{ref}$$

$$V_{out} = \frac{V_{ref}}{\beta}$$

### 11.1.2 稳压电源的分类

根据工作原理和电路结构，稳压电源主要分为以下几类：

#### 1. 按调整元件的工作方式分类

**线性稳压器**
- 串联型线性稳压器
- 并联型线性稳压器

**开关稳压器**
- 降压型（Buck）
- 升压型（Boost）
- 反转型（Buck-Boost）
- 隔离型（Flyback、Forward等）

#### 2. 按稳压方式分类

**连续调节式稳压器**
- 模拟控制
- 线性调节

**开关调节式稳压器**
- 脉冲宽度调制（PWM）
- 脉冲频率调制（PFM）
- 混合调制

## 11.2 线性稳压器

### 11.2.1 串联型线性稳压器

#### 工作原理

串联型线性稳压器通过一个串联的调整管来控制输出电压。当输出电压变化时，调整管的导通程度随之变化，从而维持输出电压稳定。

基本电路结构如图所示，主要包括：
- 调整管（通常为晶体管或MOSFET）
- 误差放大器
- 参考电压源
- 分压反馈网络

#### 电路分析

设调整管的压降为 $V_{CE}$，则：

$$V_{out} = V_{in} - V_{CE}$$

误差放大器的输出电压为：

$$V_{control} = A_v(V_{ref} - \beta V_{out})$$

其中 $A_v$ 为误差放大器的电压增益，$\beta = \frac{R_2}{R_1 + R_2}$ 为反馈系数。

#### 设计参数计算

**输出电压设计**

$$V_{out} = V_{ref} \left(1 + \frac{R_1}{R_2}\right)$$

**调整管功耗**

$$P_D = (V_{in} - V_{out}) \times I_{out}$$

**效率计算**

$$\eta = \frac{V_{out} \times I_{out}}{V_{in} \times I_{in}} = \frac{V_{out}}{V_{in}}$$

由于串联型稳压器的输入电流等于输出电流，效率主要由输入输出电压比决定。

### 11.2.2 并联型线性稳压器

#### 工作原理

并联型线性稳压器通过一个并联的调整元件来控制输出电压。当输出电压升高时，调整管的导通电流增加，从而消耗更多的电流，维持输出电压稳定。

#### 电路分析

并联型稳压器的基本关系：

$$I_{in} = I_{out} + I_{shunt}$$

其中 $I_{shunt}$ 为并联调整管的电流。

输出电压的稳定性通过调整 $I_{shunt}$ 来实现：

$$V_{out} = V_{ref} + I_{shunt} \times R_s$$

#### 优缺点分析

**优点：**
- 短路保护性能好
- 适合低电压、小电流应用
- 电路简单

**缺点：**
- 功耗较大，效率低
- 不适合大电流应用
- 负载电流变化范围有限

### 11.2.3 线性稳压器的设计要点

#### 散热设计

调整管的最大功耗：

$$P_{D(max)} = (V_{in(max)} - V_{out(min)}) \times I_{out(max)}$$

所需散热器的热阻：

$$R_{\theta} = \frac{T_j(max) - T_a(max)}{P_{D(max)}} - R_{\theta JC} - R_{\theta CS}$$

其中：
- $T_j(max)$：最大结温
- $T_a(max)$：最高环境温度
- $R_{\theta JC}$：结到壳的热阻
- $R_{\theta CS}$：壳到散热器的热阻

#### 稳定性补偿

为保证系统稳定，需要进行频率补偿。补偿电容的计算：

$$C_c \geq \frac{1}{2\pi f_{unity} \times R_{out}}$$

其中 $f_{unity}$ 为单位增益频率，$R_{out}$ 为输出阻抗。

## 11.3 开关稳压器

### 11.3.1 降压型开关稳压器（Buck）

#### 工作原理

降压型开关稳压器通过控制开关管的导通和关断时间，在电感中产生脉动的电流，再通过滤波电容平滑后得到稳定的直流输出电压。

#### PWM控制原理

设开关周期为 $T_s$，导通时间为 $T_{on}$，则占空比为：

$$D = \frac{T_{on}}{T_s}$$

输出电压与输入电压的关系：

$$V_{out} = D \times V_{in}$$

#### 电路分析

**电感电流**

连续导通模式（CCM）下的电感电流：

$$I_L = I_{out} + \frac{\Delta I_L}{2}$$

其中纹波电流：

$$\Delta I_L = \frac{(V_{in} - V_{out}) \times T_{on}}{L}$$

**电容设计**

输出电容的纹波电压：

$$\Delta V_{ripple} = \frac{\Delta I_L}{8 \times f_s \times C_{out}}$$

其中 $f_s = \frac{1}{T_s}$ 为开关频率。

### 11.3.2 升压型开关稳压器（Boost）

#### 工作原理

升压型开关稳压器通过电感储能和电容放电的原理，将输入电压提升到更高的输出电压。

#### 电压关系

在CCM模式下，输出电压与输入电压的关系：

$$V_{out} = \frac{V_{in}}{1 - D}$$

其中 $D$ 为占空比。

#### 电路参数设计

**电感设计**

电感值应满足：

$$L \geq \frac{V_{in} \times D}{f_s \times \Delta I_L}$$

**电容设计**

输出电容应满足：

$$C_{out} \geq \frac{I_{out} \times D}{f_s \times \Delta V_{ripple}}$$

### 11.3.3 反转型开关稳压器（Buck-Boost）

#### 工作原理

反转型开关稳压器可以产生与输入电压极性相反的输出电压，既可以升压也可以降压。

#### 电压关系

输出电压与输入电压的关系：

$$V_{out} = -\frac{D}{1 - D} \times V_{in}$$

### 11.3.4 PWM控制技术

#### 电压模式控制

电压模式控制是最简单的PWM控制方式，通过检测输出电压来调制占空比。

控制框图的传递函数：

$$G(s) = \frac{V_{out}}{V_{control}} = \frac{V_{in} \times A_{EA}}{1 + s \times \frac{L}{R_{load}}}$$

其中 $A_{EA}$ 为误差放大器的增益。

#### 电流模式控制

电流模式控制同时检测输出电流和电压，具有更好的动态响应。

电流环的传递函数：

$$G_i(s) = \frac{R_s}{1 + s \times \frac{L}{R_{load}}}$$

其中 $R_s$ 为电流检测电阻。

#### 补偿网络设计

补偿网络通常采用Type II或Type III补偿器：

**Type II补偿器**

传递函数：

$$G_c(s) = \frac{K}{s} \times \frac{1 + s \times R_2 \times C_1}{1 + s \times R_1 \times C_1}$$

**穿越频率**

$$f_c = \frac{f_s}{10} \sim \frac{f_s}{5}$$

**相位裕度**

$$\phi_m = 45^\circ \sim 60^\circ$$

## 11.4 稳压器的性能指标

### 11.4.1 稳压系数

稳压系数表示输入电压变化时，输出电压保持稳定的能力。

#### 绝对稳压系数

$$S_v = \frac{\Delta V_{out}/V_{out}}{\Delta V_{in}/V_{in}}$$

#### 相对稳压系数

$$S_v = \frac{\Delta V_{out}}{\Delta V_{in}} \times \frac{V_{in}}{V_{out}}$$

对于线性稳压器：

$$S_v \approx \frac{1}{\beta \times A_{OL}}$$

其中 $A_{OL}$ 为开环增益。

### 11.4.2 输出阻抗

输出阻抗表示负载电流变化时，输出电压的抗干扰能力。

#### 直流输出阻抗

$$Z_{out} = \frac{R_{out}}{1 + A_{OL} \times \beta}$$

其中 $R_{out}$ 为调整管的输出电阻。

#### 交流输出阻抗

在高频时：

$$Z_{out}(j\omega) = \frac{R_{out}}{1 + A_{OL}(j\omega) \times \beta}$$

### 11.4.3 纹波系数

纹波系数表示输出电压中交流分量的大小。

#### 纹波电压

$$V_{ripple} = \frac{I_{ripple}}{2\pi f_{ripple} \times C_{out}}$$

#### 纹波系数

$$\gamma = \frac{V_{ripple}}{V_{dc}} \times 100\%$$

### 11.4.4 效率

效率是衡量稳压器性能的重要指标。

#### 线性稳压器效率

$$\eta = \frac{V_{out} \times I_{out}}{V_{in} \times I_{in}} = \frac{V_{out}}{V_{in}}$$

#### 开关稳压器效率

$$\eta = \frac{P_{out}}{P_{in}} = \frac{V_{out} \times I_{out}}{V_{in} \times I_{in} + P_{switch} + P_{gate} + P_{core}}$$

其中：
- $P_{switch}$：开关损耗
- $P_{gate}$：栅极驱动损耗
- $P_{core}$：磁芯损耗

**开关损耗计算**

$$P_{switch} = \frac{1}{2} \times V_{ds} \times I_{ds} \times f_s \times (t_r + t_f)$$

其中 $t_r$ 和 $t_f$ 分别为上升时间和下降时间。

## 11.5 滤波电路的设计

### 11.5.1 电容滤波

#### 单电容滤波

对于半波整流电路：

$$V_{dc} = V_{peak} - \frac{I_{dc}}{4fC}$$

纹波电压：

$$V_{ripple} = \frac{I_{dc}}{fC}$$

对于全波整流电路：

$$V_{dc} = V_{peak} - \frac{I_{dc}}{2fC}$$

$$V_{ripple} = \frac{I_{dc}}{2fC}$$

#### π型滤波

π型滤波器的传递函数：

$$H(s) = \frac{1}{1 + sR_1C_1 + s^2L_1C_1 + s^3R_1L_1C_1}$$

### 11.5.2 电感滤波

#### 电感滤波的特性

电感对直流分量阻抗很小，对交流分量阻抗很大：

$$X_L = 2\pi fL$$

纹波抑制比：

$$\frac{V_{ripple(out)}}{V_{ripple(in)}} = \frac{R_{load}}{X_L}$$

### 11.5.3 LC滤波

#### LC滤波器的设计

二阶LC滤波器的传递函数：

$$H(s) = \frac{1}{LCs^2 + RCs + 1}$$

谐振频率：

$$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

品质因数：

$$Q = \frac{\sqrt{L/C}}{R}$$

#### 滤波器的选择标准

**截止频率**

$$f_c = \frac{1}{2\pi\sqrt{LC}}$$

**阻带衰减**

在阻带内，衰减为：

$$\alpha = 20\log\left|\frac{V_{in}}{V_{out}}\right| = 40\log\left(\frac{f}{f_c}\right) - 20\log\left(\frac{R}{\sqrt{L/C}}\right)$$

### 11.5.4 有源滤波

#### 运算放大器滤波

一阶有源低通滤波器：

$$H(s) = \frac{K}{1 + sRC}$$

其中 $K = 1 + \frac{R_f}{R_1}$ 为增益。

二阶有源滤波器：

$$H(s) = \frac{K\omega_0^2}{s^2 + \frac{\omega_0}{Q}s + \omega_0^2}$$

其中：
- $\omega_0 = \frac{1}{\sqrt{R_1R_2C_1C_2}}$
- $Q = \sqrt{\frac{R_2C_2}{R_1C_1}}$

## 11.6 保护电路

### 11.6.1 过流保护

#### 电流检测方法

**电阻检测法**

检测电阻上的压降：

$$V_{sense} = I_{load} \times R_{sense}$$

保护阈值：

$$I_{limit} = \frac{V_{ref}}{R_{sense}}$$

**霍尔传感器检测**

输出电压与电流的关系：

$$V_{out} = K \times I_{load}$$

其中 $K$ 为霍尔传感器的灵敏度。

#### 限流电路设计

**线性限流**

限流电阻：

$$R_{limit} = \frac{V_{control} - V_{be}}{I_{limit}}$$

其中 $V_{be}$ 为三极管的基极-发射极电压。

**开关限流**

滞回比较器的阈值：

$$V_{th+} = V_{ref} + \frac{V_{hysteresis}}{2}$$

$$V_{th-} = V_{ref} - \frac{V_{hysteresis}}{2}$$

### 11.6.2 过压保护

#### 齐纳二极管保护

齐纳二极管的击穿电压：

$$V_Z = V_{Z0} + \alpha \times (T - T_0)$$

其中 $\alpha$ 为温度系数。

保护电压：

$$V_{protection} = V_Z + I_Z \times R_{series}$$

#### 晶闸管保护

晶闸管的触发条件：

$$V_{AK} \geq V_{BO} \quad \text{或} \quad I_G \geq I_{GT}$$

其中：
- $V_{BO}$：击穿电压
- $I_G$：门极电流
- $I_{GT}$：门极触发电流

### 11.6.3 过热保护

#### 温度检测

**热敏电阻**

电阻值与温度的关系：

$$R_T = R_0 \times e^{\beta(\frac{1}{T} - \frac{1}{T_0})}$$

其中 $\beta$ 为热敏电阻的材料常数。

**PN结温度传感器**

PN结的正向压降：

$$V_{BE} = \frac{kT}{q} \ln\left(\frac{I_C}{I_S}\right)$$

温度系数：

$$\frac{dV_{BE}}{dT} \approx -2mV/^\circ C$$

#### 温度保护电路

比较器阈值电压：

$$V_{th} = V_{BE} + \Delta V_{BE}$$

其中 $\Delta V_{BE}$ 为温度补偿电压。

## 11.7 稳压电源的设计实例和参数计算

### 11.7.1 设计要求

设计一个线性稳压器，要求如下：
- 输入电压：$V_{in} = 15V \pm 20\%$
- 输出电压：$V_{out} = 5V$
- 输出电流：$I_{out(max)} = 1A$
- 稳压系数：$S_v < 0.01$
- 纹波系数：$< 0.1\%$
- 效率：$\eta > 30\%$

### 11.7.2 线性稳压器设计

#### 调整管选择

**功耗计算**

$$P_D(max) = (V_{in(max)} - V_{out}) \times I_{out(max)}$$

$$P_D(max) = (18 - 5) \times 1 = 13W$$

选择功率晶体管，要求：
- $V_{CEO} > 25V$
- $I_C > 2A$
- $P_C > 20W$
- $h_{FE} > 20$

#### 误差放大器设计

**开环增益要求**

$$A_{OL} \geq \frac{1}{\beta \times S_v}$$

设反馈系数 $\beta = 0.2$，则：

$$A_{OL} \geq \frac{1}{0.2 \times 0.01} = 500$$

选择运算放大器，要求开环增益 $> 1000$，失调电压 $< 1mV$。

#### 反馈网络设计

**分压电阻计算**

设参考电压 $V_{ref} = 1.25V$，则：

$$\frac{R_1}{R_2} = \frac{V_{out}}{V_{ref}} - 1 = \frac{5}{1.25} - 1 = 3$$

选择 $R_2 = 10k\Omega$，则 $R_1 = 30k\Omega$。

#### 散热设计

**散热器热阻计算**

设最高环境温度 $T_a = 50^\circ C$，最大结温 $T_j = 125^\circ C$，结到壳热阻 $R_{\theta JC} = 2^\circ C/W$，则：

$$R_{\theta} = \frac{125 - 50}{13} - 2 = 3.77^\circ C/W$$

选择热阻 $< 3^\circ C/W$ 的散热器。

### 11.7.3 开关稳压器设计实例

设计一个降压型开关稳压器：
- 输入电压：$V_{in} = 12V \pm 10\%$
- 输出电压：$V_{out} = 5V$
- 输出电流：$I_{out} = 2A$
- 开关频率：$f_s = 100kHz$
- 纹波系数：$< 0.5\%$

#### 电感设计

**纹波电流计算**

设纹波电流为输出电流的20%：

$$\Delta I_L = 0.2 \times I_{out} = 0.4A$$

**电感值计算**

$$L = \frac{(V_{in} - V_{out}) \times D}{\Delta I_L \times f_s}$$

占空比 $D = \frac{V_{out}}{V_{in}} = \frac{5}{12} = 0.417$

$$L = \frac{(12 - 5) \times 0.417}{0.4 \times 100 \times 10^3} = 73\mu H$$

选择标准值 $L = 100\mu H$。

#### 电容设计

**输出电容计算**

纹波电压要求：

$$\Delta V_{ripple} = 0.005 \times 5 = 25mV$$

$$C_{out} = \frac{\Delta I_L}{8 \times f_s \times \Delta V_{ripple}}$$

$$C_{out} = \frac{0.4}{8 \times 100 \times 10^3 \times 0.025} = 20\mu F$$

选择 $C_{out} = 47\mu F$，考虑ESR影响。

#### 开关管选择

**电流应力**

$$I_{DS(max)} = I_{out} + \frac{\Delta I_L}{2} = 2 + 0.2 = 2.2A$$

**电压应力**

$$V_{DS(max)} = V_{in(max)} = 13.2V$$

选择MOSFET，要求：
- $V_{DS} > 30V$
- $I_D > 5A$
- $R_{DS(on)} < 50m\Omega$

### 11.7.4 性能验证

#### 稳压系数测试

测试条件：$V_{in}$ 从 $10V$ 到 $15V$ 变化，$I_{out} = 1A$

$$S_v = \frac{\Delta V_{out}/V_{out}}{\Delta V_{in}/V_{in}}$$

#### 负载调整率测试

测试条件：$V_{in} = 12V$，$I_{out}$ 从 $0$ 到 $1A$ 变化

$$负载调整率 = \frac{V_{out(0A)} - V_{out(1A)}}{V_{out(0A)}} \times 100\%$$

#### 效率测试

$$\eta = \frac{V_{out} \times I_{out}}{V_{in} \times I_{in}} \times 100\%$$

## 11.8 线性稳压器与开关稳压器的比较

### 11.8.1 性能对比

| 性能指标 | 线性稳压器 | 开关稳压器 |
|---------|------------|------------|
| 效率 | 低（30-60%） | 高（70-95%） |
| 纹波 | 很小 | 较大 |
| 噪声 | 很小 | 较大 |
| 复杂度 | 简单 | 复杂 |
| 成本 | 低 | 较高 |
| 体积 | 较大 | 较小 |
| 响应速度 | 快 | 较慢 |

### 11.8.2 应用场合

#### 线性稳压器的应用

**适用场合：**
- 对纹波和噪声要求严格的模拟电路
- 低噪声射频电路
- 简单的稳压应用
- 小电流应用（<1A）

**典型应用：**
- 精密测量仪器
- 音频放大器
- 射频前端
- 基准电压源

#### 开关稳压器的应用

**适用场合：**
- 对效率要求较高的应用
- 大电流应用（>1A）
- 输入输出电压差较大的场合
- 体积和重量受限的便携设备

**典型应用：**
- 计算机电源
- 通信设备
- 工业控制
- 电动工具

### 11.8.3 设计权衡

#### 效率vs噪声

线性稳压器：
- 效率：$\eta = \frac{V_{out}}{V_{in}}$
- 噪声：$< 10\mu V_{rms}$

开关稳压器：
- 效率：$\eta > 80\%$
- 噪声：$1-10mV_{rms}$

#### 成本vs性能

**线性稳压器**
- 成本：$0.1-1美元$
- 性能：低噪声，高稳定度

**开关稳压器**
- 成本：$1-10美元$
- 性能：高效率，小体积

### 11.8.4 混合拓扑

#### 两级降压方案

第一级：开关稳压器（高效率）
$$V_{intermediate} = V_{out} + 2V$$

第二级：线性稳压器（低噪声）
$$V_{out} = V_{ref} \left(1 + \frac{R_1}{R_2}\right)$$

**整体效率**

$$\eta_{total} = \eta_{switch} \times \eta_{linear} = \eta_{switch} \times \frac{V_{out}}{V_{intermediate}}$$

#### 性能优化

通过合理设计两级电源，可以同时获得：
- 高效率（>80%）
- 低噪声（<100μV）
- 良好的负载瞬态响应

## 11.9 小结

稳压电源是电子系统的重要组成部分，其设计需要综合考虑效率、噪声、成本、体积等多个因素。

**主要知识点：**

1. **线性稳压器**：
   - 工作原理简单，噪声低
   - 效率等于 $V_{out}/V_{in}$
   - 适合低噪声应用

2. **开关稳压器**：
   - 效率高，体积小
   - 存在开关噪声
   - 适合大电流应用

3. **设计要点**：
   - 正确的器件选择
   - 合理的参数计算
   - 充分的散热设计
   - 完善的保护电路

4. **性能指标**：
   - 稳压系数：衡量稳压能力
   - 输出阻抗：衡量负载调整能力
   - 纹波系数：衡量输出质量
   - 效率：衡量能量利用率

通过本章的学习，读者应能够根据具体应用需求，合理选择稳压器类型，并进行完整的设计计算。
