# 第9章 有源滤波器

## 9.1 滤波器的基本概念和分类

### 9.1.1 滤波器的基本概念

滤波器是一种能够选择性地通过或抑制特定频率信号的电路。它在信号处理、通信系统、测量仪器等领域有着广泛的应用。滤波器的基本功能是：

- **频率选择**：允许特定频率范围内的信号通过
- **信号整形**：改变信号的频率特性
- **噪声抑制**：减少不需要的频率分量

### 9.1.2 滤波器的分类

根据频率响应特性，滤波器主要分为以下四类：

#### 1. 低通滤波器（Low-Pass Filter, LPF）
低通滤波器允许低频信号通过，抑制高频信号。其理想频率响应为：

$$H(j\omega) = \begin{cases}
1 & \text{for } |\omega| < \omega_c \\
0 & \text{for } |\omega| > \omega_c
\end{cases}$$

其中 $\omega_c$ 为截止角频率。

#### 2. 高通滤波器（High-Pass Filter, HPF）
高通滤波器允许高频信号通过，抑制低频信号。其理想频率响应为：

$$H(j\omega) = \begin{cases}
0 & \text{for } |\omega| < \omega_c \\
1 & \text{for } |\omega| > \omega_c
\end{cases}$$

#### 3. 带通滤波器（Band-Pass Filter, BPF）
带通滤波器允许某一频段内的信号通过，抑制该频段之外的信号。其理想频率响应为：

$$H(j\omega) = \begin{cases}
1 & \text{for } \omega_1 < |\omega| < \omega_2 \\
0 & \text{otherwise}
\end{cases}$$

其中 $\omega_1$ 和 $\omega_2$ 分别为下截止频率和上截止频率。

#### 4. 带阻滤波器（Band-Stop Filter, BSF）
带阻滤波器抑制某一频段内的信号，允许该频段之外的信号通过。其理想频率响应为：

$$H(j\omega) = \begin{cases}
0 & \text{for } \omega_1 < |\omega| < \omega_2 \\
1 & \text{otherwise}
\end{cases}$$

### 9.1.3 滤波器的数学表示

滤波器的特性通常用传递函数来描述。对于连续时间系统，传递函数的一般形式为：

$$H(s) = \frac{b_m s^m + b_{m-1} s^{m-1} + \cdots + b_1 s + b_0}{a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0}$$

其中 $s = j\omega$ 是复频率变量。

## 9.2 一阶有源滤波器的设计

### 9.2.1 一阶有源低通滤波器

#### 电路结构
一阶有源低通滤波器的基本电路结构如图所示：

```
    R1
   ───┬───
      │
Vin ──┤+\
      │  >─── Vout
      │-/
   R2
   ───┬───
      │
     GND
```

#### 传递函数推导

对于运算放大器构成的同相放大器，其增益为：

$$A_v = 1 + \frac{R_2}{R_1}$$

当在反馈回路中加入电容C时，电路变为低通滤波器。设反馈阻抗为 $Z_f$，则：

$$Z_f = R_2 \parallel \frac{1}{sC} = \frac{R_2}{1 + sR_2C}$$

因此，传递函数为：

$$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \left(1 + \frac{R_2}{R_1}\right) \frac{1}{1 + sR_2C}$$

令 $A_v = 1 + \frac{R_2}{R_1}$，$\tau = R_2C$，则：

$$H(s) = A_v \frac{1}{1 + s\tau}$$

#### 频率特性分析

将 $s = j\omega$ 代入，得到频率响应：

$$H(j\omega) = A_v \frac{1}{1 + j\omega\tau}$$

幅度响应：

$$|H(j\omega)| = A_v \frac{1}{\sqrt{1 + (\omega\tau)^2}}$$

相位响应：

$$\phi(\omega) = -\arctan(\omega\tau)$$

#### 截止频率

当 $\omega = \frac{1}{\tau} = \frac{1}{R_2C}$ 时：

$$|H(j\omega_c)| = \frac{A_v}{\sqrt{2}} = 0.707A_v$$

因此，截止频率为：

$$f_c = \frac{1}{2\pi R_2C}$$

### 9.2.2 一阶有源高通滤波器

#### 电路结构
一阶有源高通滤波器的基本电路结构：

```
    C1
   ───┬───
      │
Vin ──┤+\
      │  >─── Vout
      │-/
   R2
   ───┬───
      │
     GND
```

#### 传递函数推导

对于高通滤波器，输入信号通过电容C1耦合到运算放大器的同相输入端。输入阻抗为：

$$Z_{in} = \frac{1}{sC_1}$$

反馈网络为电阻R2，因此：

$$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \frac{sR_2C_1}{1 + sR_2C_1}$$

令 $\tau = R_2C_1$，则：

$$H(s) = \frac{s\tau}{1 + s\tau}$$

#### 频率特性分析

频率响应为：

$$H(j\omega) = \frac{j\omega\tau}{1 + j\omega\tau}$$

幅度响应：

$$|H(j\omega)| = \frac{\omega\tau}{\sqrt{1 + (\omega\tau)^2}}$$

相位响应：

$$\phi(\omega) = 90^\circ - \arctan(\omega\tau)$$

#### 截止频率

截止频率与低通滤波器相同：

$$f_c = \frac{1}{2\pi R_2C_1}$$

## 9.3 二阶有源滤波器

### 9.3.1 二阶滤波器的标准形式

二阶滤波器的传递函数一般形式为：

$$H(s) = \frac{K\omega_n^2}{s^2 + \frac{\omega_n}{Q}s + \omega_n^2}$$

其中：
- $\omega_n$ 为自然频率（无阻尼振荡频率）
- $Q$ 为品质因数
- $K$ 为增益常数

### 9.3.2 巴特沃斯滤波器

#### 特点
巴特沃斯滤波器（Butterworth Filter）具有最平坦的通带响应。其幅度响应为：

$$|H(j\omega)| = \frac{1}{\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^{2n}}}$$

其中 $n$ 为滤波器阶数。

#### 二阶巴特沃斯低通滤波器

对于二阶巴特沃斯低通滤波器：
- $Q = \frac{1}{\sqrt{2}} \approx 0.707$
- 传递函数为：

$$H(s) = \frac{K\omega_c^2}{s^2 + \sqrt{2}\omega_c s + \omega_c^2}$$

#### 电路实现 - 多重反馈型（MFB）

```
        R1      R2
    Vin ──┬─────┬─────
          │     │
         C1    R3
          │     │
          └─────┤-\
                │  >─── Vout
                │+/
               GND
          C2
          │
         GND
```

传递函数推导：

反馈阻抗为：
$$Z_f = \frac{R_3}{1 + sR_3C_2}$$

输入阻抗为：
$$Z_{in} = R_1 + \frac{1}{sC_1}$$

利用节点电流定律和运算放大器的虚短特性，可得：

$$H(s) = -\frac{R_3/R_1}{s^2R_1R_3C_1C_2 + sR_1C_1 + 1}$$

令 $R_1 = R_2 = R$，$C_1 = C_2 = C$，则：

$$H(s) = -\frac{R/R}{s^2R^2C^2 + sRC + 1} = -\frac{1}{s^2R^2C^2 + sRC + 1}$$

与标准形式比较：
- $\omega_n = \frac{1}{RC}$
- $Q = \frac{1}{\sqrt{2}}$
- $K = -1$

### 9.3.3 切比雪夫滤波器

#### 特点
切比雪夫滤波器（Chebyshev Filter）在通带内有纹波，但过渡带更陡峭。幅度响应为：

$$|H(j\omega)| = \frac{1}{\sqrt{1 + \epsilon^2 T_n^2\left(\frac{\omega}{\omega_c}\right)}}$$

其中：
- $\epsilon$ 为纹波系数
- $T_n(x)$ 为n阶切比雪夫多项式

#### 二阶切比雪夫低通滤波器

对于二阶切比雪夫滤波器：
- $Q = \frac{1}{\sqrt{2}\xi}$，其中 $\xi$ 与纹波相关
- 传递函数为：

$$H(s) = \frac{K\omega_c^2}{s^2 + \frac{\omega_c}{Q}s + \omega_c^2}$$

### 9.3.4 贝塞尔滤波器

#### 特点
贝塞尔滤波器（Bessel Filter）具有线性相位特性，即群延时恒定。幅度响应为：

$$|H(j\omega)| = \frac{1}{\sqrt{1 + \left(\frac{\omega}{\omega_c}\right)^{2n}}}$$

但相位响应更接近线性。

#### 二阶贝塞尔低通滤波器

对于二阶贝塞尔滤波器：
- $Q = \frac{1}{\sqrt{3}} \approx 0.577$
- 传递函数为：

$$H(s) = \frac{K\omega_c^2}{s^2 + \sqrt{3}\omega_c s + \omega_c^2}$$

### 9.3.5 滤波器类型比较

| 滤波器类型 | 通带特性 | 过渡带 | 相位线性度 | Q值范围 |
|------------|----------|--------|------------|---------|
| 巴特沃斯   | 最平坦   | 中等   | 中等       | 0.707   |
| 切比雪夫   | 有纹波   | 最陡   | 较差       | 0.5-10  |
| 贝塞尔     | 平坦     | 最缓   | 最好       | 0.577   |

## 9.4 传递函数的推导和分析

### 9.4.1 一般二阶系统的传递函数

对于任意二阶有源滤波器，其传递函数可以写成：

$$H(s) = \frac{b_2 s^2 + b_1 s + b_0}{a_2 s^2 + a_1 s + a_0}$$

将其标准化为：

$$H(s) = K \frac{s^2 + \frac{\omega_z}{Q_z}s + \omega_z^2}{s^2 + \frac{\omega_p}{Q_p}s + \omega_p^2}$$

其中：
- $\omega_z$ 和 $\omega_p$ 分别为零点和极点频率
- $Q_z$ 和 $Q_p$ 分别为零点和极点品质因数

### 9.4.2 频率响应分析

#### 幅度响应

$$|H(j\omega)| = K \sqrt{\frac{(\omega_z^2 - \omega^2)^2 + \left(\frac{\omega_z\omega}{Q_z}\right)^2}{(\omega_p^2 - \omega^2)^2 + \left(\frac{\omega_p\omega}{Q_p}\right)^2}}$$

#### 相位响应

$$\phi(\omega) = \arctan\left(\frac{\frac{\omega_z\omega}{Q_z}}{\omega_z^2 - \omega^2}\right) - \arctan\left(\frac{\frac{\omega_p\omega}{Q_p}}{\omega_p^2 - \omega^2}\right) + \phi_K$$

其中 $\phi_K$ 为常数相位偏移。

### 9.4.3 群延时

群延时定义为相位对频率的负导数：

$$\tau_g(\omega) = -\frac{d\phi(\omega)}{d\omega}$$

对于贝塞尔滤波器，群延时在通带内近似为常数。

## 9.5 截止频率和品质因数Q

### 9.5.1 截止频率

#### 定义
截止频率（Cutoff Frequency）是指滤波器幅度响应下降到最大值的 $\frac{1}{\sqrt{2}}$（约0.707）时的频率。

#### 计算方法

对于低通滤波器：
$$|H(j\omega_c)| = \frac{|H(j0)|}{\sqrt{2}}$$

对于高通滤波器：
$$|H(j\omega_c)| = \frac{|H(j\infty)|}{\sqrt{2}}$$

### 9.5.2 品质因数Q

#### 定义
品质因数Q描述了滤波器的频率选择性，定义为：

$$Q = \frac{\omega_0}{\Delta\omega}$$

其中：
- $\omega_0$ 为中心频率（对于带通滤波器）
- $\Delta\omega$ 为3dB带宽

#### Q值的物理意义

1. **频率选择性**：Q值越高，选择性越好
2. **峰值特性**：高Q值滤波器在谐振频率处有尖锐的峰值
3. **相位特性**：影响相位变化的陡峭程度

#### 不同滤波器的Q值

| 滤波器类型 | 低通/高通 | 带通 | 带阻 |
|------------|-----------|------|------|
| 一阶       | Q = 0.5   | -    | -    |
| 巴特沃斯   | Q = 0.707 | 0.707| 0.707|
| 切比雪夫   | 0.5-10    | 0.5-10| 0.5-10|
| 贝塞尔     | Q = 0.577 | 0.577| 0.577|

### 9.5.3 Q值对滤波器特性的影响

#### 幅度响应
- **低Q值（Q < 1）**：响应平缓，过渡带较宽
- **高Q值（Q > 1）**：响应陡峭，可能出现峰值

#### 相位响应
- **低Q值**：相位变化平缓
- **高Q值**：相位变化急剧

## 9.6 有源滤波器的优缺点

### 9.6.1 优点

#### 1. 增益可调
- 有源滤波器可以提供电压增益
- 增益由外部电阻网络精确控制
- 适合驱动后续电路

#### 2. 隔离性能好
- 输入阻抗高，不影响信号源
- 输出阻抗低，可驱动各种负载
- 前后级隔离，减少相互影响

#### 3. 设计灵活
- 可以实现各种滤波器特性
- 易于调整参数
- 支持复杂的滤波器拓扑

#### 4. 频率范围宽
- 从直流到高频都可实现
- 不受电感元件的限制
- 适合集成电路实现

#### 5. 体积小、重量轻
- 无需大体积电感元件
- 适合现代电子设备
- 便于集成化

### 9.6.2 缺点

#### 1. 功耗问题
- 需要直流电源供电
- 存在静态功耗
- 不适合电池供电的便携设备

#### 2. 频率限制
- 受运算放大器带宽限制
- 高频性能下降
- 不适合射频应用

#### 3. 噪声特性
- 运算放大器引入噪声
- 电阻热噪声
- 可能影响信号质量

#### 4. 线性度限制
- 运算放大器非线性失真
- 大信号时性能下降
- 动态范围有限

#### 5. 成本考虑
- 运算放大器成本较高
- 精密电阻电容成本
- 总体成本可能高于无源滤波器

### 9.6.3 应用选择原则

#### 适用场景
- 需要电压增益的场合
- 前后级隔离要求
- 精密滤波应用
- 低频到中频应用

#### 不适用场景
- 高频射频应用
- 极低功耗要求
- 成本敏感应用
- 强电磁干扰环境

## 9.7 实际应用电路

### 9.7.1 低通滤波器应用电路

#### 音频信号处理中的低通滤波器

**应用场景**：音响系统中的低音控制

**电路参数**：
- 截止频率：$f_c = 1$ kHz
- 滤波器类型：二阶巴特沃斯
- 增益：$K = 2$

**设计步骤**：

1. 选择电容C = 10nF
2. 计算电阻：$R = \frac{1}{2\pi f_c C} = \frac{1}{2\pi \times 1000 \times 10 \times 10^{-9}} \approx 15.9$ kΩ
3. 选择标准值：R = 16kΩ
4. 增益电阻：$R_1 = 10$ kΩ，$R_2 = 10$ kΩ（K = 2）

**完整电路**：
```
    10kΩ    16kΩ
Vin ──┬─────┬─────
      │     │
     C1    R3
     │     │
      └─────┤-\
            │  >─── Vout (增益=2)
            │+/
           GND
      10nF
          │
         GND
```

### 9.7.2 高通滤波器应用电路

#### 语音信号处理中的高通滤波器

**应用场景**：电话系统中的语音信号处理

**电路参数**：
- 截止频率：$f_c = 300$ Hz
- 滤波器类型：一阶高通
- 增益：$K = 1$

**设计步骤**：

1. 选择电容C = 47nF
2. 计算电阻：$R = \frac{1}{2\pi f_c C} = \frac{1}{2\pi \times 300 \times 47 \times 10^{-9}} \approx 11.3$ kΩ
3. 选择标准值：R = 11kΩ

**完整电路**：
```
    47nF
   ───┬───
      │
Vin ──┤+\
      │  >─── Vout
      │-/
   11kΩ
   ───┬───
      │
     GND
```

### 9.7.3 带通滤波器应用电路

#### 中心频率选择电路

**应用场景**：AM/FM收音机的中频放大器

**电路参数**：
- 中心频率：$f_0 = 455$ kHz
- 带宽：$\Delta f = 10$ kHz
- 品质因数：$Q = \frac{f_0}{\Delta f} = 45.5$

**双运放带通滤波器**：

```
         R1      R2
     Vin ──┬─────┬─────┬─── Vout
           │     │     │
          C1    R3    C2
           │     │     │
            └─────┤+\
                  │  >───
                  │-/
                 GND
          R4
          │
         GND
```

**传递函数**：

$$H(s) = -\frac{s/R_1C_1}{s^2 + \frac{s}{R_3C_2} + \frac{1}{R_1R_3C_1C_2}}$$

**参数设计**：

1. 选择C1 = C2 = 100pF
2. 计算R3：$R_3 = \frac{Q}{\omega_0 C_2} = \frac{45.5}{2\pi \times 455 \times 10^3 \times 100 \times 10^{-12}} \approx 159$ kΩ
3. 计算R1：$R_1 = \frac{1}{\omega_0 C_1} = \frac{1}{2\pi \times 455 \times 10^3 \times 100 \times 10^{-12}} \approx 3.5$ kΩ

### 9.7.4 状态变量滤波器

#### 多功能滤波器

状态变量滤波器可以同时实现低通、高通、带通输出。

**电路结构**：

```
              R1
         Vin ──┬─────┬─── LP Out
               │     │
              -│+     │
         ┌─────┤      ├─── BP Out
         │     │-     │
         │     R2     │
         │     │      │
         │     └──────┼── HP Out
         │            │
         │     R3     │
         └─────┬──────┘
               │
              GND
```

**传递函数**：

- 低通：$H_{LP}(s) = -\frac{R_2/R_1}{s^2R_2R_3C_1C_2 + sR_2C_2 + 1}$
- 带通：$H_{BP}(s) = -\frac{sR_2R_3C_1}{s^2R_2R_3C_1C_2 + sR_2C_2 + 1}$
- 高通：$H_{HP}(s) = -\frac{s^2R_2R_3C_1C_2}{s^2R_2R_3C_1C_2 + sR_2C_2 + 1}$

### 9.7.5 实际应用中的注意事项

#### 1. 元件选择

**电阻选择**：
- 精度：±1%或更高
- 温度系数：低温度系数电阻
- 噪声：金属膜电阻优于碳膜电阻

**电容选择**：
- 精度：±5%或更高
- 温度特性：NPO/C0G电容用于高频
- 漏电流：聚酯薄膜电容用于精密应用

#### 2. 电源去耦

在运算放大器电源引脚附近添加去耦电容：

```
    VCC
     │
    0.1μF ──── GND
     │
    10μF ──── GND
```

#### 3. 布局考虑

- 缩短信号路径
- 避免数字噪声干扰
- 良好的接地设计
- 元件排列整齐

#### 4. 频率补偿

对于高Q值滤波器：
- 考虑运算放大器的有限增益带宽积
- 添加适当的相位补偿
- 避免自激振荡
