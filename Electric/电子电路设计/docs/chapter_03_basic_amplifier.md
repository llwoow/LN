# 第三章 基本放大电路

## 3.1 晶体管放大电路的基本原理

### 3.1.1 放大作用的基本概念

晶体管放大电路的核心是利用晶体管的电流控制作用来实现信号放大。当输入信号加到晶体管的基极时，会引起基极电流的变化，进而控制集电极电流的变化，从而实现功率放大。

**放大的基本条件：**
1. 晶体管必须工作在放大区（发射结正偏，集电结反偏）
2. 电路必须建立合适的静态工作点
3. 输入信号必须能够引起基极电流的变化

### 3.1.2 放大电路的分类

根据晶体管连接方式的不同，放大电路可以分为三种基本组态：

1. **共射极放大器**（CE）：输入和输出共用电极
2. **共集电极放大器**（CC）：也称为射极跟随器
3. **共基极放大器**（CB）：输入和输出共用电极

## 3.2 共射极放大器分析

### 3.2.1 静态工作点分析

共射极放大器的基本电路如图所示。静态工作点是指无输入信号时晶体管的直流工作状态。

**静态工作点的计算：**

基极电流：
$$I_{BQ} = \frac{V_{CC} - V_{BEQ}}{R_B}$$

集电极电流：
$$I_{CQ} = \beta I_{BQ}$$

集电极-发射极电压：
$$V_{CEQ} = V_{CC} - I_{CQ} R_C$$

**静态工作点的稳定性：**

温度变化会影响晶体管的参数：
- $V_{BE}$ 随温度升高而减小（约-2mV/°C）
- $\beta$ 随温度升高而增大
- $I_{CBO}$ 随温度升高而急剧增大

### 3.2.2 动态分析

当有交流信号输入时，需要进行动态分析。设输入信号为：
$$v_i = V_{im} \sin(\omega t)$$

**电压放大倍数：**

空载时：
$$A_v = -\frac{\beta R_C}{r_{be}}$$

带负载时：
$$A_v = -\frac{\beta R_L'}{r_{be}}$$
其中 $R_L' = R_C \parallel R_L$

**输入电阻：**
$$r_i = R_B \parallel r_{be}$$

**输出电阻：**
$$r_o = R_C$$

### 3.2.3 h参数模型

h参数模型是描述晶体管小信号特性的重要工具。

**h参数的定义：**

$$h_{ie} = \frac{\partial v_{BE}}{\partial i_B}\bigg|_{v_{CE}=0}$$
$$h_{fe} = \frac{\partial i_C}{\partial i_B}\bigg|_{v_{CE}=0}$$
$$h_{oe} = \frac{\partial i_C}{\partial v_{CE}}\bigg|_{i_B=0}$$
$$h_{re} = \frac{\partial v_{BE}}{\partial v_{CE}}\bigg|_{i_B=0}$$

**共射极h参数模型：**

输入电阻：$h_{ie} = r_{be} = r_{bb'} + (1+\beta)\frac{V_T}{I_{EQ}}$
电流放大系数：$h_{fe} = \beta$
输出电导：$h_{oe} \approx \frac{1}{r_{ce}}$
反向电压传输比：$h_{re}$ 很小，通常可忽略

## 3.3 共集电极放大器（射极跟随器）

### 3.3.1 电路特点

射极跟随器的输出电压跟随输入电压变化，具有以下特点：

1. **电压放大倍数近似为1**：$A_v \approx 1$
2. **电流放大倍数较大**：$A_i \approx 1 + \beta$
3. **输入电阻高**：$r_i = R_B \parallel [(1+\beta)R_L']$
4. **输出电阻低**：$r_o \approx \frac{r_{be}}{1+\beta} \parallel R_E$

### 3.3.2 性能分析

**电压放大倍数：**
$$A_v = \frac{(1+\beta)R_L'}{r_{be} + (1+\beta)R_L'} \approx 1$$

**输入电阻：**
$$r_i = R_B \parallel [r_{be} + (1+\beta)R_L']$$

**输出电阻：**
$$r_o = \frac{r_{be} + R_S'}{1+\beta} \parallel R_E$$
其中 $R_S' = R_S \parallel R_B$

### 3.3.3 应用场合

射极跟随器主要应用于：
1. **阻抗变换**：实现高输入阻抗和低输出阻抗
2. **缓冲级**：隔离前后级电路，减少相互影响
3. **功率放大**：提供较大的电流驱动能力

## 3.4 共基极放大器

### 3.4.1 频率特性

共基极放大器具有优良的高频特性：

1. **截止频率高**：$f_{\alpha} = (1-\alpha)f_T$
2. **输入电容小**：$C_{i} = C_{be} + C_{bc}(1-A_v)$
3. **密勒效应小**：由于电压放大倍数小，密勒效应不明显

### 3.4.2 性能参数

**电压放大倍数：**
$$A_v = \frac{\alpha R_L'}{r_{e}}$$

**输入电阻：**
$$r_i = \frac{r_{e}}{1-\alpha} \approx r_{e}$$

**输出电阻：**
$$r_o = R_C$$

### 3.4.3 应用特点

共基极放大器适用于：
1. **高频放大**：宽频带应用
2. **恒流源**：高输出阻抗
3. **混频器**：非线性应用

## 3.5 偏置电路设计

### 3.5.1 固定偏置电路

**电路结构：** 基极通过电阻 $R_B$ 直接接电源 $V_{CC}$

**优点：** 电路简单
**缺点：** 稳定性差

**稳定性分析：**
$$I_C = \beta \frac{V_{CC} - V_{BE}}{R_B}$$

温度变化时，$I_C$ 会发生较大变化。

### 3.5.2 分压式偏置电路

**电路结构：** 基极通过分压电阻网络获得稳定电压

**静态工作点计算：**

假设 $I_1 >> I_{BQ}$，则：
$$V_{BQ} \approx \frac{R_{B2}}{R_{B1} + R_{B2}} V_{CC}$$

$$I_{EQ} = \frac{V_{BQ} - V_{BE}}{R_E}$$

$$I_{CQ} \approx I_{EQ}$$

$$V_{CEQ} = V_{CC} - I_{CQ}(R_C + R_E)$$

**稳定性分析：**
分压式偏置电路具有很好的温度稳定性，因为 $V_{BQ}$ 相对固定，而 $V_{BE}$ 的变化对 $I_{EQ}$ 的影响被 $R_E$ 产生的负反馈所抑制。

### 3.5.3 电流负反馈偏置电路

**电路结构：** 在发射极串入反馈电阻 $R_E$

**反馈原理：**
当温度升高导致 $I_C$ 增大时：
1. $I_E$ 增大
2. $V_E = I_E R_E$ 增大
3. $V_{BE} = V_B - V_E$ 减小
4. $I_B$ 减小
5. $I_C$ 减小

**稳定条件：**
$$V_E >> V_{BE}$$
$$I_1 >> I_{BQ}$$

### 3.5.4 偏置电路设计原则

1. **保证足够的稳定性**：选择合适的 $R_E$ 和分压比
2. **满足信号幅度要求**：$V_{CEQ} > V_{om} + V_{CE(sat)}$
3. **优化功耗和效率**：合理选择工作点
4. **考虑频率特性**：避免寄生参数的影响

## 3.6 放大器的性能指标

### 3.6.1 增益指标

**电压增益：**
$$A_v = \frac{v_o}{v_i}$$

**电流增益：**
$$A_i = \frac{i_o}{i_i}$$

**功率增益：**
$$A_p = A_v A_i = \frac{p_o}{p_i}$$

### 3.6.2 阻抗指标

**输入阻抗：**
$$r_i = \frac{v_i}{i_i}$$

**输出阻抗：**
$$r_o = \frac{v_o}{i_o}\bigg|_{v_i=0}$$

### 3.6.3 频率特性

**上限频率：**
$$f_H = \frac{1}{2\pi \tau_H}$$

**下限频率：**
$$f_L = \frac{1}{2\pi \tau_L}$$

**带宽：**
$$BW = f_H - f_L$$

**增益带宽积：**
$$GBW = |A_v| \cdot BW$$

## 3.7 三种组态放大器的特点对比

| 参数 | 共射极(CE) | 共集电极(CC) | 共基极(CB) |
|------|------------|--------------|------------|
| 电压增益 | 高(几十到几百) | 低(≈1) | 高(几十到几百) |
| 电流增益 | 高(β) | 高(1+β) | 低(α) |
| 功率增益 | 高 | 中等 | 中等 |
| 输入阻抗 | 中等 | 高 | 低 |
| 输出阻抗 | 高 | 低 | 高 |
| 频率特性 | 中等 | 较好 | 最好 |
| 相位关系 | 反相 | 同相 | 同相 |
| 主要应用 | 电压放大 | 阻抗变换、缓冲 | 高频放大、恒流源 |

## 3.8 设计实例

### 3.8.1 共射极放大器设计

**设计要求：**
- 电源电压：$V_{CC} = 12V$
- 电压增益：$|A_v| \geq 50$
- 输入阻抗：$r_i \geq 2k\Omega$
- 负载电阻：$R_L = 4k\Omega$

**设计步骤：**

1. 选择静态工作点：
   $$I_{CQ} = 1mA, \quad V_{CEQ} = 6V$$

2. 计算集电极电阻：
   $$R_C = \frac{V_{CC} - V_{CEQ}}{I_{CQ}} = \frac{12-6}{1} = 6k\Omega$$

3. 计算等效负载：
   $$R_L' = R_C \parallel R_L = 6 \parallel 4 = 2.4k\Omega$$

4. 计算所需 $r_{be}$：
   $$|A_v| = \frac{\beta R_L'}{r_{be}} \geq 50$$
   $$r_{be} \leq \frac{\beta R_L'}{50}$$

   取 $\beta = 100$，则：
   $$r_{be} \leq \frac{100 \times 2.4}{50} = 4.8k\Omega$$

5. 计算基极电流：
   $$I_{BQ} = \frac{I_{CQ}}{\beta} = \frac{1}{100} = 10\mu A$$

6. 选择分压式偏置电路：
   $$V_{BQ} = V_{BE} + I_{EQ}R_E = 0.7 + 1 \times R_E$$

   取 $V_{BQ} = 2V$，则 $R_E = 1.3k\Omega$

   $$R_{B1} = \frac{V_{BQ}}{I_1} = \frac{2}{5 \times 10} = 20k\Omega$$
   $$R_{B2} = \frac{V_{CC} - V_{BQ}}{I_1 + I_{BQ}} \approx \frac{10}{50} = 200k\Omega$$

## 本章小结

本章详细分析了晶体管放大电路的基本原理和三种基本组态的特点：

1. **共射极放大器**具有较高的电压增益和功率增益，是最常用的放大组态
2. **共集电极放大器**（射极跟随器）具有高输入阻抗和低输出阻抗，主要用于阻抗变换
3. **共基极放大器**具有优良的频率特性，适用于高频应用

偏置电路的设计对放大器的性能至关重要，分压式偏置电路因其良好的稳定性而被广泛采用。理解各种性能指标和设计方法对实际电路设计具有重要意义。

在实际应用中，应根据具体要求选择合适的放大器组态和偏置电路，以获得最佳的性能表现。
