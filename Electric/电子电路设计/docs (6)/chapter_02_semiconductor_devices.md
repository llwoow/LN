# 第二章 半导体器件基础

## 2.1 PN结原理和特性

### 2.1.1 PN结的形成

PN结是半导体器件的基础结构，由P型半导体和N型半导体在原子级尺度上接触形成。

**载流子扩散过程：**

当P型和N型半导体接触时，由于浓度梯度：
- P区的空穴向N区扩散
- N区的电子向P区扩散

**空间电荷区形成：**

扩散运动在接触面附近形成耗尽层（空间电荷区），产生内建电场：

$$E_{bi} = \frac{kT}{q} \ln\left(\frac{N_A N_D}{n_i^2}\right)$$

其中：
- $E_{bi}$：内建电场强度
- $N_A$：P区受主浓度
- $N_D$：N区施主浓度
- $n_i$：本征载流子浓度
- $k$：玻尔兹曼常数
- $T$：绝对温度
- $q$：电子电荷

**内建电势：**

$$V_{bi} = \frac{kT}{q} \ln\left(\frac{N_A N_D}{n_i^2}\right)$$

### 2.1.2 PN结特性曲线

#### 正向偏置

当外加电压 $V_F > 0$ 时：

$$I_D = I_S \left(e^{\frac{qV_F}{kT}} - 1\right)$$

其中 $I_S$ 为反向饱和电流：

$$I_S = qA\left(\frac{D_p p_{n0}}{L_p} + \frac{D_n n_{p0}}{L_n}\right)$$

#### 反向偏置

当外加电压 $V_R < 0$ 时：

$$I_D \approx -I_S$$

反向电流基本恒定，直到达到击穿电压。

#### 击穿机制

1. **齐纳击穿**（$V_R < 5V$）：强电场直接击穿
2. **雪崩击穿**（$V_R > 7V$）：碰撞电离机制
3. **热击穿**：温度失控导致

## 2.2 二极管的伏安特性、参数和模型

### 2.2.1 伏安特性

二极管的电流-电压关系为：

$$I_D = I_S \left(e^{\frac{V_D}{nV_T}} - 1\right)$$

其中：
- $V_D$：二极管端电压
- $n$：理想因子（1-2之间）
- $V_T = \frac{kT}{q}$：热电压（26mV @ 300K）

### 2.2.2 主要参数

#### 静态参数

1. **正向压降** $V_F$：典型值0.6-0.8V（硅管）
2. **反向饱和电流** $I_S$：nA级
3. **击穿电压** $V_{BR}$：5V-1000V不等
4. **最大正向电流** $I_{F(max)}$：通常几十mA到几A

#### 动态参数

1. **结电容** $C_j$：反偏时较大，正偏时较小
2. **反向恢复时间** $t_{rr}$：ns到μs级
3. **开关时间**：决定工作频率上限

### 2.2.3 二极管模型

#### 理想模型

```
    I_D
    ↑    |
    |    |
    +----+---- V_D
    |    |
    ↓    |
   0V   |
```

$$I_D = \begin{cases}
0, & V_D < 0 \\
\infty, & V_D \geq 0
\end{cases}$$

#### 恒压降模型

```
    I_D
    ↑    |
    |    |
    +----+---- V_D
    |    |
    ↓    |
   0.7V  |
```

$$I_D = \begin{cases}
0, & V_D < 0.7V \\
\infty, & V_D \geq 0.7V
\end{cases}$$

#### 指数模型（详细模型）

```
    I_D
    ↑    |
    |    |
    +----+---- V_D
    |    |
    ↓    |
   I_S  |
```

$$I_D = I_S \left(e^{\frac{V_D}{V_T}} - 1\right)$$

#### 小信号模型

在静态工作点 $V_{DQ}$、$I_{DQ}$ 处的小信号等效电路：

```
    i_d
    ↑    |
    |    |
    +----+---- v_d
    |    |
    ↓    |
   r_d  |
```

其中动态电阻：

$$r_d = \frac{V_T}{I_{DQ}} = \frac{26mV}{I_{DQ}}$$

## 2.3 BJT三极管的工作原理、特性曲线和h参数模型

### 2.3.1 BJT结构和工作原理

#### 基本结构

NPN型BJT由三个区域组成：
- **发射区（E）**：高掺杂，载流子发射源
- **基区（B）**：薄层，控制载流子传输
- **集电区（C）**：收集载流子

#### 工作原理

**放大条件：**
- 发射结正偏：$V_{BE} \approx 0.7V$
- 集电结反偏：$V_{CB} > 0$

**载流子传输过程：**

1. **发射**：发射结注入电子到基区
2. **扩散**：电子在基区扩散
3. **复合**：少量电子与空穴复合
4. **收集**：大部分电子被集电结收集

### 2.3.2 特性曲线

#### 输入特性曲线

$$I_B = f(V_{BE})|_{V_{CE}=const}$$

$$I_B = I_{ES}\left(e^{\frac{V_{BE}}{V_T}} - 1\right)\left(1 + \frac{V_{CE}}{V_A}\right)$$

#### 输出特性曲线

$$I_C = f(V_{CE})|_{I_B=const}$$

$$I_C = \beta I_B + I_{CBO}$$

#### 电流传输特性

$$I_C = \alpha I_E$$

其中电流增益：

$$\alpha = \frac{I_C}{I_E} \approx 0.95-0.99$$

$$\beta = \frac{I_C}{I_B} = \frac{\alpha}{1-\alpha} \approx 20-200$$

### 2.3.3 h参数模型

#### 混合π模型（小信号）

```
        i_b         i_c
         ↑          ↑
         |          |
    +----+----r_π----+----+
    |    |           |    |
    |   b|           |c   |
    |    |    g_m    |    |
    |    +----/\/\---+    |
    |         v_π         |
    |                     |
    +---------r_o---------+
         e             e
```

**主要参数：**

1. **输入电阻** $r_{\pi}$：
   $$r_{\pi} = \frac{\beta V_T}{I_{CQ}}$$

2. **跨导** $g_m$：
   $$g_m = \frac{I_{CQ}}{V_T}$$

3. **输出电阻** $r_o$：
   $$r_o = \frac{V_A}{I_{CQ}}$$

其中 $V_A$ 为Early电压。

#### h参数模型（网络参数）

```
    I1        I2
     ↑        ↑
     |        |
    +--------+--------+
    |        |        |
    |   h11  |   h12  |
    |   (输入|   (反向|
    |   电阻)|   传输)|
    |        |        |
    +--------+--------+
    |        |        |
    |   h21  |   h22  |
    |   (正向|   (输出|
    |   传输)|   导纳)|
    |        |        |
    +--------+--------+
     V1        V2
     ↓        ↓
```

**h参数定义：**

$$h_{11} = \left.\frac{V_1}{I_1}\right|_{V_2=0} = r_{\pi}$$

$$h_{12} = \left.\frac{V_1}{V_2}\right|_{I_1=0} \approx 0$$

$$h_{21} = \left.\frac{I_2}{I_1}\right|_{V_2=0} = \beta$$

$$h_{22} = \left.\frac{I_2}{V_2}\right|_{I_1=0} = \frac{1}{r_o}$$

## 2.4 MOSFET管的结构、工作原理和特性

### 2.4.1 MOSFET结构

#### N沟道增强型MOSFET

```
    D
    |
    +----+
    |    |
    |   G|
    |    |
    +----+
    |    |
    |   S|
    |    |
    +----+
```

**三个区域：**
- **源极（S）**：载流子来源
- **栅极（G）**：电压控制
- **漏极（D）**：载流子收集

**衬底效应：**
衬底与源极通常短接，但在集成电路中需要考虑衬底偏置效应。

### 2.4.2 工作原理

#### 阈值电压

当栅源电压超过阈值电压 $V_{th}$ 时，形成导电沟道：

$$V_{th} = V_{FB} + 2\phi_F + \frac{\sqrt{2\varepsilon_s q N_A (2\phi_F + V_{SB})}}{C_{ox}}$$

其中：
- $V_{FB}$：平带电压
- $\phi_F$：费米势
- $V_{SB}$：源衬底电压
- $C_{ox}$：氧化层电容密度

#### 导电沟道形成

**截止区**（$V_{GS} < V_{th}$）：
$$I_D = 0$$

**线性区**（$V_{DS} < V_{GS} - V_{th}$）：
$$I_D = \mu_n C_{ox} \frac{W}{L}\left[(V_{GS} - V_{th})V_{DS} - \frac{V_{DS}^2}{2}\right]$$

**饱和区**（$V_{DS} > V_{GS} - V_{th}$）：
$$I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{th})^2$$

### 2.4.3 特性曲线

#### 转移特性

$$I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{th})^2$$

#### 输出特性

**线性区：**
$$I_D = \mu_n C_{ox} \frac{W}{L}\left[(V_{GS} - V_{th})V_{DS} - \frac{V_{DS}^2}{2}\right]$$

**饱和区：**
$$I_D = \frac{1}{2} \mu_n C_{ox} \frac{W}{L}(V_{GS} - V_{th})^2$$

### 2.4.4 MOSFET小信号模型

```
    i_g         i_d
     ↑          ↑
     |          |
    +----+   +----+
    |    |   |    |
    |   G|   |D   |
    |    |   |    |
    +----+   +----+
    |         |
   r_g        |
    |    g_m  |
    +----/\/\-+
    |     v_gs
    |         |
    +----r_o--+
    |         |
    S         S
```

**主要参数：**

1. **栅极电阻** $r_g$：几欧姆到几千欧姆
2. **跨导** $g_m$：
   $$g_m = \sqrt{2\mu_n C_{ox} \frac{W}{L} I_D}$$

3. **输出电阻** $r_o$：
   $$r_o = \frac{1}{\lambda I_D}$$

其中 $\lambda$ 为沟道长度调制系数。

## 2.5 器件主要参数

### 2.5.1 击穿电压

#### 二极管击穿电压

$$V_{BR} = V_{Zener} + I_Z R_Z$$

- 齐纳击穿：5V以下
- 雪崩击穿：7V以上
- 温度系数：齐纳为负，雪崩为正

#### BJT击穿电压

1. **$V_{CEO}$**：基极开路时集电极-发射极击穿电压
2. **$V_{CBO}$**：发射极开路时集电极-基极击穿电压
3. **$V_{BE(max)}$**：基极-发射极最大反向电压

#### MOSFET击穿电压

1. **$V_{DS(max)}$**：漏源最大电压
2. **$V_{GS(max)}$**：栅源最大电压
3. **$V_{GB(max)}$**：栅体最大电压

### 2.5.2 功耗参数

#### 静态功耗

**二极管：**
$$P_D = V_D I_D$$

**BJT：**
$$P_C = V_{CE} I_C$$

**MOSFET：**
$$P_D = V_{DS} I_D$$

#### 动态功耗

**开关损耗：**
$$P_{sw} = f_{sw} \int_0^{T_{sw}} v(t)i(t)dt$$

**电容充放电损耗：**
$$P_C = \frac{1}{2} C V^2 f_{sw}$$

### 2.5.3 频率特性

#### 二极管频率参数

1. **截止频率** $f_T$：
   $$f_T = \frac{1}{2\pi R_S C_j}$$

2. **反向恢复时间** $t_{rr}$：
   $$t_{rr} = t_s + t_f$$

其中 $t_s$ 为存储时间，$t_f$ 为下降时间。

#### BJT频率参数

1. **特征频率** $f_T$：
   $$f_T = \frac{g_m}{2\pi (C_{\pi} + C_{\mu})}$$

2. **共基极截止频率** $f_{\alpha}$：
   $$f_{\alpha} = \frac{f_T}{\beta}$$

3. **共射极截止频率** $f_{\beta}$：
   $$f_{\beta} = \frac{f_T}{\beta}$$

#### MOSFET频率参数

1. **特征频率** $f_T$：
   $$f_T = \frac{g_m}{2\pi (C_{gs} + C_{gd})}$$

2. **最高振荡频率** $f_{max}$：
   $$f_{max} = \frac{f_T}{2\sqrt{g_m R_G}}$$

### 2.5.4 温度特性

#### 温度系数

**二极管正向压降：**
$$\frac{\partial V_F}{\partial T} \approx -2mV/^\circ C$$

**BJT电流增益：**
$$\frac{\partial \beta}{\partial T} > 0$$

**MOSFET阈值电压：**
$$\frac{\partial V_{th}}{\partial T} \approx -2 \sim -4mV/^\circ C$$

#### 热阻

$$R_{\theta} = \frac{T_j - T_a}{P}$$

其中：
- $R_{\theta}$：热阻
- $T_j$：结温
- $T_a$：环境温度
- $P$：功耗

## 2.6 器件等效电路模型总结

### 2.6.1 小信号模型对比

| 器件 | 输入电阻 | 输出电阻 | 跨导 | 主要电容 |
|------|----------|----------|------|----------|
| 二极管 | $r_d = V_T/I_D$ | - | - | $C_j$ |
| BJT | $r_{\pi} = \beta V_T/I_C$ | $r_o = V_A/I_C$ | $g_m = I_C/V_T$ | $C_{\pi}, C_{\mu}$ |
| MOSFET | $r_g$ (几Ω-几kΩ) | $r_o = 1/(\lambda I_D)$ | $g_m = \sqrt{2\mu C_{ox} W/L I_D}$ | $C_{gs}, C_{gd}$ |

### 2.6.2 频率响应特性

**主导极点：**

1. **二极管**：$f_p = 1/(2\pi R_S C_j)$
2. **BJT**：$f_p = 1/(2\pi (r_{\pi} + R_S)(C_{\pi} + C_{\mu}))$
3. **MOSFET**：$f_p = 1/(2\pi R_G (C_{gs} + C_{gd}))$

### 2.6.3 非线性特性

**泰勒展开模型：**

$$i(t) = I_0 + g_1 v(t) + g_2 v^2(t) + g_3 v^3(t) + ...$$

其中：
- $g_1$：线性电导
- $g_2$：二次非线性系数
- $g_3$：三次非线性系数

**失真分析：**

二次谐波失真：$HD_2 = \frac{|g_2|}{2|g_1|} V_m$

三次谐波失真：$HD_3 = \frac{|g_3|}{4|g_1|} V_m^2$

## 2.7 本章小结

本章详细介绍了半导体器件的基础理论：

1. **PN结理论**：内建电场、势垒高度、电流方程
2. **二极管模型**：从理想模型到指数模型的演进
3. **BJT器件**：h参数模型和混合π模型的建立
4. **MOSFET器件**：沟道调制效应和温度特性
5. **器件参数**：击穿、功耗、频率特性的量化分析

这些等效电路模型为后续放大电路的分析奠定了坚实的理论基础。掌握器件的小信号模型对于理解和设计高性能模拟电路至关重要。
