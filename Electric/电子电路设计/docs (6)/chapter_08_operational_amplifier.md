# 第8章 运算放大器

## 8.1 运算放大器的基本概念和理想特性

运算放大器（Operational Amplifier，简称运放）是一种具有高增益、高输入阻抗、低输出阻抗的差分放大器。它是模拟电路中的核心器件，广泛应用于信号放大、滤波、运算等各种电路中。

### 8.1.1 运算放大器的基本结构

运算放大器的基本结构包括：
- **同相输入端（+）**：输出信号与输入信号同相
- **反相输入端（-）**：输出信号与输入信号反相
- **输出端**：放大后的信号输出
- **电源端**：正电源（VCC）和负电源（VEE）
- **补偿端**：用于频率补偿（外接电容）

### 8.1.2 理想运算放大器的特性

理想运算放大器具有以下特性：

1. **无限大的开环增益**：$A_{OL} \rightarrow \infty$
2. **无限大的输入阻抗**：$R_{in} \rightarrow \infty$
3. **零输出阻抗**：$R_{out} = 0$
4. **无限大的带宽**：$BW \rightarrow \infty$
5. **无限大的共模抑制比**：$CMRR \rightarrow \infty$
6. **零输入失调电压**：$V_{os} = 0$
7. **零输入失调电流**：$I_{os} = 0$
8. **零噪声**

### 8.1.3 实际运算放大器与理想运放的差异

实际运算放大器的特性：
- 开环增益：$10^4 \sim 10^7$
- 输入阻抗：$10^6 \sim 10^{13} \Omega$
- 输出阻抗：$10 \sim 100 \Omega$
- 带宽：有限值
- 共模抑制比：$60 \sim 140$ dB
- 输入失调电压：$10 \mu V \sim 10$ mV
- 输入失调电流：$1 \sim 100$ nA

## 8.2 虚短和虚断的概念及应用条件

### 8.2.1 虚短（Virtual Short）

**虚短**是指运算放大器在负反馈工作条件下，同相输入端和反相输入端的电位相等，如同短路一样。

**数学表达式：**
$$V_+ = V_-$$

**应用条件：**
- 运算放大器工作在线性区（不是饱和区）
- 存在负反馈电路
- 开环增益足够大（$A_{OL} \gg 1$）

### 8.2.2 虚断（Virtual Open）

**虚断**是指运算放大器的输入电流为零，如同开路一样。

**数学表达式：**
$$I_+ = I_- = 0$$

**应用条件：**
- 输入阻抗足够大（$R_{in} \gg 1$）
- 适用于直流和低频信号

### 8.2.3 虚短虚断在分析中的应用

虚短虚断是分析运算放大器电路的重要工具。通过这两个概念，我们可以：
1. 简化电路分析
2. 快速求解电路参数
3. 理解电路工作原理

## 8.3 反相放大器

### 8.3.1 电路结构

反相放大器的基本电路结构：
- 输入信号连接反相输入端
- 同相输入端接地
- 输出端通过反馈电阻$R_f$连接到反相输入端
- 反相输入端通过输入电阻$R_1$连接输入信号

### 8.3.2 电路分析

根据虚短虚断原理：

1. **虚短条件**：$V_+ = V_- = 0$（同相端接地）
2. **虚断条件**：$I_- = 0$

对反相输入节点应用基尔霍夫电流定律（KCL）：
$$I_1 = I_f + I_-$$

由于$I_- = 0$，因此：
$$I_1 = I_f$$

各电流表达式：
- $I_1 = \frac{V_{in} - V_-}{R_1} = \frac{V_{in}}{R_1}$
- $I_f = \frac{V_- - V_{out}}{R_f} = \frac{-V_{out}}{R_f}$

代入KCL方程：
$$\frac{V_{in}}{R_1} = -\frac{V_{out}}{R_f}$$

### 8.3.3 电压增益

求解电压增益：
$$A_v = \frac{V_{out}}{V_{in}} = -\frac{R_f}{R_1}$$

**特点：**
- 增益为负值，表示输出与输入反相
- 增益大小由电阻比值$R_f/R_1$决定
- 输入阻抗为$R_1$（相对较低）

### 8.3.4 设计要点

1. **电阻选择**：
   - $R_1$和$R_f$应选择合适的阻值范围（$1k\Omega \sim 1M\Omega$）
   - 避免过大或过小的阻值

2. **增益设置**：
   - 根据所需增益选择$R_f$和$R_1$的比值
   - 例如：若需要$-10$倍增益，可选择$R_1 = 10k\Omega$，$R_f = 100k\Omega$

3. **平衡电阻**：
   - 在同相端串联平衡电阻$R_p = R_1 \parallel R_f$
   - 减少输入失调电流的影响

## 8.4 同相放大器

### 8.4.1 电路结构

同相放大器的基本电路结构：
- 输入信号连接同相输入端
- 反相输入端通过电阻$R_1$接地
- 输出端通过反馈电阻$R_f$连接到反相输入端

### 8.4.2 电路分析

根据虚短虚断原理：

1. **虚短条件**：$V_+ = V_- = V_{in}$
2. **虚断条件**：$I_- = 0$

对反相输入节点应用基尔霍夫电流定律（KCL）：
$$I_1 = I_f + I_-$$

由于$I_- = 0$，因此：
$$I_1 = I_f$$

各电流表达式：
- $I_1 = \frac{V_- - 0}{R_1} = \frac{V_{in}}{R_1}$
- $I_f = \frac{V_{out} - V_-}{R_f} = \frac{V_{out} - V_{in}}{R_f}$

代入KCL方程：
$$\frac{V_{in}}{R_1} = \frac{V_{out} - V_{in}}{R_f}$$

### 8.4.3 电压增益

求解电压增益：
$$A_v = \frac{V_{out}}{V_{in}} = 1 + \frac{R_f}{R_1}$$

**特点：**
- 增益为正值，表示输出与输入同相
- 增益最小值为1（当$R_f = 0$时）
- 输入阻抗很高（接近运放的输入阻抗）

### 8.4.4 电压跟随器

当$R_f = 0$且$R_1 = \infty$时，同相放大器变为电压跟随器：
$$A_v = 1$$

**特点：**
- 增益为1，输出跟随输入
- 极高的输入阻抗
- 极低的输出阻抗
- 用于阻抗变换和缓冲

## 8.5 加法器电路

### 8.5.1 反相加法器

#### 电路结构
反相加法器有多个输入信号，都连接到反相输入端，同相输入端接地，输出端通过反馈电阻连接到反相输入端。

#### 电路分析
根据虚短虚断原理：
- $V_+ = V_- = 0$
- $I_- = 0$

对反相输入节点应用KCL：
$$I_1 + I_2 + I_3 + \cdots + I_n = I_f$$

各电流表达式：
- $I_1 = \frac{V_1 - V_-}{R_1} = \frac{V_1}{R_1}$
- $I_2 = \frac{V_2 - V_-}{R_2} = \frac{V_2}{R_2}$
- $I_3 = \frac{V_3 - V_-}{R_3} = \frac{V_3}{R_3}$
- $\cdots$
- $I_n = \frac{V_n - V_-}{R_n} = \frac{V_n}{R_n}$
- $I_f = \frac{V_- - V_{out}}{R_f} = -\frac{V_{out}}{R_f}$

代入KCL方程：
$$\frac{V_1}{R_1} + \frac{V_2}{R_2} + \frac{V_3}{R_3} + \cdots + \frac{V_n}{R_n} = -\frac{V_{out}}{R_f}$$

#### 输出电压
$$V_{out} = -R_f \left(\frac{V_1}{R_1} + \frac{V_2}{R_2} + \frac{V_3}{R_3} + \cdots + \frac{V_n}{R_n}\right)$$

如果所有输入电阻相等（$R_1 = R_2 = R_3 = \cdots = R_n = R$）：
$$V_{out} = -\frac{R_f}{R}(V_1 + V_2 + V_3 + \cdots + V_n)$$

### 8.5.2 同相加法器

#### 电路结构
同相加法器的多个输入信号都连接到同相输入端，通过电阻网络进行加法运算。

#### 电路分析
根据虚短虚断原理：
- $V_+ = V_-$
- $I_- = 0$

同相输入端的电压为各输入信号的加权和：
$$V_+ = \frac{R_f \parallel R_1}{R_f \parallel R_1 + R_{in}} \cdot \frac{\frac{V_1}{R_1} + \frac{V_2}{R_2} + \cdots + \frac{V_n}{R_n}}{\frac{1}{R_1} + \frac{1}{R_2} + \cdots + \frac{1}{R_n}}$$

输出电压：
$$V_{out} = \left(1 + \frac{R_f}{R_1}\right) \cdot V_+$$

## 8.6 减法器电路（差分放大器）

### 8.6.1 电路结构
减法器电路有两个输入信号，分别连接到运放的同相输入端和反相输入端。

### 8.6.2 电路分析

根据虚短虚断原理：
- $V_+ = V_-$
- $I_- = I_+ = 0$

#### 同相输入端电压
$$V_+ = \frac{R_3}{R_2 + R_3} \cdot V_2$$

#### 反相输入端电压
$$V_- = \frac{R_1}{R_1 + R_f} \cdot V_1 + \frac{R_f}{R_1 + R_f} \cdot V_{out}$$

#### 虚短条件
$$V_+ = V_-$$

$$\frac{R_3}{R_2 + R_3} \cdot V_2 = \frac{R_1}{R_1 + R_f} \cdot V_1 + \frac{R_f}{R_1 + R_f} \cdot V_{out}$$

### 8.6.3 输出电压

求解输出电压：
$$V_{out} = \frac{R_f}{R_1} \cdot \frac{R_3}{R_2 + R_3} \cdot V_2 - \frac{R_f}{R_1} \cdot V_1$$

如果满足$R_1 = R_2$和$R_f = R_3$：
$$V_{out} = \frac{R_f}{R_1}(V_2 - V_1)$$

### 8.6.4 差分放大器

当$R_1 = R_2$且$R_f = R_3$时，电路为标准差分放大器：
$$A_d = \frac{R_f}{R_1}$$

**特点：**
- 放大两个输入信号的差值
- 抑制共模信号
- 共模抑制比（CMRR）是重要参数

## 8.7 积分器和微分器电路

### 8.7.1 积分器

#### 电路结构
积分器将反相放大器中的反馈电阻$R_f$替换为电容$C$，输入电阻仍为$R$。

#### 电路分析
根据虚短虚断原理：
- $V_+ = V_- = 0$
- $I_- = 0$

对反相输入节点应用KCL：
$$I_R = I_C + I_-$$

由于$I_- = 0$：
$$I_R = I_C$$

各电流表达式：
- $I_R = \frac{V_{in} - V_-}{R} = \frac{V_{in}}{R}$
- $I_C = C \frac{dV_C}{dt} = C \frac{d(V_- - V_{out})}{dt} = -C \frac{dV_{out}}{dt}$

代入KCL方程：
$$\frac{V_{in}}{R} = -C \frac{dV_{out}}{dt}$$

#### 输出电压
$$V_{out} = -\frac{1}{RC} \int V_{in} dt$$

**特点：**
- 输出电压是输入电压对时间的积分
- 积分时间常数$\tau = RC$
- 具有低通滤波特性

### 8.7.2 微分器

#### 电路结构
微分器将反相放大器中的输入电阻$R$替换为电容$C$，反馈电阻仍为$R_f$。

#### 电路分析
根据虚短虚断原理：
- $V_+ = V_- = 0$
- $I_- = 0$

对反相输入节点应用KCL：
$$I_C = I_{R_f} + I_-$$

由于$I_- = 0$：
$$I_C = I_{R_f}$$

各电流表达式：
- $I_C = C \frac{dV_{in}}{dt}$
- $I_{R_f} = \frac{V_- - V_{out}}{R_f} = -\frac{V_{out}}{R_f}$

代入KCL方程：
$$C \frac{dV_{in}}{dt} = -\frac{V_{out}}{R_f}$$

#### 输出电压
$$V_{out} = -R_f C \frac{dV_{in}}{dt}$$

**特点：**
- 输出电压是输入电压对时间的微分
- 微分时间常数$\tau = R_f C$
- 具有高通滤波特性

### 8.7.3 实际考虑

#### 积分器的实际考虑
1. **直流偏置**：输入失调电压会导致输出积分漂移
2. **频率响应**：低频增益很高，可能导致饱和
3. **相位补偿**：需要适当的相位补偿

#### 微分器的实际考虑
1. **高频噪声**：微分器会放大高频噪声
2. **稳定性**：容易产生振荡
3. **输入保护**：需要限流电阻

## 8.8 有源滤波器应用

有源滤波器使用运算放大器和RC网络构成，具有以下优点：
- 增益可调
- 输入阻抗高
- 输出阻抗低
- 易于级联

### 8.8.1 一阶有源低通滤波器

#### 电路结构
一阶低通滤波器由一阶RC低通滤波器后接同相放大器构成。

#### 传递函数
$$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \frac{A_0}{1 + sRC}$$

其中$A_0 = 1 + \frac{R_f}{R_1}$为直流增益。

#### 截止频率
$$f_c = \frac{1}{2\pi RC}$$

### 8.8.2 一阶有源高通滤波器

#### 电路结构
一阶高通滤波器由一阶RC高通滤波器后接同相放大器构成。

#### 传递函数
$$H(s) = \frac{V_{out}(s)}{V_{in}(s)} = \frac{A_0 sRC}{1 + sRC}$$

#### 截止频率
$$f_c = \frac{1}{2\pi RC}$$

### 8.8.3 二阶有源滤波器

#### 巴特沃斯滤波器
- 频率响应平坦
- 过渡带较宽
- 相位特性好

#### 切比雪夫滤波器
- 过渡带较窄
- 通带有纹波
- 阻带衰减快

#### 椭圆滤波器
- 过渡带最窄
- 通带和阻带都有纹波
- 阶数较低

### 8.8.4 常用二阶滤波器结构

#### 压控电压源（VCVS）滤波器
- 结构简单
- 调整方便
- 适合低频应用

#### 多路反馈（MFB）滤波器
- 性能较好
- 调整相对复杂
- 适合高频应用

#### 双T滤波器
- 专门用于带阻滤波器
- 谐振频率精确
- Q值较高

## 8.9 设计实例

### 8.9.1 反相放大器设计实例

**设计要求：**
- 电压增益：$-20$倍
- 输入电阻：$10k\Omega$
- 电源电压：$\pm 12V$

**设计步骤：**
1. 选择输入电阻：$R_1 = 10k\Omega$
2. 计算反馈电阻：$R_f = |A_v| \cdot R_1 = 20 \times 10k\Omega = 200k\Omega$
3. 选择平衡电阻：$R_p = R_1 \parallel R_f = 10k\Omega \parallel 200k\Omega \approx 9.5k\Omega$
4. 选择标准电阻值：$R_1 = 10k\Omega$，$R_f = 200k\Omega$，$R_p = 10k\Omega$

**最终电路：**
- $R_1 = 10k\Omega$
- $R_f = 200k\Omega$
- $R_p = 10k\Omega$
- 运放选择：LM358或等效器件

### 8.9.2 有源低通滤波器设计实例

**设计要求：**
- 截止频率：$1kHz$
- 直流增益：$2$倍
- 巴特沃斯特性

**设计步骤：**
1. 选择电容值：$C = 0.01\mu F$
2. 计算电阻值：$R = \frac{1}{2\pi f_c C} = \frac{1}{2\pi \times 1000 \times 0.01 \times 10^{-6}} \approx 15.9k\Omega$
3. 选择标准电阻值：$R = 16k\Omega$
4. 设置增益：$A_0 = 2$，选择$R_1 = 10k\Omega$，$R_f = 10k\Omega$

**最终电路：**
- $R = 16k\Omega$
- $C = 0.01\mu F$
- $R_1 = 10k\Omega$
- $R_f = 10k\Omega$

## 8.10 总结

运算放大器是模拟电路中的核心器件，通过不同的反馈配置可以实现多种功能：

1. **基本放大器**：
   - 反相放大器：$A_v = -\frac{R_f}{R_1}$
   - 同相放大器：$A_v = 1 + \frac{R_f}{R_1}$
   - 电压跟随器：$A_v = 1$

2. **运算电路**：
   - 加法器：实现多个信号的代数相加
   - 减法器：实现两个信号的差值运算
   - 积分器：实现信号的时间积分
   - 微分器：实现信号的时间微分

3. **有源滤波器**：
   - 低通滤波器：保留低频信号，抑制高频信号
   - 高通滤波器：保留高频信号，抑制低频信号
   - 带通滤波器：保留特定频段的信号
   - 带阻滤波器：抑制特定频段的信号

4. **分析工具**：
   - 虚短：$V_+ = V_-$
   - 虚断：$I_+ = I_- = 0$

掌握虚短虚断的概念是分析运放电路的关键，能够快速准确地分析各种运放电路的工作原理和性能参数。
