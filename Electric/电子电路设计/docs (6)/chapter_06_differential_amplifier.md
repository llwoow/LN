# 第6章 差分放大电路

## 6.1 引言

差分放大电路是模拟电子技术中的核心电路之一，广泛应用于运算放大器、仪表放大器等高性能模拟电路中。差分放大电路能够有效地放大两个输入信号之间的差值，同时抑制共模信号，这种特性使其在噪声抑制和信号完整性方面具有显著优势。

## 6.2 差分放大的基本原理和工作方式

### 6.2.1 基本电路结构

差分放大电路的基本结构由两个特性相同的晶体管组成，其发射极通过公共电阻或恒流源连接。基本的差分放大电路如图所示：

```
    Vcc
     |
    RC1    RC2
     |      |
    Q1     Q2
     |      |
    Vin1   Vin2
     |      |
    Re     |
     |      |
    Vee    |
```

### 6.2.2 工作原理

当两个输入端加上信号时，差分放大电路的工作过程如下：

1. **差模信号输入**：当Vin1和Vin2大小相等、极性相反时，Q1和Q2的集电极电流一增一减，输出电压为两个集电极电压的差值。

2. **共模信号输入**：当Vin1和Vin2大小相等、极性相同时，Q1和Q2的集电极电流同时增加或减少，但由于电路的对称性，输出电压变化很小。

3. **直流偏置**：发射极电阻Re或恒流源提供直流偏置，使晶体管工作在放大区。

### 6.2.3 差分放大的优势

- **噪声抑制**：能够有效抑制共模噪声
- **温度稳定性**：对温度变化引起的参数变化具有抑制作用
- **线性度好**：相对于单端放大器具有更好的线性特性
- **动态范围大**：能够处理较大的输入信号范围

## 6.3 差模信号和共模信号的概念

### 6.3.1 差模信号

差模信号是指两个输入信号之间的差值：

$$V_{dm} = V_{in1} - V_{in2}$$

差模信号是差分放大电路需要放大的有用信号。差分放大电路对差模信号具有很高的增益：

$$A_{dm} = \frac{V_{out}}{V_{dm}}$$

### 6.3.2 共模信号

共模信号是指两个输入信号的共同成分：

$$V_{cm} = \frac{V_{in1} + V_{in2}}{2}$$

共模信号通常是干扰信号或噪声，差分放大电路应该尽可能抑制共模信号。

### 6.3.3 信号分解

任意输入信号都可以分解为差模分量和共模分量：

$$V_{in1} = V_{cm} + \frac{V_{dm}}{2}$$
$$V_{in2} = V_{cm} - \frac{V_{dm}}{2}$$

## 6.4 共模抑制比（CMRR）

### 6.4.1 CMRR的定义

共模抑制比（Common Mode Rejection Ratio, CMRR）是差分放大电路的重要性能指标，定义为差模增益与共模增益的比值：

$$CMRR = \frac{A_{dm}}{A_{cm}}$$

其中：
- $A_{dm}$：差模增益
- $A_{cm}$：共模增益

CMRR通常用分贝（dB）表示：

$$CMRR_{dB} = 20\log_{10}\left(\frac{A_{dm}}{A_{cm}}\right)$$

### 6.4.2 CMRR的计算

#### 6.4.2.1 差模增益计算

对于基本的差分放大电路，差模增益为：

$$A_{dm} = -\frac{\beta R_C}{r_{\pi} + (1+\beta)R_E}$$

当$\beta >> 1$且$R_E$较小时，可近似为：

$$A_{dm} \approx -\frac{R_C}{r_e}$$

其中$r_e = \frac{V_T}{I_E}$为发射极动态电阻。

#### 6.4.2.2 共模增益计算

共模增益为：

$$A_{cm} = -\frac{R_C}{2R_E(1+\beta) + r_{\pi}}$$

当$\beta >> 1$时，可近似为：

$$A_{cm} \approx -\frac{R_C}{2\beta R_E}$$

#### 6.4.2.3 CMRR表达式

将差模增益和共模增益代入CMRR定义：

$$CMRR = \frac{A_{dm}}{A_{cm}} \approx \frac{-\frac{R_C}{r_e}}{-\frac{R_C}{2\beta R_E}} = \frac{2\beta R_E}{r_e}$$

以分贝表示：

$$CMRR_{dB} = 20\log_{10}\left(\frac{2\beta R_E}{r_e}\right)$$

### 6.4.3 提高CMRR的方法

1. **增大发射极电阻**：增大$R_E$可以提高CMRR
2. **使用恒流源**：恒流源具有无穷大的交流电阻，是提高CMRR的最佳方法
3. **电路匹配**：确保两个晶体管特性匹配
4. **负载匹配**：确保两个集电极负载电阻匹配

### 6.4.4 CMRR的频率特性

实际的CMRR是频率的函数：

$$CMRR(f) = \frac{CMRR_{DC}}{\sqrt{1 + \left(\frac{f}{f_{CMRR}}\right)^2}}$$

其中$f_{CMRR}$是CMRR的截止频率。

## 6.5 恒流源偏置电路的作用和设计

### 6.5.1 恒流源的作用

1. **提供稳定的直流偏置**：恒流源能够为差分对管提供稳定的发射极电流
2. **提高共模抑制比**：恒流源的交流电阻很大，有效抑制共模信号
3. **温度补偿**：恒流源具有温度补偿特性
4. **扩大线性工作范围**：允许更大的输入信号范围

### 6.5.2 简单恒流源电路

基本的镜像恒流源电路：

```
    Vcc
     |
    Q3
     |
    R   Q1
     |  |
     |  Iref
     |  |
     Q2
     |
    Iout
```

其中：
- $I_{ref} = \frac{V_{cc} - V_{BE3}}{R}$
- $I_{out} \approx I_{ref}$（假设Q1和Q2匹配）

### 6.5.3 改进的恒流源

#### 6.5.3.1 Widlar恒流源

Widlar恒流源在发射极加入电阻，能够获得较小的输出电流：

$$I_{out} = \frac{V_T}{R_E}\ln\left(\frac{I_{ref}}{I_{out}}\right)$$

#### 6.5.3.2 Wilson恒流源

Wilson恒流源具有更好的电流镜精度和输出电阻：

$$I_{out} = I_{ref}\left(1 - \frac{2}{\beta^2 + 2\beta + 2}\right)$$

### 6.5.4 恒流源的设计要点

1. **电流精度**：选择合适的电路结构以获得所需的电流精度
2. **输出电阻**：恒流源的输出电阻应尽可能大
3. **温度稳定性**：考虑温度对电流的影响
4. **电压余量**：确保恒流管有足够的工作电压

## 6.6 失调电压和失调电流的定义和影响

### 6.6.1 失调电压

#### 6.6.1.1 输入失调电压的定义

输入失调电压（Input Offset Voltage, $V_{OS}$）是指使输出电压为零时需要在输入端施加的直流电压：

$$V_{OS} = V_{BE1} - V_{BE2}$$

#### 6.6.1.2 失调电压的来源

1. **晶体管不匹配**：两个晶体管的$V_{BE}$特性差异
2. **电阻不匹配**：集电极电阻或发射极电阻的差异
3. **工艺偏差**：制造过程中的参数偏差

#### 6.6.1.3 失调电压的计算

对于差分放大电路：

$$V_{OS} = \Delta V_{BE} + \frac{\Delta R_C}{R_C}V_{BE}$$

其中：
- $\Delta V_{BE}$：两个晶体管$V_{BE}$的差值
- $\Delta R_C$：两个集电极电阻的差值

### 6.6.2 失调电流

#### 6.6.2.1 输入失调电流的定义

输入失调电流（Input Offset Current, $I_{OS}$）是指使输出电压为零时两个输入端的偏置电流之差：

$$I_{OS} = |I_{B1} - I_{B2}|$$

#### 6.6.2.2 失调电流的来源

1. **晶体管β不匹配**：两个晶体管的电流增益差异
2. **工艺偏差**：制造过程中的参数偏差

#### 6.6.2.3 失调电流的计算

$$I_{OS} = I_{B1} - I_{B2} = \frac{I_{C1}}{\beta_1} - \frac{I_{C2}}{\beta_2}$$

### 6.6.3 失调对性能的影响

#### 6.6.3.1 输出失调电压

输出失调电压为：

$$V_{out,OS} = A_{dm}V_{OS} + A_{cm}I_{OS}R_S$$

其中$R_S$是信号源内阻。

#### 6.6.3.2 温度漂移

失调电压和失调电流随温度的变化：

$$\frac{dV_{OS}}{dT} \approx \frac{\Delta V_{BE}}{T}$$
$$\frac{dI_{OS}}{dT} = I_{B1}\frac{1}{\beta_1}\frac{d\beta_1}{dT} - I_{B2}\frac{1}{\beta_2}\frac{d\beta_2}{dT}$$

### 6.6.4 失调的补偿方法

1. **零点调整**：通过外接电位器调整零点
2. **激光修调**：在生产过程中进行精确调整
3. **自动调零**：使用斩波稳零技术
4. **电路匹配**：提高器件匹配精度

## 6.7 差分放大器的传输特性和小信号模型

### 6.7.1 传输特性

#### 6.7.1.1 差模传输特性

差分放大电路的差模传输特性描述了输出电流与输入差模电压的关系：

$$I_{C1} = I_S e^{V_{BE1}/V_T}$$
$$I_{C2} = I_S e^{V_{BE2}/V_T}$$

总电流：

$$I_{EE} = I_{C1} + I_{C2} = I_S e^{V_{BE1}/V_T} + I_S e^{V_{BE2}/V_T}$$

单端输出电流：

$$I_{C1} = \frac{I_{EE}}{1 + e^{-V_{dm}/V_T}}$$
$$I_{C2} = \frac{I_{EE}}{1 + e^{V_{dm}/V_T}}$$

其中$V_{dm} = V_{BE1} - V_{BE2}$。

#### 6.7.1.2 传输特性的线性区

当$|V_{dm}| << V_T$时，传输特性近似线性：

$$I_{C1} \approx \frac{I_{EE}}{2} + \frac{I_{EE}}{4V_T}V_{dm}$$
$$I_{C2} \approx \frac{I_{EE}}{2} - \frac{I_{EE}}{4V_T}V_{dm}$$

差模跨导：

$$g_m = \frac{dI_{C1}}{dV_{dm}} = \frac{I_{EE}}{4V_T}$$

### 6.7.2 小信号模型

#### 6.7.2.1 差模小信号模型

差分放大电路的差模小信号模型：

- 输入电阻：$r_{id} = 2r_{\pi}$
- 电压增益：$A_{dm} = -\frac{\beta R_C}{r_{\pi} + (1+\beta)R_E}$
- 输出电阻：$r_{od} = R_C$

#### 6.7.2.2 共模小信号模型

共模小信号模型：

- 输入电阻：$r_{ic} = \frac{r_{\pi} + (1+\beta)R_E}{2}$
- 电压增益：$A_{cm} = -\frac{R_C}{2R_E(1+\beta) + r_{\pi}}$
- 输出电阻：$r_{oc} = R_C$

### 6.7.3 频率响应

#### 6.7.3.1 差模频率响应

差模增益的频率特性：

$$A_{dm}(s) = \frac{A_{dm0}}{1 + s/\omega_{dm}}$$

其中$\omega_{dm}$是差模截止频率。

#### 6.7.3.2 共模频率响应

共模增益的频率特性：

$$A_{cm}(s) = \frac{A_{cm0}}{1 + s/\omega_{cm}}$$

其中$\omega_{cm}$是共模截止频率，通常低于差模截止频率。

## 6.8 差分放大器的应用

### 6.8.1 运算放大器输入级

#### 6.8.1.1 基本结构

运算放大器的输入级通常采用差分放大电路，具有以下特点：

1. **高输入阻抗**：减少对信号源的负载影响
2. **高CMRR**：抑制共模干扰
3. **低失调**：提高直流精度
4. **宽带宽**：满足信号处理需求

#### 6.8.1.2 典型的运放输入级

```
        Vcc
         |
        RC1   RC2
         |     |
        Q1    Q2  ← 差分对管
         |     |
        Vin+  Vin-
         |     |
        Q3    Q4  ← 电流镜负载
         |     |
        IEE   |
         |     |
        Vee   |
```

### 6.8.2 仪表放大器

#### 6.2.2.1 三运放仪表放大器

仪表放大器采用三级差分放大结构：

1. **输入级**：两个同相放大器，提供高输入阻抗
2. **差分放大级**：差分放大电路，提供CMRR
3. **输出级**：缓冲放大器，提供低输出阻抗

#### 6.8.2.2 性能指标

- **增益**：$G = 1 + \frac{R_3}{R_2} + \frac{R_3}{R_1}(1 + \frac{R_3}{R_2})$
- **输入阻抗**：$R_{in} \approx 2R_1$
- **CMRR**：主要取决于差分放大级的CMRR

### 6.8.3 电流检测放大器

#### 6.8.3.1 基本原理

电流检测放大器用于检测负载电流：

$$V_{out} = I_{load} \times R_{sense} \times G$$

其中：
- $R_{sense}$：检测电阻
- $G$：放大器增益

#### 6.8.3.2 高侧电流检测

高侧电流检测将检测电阻放在电源和负载之间：

- **优点**：能够检测地线故障
- **缺点**：需要高共模电压输入能力

### 6.8.4 音频功率放大器

#### 6.8.4.1 差分输入级

音频功率放大器的输入级采用差分放大电路：

1. **提供高输入阻抗**
2. **抑制电源噪声**
3. **改善音质**

#### 6.8.4.2 性能要求

- **低噪声**：$e_n < 10nV/\sqrt{Hz}$
- **高CMRR**：$CMRR > 80dB$
- **低失真**：$THD < 0.01\%$

## 6.9 设计实例

### 6.9.1 设计指标

设计一个差分放大电路，要求：
- 差模增益：40dB
- CMRR：>80dB
- 输入失调电压：<2mV
- 电源电压：±12V

### 6.9.2 电路设计

#### 6.9.2.1 晶体管选择

选择匹配的NPN晶体管对：
- $V_{CEO} > 20V$
- $\beta > 100$
- $V_{BE}$匹配度：<2mV

#### 6.9.2.2 偏置电路设计

恒流源电流：$I_{EE} = 1mA$

镜像恒流源：
- $R = \frac{12V - 0.7V}{1mA} = 11.3k\Omega$
- 选择标准值：$R = 12k\Omega$

#### 6.9.2.3 集电极电阻

差模增益：$A_{dm} = 40dB = 100$

$$R_C = \frac{A_{dm} \times r_e}{1} = \frac{100 \times 26\Omega}{1} = 2.6k\Omega$$

选择标准值：$R_C = 2.7k\Omega$

#### 6.9.2.4 CMRR验证

$$CMRR_{dB} = 20\log_{10}\left(\frac{2\beta R_E}{r_e}\right)$$

假设$\beta = 100$，$R_E = r_o$（恒流源输出电阻）

$$CMRR_{dB} = 20\log_{10}\left(\frac{2 \times 100 \times 100k\Omega}{26\Omega}\right) = 97.7dB > 80dB$$

满足要求。

### 6.9.3 仿真验证

通过SPICE仿真验证设计：
1. 差模增益：39.6dB
2. CMRR：95dB
3. 输入失调电压：1.2mV
4. -3dB带宽：1.2MHz

## 6.10 本章小结

差分放大电路是现代模拟电子技术的基石，具有以下重要特性：

1. **基本原理**：通过对称电路结构实现差模信号放大和共模信号抑制
2. **关键指标**：CMRR是衡量差分放大电路性能的重要指标，直接影响电路的抗干扰能力
3. **恒流源偏置**：恒流源是提高CMRR的关键技术，提供高交流电阻
4. **失调特性**：输入失调电压和失调电流是限制直流精度的主要因素
5. **传输特性**：小信号模型为电路分析和设计提供理论基础
6. **广泛应用**：差分放大电路是运算放大器、仪表放大器等高性能模拟电路的核心

深入理解差分放大电路的工作原理和设计方法，对于掌握现代模拟电子技术具有重要意义。在实际应用中，需要综合考虑增益、CMRR、失调、带宽、功耗等多个性能指标的权衡，以满足具体的应用需求。
