# 第十章 振荡器

## 10.1 振荡器的基本原理

### 10.1.1 振荡的基本概念

振荡器是一种能够将直流电能转换为交流电能的电子电路，它在无需外部输入信号的情况下，能够产生周期性变化的输出信号。振荡器是电子系统中重要的信号源，广泛应用于通信、测量、控制等领域。

### 10.1.2 振荡的基本条件

振荡器的核心是正反馈机制。当放大器输出的信号通过反馈网络后，再送回输入端且相位合适时，电路就会产生自激振荡。

**巴克豪森准则（Barkhausen Criteria）**

振荡器要维持振荡必须满足两个基本条件：

1. **幅度条件**：反馈信号的幅度必须等于或大于维持振荡所需的最小值
   $$\left| A(\omega) \beta(\omega) \right| \geq 1$$

2. **相位条件**：反馈信号与输入信号必须同相，即总相移为0°或360°的整数倍
   $$\phi_A(\omega) + \phi_\beta(\omega) = 2n\pi \quad (n = 0, 1, 2, ...)$$

其中：
- $A(\omega)$ 为放大器的电压增益
- $\beta(\omega)$ 为反馈系数
- $\phi_A(\omega)$ 为放大器的相移
- $\phi_\beta(\omega)$ 为反馈网络的相移

### 10.1.3 振荡的建立过程

振荡器的建立过程可分为三个阶段：

1. **起振阶段**：初始扰动信号被放大并反馈，形成增幅振荡
2. **稳定阶段**：非线性元件限制振幅，达到平衡状态
3. **维持阶段**：在平衡点附近维持等幅振荡

## 10.2 LC振荡器

LC振荡器使用电感（L）和电容（C）组成的谐振回路作为选频网络，具有较高的频率稳定性和品质因数。

### 10.2.1 哈特莱振荡器（Hartley Oscillator）

**电路结构**
哈特莱振荡器采用电感分压式反馈网络，电感线圈具有抽头，将电感分为L₁和L₂两部分。

**振荡频率**
$$\omega_0 = \frac{1}{\sqrt{L_{eq}C}}$$

其中等效电感：
$$L_{eq} = L_1 + L_2 + 2M$$

M为L₁和L₂之间的互感。

**振荡条件**
- 幅度条件：$A_v \geq \frac{L_1}{L_2}$
- 相位条件：180°相移（放大器反相 + 反馈网络0°相移）

**特点**
- 频率调节范围宽
- 输出波形好
- 频率稳定性中等

### 10.2.2 考比兹振荡器（Colpitts Oscillator）

**电路结构**
考比兹振荡器采用电容分压式反馈网络，电容C₁和C₂构成反馈网络。

**振荡频率**
$$\omega_0 = \frac{1}{\sqrt{L_{eq}C_{eq}}}$$

其中：
$$C_{eq} = \frac{C_1C_2}{C_1 + C_2}$$

**振荡条件**
- 幅度条件：$A_v \geq \frac{C_2}{C_1}$
- 相位条件：180°相移

**特点**
- 频率稳定性较好
- 谐波含量低
- 适用于高频振荡

### 10.2.3 克拉普振荡器（Clapp Oscillator）

**电路结构**
克拉普振荡器在考比兹振荡器的基础上，在电感支路中串联一个可调电容C₃。

**振荡频率**
$$\omega_0 = \frac{1}{\sqrt{L\left(C_3 + \frac{C_1C_2}{C_1 + C_2}\right)}}$$

当$C_3 \ll \frac{C_1C_2}{C_1 + C_2}$时：
$$\omega_0 \approx \frac{1}{\sqrt{LC_3}}$$

**特点**
- 频率稳定性最高
- 频率调节范围宽
- 适用于精密频率源

## 10.3 RC振荡器

RC振荡器使用电阻和电容组成的网络作为选频电路，适用于低频振荡，具有结构简单、成本低廉的优点。

### 10.3.1 文氏电桥振荡器（Wien Bridge Oscillator）

**电路结构**
文氏电桥振荡器由同相放大器和文氏电桥反馈网络组成。

**振荡频率**
$$\omega_0 = \frac{1}{RC}$$

$$f_0 = \frac{1}{2\pi RC}$$

**文氏电桥传输函数**
$$\beta(\omega) = \frac{1}{3 + j\left(\frac{\omega}{\omega_0} - \frac{\omega_0}{\omega}\right)}$$

在$\omega = \omega_0$时：
$$\beta(\omega_0) = \frac{1}{3}$$

**振荡条件**
- 幅度条件：$A_v \geq 3$
- 相位条件：0°（同相放大器 + 0°反馈网络）

**频率稳定性分析**

振荡频率的相对变化：
$$\frac{\Delta f_0}{f_0} = \frac{1}{2}\left(\frac{\Delta R}{R} + \frac{\Delta C}{C}\right)$$

### 10.3.2 相移振荡器（Phase Shift Oscillator）

**电路结构**
相移振荡器由反相放大器和三级RC相移网络组成。

**振荡频率**
$$\omega_0 = \frac{1}{\sqrt{6}RC}$$

$$f_0 = \frac{1}{2\pi\sqrt{6}RC}$$

**相移网络特性**
每级RC网络在谐振频率处提供60°相移，三级共180°相移，加上放大器的180°反相，总相移为360°。

**振荡条件**
- 幅度条件：$A_v \geq 29$
- 相位条件：360°（180° + 3×60°）

## 10.4 石英晶体振荡器

石英晶体具有优异的频率稳定性，是精密振荡器的核心元件。

### 10.4.1 石英晶体的压电效应

石英晶体具有压电效应，当施加电场时会产生机械振动，反之亦然。这种机电耦合形成了晶体的高Q值谐振特性。

### 10.4.2 石英晶体的等效电路

石英晶体的等效电路包含：
- 等效电感$L_q$（很大，通常为几十mH到几百mH）
- 等效电容$C_q$（很小，通常为几fF到几十fF）
- 串联电阻$R_q$（通常为几Ω到几百Ω）
- 并联电容$C_0$（静态电容，通常为几pF）

### 10.4.3 串联谐振

**串联谐振频率**
$$\omega_s = \frac{1}{\sqrt{L_qC_q}}$$

**串联谐振时的阻抗**
在串联谐振频率处，晶体呈纯电阻性，阻抗最小：
$$R_s = R_q$$

### 10.4.4 并联谐振

**并联谐振频率**
$$\omega_p = \omega_s\sqrt{1 + \frac{C_q}{C_0}}$$

由于$C_q \ll C_0$，因此：
$$\omega_p \approx \omega_s\left(1 + \frac{C_q}{2C_0}\right)$$

**并联谐振时的阻抗**
在并联谐振频率处，晶体呈高阻抗。

### 10.4.5 频率稳定性分析

**频率温度系数**
石英晶体的频率温度特性可用三次多项式表示：
$$\frac{\Delta f}{f_0} = a(\Delta T) + b(\Delta T)^2 + c(\Delta T)^3$$

其中a、b、c为温度系数，ΔT为温度变化。

**老化效应**
晶体频率随时间的变化：
$$\frac{\Delta f}{f_0} = k \log(t + t_0)$$

其中k为老化系数，t为工作时间。

## 10.5 振荡频率稳定性和温度补偿

### 10.5.1 频率稳定性的衡量指标

**绝对频率稳定度**
$$\frac{\Delta f}{f_0} = \frac{f - f_0}{f_0}$$

**相对频率稳定度**
$$\frac{\Delta f}{f_0} \bigg|_{\text{相对}} = \frac{f(t_2) - f(t_1)}{f_0(t_1)}$$

### 10.5.2 影响频率稳定性的因素

1. **温度变化**
   - 元件参数随温度变化
   - 晶体频率温度系数

2. **电源电压变化**
   - 放大器工作点变化
   - 频率控制元件参数变化

3. **负载变化**
   - 输出阻抗变化
   - 频率牵引效应

4. **机械振动**
   - 晶体机械应力
   - 电路元件位移

### 10.5.3 温度补偿技术

**晶体温度补偿**
使用具有相反温度系数的电容与晶体串联或并联：
$$C_T = C_0 \left[1 + \alpha_T(T - T_0)\right]$$

其中$\alpha_T$为温度补偿系数。

**电路温度补偿**
- 使用温度敏感元件（如热敏电阻）
- 采用差分电路结构
- 恒温控制

### 10.5.4 稳频措施

1. **高Q值谐振回路**
   $$Q = \frac{\omega_0 L}{R}$$

2. **低噪声电源**
   - 使用稳压电源
   - 电源去耦滤波

3. **屏蔽和隔离**
   - 电磁屏蔽
   - 机械减震

4. **恒温控制**
   - 晶体恒温槽
   - 温度控制电路

## 10.6 频率调节和频率合成技术

### 10.6.1 频率调节方法

**LC振荡器的频率调节**

1. **可变电容调节**
   $$f_0 = \frac{1}{2\pi\sqrt{LC}}$$

2. **可变电感调节**
   - 磁芯调节
   - 抽头切换

**晶体振荡器的频率调节**

1. **负载电容调节**
   $$f = f_s\left[1 + \frac{C_q}{2(C_0 + C_L)}\right]$$

2. **变容二极管调节**
   $$C_V = \frac{C_{V0}}{\left(1 + \frac{V_R}{V_0}\right)^n}$$

其中n为变容指数（通常为0.3-0.5）。

### 10.6.2 频率合成技术

**直接频率合成（DS）**

使用多个晶体振荡器和混频器、分频器组合：
$$f_{out} = \pm f_1 \pm f_2 \pm \cdots \pm f_n$$

**间接频率合成（PLL）**

使用锁相环技术：
$$f_{out} = N \cdot f_{ref}$$

其中N为分频比。

**锁相环基本方程**
$$\theta_e(t) = \theta_i(t) - \frac{\theta_o(t)}{N}$$

稳态时：
$$\omega_o = N \cdot \omega_{ref}$$

**锁相环传递函数**
- 开环传递函数：$G(s) = \frac{K_dK_vF(s)}{s}$
- 闭环传递函数：$H(s) = \frac{G(s)}{1 + G(s)}$

其中：
- $K_d$为鉴相器增益
- $K_v$为VCO增益
- $F(s)$为环路滤波器传递函数

### 10.6.3 频率合成器性能指标

**频率分辨率**
$$\Delta f_{min} = \frac{f_{ref}}{N_{max}}$$

**频率切换时间**
$$t_{sw} \approx \frac{2\pi}{\omega_n}$$

其中$\omega_n$为环路自然频率。

**相位噪声**
$$L(f_m) = 10\log\left[\frac{P_{noise}(f_m)}{P_{carrier}}\right]$$

## 10.7 振荡器的失真和噪声分析

### 10.7.1 振荡器的非线性失真

**失真产生机制**

1. **放大器非线性**
   - 晶体管转移特性非线性
   - 动态范围限制

2. **谐振回路非线性**
   - 电感磁饱和
   - 电容电压系数

**谐波失真分析**

输出信号：
$$v_o(t) = V_0\sin(\omega_0 t) + V_2\sin(2\omega_0 t) + V_3\sin(3\omega_0 t) + \cdots$$

总谐波失真（THD）：
$$THD = \frac{\sqrt{V_2^2 + V_3^2 + \cdots}}{V_0} \times 100\%$$

**失真抑制方法**

1. **负反馈**
   $$THD_{fb} = \frac{THD_{ol}}{1 + A\beta}$$

2. **A类工作状态**
   - 静态工作点设置
   - 偏置稳定

3. **滤波**
   - 谐振回路选频
   - 外加滤波器

### 10.7.2 振荡器的噪声分析

**噪声源**

1. **热噪声**
   $$v_n^2 = 4kTR\Delta f$$

2. **散粒噪声**
   $$i_n^2 = 2qI\Delta f$$

3. **1/f噪声**
   $$S_{1/f}(f) = \frac{K}{f}$$

4. **相位噪声**
   $$\mathcal{L}(f_m) = 10\log\left[\frac{P_{sideband}(f_m)}{P_{carrier}}\right]$$

**相位噪声模型**

Leeson模型：
$$\mathcal{L}(f_m) = 10\log\left[\frac{FkT}{P_{signal}}\left(1 + \frac{f_c}{f_m}\right)\left(1 + \left(\frac{f_0}{2Q_Lf_m}\right)^2\right)\right]$$

其中：
- F为噪声系数
- $f_c$为1/f噪声转角频率
- $Q_L$为有载Q值
- $f_0$为载波频率

**噪声对频率稳定性的影响**

短期频率稳定度：
$$\sigma_y(\tau) = \sqrt{\frac{1}{2(n-1)}\sum_{i=1}^{n-1}(y_{i+1} - y_i)^2}$$

其中$y_i = \frac{f_i - f_0}{f_0}$为相对频率偏差。

**噪声抑制技术**

1. **高Q值谐振回路**
   $$Q = \frac{\omega_0}{\Delta\omega_{3dB}}$$

2. **低噪声设计**
   - 低噪声器件选择
   - 最佳噪声匹配

3. **电源滤波**
   $$L_{PSRR} = 20\log\left(\frac{V_{supply}}{V_{output}}\right)$$

4. **屏蔽和接地**
   - 单点接地
   - 电磁屏蔽

### 10.7.3 频率抖动分析

**频率抖动的时域表征**
$$J_{pk-pk} = t_{max} - t_{min}$$

**频率抖动的频域表征**
$$S_{\phi}(f) = \frac{\mathcal{L}(f_m)}{f_m^2}$$

**抖动传递函数**
$$H_{jitter}(s) = \frac{s^2}{s^2 + 2\zeta\omega_ns + \omega_n^2}$$

## 10.8 振荡器设计实例

### 10.8.1 哈特莱振荡器设计

**设计要求**
- 振荡频率：$f_0 = 1$ MHz
- 频率稳定度：$\pm 0.1\%$
- 输出电压：$V_{pp} = 2$ V

**设计步骤**

1. **选择晶体管**
   - 频率响应：$f_T > 10f_0 = 10$ MHz
   - 噪声系数：$NF < 3$ dB

2. **计算LC参数**
   $$L_{eq} = \frac{1}{\omega_0^2C}$$

选择$C = 100$ pF，则：
$$L_{eq} = \frac{1}{(2\pi \times 10^6)^2 \times 100 \times 10^{-12}} = 253.3 \mu H$$

3. **确定反馈比**
   $$\frac{L_1}{L_2} = \frac{1}{3} \quad (\text{假设})$$

则：$L_1 = 63.3 \mu H$，$L_2 = 190 \mu H$

4. **设计偏置电路**
   $$I_C = 2 \text{ mA}$$
   $$V_{CE} = 5 \text{ V}$$

### 10.8.2 晶体振荡器设计

**设计要求**
- 标称频率：$f_0 = 10$ MHz
- 频率稳定度：$\pm 50$ ppm
- 相位噪声：$L(1\text{kHz}) < -120$ dBc/Hz

**设计步骤**

1. **选择晶体**
   - 频率：$10$ MHz
   - 负载电容：$C_L = 20$ pF
   - 串联电阻：$R_q < 50$ Ω

2. **计算负载电容**
   $$C_{total} = \frac{C_1C_2}{C_1 + C_2} + C_{stray}$$

选择$C_1 = C_2 = 33$ pF，则：
$$C_{total} = \frac{33 \times 33}{33 + 33} + 2 = 18.5 \text{ pF}$$

3. **设计放大器**
   - 增益：$A_v > 3$
   - 输入阻抗：$R_{in} > 1$ MΩ
   - 输出阻抗：$R_{out} < 100$ Ω

4. **频率调节电路**
   使用变容二极管进行微调：
   $$C_V = \frac{C_{V0}}{\left(1 + \frac{V_R}{V_0}\right)^n}$$

## 10.9 小结

振荡器作为电子系统中的重要组成部分，其设计涉及多个方面的考虑：

1. **基本原理**：基于巴克豪森准则的振荡条件是振荡器工作的理论基础。

2. **类型选择**：
   - LC振荡器适用于高频、高稳定性场合
   - RC振荡器适用于低频、简单应用
   - 晶体振荡器适用于精密频率源

3. **频率稳定性**：是衡量振荡器性能的重要指标，需要从温度补偿、稳频措施等多个方面进行优化。

4. **频率合成**：现代通信系统对频率源的要求越来越高，频率合成技术是实现精确频率控制的关键。

5. **失真和噪声**：影响输出信号质量，需要通过合理设计和优化来抑制。

6. **实际设计**：需要综合考虑性能指标、成本、功耗等多个因素，选择合适的设计方案。

振荡器技术的发展趋势是向更高频率稳定性、更低相位噪声、更小功耗和更高集成度方向发展。随着新材料、新工艺的应用，振荡器的性能将不断提升，为电子系统提供更加优质的时钟源。
