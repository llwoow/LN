# 第七章 功率放大电路

## 7.1 概述

功率放大电路是电子系统中的关键组成部分，其主要功能是将小信号放大到能够驱动负载（如扬声器、电机等）的功率电平。根据工作状态的不同，功率放大器可分为A类、B类、AB类和C类四种基本类型。

## 7.2 A类功率放大器

### 7.2.1 工作原理

A类功率放大器是最基本的功率放大器类型，其特点是**晶体管在整个信号周期内都处于导通状态**。

**工作特点：**
- 静态工作点设置在负载线的中点
- 晶体管在整个输入信号周期内都导通
- 输出信号是输入信号的线性放大
- 无交越失真

**电路结构：**
```
    VCC
     |
    [RC]
     |
    [Q1]------输出
     |
    [RL]
     |
    GND
```

### 7.2.2 效率计算

A类功率放大器的效率计算如下：

**电源供给功率：**
$$P_{CC} = V_{CC} \cdot I_{CC}$$

其中，$I_{CC}$是电源提供的平均电流。

**输出功率：**
$$P_o = \frac{V_{om}^2}{2R_L}$$

其中，$V_{om}$是输出电压峰值，$R_L$是负载电阻。

**效率：**
$$\eta = \frac{P_o}{P_{CC}} = \frac{V_{om}^2}{2R_L V_{CC} I_{CC}}$$

**理论最大效率：**

对于A类放大器，当输出信号最大且不失真时：
- 电源电压：$V_{CC}$
- 静态电流：$I_{CQ} = \frac{V_{CC}}{2R_L}$
- 最大输出电压峰值：$V_{om} = \frac{V_{CC}}{2}$
- 最大输出功率：$P_{o(max)} = \frac{V_{CC}^2}{8R_L}$
- 电源功率：$P_{CC} = V_{CC} \cdot I_{CQ} = \frac{V_{CC}^2}{2R_L}$

因此：
$$\eta_{max} = \frac{P_{o(max)}}{P_{CC}} = \frac{\frac{V_{CC}^2}{8R_L}}{\frac{V_{CC}^2}{2R_L}} = \frac{1}{4} = 25\%$$

**考虑变压器耦合时：**
如果使用输出变压器，理论最大效率可达：
$$\eta_{max} = 50\%$$

### 7.2.3 失真分析

**主要失真类型：**

1. **非线性失真**
   - 由于晶体管特性曲线的非线性
   - 谐波失真系数：$THD = \sqrt{\sum_{n=2}^{\infty} \frac{V_n^2}{V_1^2}}$
   
2. **频率失真**
   - 高频时晶体管增益下降
   - 低频时耦合电容和旁路电容影响
   
3. **温度漂移**
   - 工作点随温度变化而偏移

## 7.3 B类功率放大器

### 7.3.1 工作原理

B类功率放大器采用**推挽结构**，两个晶体管交替工作，每个晶体管只在半个周期内导通。

**工作特点：**
- 静态工作点设置在截止区
- 正半周：NPN管导通，PNP管截止
- 负半周：PNP管导通，NPN管截止
- 无静态功耗

**推挽结构：**
```
    VCC
     |
    [Q1]------输出
     |
    [RL]
     |
    [Q2]
     |
    GND
```

### 7.3.2 效率计算

**电源供给功率：**

对于正半周：
$$P_{CC1} = V_{CC} \cdot \frac{I_{om}}{\pi}$$

对于负半周：
$$P_{CC2} = V_{CC} \cdot \frac{I_{om}}{\pi}$$

总电源功率：
$$P_{CC} = P_{CC1} + P_{CC2} = \frac{2V_{CC}I_{om}}{\pi}$$

**输出功率：**
$$P_o = \frac{V_{om}I_{om}}{2}$$

**效率：**
$$\eta = \frac{P_o}{P_{CC}} = \frac{\frac{V_{om}I_{om}}{2}}{\frac{2V_{CC}I_{om}}{\pi}} = \frac{\pi V_{om}}{4V_{CC}}$$

**理论最大效率：**

当$V_{om} = V_{CC}$时：
$$\eta_{max} = \frac{\pi}{4} \approx 78.5\%$$

### 7.3.3 交越失真

**交越失真产生机理：**

在B类放大器中，由于晶体管的导通电压（硅管约0.7V，锗管约0.3V），当输入信号幅度小于导通电压时，两个晶体管都处于截止状态，导致输出信号在零点附近出现失真。

**失真特点：**
- 发生在输出信号的零点附近
- 波形出现"缺口"
- 影响小信号放大质量

**抑制方法：**
1. 使用二极管提供偏置电压
2. 采用AB类工作方式
3. 使用运算放大器进行预放大

## 7.4 AB类功率放大器

### 7.4.1 特点和应用

AB类功率放大器是A类和B类的折中方案，结合了两者的优点。

**工作特点：**
- 静态工作点设置在略高于截止区
- 小信号时两个晶体管都微导通
- 大信号时类似B类工作
- 既有较高的效率，又无交越失真

**偏置电路：**
```
    VCC
     |
    [R1]
     |
    [D1][D2]
     |
    [R2]
     |
    GND
```

**效率特点：**
- 效率介于A类和B类之间
- 通常在60%-70%范围内
- 实际应用中最为广泛

**典型应用：**
- 音频功率放大器
- 通信设备功率放大
- 仪器仪表驱动电路

## 7.5 C类功率放大器

### 7.5.1 工作原理

C类功率放大器的导通角小于180°，通常用于高频功率放大，特别是射频应用。

**工作特点：**
- 静态工作点设置在深截止区
- 导通角$\theta < 180°$
- 失真很大，但效率很高
- 需要谐振回路选频

**导通角计算：**
$$\theta = 2\arccos\left(\frac{V_{bias}}{V_{im}}\right)$$

其中：
- $V_{bias}$：偏置电压
- $V_{im}$：输入信号峰值

### 7.5.2 效率分析

**效率计算：**

对于C类放大器，效率为：
$$\eta = \frac{\pi}{4} \cdot \frac{\sin\theta - \theta\cos\theta}{\theta - \sin\theta\cos\theta}$$

**理论最大效率：**

当导通角很小时，效率可达到：
$$\eta_{max} \approx 85\%$$

**效率与导通角的关系：**
- $\theta = 180°$（B类）：$\eta = 78.5\%$
- $\theta = 120°$：$\eta \approx 82\%$
- $\theta = 90°$：$\eta \approx 85\%$
- $\theta = 60°$：$\eta \approx 87\%$

## 7.6 四种类型功率放大器对比

### 7.6.1 工作状态对比

| 类型 | 导通角 | 静态功耗 | 效率 | 失真 | 应用场合 |
|------|--------|----------|------|------|----------|
| A类  | 360°   | 大       | 低   | 小   | 高保真音响 |
| B类  | 180°   | 极小     | 高   | 交越失真 | 一般音频 |
| AB类 | 180°-360° | 小     | 中等 | 小   | 通用功率放大 |
| C类  | <180°  | 极小     | 极高 | 极大 | 射频功率放大 |

### 7.6.2 效率对比

```
效率比较图：
C类: ████████████████████ 85%
AB类: ████████████████    65%
B类:  ██████████████      78.5%
A类:  ██████              25-50%
```

### 7.6.3 功率管功耗分析

**A类放大器：**
$$P_C = P_{CC} - P_o = \frac{V_{CC}^2}{2R_L} - \frac{V_{om}^2}{2R_L}$$

**B类放大器：**
$$P_C = \frac{2V_{CC}}{\pi} \cdot \frac{V_{CC}-V_{om}}{R_L}$$

## 7.7 功率放大器的散热设计和热管理

### 7.7.1 热阻分析

**热阻概念：**
热阻表示热量传递的阻力，单位为°C/W。

**热阻网络：**
```
结温 Tj ----[RθJC]---- 壳温 Tc ----[RθCS]---- 散热器温度 Ts ----[RθSA]---- 环境温度 Ta
```

**总热阻：**
$$R_{θJA} = R_{θJC} + R_{θCS} + R_{θSA}$$

**结温计算：**
$$T_j = T_a + P_d \cdot R_{θJA}$$

其中：
- $T_j$：结温
- $T_a$：环境温度
- $P_d$：功耗
- $R_{θJA}$：总热阻

### 7.7.2 散热器设计

**散热器选择原则：**

1. **功耗计算：**
   $$P_d = \frac{V_{CE(sat)} \cdot I_C + V_{BE} \cdot I_B}{\eta}$$

2. **热阻要求：**
   $$R_{θSA} = \frac{T_j - T_a}{P_d} - R_{θJC} - R_{θCS}$$

3. **散热器类型：**
   - 自然对流散热器
   - 强制风冷散热器
   - 水冷散热器

**散热器尺寸计算：**

对于自然对流散热器：
$$R_{θSA} = \frac{K}{\sqrt[4]{A \cdot H}}$$

其中：
- $K$：常数（通常为400-600）
- $A$：散热器表面积（cm²）
- $H$：散热器高度（cm）

### 7.7.3 热管理策略

**主动散热：**
1. 风扇强制风冷
2. 液冷系统
3. 热电制冷

**被动散热：**
1. 增大散热器面积
2. 使用导热材料
3. 热管技术

**温度保护：**
1. 过热保护电路
2. 温度传感器监控
3. 自动降功率运行

## 7.8 功率管的选用和安全工作区（SOA）

### 7.8.1 安全工作区（SOA）

**SOA定义：**
安全工作区（Safe Operating Area）是功率晶体管能够安全工作的电压、电流和功耗范围。

**SOA曲线限制因素：**

1. **最大集电极电流：**
   $$I_C < I_{C(max)}$$

2. **最大集电极-发射极电压：**
   $$V_{CE} < V_{CEO}$$

3. **最大功耗限制：**
   $$P_C = V_{CE} \cdot I_C < P_{C(max)}$$

4. **二次击穿限制：**
   $$P_{SB} = V_{CE} \cdot I_C < P_{SB(max)}$$

**SOA曲线方程：**

对于功耗限制：
$$I_C = \frac{P_{C(max)}}{V_{CE}}$$

对于二次击穿：
$$I_C = \frac{P_{SB(max)}}{V_{CE}}$$

### 7.8.2 功率管参数选择

**关键参数：**

1. **电压参数：**
   - $V_{CEO}$：集电极-发射极击穿电压
   - $V_{BE}$：基极-发射极电压
   - $V_{CES}$：集电极-发射极饱和电压

2. **电流参数：**
   - $I_C$：连续集电极电流
   - $I_B$：基极电流
   - $I_{CM}$：脉冲集电极电流

3. **功率参数：**
   - $P_C$：集电极功耗
   - $P_{tot}$：总功耗

4. **频率参数：**
   - $f_T$：特征频率
   - $f_{max}$：最大振荡频率

**选择原则：**
1. 电压余量：$V_{CEO} \geq 2V_{CC}$
2. 电流余量：$I_C \geq 2I_{C(max)}$
3. 功率余量：$P_C \geq 2P_{C(max)}$
4. 频率要求：$f_T \geq 10f_{signal}$

### 7.8.3 功率管的并联使用

**并联均流：**

当单个功率管不足以满足功率要求时，需要多个功率管并联：

1. **发射极电阻法：**
   $$R_E = \frac{V_{BE}}{I_{C(max)}/n}$$

2. **负反馈法：**
   - 使用电流反馈
   - 自动调节基极电流

**并联计算：**
$$I_{C(total)} = n \cdot I_C$$

其中$n$为并联管数。

## 7.9 推挽功率放大电路的结构和分析

### 7.9.1 基本推挽电路

**电路结构：**
```
    +VCC
      |
     [Q1]---输出---[RL]
      |              |
     [R1]           [R2]
      |              |
     [Q2]-----------GND
```

**工作原理：**
- 正半周：Q1导通，Q2截止
- 负半周：Q2导通，Q1截止
- 输出电压：$V_o = V_{CC} - V_{CE(sat)}$

### 7.9.2 互补对称电路

**电路特点：**
使用NPN和PNP管形成互补对称结构：

```
    +VCC
      |
     [NPN]---输出---[RL]
      |
    [驱动电路]
      |
     [PNP]
      |
    -VCC
```

**输出特性：**
$$V_o = \begin{cases}
V_{CC} - V_{CE(sat1)} & \text{(正半周)} \\
-|V_{CC}| - V_{CE(sat2)} & \text{(负半周)}
\end{cases}$$

### 7.9.3 准互补电路

**电路结构：**
当难以获得匹配的NPN和PNP功率管时，使用同类型管子组成准互补电路：

```
    +VCC
      |
     [Q1]---[Q3]---输出---[RL]
      |      |
     [Q2]    [Q4]
      |      |
    -VCC
```

其中Q1、Q2为同一类型，Q3、Q4为另一类型。

### 7.9.4 电路分析

**电压增益：**

对于共射极放大器：
$$A_v = -\frac{\beta R_L'}{r_{be}}$$

其中：
- $R_L' = R_L || r_{ce}$
- $r_{be} = r_{bb'} + (1+\beta)\frac{V_T}{I_E}$

**输入电阻：**
$$R_i = R_{b1} || R_{b2} || r_{be}$$

**输出电阻：**
$$R_o = R_c || r_{ce}$$

**频率响应：**

低频截止频率：
$$f_L = \frac{1}{2\pi(R_s + r_{be})C_1}$$

高频截止频率：
$$f_H = \frac{1}{2\pi R_L' C_{μ}}$$

### 7.9.5 性能指标

**主要性能指标：**

1. **输出功率：**
   $$P_o = \frac{V_{om}^2}{2R_L}$$

2. **功率增益：**
   $$A_p = \frac{P_o}{P_i} = A_v \cdot A_i$$

3. **效率：**
   $$\eta = \frac{P_o}{P_{CC}} \times 100\%$$

4. **失真度：**
   $$THD = \sqrt{\frac{\sum_{n=2}^{\infty} V_n^2}{V_1^2}} \times 100\%$$

5. **信噪比：**
   $$SNR = 20\log\frac{V_s}{V_n} \text{(dB)}$$

## 7.10 总结

功率放大电路是电子系统中的核心部件，不同类型的功率放大器各有特点：

- **A类放大器**：线性度好，但效率低，适用于高保真应用
- **B类放大器**：效率高，但存在交越失真，适用于一般应用
- **AB类放大器**：兼顾线性和效率，是最常用的类型
- **C类放大器**：效率最高，但失真大，适用于射频应用

在实际设计中，需要根据具体应用要求选择合适的放大器类型，并做好散热设计和热管理，确保功率管工作在安全区域内。同时，合理的电路设计和元件选择也是保证放大器性能的关键因素。
