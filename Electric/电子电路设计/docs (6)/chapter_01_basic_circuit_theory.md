# 第一章 基础电路理论

## 1.1 欧姆定律及其应用

### 1.1.1 欧姆定律基本形式

**欧姆定律**是电路分析的基础定律，描述了电压、电流和电阻之间的关系。

**基本公式：**
$$V = IR$$

其中：
- $V$：电压（单位：伏特，V）
- $I$：电流（单位：安培，A）
- $R$：电阻（单位：欧姆，Ω）

<details>
<summary>🔍 欧姆定律的推导过程</summary>

欧姆定律基于实验观察得出。通过大量实验发现：

1. **线性关系**：在恒温条件下，导体中的电流与两端电压成正比
2. **比例常数**：比例常数为导体的电阻值
3. **数学表达**：$I \propto V$，即 $I = \frac{V}{R}$ 或 $V = IR$

**实验验证：**
- 保持电阻R不变，电压V加倍，电流I也加倍
- 保持电压V不变，电阻R加倍，电流I减半
- 保持电流I不变，电压V加倍，电阻R也加倍
</details>

### 1.1.2 欧姆定律的变形

根据基本公式，可以推导出以下变形公式：

**求电流：**
$$I = \frac{V}{R}$$

**求电阻：**
$$R = \frac{V}{I}$$

### 1.1.3 欧姆定律的应用

<details>
<summary>📝 典型应用实例</summary>

**例题1：基本计算**
已知电阻R = 100Ω，电压V = 12V，求电流I。

解：$I = \frac{V}{R} = \frac{12}{100} = 0.12A = 120mA$

**例题2：功率计算结合**
已知电阻R = 50Ω，通过电流I = 2A，求电压和功率。

解：
- 电压：$V = IR = 2 × 50 = 100V$
- 功率：$P = VI = 100 × 2 = 200W$

**例题3：电阻测量**
已知电压V = 5V，电流I = 25mA，求电阻R。

解：$R = \frac{V}{I} = \frac{5}{0.025} = 200Ω$
</details>

### 1.1.4 考试要点

✅ **必考内容：**
- 欧姆定律三种形式：$V = IR$，$I = \frac{V}{R}$，$R = \frac{V}{I}$
- 串并联电路中的电压电流分配
- 功率与欧姆定律的结合：$P = I^2R = \frac{V^2}{R}$

## 1.2 基尔霍夫定律

基尔霍夫定律是分析复杂电路的基本工具，包括电流定律和电压定律。

### 1.2.1 基尔霍夫电流定律（KCL）

**基尔霍夫电流定律**：在任一时刻，流入任一节点的电流之和等于流出该节点的电流之和。

**数学表达式：**
$$\sum_{k=1}^{n} I_k = 0$$

或：
$$\sum_{k=1}^{n} I_{in} = \sum_{k=1}^{m} I_{out}$$

<details>
<summary>🔍 KCL的推导过程</summary>

**理论基础：**
KCL基于电荷守恒定律。在电路中，电荷既不能产生也不能消失，只能流动。

**推导步骤：**
1. **电荷守恒**：单位时间内流入节点的电荷数 = 流出节点的电荷数
2. **电流定义**：$I = \frac{dQ}{dt}$，即单位时间内通过的电荷量
3. **节点分析**：对于任意节点，$\sum I_{in} - \sum I_{out} = 0$
4. **符号约定**：流入为正，流出为负，则 $\sum I = 0$

**特殊情况：**
- 串联电路：各点电流相等
- 并联电路：总电流等于各支路电流之和
</details>

### 1.2.2 基尔霍夫电压定律（KVL）

**基尔霍夫电压定律**：在任一闭合回路中，各段电压的代数和等于零。

**数学表达式：**
$$\sum_{k=1}^{n} V_k = 0$$

<details>
<summary>🔍 KVL的推导过程</summary>

**理论基础：**
KVL基于能量守恒定律。电荷沿闭合路径移动一周，电场力所做的功为零。

**推导步骤：**
1. **能量守恒**：电荷沿闭合路径移动一周，电势能变化为零
2. **电势差定义**：$V = \frac{W}{Q}$，即单位电荷的电势能变化
3. **闭合路径**：$\sum \Delta V = 0$
4. **符号约定**：沿回路方向，电势升高为正，电势降低为负

**应用要点：**
- 选择回路方向（顺时针或逆时针）
- 电阻电压：$V = IR$（电流方向与回路方向一致时为正）
- 电源电压：$V = E$（正极指向负极方向与回路方向一致时为正）
</details>

### 1.2.3 基尔霍夫定律的应用

<details>
<summary>📝 复杂电路分析实例</summary>

**例题：支路电流法**

电路参数：
- $E_1 = 12V$，$E_2 = 6V$
- $R_1 = 2Ω$，$R_2 = 4Ω$，$R_3 = 6Ω$

求解各支路电流。

**解题步骤：**
1. **设定未知量**：设$I_1$、$I_2$、$I_3$为各支路电流
2. **列写KCL方程**：$I_1 = I_2 + I_3$
3. **列写KVL方程**：
   - 回路1：$E_1 - I_1R_1 - I_3R_3 = 0$
   - 回路2：$-E_2 + I_2R_2 + I_3R_3 = 0$
4. **求解方程组**：
   - $I_1 = 2A$，$I_2 = 1A$，$I_3 = 1A$

**验证**：功率平衡：$P_{电源} = P_{电阻}$
- 电源功率：$12 × 2 + 6 × 1 = 30W$
- 电阻功率：$2^2 × 2 + 1^2 × 4 + 1^2 × 6 = 8 + 4 + 6 = 18W$ ❌
</details>

### 1.2.4 考试要点

✅ **必考内容：**
- KCL：$\sum I_{in} = \sum I_{out}$ 或 $\sum I = 0$
- KVL：$\sum V = 0$（闭合回路）
- 支路电流法、节点电压法的应用
- 串并联电路的等效变换

## 1.3 戴维南定理和诺顿定理

戴维南定理和诺顿定理是简化复杂电路的重要工具。

### 1.3.1 戴维南定理

**戴维南定理**：任何一个线性有源二端网络，都可以用一个电压源和串联电阻的组合来等效代替。

**等效参数：**
- **等效电压源**：$V_{th} = V_{oc}$（开路电压）
- **等效电阻**：$R_{th} = \frac{V_{oc}}{I_{sc}}$（短路电流）

<details>
<summary>🔍 戴维南定理的推导过程</summary>

**理论基础：**
戴维南定理基于线性电路的叠加原理和电源等效变换。

**推导步骤：**
1. **开路电压**：当输出端口开路时，端口电压$V_{oc}$即为等效电压源$V_{th}$
2. **短路电流**：当输出端口短路时，端口电流$I_{sc}$与等效电阻的关系为$V_{th} = I_{sc}R_{th}$
3. **等效电阻**：$R_{th} = \frac{V_{oc}}{I_{sc}}$
4. **验证**：负载接入后，负载电压$V_L = V_{th} \frac{R_L}{R_{th} + R_L}$

**求$R_{th}$的几种方法：**
- 电压源短路，电流源开路，计算输入电阻
- $R_{th} = \frac{V_{oc}}{I_{sc}}$
- 外加电压法：$R_{th} = \frac{V}{I}$
</details>

### 1.3.2 诺顿定理

**诺顿定理**：任何一个线性有源二端网络，都可以用一个电流源和并联电阻的组合来等效代替。

**等效参数：**
- **等效电流源**：$I_{no} = I_{sc}$（短路电流）
- **等效电阻**：$R_{no} = R_{th}$（与戴维南等效电阻相等）

<details>
<summary>🔍 诺顿定理的推导过程</summary>

**理论基础：**
诺顿定理与戴维南定理互为对偶关系，基于电源等效变换。

**推导步骤：**
1. **短路电流**：$I_{sc}$即为等效电流源$I_{no}$
2. **等效电阻**：$R_{no} = R_{th}$（与戴维南等效电阻相同）
3. **等效变换**：$V_{th} = I_{no}R_{no}$，$I_{no} = \frac{V_{th}}{R_{th}}$

**戴维南-诺顿等效变换：**
- 电压源转电流源：$I = \frac{V}{R}$，$R$不变
- 电流源转电压源：$V = IR$，$R$不变
</details>

### 1.3.3 定理应用

<details>
<parameter name="📝 戴维南等效电路求解实例</summary>

**例题：求戴维南等效电路**

电路参数：
- $E = 12V$，$R_1 = 3Ω$，$R_2 = 6Ω$，$R_3 = 2Ω$
- 负载$R_L = 4Ω$

**求解步骤：**

1. **求开路电压$V_{oc}$**：
   - $R_3$开路，电路为$R_1$与$R_2$串联
   - $V_{oc} = E \frac{R_2}{R_1 + R_2} = 12 × \frac{6}{3 + 6} = 8V$

2. **求等效电阻$R_{th}$**：
   - 电压源短路，电流源开路
   - $R_{th} = R_1 // R_2 = \frac{3 × 6}{3 + 6} = 2Ω$

3. **验证负载电压**：
   - $V_L = V_{th} \frac{R_L}{R_{th} + R_L} = 8 × \frac{4}{2 + 4} = 5.33V$

**诺顿等效**：
- $I_{sc} = \frac{V_{th}}{R_{th}} = \frac{8}{2} = 4A$
- $R_{no} = 2Ω$
</details>

### 1.3.4 考试要点

✅ **必考内容：**
- 戴维南等效：$V_{th}$（开路电压）+ $R_{th}$（等效电阻）
- 诺顿等效：$I_{sc}$（短路电流）+ $R_{no}$（等效电阻）
- $R_{th} = \frac{V_{oc}}{I_{sc}}$
- 戴维南-诺顿等效变换

## 1.4 功率计算和能量守恒

### 1.4.1 功率基本公式

**功率定义**：单位时间内消耗或提供的能量。

**基本公式：**
$$P = \frac{W}{t} = VI$$

其中：
- $P$：功率（单位：瓦特，W）
- $W$：能量（单位：焦耳，J）
- $t$：时间（单位：秒，s）
- $V$：电压（单位：伏特，V）
- $I$：电流（单位：安培，A）

<details>
<summary>🔍 功率公式的推导和变形</summary>

**基本推导：**
1. **能量定义**：$W = F × d$（力乘以距离）
2. **电功**：$W = Q × V$（电荷乘以电压）
3. **电流定义**：$I = \frac{Q}{t}$，即 $Q = It$
4. **电功**：$W = VIt$
5. **功率**：$P = \frac{W}{t} = VI$

**功率的变形公式：**
- 结合欧姆定律：$P = I^2R$
- 结合欧姆定律：$P = \frac{V^2}{R}$
- 结合欧姆定律：$P = \frac{V^2}{R} = I^2R = VI$

**功率的符号约定：**
- 负载消耗功率：$P > 0$
- 电源提供功率：$P < 0$
</details>

### 1.4.2 功率计算方法

<details>
<summary>📝 不同电路中的功率计算</summary>

**直流电路功率计算：**

1. **纯电阻电路**：
   - $P = VI = I^2R = \frac{V^2}{R}$
   - 例：$R = 10Ω$，$V = 12V$，则$P = \frac{12^2}{10} = 14.4W$

2. **含源电路**：
   - 电源功率：$P_{source} = EI$（E为电源电动势）
   - 负载功率：$P_{load} = V_LI$
   - 例：$E = 15V$，$I = 2A$，则$P_{source} = 15 × 2 = 30W$

**交流电路功率计算：**

1. **瞬时功率**：$p(t) = v(t) × i(t)$
2. **平均功率**：$P = \frac{1}{T}\int_0^T p(t)dt = V_{rms}I_{rms}\cos\phi$
3. **视在功率**：$S = V_{rms}I_{rms}$
4. **无功功率**：$Q = V_{rms}I_{rms}\sin\phi$

其中$\phi$为电压与电流的相位差。
</details>

### 1.4.3 能量守恒定律

**能量守恒**：在闭合电路中，电源提供的功率等于各负载消耗的功率之和。

**数学表达式：**
$$\sum P_{source} = \sum P_{load}$$

<details>
<summary>🔍 能量守恒在电路中的应用</summary>

**理论基础：**
能量守恒定律是自然界的基本定律，在电路中表现为功率平衡。

**功率平衡分析：**

1. **理想电路**：
   - 电源功率 = 负载功率
   - $\sum E_kI_k = \sum I_j^2R_j$

2. **实际电路**：
   - 电源功率 = 负载功率 + 损耗功率
   - 损耗包括：导线电阻损耗、磁芯损耗等

3. **功率因数**：
   - 有功功率：$P = S\cos\phi$
   - 无功功率：$Q = S\sin\phi$
   - 功率因数：$\cos\phi = \frac{P}{S}$

**效率计算：**
$$\eta = \frac{P_{output}}{P_{input}} × 100\%$$
</details>

### 1.4.4 考试要点

✅ **必考内容：**
- 功率基本公式：$P = VI = I^2R = \frac{V^2}{R}$
- 功率平衡：$\sum P_{source} = \sum P_{load}$
- 交流电路功率：$P = V_{rms}I_{rms}\cos\phi$
- 效率计算：$\eta = \frac{P_{output}}{P_{input}}$

## 1.5 交流电路基础

### 1.5.1 正弦交流电的基本概念

**正弦交流电压**：
$$v(t) = V_m\sin(\omega t + \phi)$$

**正弦交流电流**：
$$i(t) = I_m\sin(\omega t + \phi_i)$$

其中：
- $V_m$、$I_m$：最大值（幅值）
- $\omega = 2\pi f$：角频率
- $f$：频率
- $\phi$：初相位

<details>
<summary>🔍 正弦交流电的参数关系</summary>

**有效值与最大值关系：**
- 电压有效值：$V_{rms} = \frac{V_m}{\sqrt{2}} \approx 0.707V_m$
- 电流有效值：$I_{rms} = \frac{I_m}{\sqrt{2}} \approx 0.707I_m$

**相位关系：**
- 同相：$\phi = 0°$
- 超前：$\phi > 0°$
- 滞后：$\phi < 0°$
- 反相：$\phi = 180°$

**频率与周期关系：**
- $f = \frac{1}{T}$
- $\omega = 2\pi f = \frac{2\pi}{T}$
- 我国标准频率：$f = 50Hz$，$\omega = 314 rad/s$
</details>

### 1.5.2 阻抗概念

**阻抗**：交流电路中电压与电流的比值，表示电路对交流电的阻碍作用。

**阻抗的复数表示：**
$$Z = \frac{\dot{V}}{\dot{I}} = R + jX$$

其中：
- $Z$：阻抗（单位：欧姆，Ω）
- $R$：电阻（实部）
- $X$：电抗（虚部）

<details>
<summary>🔍 阻抗的推导和计算</summary>

**阻抗的物理意义：**
阻抗反映了电路对交流电的阻碍作用，包括电阻和电抗两部分。

**阻抗的幅值和相位：**
- 阻抗幅值：$|Z| = \sqrt{R^2 + X^2}$
- 阻抗角：$\phi_Z = \arctan\frac{X}{R}$

**复阻抗的运算：**
1. **串联**：$Z_{eq} = Z_1 + Z_2 + Z_3 + ...$
2. **并联**：$\frac{1}{Z_{eq}} = \frac{1}{Z_1} + \frac{1}{Z_2} + \frac{1}{Z_3} + ...$

**欧姆定律在交流电路中的应用：**
- 幅值关系：$I_m = \frac{V_m}{|Z|}$
- 有效值关系：$I_{rms} = \frac{V_{rms}}{|Z|}$
- 相位关系：$\phi_i = \phi_v - \phi_Z$
</details>

### 1.5.3 容抗和感抗

#### 1.5.3.1 容抗

**电容的容抗**：
$$X_C = \frac{1}{\omega C} = \frac{1}{2\pi f C}$$

**容抗特点：**
- 容抗与频率成反比
- 频率越高，容抗越小
- 直流时（$f = 0$），$X_C = \infty$（开路）

#### 1.5.3.2 感抗

**电感的感抗**：
$$X_L = \omega L = 2\pi f L$$

**感抗特点：**
- 感抗与频率成正比
- 频率越高，感抗越大
- 直流时（$f = 0$），$X_L = 0$（短路）

<details>
<summary>📝 容抗和感抗的计算实例</summary>

**例题1：容抗计算**
已知电容$C = 100\mu F$，频率$f = 50Hz$，求容抗$X_C$。

解：
$X_C = \frac{1}{2\pi f C} = \frac{1}{2\pi × 50 × 100 × 10^{-6}} = \frac{1}{0.0314} \approx 31.8\Omega$

**例题2：感抗计算**
已知电感$L = 0.5H$，频率$f = 50Hz$，求感抗$X_L$。

解：
$X_L = 2\pi f L = 2\pi × 50 × 0.5 = 157\Omega$

**例题3：RLC串联电路**
已知$R = 30\Omega$，$L = 0.1H$，$C = 100\mu F$，$f = 50Hz$，求总阻抗。

解：
- $X_L = 2\pi × 50 × 0.1 = 31.4\Omega$
- $X_C = \frac{1}{2\pi × 50 × 100 × 10^{-6}} = 31.8\Omega$
- $X = X_L - X_C = 31.4 - 31.8 = -0.4\Omega$
- $|Z| = \sqrt{30^2 + (-0.4)^2} \approx 30\Omega$
- 电路呈电阻性（接近谐振）
</details>

### 1.5.4 交流电路的功率

#### 1.5.4.1 有功功率

**有功功率（平均功率）**：
$$P = V_{rms}I_{rms}\cos\phi$$

其中$\cos\phi$为功率因数。

#### 1.5.4.2 无功功率

**无功功率**：
$$Q = V_{rms}I_{rms}\sin\phi$$

无功功率反映储能元件与电源之间的能量交换。

#### 1.5.4.3 视在功率

**视在功率**：
$$S = V_{rms}I_{rms} = \sqrt{P^2 + Q^2}$$

<details>
<summary>🔍 交流功率三角形</summary>

**功率三角形关系：**
```
      Q
      |
      |    S = √(P² + Q²)
      |
P ----+---- φ
```

**功率因数角：**
- $\cos\phi = \frac{P}{S}$（功率因数）
- $\sin\phi = \frac{Q}{S}$
- $\tan\phi = \frac{Q}{P}$

**不同负载的功率特性：**
1. **纯电阻**：$\phi = 0°$，$\cos\phi = 1$，$Q = 0$
2. **纯电感**：$\phi = 90°$，$\cos\phi = 0$，$Q = S$
3. **纯电容**：$\phi = -90°$，$\cos\phi = 0$，$Q = -S$
4. **RLC电路**：$-90° < \phi < 90°$
</details>

### 1.5.5 考试要点

✅ **必考内容：**
- 正弦交流电三要素：最大值、角频率、初相位
- 容抗：$X_C = \frac{1}{2\pi f C}$，感抗：$X_L = 2\pi f L$
- 阻抗：$Z = R + jX$，$|Z| = \sqrt{R^2 + X^2}$
- 交流功率：$P = VI\cos\phi$，$Q = VI\sin\phi$，$S = VI$
