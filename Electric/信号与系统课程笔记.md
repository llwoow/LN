## 1. 信号基本概念与分类

### 1.1 信号的定义

**信号**是携带信息的物理量，是时间、空间或其他独立变量的函数。

数学表示：
$$x(t) = f(t)$$

其中：
- $x(t)$：信号
- $t$：时间变量
- $f(\cdot)$：函数关系

### 1.2 信号的分类

#### 1.2.1 按时间连续性分类

| 分类 | 定义 | 数学表示 | 举例 |
|------|------|----------|------|
| **连续时间信号** | 时间变量连续的信号 | $x(t)$，$t \in \mathbb{R}$ | 语音信号、温度变化 |
| **离散时间信号** | 时间变量离散的信号 | $x[n]$，$n \in \mathbb{Z}$ | 数字信号、采样信号 |

#### 1.2.2 按信号确定性分类

| 分类 | 定义 | 特点 | 举例 |
|------|------|------|------|
| **确定信号** | 可以用确定的数学函数描述 | 已知函数形式和参数 | 正弦信号、指数信号 |
| **随机信号** | 不能用确定函数描述 | 具有统计特性 | 噪声信号、通信信号 |

#### 1.2.3 按信号周期性分类

| 分类 | 定义 | 数学条件 | 周期计算 |
|------|------|----------|----------|
| **周期信号** | 按一定时间间隔重复出现的信号 | $x(t+T) = x(t)$ | 最小正周期 $T_0$ |
| **非周期信号** | 不满足周期条件的信号 | 不存在 $T > 0$ 使 $x(t+T) = x(t)$ | - |

#### 1.2.4 按信号能量特性分类

**能量信号：**
$$E = \int_{-\infty}^{\infty} |x(t)|^2 dt < \infty$$

**功率信号：**
$$P = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 dt < \infty$$

### 1.3 常见基本信号

#### 1.3.1 单位冲激信号 $\delta(t)$

<details>
<summary><strong>定义和性质</strong></summary>

**定义：**
$$\delta(t) = \begin{cases}
\infty, & t = 0 \\
0, & t \neq 0
\end{cases}$$

**筛选性质：**
$$\int_{-\infty}^{\infty} x(t)\delta(t-t_0)dt = x(t_0)$$

**重要性质：**
1. $\delta(-t) = \delta(t)$ （偶函数）
2. $\delta(at) = \frac{1}{|a|}\delta(t)$
3. $x(t)\delta(t-t_0) = x(t_0)\delta(t-t_0)$
4. $\int_{-\infty}^{\infty} \delta(t)dt = 1$
</details>

#### 1.3.2 单位阶跃信号 $u(t)$

$$u(t) = \begin{cases}
1, & t \geq 0 \\
0, & t < 0
\end{cases}$$

#### 1.3.3 复指数信号 $e^{st}$

$$x(t) = e^{st} = e^{(\sigma+j\omega)t} = e^{\sigma t}e^{j\omega t}$$

其中：
- $\sigma$：衰减因子
- $\omega$：角频率
- $s = \sigma + j\omega$：复频率

#### 1.3.4 正弦信号

**连续时间：**
$$x(t) = A\cos(\omega t + \phi)$$

**离散时间：**
$$x[n] = A\cos(\Omega n + \phi)$$

### 1.4 信号的特征参数

#### 1.4.1 幅度参数

| 参数 | 定义 | 公式 |
|------|------|------|
| **峰值** | 信号的最大绝对值 | $A_{peak} = \max\|x(t)\|$ |
| **有效值(RMS)** | 信号能量的平均度量 | $X_{rms} = \sqrt{\frac{1}{T}\int_0^T x^2(t)dt}$ |
| **平均值** | 信号的直流分量 | $\bar{x} = \frac{1}{T}\int_0^T x(t)dt$ |

#### 1.4.2 频率参数

| 参数 | 定义 | 公式 |
|------|------|------|
| **基波频率** | 周期信号的最低频率成分 | $f_0 = 1/T_0$ |
| **角频率** | 相位变化速率 | $\omega = 2\pi f$ |
| **带宽** | 信号频谱的有效宽度 | $B = f_{max} - f_{min}$ |

## 2. 系统基本概念与分类

### 2.1 系统的定义

**系统**是对输入信号进行某种变换或处理，产生输出信号的装置或算法。

数学表示：
$$y(t) = T\{x(t)\}$$

其中：
- $x(t)$：输入信号
- $y(t)$：输出信号  
- $T\{\cdot\}$：系统变换算子

### 2.2 系统的分类

#### 2.2.1 按系统线性特性分类

<details>
<summary><strong>线性系统</strong></summary>

**定义：** 满足叠加原理的系统

**叠加原理：**
1. **齐次性（比例性）：**
   $$T\{a x_1(t)\} = a T\{x_1(t)\}$$

2. **可加性：**
   $$T\{x_1(t) + x_2(t)\} = T\{x_1(t)\} + T\{x_2(t)\}$$

**综合形式：**
$$T\{a x_1(t) + b x_2(t)\} = a T\{x_1(t)\} + b T\{x_2(t)\}$$

**判定方法：**
- 线性组合输入 → 线性组合输出
- 零输入产生零输出
- 响应可分解为齐次解和特解
</details>

| 分类 | 定义 | 判定条件 | 举例 |
|------|------|----------|------|
| **线性系统** | 满足叠加原理 | $T\{a x_1 + b x_2\} = a T\{x_1\} + b T\{x_2\}$ | 线性放大器、加法器 |
| **非线性系统** | 不满足叠加原理 | 存在非线性元件 | 乘法器、整流器 |

#### 2.2.2 按系统时不变特性分类

| 分类 | 定义 | 判定条件 | 举例 |
|------|------|----------|------|
| **时不变系统** | 系统参数不随时间变化 | $y(t-t_0) = T\{x(t-t_0)\}$ | 线性时不变(LTI)系统 |
| **时变系统** | 系统参数随时间变化 | 上述条件不成立 | 调制器、开关电路 |

#### 2.2.3 按系统因果性分类

| 分类 | 定义 | 判定条件 | 举例 |
|------|------|----------|------|
| **因果系统** | 输出不超前于输入 | $y(t) = 0, \forall t < t_0$ 当 $x(t) = 0, \forall t < t_0$ | 物理可实现系统 |
| **非因果系统** | 输出可能超前于输入 | 上述条件不成立 | 理想滤波器、预测系统 |

#### 2.2.4 按系统稳定性分类

<details>
<summary><strong>稳定性判据</strong></summary>

**BIBO稳定（有界输入有界输出稳定）：**

**连续时间系统：**
$$\int_{-\infty}^{\infty} |h(t)|dt < \infty$$

**离散时间系统：**
$$\sum_{n=-\infty}^{\infty} |h[n]| < \infty$$

其中 $h(t)$ 或 $h[n]$ 为系统的冲激响应。

**稳定性判定方法：**
1. **冲激响应绝对可和/可积**
2. **系统函数的极点全部在左半平面（连续）或单位圆内（离散）**
3. **状态空间系统的特征值实部为负**
</details>

### 2.3 系统的基本性质

#### 2.3.1 记忆性

- **无记忆系统：** 输出仅取决于当前输入
  $$y[n] = f(x[n])$$

- **记忆系统：** 输出取决于过去和当前输入
  $$y[n] = f(x[n], x[n-1], x[n-2], \ldots)$$

#### 2.3.2 可逆性

**可逆系统：** 存在逆系统 $T^{-1}\{\cdot\}$ 使得：
$$T^{-1}\{T\{x(t)\}\} = x(t)$$

#### 2.3.3 时变性

**时变参数系统：** 系统参数随时间变化
$$y(t) = h(t, \tau)x(\tau)$$

## 3. 信号基本运算

### 3.1 信号的代数运算

#### 3.1.1 加法运算

$$z(t) = x(t) + y(t)$$

**性质：**
- 交换律：$x(t) + y(t) = y(t) + x(t)$
- 结合律：$(x(t) + y(t)) + z(t) = x(t) + (y(t) + z(t))$
- 单位元：$x(t) + 0 = x(t)$

#### 3.1.2 乘法运算

$$z(t) = x(t) \cdot y(t)$$

**性质：**
- 交换律：$x(t) \cdot y(t) = y(t) \cdot x(t)$
- 结合律：$(x(t) \cdot y(t)) \cdot z(t) = x(t) \cdot (y(t) \cdot z(t))$
- 单位元：$x(t) \cdot 1 = x(t)$

### 3.2 信号的时域变换

#### 3.2.1 时间平移（时移）

**右移（延迟）：**
$$y(t) = x(t - t_0), \quad t_0 > 0$$

**左移（超前）：**
$$y(t) = x(t + t_0), \quad t_0 > 0$$

#### 3.2.2 时间反转

$$y(t) = x(-t)$$

<details>
<summary><strong>时移和反转的组合</strong></summary>

**一般形式：**
$$y(t) = x(at + b)$$

**分解步骤：**
1. **时间反转：** $x_1(t) = x(-t)$
2. **时间缩放：** $x_2(t) = x_1(at) = x(-at)$
3. **时间平移：** $y(t) = x_2(t + b/a) = x(-a(t + b/a)) = x(-at - b)$

**特殊情形：**
- $a = 1$：仅有平移 $y(t) = x(t + b)$
- $b = 0$：仅有缩放 $y(t) = x(at)$
- $a = -1$：仅有反转 $y(t) = x(-t + b)$
</details>

#### 3.2.3 时间缩放

**压缩（$|a| > 1$）：**
$$y(t) = x(at), \quad |a| > 1$$

**扩展（$|a| < 1$）：**
$$y(t) = x(at), \quad |a| < 1$$

### 3.3 信号的微积分运算

#### 3.3.1 微分运算

**连续时间：**
$$\frac{dx(t)}{dt} = \lim_{\Delta t \to 0} \frac{x(t + \Delta t) - x(t)}{\Delta t}$$

**离散时间：**
$$\Delta x[n] = x[n] - x[n-1] \quad \text{(一阶前向差分})$$

#### 3.3.2 积分运算

**连续时间：**
$$y(t) = \int_{-\infty}^{t} x(\tau)d\tau$$

**离散时间：**
$$y[n] = \sum_{k=-\infty}^{n} x[k] \quad \text{(累加运算})$$

### 3.4 信号的卷积运算

<details>
<summary><strong>卷积定义和性质</strong></summary>

**连续时间卷积：**
$$y(t) = x(t) * h(t) = \int_{-\infty}^{\infty} x(\tau)h(t-\tau)d\tau$$

**离散时间卷积：**
$$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k]h[n-k]$$

**卷积的重要性质：**

1. **交换律：** $x(t) * h(t) = h(t) * x(t)$
2. **结合律：** $(x(t) * h_1(t)) * h_2(t) = x(t) * (h_1(t) * h_2(t))$
3. **分配律：** $x(t) * (h_1(t) + h_2(t)) = x(t) * h_1(t) + x(t) * h_2(t)$
4. **微分性质：** $\frac{d}{dt}[x(t) * h(t)] = x(t) * \frac{dh(t)}{dt} = \frac{dx(t)}{dt} * h(t)$
5. **积分性质：** $\int_{-\infty}^{t}[x(\tau) * h(\tau)]d\tau = x(t) * \int_{-\infty}^{t}h(\tau)d\tau$

**卷积的几何意义：**
卷积可以理解为将一个信号翻转、平移后与另一个信号相乘积分的过程。
</details>

### 3.5 相关运算

#### 3.5.1 自相关函数

**连续时间：**
$$R_{xx}(\tau) = \int_{-\infty}^{\infty} x(t)x^*(t-\tau)dt$$

**离散时间：**
$$R_{xx}[m] = \sum_{n=-\infty}^{\infty} x[n]x^*[n-m]$$

#### 3.5.2 互相关函数

**连续时间：**
$$R_{xy}(\tau) = \int_{-\infty}^{\infty} x(t)y^*(t-\tau)dt$$

**离散时间：**
$$R_{xy}[m] = \sum_{n=-\infty}^{\infty} x[n]y^*[n-m]$$

**相关与卷积的关系：**
$$R_{xy}(\tau) = x(\tau) * y^*(-\tau)$$

## 4. 连续时间信号与系统分析

### 4.1 连续时间系统的数学模型

#### 4.1.1 微分方程描述

**n阶线性常系数微分方程：**
$$a_n \frac{d^n y(t)}{dt^n} + a_{n-1} \frac{d^{n-1} y(t)}{dt^{n-1}} + \cdots + a_1 \frac{dy(t)}{dt} + a_0 y(t) = b_m \frac{d^m x(t)}{dt^m} + \cdots + b_1 \frac{dx(t)}{dt} + b_0 x(t)$$

**标准形式：**
$$\sum_{k=0}^{n} a_k \frac{d^k y(t)}{dt^k} = \sum_{k=0}^{m} b_k \frac{d^k x(t)}{dt^k}$$

### 4.2 系统的响应分析

#### 4.2.1 零输入响应

<details>
<summary><strong>零输入响应的求解</strong></summary>

**定义：** 仅由初始条件引起的响应，记为 $y_{zi}(t)$

**求解步骤：**
1. **齐次方程：** 令输入 $x(t) = 0$
   $$\sum_{k=0}^{n} a_k \frac{d^k y(t)}{dt^k} = 0$$

2. **特征方程：** 假设解的形式为 $y(t) = e^{st}$
   $$\sum_{k=0}^{n} a_k s^k = 0$$

3. **特征根：** 求特征方程的根 $s_1, s_2, \ldots, s_n$

4. **齐次解：** 
   $$y_{zi}(t) = \sum_{i=1}^{n} C_i e^{s_i t}$$

5. **系数确定：** 利用初始条件确定常数 $C_i$
</details>

#### 4.2.2 零状态响应

<details>
<summary><strong>零状态响应的求解</strong></summary>

**定义：** 仅由输入信号引起的响应，记为 $y_{zs}(t)$，初始条件为零。

**求解方法：**

1. **经典法（微分方程法）：**
   - 求齐次解 $y_h(t)$
   - 求特解 $y_p(t)$（根据输入信号形式）
   - 全解：$y_{zs}(t) = y_h(t) + y_p(t)$
   - 利用零初始条件确定系数

2. **卷积法：**
   $$y_{zs}(t) = x(t) * h(t)$$
   其中 $h(t)$ 为系统的冲激响应

3. **拉普拉斯变换法：**
   $$Y_{zs}(s) = H(s)X(s)$$
   其中 $H(s)$ 为系统函数
</details>

#### 4.2.3 冲激响应

**定义：** 单位冲激信号 $\delta(t)$ 作用于系统的零状态响应

$$h(t) = T\{\delta(t)\}$$

**重要性质：**
- 线性时不变系统的冲激响应完全表征系统特性
- 任意输入的零状态响应：$y_{zs}(t) = x(t) * h(t)$

### 4.3 频率响应

#### 4.3.1 频率响应的定义

**正弦稳态响应：**
当输入 $x(t) = A\cos(\omega t + \phi)$ 时，输出为：
$$y(t) = |H(j\omega)|A\cos(\omega t + \phi + \angle H(j\omega))$$

其中：
- $|H(j\omega)|$：幅频响应
- $\angle H(j\omega)$：相频响应
- $H(j\omega)$：频率响应

#### 4.3.2 频率响应的计算

**从系统函数得到：**
$$H(j\omega) = H(s)|_{s=j\omega}$$

**从微分方程得到：**
$$H(j\omega) = \frac{\sum_{k=0}^{m} b_k (j\omega)^k}{\sum_{k=0}^{n} a_k (j\omega)^k}$$

### 4.4 极零点分析

#### 4.4.1 系统函数的极零点表示

**有理分式形式：**
$$H(s) = K \frac{(s-z_1)(s-z_2)\cdots(s-z_m)}{(s-p_1)(s-p_2)\cdots(s-p_n)}$$

其中：
- $z_1, z_2, \ldots, z_m$：零点
- $p_1, p_2, \ldots, p_n$：极点
- $K$：增益常数

#### 4.4.2 稳定性判据

<details>
<summary><strong>极点位置与稳定性</strong></summary>

**连续时间系统稳定性判据：**
- **稳定：** 所有极点位于左半s平面（$\operatorname{Re}\{p_i\} < 0$）
- **临界稳定：** 有极点在虚轴上（二阶以下单极点，二阶以上重极点）
- **不稳定：** 有极点在右半s平面

**劳斯判据（Routh-Hurwitz判据）：**

对于特征方程：
$$a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0 = 0$$

构造劳斯表：
```
s^n:    a_n    a_{n-2}    a_{n-4}    ...
s^{n-1}: a_{n-1} a_{n-3}    a_{n-5}    ...
s^{n-2}: b_1     b_2        b_3        ...
...
s^1:     c_1     c_2
s^0:     d_1
```

**稳定性条件：** 第一列所有元素符号相同且不为零。
</details>

### 4.5 系统的时域和频域特性

#### 4.5.1 时域特性

| 特性 | 定义 | 表达式 |
|------|------|--------|
| **上升时间** $t_r$ | 从10%到90%峰值的时间 | $t_r = \frac{0.35}{BW}$ |
| **峰值时间** $t_p$ | 达到峰值的时间 | 极点和零点位置决定 |
| **超调量** $\sigma$ | 超过稳态值的最大百分比 | $\sigma = e^{-\pi\zeta/\sqrt{1-\zeta^2}} \times 100\%$ |
| **调节时间** $t_s$ | 进入±2%误差带的时间 | $t_s = \frac{4}{\zeta\omega_n}$ |

#### 4.5.2 频域特性

| 特性 | 定义 | 表达式 |
|------|------|--------|
| **带宽** $BW$ | 幅频响应下降到-3dB的频率范围 | $BW = \omega_c$ |
| **截止频率** $\omega_c$ | 幅频响应为最大值的 $\frac{1}{\sqrt{2}}$ 时的频率 | $\|H(j\omega_c)\| = \frac{|H(j\omega)|_{max}}{\sqrt{2}}$ |
| **品质因数** $Q$ | 中心频率与带宽的比值 | $Q = \frac{\omega_0}{BW}$ |

## 5. 离散时间信号与系统分析

### 5.1 离散时间系统的数学模型

#### 5.1.1 差分方程描述

**n阶线性常系数差分方程：**
$$a_n y[n] + a_{n-1} y[n-1] + \cdots + a_0 y[n-n] = b_m x[n] + b_{m-1} x[n-1] + \cdots + b_0 x[n-m]$$

**标准形式：**
$$\sum_{k=0}^{n} a_k y[n-k] = \sum_{k=0}^{m} b_k x[n-k]$$

#### 5.1.2 差分方程的求解方法

<details>
<summary><strong>经典解法</strong></summary>

**1. 齐次解：**
假设特征方程：$\sum_{k=0}^{n} a_k r^k = 0$

- **无重根：** $y_h[n] = \sum_{i=1}^{n} C_i r_i^n$
- **有重根：** 包含 $n^k r^n$ 形式的项

**2. 特解：**
根据输入信号形式选择特解形式

| 输入信号 | 特解形式 |
|----------|----------|
| 常数 $A$ | 常数 $B$ |
| $A r^n$ | $B r^n$（若 $r$ 不是特征根） |
| $A n^k$ | $n$ 的 $k$ 次多项式 |
| $A \cos(\Omega n)$ | $B \cos(\Omega n) + C \sin(\Omega n)$ |

**3. 全解：** $y[n] = y_h[n] + y_p[n]$

**4. 初始条件：** 利用初始条件确定常数
</details>

### 5.2 Z变换基础

#### 5.2.1 Z变换的定义

**双边Z变换：**
$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$

**单边Z变换：**
$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=0}^{\infty} x[n] z^{-n}$$

#### 5.2.2 收敛域（ROC）

<details>
<summary><strong>收敛域的确定</strong></summary>

**收敛域的性质：**

1. **环形区域：** ROC是z平面上的环形区域 $R_1 < |z| < R_2$
2. **极点边界：** ROC的边界由极点确定
3. **有限序列：** ROC包含整个z平面（除z=0或z=∞）
4. **右边序列：** ROC在模最大的极点之外
5. **左边序列：** ROC在模最小的极点之内
6. **双边序列：** ROC是极点之间的环形区域

**收敛域判定：**
$$\sum_{n=-\infty}^{\infty} |x[n] z^{-n}| < \infty$$

**常见序列的ROC：**

| 序列类型 | ROC |
|----------|-----|
| 有限长序列 | 整个z平面（除可能的z=0或z=∞） |
| 右边序列 | $\|z\| > \|z_{max}\|$ |
| 左边序列 | $\|z\| < \|z_{min}\|$ |
| 双边序列 | $R_1 < \|z\| < R_2$ |
</details>

### 5.3 离散时间傅里叶变换（DTFT）

#### 5.3.1 DTFT的定义

**正变换：**
$$X(e^{j\Omega}) = \mathcal{F}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n] e^{-j\Omega n}$$

**逆变换：**
$$x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\Omega}) e^{j\Omega n} d\Omega$$

其中 $\Omega$ 为数字角频率，单位为弧度。

#### 5.3.2 DTFT的性质

| 性质 | 时域 | 频域 |
|------|------|------|
| **线性** | $ax_1[n] + bx_2[n]$ | $aX_1(e^{j\Omega}) + bX_2(e^{j\Omega})$ |
| **时移** | $x[n-n_0]$ | $e^{-j\Omega n_0}X(e^{j\Omega})$ |
| **频移** | $e^{j\Omega_0 n}x[n]$ | $X(e^{j(\Omega-\Omega_0)})$ |
| **时间反转** | $x[-n]$ | $X(e^{-j\Omega})$ |
| **共轭** | $x^*[n]$ | $X^*(e^{-j\Omega})$ |
| **微分** | $nx[n]$ | $j\frac{dX(e^{j\Omega})}{d\Omega}$ |

### 5.4 离散傅里叶变换（DFT）

#### 5.4.1 DFT的定义

**N点DFT：**
$$X[k] = \mathcal{DFT}\{x[n]\} = \sum_{n=0}^{N-1} x[n] e^{-j\frac{2\pi}{N}kn}$$

**N点IDFT：**
$$x[n] = \mathcal{IDFT}\{X[k]\} = \frac{1}{N} \sum_{k=0}^{N-1} X[k] e^{j\frac{2\pi}{N}kn}$$

#### 5.4.2 DFT的性质

<details>
<summary><strong>DFT的重要性质</strong></summary>

**1. 线性性：** $\mathcal{DFT}\{ax_1[n] + bx_2[n]\} = aX_1[k] + bX_2[k]$

**2. 循环移位：**
- **时域循环移位：** $x[(n-n_0)_N] \leftrightarrow X[k]e^{-j\frac{2\pi}{N}kn_0}$
- **频域循环移位：** $x[n]e^{j\frac{2\pi}{N}n k_0} \leftrightarrow X[(k-k_0)_N]$

**3. 循环卷积：** 
$$x[n] \circledast y[n] \leftrightarrow X[k]Y[k]$$

**4. 循环相关：**
$$R_{xy}[m] = \sum_{n=0}^{N-1} x[n]y^*[(n-m)_N] \leftrightarrow X[k]Y^*[k]$$

**5. 帕塞瓦尔定理：**
$$\sum_{n=0}^{N-1} |x[n]|^2 = \frac{1}{N} \sum_{k=0}^{N-1} |X[k]|^2$$
</details>

### 5.5 快速傅里叶变换（FFT）

#### 5.5.1 FFT的基本思想

**DFT计算复杂度：**
- 直接计算DFT：$O(N^2)$ 次复数乘法
- FFT算法：$O(N \log_2 N)$ 次复数乘法

**FFT的加速原理：**
1. **分解：** 将长序列分解为短序列
2. **分治：** 递归地计算短序列的DFT
3. **合并：** 利用旋转因子性质合并结果

#### 5.5.2 基2 FFT算法

<details>
<summary><strong>基2 FFT算法步骤</strong></summary>

**算法流程：**

1. **输入：** N点序列 $x[n]$，N为2的幂
2. **分解：** 将序列分为偶数点和奇数点
   - $x_1[n] = x[2n]$ （偶数点）
   - $x_2[n] = x[2n+1]$ （奇数点）

3. **递归计算：** 
   - 计算 $X_1[k] = \mathcal{DFT}\{x_1[n]\}$
   - 计算 $X_2[k] = \mathcal{DFT}\{x_2[n]\}$

4. **合并：** 
   $$X[k] = X_1[k] + W_N^k X_2[k]$$
   $$X[k+N/2] = X_1[k] - W_N^k X_2[k]$$

其中 $W_N^k = e^{-j\frac{2\pi}{N}k}$ 为旋转因子。

**复杂度分析：**
- 每级蝶形运算：$N/2$ 次复数乘法，$N$ 次复数加法
- 总级数：$\log_2 N$
- 总复杂度：$O(N \log_2 N)$
</details>

### 5.6 数字滤波器的结构

#### 5.6.1 IIR滤波器结构

**直接型I（直接型）：**
- 分子分母系数直接实现
- 结构简单，但数值稳定性差

**直接型II（典范型）：**
- 分子分母系数共享存储单元
- 所需存储单元最少

**级联型：**
- 系统函数分解为二阶节的级联
- 数值稳定性好，便于调整

**并联型：**
- 系统函数分解为二阶节的并联
- 各支路独立，便于调整

#### 5.6.2 FIR滤波器结构

**直接型（横截型）：**
$$y[n] = \sum_{k=0}^{M} h[k]x[n-k]$$

**级联型：**
- 系统函数分解为二阶节的级联
- 便于控制零点位置

**频率采样型：**
- 在频域设计，在时域实现
- 适合窄带滤波器设计

## 6. 傅里叶变换

### 6.1 连续时间傅里叶变换（CTFT）

#### 6.1.1 CTFT的定义

**正变换：**
$$X(j\omega) = \mathcal{F}\{x(t)\} = \int_{-\infty}^{\infty} x(t) e^{-j\omega t} dt$$

**逆变换：**
$$x(t) = \mathcal{F}^{-1}\{X(j\omega)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} X(j\omega) e^{j\omega t} d\omega$$

#### 6.1.2 常见信号的傅里叶变换

<details>
<summary><strong>常用信号对</strong></summary>

| 时域信号 $x(t)$ | 频域信号 $X(j\omega)$ | 条件 |
|-----------------|----------------------|------|
| $\delta(t)$ | $1$ | - |
| $1$ | $2\pi\delta(\omega)$ | - |
| $e^{-at}u(t)$ | $\frac{1}{a+j\omega}$ | $a > 0$ |
| $e^{a\|t\|}$ | $\frac{2a}{a^2 + \omega^2}$ | $a > 0$ |
| $\text{rect}(t/T)$ | $T \text{sinc}(\omega T/2)$ | - |
| $\text{sinc}(t/T)$ | $\pi T \text{rect}(\omega T/2\pi)$ | - |
| $\cos(\omega_0 t)$ | $\pi[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)]$ | - |
| $\sin(\omega_0 t)$ | $j\pi[\delta(\omega + \omega_0) - \delta(\omega - \omega_0)]$ | - |
| $u(t)$ | $\pi\delta(\omega) + \frac{1}{j\omega}$ | - |

其中 $\text{sinc}(x) = \frac{\sin(\pi x)}{\pi x}$。
</details>

### 6.2 傅里叶变换的性质

#### 6.2.1 基本性质

| 性质 | 时域 | 频域 | 公式 |
|------|------|------|------|
| **线性** | $ax_1(t) + bx_2(t)$ | $aX_1(j\omega) + bX_2(j\omega)$ | $\mathcal{F}\{ax_1 + bx_2\} = a\mathcal{F}\{x_1\} + b\mathcal{F}\{x_2\}$ |
| **时移** | $x(t-t_0)$ | $e^{-j\omega t_0}X(j\omega)$ | $\mathcal{F}\{x(t-t_0)\} = e^{-j\omega t_0}\mathcal{F}\{x(t)\}$ |
| **频移** | $e^{j\omega_0 t}x(t)$ | $X(j(\omega - \omega_0))$ | $\mathcal{F}\{e^{j\omega_0 t}x(t)\} = \mathcal{F}\{x(t)\}(\omega - \omega_0)$ |
| **时间反转** | $x(-t)$ | $X(-j\omega)$ | $\mathcal{F}\{x(-t)\} = X(-j\omega)$ |
| **共轭** | $x^*(t)$ | $X^*(-j\omega)$ | $\mathcal{F}\{x^*(t)\} = X^*(-j\omega)$ |

#### 6.2.2 微分和积分性质

<details>
<summary><strong>微分积分性质</strong></summary>

**微分性质：**
$$\mathcal{F}\left\{\frac{d^n x(t)}{dt^n}\right\} = (j\omega)^n X(j\omega)$$

**积分性质：**
$$\mathcal{F}\left\{\int_{-\infty}^{t} x(\tau)d\tau\right\} = \frac{1}{j\omega}X(j\omega) + \pi X(0)\delta(\omega)$$

**应用：** 
- 微分方程 → 代数方程
- 积分方程 → 代数方程
</details>

#### 6.2.3 尺度变换性质

**时间尺度变换：**
$$\mathcal{F}\{x(at)\} = \frac{1}{|a|}X\left(j\frac{\omega}{a}\right)$$

**频率尺度变换：**
$$\mathcal{F}\left\{\frac{1}{|a|}x\left(\frac{t}{a}\right)\right\} = X(j\omega a)$$

#### 6.2.4 对偶性质

如果 $\mathcal{F}\{x(t)\} = X(j\omega)$，则：
$$\mathcal{F}\{X(t)\} = 2\pi x(-j\omega)$$

### 6.3 傅里叶级数（FS）

#### 6.3.1 周期信号的傅里叶级数

**三角形式：**
$$x(t) = a_0 + \sum_{n=1}^{\infty} [a_n \cos(n\omega_0 t) + b_n \sin(n\omega_0 t)]$$

**指数形式：**
$$x(t) = \sum_{n=-\infty}^{\infty} c_n e^{jn\omega_0 t}$$

#### 6.3.2 傅里叶系数计算

<details>
<summary><strong>系数计算公式</strong></summary>

**三角形式系数：**
$$a_0 = \frac{1}{T_0} \int_{T_0} x(t) dt$$
$$a_n = \frac{2}{T_0} \int_{T_0} x(t) \cos(n\omega_0 t) dt$$
$$b_n = \frac{2}{T_0} \int_{T_0} x(t) \sin(n\omega_0 t) dt$$

**指数形式系数：**
$$c_n = \frac{1}{T_0} \int_{T_0} x(t) e^{-jn\omega_0 t} dt$$

**系数关系：**
- $a_0 = c_0$
- $a_n = c_n + c_{-n}$
- $b_n = j(c_n - c_{-n})$
- $|c_n| = \frac{1}{2}\sqrt{a_n^2 + b_n^2}$
- $\angle c_n = -\tan^{-1}(b_n/a_n)$
</details>

### 6.4 卷积定理

#### 6.4.1 时域卷积定理

<details>
<summary><strong>卷积定理</strong></summary>

**时域卷积，频域乘积：**
$$\mathcal{F}\{x(t) * y(t)\} = X(j\omega)Y(j\omega)$$

**证明：**
$$\mathcal{F}\{x(t) * y(t)\} = \int_{-\infty}^{\infty} \left[\int_{-\infty}^{\infty} x(\tau)y(t-\tau)d\tau\right] e^{-j\omega t} dt$$
$$= \int_{-\infty}^{\infty} x(\tau) \left[\int_{-\infty}^{\infty} y(t-\tau)e^{-j\omega t}dt\right] d\tau$$
$$= \int_{-\infty}^{\infty} x(\tau) e^{-j\omega\tau} \left[\int_{-\infty}^{\infty} y(u)e^{-j\omega u}du\right] d\tau$$
$$= X(j\omega)Y(j\omega)$$

**应用：** 
- 线性系统分析：$Y(j\omega) = H(j\omega)X(j\omega)$
- 简化卷积计算
</details>

#### 6.4.2 频域卷积定理

**时域乘积，频域卷积：**
$$\mathcal{F}\{x(t)y(t)\} = \frac{1}{2\pi} X(j\omega) * Y(j\omega)$$

#### 6.4.3 帕塞瓦尔定理

**能量守恒：**
$$\int_{-\infty}^{\infty} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |X(j\omega)|^2 d\omega$$

**功率信号：**
$$\lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |X(j\omega)|^2 \frac{d\omega}{2\pi}$$

### 6.5 采样定理

#### 6.5.1 理想采样

**采样信号：**
$$x_s(t) = x(t) \sum_{n=-\infty}^{\infty} \delta(t-nT_s) = \sum_{n=-\infty}^{\infty} x(nT_s)\delta(t-nT_s)$$

**采样信号的频谱：**
$$X_s(j\omega) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))$$

其中 $\omega_s = \frac{2\pi}{T_s}$ 为采样角频率。

#### 6.5.2 奈奎斯特采样定理

<details>
<summary><strong>采样定理</strong></summary>

**定理：** 对于带限信号 $x(t)$，其最高频率分量为 $f_m$，如果采样频率 $f_s > 2f_m$，则可以从采样信号中无失真地恢复原信号。

**数学表达：**
- **带限条件：** $X(j\omega) = 0$，当 $|\omega| > \omega_m$
- **采样条件：** $\omega_s > 2\omega_m$
- **恢复条件：** 使用理想低通滤波器，截止频率 $\omega_c$ 满足 $\omega_m < \omega_c < \omega_s - \omega_m$

**混叠现象：**
当采样频率不满足 $\omega_s > 2\omega_m$ 时，频谱发生混叠，无法无失真恢复原信号。
</details>

#### 6.5.3 重建滤波器

**理想重建滤波器：**
$$H_r(j\omega) = \begin{cases}
T_s, & |\omega| < \omega_s/2 \\
0, & |\omega| > \omega_s/2
\end{cases}$$

**重建信号：**
$$x(t) = x_s(t) * h_r(t) = \sum_{n=-\infty}^{\infty} x(nT_s) \text{sinc}\left(\frac{t-nT_s}{T_s}\right)$$

## 7. 拉普拉斯变换

### 7.1 拉普拉斯变换的定义

#### 7.1.1 双边拉普拉斯变换

**正变换：**
$$X(s) = \mathcal{L}\{x(t)\} = \int_{-\infty}^{\infty} x(t) e^{-st} dt$$

**逆变换：**
$$x(t) = \mathcal{L}^{-1}\{X(s)\} = \frac{1}{2\pi j} \int_{\sigma-j\infty}^{\sigma+j\infty} X(s) e^{st} ds$$

其中 $s = \sigma + j\omega$ 为复频率。

#### 7.1.2 单边拉普拉斯变换

**正变换：**
$$X(s) = \mathcal{L}\{x(t)\} = \int_{0}^{\infty} x(t) e^{-st} dt$$

**实际应用更广泛**，因为：
- 物理系统通常在 $t=0$ 开始工作
- 初始条件在 $t=0$ 给出
- 便于处理因果信号

### 7.2 拉普拉斯变换的收敛域

#### 7.2.1 收敛域的确定

<details>
<summary><strong>收敛域的性质</strong></summary>

**收敛域（ROC）的特点：**

1. **带状区域：** ROC是s平面上的带状区域 $\sigma_1 < \sigma < \sigma_2$
2. **极点边界：** ROC的边界由极点确定
3. **无极点：** ROC内不包含任何极点
4. **因果序列：** ROC在最右边极点的右边
5. **反因果序列：** ROC在最左边极点的左边
6. **双边序列：** ROC是两个极点之间的带状区域

**收敛条件：**
$$\int_{0}^{\infty} |x(t) e^{-\sigma t}| dt < \infty$$

**常见信号的ROC：**

| 信号类型 | ROC |
|----------|-----|
| 右边信号 $x(t) = 0, t < t_0$ | $\sigma > \sigma_0$ |
| 左边信号 $x(t) = 0, t > t_0$ | $\sigma < \sigma_0$ |
| 双边信号 | $\sigma_1 < \sigma < \sigma_2$ |
| 有限长信号 | 整个s平面（除s=0或s=∞） |
</details>

### 7.3 拉普拉斯变换的性质

#### 7.3.1 基本性质

| 性质 | 时域 | 拉普拉斯域 | 条件 |
|------|------|------------|------|
| **线性** | $ax_1(t) + bx_2(t)$ | $aX_1(s) + bX_2(s)$ | ROC包含交集 |
| **时移** | $x(t-t_0)u(t-t_0)$ | $e^{-st_0}X(s)$ | $t_0 > 0$ |
| **频移** | $e^{s_0 t}x(t)$ | $X(s-s_0)$ | - |
| **时间反转** | $x(-t)$ | $X(-s)$ | - |
| **尺度变换** | $x(at)$ | $\frac{1}{\|a\|}X\left(\frac{s}{a}\right)$ | $a > 0$ |

#### 7.3.2 微分和积分性质

<details>
<summary><strong>微分积分性质</strong></summary>

**微分性质：**
$$\mathcal{L}\left\{\frac{d^n x(t)}{dt^n}\right\} = s^n X(s) - \sum_{k=0}^{n-1} s^{n-1-k} x^{(k)}(0^-)$$

**特殊情况：**
- **一阶微分：** $\mathcal{L}\left\{\frac{dx(t)}{dt}\right\} = sX(s) - x(0^-)$
- **二阶微分：** $\mathcal{L}\left\{\frac{d^2 x(t)}{dt^2}\right\} = s^2 X(s) - sx(0^-) - x'(0^-)$

**积分性质：**
$$\mathcal{L}\left\{\int_{0}^{t} x(\tau)d\tau\right\} = \frac{1}{s}X(s)$$

**应用：**
- 微分方程 → 代数方程
- 初始条件自然包含在变换中
</details>

#### 7.3.3 卷积性质

**时域卷积：**
$$\mathcal{L}\{x(t) * y(t)\} = X(s)Y(s)$$

**频域卷积：**
$$\mathcal{L}\{x(t)y(t)\} = \frac{1}{2\pi j} X(s) * Y(s)$$

### 7.4 拉普拉斯逆变换

#### 7.4.1 部分分式展开法

<details>
<summary><strong>部分分式展开步骤</strong></summary>

**步骤：**

1. **化为真分式：** 如果分子阶数 ≥ 分母阶数，先做多项式除法
2. **因式分解：** 将分母多项式分解为一次因子和二次因子
3. **设展开式：** 
   - **无重根：** $X(s) = \frac{A_1}{s-p_1} + \frac{A_2}{s-p_2} + \cdots + \frac{A_n}{s-p_n}$
   - **有重根：** 包含 $(s-p_i)^k$ 的项
4. **求系数：** 使用留数法或代入法
5. **查表求逆变换**

**留数法求系数：**
$$A_k = \text{Res}[X(s), p_k] = \lim_{s \to p_k} (s-p_k)X(s)$$

**常见形式：**
- $\frac{A}{s-p} \leftrightarrow Ae^{pt}u(t)$
- $\frac{As+B}{s^2+as+b} \leftrightarrow$ 指数衰减正弦信号
- $\frac{A}{(s-p)^n} \leftrightarrow \frac{A}{(n-1)!}t^{n-1}e^{pt}u(t)$
</details>

### 7.5 系统函数

#### 7.5.1 系统函数的定义

**系统函数（传递函数）：**
$$H(s) = \frac{Y(s)}{X(s)} = \frac{\mathcal{L}\{y(t)\}}{\mathcal{L}\{x(t)\}}$$

**从微分方程得到：**
对于系统微分方程：
$$\sum_{k=0}^{n} a_k \frac{d^k y(t)}{dt^k} = \sum_{k=0}^{m} b_k \frac{d^k x(t)}{dt^k}$$

系统函数为：
$$H(s) = \frac{\sum_{k=0}^{m} b_k s^k}{\sum_{k=0}^{n} a_k s^k}$$

#### 7.5.2 系统函数的极零点

**标准形式：**
$$H(s) = K \frac{(s-z_1)(s-z_2)\cdots(s-z_m)}{(s-p_1)(s-p_2)\cdots(s-p_n)}$$

其中：
- $z_1, z_2, \ldots, z_m$：零点
- $p_1, p_2, \ldots, p_n$：极点
- $K$：增益常数

#### 7.5.3 稳定性分析

<details>
<summary><strong>稳定性判据</strong></summary>

**BIBO稳定条件：**
系统函数 $H(s)$ 的所有极点必须位于左半s平面（$\operatorname{Re}\{p_i\} < 0$）。

**劳斯判据：**

对于特征方程：
$$a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0 = 0$$

构造劳斯表：
```
s^n:    a_n    a_{n-2}    a_{n-4}    ...
s^{n-1}: a_{n-1} a_{n-3}    a_{n-5}    ...
s^{n-2}: b_1     b_2        b_3        ...
s^{n-3}: c_1     c_2
...
s^1:     d_1
s^0:     e_1
```

**稳定性条件：**
1. 所有系数 $a_k > 0$
2. 劳斯表第一列所有元素符号相同且不为零

**特殊情况：**
- 出现全零行：系统临界稳定
- 第一列出现符号变化：系统不稳定
</details>

### 7.6 频率响应

#### 7.6.1 频率响应的计算

**频率响应：**
$$H(j\omega) = H(s)|_{s=j\omega} = |H(j\omega)|e^{j\angle H(j\omega)}$$

其中：
- $|H(j\omega)|$：幅频响应
- $\angle H(j\omega)$：相频响应

#### 7.6.2 频率响应的几何确定法

<details>
<summary><strong>几何确定法</strong></summary>

**基本原理：**
频率响应 $H(j\omega)$ 可以通过s平面上的极零点几何关系确定。

**计算步骤：**

1. **确定极零点位置：** 在s平面上标出所有极点和零点
2. **选择频率点：** 在虚轴上选择 $\omega$ 值
3. **计算矢量：**
   - 从每个极点 $p_i$ 到点 $j\omega$ 的矢量：$j\omega - p_i$
   - 从每个零点 $z_i$ 到点 $j\omega$ 的矢量：$j\omega - z_i$
4. **计算幅频响应：**
   $$|H(j\omega)| = |K| \frac{\prod_{i=1}^{m} |j\omega - z_i|}{\prod_{i=1}^{n} |j\omega - p_i|}$$
5. **计算相频响应：**
   $$\angle H(j\omega) = \angle K + \sum_{i=1}^{m} \angle(j\omega - z_i) - \sum_{i=1}^{n} \angle(j\omega - p_i)$$

**特殊情况：**
- **低通滤波器：** 极点远离原点，零点接近原点
- **高通滤波器：** 零点接近原点
- **带通滤波器：** 极点在虚轴附近
</details>

## 8. Z变换

### 8.1 Z变换的定义

#### 8.1.1 双边Z变换

**正变换：**
$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{\infty} x[n] z^{-n}$$

**逆变换：**
$$x[n] = \mathcal{Z}^{-1}\{X(z)\} = \frac{1}{2\pi j} \oint_C X(z) z^{n-1} dz$$

其中 $z = re^{j\Omega}$ 为复变量，$C$ 为ROC内的闭合曲线。

#### 8.1.2 单边Z变换

**正变换：**
$$X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=0}^{\infty} x[n] z^{-n}$$

**特点：**
- 适用于因果序列
- 便于处理初始条件
- 与拉普拉斯变换形式相似

### 8.2 收敛域

#### 8.2.1 收敛域的性质

<details>
<summary><strong>ROC的详细性质</strong></summary>

**基本性质：**

1. **环形区域：** ROC是z平面上的环形区域 $R_1 < |z| < R_2$
2. **无极点：** ROC内不包含任何极点
3. **有限长序列：** 
   - 两边有限：ROC是整个z平面（除z=0或z=∞）
   - 右边有限：ROC在 $|z| > R_{min}$
   - 左边有限：ROC在 $|z| < R_{max}$

4. **无限长序列：**
   - 右边序列：ROC在模最大的极点之外
   - 左边序列：ROC在模最小的极点之内
   - 双边序列：ROC是极点之间的环形区域

**收敛条件：**
$$\sum_{n=-\infty}^{\infty} |x[n] z^{-n}| < \infty$$

**常见序列的ROC：**

| 序列类型 | ROC |
|----------|-----|
| 有限长（两边） | 整个z平面 |
| 有限长（右边） | $\|z\| > 0$ |
| 有限长（左边） | $\|z\| < \infty$ |
| 右边无限长 | $\|z\| > r_{max}$ |
| 左边无限长 | $\|z\| < r_{min}$ |
| 双边无限长 | $r_{min} < \|z\| < r_{max}$ |
</details>

### 8.3 Z变换的性质

#### 8.3.1 基本性质

| 性质 | 时域 | Z域 | ROC |
|------|------|-----|-----|
| **线性** | $ax_1[n] + bx_2[n]$ | $aX_1(z) + bX_2(z)$ | 包含交集 |
| **时移** | $x[n-n_0]$ | $z^{-n_0}X(z)$ | 与原ROC相同（除z=0） |
| **频移** | $z_0^n x[n]$ | $X(z/z_0)$ | 缩放ROC |
| **时间反转** | $x[-n]$ | $X(1/z)$ | ROC取倒数 |
| **共轭** | $x^*[n]$ | $X^*(z^*)$ | ROC相同 |

#### 8.3.2 微分性质

<details>
<summary><strong>微分性质</strong></summary>

**z域微分：**
$$\mathcal{Z}\{n x[n]\} = -z \frac{dX(z)}{dz}$$

**证明：**
$$\frac{dX(z)}{dz} = \frac{d}{dz} \sum_{n=-\infty}^{\infty} x[n] z^{-n} = \sum_{n=-\infty}^{\infty} x[n] (-n) z^{-n-1}$$
$$= -\frac{1}{z} \sum_{n=-\infty}^{\infty} n x[n] z^{-n}$$

因此：
$$\mathcal{Z}\{n x[n]\} = -z \frac{dX(z)}{dz}$$

**应用：**
- 从已知变换求 $n x[n]$ 的变换
- 处理包含n因子的序列
</details>

#### 8.3.3 序列乘法（频域卷积）

**时域乘积，Z域卷积：**
$$\mathcal{Z}\{x[n]y[n]\} = \frac{1}{2\pi j} \oint_C X(v)Y(z/v) v^{-1} dv$$

**特殊情况（有限长序列）：**
$$\mathcal{Z}\{x[n]y[n]\} = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\Omega})Y(e^{j(\Omega-\Omega_0)}) d\Omega$$

### 8.4 逆Z变换

#### 8.4.1 部分分式展开法

<details>
<summary><strong>部分分式展开步骤</strong></summary>

**步骤：**

1. **化为真分式：** 如果分子阶数 ≥ 分母阶数，先做多项式除法
2. **因式分解：** 将分母多项式分解为一次因子
3. **设展开式：**
   $$X(z) = \sum_{i=1}^{n} \frac{A_i}{1 - p_i z^{-1}} + \sum_{j} \frac{B_j z^{-1} + C_j}{1 - 2r_j \cos\theta_j z^{-1} + r_j^2 z^{-2}}$$
4. **求系数：** 使用留数法或长除法
5. **查表求逆变换**

**留数法求系数：**
$$A_k = \text{Res}\left[\frac{X(z)}{z}, z = p_k\right]$$

**常见形式：**
- $\frac{A}{1 - p z^{-1}} \leftrightarrow A p^n u[n]$
- $\frac{A z^{-1}}{1 - 2r \cos\theta z^{-1} + r^2 z^{-2}} \leftrightarrow A r^n \sin(n\theta + \phi) u[n]$
</details>

#### 8.4.2 幂级数展开法

**适用于：**
- 已知 $X(z)$ 的幂级数形式
- 有限长序列

**方法：**
将 $X(z)$ 展开为 $z^{-1}$ 的幂级数，系数即为序列值。

$$X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n} = \cdots + x[-1] z + x[0] + x[1] z^{-1} + x[2] z^{-2} + \cdots$$

#### 8.4.3 围线积分法（留数法）

**公式：**
$$x[n] = \frac{1}{2\pi j} \oint_C X(z) z^{n-1} dz = \sum \text{Res}[X(z) z^{n-1}, \text{ROC内的极点}]$$

### 8.5 系统函数

#### 8.5.1 系统函数的定义

**系统函数：**
$$H(z) = \frac{Y(z)}{X(z)} = \frac{\mathcal{Z}\{y[n]\}}{\mathcal{Z}\{x[n]\}}$$

**从差分方程得到：**
对于系统差分方程：
$$\sum_{k=0}^{n} a_k y[n-k] = \sum_{k=0}^{m} b_k x[n-k]$$

系统函数为：
$$H(z) = \frac{\sum_{k=0}^{m} b_k z^{-k}}{\sum_{k=0}^{n} a_k z^{-k}}$$

#### 8.5.2 极零点分析

**标准形式：**
$$H(z) = K \frac{(1 - z_1 z^{-1})(1 - z_2 z^{-1})\cdots(1 - z_m z^{-1})}{(1 - p_1 z^{-1})(1 - p_2 z^{-1})\cdots(1 - p_n z^{-1})}$$

其中：
- $z_1, z_2, \ldots, z_m$：零点
- $p_1, p_2, \ldots, p_n$：极点
- $K$：增益常数

#### 8.5.3 稳定性判据

<details>
<summary><strong>稳定性判据</strong></summary>

**BIBO稳定条件：**
系统函数 $H(z)$ 的所有极点必须位于单位圆内（$|p_i| < 1$）。

**朱里判据（Jury判据）：**

对于特征多项式：
$$P(z) = a_n z^n + a_{n-1} z^{n-1} + \cdots + a_1 z + a_0 = 0$$

构造朱里表，稳定性条件：
1. $P(1) > 0$
2. $(-1)^n P(-1) > 0$
3. $|a_0| < a_n$
4. 朱里表第一列元素的绝对值递减

**特殊情况：**
- **一阶系统：** $|a_0| < a_1$
- **二阶系统：** $|a_0| < a_2$ 且 $|a_0^2 - a_2^2| < a_1(a_2 - a_0)$
</details>

### 8.6 频率响应

#### 8.6.1 频率响应的计算

**频率响应：**
$$H(e^{j\Omega}) = H(z)|_{z=e^{j\Omega}} = |H(e^{j\Omega})|e^{j\angle H(e^{j\Omega})}$$

其中 $\Omega$ 为数字角频率，$0 \leq \Omega \leq 2\pi$。

#### 8.6.2 几何确定法

<details>
<summary><strong>几何确定法</strong></summary>

**基本原理：**
频率响应 $H(e^{j\Omega})$ 可以通过z平面上单位圆上的极零点几何关系确定。

**计算步骤：**

1. **确定极零点位置：** 在z平面上标出所有极点和零点
2. **选择频率点：** 在单位圆上选择 $\Omega$ 值，对应点 $e^{j\Omega}$
3. **计算矢量：**
   - 从每个极点 $p_i$ 到点 $e^{j\Omega}$ 的矢量：$e^{j\Omega} - p_i$
   - 从每个零点 $z_i$ 到点 $e^{j\Omega}$ 的矢量：$e^{j\Omega} - z_i$
4. **计算幅频响应：**
   $$|H(e^{j\Omega})| = |K| \frac{\prod_{i=1}^{m} |e^{j\Omega} - z_i|}{\prod_{i=1}^{n} |e^{j\Omega} - p_i|}$$
5. **计算相频响应：**
   $$\angle H(e^{j\Omega}) = \angle K + \sum_{i=1}^{m} \angle(e^{j\Omega} - z_i) - \sum_{i=1}^{n} \angle(e^{j\Omega} - p_i)$$

**频率响应特性：**
- **低通：** 零点接近单位圆上的 $\Omega = 0$
- **高通：** 零点接近单位圆上的 $\Omega = \pi$
- **带通：** 零点接近单位圆上的 $\Omega = \pm\Omega_0$
</details>

## 9. 状态空间分析

### 9.1 状态空间模型

#### 9.1.1 连续时间系统状态空间模型

**状态方程：**
$$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}\mathbf{u}(t)$$

**输出方程：**
$$\mathbf{y}(t) = \mathbf{C}\mathbf{x}(t) + \mathbf{D}\mathbf{u}(t)$$

其中：
- $\mathbf{x}(t) \in \mathbb{R}^n$：状态向量
- $\mathbf{u}(t) \in \mathbb{R}^p$：输入向量
- $\mathbf{y}(t) \in \mathbb{R}^q$：输出向量
- $\mathbf{A} \in \mathbb{R}^{n \times n}$：系统矩阵
- $\mathbf{B} \in \mathbb{R}^{n \times p}$：输入矩阵
- $\mathbf{C} \in \mathbb{R}^{q \times n}$：输出矩阵
- $\mathbf{D} \in \mathbb{R}^{q \times p}$：直接传输矩阵

#### 9.1.2 离散时间系统状态空间模型

**状态方程：**
$$\mathbf{x}[n+1] = \mathbf{A}\mathbf{x}[n] + \mathbf{B}\mathbf{u}[n]$$

**输出方程：**
$$\mathbf{y}[n] = \mathbf{C}\mathbf{x}[n] + \mathbf{D}\mathbf{u}[n]$$

### 9.2 状态转移矩阵

#### 9.2.1 连续时间系统

<details>
<summary><strong>状态转移矩阵</strong></summary>

**定义：** 状态转移矩阵 $\Phi(t) = e^{\mathbf{A}t}$ 满足：
$$\dot{\Phi}(t) = \mathbf{A}\Phi(t), \quad \Phi(0) = \mathbf{I}$$

**性质：**
1. $\Phi(t_1 + t_2) = \Phi(t_1)\Phi(t_2)$
2. $\Phi(-t) = \Phi^{-1}(t)$
3. $\frac{d}{dt}\Phi(t) = \mathbf{A}\Phi(t) = \Phi(t)\mathbf{A}$

**计算方法：**

1. **特征值分解法：**
   $$\mathbf{A} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^{-1}$$
   $$e^{\mathbf{A}t} = \mathbf{V}e^{\mathbf{\Lambda}t}\mathbf{V}^{-1}$$

2. **凯莱-哈密顿定理：**
   利用特征方程 $\mathbf{A}^n = -\sum_{k=0}^{n-1} a_k \mathbf{A}^k$

3. **拉普拉斯变换法：**
   $$e^{\mathbf{A}t} = \mathcal{L}^{-1}\{(s\mathbf{I} - \mathbf{A})^{-1}\}$$

4. **级数展开法：**
   $$e^{\mathbf{A}t} = \sum_{k=0}^{\infty} \frac{(\mathbf{A}t)^k}{k!}$$
</details>

#### 9.2.2 离散时间系统

**状态转移矩阵：**
$$\Phi[n] = \mathbf{A}^n$$

**性质：**
1. $\Phi[n_1 + n_2] = \Phi[n_1]\Phi[n_2]$
2. $\Phi[-n] = \Phi^{-1}[n]$（若 $\mathbf{A}$ 可逆）
3. $\Phi[n_1 - n_2] = \Phi[n_1]\Phi^{-1}[n_2]$

### 9.3 状态方程的求解

#### 9.3.1 连续时间系统

<details>
<summary><strong>状态方程求解</strong></summary>

**齐次方程：**
$$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t)$$

**解：**
$$\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0) = \Phi(t)\mathbf{x}(0)$$

**非齐次方程：**
$$\dot{\mathbf{x}}(t) = \mathbf{A}\mathbf{x}(t) + \mathbf{B}\mathbf{u}(t)$$

**解：**
$$\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0) + \int_{0}^{t} e^{\mathbf{A}(t-\tau)}\mathbf{B}\mathbf{u}(\tau)d\tau$$

**状态转移形式：**
$$\mathbf{x}(t) = \Phi(t-t_0)\mathbf{x}(t_0) + \int_{t_0}^{t} \Phi(t-\tau)\mathbf{B}\mathbf{u}(\tau)d\tau$$

**输出：**
$$\mathbf{y}(t) = \mathbf{C}e^{\mathbf{A}t}\mathbf{x}(0) + \int_{0}^{t} \mathbf{C}e^{\mathbf{A}(t-\tau)}\mathbf{B}\mathbf{u}(\tau)d\tau + \mathbf{D}\mathbf{u}(t)$$
</details>

#### 9.3.2 离散时间系统

**齐次方程：**
$$\mathbf{x}[n] = \mathbf{A}^n \mathbf{x}[0]$$

**非齐次方程：**
$$\mathbf{x}[n] = \mathbf{A}^n \mathbf{x}[0] + \sum_{k=0}^{n-1} \mathbf{A}^{n-1-k}\mathbf{B}\mathbf{u}[k]$$

**状态转移形式：**
$$\mathbf{x}[n] = \mathbf{A}^{n-n_0}\mathbf{x}[n_0] + \sum_{k=n_0}^{n-1} \mathbf{A}^{n-1-k}\mathbf{B}\mathbf{u}[k]$$

### 9.4 稳定性分析

#### 9.4.1 连续时间系统

<details>
<summary><strong>连续时间系统稳定性</strong></summary>

**渐近稳定：** 所有特征值实部为负
$$\lambda_i(\mathbf{A}) < 0, \quad i = 1, 2, \ldots, n$$

**李雅普诺夫稳定性判据：**

**定理：** 系统 $\dot{\mathbf{x}} = \mathbf{A}\mathbf{x}$ 渐近稳定的充要条件是：对任意正定矩阵 $\mathbf{Q}$，李雅普诺夫方程
$$\mathbf{A}^T\mathbf{P} + \mathbf{P}\mathbf{A} = -\mathbf{Q}$$
有唯一正定解 $\mathbf{P}$。

**李雅普诺夫函数：**
$$V(\mathbf{x}) = \mathbf{x}^T\mathbf{P}\mathbf{x}$$
- $V(\mathbf{x}) > 0$（正定）
- $\dot{V}(\mathbf{x}) = \mathbf{x}^T(\mathbf{A}^T\mathbf{P} + \mathbf{P}\mathbf{A})\mathbf{x} < 0$（负定）

**判别方法：**
1. 计算特征值
2. 构造李雅普诺夫方程
3. 赫尔维茨判据（矩阵形式）
</details>

#### 9.4.2 离散时间系统

**渐近稳定：** 所有特征值在单位圆内
$$|\lambda_i(\mathbf{A})| < 1, \quad i = 1, 2, \ldots, n$$

**李雅普诺夫稳定性判据：**

**定理：** 系统 $\mathbf{x}[n+1] = \mathbf{A}\mathbf{x}[n]$ 渐近稳定的充要条件是：对任意正定矩阵 $\mathbf{Q}$，李雅普诺夫方程
$$\mathbf{A}^T\mathbf{P}\mathbf{A} - \mathbf{P} = -\mathbf{Q}$$
有唯一正定解 $\mathbf{P}$。

### 9.5 可控性和可观性

#### 9.5.1 可控性

<details>
<summary><strong>可控性判据</strong></summary>

**定义：** 系统状态完全可控，如果对任意初始状态 $\mathbf{x}(0)$ 和任意最终状态 $\mathbf{x}(T)$，存在有限时间 $T > 0$ 和控制输入 $\mathbf{u}(t)$，使得 $\mathbf{x}(T) = \mathbf{x}_f$。

**连续时间系统可控性判据：**

1. **秩判据：**
   $$\text{rank}[\mathbf{B}, \mathbf{AB}, \mathbf{A}^2\mathbf{B}, \ldots, \mathbf{A}^{n-1}\mathbf{B}] = n$$

2. **格拉姆矩阵判据：**
   $$\mathbf{W}_c(T) = \int_{0}^{T} e^{\mathbf{A}\tau}\mathbf{B}\mathbf{B}^T e^{\mathbf{A}^T\tau} d\tau > 0$$

**离散时间系统可控性判据：**
$$\text{rank}[\mathbf{B}, \mathbf{AB}, \mathbf{A}^2\mathbf{B}, \ldots, \mathbf{A}^{n-1}\mathbf{B}] = n$$

**可控性指数：** $\mu_c = \min\{k : \text{rank}[\mathbf{B}, \mathbf{AB}, \ldots, \mathbf{A}^{k-1}\mathbf{B}] = n\}$
</details>

#### 9.5.2 可观性

<details>
<summary><strong>可观性判据</strong></summary>

**定义：** 系统状态完全可观，如果根据有限时间内的输出 $\mathbf{y}(t)$ 和输入 $\mathbf{u}(t)$，能够唯一确定初始状态 $\mathbf{x}(0)$。

**连续时间系统可观性判据：**

1. **秩判据：**
   $$\text{rank}\begin{bmatrix}
   \mathbf{C} \\
   \mathbf{CA} \\
   \mathbf{CA}^2 \\
   \vdots \\
   \mathbf{CA}^{n-1}
   \end{bmatrix} = n$$

2. **格拉姆矩阵判据：**
   $$\mathbf{W}_o(T) = \int_{0}^{T} e^{\mathbf{A}^T\tau}\mathbf{C}^T\mathbf{C} e^{\mathbf{A}\tau} d\tau > 0$$

**离散时间系统可观性判据：**
$$\text{rank}\begin{bmatrix}
\mathbf{C} \\
\mathbf{CA} \\
\mathbf{CA}^2 \\
\vdots \\
\mathbf{CA}^{n-1}
\end{bmatrix} = n$$

**可观性指数：** $\\nu_o = \min\{k : \text{rank}[\mathbf{C}^T, \mathbf{A}^T\mathbf{C}^T, \ldots, (\mathbf{A}^T)^{k-1}\mathbf{C}^T]^T = n\}$
</details>

#### 9.5.3 可控可观性分解

**标准形分解：**
通过坐标变换，可以将系统分解为：
- 可控可观子系统
- 可控不可观子系统  
- 不可控可观子系统
- 不可控不可观子系统

**卡尔曼分解：**
$$\mathbf{A}_c = \mathbf{T}^{-1}\mathbf{A}\mathbf{T} = \begin{bmatrix}
\mathbf{A}_{co} & \mathbf{A}_{12} & \mathbf{A}_{13} & \mathbf{A}_{14} \\
0 & \mathbf{A}_{co} & 0 & \mathbf{A}_{24} \\
0 & 0 & \mathbf{A}_{c\bar{o}} & \mathbf{A}_{34} \\
0 & 0 & 0 & \mathbf{A}_{\bar{c}\bar{o}}
\end{bmatrix}$$

其中：
- 下标 $co$：可控可观
- $c\bar{o}$：可控不可观
- $\bar{c}o$：不可控可观
- $\bar{c}\bar{o}$：不可控不可观

### 9.6 状态反馈与状态观测器

#### 9.6.1 状态反馈控制

<details>
<summary><strong>状态反馈控制</strong></summary>

**控制律：**
$$\mathbf{u}(t) = -\mathbf{K}\mathbf{x}(t) + \mathbf{r}(t)$$

其中 $\mathbf{K}$ 为状态反馈增益矩阵，$\mathbf{r}(t)$ 为参考输入。

**闭环系统：**
$$\dot{\mathbf{x}}(t) = (\mathbf{A} - \mathbf{BK})\mathbf{x}(t) + \mathbf{B}\mathbf{r}(t)$$

**极点配置：**
通过选择适当的 $\mathbf{K}$，可以任意配置闭环系统的极点（当系统完全可控时）。

**阿克曼公式（Ackermann公式）：**
$$\mathbf{K} = [0, 0, \ldots, 1] \mathcal{C}^{-1} \phi(\mathbf{A})$$

其中：
- $\mathcal{C} = [\mathbf{B}, \mathbf{AB}, \ldots, \mathbf{A}^{n-1}\mathbf{B}]$：可控性矩阵
- $\phi(\mathbf{A})$：期望特征多项式在 $\mathbf{A}$ 处的值
</details>

#### 9.6.2 状态观测器

<details>
<summary><strong>状态观测器</strong></summary>

**全维观测器：**
$$\dot{\hat{\mathbf{x}}}(t) = \mathbf{A}\hat{\mathbf{x}}(t) + \mathbf{B}\mathbf{u}(t) + \mathbf{L}[\mathbf{y}(t) - \mathbf{C}\hat{\mathbf{x}}(t)]$$

其中 $\mathbf{L}$ 为观测器增益矩阵。

**观测器误差：**
$$\dot{\mathbf{e}}(t) = \dot{\mathbf{x}}(t) - \dot{\hat{\mathbf{x}}}(t) = (\mathbf{A} - \mathbf{LC})\mathbf{e}(t)$$

**稳定性条件：**
观测器渐近稳定的充要条件是 $(\mathbf{A} - \mathbf{LC})$ 的特征值位于左半平面。

**极点配置：**
通过选择适当的 $\mathbf{L}$，可以任意配置观测器的极点（当系统完全可观时）。

**阿克曼公式（观测器形式）：**
$$\mathbf{L} = \phi(\mathbf{A}) \mathcal{O}^{-1} \begin{bmatrix}
0 \\ 0 \\ \vdots \\ 1
\end{bmatrix}$$

其中 $\mathcal{O}$ 为可观性矩阵。
</details>

## 10. 随机信号分析

### 10.1 随机过程基础

#### 10.1.1 随机过程的定义

**随机过程：** 随时间演化的随机现象，是时间 $t$ 和随机试验结果 $\omega$ 的函数

$$X(t, \omega), \quad t \in T, \omega \in \Omega$$

**简化表示：** $X(t)$，其中 $t$ 为时间参数，$X(t)$ 为随机变量。

#### 10.1.2 随机过程的统计特性

**均值函数：**
$$m_X(t) = E\{X(t)\} = \int_{-\infty}^{\infty} x f_X(x, t) dx$$

**自相关函数：**
$$R_X(t_1, t_2) = E\{X(t_1)X(t_2)\} = \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} x_1 x_2 f_X(x_1, x_2; t_1, t_2) dx_1 dx_2$$

**自协方差函数：**
$$C_X(t_1, t_2) = E\{[X(t_1) - m_X(t_1)][X(t_2) - m_X(t_2)]\}$$

#### 10.1.3 随机过程的分类

| 分类 | 定义 | 特征 |
|------|------|------|
| **连续时间随机过程** | 时间连续 $t \in \mathbb{R}$ | $X(t)$ 为连续随机变量 |
| **离散时间随机过程** | 时间离散 $t \in \mathbb{Z}$ | $X[n]$ 为离散随机变量 |
| **连续值随机过程** | 取值连续 | $X(t)$ 为连续随机变量 |
| **离散值随机过程** | 取值离散 | $X(t)$ 为离散随机变量 |

### 10.2 平稳随机过程

#### 10.2.1 平稳性的定义

<details>
<summary><strong>平稳性判据</strong></summary>

**严格平稳（强平稳）：**
随机过程 $X(t)$ 称为严格平稳的，如果对任意 $t_1, t_2, \ldots, t_n$ 和任意 $\tau$，有：
$$F_X(x_1, x_2, \ldots, x_n; t_1, t_2, \ldots, t_n) = F_X(x_1, x_2, \ldots, x_n; t_1+\tau, t_2+\tau, \ldots, t_n+\tau)$$

**广义平稳（弱平稳）：**
随机过程 $X(t)$ 称为广义平稳的，如果：
1. 均值函数为常数：$m_X(t) = m_X$（常数）
2. 自相关函数仅与时间差有关：$R_X(t_1, t_2) = R_X(\tau)$，其中 $\tau = t_1 - t_2$

**各态遍历性：**
随机过程 $X(t)$ 称为各态遍历的，如果时间平均等于统计平均：
$$m_X = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} X(t) dt$$
$$R_X(\tau) = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} X(t)X(t+\tau) dt$$
</details>

#### 10.2.2 平稳随机过程的性质

**自相关函数的性质：**

1. **对称性：** $R_X(-\tau) = R_X^*(\tau)$
2. **最大值：** $|R_X(\tau)| \leq R_X(0)$
3. **周期性：** 如果 $R_X(\tau)$ 是周期函数，则 $X(t)$ 是周期平稳过程
4. **连续性：** $R_X(\tau)$ 在 $\tau = 0$ 处连续

**功率谱密度：**
$$S_X(\omega) = \mathcal{F}\{R_X(\tau)\} = \int_{-\infty}^{\infty} R_X(\tau) e^{-j\omega\tau} d\tau$$

### 10.3 功率谱密度

#### 10.3.1 维纳-辛钦定理

<details>
<summary><strong>维纳-辛钦定理</strong></summary>

**定理：** 广义平稳随机过程的功率谱密度 $S_X(\omega)$ 与自相关函数 $R_X(\tau)$ 是一对傅里叶变换对：

$$S_X(\omega) = \int_{-\infty}^{\infty} R_X(\tau) e^{-j\omega\tau} d\tau$$

$$R_X(\tau) = \frac{1}{2\pi} \int_{-\infty}^{\infty} S_X(\omega) e^{j\omega\tau} d\omega$$

**物理意义：**
- $S_X(\omega)$ 表示随机过程在频率 $\omega$ 处的功率分布
- $R_X(\tau)$ 表示随机过程在不同时刻的相关程度

**功率计算：**
$$P_X = E\{X^2(t)\} = R_X(0) = \frac{1}{2\pi} \int_{-\infty}^{\infty} S_X(\omega) d\omega$$

**离散时间形式：**
$$S_X(e^{j\Omega}) = \sum_{m=-\infty}^{\infty} R_X[m] e^{-j\Omega m}$$
$$R_X[m] = \frac{1}{2\pi} \int_{-\infty}^{\infty} S_X(e^{j\Omega}) e^{j\Omega m} d\Omega$$
</details>

#### 10.3.2 常见随机过程的功率谱密度

| 随机过程 | 自相关函数 | 功率谱密度 |
|----------|------------|------------|
| **白噪声** | $R_X(\tau) = \frac{N_0}{2}\delta(\tau)$ | $S_X(\omega) = \frac{N_0}{2}$ |
| **低通白噪声** | $R_X(\tau) = \frac{N_0}{2} \frac{\sin(\omega_c \tau)}{\pi \tau}$ | $S_X(\omega) = \begin{cases} \frac{N_0}{2}, & \|\omega\| < \omega_c \\ 0, & \|\omega\| > \omega_c \end{cases}$ |
| **马尔可夫过程** | $R_X(\tau) = \sigma^2 e^{-\alpha\|\tau\|}$ | $S_X(\omega) = \frac{2\alpha\sigma^2}{\alpha^2 + \omega^2}$ |
| **正弦信号加噪声** | $R_X(\tau) = \frac{A^2}{2}\cos(\omega_0\tau) + \frac{N_0}{2}\delta(\tau)$ | $S_X(\omega) = \frac{\pi A^2}{2}[\delta(\omega - \omega_0) + \delta(\omega + \omega_0)] + \frac{N_0}{2}$ |

### 10.4 白噪声

#### 10.4.1 白噪声的定义

**连续时间白噪声：**
$$E\{w(t)\} = 0, \quad E\{w(t_1)w(t_2)\} = \frac{N_0}{2}\delta(t_1 - t_2)$$

**离散时间白噪声：**
$$E\{w[n]\} = 0, \quad E\{w[n]w[m]\} = \sigma_w^2 \delta[n-m]$$

#### 10.4.2 白噪声的性质

<details>
<summary><strong>白噪声特性</strong></summary>

**性质：**

1. **功率谱密度：** 恒定（白噪声的"白"字由此而来）
2. **相关性：** 不同时刻的取值不相关
3. **高斯白噪声：** 如果 $w(t)$ 服从高斯分布，则称为高斯白噪声
4. **理想化：** 实际中不存在真正的白噪声，只能近似

**通过线性系统：**
设白噪声 $w(t)$ 通过线性时不变系统 $h(t)$，输出为 $y(t) = w(t) * h(t)$。

**输出功率谱密度：**
$$S_Y(\omega) = |H(j\omega)|^2 S_W(\omega)$$

**输出自相关函数：**
$$R_Y(\tau) = R_W(\tau) * h(\tau) * h(-\tau)$$

**应用：**
- 系统辨识
- 噪声分析
- 卡尔曼滤波
- 随机微分方程
</details>

### 10.5 随机信号的线性系统响应

#### 10.5.1 连续时间系统

<details>
<summary><strong>随机信号通过连续时间系统</strong></summary>

**系统输入：** 广义平稳随机过程 $X(t)$
**系统冲激响应：** $h(t)$
**系统输出：** $Y(t) = X(t) * h(t)$

**输出均值：**
$$m_Y = E\{Y(t)\} = E\{X(t) * h(t)\} = m_X \int_{-\infty}^{\infty} h(\tau) d\tau = m_X H(0)$$

**输出自相关函数：**
$$R_Y(\tau) = R_X(\tau) * h(\tau) * h(-\tau)$$

**输出功率谱密度：**
$$S_Y(\omega) = |H(j\omega)|^2 S_X(\omega)$$

**输出功率：**
$$P_Y = E\{Y^2(t)\} = \frac{1}{2\pi} \int_{-\infty}^{\infty} |H(j\omega)|^2 S_X(\omega) d\omega$$

**互功率谱密度：**
$$S_{XY}(\omega) = H(j\omega) S_X(\omega)$$

**互相关函数：**
$$R_{XY}(\tau) = h(\tau) * R_X(\tau)$$
</details>

#### 10.5.2 离散时间系统

**系统输入：** 广义平稳随机过程 $X[n]$
**系统单位脉冲响应：** $h[n]$
**系统输出：** $Y[n] = X[n] * h[n]$

**输出均值：**
$$m_Y = m_X \sum_{k=-\infty}^{\infty} h[k] = m_X H(e^{j0})$$

**输出自相关函数：**
$$R_Y[m] = R_X[m] * h[m] * h[-m]$$

**输出功率谱密度：**
$$S_Y(e^{j\Omega}) = |H(e^{j\Omega})|^2 S_X(e^{j\Omega})$$

**输出功率：**
$$P_Y = \frac{1}{2\pi} \int_{-\infty}^{\infty} |H(e^{j\Omega})|^2 S_X(e^{j\Omega}) d\Omega$$

### 10.6 随机信号的参数估计

#### 10.6.1 均值估计

**样本均值：**
$$\hat{m}_X = \frac{1}{N} \sum_{n=1}^{N} X[n]$$

**估计性质：**
- **无偏性：** $E\{\hat{m}_X\} = m_X$
- **方差：** $\text{Var}\{\hat{m}_X\} = \frac{R_X[0] + 2\sum_{k=1}^{N-1} \frac{N-k}{N} R_X[k]}{N}$

#### 10.6.2 自相关函数估计

**样本自相关函数：**
$$\hat{R}_X[m] = \frac{1}{N} \sum_{n=0}^{N-1-m} X[n]X[n+m]$$

**估计性质：**
- **有偏估计：** $E\{\hat{R}_X[m]\} = \frac{N-|m|}{N} R_X[m]$
- **无偏估计：** $\tilde{R}_X[m] = \frac{1}{N-|m|} \sum_{n=0}^{N-1-m} X[n]X[n+m]$

#### 10.6.3 功率谱密度估计

<details>
<summary><strong>功率谱密度估计方法</strong></summary>

**1. 周期图法：**
$$\hat{S}_X(e^{j\Omega}) = \frac{1}{N} \left|\sum_{n=0}^{N-1} X[n] e^{-j\Omega n}\right|^2$$

**2. 韦尔奇法（Welch方法）：**
- 将数据分为重叠段
- 对每段计算周期图
- 平均周期图

**3. 自相关法（Blackman-Tukey方法）：**
$$\hat{S}_X(e^{j\Omega}) = \sum_{m=-(N-1)}^{N-1} \hat{R}_X[m] w[m] e^{-j\Omega m}$$

其中 $w[m]$ 为窗函数。

**4. 现代谱估计方法：**
- AR模型法
- MA模型法
- ARMA模型法
- Prony方法
- MUSIC算法
</details>

## 11. 数字信号处理基础

### 11.1 数字滤波器设计

#### 11.1.1 IIR滤波器设计

<details>
<summary><strong>IIR滤波器设计方法</strong></summary>

**1. 冲激响应不变法：**

**设计步骤：**
1. 设计模拟滤波器 $H_a(s)$
2. 求模拟滤波器的冲激响应 $h_a(t)$
3. 采样得到数字滤波器冲激响应 $h[n] = T_s h_a(nT_s)$
4. 对 $h[n]$ 进行Z变换得到 $H(z)$

**优点：** 保持模拟滤波器的频率响应形状
**缺点：** 存在频率混叠现象

**2. 双线性变换法：**

**变换公式：**
$$s = \frac{2}{T_s} \frac{1 - z^{-1}}{1 + z^{-1}}$$

**优点：** 消除频率混叠
**缺点：** 频率轴发生非线性畸变

**频率预畸变：**
$$\omega_a = \frac{2}{T_s} \tan\left(\frac{\omega_d T_s}{2}\right)$$

其中 $\omega_a$ 为模拟频率，$\omega_d$ 为数字频率。
</details>

#### 11.1.2 FIR滤波器设计

**窗函数法：**

<details>
<summary><strong>窗函数设计法</strong></summary>

**设计步骤：**
1. 确定理想频率响应 $H_d(e^{j\Omega})$
2. 计算理想冲激响应 $h_d[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} H_d(e^{j\Omega}) e^{j\Omega n} d\Omega$
3. 选择窗函数 $w[n]$
4. 得到实际冲激响应 $h[n] = h_d[n] w[n]$
5. 对 $h[n]$ 进行截断和移位

**常用窗函数：**

| 窗函数 | 表达式 | 主瓣宽度 | 旁瓣衰减 |
|--------|--------|----------|----------|
| **矩形窗** | $w[n] = 1, 0 \leq n \leq N-1$ | $4\pi/N$ | -13dB |
| **汉宁窗** | $w[n] = 0.5 - 0.5\cos\left(\frac{2\pi n}{N-1}\right)$ | $8\pi/N$ | -31dB |
| **汉明窗** | $w[n] = 0.54 - 0.46\cos\left(\frac{2\pi n}{N-1}\right)$ | $8\pi/N$ | -41dB |
| **布莱克曼窗** | $w[n] = 0.42 - 0.5\cos\left(\frac{2\pi n}{N-1}\right) + 0.08\cos\left(\frac{4\pi n}{N-1}\right)$ | $12\pi/N$ | -58dB |
| **凯泽窗** | $w[n] = \frac{I_0\left(\beta\sqrt{1-(2n/(N-1)-1)^2}\right)}{I_0(\beta)}$ | 可调 | 可调 |

其中 $I_0(\cdot)$ 为零阶修正贝塞尔函数，$\beta$ 为形状参数。
</details>

**频率采样法：**

**设计步骤：**
1. 在频率轴上采样理想频率响应 $H_d(e^{j\Omega})$
2. 得到采样值 $H[k] = H_d(e^{j\frac{2\pi k}{N}})$
3. 通过IDFT得到时域序列
4. 对时域序列进行加窗处理

### 11.2 多速率信号处理

#### 11.2.1 抽取（Downsampling）

<details>
<summary><strong>抽取操作</strong></summary>

**抽取因子：** $M$（整数）

**抽取信号：**
$$y[n] = x[Mn]$$

**频域关系：**
$$Y(e^{j\Omega}) = \frac{1}{M} \sum_{k=0}^{M-1} X\left(e^{j(\Omega - 2\pi k)/M}\right)$$

**混叠现象：**
当 $x[n]$ 的最高频率分量超过 $\pi/M$ 时，抽取后会发生混叠。

**抗混叠滤波器：**
在抽取前需要使用低通滤波器，截止频率为 $\pi/M$。

**抽取滤波器设计：**
- 过渡带：$\pi/M - \omega_s$
- 通带纹波：$\delta_p$
- 阻带纹波：$\delta_s$
</details>

#### 11.2.2 插值（Upsampling）

**插值因子：** $L$（整数）

**插值信号：**
$$y[n] = \begin{cases}
x[n/L], & n = 0, \pm L, \pm 2L, \ldots \\
0, & \text{其他}
\end{cases}$$

**频域关系：**
$$Y(e^{j\Omega}) = X(e^{jL\Omega})$$

**镜像频率：**
插值后在 $\Omega = \pi/L, 2\pi/L, \ldots$ 处出现镜像频率，需要用低通滤波器消除。

**插值滤波器设计：**
- 截止频率：$\pi/L$
- 通带纹波：$\delta_p$
- 阻带纹波：$\delta_s$

#### 11.2.3 采样率变换

**有理数倍变换：**
$$y[n] = x\left[\left\lfloor \frac{nL}{M} \right\rfloor\right]$$

其中 $L/M$ 为有理数变换因子。

**实现结构：**
1. 先插值（因子 $L$）
2. 再抽取（因子 $M$）
3. 中间需要抗混叠/抗镜像滤波器

### 11.3 窗函数设计

#### 11.3.1 窗函数的特性

<details>
<summary><strong>窗函数性能指标</strong></summary>

**主要性能指标：**

1. **主瓣宽度：** 定义为第一对零点之间的宽度
   - 决定频率分辨率
   - 主瓣越窄，分辨率越高

2. **最大旁瓣衰减：** 最大旁瓣与主瓣的比值（dB）
   - 决定频谱泄漏程度
   - 衰减越大，泄漏越小

3. **旁瓣衰减速率：** 旁瓣随频率衰减的速率
   - 决定频谱的平滑程度

**常用窗函数比较：**

| 窗函数 | 主瓣宽度 | 最大旁瓣衰减 | 旁瓣衰减速率 |
|--------|----------|--------------|--------------|
| 矩形窗 | $4\pi/N$ | -13dB | -6dB/倍频程 |
| 汉宁窗 | $8\pi/N$ | -31dB | -18dB/倍频程 |
| 汉明窗 | $8\pi/N$ | -41dB | -6dB/倍频程 |
| 布莱克曼窗 | $12\pi/N$ | -58dB | -6dB/倍频程 |
| 凯泽窗($\beta=8$) | $10\pi/N$ | -58dB | 可调 |

**选择原则：**
- 需要高分辨率：选择主瓣窄的窗函数
- 需要低泄漏：选择旁瓣衰减大的窗函数
- 需要平滑频谱：选择衰减速率快的窗函数
</details>

#### 11.3.2 凯泽窗

**定义：**
$$w[n] = \frac{I_0\left(\beta\sqrt{1-(2n/(N-1)-1)^2}\right)}{I_0(\beta)}, \quad 0 \leq n \leq N-1$$

其中：
- $I_0(\cdot)$：零阶修正贝塞尔函数
- $\beta$：形状参数，控制窗函数的特性

**特性控制：**
- $\beta = 0$：矩形窗
- $\beta = 5.44$：近似汉宁窗
- $\beta = 8$：近似布莱克曼窗
- $\beta$ 越大，主瓣越宽，旁瓣衰减越大

### 11.4 谱估计方法

#### 11.4.1 经典谱估计

<details>
<summary><strong>经典谱估计方法</strong></summary>

**1. 周期图法：**

**定义：**
$$P_{per}(e^{j\Omega}) = \frac{1}{N} \left|\sum_{n=0}^{N-1} x[n] e^{-j\Omega n}\right|^2$$

**性质：**
- **有偏估计：** $E\{P_{per}(e^{j\Omega})\} = \frac{1}{2\pi} \int_{-\pi}^{\pi} |W(e^{j(\Omega-\theta)})|^2 S_X(e^{j\theta}) d\theta$
- **方差大：** 不随数据长度增加而减小
- **分辨率有限：** 受窗函数主瓣宽度限制

**2. 平均周期图法（Welch方法）：**

**步骤：**
1. 将数据分为 $K$ 段，每段长度为 $L$
2. 对每段加窗并计算周期图
3. 平均所有周期图

**优点：**
- 降低方差
- 允许数据重叠

**3. 自相关法（BT方法）：**

**定义：**
$$P_{BT}(e^{j\Omega}) = \sum_{m=-(M)}^{M} \hat{R}_X[m] w[m] e^{-j\Omega m}$$

其中 $w[m]$ 为窗函数，$M$ 为自相关函数的最大延迟。
</details>

#### 11.4.2 现代谱估计

<details>
<summary><strong>现代谱估计方法</strong></summary>

**1. AR模型法（自回归模型）：**

**模型假设：**
$$x[n] = -\sum_{k=1}^{p} a_k x[n-k] + w[n]$$

其中 $w[n]$ 为白噪声。

**Yule-Walker方程：**
$$\begin{bmatrix}
R_X[0] & R_X[1] & \cdots & R_X[p] \\
R_X[1] & R_X[0] & \cdots & R_X[p-1] \\
\vdots & \vdots & \ddots & \vdots \\
R_X[p] & R_X[p-1] & \cdots & R_X[0]
\end{bmatrix}
\begin{bmatrix}
1 \\ a_1 \\ \vdots \\ a_p
\end{bmatrix}
=
\begin{bmatrix}
\sigma_w^2 \\ 0 \\ \vdots \\ 0
\end{bmatrix}$$

**功率谱密度：**
$$P_{AR}(e^{j\Omega}) = \frac{\sigma_w^2}{|1 + \sum_{k=1}^{p} a_k e^{-j\Omega k}|^2}$$

**2. MA模型法（滑动平均模型）：**

**模型假设：**
$$x[n] = \sum_{k=0}^{q} b_k w[n-k]$$

**功率谱密度：**
$$P_{MA}(e^{j\Omega}) = \sigma_w^2 \left|\sum_{k=0}^{q} b_k e^{-j\Omega k}\right|^2$$

**3. ARMA模型法：**

**模型假设：**
$$x[n] = -\sum_{k=1}^{p} a_k x[n-k] + \sum_{k=0}^{q} b_k w[n-k]$$

**功率谱密度：**
$$P_{ARMA}(e^{j\Omega}) = \sigma_w^2 \frac{|\sum_{k=0}^{q} b_k e^{-j\Omega k}|^2}{|1 + \sum_{k=1}^{p} a_k e^{-j\Omega k}|^2}$$
</details>

#### 11.4.3 高分辨率谱估计

**Prony方法：**

**模型假设：**
$$x[n] = \sum_{k=1}^{p} A_k e^{j(\omega_k n + \phi_k)}$$

**求解步骤：**
1. 构造数据矩阵
2. 求解特征方程得到极点
3. 计算留数得到幅度和相位

**MUSIC算法：**

**基本思想：** 利用信号子空间和噪声子空间的正交性

**算法步骤：**
1. 计算数据协方差矩阵
2. 特征值分解
3. 构造噪声子空间投影矩阵
4. 搜索谱峰得到频率估计

**ESPRIT算法：**

**基本思想：** 利用旋转不变结构

**特点：**
- 无需搜索
- 高分辨率
- 适用于多个正弦信号的频率估计

## 12. 滤波器设计

### 12.1 模拟滤波器设计

#### 12.1.1 巴特沃思滤波器

<details>
<summary><strong>巴特沃思滤波器特性</strong></summary>

**幅度响应：**
$$|H(j\omega)| = \frac{1}{\sqrt{1 + (\omega/\omega_c)^{2n}}}$$

其中：
- $n$：滤波器阶数
- $\omega_c$：截止频率（3dB带宽）

**特性：**
1. **通带：** 单调递减
2. **阻带：** 单调递减
3. **最大平坦：** 在 $\omega = 0$ 处具有最大平坦特性
4. **相位：** 线性相位（近似）

**设计参数：**
- 通带截止频率：$\omega_p$
- 通带最大衰减：$A_p = -20\log_{10}|H(j\omega_p)|$
- 阻带截止频率：$\omega_s$
- 阻带最小衰减：$A_s = -20\log_{10}|H(j\omega_s)|$

**阶数计算：**
$$n \geq \frac{\log_{10}\left(\frac{10^{A_s/10} - 1}{10^{A_p/10} - 1}\right)}{2\log_{10}(\omega_s/\omega_p)}$$

**极点位置：**
$$p_k = \omega_c e^{j(\pi/2 + \pi(2k+n-1)/(2n))}, \quad k = 1, 2, \ldots, n$$
</details>

#### 12.1.2 切比雪夫I型滤波器

<details>
<summary><strong>切比雪夫I型滤波器特性</strong></summary>

**幅度响应：**
$$|H(j\omega)| = \frac{1}{\sqrt{1 + \epsilon^2 C_n^2(\omega/\omega_c)}}$$

其中：
- $\epsilon$：纹波参数
- $C_n(\cdot)$：$n$ 阶切比雪夫多项式

**切比雪夫多项式：**
$$C_n(x) = \begin{cases}
\cos(n\cos^{-1}x), & |x| \leq 1 \\
\cosh(n\cosh^{-1}x), & |x| > 1
\end{cases}$$

**特性：**
1. **通带：** 等纹波特性
2. **阻带：** 单调递减
3. **过渡带：** 比巴特沃思更陡峭
4. **相位：** 非线性

**纹波参数计算：**
$$\epsilon = \sqrt{10^{A_p/10} - 1}$$

**阶数计算：**
$$n \geq \frac{\cosh^{-1}\left(\sqrt{\frac{10^{A_s/10} - 1}{10^{A_p/10} - 1}}\right)}{\cosh^{-1}(\omega_s/\omega_c)}$$

**极点位置：**
$$p_k = \omega_c \sinh\left(\frac{1}{n}\sinh^{-1}\frac{1}{\epsilon}\right) e^{j(\pi/2 + \pi(2k+n-1)/(2n))}$$
</details>

#### 12.1.3 椭圆滤波器

<details>
<summary><strong>椭圆滤波器特性</strong></summary>

**幅度响应：**
$$|H(j\omega)| = \frac{1}{\sqrt{1 + \epsilon^2 R_n^2(\omega/\omega_c, \xi)}}$$

其中：
- $R_n(\cdot, \xi)$：$n$ 阶雅可比椭圆函数
- $\xi$：选择性参数

**特性：**
1. **通带：** 等纹波特性
2. **阻带：** 等纹波特性
3. **过渡带：** 最陡峭
4. **相位：** 非线性

**优点：**
- 过渡带最陡峭
- 阶数最低
- 阻带衰减最大

**缺点：**
- 设计复杂
- 相位非线性严重
- 对元件敏感

**应用：**
- 要求严格的频率选择应用
- 通信系统中的信道选择
</details>

**求解方法：**

### 12.3 滤波器特性参数

#### 12.3.1 幅度特性参数

<details>
<summary><strong>幅度特性指标</strong></summary>

**通带特性：**
- **通带截止频率：** $\Omega_p$
- **通带纹波：** $\delta_p = 20\log_{10}(1 + \epsilon_p)$ dB
- **通带衰减：** $A_p = -20\log_{10}(1 - \delta_p)$ dB

**阻带特性：**
- **阻带截止频率：** $\Omega_s$
- **阻带纹波：** $\delta_s$
- **阻带衰减：** $A_s = -20\log_{10}(\delta_s)$ dB

**过渡带：**
- **过渡带宽度：** $\Delta\Omega = |\Omega_s - \Omega_p|$

**3dB带宽：**
- **定义：** 幅度响应下降3dB的频率范围
- **计算：** $|H(e^{j\Omega_{3dB}})| = |H(e^{j0})|/\sqrt{2}$

**品质因数：**
$$Q = \frac{\Omega_0}{\Delta\Omega}$$

其中 $\Omega_0$ 为中心频率，$\Delta\Omega$ 为3dB带宽。
</details>

#### 12.3.2 相位特性参数

**群延迟：**
$$\tau_g(\Omega) = -\frac{d\angle H(e^{j\Omega})}{d\Omega}$$

**相位延迟：**
$$\tau_p(\Omega) = -\frac{\angle H(e^{j\Omega})}{\Omega}$$

**线性相位条件：**
$$\angle H(e^{j\Omega}) = -\Omega\tau_0 + \phi_0$$

其中 $\tau_0$ 为常数，$\phi_0$ 为常数相位偏移。

**线性相位FIR滤波器：**

| 类型 | 冲激响应 | 相位特性 | 幅度特性 |
|------|----------|----------|----------|
| **I型** | 偶对称，$N$ 奇数 | 线性 | 任意 |
| **II型** | 偶对称，$N$ 偶数 | 线性 | $\Omega = \pi$ 处为零 |
| **III型** | 奇对称，$N$ 奇数 | 线性 | 直流分量为零 |
| **IV型** | 奇对称，$N$ 偶数 | 线性 | $\Omega = 0$ 处为零 |

### 12.4 滤波器实现结构

#### 12.4.1 IIR滤波器结构

<details>
<summary><strong>IIR滤波器实现结构</strong></summary>

**1. 直接型I：**

**差分方程：**
$$y[n] = \sum_{k=0}^{M} b_k x[n-k] - \sum_{k=1}^{N} a_k y[n-k]$$

**结构特点：**
- 分子分母系数直接实现
- 需要 $M+N+1$ 个延迟单元
- 数值稳定性较差

**2. 直接型II（典范型）：**

**结构特点：**
- 分子分母系数共享延迟单元
- 只需要 $\max(M,N)$ 个延迟单元
- 数值稳定性较好

**3. 级联型：**

**系统函数分解：**
$$H(z) = K \prod_{i=1}^{L} H_i(z)$$

其中每个 $H_i(z)$ 为一阶或二阶节。

**优点：**
- 数值稳定性好
- 便于调整增益
- 便于硬件实现

**4. 并联型：**

**系统函数分解：**
$$H(z) = K + \sum_{i=1}^{L} H_i(z)$$

**优点：**
- 各支路独立
- 便于调整
- 适合并行处理
</details>

#### 12.4.2 FIR滤波器结构

**直接型（横截型）：**

**卷积形式：**
$$y[n] = \sum_{k=0}^{M} h[k] x[n-k]$$

**结构特点：**
- 结构简单
- 线性相位易于实现
- 数值稳定

**级联型：**

**系统函数分解：**
$$H(z) = \prod_{i=1}^{L} H_i(z)$$

每个 $H_i(z)$ 为一阶或二阶节。

**频率采样型：**

**系统函数：**
$$H(z) = \frac{1 - z^{-N}}{N} \sum_{k=0}^{N-1} \frac{H[k]}{1 - e^{j2\pi k/N} z^{-1}}$$

**特点：**
- 适合窄带滤波器
- 频域设计，时域实现
- 便于调整频率响应

## 13. 采样定理与调制解调

### 13.1 采样定理

#### 13.1.1 理想采样

<details>
<summary><strong>理想采样过程</strong></summary>

**采样信号：**
$$x_s(t) = x(t) \sum_{n=-\infty}^{\infty} \delta(t - nT_s) = \sum_{n=-\infty}^{\infty} x(nT_s) \delta(t - nT_s)$$

**采样频谱：**
$$X_s(j\omega) = \frac{1}{T_s} \sum_{k=-\infty}^{\infty} X(j(\omega - k\omega_s))$$

其中：
- $T_s$：采样周期
- $\omega_s = 2\pi/T_s$：采样角频率
- $f_s = 1/T_s$：采样频率

**频谱特点：**
- 原信号频谱在 $\omega = 0$ 附近
- 采样后频谱以 $\omega_s$ 为周期重复
- 幅度按 $1/T_s$ 缩放

**混叠现象：**
当采样频率不满足奈奎斯特条件时，相邻周期的频谱会发生重叠。
</details>

#### 13.1.2 奈奎斯特采样定理

<details>
<summary><strong>采样定理内容</strong></summary>

**定理：** 如果信号 $x(t)$ 是带限的，即 $X(j\omega) = 0$ 当 $|\omega| > \omega_m$，并且采样频率 $\omega_s > 2\omega_m$，那么可以从采样信号 $x_s(t)$ 中无失真地恢复原信号 $x(t)$。

**数学表达：**
- **带限条件：** $X(j\omega) = 0$，$\forall |\omega| > \omega_m$
- **采样条件：** $\omega_s > 2\omega_m$ 或 $f_s > 2f_m$
- **奈奎斯特频率：** $f_N = 2f_m$

**混叠频率：**
当 $f_s < 2f_m$ 时，混叠频率为：
$$f_a = |kf_s - f|, \quad k = \pm1, \pm2, \ldots$$

其中 $f$ 为信号频率。

**实际应用中的考虑：**
1. **抗混叠滤波器：** 在采样前滤除高于 $f_s/2$ 的频率分量
2. **过采样：** 采样频率大于奈奎斯特频率
3. **数字下采样：** 在数字域降低采样率
</details>

#### 13.1.3 重建滤波器

**理想重建滤波器：**
$$H_r(j\omega) = \begin{cases}
T_s, & |\omega| < \omega_s/2 \\
0, & |\omega| > \omega_s/2
\end{cases}$$

**重建信号：**
$$x(t) = x_s(t) * h_r(t) = \sum_{n=-\infty}^{\infty} x(nT_s) \frac{\sin(\pi(t-nT_s)/T_s)}{\pi(t-nT_s)/T_s}$$

** sinc 插值函数：**
$$\text{sinc}(t) = \frac{\sin(\pi t)}{\pi t}$$

**实际重建滤波器：**
由于理想滤波器不可实现，实际使用：
- 巴特沃思滤波器
- 切比雪夫滤波器
- 椭圆滤波器

### 13.2 调制解调技术

#### 13.2.1 幅度调制（AM）

<details>
<summary><strong>幅度调制原理</strong></summary>

**标准AM：**

**调制信号：** $m(t)$（消息信号）
**载波信号：** $c(t) = A_c \cos(\omega_c t)$
**AM信号：** $s_{AM}(t) = [A_c + m(t)] \cos(\omega_c t)$

**AM信号频谱：**
$$S_{AM}(\omega) = \pi A_c [\delta(\omega - \omega_c) + \delta(\omega + \omega_c)] + \frac{1}{2}[M(\omega - \omega_c) + M(\omega + \omega_c)]$$

**调制指数：**
$$\mu = \frac{|m(t)|_{max}}{A_c}$$

**功率关系：**
- **载波功率：** $P_c = A_c^2/2$
- **边带功率：** $P_{sb} = \overline{m^2(t)}/2$
- **总功率：** $P_{AM} = P_c + P_{sb}$

**DSB-SC（抑制载波双边带）：**
$$s_{DSB}(t) = m(t) \cos(\omega_c t)$$

**SSB（单边带）：**
$$s_{SSB}(t) = m(t) \cos(\omega_c t) \mp \hat{m}(t) \sin(\omega_c t)$$

其中 $\hat{m}(t)$ 为 $m(t)$ 的希尔伯特变换。
</details>

#### 13.2.2 频率调制（FM）

<details>
<summary><strong>频率调制原理</strong></summary>

**瞬时频率：**
$$f_i(t) = f_c + k_f m(t)$$

**FM信号：**
$$s_{FM}(t) = A_c \cos\left(\omega_c t + 2\pi k_f \int_{0}^{t} m(\tau) d\tau\right)$$

**调频指数：**
$$\beta = \frac{k_f |m(t)|_{max}}{f_m}$$

其中 $f_m$ 为调制信号的最高频率。

**卡森带宽：**
$$B_{FM} = 2(\beta + 1)f_m$$

**功率关系：**
- **平均功率：** $P_{FM} = A_c^2/2$
- **功率分配：** 取决于调频指数 $\beta$

**相位调制（PM）：**
$$s_{PM}(t) = A_c \cos(\omega_c t + k_p m(t))$$

**PM与FM的关系：**
- FM：瞬时频率与调制信号成正比
- PM：瞬时相位与调制信号成正比
- 两者可以通过积分或微分相互转换
</details>

#### 13.2.3 解调技术

<details>
<summary><strong>解调方法</strong></summary>

**1. AM包络检波：**

**原理：** 提取AM信号的包络

**实现：**
- 整流器
- 低通滤波器
- 直流隔离

**适用条件：** 调制指数 $\mu < 1$

**2. 相干解调：**

**原理：** 用相干载波与调制信号相乘

**AM相干解调：**
$$y(t) = s_{AM}(t) \cos(\omega_c t) = [A_c + m(t)] \cos^2(\omega_c t)$$
$$= \frac{A_c}{2} + \frac{m(t)}{2} + \frac{A_c}{2}\cos(2\omega_c t) + \frac{m(t)}{2}\cos(2\omega_c t)$$

通过低通滤波器得到：$\frac{A_c}{2} + \frac{m(t)}{2}$

**FM相干解调：**
- 鉴频器
- 锁相环（PLL）
- 科斯塔斯环

**3. 非相干解调：**

**FM非相干解调：**
- 斜率鉴频器
- 乘积鉴频器
- 锁相环鉴频器

**4. 数字解调：**

**数字AM解调：**
- 平方律检波
- 数字包络检波

**数字FM解调：**
- 数字鉴频器
- 数字锁相环
</details>

### 13.3 复用技术

#### 13.3.1 频分复用（FDM）

<details>
<summary><strong>频分复用原理</strong></summary>

**FDM系统框图：**

1. **调制：** 各路信号调制到不同载频
   $$s_i(t) = m_i(t) \cos(\omega_i t + \phi_i)$$

2. **合路：** 将各路已调信号相加
   $$s(t) = \sum_{i=1}^{N} s_i(t)$$

3. **传输：** 通过信道传输

4. **分路：** 用带通滤波器分离各路信号

5. **解调：** 各路信号独立解调

**频率分配：**
- 各载频间隔：$\Delta f > 2B$
- 其中 $B$ 为各路信号带宽

**应用：**
- 无线电广播
- 电视广播
- 电话系统
- 卫星通信

**优点：**
- 各路独立
- 便于监控
- 适合模拟信号

**缺点：**
- 需要线性功率放大器
- 频率利用率较低
- 容易产生交调失真
</details>

#### 13.3.2 时分复用（TDM）

<details>
<summary><strong>时分复用原理</strong></summary>

**TDM系统框图：**

1. **采样：** 各路信号按不同时隙采样
   $$x_i[n] = x_i(nT_s)$$

2. **合路：** 将各路采样值按时隙排列
   $$s[n] = \{x_1[n], x_2[n], \ldots, x_N[n]\}$$

3. **传输：** 传输复合信号

4. **分路：** 按时间顺序分离各路信号

5. **重建：** 对各路信号进行插值重建

**帧结构：**
- **帧长：** $T_f = NT_s$
- **时隙：** $T_s = T_f/N$
- **同步：** 帧同步码

**应用：**
- 数字电话系统
- PCM系统
- T1/E1载波系统

**优点：**
- 数字信号处理
- 易于再生
- 频率利用率高

**缺点：**
- 需要精确同步
- 时延较大
- 对抖动敏感
</details>

#### 13.3.3 码分复用（CDM）

<details>
<summary><strong>码分复用原理</strong></summary>

**CDMA基本原理：**

**扩频信号：**
$$s_i(t) = m_i(t) c_i(t)$$

其中：
- $m_i(t)$：第 $i$ 路信息信号
- $c_i(t)$：第 $i$ 路扩频码

**扩频码特性：**
- **自相关：** $R_{c_i}(\tau) = \begin{cases} L, & \tau = 0 \\ 1, & \tau \neq 0 \end{cases}$
- **互相关：** $R_{c_i,c_j}(\tau) \approx 0, \quad i \neq j$

**接收端解扩：**
$$y_i(t) = \sum_{j=1}^{N} s_j(t) c_i(t) = m_i(t) + \sum_{j \neq i} m_j(t) c_j(t) c_i(t)$$

**处理增益：**
$$G_p = \frac{B_{ss}}{B_{message}} = \frac{T_{message}}{T_{chip}}$$

其中：
- $B_{ss}$：扩频信号带宽
- $B_{message}$：信息信号带宽
- $T_{message}$：信息码元宽度
- $T_{chip}$：扩频码片宽度

**应用：**
- 移动通信（IS-95, CDMA2000, WCDMA）
- 卫星通信
- 无线局域网
- 全球定位系统（GPS）
</details>

### 13.4 数字调制技术

#### 13.4.1 数字幅度调制

<details>
<summary><strong>ASK调制</strong></summary>

**二进制ASK（2-ASK）：**
$$s_{ASK}(t) = \begin{cases}
A \cos(\omega_c t), & \text{发送"1"} \\
0, & \text{发送"0"}
\end{cases}$$

**多进制ASK（M-ASK）：**
$$s_{ASK}(t) = A_i \cos(\omega_c t), \quad i = 1, 2, \ldots, M$$

**功率谱密度：**
$$S_{ASK}(f) = \frac{A^2}{4} [S_m(f-f_c) + S_m(f+f_c)]$$

其中 $S_m(f)$ 为基带信号功率谱密度。

**误码性能：**
- **相干解调：** $P_e = \frac{1}{2} \text{erfc}\left(\sqrt{\frac{E_b}{2N_0}}\right)$
- **非相干解调：** $P_e = \frac{1}{2} e^{-E_b/2N_0}$

**应用：**
- 光纤通信
- 短波通信
- 数字用户线路（DSL）
</details>

#### 13.4.2 数字频率调制

<details>
<summary><strong>FSK调制</strong></summary>

**二进制FSK（2-FSK）：**
$$s_{FSK}(t) = \begin{cases}
A \cos(\omega_1 t), & \text{发送"1"} \\
A \cos(\omega_2 t), & \text{发送"0"}
\end{cases}$$

**相位连续的FSK：**
$$s_{FSK}(t) = A \cos\left(\omega_c t + 2\pi h \int_{0}^{t} m(\tau) d\tau\right)$$

其中 $h$ 为调制指数。

**功率谱密度：**
- **相位连续：** 频谱较窄
- **相位不连续：** 频谱较宽

**最小频移键控（MSK）：**
- 调制指数 $h = 0.5$
- 相位连续
- 最小频谱占用

**高斯最小频移键控（GMSK）：**
- MSK基础上加高斯滤波
- 更紧凑的频谱
- 应用于GSM系统

**误码性能：**
- **相干解调：** $P_e = \frac{1}{2} \text{erfc}\left(\sqrt{\frac{E_b}{2N_0}}\right)$
- **非相干解调：** $P_e = \frac{1}{2} e^{-E_b/2N_0}$

**应用：**
- 调制解调器
- 寻呼系统
- 移动通信
</details>

#### 13.4.3 数字相位调制

<details>
<summary><strong>PSK调制</strong></summary>

**二进制PSK（2-PSK/BPSK）：**
$$s_{PSK}(t) = A \cos(\omega_c t + \phi_i), \quad \phi_i = \begin{cases}
0, & \text{发送"1"} \\
\pi, & \text{发送"0"}
\end{cases}$$

**差分PSK（DPSK）：**
$$s_{DPSK}(t) = A \cos(\omega_c t + \phi_{i-1} + \Delta\phi_i)$$

其中 $\Delta\phi_i$ 为当前码元的相位变化。

**多进制PSK（M-PSK）：**
$$\phi_i = \frac{2\pi i}{M}, \quad i = 0, 1, \ldots, M-1$$

**四进制PSK（QPSK）：**
$$\phi_i = \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$$

**正交振幅调制（QAM）：**
$$s_{QAM}(t) = A_i \cos(\omega_c t) + B_i \sin(\omega_c t)$$

**误码性能：**
- **BPSK：** $P_e = \frac{1}{2} \text{erfc}\left(\sqrt{\frac{E_b}{N_0}}\right)$
- **QPSK：** $P_e = \frac{1}{2} \text{erfc}\left(\sqrt{\frac{E_b}{N_0}}\right)$
- **M-PSK：** 随M增加性能下降

**应用：**
- 卫星通信
- 数字电视
- 调制解调器
- 移动通信
</details>

## 14. 时频分析

### 14.1 短时傅里叶变换（STFT）

#### 14.1.1 STFT的定义

<details>
<summary><strong>短时傅里叶变换</strong></summary>

**连续时间STFT：**
$$STFT_x(t, f) = \int_{-\infty}^{\infty} x(\tau) w^*(\tau - t) e^{-j2\pi f\tau} d\tau$$

其中 $w(t)$ 为窗函数。

**离散时间STFT：**
$$STFT_x[n, k] = \sum_{m=-\infty}^{\infty} x[m] w^*[m-n] e^{-j2\pi km/N}$$

**物理意义：**
- $t$：时间变量
- $f$：频率变量
- $w(t)$：窗函数，用于局部化时间

**窗函数选择：**
- **汉宁窗：** $w(t) = 0.5 - 0.5\cos(2\pi t/T)$
- **汉明窗：** $w(t) = 0.54 - 0.46\cos(2\pi t/T)$
- **高斯窗：** $w(t) = e^{-\alpha t^2}$

**时频分辨率：**
- **时间分辨率：** 由窗长 $T$ 决定
- **频率分辨率：** 由窗长的倒数决定
- **不确定性原理：** $\Delta t \cdot \Delta f \geq 1/(4\pi)$
</details>

#### 14.1.2 STFT的性质

**线性性：**
$$STFT_{ax+by}(t, f) = a \cdot STFT_x(t, f) + b \cdot STFT_y(t, f)$$

**时移性：**
$$STFT_{x(t-t_0)}(t, f) = STFT_x(t-t_0, f) e^{-j2\pi f t_0}$$

**频移性：**
$$STFT_{x(t)e^{j2\pi f_0 t}}(t, f) = STFT_x(t, f-f_0)$$

**调制性：**
$$STFT_{x(t)w(t)}(t, f) = STFT_x(t, f) * STFT_w(t, f)$$

#### 14.1.3 STFT的实现

<details>
<summary><strong>STFT计算方法</strong></summary>

**重叠相加法：**

**步骤：**
1. 将信号分为重叠段
2. 对每段加窗
3. 计算每段的FFT
4. 拼接结果

**参数选择：**
- **窗长：** $N$
- **重叠：** $L$
- **步长：** $R = N - L$
- **FFT长度：** $M \geq N$

**重叠保留法：**

**步骤：**
1. 选择窗长 $N$ 和步长 $R$
2. 从信号中取长度为 $N$ 的段
3. 加窗并计算FFT
4. 保留中间 $R$ 点
5. 移动窗口

**优点：**
- 计算效率高
- 适合实时处理
- 重叠度可调

**应用：**
- 语音信号分析
- 音乐信号处理
- 雷达信号处理
- 生物医学信号分析
</details>

### 14.2 小波变换

#### 14.2.1 连续小波变换（CWT）

<details>
<summary><strong>连续小波变换定义</strong></summary>

**连续小波变换：**
$$CWT_x(a, b) = \frac{1}{\sqrt{a}} \int_{-\infty}^{\infty} x(t) \psi^*\left(\frac{t-b}{a}\right) dt$$

其中：
- $\psi(t)$：母小波
- $a$：尺度参数（$a > 0$）
- $b$：平移参数

**尺度参数的意义：**
- $a > 1$：小波拉伸，对应低频
- $a < 1$：小波压缩，对应高频
- $a$ 越小，时间分辨率越高，频率分辨率越低

**平移参数的意义：**
- $b$ 控制小波在时间轴上的位置
- 用于分析信号在不同时间的位置特性

**母小波条件：**
1. **有限能量：** $\int_{-\infty}^{\infty} |\psi(t)|^2 dt < \infty$
2. **零均值：** $\int_{-\infty}^{\infty} \psi(t) dt = 0$
3. ** admissibility 条件：** $C_\psi = \int_{0}^{\infty} \frac{|\Psi(\omega)|^2}{\omega} d\omega < \infty$

其中 $\Psi(\omega)$ 为 $\psi(t)$ 的傅里叶变换。
</details>

#### 14.2.2 常见小波函数

<details>
<summary><strong>常用小波函数</strong></summary>

**1. 墨西哥帽小波（Mexican Hat）：**
$$\psi(t) = \frac{2}{\sqrt{3}\pi^{1/4}} (1-t^2) e^{-t^2/2}$$

**特性：**
- 高斯函数的二阶导数
- 紧支撑
- 对称性

**2. Morlet小波：**
$$\psi(t) = \pi^{-1/4} e^{j\omega_0 t} e^{-t^2/2}$$

**特性：**
- 复数小波
- 适合时频分析
- 频率分辨率高

**3. Daubechies小波：**
$$\psi(t) = \sum_{k} h_k \sqrt{2} \psi(2t-k)$$

**特性：**
- 紧支撑
- 正交性
- 不同消失矩阶数

**4. Biorthogonal小波：**
- 双正交小波
- 对称性
- 线性相位

**5. Coiflets小波：**
- 紧支撑
- 高消失矩
- 近正交性

**选择原则：**
- **信号特性：** 连续/突变、实数/复数
- **分析要求：** 时间/频率分辨率
- **应用场景：** 压缩/去噪/特征提取
</details>

#### 14.2.3 离散小波变换（DWT）

<details>
<summary><strong>离散小波变换</strong></summary>

**二进制小波变换：**
$$DWT_x(j, k) = \frac{1}{\sqrt{2^j}} \int_{-\infty}^{\infty} x(t) \psi^*\left(\frac{t-2^j k}{2^j}\right) dt$$

**Mallat算法：**

**分解过程：**
1. **低通滤波：** $c_{j+1}[k] = \sum_n h[n-2k] c_j[n]$
2. **高通滤波：** $d_{j+1}[k] = \sum_n g[n-2k] c_j[n]$

其中：
- $c_j[k]$：尺度系数（近似系数）
- $d_j[k]$：小波系数（细节系数）
- $h[n]$：低通滤波器
- $g[n]$：高通滤波器

**重构过程：**
$$c_j[n] = \sum_k h[n-2k] c_{j+1}[k] + \sum_k g[n-2k] d_{j+1}[k]$$

**滤波器关系：**
$$g[n] = (-1)^n h[1-n]$$

**多分辨率分析：**
- **尺度函数：** $\phi(t)$
- **小波函数：** $\psi(t)$
- **尺度关系：** $\phi(t) = \sum_n h[n] \sqrt{2} \phi(2t-n)$
- **小波关系：** $\psi(t) = \sum_n g[n] \sqrt{2} \phi(2t-n)$
</details>

### 14.3 小波包分解

#### 14.3.1 小波包定义

<details>
<summary><strong>小波包概念</strong></summary>

**小波包函数：**
$$W_{2n}(t) = \sum_k h[k] \sqrt{2} W_n(2t-k)$$
$$W_{2n+1}(t) = \sum_k g[k] \sqrt{2} W_n(2t-k)$$

其中 $W_0(t) = \phi(t)$ 为尺度函数，$W_1(t) = \psi(t)$ 为小波函数。

**小波包树结构：**
```
         S
        / \
      A1   D1
     / \   / \
   A2  D2 A2  D2
   ... ... ... ...
```

其中：
- $S$：原始信号
- $A$：近似分量
- $D$：细节分量

**频带划分：**
- **第0层：** 整个频带 $[0, f_s/2]$
- **第1层：** $[0, f_s/4]$, $[f_s/4, f_s/2]$
- **第2层：** $[0, f_s/8]$, $[f_s/8, f_s/4]$, $[f_s/4, 3f_s/8]$, $[3f_s/8, f_s/2]$
- ...
</details>

#### 14.3.2 最优小波包基选择

<details>
<summary><strong>最优基选择算法</strong></summary>

**代价函数：**

**1. 熵代价函数：**
$$E(x) = -\sum_i p_i \log p_i$$

其中 $p_i = |x_i|^2 / \sum_j |x_j|^2$

**2. 对数能量代价函数：**
$$E(x) = \sum_i \log(|x_i|^2)$$

**3. $l^p$ 范数代价函数：**
$$E(x) = \left(\sum_i |x_i|^p\right)^{1/p}$$

**最优基选择步骤：**

1. **计算所有节点的代价**
2. **从叶子节点开始**
3. **比较节点代价与子节点代价之和**
4. **选择代价较小的方案**
5. **向上递归**

**应用：**
- 信号压缩
- 特征提取
- 噪声抑制
- 模式识别
</details>

## 15. 系统辨识与参数估计

### 15.1 系统辨识基础

#### 15.1.1 系统辨识的概念

<details>
<summary><strong>系统辨识定义</strong></summary>

**系统辨识：** 根据系统的输入输出数据，建立系统数学模型的过程。

**数学描述：**
给定输入输出数据 $\{u(k), y(k)\}_{k=1}^N$，寻找模型 $\mathcal{M}$ 使得：
$$\hat{y}(k) = \mathcal{M}(u(k), \theta)$$

其中 $\theta$ 为模型参数。

**系统辨识三要素：**
1. **数据：** 输入输出观测数据
2. **模型类：** 候选模型集合
3. **准则：** 参数估计准则

**辨识步骤：**
1. **实验设计：** 确定输入信号、采样率、实验长度
2. **模型选择：** 选择模型结构和阶数
3. **参数估计：** 估计模型参数
4. **模型验证：** 检验模型有效性
5. **模型应用：** 用于预测、控制等

**应用领域：**
- 控制系统设计
- 信号处理
- 经济建模
- 生物医学
- 故障诊断
</details>

#### 15.1.2 常见系统模型

<details>
<summary><strong>系统模型类型</strong></summary>

**1. 线性时不变模型：**

**差分方程模型：**
$$y(k) + a_1 y(k-1) + \cdots + a_n y(k-n) = b_1 u(k-1) + \cdots + b_m u(k-m)$$

**状态空间模型：**
$$\begin{cases}
x(k+1) = Ax(k) + Bu(k) \\
y(k) = Cx(k) + Du(k)
\end{cases}$$

**传递函数模型：**
$$G(z) = \frac{B(z)}{A(z)} = \frac{b_1 z^{-1} + \cdots + b_m z^{-m}}{1 + a_1 z^{-1} + \cdots + a_n z^{-n}}$$

**2. 非线性模型：**

**Volterra模型：**
$$y(k) = \sum_{n=1}^{\infty} \sum_{i_1=1}^{\infty} \cdots \sum_{i_n=1}^{\infty} h_n(i_1, \ldots, i_n) u(k-i_1) \cdots u(k-i_n)$$

**多项式模型：**
$$y(k) = \theta_0 + \theta_1 u(k) + \theta_2 u^2(k) + \cdots + \theta_p u^p(k)$$

**3. 随机模型：**

**AR模型：**
$$y(k) = -a_1 y(k-1) - \cdots - a_n y(k-n) + w(k)$$

**ARMA模型：**
$$y(k) + a_1 y(k-1) + \cdots + a_n y(k-n) = w(k) + c_1 w(k-1) + \cdots + c_m w(k-m)$$

**ARX模型：**
$$y(k) + a_1 y(k-1) + \cdots + a_n y(k-n) = b_1 u(k-1) + \cdots + b_m u(k-m) + w(k)$$
</details>

### 15.2 最小二乘法

#### 15.2.1 线性最小二乘

<details>
<summary><strong>线性最小二乘原理</strong></summary>

**问题描述：**
给定数据 $\{x_i, y_i\}_{i=1}^N$，寻找参数 $\theta$ 使得：
$$\min_\theta \sum_{i=1}^N [y_i - \phi^T(x_i)\theta]^2$$

其中 $\phi(x_i)$ 为回归向量。

**矩阵形式：**
$$\min_\theta \|Y - \Phi\theta\|^2$$

其中：
- $Y = [y_1, y_2, \ldots, y_N]^T$
- $\Phi = [\phi(x_1), \phi(x_2), \ldots, \phi(x_N)]^T$

**正规方程：**
$$\Phi^T \Phi \theta = \Phi^T Y$$

**最小二乘解：**
$$\hat{\theta}_{LS} = (\Phi^T \Phi)^{-1} \Phi^T Y$$

**几何意义：**
$\hat{\theta}_{LS}$ 使得残差向量 $Y - \Phi\theta$ 与回归子空间正交。

**加权最小二乘：**
$$\min_\theta (Y - \Phi\theta)^T W (Y - \Phi\theta)$$

解为：
$$\hat{\theta}_{WLS} = (\Phi^T W \Phi)^{-1} \Phi^T W Y$$

其中$W$ 为权重矩阵。
</details>

#### 15.2.2 递推最小二乘

<details>
<summary><strong>递推最小二乘算法</strong></summary>

**递推公式：**
$$\hat{\theta}(k) = \hat{\theta}(k-1) + K(k)[y(k) - \phi^T(k)\hat{\theta}(k-1)]$$

其中：
- $K(k) = P(k-1)\phi(k)[\phi^T(k)P(k-1)\phi(k) + 1]^{-1}$
- $P(k) = [I - K(k)\phi^T(k)]P(k-1)$

**初始化：**
- $\hat{\theta}(0) = 0$ 或先验估计
- $P(0) = \alpha I$，$\alpha$ 为大常数

**遗忘因子最小二乘：**
$$P(k) = \frac{1}{\lambda}[I - K(k)\phi^T(k)]P(k-1)$$

其中 $\lambda$ 为遗忘因子（$0 < \lambda < 1$）。

**优点：**
- 在线更新参数
- 内存需求小
- 适合实时应用

**应用：**
- 自适应控制
- 系统辨识
- 参数跟踪
- 信号预测
</details>

### 15.3 极大似然估计

#### 15.3.1 极大似然原理

<details>
<summary><strong>极大似然估计</strong></summary>

**似然函数：**
$$L(\theta) = \prod_{i=1}^N f(y_i; \theta)$$

其中 $f(y_i; \theta)$ 为概率密度函数。

**对数似然函数：**
$$l(\theta) = \log L(\theta) = \sum_{i=1}^N \log f(y_i; \theta)$$

**极大似然估计：**
$$\hat{\theta}_{ML} = \arg\max_\theta l(\theta)$$

**性质：**
1. **一致性：** $\hat{\theta}_{ML} \xrightarrow{P} \theta_0$
2. **渐近正态性：** $\sqrt{N}(\hat{\theta}_{ML} - \theta_0) \xrightarrow{d} \mathcal{N}(0, I^{-1}(\theta_0))$
3. **渐近有效性：** 达到Cramér-Rao下界

其中 $I(\theta)$ 为Fisher信息矩阵。

**高斯噪声情况：**
假设 $y(k) = \phi^T(k)\theta + w(k)$，$w(k) \sim \mathcal{N}(0, \sigma^2)$

**对数似然函数：**
$$l(\theta, \sigma^2) = -\frac{N}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_{k=1}^N [y(k) - \phi^T(k)\theta]^2$$

**ML估计：**
$$\hat{\theta}_{ML} = (\Phi^T \Phi)^{-1} \Phi^T Y$$
$$\hat{\sigma}^2_{ML} = \frac{1}{N} \sum_{k=1}^N [y(k) - \phi^T(k)\hat{\theta}_{ML}]^2$$
</details>

### 15.4 卡尔曼滤波

#### 15.4.1 线性卡尔曼滤波

<details>
<summary><strong>卡尔曼滤波算法</strong></summary>

**系统模型：**
$$\begin{cases}
x(k+1) = F(k)x(k) + w(k) \\
y(k) = H(k)x(k) + v(k)
\end{cases}$$

其中：
- $x(k)$：状态向量
- $y(k)$：观测向量
- $w(k)$：过程噪声，$w(k) \sim \mathcal{N}(0, Q(k))$
- $v(k)$：观测噪声，$v(k) \sim \mathcal{N}(0, R(k))$

**卡尔曼滤波方程：**

**预测步：**
- 状态预测：$\hat{x}(k|k-1) = F(k-1)\hat{x}(k-1|k-1)$
- 协方差预测：$P(k|k-1) = F(k-1)P(k-1|k-1)F^T(k-1) + Q(k-1)$

**更新步：**
- 新息：$\tilde{y}(k) = y(k) - H(k)\hat{x}(k|k-1)$
- 新息协方差：$S(k) = H(k)P(k|k-1)H^T(k) + R(k)$
- 卡尔曼增益：$K(k) = P(k|k-1)H^T(k)S^{-1}(k)$
- 状态更新：$\hat{x}(k|k) = \hat{x}(k|k-1) + K(k)\tilde{y}(k)$
- 协方差更新：$P(k|k) = [I - K(k)H(k)]P(k|k-1)$

**初始条件：**
- $\hat{x}(0|0) = x_0$
- $P(0|0) = P_0$
</details>

#### 15.4.2 扩展卡尔曼滤波

**非线性系统模型：**
$$\begin{cases}
x(k+1) = f[x(k), u(k)] + w(k) \\
y(k) = h[x(k), v(k)] + v(k)
\end{cases}$$

**线性化：**
- $F(k) = \frac{\partial f}{\partial x}\bigg|_{x = \hat{x}(k|k)}$
- $H(k) = \frac{\partial h}{\partial x}\bigg|_{x = \hat{x}(k|k-1)}$

**EKF算法：**
1. 使用非线性函数进行状态预测
2. 使用雅可比矩阵进行协方差预测
3. 标准的卡尔曼更新

**应用：**
- 目标跟踪
- 导航系统
- 机器人定位
- 金融建模

### 15.5 参数估计的统计性质

#### 15.5.1 估计量的性质

<details>
<summary><strong>估计量性质</strong></summary>

**1. 无偏性：**
$$E\{\hat{\theta}\} = \theta_0$$

**2. 渐近无偏性：**
$$\lim_{N \to \infty} E\{\hat{\theta}\} = \theta_0$$

**3. 一致性：**
$$\hat{\theta} \xrightarrow{P} \theta_0$$

**4. 渐近正态性：**
$$\sqrt{N}(\hat{\theta} - \theta_0) \xrightarrow{d} \mathcal{N}(0, \Sigma)$$

**5. 有效性：**
估计量 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ 有效，如果：
$$\text{Var}(\hat{\theta}_1) < \text{Var}(\hat{\theta}_2)$$

**Cramér-Rao下界：**
对于无偏估计量 $\hat{\theta}$：
$$\text{Var}(\hat{\theta}) \geq \frac{1}{I(\theta)}$$

其中 $I(\theta)$ 为Fisher信息量：
$$I(\theta) = E\left[\left(\frac{\partial \log f(y;\theta)}{\partial \theta}\right)^2\right]$$

**渐近Cramér-Rao下界：**
$$\lim_{N \to \infty} N \cdot \text{Var}(\hat{\theta}) \geq I^{-1}(\theta_0)$$
</details>

#### 15.5.2 模型选择准则

<details>
<summary><strong>模型选择准则</strong></summary>

**1. 赤池信息准则（AIC）：**
$$AIC = -2\log L(\hat{\theta}) + 2k$$

其中：
- $L(\hat{\theta})$：极大似然函数值
- $k$：模型参数个数

**2. 贝叶斯信息准则（BIC）：**
$$BIC = -2\log L(\hat{\theta}) + k\log N$$

**3. 预测误差准则（PEC）：**
$$PEC = \frac{1}{N} \sum_{k=1}^N [y(k) - \hat{y}(k)]^2$$

**4. 最终预测误差准则（FPE）：**
$$FPE = \frac{N + k}{N - k} \cdot \frac{1}{N} \sum_{k=1}^N [y(k) - \hat{y}(k)]^2$$

**准则比较：**
- **AIC：** 倾向于选择复杂模型
- **BIC：** 倾向于选择简单模型
- **FPE：** 平衡偏差和方差

**交叉验证：**
- **k折交叉验证**
- **留一法交叉验证**
- **时间序列交叉验证**
</details>
