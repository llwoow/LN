## 1. 绪论

### 1.1 电力电子技术概述

电力电子技术是使用电力电子器件对电能进行变换和控制的技术，被誉为"强电与弱电的桥梁"。

**主要特点：**
- 处理功率大（从几瓦到几千兆瓦）
- 工作在开关状态
- 与多学科密切相关
- 实验性强

**发展历程：**
- 1957年：晶闸管发明，标志着电力电子技术开始
- 20世纪70年代：功率晶体管(GTR)、功率MOSFET问世
- 20世纪80年代：IGBT出现
- 近年来：SiC、GaN宽禁带半导体器件应用

### 1.2 应用领域

| 应用领域 | 具体应用 |
|---------|---------|
| 工业领域 | 变频调速、电解电镀、电弧炉 |
| 交通领域 | 电动汽车、轨道交通、船舶推进 |
| 新能源 | 太阳能发电、风力发电、储能系统 |
| 电力系统 | 柔性直流输电、电能质量治理 |
| 消费电子 | 开关电源、LED照明、变频空调 |

### 1.3 四类基本电能变换

| 变换类型 | 英文名称 | 主要功能 | 典型应用 |
|---------|---------|---------|---------|
| AC-DC | 整流 | 交流→直流 | 开关电源、充电器 |
| DC-DC | 直流变换 | 直流电压变换 | 电源管理、电动汽车 |
| DC-AC | 逆变 | 直流→交流 | 变频器、UPS、光伏逆变 |
| AC-AC | 交流变换 | 交流参数调节 | 交流调压、变频器 |

## 2. 电力电子器件

### 2.1 器件分类

根据可控性分类：

| 器件类型 | 可控性 | 典型器件 | 特点 |
|---------|-------|---------|------|
| 不可控器件 | 不可控 | 电力二极管 | 单向导电，自动导通 |
| 半控型器件 | 半控 | 晶闸管(SCR) | 可控导通，不可控关断 |
| 全控型器件 | 全控 | GTO、GTR、MOSFET、IGBT | 可控导通和关断 |

### 2.2 电力二极管

#### 2.2.1 基本特性

**工作原理：** 基于PN结的单向导电特性

**主要参数：**
- 正向平均电流 $I_F(AV)$
- 正向压降 $U_F$
- 反向重复峰值电压 $U_{RRM}$
- 反向恢复时间 $t_{rr}$

#### 2.2.2 重要公式

正向平均电流与有效值的关系：
$$I_{rms} = 1.57 \times I_F(AV)$$

### 2.3 晶闸管(SCR)

#### 2.3.1 基本特性

**结构：** 四层三端结构(PNPN)

**工作条件：**
- 承受正向阳极电压
- 门极有触发脉冲

**主要参数：**
- 断态重复峰值电压 $U_{DRM}$
- 反向重复峰值电压 $U_{RRM}$
- 通态平均电流 $I_T(AV)$
- 维持电流 $I_H$
- 擎住电流 $I_L$

#### 2.3.2 重要关系

擎住电流与维持电流的关系：
$$I_L = (2-4) \times I_H$$

### 2.4 全控型器件对比

| 器件 | 驱动方式 | 开关频率 | 电压/电流等级 | 典型应用 |
|-----|---------|---------|-------------|---------|
| GTO | 电流驱动 | 低 | 最高 | 高压大电流换流 |
| GTR | 电流驱动 | 中 | 中 | 直流调速系统 |
| MOSFET | 电压驱动 | 最高 | 最小 | 高频开关电源 |
| IGBT | 电压驱动 | 第2高 | 第3高 | 逆变器、电源 |

#### 2.4.1 MOSFET特性

**主要参数：**
- 导通电阻 $R_{DS(on)}$（正温度系数）
- 栅极总电荷 $Q_G$
- 米勒电容 $C_{gd}$

**安全工作区(SOA)边界：**
- $R_{DS(on)}$限制线
- 脉冲电流限制 $I_{DM}$
- 最大功率线
- 热不稳定边界
- 击穿电压限制

#### 2.4.2 IGBT特性

**主要参数：**
- 集射饱和压降 $V_{CE(sat)}$
- 开关能量 $E_{on}$、$E_{off}$
- 短路耐受时间 $t_{SC}$

### 2.5 器件选择原则

<details>
<summary>点击展开器件选择流程</summary>

**选择步骤：**

1. **电气应力分析**
   - 确定工作电压和电流
   - 考虑浪涌和短路情况
   - 选择额定值，留有2-3倍安全裕度

2. **频率要求评估**
   - 高频应用选择开关速度快的器件
   - 低频应用可选择开关速度一般的器件

3. **驱动功率考虑**
   - 电压驱动器件驱动功率小
   - 电流驱动器件驱动功率大

4. **成本与可靠性**
   - 在满足性能要求前提下选择性价比高的器件
   - 考虑器件的可靠性和寿命

</details>

## 3. 整流电路

### 3.1 整流电路分类

| 分类方式 | 类型 | 器件 | 特点 |
|---------|------|------|------|
| 按器件 | 不可控整流 | 二极管 | 自动导通 |
| | 半控整流 | 二极管+晶闸管 | 部分可控 |
| | 全控整流 | 晶闸管 | 完全可控 |
| 按相数 | 单相整流 | 1相输入 | 功率较小 |
| | 三相整流 | 3相输入 | 功率较大，纹波小 |

### 3.2 单相半波可控整流电路

#### 3.2.1 电路拓扑

```
    u2
     ~
    ┌─┐
    │ │  T
    └─┘
     │
    ┌─┬─┐
    │ │ │  SCR
    └─┴─┘
     │
    ┌─┬─┐
    │ │ │  R
    └─┴─┘
     │
    ─┴─
```

#### 3.2.2 工作原理

<details>
<summary>点击展开详细工作原理分析</summary>

**工作过程：**

1. **α ≤ ωt < π期间：**
   - SCR承受正向电压
   - 有触发脉冲时，SCR导通
   - 负载获得电压：$u_d = \sqrt{2}U_2\sin(\omega t)$

2. **π ≤ ωt < 2π期间：**
   - SCR承受反向电压
   - SCR关断
   - 负载电压为零

3. **重复周期：**
   - 下一个周期重复上述过程

</details>

#### 3.2.3 重要公式推导

<details>
<summary>点击展开单相半波可控整流公式推导</summary>

**输出电压平均值：**

对于电阻负载，输出电压平均值为：
$$U_d = \frac{1}{2\pi} \int_{\alpha}^{\pi} \sqrt{2}U_2 \sin(\omega t) d(\omega t)$$

$$U_d = \frac{\sqrt{2}U_2}{2\pi} \int_{\alpha}^{\pi} \sin(\omega t) d(\omega t)$$

$$U_d = \frac{\sqrt{2}U_2}{2\pi} [-\cos(\omega t)]_{\alpha}^{\pi}$$

$$U_d = \frac{\sqrt{2}U_2}{2\pi} (-\cos\pi + \cos\alpha)$$

$$U_d = \frac{\sqrt{2}U_2}{2\pi} (1 + \cos\alpha)$$

$$U_d = \frac{\sqrt{2}U_2}{\pi} \cdot \frac{1 + \cos\alpha}{2}$$

**特殊情况：**
- 当 α = 0° 时：$U_d = \frac{\sqrt{2}U_2}{\pi} \approx 0.45U_2$
- 当 α = 180° 时：$U_d = 0$

**输出电流平均值：**
$$I_d = \frac{U_d}{R}$$

</details>

#### 3.3.2 输出电压公式

<details>
<summary>点击展开单相桥式全控整流公式推导</summary>

**对于电阻负载：**

$$U_d = \frac{2\sqrt{2}U_2}{\pi} \cdot \frac{1 + \cos\alpha}{2}$$

$$U_d = 0.9U_2 \cdot \frac{1 + \cos\alpha}{2}$$

**对于电感性负载：**

$$U_d = 0.9U_2 \cos\alpha \quad (\alpha \leq 90°)$$

当 α > 90° 时，电路进入逆变状态。

</details>

### 3.4 三相桥式全控整流电路

#### 3.4.1 电路特点

- 由6个晶闸管组成
- 输出电压脉动频率是工频的6倍
- 变压器利用率高
- 适用于大功率场合

#### 3.4.2 重要公式

<details>
<summary>点击展开三相桥式整流公式推导</summary>

**输出电压平均值：**

对于电感性负载：
$$U_d = \frac{3\sqrt{2}U_2}{\pi} \cos\alpha \quad (\alpha \leq 30°)$$

$$U_d = 2.34U_2 \cos\alpha$$

**当 α > 30° 时：**
- 电路进入逆变状态
- 输出电压平均值为负值
- 直流侧能量反馈回交流电网

**换相重叠角 μ：**
$$\cos\alpha - \cos(\alpha + \mu) = \frac{2X_B I_d}{\sqrt{2}U_2}$$

其中 $X_B$ 为变压器漏抗。

</details>

### 3.5 有源逆变

#### 3.5.1 有源逆变条件

<details>
<summary>点击展开有源逆变条件分析</summary>

**必要条件：**

1. **触发延迟角条件**
   $$\alpha > 90°$$

2. **直流侧条件**
   - 直流侧必须有直流电动势源
   - 电动势极性要保证电流从直流侧流向交流侧

3. **交流侧条件**
   - 交流侧必须与电网连接
   - 电网电压要能维持电流流动

**有源逆变的特点：**
- 直流侧功率流向交流侧
- 电网吸收功率
- 必须严格控制最小逆变角 βmin

</details>

#### 3.5.2 最小逆变角

最小逆变角 βmin 由以下因素决定：
$$\beta_{min} = \gamma + \delta + \theta$$

其中：
- γ：换相重叠角
- δ：晶闸管关断时间对应的角度
- θ：安全裕度角

### 3.6 谐波分析与功率因数

#### 3.6.1 总谐波失真(THD)

<details>
<summary>点击展开THD计算公式</summary>

**THD定义：**
$$THD = \frac{\sqrt{\sum_{n=2}^{\infty} V_n^2}}{V_1} \times 100\%$$

其中：
- $V_1$：基波电压有效值
- $V_n$：第n次谐波电压有效值

**功率因数：**
$$PF = \cos\phi \times \frac{1}{\sqrt{1 + THD^2}}$$

其中 $\cos\phi$ 为位移因子。

</details>

#### 3.6.2 谐波抑制方法

| 抑制方法 | 原理 | 适用场合 |
|---------|------|---------|
| 无源滤波器 | 提供低阻抗通道 | 主要谐波频次 |
| 有源滤波器(APF) | 注入补偿电流 | 动态补偿 |
| PFC技术 | 改善输入电流波形 | 整流前端 |

### 4.2 非隔离型DC-DC变换器

#### 4.2.1 降压斩波电路(Buck电路)

##### 电路拓扑

```
    Vi
     +
     |
    ┌─┐
    │ │  Q
    └─┘
     │
    ┌─┬─┐
    │ │ │  L
    └─┴─┘
     │
    ┌─┬─┐
    │ │ │  C
    └─┴─┘
     │
    VT1    D
    ┌─┐  ┌─┐
    │ │  │ │
    └─┘  └─┘
     │    │
    ┌─┬─┬─┬─┐
    │ │ │ │ │  R
    └─┴─┴─┴─┘
     │
    Vo
     -
```

##### 工作原理

<details>
<summary>点击展开Buck电路工作原理</summary>

**开关导通期间 (0 ≤ t < DT)：**
- 开关管Q导通，二极管D截止
- 输入电压加在电感L两端
- 电感电流线性上升：$i_L(t) = \frac{V_i - V_o}{L}t + I_L(0)$
- 电感储能

**开关关断期间 (DT ≤ t < T)：**
- 开关管Q截止，二极管D导通
- 电感电压为 -Vo
- 电感电流线性下降：$i_L(t) = -\frac{V_o}{L}(t - DT) + I_L(DT)$
- 电感释放能量

</details>

##### 重要公式推导

<details>
<summary>点击展开伏秒平衡原理推导Buck电路公式</summary>

**伏秒平衡原理：**

对于工作在稳态的电感，在一个开关周期内，电感电压的积分为零：
$$\int_0^T v_L(t) dt = 0$$

**开关导通期间：**
$$v_L = V_i - V_o$$

**开关关断期间：**
$$v_L = -V_o$$

**伏秒平衡方程：**
$$(V_i - V_o) \cdot DT = V_o \cdot (T - DT)$$

**整理得：**
$$V_i \cdot DT = V_o \cdot T$$

$$V_o = V_i \cdot \frac{DT}{T} = V_i \cdot D$$

其中 $D = \frac{T_{on}}{T}$ 为占空比。

**临界电感：**
当电路刚好工作在CCM和DCM边界时：
$$L_{critical} = \frac{V_o(1-D)}{2f_s I_o}$$

其中 $f_s = \frac{1}{T}$ 为开关频率。

</details>

##### 波形分析

**电感电流波形：**
- CCM模式：电感电流连续，始终大于零
- DCM模式：电感电流断续，有一段时间为零
- BCM模式：电感电流刚好在开关周期结束时降到零

**输出电压纹波：**
$$\Delta V_o = \frac{\Delta I_L}{8f_s C}$$

其中 $\Delta I_L$ 为电感电流纹波。

##### 公式推导

<details>
<summary>点击展开Boost电路公式推导</summary>

**开关导通期间 (0 ≤ t < DT)：**
- 开关管VT1导通，二极管D截止
- 电感电压：$v_L = V_i$
- 电感电流：$i_L(t) = \frac{V_i}{L}t + I_L(0)$

**开关关断期间 (DT ≤ t < T)：**
- 开关管VT1截止，二极管D导通
- 电感电压：$v_L = V_i - V_o$
- 电感电流：$i_L(t) = \frac{V_i - V_o}{L}(t - DT) + I_L(DT)$

**伏秒平衡：**
$$V_i \cdot DT = (V_o - V_i) \cdot (T - DT)$$

**整理得：**
$$V_o = V_i \cdot \frac{T}{T - DT} = \frac{V_i}{1-D}$$

**临界电感：**
$$L_{critical} = \frac{V_i D(1-D)^2}{2f_s I_o}$$

</details>

- 电感电流：$i_L(t) = \frac{V_i}{L}t + I_L(0)$

**临界电感：**
$$L_{critical} = \frac{V_o D(1-D)}{2f_s I_o}$$

</details>

##### 工作原理

<details>
<summary>点击展开反激变换器工作原理</summary>

**开关导通期间 (0 ≤ t < DT)：**
- 开关管VT1导通
- 变压器一次侧储能：$W = \frac{1}{2}L_1 I_{L1}^2$
- 二次侧感应电压为负，二极管D截止
- 负载由电容C供电

**开关关断期间 (DT ≤ t < T)：**
- 开关管VT1截止
- 变压器一次侧电流为零
- 二次侧感应电压为正，二极管D导通
- 变压器释放能量向负载供电

</details>

##### 公式推导

<details>
<summary>点击展开反激变换器公式推导</summary>

**变压器磁通平衡：**

**开关导通期间：**
- 一次侧电压：$V_i$
- 磁通变化：$\Delta \Phi = \frac{V_i}{N_1} DT$

**开关关断期间：**
- 二次侧电压：$V_o$
- 磁通变化：$\Delta \Phi = \frac{V_o}{N_2} (T - DT)$

**磁通平衡条件：**
$$\frac{V_i}{N_1} DT = \frac{V_o}{N_2} (T - DT)$$

**整理得：**
$$V_o = \frac{N_2}{N_1} \cdot V_i \cdot \frac{D}{1-D}$$

其中 $\frac{N_2}{N_1}$ 为变压器匝比。

</details>

#### 4.3.2 隔离型拓扑对比

| 拓扑 | 功率等级 | 器件应力 | 变压器利用率 | 控制复杂度 | 典型应用 |
|-----|---------|---------|-------------|-----------|---------|
| Flyback | ≤150W | 高 | 低 | 低 | 适配器、辅助电源 |
| Forward | 中小功率 | 中 | 中 | 中 | 工业控制、通讯电源 |
| 推挽 | 中功率 | 高 | 高 | 中-高 | 车载DC-DC |
| 半桥 | 中功率 | 中 | 高 | 高 | 服务器电源 |
| 全桥 | 中大功率 | 低 | 高 | 高 | 大功率DC-DC |

### 4.4 工作模式分析

#### 4.4.1 CCM/DCM/BCM定义

<details>
<summary>点击展开工作模式详细分析</summary>

**CCM (Continuous Conduction Mode)：**
- 电感电流在整个开关周期内都大于零
- 适用于大功率场合
- 输出纹波小，效率高

**DCM (Discontinuous Conduction Mode)：**
- 电感电流在开关周期的一部分时间内为零
- 适用于小功率场合
- 控制简单，但输出纹波大

**BCM (Boundary Conduction Mode)：**
- 电感电流刚好在开关周期结束时降到零
- 临界状态
- 常用于PFC电路

**边界条件：**
对于Buck电路：
$$L = \frac{V_o(1-D)}{2f_s I_o}$$

当实际电感 $L < L_{critical}$ 时，电路工作在DCM模式；
当实际电感 $L > L_{critical}$ 时，电路工作在CCM模式。

</details>

### 5.2 电压型逆变电路

#### 5.2.1 单相半桥逆变电路

     +

#### 5.4.1 换流方式分类

|---------|------|---------|---------|
| 器件换流 | 利用全控器件的自关断能力 | 全控器件 | 逆变电路 |
| 电网换流 | 电网提供换流电压 | 与电网连接的电路 | 整流电路 |
| 负载换流 | 负载提供换流电压 | 容性负载 | 特殊应用 |
| 强迫换流 | 附加换流电路强迫换流 | 半控器件 | 早期应用 |

#### 5.4.2 强迫换流原理

<details>
<summary>点击展开强迫换流原理分析</summary>

**电容换流原理：**

1. **换流准备阶段：**
   - 主晶闸管VT1导通，负载获得电压
   - 辅助晶闸管VT2关断，换流电容C充电

2. **换流阶段：**
   - 触发辅助晶闸管VT2
   - 电容C通过VT2和VT1放电
   - VT1电流逐渐减小直至关断
   - VT2电流逐渐增大直至导通

3. **换流完成：**
   - VT1完全关断
   - VT2导通，负载获得反向电压

**换流时间：**
$$t_c = \pi\sqrt{LC}$$

其中L为换流电感，C为换流电容。

</details>

## 6. 交流变换电路

### 6.1 交流调压电路

#### 6.1.1 单相交流调压电路

##### 电路拓扑

```
    u2
     ~
    ┌─┐
    │ │  T
    └─┘
     │
    VT1    VT2
    ┌─┐  ┌─┐
    │ │  │ │
    └─┘  └─┘
     │    │
    ┌─┬─┬─┬─┐
    │ │ │ │ │  R
    └─┴─┴─┴─┘
     │
    ─┴─
```

##### 调压原理

<details>
<summary>点击展开单相交流调压原理</summary>

**工作过程：**

1. **正半周 (0 ≤ ωt < π)：**
   - VT1承受正向电压
   - 触发角为α时，VT1导通
   - 负载电压：$u_o = u_2$

2. **负半周 (π ≤ ωt < 2π)：**
   - VT2承受正向电压
   - 触发角为α+π时，VT2导通
   - 负载电压：$u_o = u_2$

3. **关断过程：**
   - 电流过零时，晶闸管自然关断

</details>

##### 电压调节公式

<details>
<summary>点击展开交流调压公式推导</summary>

**输出电压有效值：**

对于电阻负载，输出电压有效值为：
$$U_o = U_2 \sqrt{\frac{1}{2\pi} \int_{\alpha}^{\pi} \sin^2(\omega t) d(\omega t)}$$

$$U_o = U_2 \sqrt{\frac{1}{2} - \frac{\alpha}{2\pi} + \frac{\sin(2\alpha)}{4\pi}}$$

其中 $U_2$ 为输入电压有效值。

**特殊情况：**
- 当 α = 0° 时：$U_o = U_2$（满导通）
- 当 α = 180° 时：$U_o = 0$（全关断）

**输出功率：**
$$P_o = \frac{U_o^2}{R}$$

</details>

#### 6.1.2 三相交流调压电路

##### 三相三线制

- 负载通常接成三角形或星形
- 不需要中性线
- 适用于三相平衡负载

##### 三相四线制

- 负载可以接成星形
- 需要中性线
- 适用于不平衡负载

### 6.2 交流调功电路

#### 6.2.1 周波控制原理

<details>
<summary>点击展开周波控制原理</summary>

**控制方法：**

1. **导通m个周波，关断n个周波**
2. **控制周期为m+n个周波**
3. **负载获得的平均功率：**
   $$P_o = \frac{m}{m+n} \times P_{max}$$

其中 $P_{max}$ 为满导通时的功率。

**特点：**
- 输出功率连续可调
- 输出电压和电流波形完整
- 谐波含量小
- 适用于大惯性负载

</details>

### 6.3 交-交变频电路

#### 6.3.1 单相交-交变频电路

##### 电路组成

- P组：正组反并联整流电路
- N组：负组反并联整流电路
- 两组电路交替工作

##### 工作原理

<details>
<summary>点击展开交-交变频工作原理</summary>

**输出频率控制：**

1. **P组工作期间：**
   - 输出电压与输入电压同相
   - 负载电流为正

2. **N组工作期间：**
   - 输出电压与输入电压反相
   - 负载电流为负

3. **切换频率：**
   - 控制两组电路的切换频率
   - 从而控制输出频率

**输出频率限制：**
$$f_o < \frac{f_i}{3}$$

其中 $f_i$ 为输入频率，$f_o$ 为输出频率。

</details>

#### 6.3.2 三相交-交变频电路

- 由三组单相交-交变频电路组成
- 分别输出三相交流电
- 需要考虑三相之间的相位关系

### 6.4 矩阵变换器

#### 6.4.1 基本结构

3×3矩阵变换器由9个双向开关组成：
$$\begin{bmatrix} v_{o1} \\ v_{o2} \\ v_{o3} \end{bmatrix} = \begin{bmatrix} s_{11} & s_{12} & s_{13} \\ s_{21} & s_{22} & s_{23} \\ s_{31} & s_{32} & s_{33} \end{bmatrix} \begin{bmatrix} v_{i1} \\ v_{i2} \\ v_{i3} \end{bmatrix}$$

其中 $s_{ij}$ 为开关状态函数。

| 输入输出性能好 | 成本高 |

## 7. PWM控制技术

### 7.1 PWM控制基本原理

#### 7.1.1 面积等效原理

<details>
<summary>点击展开面积等效原理</summary>

**基本思想：**
冲量相等而形状不同的窄脉冲作用于惯性环节时，其效果基本相同。

**数学表达：**
$$\int_{t_1}^{t_2} f(t) dt = \text{常数}$$

**应用：**
可以用宽度按正弦规律变化的脉冲序列来等效地表示正弦波。

</details>

#### 7.1.2 PWM调制系统

**基本组成：**
- 调制波：需要输出的波形（正弦波）
- 载波：高频三角波或锯齿波
- 比较器：产生PWM信号

### 7.2 SPWM调制技术

#### 7.2.1 单极性SPWM

##### 调制原理

<details>
<summary>点击展开单极性SPWM原理</summary>

**载波信号：**
- 单极性三角波
- 频率：$f_c$
- 幅值：$U_c$

**调制波信号：**
- 双极性正弦波
- 频率：$f_s$
- 幅值：$U_m$

**调制深度：**
$$m_a = \frac{U_m}{U_c}$$

**载波比：**
$$p = \frac{f_c}{f_s}$$

**输出PWM：**
当调制波 > 载波时，输出高电平；
当调制波 < 载波时，输出低电平。

</details>

#### 7.2.2 双极性SPWM

##### 特点

- 载波信号是双极性的三角波
- 调制波是双极性的正弦波
- 输出PWM是双极性的
- 开关损耗较大，但控制简单

### 7.3 SPWM输出特性分析

#### 7.3.1 基波电压

<details>
<summary>点击展开SPWM基波电压推导</summary>

**双极性SPWM输出电压：**

对于双极性SPWM逆变电路，输出电压的基波分量为：
$$u_1(t) = \frac{4U_d}{\pi} \cdot \frac{m_a}{2} \sin(\omega_s t)$$

其中：
- $U_d$：直流母线电压
- $m_a$：调制深度
- $\omega_s$：调制波角频率

**基波电压幅值：**
$$U_{1m} = \frac{m_a U_d}{2}$$

**基波电压有效值：**
$$U_1 = \frac{U_{1m}}{\sqrt{2}} = \frac{m_a U_d}{2\sqrt{2}}$$

</details>

#### 7.3.2 直流电压利用率

<details>
<summary>点击展开直流电压利用率计算</summary>

**定义：**
直流电压利用率定义为输出线电压基波有效值与直流母线电压之比。

**计算公式：**
$$\eta = \frac{U_{1(线)}}{U_d} = \frac{2\sqrt{2}}{\pi} \cdot \frac{U_{1(相)}}{U_d}$$

**SPWM的直流电压利用率：**
- 线性区：$\eta = \frac{2\sqrt{2}}{\pi} \approx 0.9$
- 过调制区：$\eta > 0.9$

**SVPWM的直流电压利用率：**
$$\eta_{SVPWM} = \frac{2}{\sqrt{3}} \cdot \frac{2\sqrt{2}}{\pi} \approx 1.1$$

比SPWM高约15%。

</details>

### 7.4 空间矢量PWM(SVPWM)

#### 7.4.1 基本空间矢量

<details>
<summary>点击展开SVPWM原理</summary>

**8个基本电压矢量：**

- 6个非零矢量：$V_1$ 到 $V_6$
- 2个零矢量：$V_0$ 和 $V_7$

**非零矢量幅值：**
$$|V_k| = \frac{2U_d}{3}$$

**矢量角度：**
$$V_k = \frac{2U_d}{3} \angle (k-1) \times 60° \quad (k = 1,2,...,6)$$

</details>

#### 7.4.2 矢量合成

##### 合成原理

任意期望输出电压矢量 $V^*$ 可以由三个相邻基本矢量合成：
$$V^* = d_k V_k + d_{k+1} V_{k+1} + d_0 V_0$$

其中占空比为：
$$d_k = \frac{2}{\sqrt{3}} \frac{|V^*|}{U_d} \sin\left(\frac{\pi}{3} - \theta\right)$$
$$d_{k+1} = \frac{2}{\sqrt{3}} \frac{|V^*|}{U_d} \sin(\theta)$$
$$d_0 = 1 - d_k - d_{k+1}$$

## 9. 考试重点总结

### 9.1 器件部分考试重点

#### 9.1.1 器件特性比较

| 器件 | 驱动方式 | 开关频率 | 功率容量 | 典型应用 |
|-----|---------|---------|---------|---------|
| 二极管 | 不可控 | 中 | 中 | 整流、续流 |
| SCR | 电流驱动 | 低 | 最高 | 相控整流 |
| GTO | 电流驱动 | 低 | 第2高 | 高压换流 |
| MOSFET | 电压驱动 | 最高 | 最小 | 高频开关 |
| IGBT | 电压驱动 | 第2高 | 第3高 | 逆变器 |

#### 9.1.2 重要参数计算

**二极管：**
- 正向平均电流与有效值关系：$I_{rms} = 1.57 \times I_F(AV)$

**晶闸管：**
- 通态平均电流与有效值关系：$I_{rms} = 1.57 \times I_T(AV)$
- 擎住电流与维持电流关系：$I_L = (2-4) \times I_H$

**器件选型原则：**
- 电压和电流额定值留有2-3倍安全裕度

### 9.2 整流电路考试重点

#### 9.2.1 基本公式

| 电路类型 | 输出电压公式 | 适用条件 |
|---------|-------------|---------|
| 单相半波可控 | $U_d = \frac{\sqrt{2}U_2}{\pi} \cdot \frac{1 + \cos\alpha}{2}$ | 电阻负载 |
| 单相桥式全控 | $U_d = 0.9U_2 \cdot \frac{1 + \cos\alpha}{2}$ | 电阻负载 |
| 三相桥式全控 | $U_d = 2.34U_2 \cos\alpha$ | α ≤ 30° |

#### 9.2.2 有源逆变条件

3. 交流侧必须与电网连接

### 9.3 DC-DC变换器考试重点

#### 9.3.1 基本拓扑公式

| 拓扑 | 电压关系 | 电流路径 | 输出纹波 |
|-----|---------|---------|---------|
| Buck | $V_o = V_i \times D$ | 导通：电源→电感→负载 | 随L、C增大而降低 |
| Boost | $V_o = \frac{V_i}{1-D}$ | 导通：电源→电感 | 受ESR/ESL与C影响 |
| Buck-Boost | $V_o = -V_i \cdot \frac{D}{1-D}$ | 导通：电源→电感 | 相对较大，极性反转 |

#### 9.3.2 工作模式

**CCM (连续导通模式)：**
- 电感电流在整个开关周期内都大于零
- 适用于大功率场合

**DCM (断续导通模式)：**
- 电感电流在开关周期的一部分时间内为零
- 适用于小功率场合

**BCM (临界导通模式)：**
- 电感电流刚好在开关周期结束时降到零
- 常用于PFC电路

#### 9.3.3 伏秒平衡原理

**数学表达：**
$$\int_0^T v_L(t) dt = 0$$

**物理意义：**
在一个开关周期内，电感储存的能量等于释放的能量。

#### 9.3.4 常见考试题型

**计算题：**
- 给定输入电压和占空比，计算输出电压
- 计算临界电感和输出电容

**分析题：**
- 分析不同工作模式下电感电流波形
- 分析占空比对输出电压的影响

**设计题：**
- 设计Buck变换器的电感和电容参数
- 选择合适的开关管和二极管

### 9.4 逆变电路考试重点

#### 9.4.1 PWM调制技术

**SPWM调制：**
- 调制波：正弦波
- 载波：三角波
- 调制深度：$m_a = \frac{U_m}{U_c}$
- 载波比：$p = \frac{f_c}{f_s}$

**基波电压：**
$$U_{1m} = \frac{m_a U_d}{2}$$

**直流电压利用率：**
$$\eta = \frac{U_{1(线)}}{U_d} = \frac{2\sqrt{2}}{\pi} \approx 0.9$$

#### 9.4.2 换流方式

| 换流方式 | 原理 | 适用器件 | 应用场合 |
|---------|------|---------|---------|
| 器件换流 | 利用全控器件的自关断能力 | 全控器件 | 逆变电路 |
| 电网换流 | 电网提供换流电压 | 与电网连接的电路 | 整流电路 |
| 负载换流 | 负载提供换流电压 | 容性负载 | 特殊应用 |
| 强迫换流 | 附加换流电路强迫换流 | 半控器件 | 早期应用 |

#### 9.4.3 常见考试题型

**计算题：**
- 给定直流母线电压和调制比，计算输出电压基波幅值
- 计算直流电压利用率

**分析题：**

**设计题：**

### 9.5 交流变换电路考试重点

#### 9.5.1 交流调压电路

**单相交流调压：**
$$U_o = U_2 \sqrt{\frac{1}{2} - \frac{\alpha}{2\pi} + \frac{\sin(2\alpha)}{4\pi}}$$

**触发延迟角控制范围：**
- 单相：0° ≤ α ≤ 180°
- 三相：0° ≤ α ≤ 150°

#### 9.5.2 交-交变频电路

**输出频率限制：**
$$f_o < \frac{f_i}{3}$$

**基本原理：**
- P组和N组反并联工作
- 通过控制触发延迟角输出可调频率的交流电
