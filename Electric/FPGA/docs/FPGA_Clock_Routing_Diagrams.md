## 时钟缓冲器类型对比表

| 缓冲器类型 | 覆盖范围 | 偏斜特性 | 驱动能力 | 功耗 | 主要应用 |
|-----------|---------|---------|---------|------|---------|
| BUFG | 全局 | < 50ps | 高 | 中等 | 全局时钟 |
| BUFH | 水平区域 | < 100ps | 中等 | 低 | 区域时钟 |
| BUFR | 区域 | < 100ps | 中等 | 低 | 局部时钟 |
| BUFIO | I/O列 | < 25ps | 专用 | 专用 | I/O接口 |
| BUFMR | 多区域 | < 75ps | 中等 | 中等 | 跨区域时钟 |

## 时序约束规范

### 全局时钟约束
```
create_clock -period 10.000 -name clk_global [get_ports clk]
set_clock_uncertainty -setup 0.250 clk_global
set_clock_uncertainty -hold 0.100 clk_global
```

### 区域时钟约束
```
create_clock -period 5.000 -name clk_region [get_pins region_bufg/O]
set_clock_groups -asynchronous -group clk_global -group clk_region
```

### I/O时钟约束
```
create_clock -period 2.500 -name clk_io [get_pins bufio/O]
set_input_delay -clock clk_io 1.000 [get_ports data_in]
set_output_delay -clock clk_io 1.000 [get_ports data_out]
```

## 功耗优化策略

### 动态功耗计算
```
P_dynamic = α × C × V² × f
```
其中：
- α: 开关活动因子
- C: 负载电容
- V: 工作电压
- f: 工作频率

### 时钟门控技术
1. **全局门控**: 关闭整个时钟域
2. **模块门控**: 关闭特定功能模块
3. **寄存器级门控**: 关闭特定寄存器
4. **条件门控**: 基于条件信号的门控
