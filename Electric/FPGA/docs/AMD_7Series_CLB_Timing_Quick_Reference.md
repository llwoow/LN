# AMD 7系列CLB时序参数速查表

## 通用命名约定
- `T<sub>source</sub><sub>destination</sub>`: 基本时序参数
- `TXXCK`: 建立时间
- `TCKXX`: 保持时间

## 1. 组合逻辑延迟

| 参数 | 描述 | 路径 |
|------|------|------|
| TILO | LUT直接输出延迟 | LUT A/B/C/D → A/B/C/D |
| TITO | 通过锁存器输出延迟 | LUT A/B/C/D → AQ/BQ/CQ/DQ |
| TILO_2 | F7/F8多路复用器延迟 | A/C → AMUX/CMUX |

## 2. 时钟到输出延迟

| 参数 | 描述 | 路径 |
|------|------|------|
| TCKO | FF时钟到输出 | FF时钟 → AQ/BQ/CQ/DQ |
| TCKLO | 锁存器时钟到输出 | 锁存器时钟 → AQ/BQ/CQ/DQ |
| TSHCKO | FF时钟到多路复用器 | FF时钟 → AMUX/BMUX/CMUX/DMUX |

## 3. 建立/保持时间

| 参数 | 类型 | 描述 |
|------|------|------|
| TAS/TAH | 数据 | A/B/C/D输入建立/保持时间 |
| TDICK/TCKDI | 数据 | AX/BX/CX/DX输入建立/保持时间 |
| TCECK/TCKCE | 控制 | CE（时钟使能）建立/保持时间 |
| TSRCK/TCKSR | 控制 | SR（同步复位）建立/保持时间 |

## 4. 置位/复位特性

| 参数 | 描述 |
|------|------|
| TRPW (TSRMIN) | 最小SR脉冲宽度 |
| TRQ | 异步SR传播到输出的延迟 |
| FTOG | FF最大切换频率 |

## 5. 宽多路复用器时序

| 参数 | 描述 |
|------|------|
| TAXA/TAXB/TBXB/TCXB/TCXC | AX/BX/CX输入到多路复用器延迟 |
| TOPAB/TOPBA/TOPBB/TOPCB/TOPDB/TOPDC | A/B/C/D输入到多路复用器延迟 |

## 6. 进位链时序参数

| 参数 | 描述 |
|------|------|
| TAXA–TDXD | 输入到进位输出延迟 |
| TAXCY/TBXCY/TCXCY/TDXCY | 输入到COUT延迟 |
| TBYP | CIN到COUT进位旁路延迟 |
| TOPCYA–TOPCYD | A/B/C/D到COUT延迟 |
| TCINA–TCIND | CIN到多路复用器延迟（通过XOR） |
| TCINCK/TCKCIN | CIN相对于CLK的建立/保持时间 |

## 7. 分布式RAM时序（SLICEM专用）

| 参数 | 描述 |
|------|------|
| TSHCKO | CLK到RAM输出延迟 |
| TAS/TAH | 地址建立/保持时间 |
| TDS/TDH | 数据输入建立/保持时间 |
| TWS/TWH | 写使能建立/保持时间 |
| TMPW | 最小时钟脉冲宽度 |
| TMCP | 地址写周期最小时钟周期 |

## 8. SRL移位寄存器时序（SLICEM专用）

| 参数 | 描述 |
|------|------|
| 标准SRLC32E参数 | 包含时钟、CE/SR路径的建立/保持时间 |
| 时钟到输出 | 移位寄存器输出延迟 |

## 时序计算公式

### 基本时序约束
```
时钟周期 ≥ 建立时间 + 保持时间 + 组合逻辑延迟 + 寄存器延迟
```

### 进位链延迟计算
```
总进位延迟 = n × 单级进位延迟 + 各级间连接延迟
```

### RAM访问时间
```
读访问时间 = 地址建立时间 + RAM访问延迟 + 时钟到输出延迟
写访问时间 = 数据建立时间 + 地址建立时间 + 写使能建立时间
```

## 设计注意事项

### 1. 进位链使用
- ✅ 垂直放置在每隔一列
- ✅ 自动放置由工具完成
- ❌ 避免跨SLR级联（SSI器件）
- ✅ 作为组进行布局规划

### 2. 时序分析建议
- 使用AMD Timing Analyzer进行验证
- 结合器件数据手册获取具体数值
- 考虑温度和电压变化的影响
- 在时序报告中验证参数使用

### 3. 性能优化
- 合理使用进位链提高算术运算性能
- 考虑分布式RAM和SRL的资源利用
- 对于宽位宽算术运算，考虑使用DSP48E1切片
