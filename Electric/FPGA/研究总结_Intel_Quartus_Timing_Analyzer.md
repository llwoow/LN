### 3. 数学公式和计算方法

#### 3.1 Setup时序分析公式
```
Data Arrival Time = Launch Edge + Clock Network Delay + Data Path Delay
Data Required Time = Latch Edge + Clock Network Delay - Setup Time
Setup Slack = Data Required Time - Data Arrival Time
```

#### 3.2 多周期计算示例
- **场景：** 源时钟10ns → 目标时钟5ns，多周期数=2
- **默认Setup：** 5ns周期约束
- **多周期Setup：** 12.5ns周期约束
- **计算公式：** (多周期数 × 目标时钟周期) + (源时钟周期 - 目标时钟周期)

#### 3.3 Hold时序分析
```
Hold Slack = Data Arrival Time - (Latch Edge + Clock Network Delay + Hold Time)
```
